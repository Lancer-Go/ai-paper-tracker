影响报告Impact Statements

这项工作通过将孤立的试错经验转化为可在代理和环境之间共享的可重用的结构化技能知识库，推进了可推广的代理学习。 通过使较弱的智能体能够从较强的智能体提取的技能中受益，所提出的框架减少了冗余探索，提高了样本效率，并降低了训练 LLM 智能体的计算和环境成本。 即插即用设计促进了模块化和可重复性，支持在长期、用户交互式应用中更广泛的采用。潜在风险包括过度依赖预先建立的技能以及源代理中存在的偏见的传播；然而，自动化的细化和扩展机制提供了一条缓解停滞和鼓励持续适应的途径。This work advances generalizable agent learning by transforming isolated trial-and-error experience into a reusable, structured skill knowledge base that can be shared across agents and environments. By enabling weaker agents to benefit from skills distilled by stronger ones, the proposed framework reduces redundant exploration, improves sample efficiency, and lowers the computational and environmental costs of training LLM agents. The plug-and-play design promotes modularity and reproducibility, supporting broader adoption in long-horizon, user-interactive applications. Potential risks include over-reliance on pre-built skills and the propagation of biases present in source agents; however, the automated refinement and expansion mechanisms provide a pathway to mitigate stagnation and encourage continual adaptation.

局限性Limitations

跨环境转移。Cross-environment transfer. 技能XSkillX目前，当技能可以扎根于相对稳定的工具环境中时，它是最自然适用的。提取的技能与特定的工具模式相关联，这使得跨不同领域或工具生态系统的直接重用变得不那么简单。is currently most naturally applicable when skills can be grounded in a relatively stable tool environment. 用户交互设置。User-interactive settings.当前的研究主要集中在使用工具的代理环境。更多的用户交互场景，特别是没有函数调用的对话场景，还不是这项工作的主要重点。The current study focuses mainly on tool-using agent environments. More user interactive scenarios, particularly dialogue scenarios without function calls, are not yet the primary focus of this work.

Berkeley 函数调用排行榜 V3 (BFCL-v3)Berkeley Function Calling Leaderboard V3 (BFCL-v3)(Patil et al., 2025)是评估大型语言模型中函数调用和工具使用的基准。它强调多回合交互和多步骤推理。该基准测试包含超过 1,800 个测试实例，并支持多种编程语言，包括 Python、Java 和 JavaScript。模型需要生成有效的 API 调用并处理重要的交互模式。评估同时考虑结构有效性和功能正确性。我们首先使用抽象语法树分析检查生成的代码在语法上是否有效，然后执行它以验证输出是否与预期结果匹配。仅当代理以正确的语法生成所有必需的函数调用并返回正确的计算结果时，任务才被视为成功。在这项工作中，我们报告了 Avg@4，它衡量四个独立试验的平均任务成功率，以及 Pass@4，它衡量四个试验中至少一个成功的概率。is a benchmark for evaluating function calling and tool use in large language models. It emphasizes multi-turn interaction and multi-step reasoning. The benchmark contains over 1,800 test instances and supports multiple programming languages, including Python, Java, and JavaScript. Models are required to generate valid API calls and handle non-trivial interaction patterns. Evaluation considers both structural validity and functional correctness. We first check whether the generated code is syntactically valid using Abstract Syntax Tree analysis, and then execute it to verify that the outputs match the expected results. A task is considered successful only when the agent produces all required function calls with correct syntax and returns the correct computational outcomes. In this work, we report Avg@4, which measures the average task success rate across four independent trials, and Pass@4, which measures the probability that at least one of the four trials succeeds.

应用世界Appworld

应用世界AppWorld(Trivedi et al., 2024)是一个基准套件，用于在实际应用程序环境中评估函数调用代理和交互式编码系统。它模拟了由九种广泛使用的应用程序组成的生态系统，例如电子邮件服务、音乐流媒体平台和支付系统，并提供 457 个 API 端点以及来自大约 100 个虚拟用户的活动数据。 AppWorld 中的任务通常是长期的，需要执行扩展的相互依赖的操作序列。许多任务涉及发现适当的 API，而不是直接重用熟悉的模式，这对探索和规划提出了额外的要求。该基准测试还显示出训练集和测试集之间存在明显的分布差距，其中测试集中的 API 使用模式和任务结构与训练期间观察到的不同。此外，任务执行与不断变化的环境状态紧密耦合。中间动作会修改系统状态并影响未来的决策，这会增加对规划错误的敏感性并使稳健的多步骤推理变得更加困难。评估基于状态驱动的单元测试，从多个方面评估任务完成情况。 AppWorld 提供任务级和场景级指标。在这项工作中，我们使用任务目标完成作为绩效的主要衡量标准。按照标准方案，我们报告了四项独立试验的 Avg@4 和 Pass@4。is a benchmark suite for evaluating function calling agents and interactive coding systems in realistic application environments. It simulates an ecosystem of nine widely used applications, such as email services, music streaming platforms, and payment systems, and provides 457 API endpoints together with activity data from around 100 virtual users. Tasks in AppWorld are typically long-horizon and require executing extended sequences of interdependent actions. Many tasks involve discovering appropriate APIs rather than directly reusing familiar patterns, which places additional demands on exploration and planning. The benchmark also exhibits a noticeable distribution gap between training and test sets, where API usage patterns and task structures in the test set differ from those observed during training. In addition, task execution is tightly coupled with the evolving environment state. Intermediate actions modify the system state and influence future decisions, which increases sensitivity to planning errors and makes robust multi-step reasoning more difficult. Evaluation is based on state-driven unit tests that assess task completion from multiple aspects. AppWorld provides both task-level and scenario-level metrics. In this work, we use Task Goal Completion as the primary measure of performance. Following the standard protocol, we report Avg@4 and Pass@4 across four independent trials.

τ2\tau^{2}-长凳-Bench (Barres et al., 2025)评估对话代理设置中的工具使用情况，重点关注用户与代理的交互。该基准测试模拟用户和代理之间的多轮对话，旨在反映真实的对话行为。代理必须跟踪对话上下文、解释用户请求、适当选择和调用 API，并遵循特定于领域的业务规则。这些任务涵盖航空公司客户服务和零售客户服务等领域。基准测试的交互性质要求代理响应用户反馈，保持连贯的对话流程，并协调工具的使用与正在进行的对话。根据任务完成的准确性、工具使用的正确性以及对政策的遵守情况来评估绩效。在这项工作中，我们对每个任务进行四次独立试验，并在三个领域中的每一个领域报告 Pass@1。evaluates tool use in conversational agent settings, with a strong emphasis on user-agent interaction. The benchmark simulates multi-turn dialogues between a user and an agent, aiming to reflect realistic conversational behavior. Agents must track dialogue context across turns, interpret user requests, select and invoke APIs appropriately, and follow domain-specific business rules. The tasks cover domains such as airline customer service and retail customer service. The interactive nature of the benchmark requires agents to respond to user feedback, maintain coherent dialogue flow, and coordinate tool use with the ongoing conversation. Performance is assessed based on task completion accuracy, correctness of tool use, and compliance with policies. In this work, we conduct four independent trials per task and report Pass@1 on each of the three domains.

A-Mem (Xu et al., 2025)是一个代理记忆框架，使基于 LLM 的代理能够在扩展交互中维护和利用长期知识。 该方法将积累的经验组织成以记忆为中心的结构，使代理能够根据任务目标和观察到的结果有选择地保留、检索和修改存储的信息。 A-Mem 没有将内存视为被动日志，而是强调由智能体的目标和交互上下文驱动的自主内存管理。 在我们的实验中，我们根据其公开可用的实现重现了 A-Mem，并进行了细微的提示调整以支持任务交互期间的记忆写入和组织。is an agentic memory framework that equips LLM-based agents with the ability to maintain and utilize long-term knowledge over extended interactions. The method organizes accumulated experiences into a memory-centric structure, enabling agents to selectively retain, retrieve, and revise stored information according to task objectives and observed outcomes. Rather than treating memory as a passive log, A-Mem emphasizes autonomous memory management driven by the agent’s goals and interaction context. In our experiments, we reproduce A-Mem based on its publicly available implementation, with minor prompt adaptations to support memory writing and organization during task interactions.

A.3 实施细节Implementation Details

技能提取。Skills Extraction.

在经验提取阶段，包括推理和经验提取，我们采用GLM-4.6，温度为0.9。对于训练集中的每个任务，我们独立采样四个轨迹。超过1500个token的环境反馈被汇总。我们使用 DBSCAN（基于密度的噪声应用程序空间聚类）对提取的技能进行聚类，余弦相似度阈值为 0.9。对于每个集群，我们将技能集截断为最多 15 个技能。技能更新最多可进行三轮迭代细化。 在技​​能扩展阶段，我们将探索模型温度设置为1.0，并为每个训练任务执行1次探索环境。During the experience extraction stage, which comprises both reasoning and experience extraction, we employ GLM-4.6 with a temperature of 0.9. For each task in the training set, we independently sample four trajectories. Environment feedback exceeding 1500 tokens is summarized. We cluster the extracted skills using DBSCAN (Density-Based Spatial Clustering of Applications with Noise) with a cosine similarity threshold of 0.9. For each cluster, we truncate the skill set to at most 15 skills. Skill updates are performed with up to three iterative refinement rounds. During the skill expansion stage, we set the exploration model temperature to 1.0 and perform 1 time to explore environment for each training task.

技能使用。Skills Usage.

我们使用 FAISS 和余弦相似度下的 HNSW 索引构建技能语义向量存储（通过 L2 归一化嵌入和内积搜索）。在查询时，我们首先对前 100 个最接近的技能进行广泛检索。然后通过混合相关性阈值过滤候选对象：我们仅保留余弦相似度至少为 0.45 且与该查询的最佳匹配相差在 0.08 以内的结果，从而确保最低质量下限和自适应选择性。为了减少接近重复的技能，我们通过删除成对余弦相似度超过 0.95 的项目来应用语义去重，保留得分较高的代表。最后，在应用最大边际相关性 (MMR) 进行多样性感知选择后，我们返回最多 8 项技能，使用相关性-多样性权衡权重 0.75 来强调相关性，同时减少冗余。We build a skill semantic vector store using FAISS with an HNSW index under cosine similarity (via L2-normalized embeddings and inner-product search). At query time, we first perform a broad retrieval of the Top‑100 nearest skills. Candidates are then filtered by a hybrid relevance threshold: we keep only results whose cosine similarity is at least 0.45, and also within 0.08 of the best match for that query, ensuring both a minimum quality floor and adaptive selectivity. To reduce near-duplicate skills, we apply semantic deduplication by removing items whose pairwise cosine similarity exceeds 0.95, retaining the higher-scoring representative. Finally, we return up to 8 skills after applying Maximal Marginal Relevance (MMR) for diversity-aware selection, using a relevance–diversity trade-off weight of 0.75 to emphasize relevance while mitigating redundancy.

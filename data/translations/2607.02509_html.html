1 简介Introduction

However, longer context windows do not guarantee reliable long-context reasoning. 标准的长上下文提示需要一个模型在一次推理过程中读取上下文并回答查询。随着背景的发展，证据必须与越来越多的不相关信息竞争，这使得模型更难确定其答案并导致错误或幻觉Standard long-context prompting requires a model to read the context and answer the query in a single inference pass. As the context grows, the evidence must compete with increasing irrelevant information, making it harder for the model to ground its answers and leading to errors or hallucinations(Li et al., 2024; Liu et al., 2025)。最近的努力从不同角度解决了这个问题：注意力干预方法修改低级模型行为. Recent efforts address this problem from different angles: attention intervention methods modify low-level model behavior(Li et al., 2024; Tang et al., 2024; Ye et al., 2026)，使它们具有侵入性，因为它们需要改变骨干转发或解码逻辑。检索和外部记忆方法添加检索系统, making them invasive because they require changing the backbone forward or decoding logic. Retrieval and external-memory methods add retrieval systems(Lewis et al., 2021; Xu et al., 2025)，而压缩方法缩短了有效输入, while compression methods shorten the effective input(Jiang et al., 2023, 2024; Zhao et al., 2025c)，两者通常都依赖于检索的、压缩的或 LLM 总结的证据视图，这可能会丢失细粒度的细节，并且在复杂的多跳任务上变得不稳定。这表明上下文工具不应仅限于检索或减少输入。相反，在保留对原始输入的完全访问的同时，它应该根据当前推理阶段动态查询和维护支持证据的存储库，帮助模型在长上下文中执行高质量的推理。, both often rely on retrieved, compressed, or LLM-summarized evidence views, which may lose fine-grained details and become unstable on complex multi-hop tasks. This suggests that a context harness should not be limited to retrieving or reducing the input. Instead, while preserving full access to the original input, it should dynamically query and maintain a repository of supporting evidence according to the current reasoning stage, helping the model perform high-quality reasoning over long contexts.

5 结论Conclusion

我们呈现We present重新关联ReContext，一种免训练方法，可将模型内部相关信号转化为长上下文推理的明确证据支架。, a training-free method that turns model-internal relevance signals into an explicit evidence scaffold for long-context reasoning.重新关联ReContext递归地选择候选证据并在答案生成之前重播组织好的支架，同时保留原始上下文，从而将证据组织与答案生成分开。我们的联想记忆分析对此过程提供了一个简单的解释，即线索条件跟踪重新激活，并且我们在 8 个 128K 上下文数据集和三个骨干网中进行的实验显示了相对于强长上下文基线的一致改进。 这些发现表明，长上下文推理不仅可以通过扩展上下文窗口或压缩输入来改进，还可以通过更好地组织提示中已有的证据来改进。recursively selects candidate evidence and replays the organized scaffold before answer generation while preserving the original context, thereby separating evidence organization from answer generation. Our associative-memory analysis provides a simple interpretation of this process as cue-conditioned trace reactivation, and our experiments across eight 128K-context datasets and three backbones show consistent improvements over strong long-context baselines. 长上下文建模和评估。Long-context modeling and evaluation.

最近的长上下文研究通过有效的注意力、位置外推和长上下文微调，大大扩展了法学硕士可以处理的输入长度Recent long-context research has substantially expanded the input length that LLMs can process through efficient attention, position extrapolation, and long-context fine-tuning(Beltagy et al., 2020; Zaheer et al., 2020; Peng et al., 2023; Chen et al., 2024; Ding et al., 2023, 2024; Zhao et al., 2023; Ren et al., 2025; Ning et al., 2026; Guo et al., 2024; Wei et al., 2026)。与此同时，长上下文基准测试已将评估不仅仅局限于输入长度，涵盖文档理解、多文档推理、检索、摘要、代码和综合压力测试. In parallel, long-context benchmarks have shifted evaluation beyond input length alone, covering document understanding, multi-document reasoning, retrieval, summarization, code, and synthetic stress tests(Bai et al., 2024; Shaham et al., 2023; An et al., 2023; Zhang et al., 2024; Hsieh et al., 2024; Yen et al., 2025; Zhao et al., 2026)。这些研究澄清了上下文访问和上下文利用之间的一个重要区别：模型可能接受很长的提示，但仍然无法找到或使用特定问题所需的证据。这种差距也反映在位置敏感性分析中，当相关信息出现在不太有利的位置时，相关信息可能没有得到充分利用. These studies clarify an important distinction between context access and context utilization: a model may accept a long prompt while still failing to locate or use the evidence needed for a particular question. This gap is also reflected in analyses of position sensitivity, where relevant information can be underused when it appears in less favorable locations(Liu et al., 2023a). 重新关联ReContext在不改变主干模型或扩展其上下文窗口的情况下解决了这个利用问题。它保持原始上下文可用，但添加了一个查询条件的证据支架，使候选支持跨度在接近生成时更容易访问。addresses this utilization problem without changing the backbone model or extending its context window. It keeps the original context available, but adds a query-conditioned evidence scaffold that makes candidate supporting spans more accessible near generation time.

检索、外部存储器和即时压缩。Retrieval, external memory, and prompt compression.

检索增强生成和检索增强语言建模通过在生成之前检索相关段落或块来改善基础Retrieval-augmented generation and retrieval-enhanced language modeling improve grounding by retrieving relevant passages or chunks before generation(Lewis et al., 2021; Borgeaud et al., 2022)，而最近的代理记忆系统跨交互维护和查询外部记忆结构, while recent agentic memory systems maintain and query external memory structures across interactions(Xu et al., 2025)。提示和上下文压缩方法采用不同的途径：它们通过过滤、修剪或压缩信息量较少的内容来减少传递给模型的文本量. Prompt and context compression methods take a different route: they reduce the amount of text passed to the model by filtering, pruning, or compressing less informative content(Li et al., 2023; Jiang et al., 2023, 2024; Zhao et al., 2025c, a)。这些方法可以减少干扰和计算，但它们也引入了额外的选择或压缩步骤，可能会忽略有用的证据。. These approaches can reduce distraction and computation, but they also introduce an additional selection or compression step that may omit useful evidence.重新关联ReContext是对这一工作的补充。它不会构建持久记忆、训练检索器或用缩短的版本替换原始的长上下文。相反，它使用模型自己的提示内部信号将候选证据范围复制到显式支架中，同时将提示中的完整上下文保留为后备信息源。is complementary to this line of work. It does not build a persistent memory, train a retriever, or replace the original long context with a shortened version. Instead, it uses the model’s own prompt-internal signals to copy candidate evidence spans into an explicit scaffold, while leaving the full context in the prompt as a fallback source of information.

基于注意力的推理和 KV 缓存方法。Attention-based inference and KV-cache methods.

几种推理时间方法使用内部注意模式来提高长上下文效率或利用率。查询感知稀疏性和动态注意力扩展方法使用注意力衍生信号来选择相关标记或在解码过程中调整注意力行为Several inference-time methods use internal attention patterns to improve long-context efficiency or utilization. Query-aware sparsity and dynamic attention-scaling methods use attention-derived signals to select relevant tokens or adjust attention behavior during decoding(Tang et al., 2024; Ye et al., 2026)。 KV 缓存方法的相关系列观察到长上下文注意力通常集中在重击者、注意力池或显着关键位置，并使用这种结构进行缓存保留或驱逐. A related line of KV-cache methods observes that long-context attention often concentrates on heavy hitters, attention sinks, or salient key positions, and uses this structure for cache retention or eviction(Liu et al., 2023b; Zhang et al., 2023; Xiao et al., 2024; Li et al., 2024; Cai et al., 2025; Feng et al., 2025; Zhao et al., 2025b; Dang et al., 2025). 重新关联ReContext目标和机制都有所不同。它不会在最终解码期间直接重新调整注意力逻辑，并且不会优化缓存预算。更重要的是，它仅将注意力视为一种廉价的提议信号，而不是对模型行为的忠实解释。选定的跨度被具体化为可读文本，因此最终生成以明确的证据支架为条件，而不仅仅是潜在的注意力干预。differs in both objective and mechanism. It does not directly rescale attention logits during final decoding and does not optimize a cache budget. More importantly, it treats attention only as an inexpensive proposal signal rather than as a faithful explanation of model behavior. The selected spans are materialized as readable text, so the final generation is conditioned on an explicit evidence scaffold rather than only on latent attention intervention.

联想记忆解释。Associative-memory interpretation.

的行为The behavior of重新关联ReContext也可以通过联想记忆镜头来观察。经典的联想记忆模型描述了从存储模式中进行内容可寻址的检索，而密集和现代的霍普菲尔德式公式将这种检索与更高容量的记忆和类似注意力的更新联系起来can also be viewed through an associative-memory lens. Classical associative-memory models describe content-addressable retrieval from stored patterns, while dense and modern Hopfield-style formulations connect such retrieval with higher-capacity memory and attention-like updates(Hopfield, 1982; Krotov and Hopfield, 2016; Ramsauer et al., 2021; Krotov et al., 2025; Zhao et al., 2024; Chen et al., 2025)。相关的神经记忆架构，包括记忆网络和键值记忆网络，框架推理作为对存储表示或事实的查询条件访问. Related neural memory architectures, including Memory Networks and key-value memory networks, frame reasoning as query-conditioned access to stored representations or facts(Weston et al., 2015; Sukhbaatar et al., 2015; Miller et al., 2016)。 Transformer 特定的分析进一步将注意力或前馈组件与关联和键值内存视图联系起来. Transformer-specific analyses further connect attention or feed-forward components with associative and key-value memory views(Bricken and Pehlevan, 2021; Geva et al., 2021)。在我们的设置中，长上下文充当记忆痕迹的集合，问题充当检索线索，而注意力则为线索-痕迹关联提供即时内部代理，而不是对模型决策过程的忠实解释。证据筛选选择候选痕迹，证据物化将它们转回接地文本范围，重播在答案生成附近重新激活这些范围。在这种观点下，递归证据筛选是一种轻量级的方法，可以在脚手架条件下重复重新查询相同的上下文，从而改进查询-证据重新绑定，而无需添加外部存储模块、训练检索器或删除原始上下文。. In our setting, the long context acts as a collection of memory traces, the question serves as a retrieval cue, and attention provides a prompt-internal proxy for cue–trace association rather than a faithful explanation of the model’s decision process. Evidence sifting selects candidate traces, evidence materialization turns them back into grounded text spans, and replay reactivates these spans near answer generation. Under this view, recursive evidence sifting is a lightweight way to repeatedly re-query the same context under a scaffold-conditioned state, improving query–evidence rebinding without adding an external memory module, training a retriever, or removing the original context.

3.3 属性Properties

VPS 可以被视为语言中的广义演员-评论家框架 空间：演员生成轨迹；批评家提供了密集的， 阶梯级口头反馈代替标量值函数。它出发了 在三个方面与经典演员评论家不同：（i）操作完全是在 推理时间，通过条件再生来改进策略，并且没有 梯度更新； (ii) 语言批评取代标量值估计， 实现更丰富、更可解释的监管； (iii) 演员的 重量始终保持固定。因为批评是分阶段的，VPS 提供密集的反馈，改善时间学分分配。它是 免训练，直接适用于仅可访问的黑盒模型 通过 API，它具有广泛的通用性，没有特定于任务的奖励 工程。VPS can be viewed as a generalized actor–critic framework in language space: the actor generates trajectories; the critic provides dense, step-level verbal feedback in place of a scalar value function. It departs from classical actor–critic in three respects: (i) operation is entirely at inference time, with policy improvement via conditional regeneration and no gradient updates; (ii) language critiques replace scalar value estimates, enabling richer and more interpretable supervision; and (iii) the actor’s weights remain fixed throughout. Because critiques are step-level, VPS provides dense feedback that improves temporal credit assignment. It is training-free and directly applicable to black-box models accessible only via API, and it generalizes broadly with no task-specific reward engineering.

Modern systems can produce fluent, contextually appropriate outputs across tasks such as summarization, dialogue, reasoning, and instruction following, but evaluating those outputs remains a major bottleneck. Human evaluation is slow and expensive, lexical metrics such as ROUGE(Lin, 2004), 蓝色, BLEU(Papineni et al., 2002)和 BERT 分数, and BERTScore(Zhang et al., 2020)错过语义正确性和事实性，以及整体法学硕士法官miss semantic correctness and factuality, and holistic LLM judges(Zheng et al., 2023; Liu et al., 2023)通常会返回难以诊断的不透明分数。often return opaque scores that are difficult to diagnose.

这个瓶颈在迭代开发中成本尤其高昂。比较提示、模型或解码策略需要的反馈不仅准确而且可操作。单一的标量分数通常是不够的：如果摘要获得平庸的评级，仍然不清楚问题是否是事实不一致、相关性弱、内容缺失或流畅性差。This bottleneck is especially costly in iterative development. A single scalar score is often insufficient: if a summary receives a mediocre rating, it is still unclear whether the problem is factual inconsistency, weak relevance, missing content, or poor fluency.

我们的前提很简单：不要要求模型进行广泛的判断，而是询问一组小的、可检查的问题。因此我们建议Our premise is simple: instead of asking a model for one broad judgment, ask it a set of small, checkable questions. First, a meta-prompt decomposes a task prompt into atomic questions organized by evaluation dimension. Second, an evaluator answers each question independently and aggregates the answers into per-dimension and overall scores. Third, a two-phase optimization loop improves both evaluator prompts and generation prompts using question-level feedback.

6 讨论Discussion

失效模式。Failure Modes.分解最适合事实一致性等具体标准，其中错误可以与特定的主张或实体联系起来，因此可以通过相对明确的是/否决策进行检查。它对于主观质量不太可靠，因为人类的判断更加全面，并且不太能简化为一组二进制检查。在这种情况下，评估的质量在很大程度上取决于生成的问题是否捕捉到了人类在形成总体判断时实际权衡的各个方面。附录显示了两种模式：当分解变得过于严格时，相关性可能会降低，而当失败反映模型的基本功能而不是其指令时，及时更新的帮助就会较小。在 IFBench 上，更清晰的提示有助于格式和句子级约束，但不能帮助计数或比率跟踪，这表明一些错误源于执行限制，而不仅仅是任务规范。Decomposition works best for concrete criteria such as factual consistency, where errors can be tied to specific claims or entities and can therefore be checked with relatively clear yes/no decisions. It is less reliable for subjective qualities, where human judgments are more holistic and less reducible to a set of binary checks. In such cases, the quality of the evaluation depends heavily on whether the generated questions capture the aspects that humans actually weigh when forming an overall judgment. The appendix shows both patterns: relevance can degrade when decomposition becomes too strict, and prompt update helps less when failures reflect the model’s base capability rather than its instructions. On IFBench, clearer prompts help with format and sentence-level constraints but not with counting or ratio tracking, suggesting that some errors stem from execution limits rather than task specification alone.

计算成本。Computational Cost. 宾评估BinEval以效率换取诊断价值。与单一的整体判断相比，它必须产生二元问题并回答每个问题。这增加了模型调用的数量和评估期间处理的文本总量。提示更新增加了笔记记录、课程重复数据删除和元提示重写，尽管批处理保留了前两个适度的内容，并且大多数更新方法都共享提示重写。主要的经常性成本是问题级评估。trades efficiency for diagnostic value. Compared with a single holistic judgment, it must generate binary questions and answer each of them. This increases both the number of model calls and the total amount of text processed during evaluation. Prompt updating adds note-taking, lesson deduplication, and meta-prompt rewriting, though batching keeps the first two modest and prompt rewriting is shared by most update methods. The main recurring cost is question-level evaluation.

局限性。Limitations.该方法仍然取决于问题质量：如果缺少重要标准，最终得分将错过它们。它还假设满意问题的比例与整体质量近似线性映射，但这并不总是成立。The method still depends on question quality: if important criteria are missing, the final score will miss them. It also assumes that the fraction of satisfied questions maps approximately linearly to overall quality, which need not always hold.

7 结论Conclusion

我们提出了We presented宾评估BinEval，一个与任务无关、免训练的框架，通过将标准分解为原子二进制问题来评估 LLM 输出。在 SummEval、Topical-Chat 和 QAGS 中，它匹配或优于强大的评估器，同时还支持摘要和 IFBench 的迭代提示优化。因为每个分数都是基于个人的判断和解释，, a task-agnostic, training-free framework that evaluates LLM outputs by decomposing criteria into atomic binary questions. Across SummEval, Topical-Chat, and QAGS, it matches or outperforms strong evaluators while also supporting iterative prompt optimization on summarization and IFBench. Because each score is grounded in individual verdicts with explanations,宾评估BinEval提供可解释的反馈，帮助从业者诊断和改进法学硕士系统，并建议原子二进制分解作为更广泛评估任务的有希望的方向。这些结果表明，可解释性和强大的评估性能不需要以牺牲可扩展性或灵活性为代价。展望未来，我们看到代理和多回合设置的自然扩展，其中细粒度的声明级反馈对于识别系统出错的位置和原因特别有价值。offers interpretable feedback that helps practitioners diagnose and improve LLM systems, and suggests atomic binary decomposition as a promising direction for broader evaluation tasks. These results indicate that interpretability and strong evaluation performance need not come at the expense of scalability or flexibility. Looking ahead, we see natural extensions to agentic and multi-turn settings, where fine-grained, claim-level feedback is especially valuable for identifying where and why a system goes wrong.

复合 AI 应用程序使用 Python 等通用编程语言对 ML 模型进行调用，广泛用于从软件工程到企业自动化的各种面向用户的任务，这使得它们的端到端延迟成为关键瓶颈。 与传统应用程序相比，执行时间由外部组件主导，无法控制 处理过 通过传统的语言优化系统，例如优化编译器。Compound AI applications, which compose calls to ML models using a general-purpose programming language like Python, are widely used for a variety of user-facing tasks, from software engineering to enterprise automation, making their end-to-end latency a critical bottleneck. In contrast to traditional applications, execution time is dominated by the external components, which cannot be handled by traditional language optimization systems, like optimizing compilers.

To address this problem, we develop 罂粟PopPy，该系统可以在调用这些重型外部组件（包括复合 AI 应用程序中使用的组件）的 Python 应用程序中发现并行化机会。, a system that can uncover parallelization opportunities in Python applications that invoke these heavy external components, including those used in compound AI applications.罂粟PopPy支持极具表现力的 Python 片段，并且需要最少的开发人员输入来发现并行性。 它将提前编译器与运行时相结合，解决了从 Python 应用程序中提取并行性的三个关键挑战：语言复杂性、动态调度和变量突变。 On a set of real-world compound AI applications,supports a very expressive fragment of Python and requires minimal developer input to uncover parallelism.

2.1 系统模型System Model

通常， 聚合计算系统由一组设备组成， 每个都配备了本地计算能力， 用于感知环境的传感器， 用于与邻近设备交换信息的通信接口。 每个设备都连接到其他设备的子集， 形成动态且可能不可靠的网络拓扑。 通信模型通常基于消息传递， 设备可以与邻居异步发送和接收消息。Typically, an aggregate computing system consists of a collection of devices, each equipped with local computation capabilities, sensors for perceiving the environment, and communication interfaces for exchanging information with neighboring devices. Each device is connected to a subset of other devices, forming a dynamic and potentially unreliable network topology. The communication model is typically based on message passing, where devices can send and receive messages asynchronously to and from their neighbors.

每个设备执行相同的聚合程序， 从概念上讲，它可以被视为一个函数，它将设备的本地状态和从邻居接收到的值作为输入， 并产生一个输出值，表示设备对全局计算的贡献。 具体来说， 每个设备将其执行组织为离散的轮次， 在每一轮中它执行以下步骤（Each device executes the same aggregate program, which can be conceptually viewed as a function that takes the device’s local state and the values received from neighbors as input, and produces an output value that represents the device’s contribution to the global computation.

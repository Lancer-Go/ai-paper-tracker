摘要Abstract

自主 6G 网络管理需要代理能够执行工具、观察结果的状态变化并相应地调整其决策。然而，基于静态问题或脚本化情节重播的现有基准不支持这种闭环交互，从而将代理限制为被动评估，而无法从环境反馈中学习。本文介绍了Autonomous 6G network management requires agents that can execute tools, observe the resulting state changes, and adapt their decisions accordingly. Existing benchmarks based on static questions or scripted episode replay, however, do not support such closed-loop interaction, limiting agents to passive evaluation without the ability to learn from environmental feedback. This paper presents6G特工健身房6GAgentGym提供闭环能力。该框架提供了一个包含 42 个类型工具的交互式环境，其效果分类将只读观察与状态突变配置区分开来，并由基于 NS-3 模拟数据校准的学习实验模型支持。to provide closed-loop capability. The framework provides an interactive environment with 42 typed tools whose effect classification distinguishes read-only observation from state-mutating configuration, backed by a learned Experiment Model calibrated on NS-3 simulation data.6G-锻造6G-Forge通过迭代自指令生成以及针对实验模型的执行验证，从 NS-3 种子引导闭环训练轨迹。对生成的语料库进行有监督的微调，然后通过在线闭环交互进行强化学习，使 8B 开源模型能够在随附的基础上实现与 GPT-5 相当的总体成功率bootstraps closed-loop training trajectories from NS-3 seeds via iterative Self-Instruct generation with execution verification against the Experiment Model. Supervised fine-tuning on the resulting corpus followed by reinforcement learning with online closed-loop interaction enables an 8B open-source model to achieve comparable overall success rate to GPT-5 on the accompanying6G代理工作台6GAgentBench，在长期任务上具有更强的性能。这些组件共同提供了一条实现自主闭环网络管理的可行途径。, with stronger performance on long-horizon tasks. Together, these components provide a viable path toward autonomous, closed-loop network management.

I 简介Introduction

6G 与大规模物联网的融合带来了网络管理的巨大复杂性，涵盖边缘智能、动态切片和空地一体化The convergence of 6G with massive IoT introduces substantial complexity in network management, spanning edge intelligence, dynamic slicing, and space-air-ground integration[16]。配置和优化同时管理意图转换、动态网络切片、信任策略和多代理协调的现代网络通常需要经验丰富的工程师在每次部署时花费数小时到数天的手动工作。行业分析表明，45% 的网络中断源于配置和变更管理故障。随着无线接入技术、频段组合和网络切片数量的增长，手动优化变得越来越困难。虽然深度学习改进了网络流量预测. Configuring and optimizing a modern network that simultaneously manages intent translation, dynamic network slicing, trust policies, and multi-agent coordination typically requires an experienced engineer hours to days of manual effort per deployment. Industry analyses indicate that 45% of network outages stem from configuration and change management failures. As the number of radio-access technologies, band combinations, and network slices grows, manual optimization becomes increasingly difficult. While deep learning has improved network traffic prediction[1]多级深度 RL 已显示出在基于 O-RAN 的 6G 网络中实现自动切片的前景and multi-level deep RL has shown promise for automated slicing in O-RAN-based 6G networks[8]，这些方法解决孤立的子任务，但尚未提供操作员所需的端到端、基于语义的管理。, these approaches address isolated subtasks and do not yet provide the end-to-end, semantically grounded management that operators need.

Their capabilities in multi-step planning and tool orchestration[22, 27]允许代理以自然语言解释操作员意图，选择适当的网络功能，并根据执行反馈调整决策allow agents to interpret operator intent in natural language, select appropriate network functions, and adapt decisions based on execution feedback[5, 15, 30]。最近的工作探索了法学硕士驱动的数字孪生用于闭环网络优化. Recent work has explored LLM-driven digital twins for closed-loop network optimization[9]和基于 LLM 的意图翻译，用于基于意图的网络and LLM-based intent translation for intent-based networking[24]，展示了法学硕士在网络管理中应用的广度。如图。, demonstrating the breadth of LLM applications in network management. Ⅱ-CII-C 网络管理的强化学习Reinforcement Learning for Network Management

将强化学习应用于网络管理已有很长的历史，但其操作空间与 LLM 工具的使用有着根本的不同。深度强化学习已应用于网络切片资源分配Applying RL to network management has a long history, but the action spaces differ fundamentally from LLM tool use. Deep RL has been applied to network slicing resource allocation[12, 3];最近，Ghafouri 等人。; more recently, Ghafouri et al.[8]为基于 O-RAN 的 6G 无细胞网络提出了一种多级深度 RL 框架，该框架将集中式多智能体决策与分散式执行相结合。深度学习也被应用于网络流量预测propose a multi-level deep RL framework for O-RAN-based 6G cell-free networks that combines centralized multi-agent decision-making with decentralized execution. Deep learning has also been applied to network traffic prediction[1]，提供互补的预测能力。这些方法在固定的低维动作空间（例如，每个切片的带宽分配）上进行优化，并且缺乏解释操作员意图或组成多步骤诊断工作流程的能力。基于 LLM 的代理在语义层面提供了补充范例：ReAct 框架, providing complementary forecasting capabilities. These methods optimize over fixed, low-dimensional action spaces (e.g., bandwidth allocation per slice) and lack the ability to interpret operator intent or compose multi-step diagnostic workflows. LLM-based agents offer a complementary paradigm at the semantic level: the ReAct framework[28]将推理轨迹与工具操作交织在一起，而世界知识模型interleaves reasoning traces with tool actions, while the World Knowledge Model[19]表明 LLM 代理可以利用先验知识和动态知识来减少盲目试错。最近，SWE-Worldshows that LLM agents can leverage both prior and dynamic state knowledge to mitigate blind trial-and-error. More recently, SWE-World[25]用在真实交互数据上训练的学习代理模型取代容器化执行环境，从而实现软件工程任务的无 Docker 代理训练和测试时间扩展。在网络领域，NS-3replaces containerized execution environments with learned surrogate models trained on real interaction data, enabling Docker-free agent training and test-time scaling for software engineering tasks. In the networking domain, NS-3[21]仍然是用于协议级研究的标准离散事件模拟器，最近的扩展集成了 6G 多 RAT 场景的光线追踪通道remains the standard discrete-event simulator for protocol-level research, with recent extensions integrating ray-tracing channels for 6G multi-RAT scenarios[18];我们的工作采用 NS-3 作为物理层地面事实，并将其动态提炼为学习代理，以实现可扩展的代理训练。; our work adopts NS-3 as the physical-layer ground truth and distills its dynamics into a learned surrogate to enable scalable agent training.

V 结论Conclusion

本文介绍了 6GAgentGym，一个集成了具有 42 种类型工具的交互式环境和学习实验模型的框架、源自 NS-3 真实数据的自指导数据合成管道 (6G-Forge) 以及分层评估套件 (6GAgentBench)。 Agentic SFT 和 RL 以及在线闭环交互使 8B 模型能够实现与 GPT-5 相当的整体性能，并在长期任务上具有优势。This paper presents 6GAgentGym, a framework integrating an interactive environment with 42 typed tools and a learned Experiment Model, a Self-Instruct data synthesis pipeline (6G-Forge) seeded from NS-3 real data, and a tiered evaluation suite (6GAgentBench). Agentic SFT followed by RL with online closed-loop interaction enables an 8B model to achieve comparable overall performance to GPT-5, with an advantage on long-horizon tasks.

在实际部署之前仍然存在一些限制。实验模型近似 NS-3 动态，但没有捕获完整的协议级瞬态，特别是在切换和故障恢复期间。当前的 42 个工具集涵盖网络切片和无人机控制，但不包括波束成形和功率控制等无线电级操作。将强化学习扩展到更大的轨迹预算并集成多模态输入（频谱可视化、拓扑图）是未来工作的方向。Several limitations remain before practical deployment. The Experiment Model approximates NS-3 dynamics but does not capture full protocol-level transients, particularly during handover and failure recovery. The current tool set of 42 covers network slicing and UAV control but excludes radio-level operations such as beamforming and power control. Extending RL to larger trajectory budgets and integrating multi-modal inputs (spectrum visualizations, topology maps) are directions for future work.

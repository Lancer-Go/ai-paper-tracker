一、简介1. Introduction

1.1 意图传输问题1.1 The Intent Transmission Problem

与大型语言模型 (LLM) 的每次交互都以文本提示开始——一种看似简单的输入，必须以某种方式编码用户意图的全部丰富性：他们的背景、目的、受众、约束、所需的语气和预期的格式。当前的实践没有为用户提供结构化的方式来表达这种复杂性。结果是Every interaction with a large language model (LLM) begins with a text prompt — a deceptively simple input that must somehow encode the full richness of a user's intent: their background, purpose, audience, constraints, desired tone, and expected format. Current practice offers users no structured way to express this complexity. The result is意图传输损失intent transmission loss：用户需要的内容和人工智能系统收到的内容之间存在系统性差距。: a systematic gap between what users need and what AI systems receive.

这个问题的规模非常重大。法学硕士系统向数亿用户的大规模部署[15]揭示了一个根本性的不匹配：用户自然地交流，而法学硕士对精心指定的指令反应最好。然而，没有标准化协议来管理人类意图如何向人工智能系统表达。每个用户即兴发挥，每个 LLM 供应商都实施自己的约定。The scale of this problem is significant. Large-scale deployment of LLM systems to hundreds of millions of users [15] has revealed a fundamental mismatch: users communicate naturally, while LLMs respond best to carefully specified instructions. Yet no standardized protocol governs how human intent is expressed to AI systems. Each user improvises, and each LLM vendor implements its own conventions.

我们建议通过用户意图的结构化表示来解决意图传输损失。We propose addressing intent transmission loss through a structured representation of user intent.聚苯硫醚PPS（提示协议规范）没有规定AI应该输出什么；它标准化了(Prompt Protocol Specification) does not prescribe what AI should output; it standardizes用户如何表达意图how users express intent。 PPS 格式的提示是一个机器可读的 JSON 信封，具有八个结构化维度，其灵感大致来自通信系统如何标准化表示以提高传输可靠性。自然语言渲染层将这个信封翻译成当前法学硕士可以处理的散文，将关注点分开. 1.3 5W3H 框架1.3 The 5W3H Framework

PPS 围绕 5W3H 模型组织人类意图，这是经典新闻 5W 框架的扩展，适用于任务规范：PPS organizes human intent around the 5W3H model — an extension of the classical journalistic 5W framework adapted for task specification:

  • 什么What：核心任务或可交付成果: The core task or deliverable

  • 为什么Why：目的、动机、成功标准: Purpose, motivation, success criteria

  • 谁Who：受众、作者角色、专业水平: Audience, author role, expertise level

  • 当When：时间限制、新鲜度要求、时间表: Temporal constraints, freshness requirements, schedule

  • 哪里Where：部署环境、平台、地理范围: Deployment context, platform, geographic scope

  • 操作方法How-to-do：方法、程序、工作流程首选项: Methods, procedures, workflow preferences

  • 多少钱How-much：定量参数——长度、计数、覆盖深度: Quantitative parameters — length, count, coverage depth

  • 感觉如何How-feel：基调、风格、情感表达、品牌定位: Tone, style, emotional register, brand alignment

这八个维度共同为指定许多人工智能辅助任务提供了一个实用的框架。指定所有八个维度的用户可以减少输出不匹配的主要来源。Together, these eight dimensions provide a practically useful framework for specifying many AI-assisted tasks. A user who specifies all eight dimensions can reduce major sources of output mismatch.

6.1 测量不对称问题：对评估研究的启示6.1 The Measurement Asymmetry Problem: Implications for Evaluation Research

我们发现对于无约束提示，constraint_adherence 几乎可以达到 5.000 ± 0.000，这对 LLM 评估文献具有广泛的影响。任何比较不同水平的提示特异性的研究都必须控制“缺乏约束”问题。我们推荐：Our finding that constraint_adherence trivially reaches 5.000 ± 0.000 for unconstrained prompts has broad implications for the LLM evaluation literature. Any study comparing different levels of prompt specificity must control for the "absent constraint" problem. We recommend:

  2. 目标参考评估Goal-referenced evaluation：评估框架应至少包括一个维度，参考评估的内容: Evaluation frameworks should include at least one dimension that references what the用户试图实现user was trying to achieve而不是一般的品质。 goal_alignment 提供了此参考。rather than generic quality. goal_alignment provides this reference.

6.4 限制6.4 Limitations

语言范围Language scope：所有提示和输出均为中文（简体）。 PPS 的价值在英语或其他语言中可能有所不同，因为法学硕士具有不同的优势。我们预测英语中有类似的模式，但没有验证这一点。: All prompts and outputs are in Chinese (Simplified). PPS's value may differ in English or other languages where LLMs have different strengths. We predict similar patterns in English but do not verify this.

判断自我偏见Judge self-bias：使用 DeepSeek 作为测试模型和判断会引入潜在的自私偏见，我们的分析证实了这一点（第 5.3 节）。尽管如此，稳健性分析（不包括 DeepSeek）加强了而不是推翻了我们的主要发现。未来的工作应该使用来自不同供应商的判断（例如，在评估 DeepSeek/Qwen/Kimi 输出时，GPT-4o 或 Claude 作为判断）。: Using DeepSeek as both a test model and judge introduces potential self-serving bias, confirmed by our analysis (§5.3). Despite this, the robustness analysis (excluding DeepSeek) strengthens rather than reverses our main findings. Future work should use a judge from a different vendor (e.g., GPT-4o or Claude as judge when evaluating DeepSeek/Qwen/Kimi outputs).

6.5 对人机交互界面设计的影响6.5 Implications for Human-AI Interface Design

我们的研究结果为人机人工智能界面设计的未来工作提出了三个实用方向：Our findings suggest three practical directions for future work in human-AI interface design:

系统级支持System-level support。企业部署可以在系统提示中包含PPS解析指令，使当前模型能够更可靠地处理PPS结构。我们的条件 B 为该方法在当前模型中的有效性提供了下限；具有显式 PPS 解析规则的专用系统提示可能会接近 C 语言的性能。. Enterprise deployments can include PPS parsing instructions in the system prompt, enabling current models to process PPS structure more reliably. Our Condition B provides a lower bound on this approach's effectiveness with current models; purpose-built system prompts with explicit PPS parsing rules would likely approach C performance.

模型级原生支持Model-level native support。未来基于结构化意图数据训练的模型可能会内在化 PPS 维度，而无需显式渲染。这仍然是一个悬而未决的实证问题。. Future models trained on structured intent data may internalize PPS dimensions without requiring explicit rendering. This remains an open empirical question.

PPS 作为澄清界面PPS as clarification interface。我们的研究结果表明交互倒置：人工智能可以在收到不明确的提示时主动呈现 5W3H 草稿供用户审核，而不是让用户预先指定 PPS——将 PPS 从. Our findings suggest an interaction inversion: rather than users specifying PPS upfront, an AI could proactively present a 5W3H draft for user review when receiving ambiguous prompts — transforming PPS from a规范协议specification protocol变成一个into a澄清界面clarification interface。这解决了意图传输丢失的问题，同时用户在明确请求时只需付出最少的额外努力。. This addresses intent transmission loss while requiring minimal additional effort from users on clear requests.

未来的工作还有几个方向。Several directions remain for future work.一个重要的扩展是在构建 A/B/C 条件之前为每项任务引入外部黄金意图文档，这将允许与共享参考进行更客观的比较。第二个方向是跨语言验证，因为目前的研究仅限于中文，尚未确定 PPS 是否可以跨语言推广。第三个方向是通过纵向互动日志分析而不是仅仅回顾性自我报告对国际电联进行更强有力的行为验证。最后，未来的研究可能会将 PPS 与其他针对人类与人工智能通信相关方面的结构化提示或交互框架进行比较。One important extension is to introduce an external gold-intent document for each task prior to constructing the A/B/C conditions, which would allow more objective comparison against a shared reference. A second direction is cross-lingual validation, since the present study is limited to Chinese and does not yet establish whether PPS generalizes across languages. A third direction is stronger behavioral validation of ITU through longitudinal interaction-log analysis rather than retrospective self-report alone. Finally, future studies may compare PPS with other structured prompting or interaction frameworks that operate on related aspects of human-AI communication.

七、结论7. Conclusion

我们提出了 PPS（一种基于 5W3H 的结构化意图表示框架），并进行了一项受控实证研究，比较了 540 个 AI 生成的输出中的简单提示、原始结构化表示和渲染的结构化表示。We presented PPS, a 5W3H-based structured intent representation framework, and conducted a controlled empirical study comparing simple prompts, raw structured representation, and rendered structured representation across 540 AI-generated outputs.

Your task: score the "goal_alignment" of an AI output — how well it matches
the USER'S ACTUAL INTENT, not just generic quality.

Scoring rubric (1-5):
  5 = Perfect alignment: audience, purpose, depth, format all match exactly.
      The output is immediately usable by the target user without further prompting.
  4 = Good alignment: main goals achieved, minor gaps in depth or specificity.
  3 = Partial alignment: task completed but direction is off.
  2 = Poor alignment: output is generic; user needs 3+ follow-up prompts.
  1 = No alignment: output irrelevant or completely misses user's purpose.
Key rules:
- For SIMPLE prompts: infer the MOST LIKELY user intent from context.

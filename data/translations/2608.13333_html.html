Hai Xia Email: hxia@ac.tuwien.ac.at    Vaidyanathan Peruvemba Ramaswamy Email: vaidyanathan@ac.tuwien.ac.at    Stefan Szeider Email: sz@ac.tuwien.ac.at Affiliation: Algorithms and Complexity Group, TU Wien, Austria
摘要Abstract

大邻域搜索通常选择决策变量的随机子集进行迭代优化。 为了有效地解决不同的问题，研究人员倾向于通过考虑来设计变量选择策略 不同领域的结构特征。在本文中，我们构建了一个自动管道，该管道与 MiniZinc 格式中的所有问题无关。 通过用我们的语义指南提示法学硕士，我们指导法学硕士生成一个图形生成器，可以映射任何实例 统一加权图的问题类型，其中节点代表 决策变量和边代表约束关系。这些 与问题无关的图指导我们基于结构的局部改进 变量选择框架（SLIM）。同时，加权图使所有问题实例能够共享相同的通用图表示，从中可以提取相同的图特征并用于配置选择。我们针对 20 个 MiniZinc 竞争问题的实例评估了我们的流程，发现 该算法选择实现了 39.5% 的平均问题加权胜率 与一次性 Gurobi 基线相比，是最佳单一配置 (19.3%) 的两倍多。配置和功能消融 性能进一步提升至 44.0%，证明基于 LLM 的 语义生成可实现有效的自动结构提取和特征提取 用于约束优化。Large neighborhood search normally selects a random subset of decision variables for iterative optimization. For efficiently solving different problems, researchers tend to design variable selection strategies by taking into account structural features from different domains. In this paper, we build an automatic pipeline that is problem-agnostic to all problems in the MiniZinc format. By prompting an LLM with our semantic guidelines, we guide the LLM to produce a graph generator that maps any instance of a problem type to a uniform weighted graph, where nodes represent decision variables and edges represent constraint relationships. These problem-agnostic graphs guide our structure-based local improvement framework (SLIM) in variable selection. Meanwhile, the weighted graph enables all problem instances to share the same generic graph representation, from which the same graph features can be extracted and used for configuration selection. We evaluated our pipeline on instances across 20 MiniZinc competition problems, finding that algorithm selection achieves a 39.5% average problem-weighted win rate against a one-shot Gurobi baseline, more than doubling the best single configuration (19.3%). Configuration and feature ablation boost the performance further to 44.0%, demonstrating that LLM-based semantic generation enables effective automated structure extraction and feature extraction for constraint optimization.

1 简介Introduction

大邻域搜索 (LNS) 是最有用的搜索方法之一 硬组合优化的元启发法 问题Large Neighborhood Search (LNS) is one of the most useful metaheuristics for hard combinatorial optimization problems(Shaw 1998; Pisinger and Ropke 2019)，特别是当 问题变得更大、更复杂。 在每次迭代中，LNS 仅选择决策变量的子集， 由精确求解器优化。 本地实例优化后，本地较好的方案为 修补回原来的全局。 因此，搜索的效率很大程度上取决于是否 选择有希望且合适的变量进行局部优化。, especially when the problems become larger and more complicated. In each iteration, LNS only selects a subset of the decision variables, which is optimized by an exact solver. After the local instance is optimized, the better local solution is patched back to the original global one. Therefore, the efficiency of the search relies heavily on whether promising and suitable variables are selected for local optimization.

在实践中，变量选择（邻域选择）是相当有效的。 灵活。 随机选择是最简单的一种，计算成本低， 但忽略了实例特征和问题结构，浪费了 解决松散耦合子问题的时间。 结构引导变量选择可以利用变量关系， 产生紧密耦合的邻域。 但应该考虑什么样的特征或结构信息 这也是一个与具体问题类型密切相关的问题， 需要大量的专业领域知识。 针对不同的问题领域，有不同的原则 设计有效的基于结构的局部改进方法 （修身）In practice, variable selection (neighborhood selection) is quite flexible. Random selection is the simplest one, which is computationally cheap, but ignores the instance features and the problem structure, wasting solving time on loosely coupled subproblems. Structure-guided variable selection can exploit the variable relations, producing tightly coupled neighborhoods. But what kind of features or structure information should be considered is also a question quite related to the specific problem type, and it needs a lot of expert domain knowledge. For different problem domains, there are different principles for designing efficient Structure-Based Local Improvement Methods (SLIM)(Fichte et al. 2017)。 在过去的十年中，SLIM已经应用于不同的问题领域， 包括树宽计算. In the last decade, SLIM has been applied to different problem domains, including treewidth computation(Fichte et al. 2017), 分支宽度, branchwidth(Lodha et al. 2019), 树深度, treedepth(Ramaswamy and Szeider 2020), 贝叶斯网络学习, Bayesian network learning(Ramaswamy and Szeider 2021; Peruvemba Ramaswamy and Szeider 2022), 图形着色, graph coloring(Schidler and Szeider 2023)，决策树 优化, decision tree optimization(Schidler and Szeider 2024b)，和最大 满意度, and Maximum Satisfiability(Schidler and Szeider 2024a)。 在不同的针对特定问题的 SLIM 算法中，有不同的 邻域的构建方法和相应变量 选择策略。 所有这些设计都是由领域专家精心设计的， 几个月的体力劳动。 除了算法设计之外，高效的算法实现也是 当应用于不同的问题实例时也并非微不足道：算法 配置器通常需要大量的计算预算 获得更好的 SLIM 配置 算法. In different problem-specific SLIM algorithms, there are various construction methods for neighborhoods and corresponding variable selection strategies. All these designs are highly engineered by domain experts, taking months of manual work. Besides the algorithm design, efficient algorithm implementation is also not trivial when applied to different problem instances: algorithm configurators typically demand extensive computational budgets for getting better configurations of SLIM algorithms(Ramaswamy et al. 2024)，以及基于投资组合的算法 选择需要针对具体问题的特征，这些特征也需要 由专家策划, and portfolio-based algorithm selection requires problem-specific features that also need to be curated by experts(Xia and Szeider 2024).

The generic extraction algorithms can select the neighborhoods with semantic structure information derived from the original constraints. Furthermore, the problem-generic representation also makes it possible to do cross-problem algorithm selection, as we can extract topological and statistical features from the generic graphs of the instances from different problems.

3.3 基于通用结构的局部改进（SLIM）Generic Structure-Based Local Improvement (SLIM)

因为我们已经有了图中的通用图形表示 生成器，SLIM 现在可以处理与问题无关的均匀加权 图表。 尽管 SLIM 现在没有先验知识或偏好 不同的问题，它可以提取一些有用的变量 信息，例如节点的权重和域大小，以及 图中边的耦合权重。 在每次迭代中，我们使用提取算法来选择 均匀图中变量的邻域，而其余的 邻域之外的变量被冻结。 然后局部求解器可以优化较小的子问题，从而得到 更好的本地解决方案。As we already have a generic graph representation from the graph generator, SLIM can now work on a problem-agnostic uniform weighted graph. Even though SLIM now has no prior knowledge or preferences for different problems, it can extract the variables with some useful information, like the weights and the domain sizes of the nodes, and the coupling weights of the edges in the graph. In each iteration, we use the extraction algorithms to select the neighborhood of variables from the uniform graph, while the remaining variables outside of the neighborhood are frozen. Then the local solver can optimize the smaller subproblem, resulting in better local solutions.

5 结论Conclusion

在本文中，我们提出了一个使用法学硕士的自动管道 用于合成图生成器来转换 MiniZinc 问题 将实例转化为统一的图形表示。 通过问题通用图，我们可以跨区域使用结构感知 SLIM 不同的问题。 同时，我们还可以从均匀图中提取特征 自动为 SLIM 选择性能最佳的配置。 通过对这20个问题的广泛评估，我们发现 与 one-shot 相比，问题无关的 SLIM 可以获得更强的结果 古罗比。 基于配置选择的SLIM平均可以达到44.0% 对一击古罗比的问题加权胜率，显着 性能也优于单一最佳配置 SLIM (19.3%)。In this paper, we presented an automatic pipeline where an LLM is used for synthesizing graph generators to transform MiniZinc problem instances into a uniform graph representation. With the problem-generic graph, we can use structure-aware SLIM across different problems. Meanwhile, we can also extract the features from the uniform graph to automatically select the best-performing configurations for SLIM. By extensive evaluation on the 20 problems, we found that the problem-agnostic SLIM can get stronger results compared with one-shot Gurobi. The configuration-selection-based SLIM can get a 44.0% average problem-weighted win rate against one-shot Gurobi, significantly outperforming the single best configuration SLIM (19.3%) as well.

也有一些限制。 当问题不可知的 SLIM 应用于特定问题时，SLIM 即使有最好的搜索，也无法超越一次性的 Gurobi 策略。 这可能是由于法学硕士指导的图形生成所致。生成器虽然经过验证，但仍然是 LLM 生成的真实约束语义的近似值，并且我们的评估仅涵盖 MiniZinc 竞争基准。未来我们可能会有更有针对性的提示来指导LLM 将实例转换为具有其他类型的统一图 信息，例如一些探测拓扑特征等。 此外，我们甚至可以添加一些可以动态更新的信息 在搜索过程中更新。 比如特定的组件经过多次优化后， 我们可以使用禁忌搜索或自适应调整权重来逃避 重复优化。There are also limitations. When the problem-agnostic SLIM is applied to specific problems, SLIM is not able to outperform one-shot Gurobi even with the best search strategies. This is probably due to the LLM-guided graph generation. The generators, while validated, remain LLM-produced approximations of the true constraint semantics, and our evaluation covers only MiniZinc competition benchmarks. In the future, we may have more targeted prompts to guide the LLM to transform the instances into uniform graphs with other types of information, like some probing topological features and so on. Furthermore, we can even add some information that can be dynamically updated during the search. For example, after specific components have been optimized many times, we can use tabu search or adaptively adjust the weights to escape the repetitive optimization.

使用有限 VRAM 进行长上下文微调Long-Context Fine-Tuning with Limited VRAM

Vladimir Fedosov  Aleksandr Sazhin  Artemiy Grinenko  Frank Woernle
BMW Group
https://github.com/vfedosov77/HierarchicalGlobalAttention
（2026 年 7 月）(July 2026)
摘要Abstract

参数高效的微调减少了模型和优化器的内存，但密集的注意力仍然使长训练序列变得昂贵。我们将分层全局注意力（HGA）与分段反向传播和分层 KV 存储相结合。只有活动段在 VRAM 中保持可微分；旧的 KV 被分离到 RAM 或 NVMe 中，HGA 为每个查询块加载一组有界的精确历史令牌。在具有 4 位 QLoRA 和 PG19 的 Qwen3-8B 上，16 GB Quadro RTX 5000 上的密集训练适合 2,048 个令牌，但在 4,096 个令牌时失败，而 HGA 在 15.28 GB 峰值 VRAM 下达到 16,384 个令牌。在评估中，同一适配器在该卡上运行 131,072 个令牌； VRAM 不是恒定的，而是随着驻留块摘要缓慢增长，因此 RAM 和 NVMe 容量设置了超出这些长度的实际限制。在共享的 2K 训练长度下，HGA 训练和密集训练的适配器在相同的密集注意力读数下获得 2.7405 和 2.7383 nat，而库存模型获得 2.9541。在此边界上，HGA 训练已经稍快一些（217.75 与 207.02 令牌/秒），并且 HGA 与密集吞吐量的比率从 1K 提高到 2K；由于 HGA 使每个代币的参与历史集保持大致恒定，而每个代币的密集工作量不断增长，因此我们预计这种领先优势会随着上下文的增长而扩大。密集注意力用于主要质量和检索比较，以便它们衡量学习权重并与标准生成框架保持兼容。 HGA还可用于检索和生成；优化的生产级服务实施正在开发中。Parameter-efficient fine-tuning reduces model and optimizer memory, but dense attention still makes long training sequences expensive. We combine Hierarchical Global Attention (HGA) with segment-wise backpropagation and tiered KV storage. Only the active segment remains differentiable in VRAM; older KV is detached into RAM or NVMe, and HGA loads a bounded set of exact historical tokens for each query block. On Qwen3-8B with 4-bit QLoRA and PG19, dense training on a 16 GB Quadro RTX 5000 fits 2,048 tokens but fails at 4,096, whereas HGA reaches 16,384 tokens with 15.28 GB peak VRAM. Under evaluation the same adapter runs through 131,072 tokens on this card; VRAM is not constant but grows gently with the resident chunk summaries, so RAM and NVMe capacity set the practical limit beyond these lengths. At the shared 2K training length, HGA-trained and dense-trained adapters obtain 2.7405 and 2.7383 nat under the same dense-attention readout, while the stock model obtains 2.9541. At this boundary HGA training is already marginally faster (217.75 vs. 207.02 tokens/s), and the HGA-to-dense throughput ratio improves from 1K to 2K; because HGA keeps the attended historical set per token approximately constant while dense work per token grows, we expect this lead to widen as context grows. Dense attention is used for the main quality and retrieval comparisons so that they measure the learned weights and remain compatible with standard generation frameworks. HGA can also be used for retrieval and generation; an optimized production-grade serving implementation is under development.

1  简介1  Introduction

长上下文适应通常受到注意力和反向传播状态的限制，而不是受可训练适配器参数数量的限制。确切的边界取决于模型大小、量化、GPU 容量和内核，但故障模式是通用的：一旦模型权重消耗了大部分 VRAM，则序列相关的训练状态就几乎没有剩余。 QLoRALong-context adaptation is often limited by attention and backpropagation state rather than by the number of trainable adapter parameters. The exact boundary depends on model size, quantization, GPU capacity, and kernels, but the failure mode is general: once model weights consume most VRAM, little remains for sequence-dependent training state. QLoRA[3]通过量化冻结权重和训练低秩适配器来移动这个边界，但仍然必须集中注意力来处理完整的历史记录。moves this boundary by quantizing frozen weights and training low-rank adapters, but dense attention must still process the full history.

磁头GAHGA[1]取代模型的标准注意力，而不改变其预训练的 Q/K/V/O 预测。它首先将查询块路由到相关的历史块和组，然后计算对所选块的注意力replaces a model’s standard attention without changing its pretrained Q/K/V/O projections. It first routes a query block to relevant historical chunks and groups, then computes attention over the selected确切的标记exact tokenK/V。在这里，我们将 HGA 与截断时间反向传播 (TBPTT) 和外部 KV 存储结合起来。K/V. Here we combine HGA with truncated backpropagation through time (TBPTT) and external KV storage.

We use dense inference for the main comparisons and compatibility with existing serving frameworks; production-grade routed serving is ongoing work.

2  方法2  Method

2.1 精确令牌分层路由2.1 Exact-token hierarchical routing

上下文被分为 64 个 token 的块和更小的组；图The context is divided into 64-token chunks and smaller groups; Figure1说明了 8 个标记组。两种尺寸均可配置。 HGA 根据模型现有的投影键构建两个级别的键摘要：illustrates 8-token groups. Both sizes are configurable. HGA builds two levels of key summaries from the model’s existing projected keys:

  1. 1.

    块选择。Chunk selection.每个封闭的 64 个令牌块的紧凑摘要保留在 VRAM 中。除了固定接收器和本地窗口之外，当前查询块对这些摘要进行评分并选择最相关的块。A compact summary for every closed 64-token chunk remains in VRAM. The current query block scores these summaries and selects the most relevant chunks, in addition to fixed sink and local windows.

  2. 2.

    分组选择。Group selection.选定的块在组级别打开。 8 个令牌组的摘要保存在更大的 VRAM 缓存中；缺失的摘要是从 RAM 或 NVMe 中获取的。路由器选择所选块内的最佳组。The selected chunks are opened at group level. Summaries of 8-token groups are kept in a larger VRAM cache; missing summaries are fetched from RAM or NVMe. The router selects the best groups inside the chosen chunks.

  3. 3.

    确切的象征性关注。Exact-token attention.只有所选组的确切令牌 K/V 才会加载到路由工作集中。摘要向量永远不会用作注意力值或输出标记。Only the exact token K/V of the selected groups is loaded into the routed working set. Summary vectors are never used as attention values or output tokens.

路由选择在没有梯度跟踪的情况下运行，而 K/V 收集和精确令牌注意力仍然是可微的。包装器通过引用保留预训练的投影模块，并且不添加学习的路由器权重，因此梯度会在密集和 HGA 训练中更新相同的 Q/K/V/O 和 MLP 投影。Routing selection runs without gradient tracking, while K/V gathering and exact-token attention remain differentiable. The wrapper keeps the pretrained projection modules by reference and adds no learned router weights, so gradients update the same Q/K/V/O and MLP projections in both dense and HGA training.

2.2 分段后向分层KV存储2.2 Segment-wise backward and tiered KV storage

长度序列A sequence of lengthLL被分成长度的片段is split into segments of lengthSS。每个分段都会关注其本地令牌和 HGA 从提交的历史记录中选择的令牌，计算语言模型损失，并立即向后运行。在段边界处，其历史 K/V 在下一个段之前分离。后面的段可以读取前面的内容，但渐变不会跨越段边界。这是 TBPTT. Each segment attends to its local tokens and to HGA-selected tokens from the committed history, computes the language-model loss, and immediately runs backward. At the segment boundary, its historical K/V is detached before the next segment. Later segments can read earlier content, but gradients do not cross segment boundaries. This is TBPTT[9].

2.3 匹配密集和HGA训练2.3 Matched dense and HGA training

我们使用相同的数据顺序、种子和超参数训练两个 QLoRA 适配器。唯一的区别是微调时使用的注意力：原始的密集模块或HGA。两个适配器都在两种注意力模式下进行评估。密集读数是学习权重质量的主要衡量标准；路由读数单独测量 HGA 选择的效果。We train two QLoRA adapters with identical data order, seed, and hyperparameters. The only difference is the attention used during fine-tuning: the original dense module or HGA. Both adapters are evaluated under both attention modes. Dense readout is the primary measure of learned-weight quality; routed readout separately measures the effect of HGA selection.

6  限制6  Limitations

6.1 长期因果泄漏6.1 Long-horizon causal leakage

在我们的实验中，当前的 HGA 训练实现对于最多约 1 亿个训练令牌的微调运行保持稳定。然而，更长的训练揭示了由于在块内跨令牌共享路由决策而导致的因果侧通道。特别是，为块选择的路由集取决于多个查询位置产生的分数。因此，较早的令牌可以获得有关从中选择或拒绝远程块的较晚令牌的间接信息。尽管该信号最初很弱，但在大约 100-2 亿次训练令牌之后，模型开始利用它来改进下一个令牌的预测，从而导致可测量的因果泄漏。因此，当前的实现适合在测试的训练范围内进行微调，但不适合从头开始预训练模型。我们的初步结果表明，严格因果路由变体可以消除此限制；其设计和评估留待未来工作。In our experiments, the current HGA training implementation remains stable for fine-tuning runs of up to approximately 100 million training tokens. However, substantially longer training reveals a causal side channel caused by sharing routing decisions across tokens within a chunk. In particular, the routing set selected for a chunk depends on scores produced by multiple query positions. An earlier token can therefore obtain indirect information about later tokens from which remote chunks were selected or rejected. Although this signal is initially weak, after approximately 100–200 million training tokens the model begins to exploit it to improve next-token prediction, resulting in measurable causal leakage. Consequently, the current implementation is suitable for fine-tuning within the tested training horizon, but not for pretraining a model from scratch. We have preliminary results indicating that a strictly causal routing variant can remove this limitation; its design and evaluation are left for future work.

6.2 实验限制6.2 Experimental limitations

主要的上下文扩展实验使用一个模型和 GPU，训练持续 100 个优化器步骤。仅当密集训练适合时，匹配的密集训练基线才可用； 8K–16K 的质量无法与同一设备上的密集训练相比。 TBPTT 截断了分段边界上的梯度，尽管后面的分段仍然关注早期的精确 K/V。本研究中实施了 NVMe 支持的层，但未进行基准测试。最后，路由推理路径仍然是研究实现，而不是生产服务引擎。The main context-scaling experiment uses one model and GPU, and training lasts 100 optimizer steps. A matched dense-trained baseline is available only where dense training fits; quality at 8K–16K cannot be compared to dense training on the same device. TBPTT truncates gradients across segment boundaries, although later segments still attend to earlier exact K/V. The NVMe-backed tier is implemented but not benchmarked in this study. Finally, the routed inference path remains a research implementation rather than a production serving engine.

7  结论7  Conclusion

HGA、分段反向传播和分层 KV 存储将 GPU 工作集与完整的训练历史记录分开。在报告的 Qwen3-8B/16 GB 配置中，这将可行的训练环境从 2K 扩展到 16K，同时保持密集读出适配器质量并在重叠边界匹配密集吞吐量。 HGA训练通过该卡上的16,384个令牌进行验证，HGA评估通过该卡上的131,072个令牌进行验证；驻留块摘要使 VRAM 缓慢增长HGA, segment-wise backpropagation, and tiered KV storage separate the GPU working set from the full training history. In the reported Qwen3-8B/16 GB configuration, this extends the feasible training context from 2K to 16K while preserving dense-readout adapter quality and matching dense throughput at the overlap boundary. HGA training is validated through 16,384 tokens and HGA evaluation through 131,072 tokens on this card; the resident chunk summaries make VRAM grow gently asO​(L/c)O(L/c)，因此 RAM 和 NVMe 容量设置了超出这些长度的实际限制。由于每个代币的路由历史预算保持大致恒定，而每个代币的密集工作增长，并且 HGA 在 2K 重叠处已经稍微快一些，因此我们预计随着上下文的增长，它会变得比密集注意力更快。微调后，适配器可以使用现有生成框架的标准密集注意力或 HGA 检索/生成；为后者服务的优化生产正在进行中。, so RAM and NVMe capacity set the practical limit beyond these lengths. Because the routed historical budget per token remains approximately constant while dense work per token grows, and HGA is already marginally faster at the 2K overlap, we expect it to become faster than dense attention as context grows. After fine-tuning, the adapter can use either standard dense attention with existing generation frameworks or HGA retrieval/generation; optimized production serving for the latter is ongoing work.

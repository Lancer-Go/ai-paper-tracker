MeClear：长期 LLM 代理的合作博弈论归因和风险意识记忆清除MeClear: Cooperative Game-Theoretic Attribution and Risk-Aware Memory Clearance for Long-Horizon LLM Agents

Boyu Yang    Jiazheng Sun    Zilong Lu    Zhi Qiu    Xin Peng    Jun Zheng
摘要Abstract

长期大型语言模型 (LLM) 代理依靠外部存储系统来在扩展交互中保留用户偏好和任务知识。传统的检索机制优化语义兼容性而不是下游效用，经常将过时的、误导性的或相互矛盾的证据引入活动上下文中。我们提出了 MeClear，一个任务条件记忆清除框架，它通过合作归因识别具有负面下游效用的记忆，并有选择地抑制它们执行代理。 MeClear 将留一筛选与采样合作 Shapley 归因相结合，在交互证据之间分配效用，有效解决单一去除评估失败的冗余冲突掩盖问题。利用归因排名，MeClear 在嵌套过滤上执行查询范围的最小清除策略，在清除的上下文上验证任务恢复，而无需永久更改持久内存库。对十个长对话记忆池的综合实验评估表明，MeClear 实现了 85.9% 的目标召回率和 82.3% 的总体任务恢复率，比留一法 (LOO) 基线提高了 25.5 个百分点。Long horizon Large Language Model (LLM) agents rely on external memory systems to preserve user preferences and task knowledge across extended interactions. Conventional retrieval mechanisms optimize semantic compatibility rather than downstream utility, frequently introducing outdated, misleading, or conflicting evidence into the active context. We present MeClear, a task conditioned memory clearance framework that identifies memories featuring negative downstream utility through cooperative attribution and selectively suppresses them from agent execution. MeClear combines Leave One Out screening with sampled cooperative Shapley attribution to distribute utility across interacting evidence, effectively resolving redundant conflict masking where single removal evaluations fail. Utilizing attribution rankings, MeClear executes a query scoped minimal clearance strategy over a nested filtration, verifying task recovery on the cleared context without permanently altering the persistent memory bank. Comprehensive experimental evaluations across ten long dialogue memory pools demonstrate that MeClear achieves a target recall of 85.9% and an overall task recovery rate of 82.3%, representing a 25.5 percentage point improvement over Leave One Out (LOO) baselines.

简介Introduction

长视野大语言模型 (LLM) 智能体越来越依赖外部记忆来保留扩展交互中的偏好、观察结果和状态Long-horizon Large Language Model (LLM) agents increasingly depend on external memory to retain preferences, observations, and state across extended interactions(Wang et al. 2024a; Zhang et al. 2025)。早期的架构表明持久的经验支持规划、反思和持续适应. Early architectures demonstrated that persistent experience supports planning, reflection, and continual adaptation(Park et al. 2023)。然而，不断增长的交互历史积累了陈旧的、误导性的、冗余的或不兼容的记录。最近的研究表明，不准确的经验会在未来的任务中传播错误. However, growing interaction histories accumulate stale, misleading, redundant, or incompatible records. Recent studies reveal that inaccurate experiences propagate errors across future tasks(Xiong et al. 2025)，而语义相关的记忆通常被证明上下文不合适或功能有害, while semantically related memories often prove contextually inappropriate or functionally harmful(Zhang et al. 2026b; Ha et al. 2026)。这些发现暴露了以相关性为中心的检索的根本失败：高语义相似性并不能确保下游任务的实用性。因此，可靠的内存部署需要对检索到的记录如何因果影响代理执行进行任务调节、检索后评估。. These findings expose a fundamental failure of relevance-centered retrieval: high semantic similarity does not ensure downstream task utility. Reliable memory deployment therefore demands task-conditioned, post-retrieval evaluation of how retrieved records causally influence agent execution.

While recent frameworks refine credit assignment via evidence-anchored rewards(Ma et al. 2026)或单记录因果干预or single-record causal interventions(Srivastava 2026)，当冗余内存独立维持任务失败时，单记录删除崩溃，产生零可观察的反事实变化。基于联盟的归因通过测量子集排列中的边际贡献来解决这种局部屏蔽问题, single-record deletion collapses when redundant memories independently sustain task failure, yielding zero observable counterfactual change. Coalition-based attribution resolves this local masking by measuring marginal contributions across subset permutations(Ghorbani and Zou 2019; Jia et al. 2019a; Nematov et al. 2025)。由于精确的联盟枚举对于多记录上下文窗口来说在计算上是禁止的，因此实际清除必须有效地近似合作交互效应，同时保留足够的上下文变化以发现隐藏的毒性。. Because exact coalition enumeration is computationally prohibitive for multi-record context windows, practical clearance must efficiently approximate cooperative interaction effects while preserving sufficient contextual variation to uncover masked toxicity.

由于跨长期部署的内存实用程序固有的查询条件性质，直接修改持久内存会带来严重的安全风险。降低查询性能的存储记录可以为后续任务提供不可或缺的上下文基础，从而导致永久性数据库覆盖容易导致灾难性的跨任务性能回归Directly modifying persistent memory introduces severe safety risks due to the inherently query-conditioned nature of memory utility across long-horizon deployment. A stored record that degrades performance on a query can provide indispensable contextual grounding for subsequent tasks, rendering permanent database overwrites prone to catastrophic cross-task performance regression(Wang et al. 2024b; Xu 2025)。检索时防御通过在推理期间动态调节活动上下文可见性而不是更改数据库记录来减轻这种危险. Retrieval-time defenses mitigate this danger by dynamically regulating active context visibility during inference rather than altering database records(Ha et al. 2026; Zhang et al. 2026b)。然而，现有的准入过滤器无法隔离哪些交互记忆会导致下游任务失败，也无法验证抑制记录是否可以恢复执行准确性。因此，可靠的记忆维护需要可逆的、最小的上下文清除，并伴有明确的、抑制后行为恢复验证。. Nevertheless, existing admission filters fail to isolate which interacting memories causally induce downstream task failures, nor do they verify whether suppressing records restores execution accuracy. Reliable memory maintenance consequently demands reversible, minimal context clearance accompanied by explicit, post-suppression behavioral recovery verification.

为了解决这个问题，我们提出了 MeClear，一种用于长期大语言模型代理的合作博弈论归因和风险意识记忆清除框架。 MeClear 将记忆维护制定为一个任务条件决策过程，将反事实筛选、合作 Shapley 归因和经过验证的上下文清除相结合。该框架首先将主动上下文与检索随机性隔离开来，并应用留一法（LOO）筛选来过滤强阳性证据。随后，它执行采样合作归因，以量化不同联盟中的个体记忆贡献，解决本地删除失败的冗余冲突屏蔽问题。基于归因优先级，MeClear 在嵌套候选过滤上执行查询范围的最小清除策略，在输出生成之前验证任务恢复，而无需永久更改底层内存库。据我们所知，我们是第一个利用合作博弈论分配来解决 LLM 代理中有害的内存上下文清除问题的人。 我们的贡献总结如下：To address this problem, we present MeClear, a cooperative game-theoretic attribution and risk aware memory clearance framework for long horizon Large Language Model agents. MeClear formulates memory maintenance as a task conditioned decision process connecting counterfactual screening, cooperative Shapley attribution, and verified context clearance. The framework first isolates active contexts from retrieval stochasticity and applies Leave One Out (LOO) screening to filter strong positive evidence. It subsequently executes sampled cooperative attribution to quantify individual memory contributions across diverse coalitions, resolving redundant conflict masking where local deletion fails. Based on attribution priorities, MeClear executes a query scoped minimal clearance strategy over a nested candidate filtration, verifying task recovery prior to output generation without permanently altering the underlying memory bank. To the best of our knowledge, we are the first to leverage cooperative game-theoretic allocation to address harmful memory context clearance in LLM agents.

下水道网络中管道严重程度预测的基于模糊规则的神经符号方法A Fuzzy Rule-based Neuro-Symbolic Approach for Pipe Severity Prediction in Sewer Networks

Ngoc Thai Le Can Tho University, Can Tho, Vietnam Thanh Ma Can Tho University, Can Tho, Vietnam Umberto Straccia Corresponding author Istituto di Scienza e Tecnologie dell’Informazione, CNR - ISTI, Pisa, Italy
摘要Abstract

标准自动化污水管道严重性评估依赖于直接图像分类，创建一个“黑匣子”，其中视觉缺陷和最终严重性评分之间的联系仍然隐含。这项研究引入了一种模块化、基于模糊规则的神经符号框架，该框架通过将神经感知与符号推理解耦来弥补这一差距。感知模块利用 Swin Transformer 直接从图像预测 14 个多标签检查 CODE 度。为了进行推理，DT（特别是 Weka 的 J48）算法根据真实代码和严重性标签进行训练，并且其路径被转换为 19 个固定的 IF-THEN 规则。推理通过模糊逻辑进行：来自 CODE 条件的 t 范数激活按规则置信度进行加权，并与相应的 s 范数相结合以生成可解释的类别证据。我们使用涵盖五个高度不平衡严重性类别的 3,244 张图像的数据集评估了 Product、Łukasiewicz 和 Hamacher 算子对。通过分析原始检查员笔记的五个独立大型语言模型的共识，可以稳健地生成真实标签。我们的结果显示，与仅基于图像的分类相比，准确度、平衡准确度、宏 F1 和 MCC 分别提高了 17.9%、12.2%、23.0% 和 17.3%。 总体而言，该框架将具有竞争力的类平衡性能与从预测的 CODE 程度到规则支持和严重性证据的可追溯推理相结合。Standard automated sewer pipe severity assessment relies on direct image classification, creating a ”black box” where the link between visual defects and final severity scores remains implicit. This study introduces a modular, fuzzy rule-based neuro-symbolic framework that bridges this gap by decoupling neural perception from symbolic reasoning. The perception module utilizes a Swin Transformer to predict 14 multilabel inspection CODE degrees directly from images. For reasoning, a DT, specifically Weka’s J48, algorithm is trained on ground-truth CODEs and severity labels, and its paths are converted into 19 fixed IF–THEN rules. Inference operates via fuzzy logic: t-norm activations from CODE conditions are weighted by rule confidence and combined with corresponding s-norms to produce interpretable class evidence. We assessed Product, Łukasiewicz, and Hamacher operator pairs using a dataset of 3,244 images spanning five highly imbalanced severity classes. Ground-truth labels were robustly generated via consensus from five independent large language models analyzing original inspector notes. Our results show an improvement of accuracy, balanced accuracy, Macro F1 and MCC by 17.9%, 12.2%, 23.0%, and 17.3%, respectively, over image-only based classification. Overall, the framework combines competitive class-balanced performance with traceable reasoning from predicted CODE degrees to rule supports and severity evidence.

1 简介Introduction

下水道网络是支持公共卫生、环境保护和城市服务连续性的重要城市基础设施资产。它们的恶化可能会导致水力效率低下、结构失效、地下水渗透、堵塞以及昂贵的紧急干预等Sewer networks are essential urban infrastructure assets that support public health, environmental protection, and urban service continuity. Their deterioration may lead to hydraulic inefficiency, structural failure, groundwater infiltration, blockage, and costly emergency interventions among others[8, 27, 1]。因此，定期检查和可靠的状况评估对于维护计划、降低风险和确定修复优先级非常重要。在下水道检查实践中，目视观察通常被手动转化为缺陷描述、标准化缺陷代码和严重程度。在这些输出中，严重性预测尤其重要，因为它提供了一个紧凑的决策变量，用于确定维护操作的优先级并识别需要进一步关注的管道段。. Therefore, regular inspection and reliable condition assessment are important for maintenance planning, risk reduction, and rehabilitation prioritization. In sewer inspection practice, visual observations are commonly translated manually into defect descriptions, standardized defect CODEs, and severity levels. Among these outputs, the severity prediction is particularly important because it provides a compact decision variable for prioritizing maintenance actions and identifying pipe segments that require further attention.

计算机视觉的最新进展鼓励了基于深度神经网络的自动化下水道管道检查方法的发展。基于图像的模型可以学习与管道缺陷相关的视觉模式，并且可以经过训练来预测缺陷类别或严重程度类别Recent advances in computer vision have encouraged the development of automated sewer pipe inspection methods based on deep neural networks. Image-based models can learn visual patterns associated with pipe defects and can be trained to predict either defect categories or severity classes[11, 15, 29]。然而，根据下水道检查图像预测管道严重程度仍然是一项具有挑战性的任务。闭路电视图像经常受到低照度、模糊、水、沉积物、遮挡、视点变化和视觉噪声的影响。此外，下水道缺陷在视觉上是多种多样的，并且可能同时出现在同一图像中。这意味着视觉证据在缺陷级别通常是多标签的，而最终输出通常表示为单个严重性类别。高级不平衡使任务变得更加复杂，因为在许多检查数据集中，低严重性案例比严重案例要频繁得多。我们要注意的是，在实际的下水道检查中，很少直接根据原始图像进行严重性评估。相反，检查员首先识别描述可观察结构状况的标准化缺陷代码，然后根据检查指南确定总体严重性。因此，缺陷代码提供了一种自然的语义表示，可以连接低级视觉观察和高级维护决策。这种实用的工作流程表明，中间缺陷语义的显式建模可以为直接图像到严重性预测提供更透明的替代方案。. However, pipe severity prediction from sewer inspection images still remains a challenging task. CCTV images are often affected by low illumination, blur, water, deposits, occlusion, viewpoint changes, and visual noise. Moreover, sewer defects are visually diverse and may co-occur in the same image. This means that visual evidence is often multilabel at the defect level, whereas the final output is usually represented as a single severity class. The task is further complicated by high class imbalance because low-severity cases are much more frequent than critical cases in many inspection datasets. Let us note that in practical sewer inspection, severity assessment is rarely performed directly from raw images. Instead, inspectors first identify standardized defect CODEs that describe observable structural conditions and subsequently determine the overall severity according to inspection guidelines. Defect CODEs therefore provide a natural semantic representation that bridges low-level visual observations and high-level maintenance decisions. This practical workflow suggests that explicit modelling of intermediate defect semantics may offer a more transparent alternative to direct image-to-severity prediction.

尽管最近的深度学习模型已经取得了令人鼓舞的预测性能，但大多数方法将管道严重性预测制定为直接图像分类问题。然而，缺陷识别和严重性预测是相关但根本不同的任务。视觉模型可以识别局部缺陷证据，但严重性级别的分配通常取决于多个缺陷指标的组合方式。例如，不同缺陷代码的存在、不存在和相互作用可能导致不同的严重性决策。因此，管道严重性预测不仅是视觉分类问题，也是中间缺陷语义的推理问题。直接图像到严重性模型可能提供有用的预测有效性，但通常不能明确表示将视觉观察与严重性结果联系起来的缺陷级推理过程。因此，将视觉证据与严重性决策联系起来的推理过程在很大程度上仍然是隐含的，这使得解释预测或验证哪些缺陷证据支持特定的维护建议变得困难。Although recent deep learning models have achieved encouraging predictive performance, most approaches formulate pipe severity prediction as a direct image classification problem. However, defect recognition and severity prediction are related but fundamentally different tasks. A visual model may identify local defect evidence, but the assignment of a severity level often depends on how several defect indicators are combined. For instance, the presence, absence, and interaction of different defect CODEs may lead to different severity decisions. Therefore, pipe severity prediction is not only a visual classification problem, but also a reasoning problem over intermediate defect semantics. Direct image-to-severity models may provide useful predictive effectiveness, but usually do not explicitly represent the defect-level reasoning process that links visual observation to severity outcomes. Consequently, the reasoning process that links visual evidence to severity decisions remains largely implicit, making it difficult to explain predictions or verify which defect evidence supports a particular maintenance recommendation.

为了解决这个问题，本文提出了一种基于模糊规则的神经符号方法，用于下水道网络中管道严重程度的预测。中心思想是引入缺陷代码作为原始下水道管道图像和最终严重性类别之间的中间语义表示。所提出的框架不是直接将图像映射到严重性标签，而是首先从检查图像预测多标签缺陷代码等级，然后通过固定的符号规则库推断严重性等级。这种设计将神经视觉感知与符号严重性推理分开，同时允许通过预测的代码、激活的规则、规则置信度值和类别级证据评分来追踪最终决策。也就是说，每个严重性预测都可以通过预测的缺陷代码、激活的规则、规则置信值和聚合的类别证据来追踪，为下水道检查提供透明的决策支持。To address this issue, this paper proposes a fuzzy rule-based neuro-symbolic approach for pipe severity prediction in sewer networks. The central idea is to introduce defect CODEs as an intermediate semantic representation between raw sewer pipe images and final severity classes. Instead of directly mapping an image to a severity label, the proposed framework first predicts multilabel defect CODE degrees from the inspection image and then infers the severity degree through a fixed symbolic rule base. This design separates neural visual perception from symbolic severity reasoning, while allowing the final decision to be traced through predicted CODEs, activated rules, rule confidence values, and class-level evidence scores. That is, every severity prediction can be traced through predicted defect CODEs, activated rules, rule confidence values, and aggregated class evidence, providing transparent decision support for sewer inspection.

值得注意的是，所提出的方法应与端到端神经符号学习系统仔细区分。在本研究中，符号规则库没有与神经模型联合优化，也没有使用规则损失反向传播。相反，神经符号一词是指神经多标签 CODE 预测与基于固定符号规则的推理层的集成。神经组件执行基于图像的感知，而符号组件执行可解释的严重性推断。这种分离是有意的，因为主要目标是通过使中间缺陷表示和基于规则的推理过程变得明确来提高管道严重性预测的透明度。It is worth noting that the proposed approach should be carefully distinguished from end-to-end neuro-symbolic learning systems. In this study, the symbolic rule base is not jointly optimized with the neural model, and no rule-loss backpropagation is used. Instead, the term neuro-symbolic refers to the integration of neural multilabel CODE prediction with a fixed symbolic rule-based reasoning layer. The neural component performs image-based perception, whereas the symbolic component performs interpretable severity inference. This separation is intentional because the main objective is to improve transparency in pipe severity prediction by making the intermediate defect representation and rule-base reasoning process explicit.

4.6 评估指标Evaluation metrics

Because the severity distribution is highly imbalanced, macro F1 and balanced accuracy are emphasized when comparing inference settings. MCC is reported as a complementary global measure of agreement that accounts for all cells of the confusion matrix. Macro F1 is used as the primary criterion for selecting the CODE-interface configuration on the validation set. These metrics provide a more informative assessment of minority-class recognition than accuracy alone, particularly for rare severe defects, as accuracy may overestimate the effectiveness of a model that mainly captures the dominant low-severity class.

5.5 讨论和限制Discussion and limitations

实验结果表明，使用缺陷代码作为中间语义表示提高了基于图像的严重性评估的可解释性和类平衡有效性。所提出的框架将严重性预测分解为神经代码预测和符号规则推理，与仅图像基线相反，后者直接将图像映射到严重性标签。The experimental results show that using defect CODEs as an intermediate semantic representation improves the interpretability and class-balanced effectiveness of image-based severity assessment. The proposed framework decomposes severity prediction into neural CODE prediction and symbolic rule reasoning, in contrast to the image-only baseline, which directly maps images to severity labels.

For Product and Hamacher, relative gains reach 17.9% in accuracy, 12.2% in balanced accuracy, 23.0% in Macro F1, and 17.3% in MCC. The MCC increase confirms that the improvement extends beyond the two class-balanced metrics. Nevertheless, the class-wise analysis shows that these aggregate gains coexist with weak class-4 recall and should not be interpreted as uniform improvement across severity levels.

验证分析为 Product、Hamacher 和 Łukasiewicz 选择软度推理。 Product 和 Hamacher 在此接口下产生相同的聚合测试指标，但聚合相等本身并不能建立相同的规则激活或类证据。 Łukasiewicz 产生相同的精度和平衡精度，但在 Macro F1、Macro Precision、MCC 和几个混淆矩阵单元中略有不同。The validation analysis selects soft-degree inference for Product, Hamacher, and Łukasiewicz. Product and Hamacher yield identical aggregate test metrics under this interface, but aggregate equality alone does not establish identical rule activations or class evidence. Łukasiewicz produces the same accuracy and balanced accuracy but differs slightly in Macro F1, Macro Precision, MCC, and several confusion-matrix cells.

验证结果还表明接口选择可能与拆分相关。 Product 和 Hamacher 相对于最佳阈值候选的软度优势仅为 0.0033 Macro F1，而 Łukasiewicz 则为 0.0015。这些差异应被解释为特定于配置的发现，而不是证明一种接口能够最好地推广到其他数据集或编码标准的证据。The validation results also indicate that interface selection may be split-dependent. The soft-degree advantage over the best thresholded candidate is only 0.0033 Macro F1 for Product and Hamacher and 0.0015 for Łukasiewicz. These differences should be interpreted as configuration-specific findings rather than evidence that one interface will generalize best to other datasets or coding standards.

Oracle CODE + Rule 实验阐明了符号规则库的作用。其强大的有效性（包括 0.7341 的 MCC）表明，当可靠的 CODE 输入可用时，规则库可以将 CODE 模式映射到严重性类别。相对于 Product 和 Hamacher 大约 50.0% 的 MCC 差距将多标签 CODE 预测视为重要瓶颈，尽管汉明精度很高，但与中等的 CODE 级宏 F1 一致。然而，由于 Oracle 推理并不完美，规则覆盖范围和标签不确定性也仍然相关。The Oracle CODE + Rule experiment clarifies the role of the symbolic rule base. Its strong effectiveness, including an MCC of 0.7341, indicates that the rule base can map CODE patterns to severity classes when reliable CODE inputs are available. The approximately 50.0% MCC gap relative to Product and Hamacher identifies multilabel CODE prediction as an important bottleneck, consistent with the moderate CODE-level Macro F1 despite high Hamming accuracy. Because Oracle reasoning is not perfect, however, rule coverage and label uncertainty also remain relevant.

仍然存在一些限制。首先，该框架取决于预测的 CODE 程度的质量。如果错过关键代码，规则层可能会激活不正确的严重性规则。其次，所选的操作员界面配置基于一次验证拆分；几个候选者之间的微小差异表明，当有足够的数据可用时，应使用重复分割或交叉验证来检查其稳定性。第三，规则库是从单个DT中提取的，这使推理轨迹保持紧凑，但可能会限制罕见缺陷组合的覆盖范围。 最后，根据检查员撰写的观察结果，使用多法学硕士共识协议生成严重性标签；额外的专家验证将进一步加强评价的可靠性。Several limitations remain. First, the framework depends on the quality of predicted CODE degrees. If critical CODEs are missed, the rule layer may activate an incorrect severity rule. Second, the selected operator–interface configurations are based on one validation split; the small differences between several candidates suggest that their stability should be examined using repeated splits or cross-validation when sufficient data are available. Third, the rule base is extracted from a single DT, which keeps the reasoning trace compact but may limit coverage for rare defect combinations. Finally, the severity labels are generated using a multi-LLM consensus protocol based on inspector-written observations; additional expert validation would further strengthen the reliability of the evaluation.

总体而言，结果支持所提出的框架作为可解释的基于图像的严重性评估方法。在可部署的方法中，该框架在所有报告的指标（包括平衡准确性、宏 F1 和 MCC）中取得了最强的结果，同时提供了明确的规则级解释。 Oracle 分析进一步显示了当真实代码注释可用时，巨大的诊断潜力。剩余的有效性差距主要但并非排他性地表明需要更强的多标签 CODE 预测。Overall, the results support the proposed framework as an interpretable image-based severity assessment approach. Among the deployable methods, the framework achieves the strongest results across all reported metrics, including balanced accuracy, Macro F1, and MCC, while providing explicit rule-level explanations. The Oracle analysis further shows substantial diagnostic potential when ground-truth CODE annotations are available. The remaining effectiveness gap points primarily, but not exclusively, to the need for stronger multilabel CODE prediction.

6 结论Conclusion

本研究提出了一种基于模糊规则的神经符号框架，用于基于图像的下水道管道严重性评估。该框架将任务分解为 14 个缺陷 CODE 程度的神经多标签预测和通过 DT（即 Weka 的 J48 算法）提取的固定符号规则库进行模糊严重性推理。此设计保留了仅图像部署设置，同时公开了中间代码表示、激活的 IF-THEN 规则、规则置信度值以及每个严重性预测背后的聚合类证据。 Product、Łukasiewicz 和 Hamacher t-norm/s-norm 对与软度和阈值 CODE 接口一起进行评估，接口配置仅在验证集上选择。This study presented a fuzzy rule-based neuro-symbolic framework for image-based sewer pipe severity assessment. The framework decomposes the task into neural multilabel prediction of 14 defect CODE degrees and fuzzy severity reasoning over a fixed symbolic rule base extracted via a DT (viz. Weka’s J48 algorithm). This design preserves an image-only deployment setting while exposing the intermediate CODE representation, activated IF–THEN rules, rule confidence values, and aggregated class evidence underlying each severity prediction. Product, Łukasiewicz, and Hamacher t-norm/s-norm pairs were evaluated together with soft-degree and thresholded CODE interfaces, with the interface configuration selected exclusively on the validation set.

验证选择的 Product 和 Hamacher 软度配置实现了最高的可部署 Macro F1，而 Łukasiewicz 则实现了比前两者略高的 MCC。在报告的聚合指标中，所有三个变体都优于仅图像基线。 Oracle CODE + Rule 实验表明，固定规则库包含有用的严重性知识，并且不完善的 CODE 预测是下游错误的主要来源（尽管不是唯一来源）。定性案例进一步表明，可以通过相同的显式规则级推理跟踪来检查正确和错误的决策。The validation-selected Product and Hamacher soft-degree configurations achieved the highest deployable Macro F1, while Łukasiewicz achieved a marginally higher MCC than the two before. All three variants outperformed the image-only baseline across the reported aggregate metrics. The Oracle CODE + Rule experiment indicated that the fixed rule base contains useful severity knowledge and that imperfect CODE prediction is a major, although not the only, source of downstream error. The qualitative cases further showed that both correct and incorrect decisions can be examined through the same explicit rule-level inference trace.

为所有三个模糊算子选择了软度推理，尽管它相对于最佳阈值候选的验证优势很小。进一步的工作应该提高对罕见和视觉上模糊的代码的识别，检查重复或交叉验证评估下界面选择的稳定性，并研究更丰富但仍然可解释的规则提取器，例如 RIPPERSoft-degree inference was selected for all three fuzzy operators, although its validation advantage over the best thresholded candidate was small. Further work should improve recognition of rare and visually ambiguous CODEs, examine the stability of interface selection under repeated or cross-validated evaluation, and investigate richer but still interpretable rule extractors, such as RIPPER[6]。多法学硕士衍生的严重性标签的领域专家验证也可以增强目标注释的可靠性。. Domain-expert validation of the multi-LLM-derived severity labels may also strengthen the reliability of the target annotations.

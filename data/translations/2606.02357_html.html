多模式代理真的能从工具的使用中受益吗？能力增益的系统研究Do Multimodal Agents Really Benefit from Tool Use? A Systematic Study of Capability Gains

摘要Abstract

工具增强的多模式代理显示出强大的基准收益，通常被视为代理已经学会使用工具的证据。我们认为这种解释可能为时过早：工具调用跟踪本身并不能显示该工具是否提供了关键答案信息。我们研究了两种具有代表性的“图像思维”智能体 Thyme 和 DeepEyesV2，涉及现实世界理解、OCR、图表理解和数学推理。每个代理都会与它的无工具对应代理以及从相同源池训练的纯文本推理器进行比较，而无需工具调用轨迹。工具访问几乎不会产生一致的总体改进，不能可靠地降低生成代币的成本，并且只留下一小部分仅由工具解决的问题：DeepEyesV2 的 93% 的工具解决问题和 96% 的 Thyme 问题也通过至少一种非工具设置解决。机制消融进一步表明，完整的工具使用循环并不总是优于工具调用格式或单独返回的执行结果。在我们研究的环境中，被分析的智能体似乎比工具贡献的能力更可靠地学习工具调用模式，这表明评估应该区分工具可用性和工具是否真正扩展了智能体可以解决的问题。Tool-augmented multimodal agents show strong benchmark gains, often taken as evidence that agents have learned to use tools. We argue that this interpretation can be premature: a tool-call trace alone does not show whether the tool supplied answer-critical information. We study two representative “thinking with images” agents, Thyme and DeepEyesV2, across real-world understanding, OCR, chart understanding, and mathematical reasoning. Each agent is compared with its Tool-Free counterpart and with a Pure-Text Reasoner trained from the same source pool without tool-calling trajectories. Tool access yields little consistent aggregate improvement, does not reliably reduce generated-token cost, and leaves only a small tool-only solved set: 93% of DeepEyesV2’s tool-solved problems and 96% of Thyme’s are also solved by at least one nontool setting. Mechanism ablations further show that the full tool-use loop does not consistently outperform either the tool-call format or the returned execution result alone. In the settings we study, the analyzed agents appear to learn tool-calling patterns more reliably than toolcontributed capabilities, suggesting that evaluation should distinguish tool availability from whether tools actually expand what agents can solve.

这并不是一个孤立的好奇心。最近的多模态系统越来越多地使用中间视觉或计算操作，包括 OCR、代码执行、区域检查、视觉操作或代码中介推理，它们的基准增益通常与这些操作相关（Wu 等人，2025；Liu 等人，2025；Wang 等人，2025b；Wei 等人，2025；Li 等人，2025b）。然而观察这样的操作仅表明模型执行了一个操作；它是否提供了缺失的信息，或者如果没有它，模型是否会失败，这是一个单独的问题。因此，我们要问：跨实例，工具访问实际上是否扩大了代理可以解决的问题集？This is not an isolated curiosity. Recent multimodal systems increasingly use intermediate visual or computational operations—including OCR, code execution, region inspection, visual manipulation, or code-mediated reasoning—and their benchmark gains are often linked to these operations (Wu et al., 2025; Liu et al., 2025; Wang et al., 2025b; Wei et al., 2025; Li et al., 2025b). Yet observing such an operation only shows that the model performed one; whether it supplied missing information, or whether the model would have failed without it, is a separate question. We therefore ask: across instances, does tool access actually expand the set of problems an agent can solve?

为了研究这个问题，我们首先将工具增强的图像思维代理置于更广泛的基准比较中。在现实世界理解、OCR、图表理解和数学推理基准方面，我们将几个最近的工具增强多模态系统与非工具推理基线（Bai 等人，2025b；Wang 等人，2025a；Meng 等人，2025）以及使用来自 DeepEyesV2（Hong 等人，2026）源池的过滤数据进行训练的无工具纯文本推理器进行了比较。比较表明，经过工具增强的代理通常会取得很好的结果，但在没有工具的情况下也可以获得类似的性能To examine this question, we first place tool-augmented thinking-with-images agents in a broader benchmark comparison. Across realworld understanding, OCR, chart understanding, and mathematical reasoning benchmarks, we compare several recent tool-augmented multimodal systems with non-tool reasoning baselines (Bai et al., 2025b; Wang et al., 2025a; Meng et al., 2025) and a tool-free Pure-Text Reasoner trained on filtered data from the DeepEyesV2 (Hong et al., 2026) source pool. 2.1 工具增强多模态推理2.1 Tool-Augmented Multimodal Reasoning

越来越多的工作将多模态模型从被动图像理解转向主动视觉推理，通常被描述为“用图像思考”（OpenAI，2025）。免训练系统通过可执行程序编排视觉模块（Gupta 和 Kembhavi，2023；Surís 等人，2023）或产生视觉工件作为中间推理步骤（Hu 等人，2024）。最近经过训练的系统教导多模态模型直接调用工具，涵盖端到端强化学习启发（Zheng et al., 2026）、像素空间和缩放和聚焦操作（Su et al., 2026a；Zhang et al., 2025）、查询条件工具选择（Huang et al., 2025）、交错可视化编辑（Wu et al., 2026）、深度多轮轨迹（Lai 等人，2026），以及轨迹合成、基于工具的奖励建模和经验重用的改进（Ashraf 等人，2025；Ding 等人，2026；Wang 等人，2026b）。我们研究的两个系统 Thyme（Zhang 等人，2026b）和 DeepEyesV2（Hong 等人，2026）遵循这一范式，在推理过程中使用代码执行进行图像处理和数值计算。先前的工作询问如何改进工具的使用；我们询问工具访问是否扩展了代理可以解决的问题。A growing line of work moves multimodal models from passive image understanding toward active visual reasoning, often described as “thinking with images” (OpenAI, 2025). Training-free systems orchestrate vision modules through executable programs (Gupta and Kembhavi, 2023; Surís et al., 2023) or produce visual artifacts as intermediate reasoning steps (Hu et al., 2024). Recent trained systems teach multimodal models to invoke tools directly, covering end-to-end RL elicitation (Zheng et al., 2026), pixel-space and zoom-and-focus operations (Su et al., 2026a; Zhang et al., 2025), queryconditional tool selection (Huang et al., 2025), interleaved visual editing (Wu et al., 2026), deep multi-turn trajectories (Lai et al., 2026), and refinements in trajectory synthesis, tool-grounded reward modeling, and experience reuse (Ashraf et al., 2025; Ding et al., 2026; Wang et al., 2026b). The two systems we study, Thyme (Zhang et al., 2026b) and DeepEyesV2 (Hong et al., 2026), follow this paradigm by using code execution for image manipulation and numerical computation during reasoning. Prior work asks how to improve tool use; we ask whether tool access expands what agents can solve.

2.3 代理多模态推理的基准2.3 Benchmarks for Agentic Multimodal Reasoning

最近的基准将多模态评估扩展到明确强调工具使用的代理设置，包括跨不同任务的图像代理思维（Li et al., 2025b）、跨许多子域的长视野混合工具使用（Su et al., 2026b）以及带有专家注释的逐步轨迹的知识密集型地理定位推理（Geng et al., 2026）。这些基准使工具的使用在评估中更加重要，但它们的主要目标是衡量更困难或更具流程意识的任务下的性能。我们提出一个补充问题：观察到的工具启用性能实际上是否归因于工具访问？Recent benchmarks broaden multimodal evaluation toward agentic settings that explicitly stress tool use, including agentic thinking-with-images across diverse tasks (Li et al., 2025b), long-horizon hybrid tool use across many sub-domains (Su et al., 2026b), and knowledge-intensive geolocation reasoning with expert-annotated stepwise traces (Geng et al., 2026). These benchmarks make tool use more central to evaluation, but their primary goal is to measure performance under harder or more process-aware tasks. We ask a complementary question: is the observed tool-enabled performance actually attributable to tool access?

3.1 研究设置3.1 Study Settings

本节介绍了整篇论文中使用的五种设置、它们所应用的两种多模式代理、涵盖的基准以及如何训练纯文本推理机。三种设置测试工具访问是否扩大了代理可以解决的问题集；其余两个隔离行为是否更多地依赖于模型生成的工具调用消息或返回的执行结果。This section describes the five settings used throughout the paper, the two multimodal agents they are applied to, the benchmarks covered, and how the Pure-Text Reasoner is trained. 4.1 工具访问并不能一致地扩展已解集4.1 Tool Access Does Not Consistently Expand Solved Sets

如果工具访问提供了强大的能力增益，我们希望它能够提高工具相关基准的准确性或减少达到可比答案所需的生成令牌成本。在我们的实验中，这两种模式都不一致。If tool access provides a robust capability gain, we would expect it to improve accuracy on toolrelevant benchmarks or reduce the generated-token cost needed to reach comparable answers. In our experiments, neither pattern appears consistently.

聚合精度。Aggregate accuracy.在感知和推理基准（表 1 和表 2）中，ToolEnabled 代理具有竞争力，有时会超过单个基准，但跨任务系列并没有出现一致的优势。此外，禁用工具不会导致性能的系统性崩溃：无工具变体通常保持接近，有时甚至超过启用工具的对应版本，这表明许多成功并不依赖于执行的工具使用。尽管在没有任何工具调用机制的情况下对来自同一源池的处理数据进行了训练，但在涵盖 OCR、图表和数学推理的多个基准测试中，纯文本推理器匹配或超越了它们。因此，对于工具支持的推理而言，总体准确性并未表现出一致的优势。Across perception and reasoning benchmarks (Tables 1 and 2), the ToolEnabled Agents are competitive and occasionally top an individual benchmark, but no consistent advantage emerges across task families. Moreover, disabling tools does not lead to a systematic collapse in performance: the Tool-Free variants often remain close to, and occasionally surpass, their tool-enabled counterparts, suggesting that many successes do not depend on executed tool use. On several benchmarks — spanning OCR, charts, and math reasoning — the Pure-Text Reasoner matches or surpasses them, despite being trained on processed data derived from the same source pool without any tool-calling mechanism. Thus, aggregate accuracy does not show a consistent advantage for tool-enabled inference.

5 结论5 Conclusion

人们很自然地认为，向多模式代理添加工具并训练其调用这些工具可以使代理变得更强大。我们的结果表明需要进行更仔细的区分。在两个训练有素的代理、四个任务系列以及对正确性、过程、生成令牌成本和机制的分析中，我们发现几乎没有证据表明工具访问相对于可比较的非工具设置一致地扩展了已解决的集合。工具调用通常发生在无需工具即可解决的样本上，无法修复不正确的预测，并且由不同代理中工具使用循环的不同部分保留。这些模式指出了学习调用工具和学习工具输出改变可解决问题之间的差距：最终答案的正确性本身并不能区分提供缺失信息的工具和仅确认可用答案的工具。It has become natural to assume that adding tools to a multimodal agent, and training it to call them, makes the agent more capable. Our results suggest a more careful distinction. Across two trained agents, four task families, and analyses of correctness, process, generated-token cost, and mechanism, we find little evidence that tool access consistently expands the solved set relative to comparable non-tool settings. Tool calls often occur on samples already solved without tools, fail to repair incorrect predictions, and are preserved by different parts of the tool-use loop in different agents. These patterns point to a gap between learning to call tools and learning when tool outputs change what can be solved: final-answer correctness alone does not distinguish tools that supply missing information from those that merely confirm an available answer.

因此，评估和训练信号应该归功于工具所添加的信息，而不仅仅是因为它们存在于成功的轨迹中；否则，扩展工具访问可能会加强工具调用频率，而不是有意义的工具使用。Evaluation and training signals should therefore credit tools for the information they add, not merely for their presence in successful trajectories; otherwise, scaling tool access may reinforce tool-calling frequency rather than meaningful tool use.

局限性Limitations

这项研究的一些界限值得标记。首先，我们的分析集中在两个代表性的“用图像思考”智能体和四个任务族上。代理生态系统不断发展，因此我们报告的模式应该被理解为表征该领域的一部分，而不是整个领域。纯文本推理机的作用也有限：尽管它使用相同的主干规模和源数据池并且不包含工具调用轨迹，但它是通过重新注释和过滤单独进行训练的。因此，我们将其用作解决集归因的诊断参考，而不是作为无工具训练通常更优越的证据。A few boundaries on this study are worth flagging. First, our analysis centers on two representative “thinking with images” agents and four task families. The agent ecosystem continues to grow, so the patterns we report should be read as characterizing this slice of the field rather than the field as a whole. The Pure-Text Reasoner also has a limited role: although it uses the same backbone scale and source data pool and contains no tool-calling trajectories, it is separately trained with re-annotation and filtering. We therefore use it as a diagnostic reference for solved-set attribution, not as evidence that tool-free training is generally superior.

其次，我们的框架在三个层面上描述了工具使用的特征：总体性能和解决集组成、每个样本的结果与过程归因以及机制层面的消融。互补的观点，例如用户感知的帮助、多轮交互或特定领域的部署，可以进一步丰富这一观点。Second, our framework characterizes tool use at three levels: aggregate performance and solved-set composition, per-sample outcomes with process attribution, and mechanism-level ablations. Complementary perspectives, such as user-perceived helpfulness, multi-turn interaction, or domain-specific deployment, could further enrich this view.

第三，流程层面的归因依赖于强大的语言模型作为判断，尽管 40% 的人工审核支持主要角色区分。其他归因范式，例如多法官整体或细粒度的人类研究，可以提供额外的三角测量。尽管如此，所有四个分析维度的定性模式都是一致的，这表明它们不是任何单一法官的产物。Third, the process-level attribution relies on a strong language model as a judge, although a 40% manual audit supports the major role distinctions. Alternative attribution paradigms, such as multijudge ensembles or fine-grained human studies, could provide additional triangulation. Nevertheless, the qualitative patterns are consistent across all four analytical dimensions, suggesting that they are not artifacts of any single judge.

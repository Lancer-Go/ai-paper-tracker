摘要Abstract

具有可验证奖励的强化学习，特别是组相对策略优化（GRPO），现在在监督检查点上例行运行，以期产生更强大的智能体。我们询问它是否为 4B 到 8B 规模的小型语言和视觉语言模型网络代理增加了技能，或者它是否主要重塑了监督模型已有的行为。在 18 次运行的控制网格中，不同的学习率、KL 权重、种子、初始化和裁剪，没有任何配置能够可靠地提高智能体已基本掌握的任务的强监督基线的成功率。在文本轨道上，中等到高的学习率会使情况变得更糟。在配对测试、25 个评估种子、6 个训练种子、配方更改、文本和标记集屏幕截图观察以及将主干缩放至 8B 下，零值成立；可信的损害是文本跟踪发现的结果，并且在标记集下只是名义上的。为了表明零值反映了设置而不是损坏的管道，我们对可通过采样获得奖励的任务运行相同的工具、奖励和配方，并且在排除零的配对间隔的情况下，成功率提高了 22 个点。因此，GRPO 仅在有上升空间时才有帮助，这意味着抽样策略已经比贪婪策略更容易成功。然后我们解释失败的原因。中等学习率会使智能体退化，高学习率会使智能体崩溃，这两种机制形成双重分离：将退化机制嫁接到注意力和 MLP 块上，而崩溃机制无法追溯到任何单个组，并且主导权重运动的嵌入变化是因果惰性的。在 4B 处，后层中的有效排名跟踪两个方向的能力；到了8B，两人就分开了。这种耦合特定于较小的模型，因此我们将其报告为与比例相关。Reinforcement learning with verifiable rewards, and Group Relative Policy Optimization (GRPO) in particular, is now run routinely on a supervised checkpoint in the hope of producing a stronger agent. We ask whether it adds skill to a small language and vision-language model web agent at the 4B to 8B scale, or whether it mostly reshapes behavior the supervised model already has. Across a control grid of 18 runs that varies learning rate, KL weight, seed, initialization, and clipping, no configuration credibly improves the success rate of a strong supervised baseline on tasks the agent has largely mastered. On the text track, moderate to high learning rates make it credibly worse. The null holds under paired testing, 25 evaluation seeds, 6 training seeds, changes to the recipe, both text and Set-of-Marks screenshot observations, and scaling the backbone to 8B; the credible harm is a text-track finding and is only nominal under Set-of-Marks. To show that the null reflects the setting and not a broken pipeline, we run the identical harness, reward, and recipe on tasks whose reward is reachable by sampling, and there the success rate rises by 22 points with a paired interval that excludes zero. GRPO therefore helps only when there is headroom to climb, meaning the sampled policy already succeeds more often than the greedy one. We then explain the failure. A middle learning rate degrades the agent and a high one collapses it, and the two regimes form a double dissociation: grafting localizes the degrade regime to the attention and MLP blocks, while the collapse regime cannot be traced to any single group, and the embedding change that dominates the weight movement is causally inert. At 4B, effective rank in the late layers tracks capability in both directions; at 8B the two come apart. This coupling is specific to the smaller model, so we report it as scale-dependent.

1 简介Introduction

强化学习的后期训练已成为语言和多模态智能体的日常工作。首先教导监督模型遵循任务格式，GRPO 或近亲Post-training with reinforcement learning has become routine for language and multimodal agents. A supervised model is first taught to follow the task format, and GRPO or a close relative(Shao et al., 2024; Yu et al., 2026; Liu et al., 2025)然后，我们会面临可验证的奖励，希望将能力推向超越仅靠监督所达到的水平。对于网络代理来说，吸引力是直接的，因为部署任务成功的成本很低，而提升数学和编码模型的秘诀预计将提升代理的点击、打字和导航能力is then run against a verifiable reward in the hope of pushing capability past what supervision alone reached. For web agents the appeal is direct, since rollouts are cheap to score against task success and the recipe that lifted mathematics and coding models is expected to lift an agent that clicks, types, and navigates(Qi et al., 2025)。目前尚不清楚的是，第二阶段是否为小型语言和视觉语言模型智能体增加了新技能，或者是否主要强化了监督模型可能已经做出的选择. What remains unclear is whether this second stage adds new skill to a small language and vision-language model agent, or whether it mostly sharpens choices the supervised model could already make(Chen et al., 2026)。这在实践中很重要。如果强化学习增加了能力，那么更多的投资就是正确的；如果它只是强化监督模型已经做的事情，那么努力就属于更好的监督或蒸馏。. This matters in practice. If reinforcement learning adds capability, more of it is the right investment; if it only sharpens what the supervised model already does, the effort belongs in better supervision or distillation.

我们研究了一种严格控制下的代理：4B 语言和视觉语言模型We study one such agent under tight control: a 4B language and vision-language model(Bai et al., 2025)在 MiniWoB 基准上驱动网络代理driving a web agent on the MiniWoB benchmark(Shi et al., 2017; Liu et al., 2018)。保持安全带、奖励和任务集固定，我们扫清强化学习选择，练习者将通过干净的贪婪解码和针对监督基线的配对测试来调整和评分每次运行。结果为空。在 18 次运行的网格中，没有任何配置能够可靠地击败智能体已经基本上掌握的任务的监督，并且一旦学习率离开狭窄的低带，智能体就会变得更糟。空值也很稳健。它仍然存在添加评估和训练种子、添加网格省略的时间表和组大小选择、从文本观察切换到标记集屏幕截图以及将主干缩放到 8B 的情况。图. Holding the harness, reward, and task set fixed, we sweep the reinforcement-learning choices a practitioner would tune and score every run with clean greedy decoding and a paired test against the supervised baseline. The result is a null. No configuration in the grid of 18 runs credibly beats supervision on tasks the agent has already largely mastered, and once the learning rate leaves a narrow low band the agent gets worse. The null is also robust. It survives adding evaluation and training seeds, adding the schedule and group-size choices the grid omitted, switching from a text observation to a Set-of-Marks screenshot, and scaling the backbone to 8B. 读数为零时，管道已损坏或动力不足，无法爬升到任何地方。阳性对照排除了这种情况。使用相同的工具、奖励和配方，我们选择可以通过采样获得奖励的任务，其中模型在温度下比在贪婪解码下更容易成功，并重新训练。在此情况下，智能体最高可攀升 22 点，且配对区间不包括零。当采样策略已经可以击败贪婪策略时，GRPO 会改进代理；而当贪婪策略是两者中更好的策略时，GRPO 就会停止，这是一个有能力的监督代理所占据的状态。实践者可以通过首先测量采样成功与贪婪成功之间的差距来采取行动，当差距不为正时，对强化学习期望很少。对于一个有能力的小型网络代理来说，额外的技能来自监督或蒸馏，而不是来自更多的强化学习。One reading of a null is that the pipeline is broken or underpowered and would fail to climb anywhere. A positive control rules this out. Using the identical harness, reward, and recipe, we select tasks whose reward is reachable by sampling, where the model already succeeds under temperature more often than under greedy decoding, and retrain. There the agent climbs by up to 22 points, with a paired interval that excludes zero. GRPO improves the agent when the sampled policy can already beat the greedy one, and it stalls when greedy is the better of the two, which is the regime a competent supervised agent occupies. A practitioner can act on this by measuring the gap between sampled and greedy success first and expecting little from reinforcement learning when that gap is not positive. For a competent small web agent, extra skill comes from supervision or distillation, not from more reinforcement learning.

然后我们打开模型来询问为什么有害政权会失败。低学习率留下的更新是真实的，但太小而无法改变行为；中等速率会降低代理的性能，而高速率则会使其崩溃。两次失败是不同的病变。降级制度破坏有效等级We then open the model to ask why the harmful regimes fail. A low learning rate leaves an update that is real but too small to change behavior; a middle rate degrades the agent, and a high rate collapses it. The two failures are different lesions. The degrade regime destroys the effective rank(Roy and Vetterli, 2007)后面的层，同时保持前面的层完好无损，而崩溃机制保持该等级等于或高于监督，反而破坏了读数，这是我们在近两千个固定状态下确认的反转。为了测试这种相关性是否是因果关系，我们移植了权重。从初始化中恢复注意力或 MLP 块会修复退化的代理，同时恢复嵌入（其漂移主导原始权重变化）不会执行任何操作，这将计算块指向失败的位置并清除嵌入，尽管其移动较大of the late layers while leaving earlier layers intact, whereas the collapse regime holds that rank at or above supervision and instead destroys the readout, an inversion we confirm at nearly two thousand fixed states. To test whether this correlation is causal, we graft weights. Restoring the attention or MLP blocks from initialization repairs the degraded agent, while restoring the embedding, whose drift dominates the raw weight change, does nothing, which points to the compute blocks as the site of the failure and clears the embedding despite its large movement(Ilharco et al., 2022)。从另一个方向看，同一个探针显示，后期层等级随着代理能力的提升而上升，在能力下降的地方下降，因此在 4B 等级时，技能是双向跟踪的。在 8B 时，这种耦合失效了，我们这么说。. Read in the other direction, the same probe shows late-layer rank rising with capability where the agent climbs and falling where it degrades, so at 4B rank tracks skill both ways. At 8B this coupling breaks down, and we say so.

我们对单一基准的选择是经过深思熟虑的，并且遵循可解释性目标。机械账户要求将除干预之外的所有内容保持固定，以便有效排名或成功率的变化可以归因于学习率，而不是环境中不受控制的变化。 MiniWoB 提供了这种控制。它的任务在种子下是确定性的，它的成功检查是精确的，它涵盖的界面技能的广度（从点击和打字到选择和导航）使其成为对网络代理行为的广泛探索，而不是狭隘的探索。 WebArena 等基准测试Our choice of a single benchmark is deliberate and follows from the interpretability goal. A mechanistic account requires holding everything except the intervention fixed, so that a change in effective rank or success rate can be attributed to the learning rate and not to uncontrolled variation in the environment. MiniWoB provides that control. Its tasks are deterministic under a seed, its success check is exact, and the breadth of interface skills it covers, from clicking and typing to selection and navigation, makes it a broad probe of web-agent behavior, not a narrow one. A benchmark such as WebArena(Zhou et al., 2024)更接近部署，但引入了难以保持恒定的运行间变化，并且这种变化会混淆本研究所依赖的归因。我们将 MiniWoB 视为可以清楚地读取其机制的受控环境，并且我们很清楚其一般性成本。is closer to deployment but introduces run-to-run variation that is hard to hold constant, and that variation would confound the attributions this study rests on. We treat MiniWoB as the controlled setting in which the mechanism can be read cleanly, and we are clear about what that costs in generality.

我们的贡献如下。Our contributions are the following.

  1. 1.

    受控空值：在 18 次运行和多次稳健性检查的网格中，GRPO 并没有可靠地为有能力的小语言和视觉语言模型网络代理添加技能，而更高的学习率则可靠地消除了它。A controlled null: across a grid of 18 runs and several robustness checks, GRPO does not credibly add skill to a competent small language and vision-language model web agent, and higher learning rates credibly remove it.

  2. 2.

    将零值的原因识别为余量条件的正控制，以及可预先应用的针对贪婪成功的廉价采样测试。A positive control that identifies the cause of the null as a headroom condition, together with a cheap test of sampled against greedy success that can be applied beforehand.

  3. 3.

    将失败的机制解释为学习率门控双解离，通过权重移植进行因果定位，其中主要的嵌入漂移被证明是相关的红鲱鱼。A mechanistic account of the failure as a learning-rate-gated double dissociation, causally localized by weight grafting, with the dominant embedding drift shown to be a correlational red herring.

  4. 4.

    有证据表明，后层有效等级在 4B 处跟踪两个方向的能力，并在 8B 处解离，报告为取决于规模的属性。Evidence that late-layer effective rank tracks capability in both directions at 4B and dissociates at 8B, reported as a property that depends on scale.

  5. 5.

    发布了完整的配对统计数据、等价性检验和可解释性测量，以便其他人可以自己检查零值。A full battery of paired statistics, equivalence tests, and interpretability measurements, released so others can check the null for themselves.

2 相关工作Related Work

具有可验证奖励的强化学习推动了推理模型和 GRPO 的最新进展Reinforcement learning with verifiable rewards has driven recent gains in reasoning models, and GRPO(Shao et al., 2024)，进行了诸如解耦限幅等改进, with refinements such as decoupled clipping(Yu et al., 2026)和较少偏差的优势估计and less biased advantage estimation(Liu et al., 2025)基于最近的策略优化目标on top of the proximal policy optimization objective(Schulman et al., 2017)，现在是标准配方。这些收益是否反映了真正的新能力，还是基础模型已经能够产生的行为的锐化，存在争议，有证据表明，强化学习通常无法将模型扩展到采样已经达到的范围之外, is now a standard recipe. Whether these gains reflect genuinely new capability or a sharpening of behavior the base model can already produce is contested, with evidence that reinforcement learning often fails to extend a model beyond what sampling already reaches(Chen et al., 2026)。这个问题主要是在 pass@k 的推理基准上争论的。我们将其交给交互式代理，并像从业者一样根据代理自己的监督基线进行询问。. That question has been argued mostly on reasoning benchmarks through pass@k. We bring it to an interactive agent and ask it as a practitioner would, against the agent’s own supervised baseline.

对于网络代理来说，监督学习和强化学习管道都提高了 MiniWoB 环境中交互式基准的成功率For web agents, both supervised and reinforcement learning pipelines have raised success rates across interactive benchmarks, from the MiniWoB environment(Shi et al., 2017; Liu et al., 2018)到更大的网络竞技场to the larger WebArena(Zhou et al., 2024)，在线课程方法报告了进一步的成果, and online curriculum methods report further gains(Qi et al., 2025)。这一系列工作表明强化学习可以帮助网络代理。它并没有解决它是否有助于小型语言和视觉语言模型代理完成代理已经学会解决的任务，这是一个有能力的部署系统通常占据的制度，也是我们在这里隔离的制度。. This line of work shows that reinforcement learning can help a web agent. It does not settle whether it helps a small language and vision-language model agent on tasks the agent has already learned to solve, which is the regime a competent deployed system usually occupies and the one we isolate here.

我们的机制分析建立在读取模型内部状态的工具之上。有效排名Our mechanistic analysis builds on tools for reading a model’s internal state. Effective rank(Roy and Vetterli, 2007)测量表示实际使用的方向数，并且在权重空间中进行编辑表明可以通过重新组合参数组来移动行为measures how many directions a representation actually uses, and editing in weight space shows that behavior can be moved by recombining parameter groups(Ilharco et al., 2022)。我们将这些变成因果测试而不是相关测试：我们从初始化中恢复单个组件组，保留其余组件，并重新测量成功，这将失败的参数与仅移动最多的参数分开。. We turn these into a causal test rather than a correlational one: we restore a single component group from its initialization, keep the rest, and re-measure success, which separates the parameters that carry a failure from those that merely move the most.

两个差距激发了本文的写作。对于智能体来说，锐化问题还没有通过与其自身的监督开始（具有匹配的正控制）进行受控比较来解决，并且在报告强化学习无效的情况下，很少在权重水平上进行解释。我们解决这两个问题。我们为小型语言和视觉语言模型网络代理建立了受控零值，使用正控制来表明零值是任务的属性而不是训练管道的属性，并在各个权重组的级别上给出了失败的因果解释。据我们所知，这是第一项将网络代理的受控强化学习零值与其发生机制配对的研究。Two gaps motivate this paper. The sharpening question has not been settled for an agent by a controlled comparison against its own supervised start with a matched positive control, and where a reinforcement learning null is reported it is seldom explained at the level of the weights. We address both. We establish a controlled null for a small language and vision-language model web agent, use a positive control to show the null is a property of the task rather than the training pipeline, and give a causal account of the failure at the level of individual weight groups. To our knowledge this is the first study to pair a controlled reinforcement learning null for a web agent with a mechanism for why it occurs.

On a small web agent that already performs its tasks, the next increment of skill does not come from a second stage of reinforcement learning, because the agent’s greedy policy already sits above what its own sampling reaches and GRPO can pursue only the sampled policy. The link between late-layer rank and capability that grafting and the positive control establish at 4B does not hold at 8B, where a rank collapse and a change in behavior never coincide, so the rank account is a property of the smaller model and not a law across scale.

这一发现引发了激烈的争论，到目前为止，争论主要集中在 pass@k 的推理任务上The finding brings the sharpening debate, so far settled largely on reasoning tasks by pass@k(Chen et al., 2026)，到具有受控答案的交互式代理。当争论询问强化学习是否将模型扩展到其基础之外时，我们对代理在其自身的监督启动下进行同样的询问，发现它没有，然后用正向控制表明边界不是方法而是任务的余量。有争议的一般主张成为我们可以测试的具体主张：强化学习仅在其采样策略已经击败其贪婪策略时才扩展代理。, to an interactive agent with a controlled answer. Where that debate asks whether reinforcement learning extends a model beyond its base, we ask the same of an agent against its own supervised start and find that it does not, then show with the positive control that the boundary is not the method but the headroom of the task. The contested general claim becomes a specific one we can test: reinforcement learning extends the agent only when its sampled policy already beats its greedy policy.

8 结论Conclusion

我们询问 GRPO 是否可以为小型语言和视觉语言网络代理增加其已经学会的任务的技能。在整个网格和鲁棒性检查中，它不会，并且超过一个狭窄的学习率范围，它会减少技能。一旦任务有空间，相同的管道就会爬升 22 个点，因此 null 与任务有关，而不是与方法有关。这种失败有一个明确的机制：中等速率会擦除嫁接到注意力和 MLP 的后层等级，高速率会擦除没有单个组修复的读出，并且主要的嵌入漂移是惰性的。对于一个有能力的小代理来说，更多的技能来自于更好的监督，而 GRPO 只有在采样击败贪婪的情况下才能获得计算能力。We asked whether GRPO adds skill to a small language and vision-language web agent on tasks it has already learned. Across the grid and the robustness checks it does not, and past a narrow band of learning rates it subtracts skill instead. The same pipeline climbs 22 points once the task has headroom, so the null is about the task, not the method. The failure has a clear mechanism: a middle rate erases the late-layer rank that grafting traces to attention and MLP, a high rate erases the readout that no single group repairs, and the dominant embedding drift is inert. For a competent small agent, more skill comes from better supervision, and GRPO earns its compute only where sampling beats greedy.

局限性Limitations

这项研究故意缩小范围，应牢记几个界限。它使用单一基准 MiniWoB 和单一模型系列 Qwen3-VL（4B 和 8B）； null 和机制在更多样化的环境（例如 WebArena）或不同的主干上可能看起来不同。大学习率带来的可信危害是在 4B 文本轨道上建立的，而在标记集轨道上它只是名义上的，因此结果的危害面是文本轨道证据，而不是普遍的主张。该机制有自己的规模边界：后期层等级和能力之间的联系在 4B 处保持，但在 8B 处断裂，因此等级帐户特定于较小的模型。因果嫁接和排名健康读数依赖于每个政权的少量检查点，并且它们的点估计是嘈杂的，因此我们定性地报告它们。最后，零值涉及代理已经掌握其任务的状态，而正控制表明，一旦任务有空间，相同的配方就会爬升；因此，我们并不认为强化学习对于一般的网络代理来说是无用的，只是说它不会增加我们隔离的有能力的代理制度中的技能。This study is deliberately narrow, and several boundaries should be kept in mind. It uses a single benchmark, MiniWoB, and a single model family, Qwen3-VL at 4B and 8B; the null and the mechanism may look different on a more varied environment such as WebArena or on a different backbone. The credible harm from a large learning rate is established on the 4B text track, and on the Set-of-Marks track it is only nominal, so the harm side of the result is text-track evidence and not a universal claim. The mechanism has a scale boundary of its own: the link between late-layer rank and capability holds at 4B but breaks at 8B, so the rank account is specific to the smaller model. The causal grafting and rank-health readings rest on a small number of checkpoints per regime and their point estimates are noisy, so we report them qualitatively. Finally, the null concerns the regime where the agent has already mastered its tasks, and the positive control shows that the same recipe does climb once the task has headroom; we therefore make no claim that reinforcement learning is useless for web agents in general, only that it adds no skill in the competent-agent regime we isolate.

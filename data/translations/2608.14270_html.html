摘要Abstract

Existing time series QA benchmarks mostly rely on fixed snapshots, leaving temporal validity and cutoff-aware evidence use unevaluated. 1 简介Introduction

在从金融、公共卫生到交通运输的高风险领域，时间序列分析不是静态预测任务，而是重复的工作流程。分析师必须不断吸收新发布的数据，更新历史背景，并将数字趋势与机构报告综合起来。至关重要的是，每个新版本都会改​​变可用证据的分布，需要严格遵守时间戳感知信息截止。我们将这种循环工作流程形式化为不断变化的环境中的代理时间序列分析，要求大型语言模型（LLM）在对动态多模态证据进行推理的同时保持时间有效性。Across high-stakes domains, from finance and public health to transportation, time series analysis is not a static prediction task but a recurring workflow. Analysts must continuously ingest new data releases, update historical context, and synthesize numeric trends with institutional reports. Crucially, each new release shifts the available evidence distribution, requiring strict adherence to timestamp-aware information cutoffs. We formalize this recurring workflow as agentic time series analysis in evolving environments, requiring Large Language Models (LLMs) to maintain temporal validity while reasoning over dynamic multimodal evidence.

现有的基准仅部分覆盖此设置，有两个关键限制。Existing benchmarks only partially cover this setting, with two key limitations.(1)时间序列问答 (QA) 基准，例如 ChatTime-TSQATime series question answering (QA) benchmarks, such as ChatTime-TSQA20, 时间-MQA, Time-MQA12和 TSRBench, and TSRBench28，测试时间序列上的时间推理，但通常在预定义的时间序列任务上构建固定的 QA 对，而不是不断发展的工作流程。, test temporal reasoning over time series, but usually construct fixed QA pairs over predefined time series tasks rather than evolving workflows.(2)以代理为中心的基准评估编码Agent-centric benchmarks evaluate coding8, 网页导航, web navigation29; 14, 多跳检索, multi-hop retrieval21，以及工具的使用, and tool use26，但不是围绕重复时间序列分析而设计的。他们很少要求代理人跟踪时间索引的证据，将新的观察结果与历史背景进行比较，并将时间序列与机构报告综合起来。因此，由于证据随着时间的推移而变化，法学硕士代理人是否能够执行此类分析工作仍不清楚。, but are not designed around recurring time series analysis. They rarely require agents to track time-indexed evidence, compare new observations with historical context, and synthesize time series with institutional reports. Thus, it remains unclear whether LLM agents can perform such analytical work as the evidence changes over time.

为这种动态环境构建基准面临三个挑战。Constructing a benchmark for this dynamic setting presents three challenges.(1)每个场景都必须来自稳定的机构来源，并具有定期发布计划，确保评估反映实时监控而不是合成快照。Each scenario must be drawn from a stable institutional source with a recurring release schedule, ensuring the evaluation reflects real-time monitoring rather than synthetic snapshots.(2)每个目标时期都必须实行严格的信息截止。特工只能访问目标发布之前发布的累积数据和源文档，而目标发布本身则被保留用于地面真相构建和证据验证。Each target period must impose a strict information cutoff. Agents can only access cumulative data and source documents published prior to the target release, while the target release itself is withheld for ground truth construction and evidence verification.(3)评估不能仅限于封闭式选择。为了与实际应用保持一致，它必须评估关键分析任务和人类可读的报告。这些要求激发了基准设计，包括时间戳感知的地面事实、可追踪的证据、截止有效输入以及明确区分事实正确性和报告忠实度的指标。Evaluation cannot be restricted to closed-form choices. To align with practical applications, it must assess both key analytical tasks and human-readable reports. These requirements motivate a benchmark design with timestamp-aware ground truth, traceable evidence, cutoff-valid inputs, and metrics that explicitly separate factual correctness from report faithfulness.

A.1 任务理由Task Rationale

为什么循环时间序列分析不同。Why recurring time series analysis is different.

TimeSage-EV 的目标是标准时间序列预测、静态时间序列 QA 或通用代理基准未捕获的设置。在经常性的机构分析中，任务规范保持不变，但分析师可用的证据在每次发布后都会发生变化。代理必须解释最新的观察结果，将其与历史背景进行比较，仅使用截止有效的文档，并随着环境的变化修改其报告。TimeSage-EV targets a setting that is not captured by standard time series forecasting, static time series QA, or generic agent benchmarks. In recurring institutional analysis, the task specification remains fixed, but the evidence available to the analyst changes after each release. The agent must interpret the latest observation, compare it with historical context, use only cutoff-valid documents, and revise its report as the environment evolves.

为什么时间隔离很重要。Why temporal isolation matters.

TimeSage-EV 的一个核心动机是评估智能体是否可以在目标时期应用的信息限制内进行推理。如果没有此限制，代理可以使用未来的报告、事后解释或目标发布后发布的文档来回答。 TimeSage-EV 通过公开累积时间序列数据和前期源文档，同时保留目标期间的发布以进行地面实况构建和证据验证来防止这种情况发生。A central motivation of TimeSage-EV is to evaluate whether agents can reason within the information limit that would have been applied at a target period. Without this constraint, an agent may answer using future reports, post-hoc explanations, or documents published after the target release. TimeSage-EV prevents this by exposing cumulative time series data and prior-period source documents while withholding the target-period release for ground truth construction and evidence verification.

为什么代理评估很重要。Why agentic evaluation matters.

真正的分析工作流程需要的不仅仅是读取固定的表格。代理必须检查数据文件、使用工具、查阅文档、跨时期保存状态，并生成结构化答案和自然语言报告。 TimeSage-EV 将代理时间序列分析作为集成工作流程进行评估，暴露诸如无支持的因果关系、证据使用不当和报告不完整等失败。Real analytical workflows require more than reading a fixed table. Agents must inspect data files, use tools, consult documents, preserve state across periods, and produce both structured answers and natural-language reports. TimeSage-EV evaluates agentic time series analysis as an integrated workflow, exposing failures such as unsupported causal claims, poor use of evidence, and incomplete reporting.

2. 概述Overview

2.1. 越狱Jailbreak

越狱是一种综合高性能表读取器以绕过数据库系统的代理方法。越狱利用以下两个见解。首先，法学硕士可以从源代码和文档中获取数据库系统的存储层详细信息。对于大多数流行的开源数据库系统，这些信息已经包含在现有的预训练的 LLM 中。其次，LLM可以利用这些知识来自动合成高性能代码，完全绕过数据库系统，直接读取数据库系统存储文件。这种方法提供了多种性能优势。首先，它消除了有线协议序列化/反序列化开销，因为外部应用程序或查询引擎可以直接读取存储文件。其次，它使目标数据库系统保持完整，因为通常通过 JDBC/ODBC 发生并给数据库系统增加额外负载的查询执行被完全消除。第三，它为更高的应用层提供了更多的控制权。Jailbreak is an agentic approach for synthesizing high-performance table readers for database system bypass. Jailbreak exploits the two following insights. First, the storage layer details of a database system can be ingested by an LLM both from the source code and documentation. For most of the popular open-source database systems, this information is already included in the already existing pretrained LLMs. Second, the LLM can utilize this knowledge in order to automatically synthesize high-performance code that can read the database system storage files directly, by completely bypassing the database system. This approach offers several performance benefits. First, it eliminates the wire protocol serialization/deserialization overheads, since the external application or query engine can read the storage files directly. Second, it leaves the target database system intact, since query execution that normally happens through JDBC/ODBC and adds extra load to the database system is completely eliminated. Third, it gives more control to the higher application layer on如何how读取和处理数据（例如分区方案），因为合成读取器在字节级别工作。to read and handle the data (e.g. partitioning schemes), since the synthesized reader works at the byte-level.

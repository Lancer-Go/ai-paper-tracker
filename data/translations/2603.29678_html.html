1 简介Introduction

情境学习研究非常关注上层架构选择：生成器、反射器和策展人之间的角色分解Context learning research has devoted considerable attention to upper-level architectural choices: role decomposition among generators, reflectors, and curators[58];分层记忆组织和检索; hierarchical memory organization and retrieval[29, 31];工具使用; tool use[32];以及从代理轨迹中提取和概括经验; and experience extraction and generalization from agent trajectories[8, 39, 35]。消息本身的格式（代理跟踪如何表示并呈现给 LLM 进行分析）在很大程度上被视为琐碎的工程细节，以纯文本、JSON、YAML 和 grep 作为默认约定。. The format of the messages themselves—how an agent trace is represented and presented to an LLM for analysis—has largely been treated as a trivial engineering detail, with plain text, JSON, YAML, and grep serving as default conventions.

讨论。Discussion.

更高的通过率、更低的令牌消耗和更小的内存文件并不是独立的结果。一个似乎合理的共同原因是，结构化视图让反思者专注于与决策相关的内容，而不是浏览原始数据。这会产生更精确（更高的通过率）和更简洁（更小的内存）的规则，而导航结构本身减少了反射器必须处理的文本量（更少的标记）。这三个指标可能测量相同的潜在变量——反映者的注意力集中在正确信息上的程度。Higher pass rates, lower token consumption, and smaller memory files are not independent outcomes. A plausible shared cause is that structured views let the reflector focus on decision-relevant content rather than navigating raw data. This produces rules that are both more precise (higher pass rates) and more concise (smaller memory), while the navigation structure itself reduces the volume of text the reflector must process (fewer tokens). The three metrics may be measuring the same underlying variable—the degree to which the reflector’s attention is directed at the right information.

5 结论Conclusion

VCC 将原始代理 JSONL 日志编译为语义注释、行号一致、指针可导航的结构化视图。仅替换反射器的输入格式（从原始 JSONL 到 VCC 编译的视图）可以在 AppWorld 上的三个模型配置中产生更高的通过率、更低的令牌消耗和更简洁的学习记忆，并且三个指标同时改进而不是权衡。实验对学习算法、模型或任务集没有任何改变；唯一的区别在于轨迹的呈现方式。这种单一替换使所有三个指标朝同一方向移动，这表明消息格式不是偶然的实现选择，而是上下文学习基础设施的承载组件。目前评测仅限AppWorld；扩展到其他代理基准——SWE-benchVCC compiles raw agent JSONL logs into semantically annotated, line-number-consistent, pointer-navigable structured views. Replacing only the reflector’s input format—from raw JSONL to VCC-compiled views—yields higher pass rates, lower token consumption, and more concise learned memory across three model configurations on AppWorld, with the three metrics improving simultaneously rather than trading off. The experiment changes nothing about the learning algorithm, the model, or the task set; the only difference is how the trace is presented. That this single substitution moves all three metrics in the same direction suggests that message format is not an incidental implementation choice but a load-bearing component of context learning infrastructure. The current evaluation is limited to AppWorld; extending to other agent benchmarks—SWE-bench[17], TAU 工作台, TAU-bench[53], 网络竞技场, WebArena[61], AgentBench [25]——其他轨迹学习方法仍然是一个开放的方向。—and to additional trajectory-learning methods remains an open direction.

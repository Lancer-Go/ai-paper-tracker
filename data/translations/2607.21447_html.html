摘要Abstract

法学硕士处理长期记忆的能力变得越来越重要，但现有的基准仍然以英语为中心，依赖于聚合检索指标，无法捕获长期上下文、时间信息和推理之间的相互作用。为了解决这个问题，我们引入The ability to handle long-term memory in LLMs is becoming increasingly critical, yet existing benchmarks remain English-centric and rely on aggregate retrieval metrics, fail- ing to capture interactions between long range context, temporal information, and reasoning. To address this, we introduce伦巴RUMBA（俄罗斯用户记忆基准测试）——长期会话记忆的新基准，提供以记忆为中心的问题类型的细粒度分类，以及考虑语义类型、会话范围、时间推理和时间表达的明确性的统一方法。 RUMBA 由带有时间戳的用户助理对话和需要跨会话检索、组合和推理的 QA 对组成。在专为俄语设计的同时，我们还根据相同的方法提供了一致的英语子集。我们评估当代记忆系统和长上下文模型，并展示 RUMBA 如何作为诊断工具来分析跨基准切片的模型行为，并识别不同记忆机制的优势和故障模式。(Russian User Memory BenchmArk) — a new benchmark for long-term conversational mem- ory that provides a fine grained taxonomy of memory-centric question types and a unified methodology accounting for semantic type, session scope, temporal reasoning, and the explicitness of temporal expressions. RUMBA consists of timestamped user–assistant dialogues with QA pairs requiring retrieval, combination, and reasoning across sessions. While designed for Russian, we also provide an aligned English subset under the same methodology. We evaluate contemporary memory systems and - long context models, and show how RUMBA serves as a diagnostic tool to analyze model behavior across benchmark slices and identify strengths and failure modes of different memory mechanisms.

2 相关工作2 Related work

最近评估语言模型记忆能力的工作受到 LoCoMo（Maharana 等人，2024）、LongMemEval（Wu 等人，2025）、Mem-Gallery（Bei 等人，2026）等基准的影响。这些数据集为研究会话系统中的长期记忆提供了一个结构化的起点。特别是，LoCoMo 围绕面向推理的问题族（例如，单跳、多跳、时间、常识、对抗性）组织评估，而 LongMemEval 定义了一组核心记忆能力（例如，回忆、个性化、多会话推理、更新、时间推理、弃权），并通过特定的问题类型来操作它们。这些基准共同为内存评估，特别是 RUMBA 分类法建立了有用的概念和方法基线。Recent work on evaluating memory capabilities in language models has been shaped by benchmarks such as LoCoMo (Maharana et al., 2024), LongMemEval (Wu et al., 2025), Mem-Gallery (Bei et al., 2026). Instead of assigning each question to a single class, RUMBA decomposes tasks along several orthogonal axes, including:

  • 所需的语义操作（例如，召回、更新跟踪、比较），the semantic operation required (e.g., recall, update tracking, comparison),

  • 时间维度（时间维度与非时间维度），the temporal dimension (temporal vs. atemporal),

  • 涉及的会话数量，the number of sessions involved,

  • 推理复杂性，the reasoning complexity,

这种基于轴的设计可以更精确地表征模型行为。例如，可以在时间和非时间设置中评估相同的基础操作（例如，召回），从而揭示不同的故障模式。同样，推理不被视为一个单独的类别，而是被视为可以与不同类型的内存访问相结合的属性，从而允许对模型功能进行更细粒度的分析。This axis-based design enables a more precise characterization of model behavior. For example, the same underlying operation (e.g., recall) can be evaluated in both temporal and atemporal settings, revealing different failure modes. Similarly, reasoning is treated not as a separate category, but as a property that can be combined with different types of memory access, allowing finer-grained analysis of model capabilities.

RUMBA 的一个关键优势是它的治疗A key strength of RUMBA is its treatment of暂时性temporality作为一个独立的维度。与之前的基准测试不同的是，时间推理被隔离为特定的任务类型，RUMBA 允许时间性与所有其他轴交互。这使得系统地研究模型如何在同一语义框架内处理时间相关和时间无关的内存查询成为可能。as an independent dimension. Unlike prior benchmarks, where temporal reasoning is isolated as a specific task type, RUMBA allows temporality to interact with all other axes. This makes it possible to systematically study how models handle time-dependent versus time-independent memory queries within the same semantic framework.

另一个重要贡献是记忆控制和有效性的显式建模。除了回忆和更新跟踪等标准能力之外，RUMBA 还引入了对有意遗忘的评估，其中模型必须在明确的用户指令后正确排除先前存储的信息。遗忘场景是通过用户行为和专用问题类型DeleteInfo 支持的。用户可以通过“删除这个”或“忘记它”等请求来触发它。正确的响应是“没有这样的信息”（或类似的），表明该信息已成功忘记，不再被系统保留。Another important contribution is the explicit modeling of memory control and validity. In addition to standard abilities such as recall and update tracking, RUMBA introduces evaluation of intentional forgetting, where models must correctly exclude previously stored information after explicit user instructions. The forgetting scenario is supported through user behavior and a dedicated question type, DeleteInfo. 我们评估了两个基线系列，它们对应于在基于 LLM 的助理中使用长交互历史的两种常见方式：全上下文推理和基于记忆的检索增强推理。We evaluate two families of baselines that correspond to two common ways of using long interaction histories in LLM-based assistants: full-context inference and memory-based retrieval-augmented inference.

局限性Limitations

数据。Data.数据集大小虽然足以进行初始基准测试，但不足以给超长上下文模型带来实质性困难。扩大对话的数量和长度将进一步对长上下文能力进行压力测试。此外，面向提取的问题占主导地位，而复杂推理和时间纠缠查询的代表性不足。这种不平衡反映了实际的考虑并确保了坚实的基础，但它限制了对高阶记忆能力的评估。最后，英文版本是通过自动翻译而不是手动重写获得的，没有进行明确的本地化。这可能会使英语分裂在文化上不太自然，并引入可能影响模型理解和基于嵌入的检索的翻译伪影。The dataset size, while adequate for initial benchmarking, is not large enough to introduce substantial difficulties for very long-context models. Scaling up both the number of dialogues and their length would further stress-test long-context capabilities. In addition, extraction-oriented questions dominate, whereas complex reasoning and temporally entangled queries are underrepresented. This imbalance reflects practical considerations and ensures a solid foundation, but it limits evaluation of higher-order memory abilities. Finally, the English version is obtained through automatic translation rather than manual rewriting, with no explicit localization applied. This may make the English split less culturally natural and introduce translation artifacts that can affect model understanding and embedding-based retrieval.

评价。Evaluation.我们的俄语和英语评估使用不同的法学硕士法官。因此，观察到的部分跨语言差异可能源于法官特定的校准，而不仅仅是模型的表现（Thakur et al., 2025；Fu and Liu, 2025）。 RUMBA 还遵循标准的 QA 管道，该管道可以对输出正确性进行透明且可重复的评估，但不会直接探测模型的内部存储器表示。尽管如此，该基准测试的目标是构建记忆能力：与开放域 QA 不同，RUMBA 侧重于随时间变化的用户特定信息，包括重复更新、更正和个人事实的变化。Our Russian and English evaluations use different LLM judges. Consequently, part of the observed cross-lingual difference may stem from judge-specific calibration rather than model performance alone (Thakur et al., 2025; Fu and Liu, 2025). RUMBA also follows a standard QA pipeline, which enables transparent and reproducible evaluation of output correctness but does not directly probe the model’s internal memory representations. Nevertheless, the benchmark targets memory capabilities by construction: unlike opendomain QA, RUMBA centers on user-specific information that evolves over time, including repeated updates, corrections, and changes in personal facts.

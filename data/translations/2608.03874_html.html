摘要Abstract

现代代理框架为大型语言模型配备了外部技能库来解决复杂的任务。然而，目前尚不清楚这些系统是否可以有效地发展其技能以及由此产生的技能是否可以提高任务解决能力。为了弥补这一差距，我们引入Modern agent frameworks equip large language models with external skill libraries to solve complex tasks. However, it remains unclear whether these systems can effectively evolve their skills and whether the resulting skills improve task-solving capabilities. To bridge this gap, we introduce持续技能台ContinualSkillBench，一个用于上下文持续技能学习的动态评估框架。它涵盖五个代表性领域，每个领域包含 100 个相互关联的子任务，这些子任务按照难度的增加和跨任务技能重用的机会进行排序。我们的实验表明，顺序执行通常可以提高性能，但不同模型和领域的收益差异很大。此外，平均而言，上下文学习的表现与显式技能维护相当，这表明大部分改进来自于对先前上下文和反馈的适应，而不仅仅是可重用的技能抽象。然而，显性技能为需要可重用程序或精确输出的任务提供了选择性的好处。我们进一步发现，能力较差的模型往往会积累更大、更分散的特定任务技能集合。这些发现表明，当前的情境技能进化机制可以支持持续适应，但仍难以持续地将经验巩固为强大且可转移的技能。, a dynamic evaluation framework for in-context continual skill learning. It covers five representative domains, each containing 100 interconnected subtasks ordered by increasing difficulty and opportunities for cross-task skill reuse. Our experiments show that sequential execution generally improves performance, but the gains vary substantially across models and domains. Moreover, in-context learning performs comparably to explicit skill maintenance on average, suggesting that much of the improvement arises from adaptation to prior context and feedback rather than reusable skill abstraction alone. Explicit skills nevertheless provide selective benefits for tasks requiring reusable procedures or precise outputs. We further find that less capable models tend to accumulate larger, more fragmented collections of task-specific skills. These findings show that current in-context skill evolution mechanisms can support continual adaptation, but still struggle to consistently consolidate experience into robust and transferable skills.

1 简介Introduction

大型语言模型 (LLM) 正在迅速从简单的问答系统发展成为能够解决复杂的现实世界问题的代理的骨干。由于现实世界的任务具有丰富的要求，并且可能会偏离预训练的动态，因此仅依靠预训练的权重通常是不够的。为了弥补特定领域知识或处理逻辑的缺乏，从根本上增强其在部署过程中解决任务的性能，“代理技能”Large language models (LLMs) are rapidly evolving from simple question-answering systems into backbones of agents capable of solving complex, real-world problems. Since real-world tasks are rich in requirements and may shift from pretrained dynamics, relying solely on their pre-trained weights is often insufficient. To compensate for the lack of domain-specific knowledge or processing logic, and fundamentally enhance their task-solving performance during deployment, “agent skills”(Schick et al., 2023; Shen et al., 2023)已被介绍。这些技能通常被组织成结构化文档，并已被 Claude Code 等主流代理平台广泛采用have been introduced. These skills are typically organized into structured documents and have already been widely adopted by mainstream agent platforms such as Claude Code(Anthropic, 2025)和法典and Codex(OpenAI, 2025).

最近的工作表明，鉴于人类专家精心编写的技能，智能体在相应任务上的表现明显更好Recent work has shown that given well-written skills from human experts, agents perform significantly better on corresponding tasks(Li et al., 2026)。然而，手动为座席建立全面的技能库从根本上来说是困难且昂贵的。在更现实的设置中，用户仅通过任务序列提供任务描述和反馈，一个关键问题是代理是否可以从这些交互中自主综合和发展自己的技能。尽管有些作品探索了这个方向. However, it is fundamentally difficult and expensive to manually build a comprehensive skill library for agents. In more realistic settings, where users only provide task descriptions and feedback through a task sequence, a critical question is whether agents can autonomously synthesize and evolve their own skills from these interactions. Although some works explore this direction(Asawa et al., 2026; Zhong et al., 2026)，我们仍然缺乏对他们的能力极限的系统评估。, we still lack a systematic evaluation of their capability limits.

座席的情境技能演变In-Context Skill Evolution for Agents。 为了执行复杂的、特定领域的任务，LLM代理越来越依赖外部工具或结构化的工具. To execute complex, domain-specific tasks, LLM agents increasingly rely on external tools or structured技能skills (Schick et al., 2023; Shen et al., 2023; Xu and Yan, 2026)。然而，当前大多数方法都假设静态技能库，严重限制了动态环境中的适应性。此外，通过标准参数更新（例如微调）使模型适应新的顺序任务通常会导致灾难性遗忘. However, most current approaches assume a static skill library, severely limiting adaptability in dynamic environments. Furthermore, adapting models to new sequential tasks via standard parametric updates (e.g., fine-tuning) typically leads to catastrophic forgetting(Kirkpatrick et al., 2017)。为了缓解这一问题，最近的研究探索了. To mitigate this, recent research has explored上下文中in-context持续学习continual learning(Wu et al., 2024; Raparthy et al., 2023)。通过利用扩展的上下文窗口，智能体可以实现终身学习——在连续任务中动态更新和检索不断增长的技能库——而无需微调其参数。. By leveraging extended context windows, agents can achieve lifelong learning—dynamically updating and retrieving a growing library of skills over sequential tasks—without fine-tuning their parameters.

This setting allows us to examine whether experience acquired from one task can be consolidated into structured skills and reused on different downstream tasks, as well as how this ability varies across domains and models.

5 结论Conclusion

我们介绍了We introduced持续技能台ContinualSkillBench评估五个领域中长任务序列的持续技能学习。顺序执行通常会提高性能，但收益因模型和领域而异。情境学习的平均表现与显性技能维持相当，这表明大部分改进来自于对先前情境和反馈的适应。显性技能仍然为需要可重复使用的程序或精确输出的任务提供选择性的好处。此外，较弱的模型往往会建立更大、更分散的技能存储库。总体而言，当前的座席可以从持续的互动中受益，但不断将经验整合为强大且可转移的技能仍然是一个开放的挑战。to evaluate continual skill learning across long task sequences in five domains. Sequential execution generally improves performance, but the gains vary across models and domains. In-context learning performs comparably to explicit skill maintenance on average, suggesting that much of the improvement comes from adaptation to prior context and feedback. Explicit skills still provide selective benefits for tasks requiring reusable procedures or precise outputs. Moreover, weaker model tends to build larger and more fragmented skill repositories. Overall, current agents can benefit from continual interaction, but consistently consolidating experience into robust and transferable skills remains an open challenge.

局限性Limitations

我们的研究有几个局限性。首先，虽然Our study has several limitations. First, while持续技能台ContinualSkillBench涵盖五个核心领域，每个领域内的任务仍然是从一组固定的来源中策划的。实际部署更加多样化且控制较少：代理可能会看到罕见的边缘情况、变化的数据分布以及与基准格式有很大不同的指令。我们当前的评估并未完全涵盖这些长尾设置。covers five core domains, the tasks within each domain are still curated from a fixed set of sources. Real deployments are more diverse and less controlled: agents may see rare edge cases, shifted data distributions, and instructions that differ substantially from the benchmark format. These long-tail settings are not fully covered by our current evaluation.

其次，由于顺序代理评估的时间和 API 成本很高，我们仅评估一组有限的代表性模型和工具。我们没有详尽地涵盖其他 Claude、GPT 或 Gemini 变体，也没有使基准测试适应其他代理环境，例如 Cursor 或 Google CLI。由于不同的模型和代理框架可能以不同的方式处理内存、技能检索和执行控制，因此未来的工作应该扩大模型和基础设施的覆盖范围。Second, due to the high time and API cost of sequential agent evaluation, we evaluate only a limited set of representative models and harnesses. We do not exhaustively cover additional Claude, GPT, or Gemini variants, nor do we adapt the benchmark to other agent environments such as Cursor or Google CLI. Since different models and agent frameworks may handle memory, skill retrieval, and execution control differently, future work should broaden both model and infrastructure coverage.

2 相关工作Related Work

2.1 多代理法学硕士系统Multi-Agent LLM Systems

多智能体框架的快速成熟The rapid maturation of multi-agent frameworks[7, 8, 9, 10]已将代理协作确立为核心人工智能范式。自动生成器has established agent collaboration as a core AI paradigm. AutoGen[7]引入结构化多代理对话；元GPTintroduced structured multi-agent conversations; MetaGPT[8]将软件工程工作流程应用于代理协调；聊天开发applied software engineering workflows to agent coordination; ChatDev[11]通过代理角色演示了端到端软件开发。至关重要的是，所有这些系统都依赖于代理评估彼此的输出，但没有一个系统分析这种同行评估机制是否会引入系统性偏差放大。虽然这些框架侧重于demonstrated end-to-end software development via agent roles. Critically, all these systems rely on agents evaluating each other’s outputs—yet none analyze whether this peer evaluation mechanism introduces systematic bias amplification. While these frameworks focus on效率efficiency（任务完成情况、沟通开销），我们研究(task completion, communication overhead), we study保真度fidelity：评估信号在通过代理网络传播时是否仍然忠实于任务质量？: does the evaluation signal remain faithful to task quality as it propagates through the agent network?

The broader LLM-as-judge literature documents systematic biases including position bias[2], 冗长偏差, verbosity bias[3]，以及自我偏好放大, and self-preference amplification[4]。奖励过度优化. Reward overoptimization[5]和阿谀奉承and sycophancy[6]展示代理如何利用评估者的弱点。然而，所有先前的工作研究demonstrate how agents exploit evaluator weaknesses. 2.3 人工智能系统中的流行病学模型Epidemiological Models in AI Systems

信息传播与疾病传播之间的类比在网络科学中有着悠久的历史The analogy between information propagation and disease spread has a rich history in network science[13]。 SIS（易感-感染-易感）和SIR（易感-感染-恢复）模型描述了复杂网络上的阈值动态。我们利用这一传统，将评估者偏差建模为通过代理交互图传播的“感染”，并使用传染矩阵. SIS (Susceptible-Infected-Susceptible) and SIR (Susceptible-Infected-Recovered) models characterize threshold dynamics on complex networks. We draw on this tradition to model evaluator bias as an “infection” that propagates through agent interaction graphs, with the contagion matrixΓN\Gamma_{N}充当流行病学中下一代矩阵的模拟。这个框架使我们能够得出可通过经验测试的精确级联条件和多样性阈值。serving as the analog of the next-generation matrix in epidemiology. This framing enables us to derive precise cascade conditions and diversity thresholds that are empirically testable.

摘要Abstract

通过合成训练数据控制语言模型有哪些限制？我们开发了一种强化学习（RL）原语，即数据集策略梯度（DPG），它可以精确优化合成数据生成器以生成目标示例的数据集。当用于目标模型的监督微调（SFT）时，这些示例使目标模型在我们选择的可微指标上表现良好。我们的方法通过高阶梯度获取精确的数据归因并将这些分数用作策略梯度奖励来实现这一目标。我们证明这个过程非常接近合成数据生成器的真实的、难以处理的梯度。 为了说明 DPG 的潜力，我们表明，仅在生成的示例上使用 SFT，我们可以使目标模型的 LM 头权重变为 (1) 嵌入二维码，(2) 嵌入图案What are the limits of controlling language models via synthetic training data? We develop a reinforcement learning (RL) primitive, the Dataset Policy Gradient (DPG), which can precisely optimize synthetic data generators to produce a dataset of targeted examples. When used for supervised fine-tuning (SFT) of a target model, these examples cause the target model to do well on a differentiable metric of our choice. Our approach achieves this by taking exact data attribution via higher-order gradients and using those scores as policy gradient rewards. We prove that this procedure closely approximates the true, intractable gradient for the synthetic data generator. To illustrate the potential of DPG, we show that, using only SFT on generated examples, we can cause the target model’s LM head weights to (1) embed a QR code, (2) embed the pattern67，并且（3）具有较低的, and (3) have lowerℓ2\ell^{2}规范。我们还表明，我们可以使生成器（4）用新语言重新表述输入并（5）生成特定的 UUID，即使生成器的输入提示中没有传达这些目标。 这些发现表明，DPG 是一种强大而灵活的技术，仅使用合成训练示例即可塑造模型属性。norm. We additionally show that we can cause the generator to (4) rephrase inputs in a new language and (5) produce a specific UUID, even though neither of these objectives is conveyed in the generator’s input prompts. These findings suggest that DPG is a powerful and flexible technique for shaping model properties using only synthetic training examples.

1 简介Introduction

合成训练数据最近引起了人们的极大兴趣Synthetic training data has recently gained significant interest(Wang et al., 2023; Taori et al., 2023; Yang et al., 2025a; Ruan et al., 2025)但我们能够如何精细地控制合成数据的生成呢？事实证明，即使在简单的监督微调（SFT）的背景下，训练示例（真实的和合成的）也可以向语言模型传达意想不到的信息。最近的突出例子包括紧急失准but how finely can we control synthetic data generation? It is well-attested that training examples (real and synthetic) can communicate unexpected information to language models even in the context of simple supervised fine-tuning (SFT). Recent prominent examples include emergent misalignment(Betley et al., 2026; Chua et al., 2025), 潜意识学习, subliminal learning(Cloud et al., 2025; Betley et al., 2025)，无害输入造成的数据中毒, data poisoning from harmless inputs(Kong et al., 2025)，以及模型出处, and model provenance(Kuditipudi et al., 2025)。有没有一种方法可以轻松地训练合成数据生成器，生成针对我们选择的任何现象的训练数据？. Is there a way to tractably train a synthetic data generator that produces training data targeting any phenomena we choose?

直观地说，简单的强化学习技术可用于直接优化下游指标的合成数据生成器。每次我们的策略生成数据集时，我们都可以在其上训练模型并从模型中测量感兴趣的指标。然后我们可以使用这个指标作为整个数据集的单一奖励并执行策略梯度步骤。然而，这种方法在计算上是令人望而却步的，因为它只为完整运行的内部目标模型训练和评估提供单一奖励。Intuitively, straightforward reinforcement learning techniques could be used to optimize synthetic data generators directly for downstream metrics. Every time a dataset is generated by our policy, we could train a model on it and measure a metric of interest from the model. We could then use this metric as a single reward for the entire dataset and perform a policy gradient step. However, this approach is computationally prohibitive because it provides only a single reward for a full run of inner target model training and evaluation.

在这项工作中，我们提出了数据集策略梯度（DPG），这是一种有原则的强化学习方法，使我们能够为任何可微分的下游目标生成合成训练数据。使用我们的方法，奖励是在单个合成文本的级别，而不是数据集级别。这种方法为广泛的应用打开了大门，在这些应用中选择或合成训练示例的目的是为目标模型注入特定的属性。In this work, we present the Dataset Policy Gradient (DPG), a principled RL approach that enables us to generate synthetic training data for any differentiable downstream target. With our method, rewards are at the level of individual synthetic texts, instead of the dataset level. This method opens the door to a wide range of applications in which training examples are chosen or synthesized with the goal of imbuing a target model with a specific property.

用于语言模型训练的合成数据。Synthetic data for language model training.

合成数据越来越被视为提高语言模型性能的关键资源Synthetic data is increasingly viewed as a key resource for language model performance gains(Wang et al., 2023; Taori et al., 2023; Maini et al., 2024; Abdin et al., 2024; Ruan et al., 2025; Yang et al., 2025b)。我们的贡献是正交的：我们不是询问哪些合成数据启发式方法可以提高性能，而是研究如何通过元梯度精确优化合成数据，以在训练模型中引入有针对性的甚至非常规的可微属性。. Our contribution is orthogonal: instead of asking what synthetic data heuristics improve performance, we study how precisely synthetic data can be optimized – via metagradients – to induce targeted and even unconventional differentiable properties in trained models.

影响Implications

DPG 可以使从业者能够使用合成的 SFT 示例有意识地引导模型实现所需的功能。同时，这种控制程度也存在潜在风险。如果可以优化合成数据生成以在训练模型中引入任意可微属性，那么对手可能会针对特定偏差或行为发起微妙的数据中毒攻击。随着合成数据日益成为现代机器学习管道的核心组成部分，了解有针对性的合成数据生成的功能和风险将变得非常重要。DPG may enable practitioners to intentionally steer models toward desirable capabilities using synthetic SFT examples. At the same time, this level of control has potential risks. If synthetic data generation can be optimized to induce arbitrary differentiable properties in trained models, adversaries could potentially craft subtle data poisoning attacks that target specific biases or behaviors. Understanding both the capabilities and risks of targeted synthetic data generation will be important as synthetic data becomes an increasingly central component of modern machine learning pipelines.

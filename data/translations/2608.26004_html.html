摘要Abstract

1 简介Introduction

现代法学硕士部署越来越多地作为代理管道运行——检索文档Modern LLM deployments increasingly operate as agentic pipelines—retrieving documents(Lewis et al., 2020; Gao et al., 2023; Wu et al., 2025a)、调用工具, invoking tools(Yao et al., 2023; Schick et al., 2023)，维持多轮对话和记忆, maintaining multi-turn dialogue and memory(Sirdeshmukh et al., 2025; Zhang et al., 2025b; Wu et al., 2025b)，并处理多模式输入, and processing multimodal inputs(Liu et al., 2023)。这些设置会在随每一步增长的上下文中发出重复的 LLM 调用。随着检索到的段落、工具观察和交互历史的积累，前向传递成为主要的延迟瓶颈，使得上下文长度成为生产中推理开销的主要驱动因素。. These settings issue repeated LLM calls over context that grows with every step. As retrieved passages, tool observations, and interaction histories accumulate, the forward pass becomes the dominant latency bottleneck, making context length the primary driver of inference overhead in production.

为了控制这种开销，定期进行部署To control this overhead, deployments routinely压缩compress上下文the context(Pan et al., 2024b)：RAG 管道总结检索到的段落，工具使用代理仅传递 API 签名而不是完整文档，多模式工作流程提供简短的标题而不是原始图像。压缩可以降低服务成本，但会系统地丢弃对任务准确性至关重要的细粒度细节。因此，部署面临着严格的准确性和开销权衡：要么吸收全上下文生成的令人望而却步的延迟，要么接受显着的降级。: RAG pipelines summarize retrieved passages, tool-use agents pass only API signatures instead of full documentation, and multimodal workflows feed short captions instead of raw images. Compression reduces serving cost but systematically discards fine-grained details critical for task accuracy. Deployments thus face a rigid accuracy–overhead trade-off: absorb the prohibitive latency of full-context generation, or accept significant degradation.

推测解码 (SD)Speculative decoding (SD)(Leviathan et al., 2023; Chen et al., 2023)已成为加速 LLM 推理的标准方法：轻量级起草者提出候选令牌，大型验证者并行检查，保证目标分布下的无损生成。尽管对绘图器架构进行了广泛的改进has become the standard approach for accelerating LLM inference: a lightweight drafter proposes candidate tokens that a large verifier checks in parallel, guaranteeing lossless generation under the target distribution. Despite extensive improvements to drafter architectures(Li et al., 2024c; Cai et al., 2024; Li et al., 2024b)以及推测循环中的对比 Logit 融合and contrastive logit fusion in the speculative loop(Yuan et al., 2023)，所有现有的 SD 方法都共享一个基本约束：起草者和验证者处理相同的输入标记。 SD 加速固定目标分布，而不改变目标模型所看到的内容；一旦验证者被压缩，SD 只能加速压缩模型——它无法恢复压缩删除的内容。要么两个模型都支付全上下文成本，要么都继承压缩损失。, all existing SD methods share a foundational constraint: drafter and verifier process the same input tokens. SD accelerates a fixed target distribution without changing what the target model sees; once the verifier is compressed, SD can only accelerate the compressed model—it cannot recover what compression removed. Either both models pay the full-context cost, or both inherit the compression loss.

我们的主要观察是结构性的Our key observation is a structural计算不对称性compute asymmetry：每步延迟主要由大型验证器主导，而轻量级起草器增加的开销可以忽略不计。仅压缩验证器可以节省大部分延迟，但标准 SD 无法利用这一点，因为它强制执行相同的输入。我们打破这种对称性: per-step latency is dominated by the large verifier, while a lightweight drafter adds negligible overhead. Compressing only the verifier captures most of the latency savings, but standard SD cannot exploit this because it enforces identical input. We break this symmetry with不对称规格AsymSpec，一种显式解耦上下文访问的非对称推测解码框架。验证者严格在压缩视图上运行以提高效率，而起草者则读取完整的输入以重建丢弃的信息。我们通过对比机制实现这种恢复：起草者处理两个上下文视图，并减去它们的输出分布，消除了起草者与上下文无关的偏好，从而隔离了未压缩输入提供的信息增益。该增益信号，, an asymmetric speculative decoding framework that explicitly decouples context access. The verifier operates strictly on the compressed view for efficiency, while the drafter reads the full input to reconstruct the discarded information. We realize this recovery through a contrastive mechanism: the drafter processes both context views, and subtracting their output distributions removes the drafter’s context-independent preferences, isolating the information gain the uncompressed input provides. This gain signal,δ\delta，被融合到验证者的逻辑中，并由无参数上下文分歧接受（CDA）门进行调制。通过根据上下文差异缩放注入强度，门保持稳定的验证和高接受率。由于只有起草者处理完整的输入，, is fused into the verifier’s logits and modulated by a parameter-free Context-Divergence Acceptance (CDA) gate. By scaling injection strength with the context divergence, the gate maintains stable verification and high acceptance rates. Since only the drafter processes the full input,不对称规格AsymSpec在压缩验证器的延迟下恢复全上下文推理保真度，并扩展到跨模式设置（例如，原始图像上的视觉语言起草者引导字幕上的纯文本验证器）。recovers full-context reasoning fidelity at the compressed verifier’s latency, and extends to cross-modal settings (e.g., a vision–language drafter on raw images steering a text-only verifier on captions).

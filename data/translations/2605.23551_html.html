摘要Abstract

探索环境的目标条件强化学习代理将在整个轨迹中看到大量信息，当仅针对命令目标执行策略更新时，其中大部分信息都会被丢弃。A goal-conditioned reinforcement learning agent exploring an environment will see a wealth of information throughout a trajectory, most of which is discarded when only performing on-policy updates with respect to the commanded goal.全目标学习All-goals learning，其中每个转换都用于学习每个目标的离策略，允许代理提取最大的信息，但是当通过简单的重新标记完成时，它通常在计算上不可行。这可以通过同时联合输出每个目标的值和动作来克服，从而允许通过网络单次进行高效、并行的所有目标更新，这个过程我们称为一次学习一切（LEO）。我们表明，这种方法在目标条件 Craftax 上显着优于其他方法，并且与连续控制环境中的现有基线具有竞争力，同时实现了, where each transition is used for learning off-policy with respect to every goal, allows agents to extract maximal information, however it is usually computationally infeasible when done via naïve relabelling. This can be overcome by jointly outputting values and actions for every goal at once, allowing for efficient, parallel all-goals updates with a single pass through the network, in a process we call Learning Everything all at Once (LEO). We show that this approach significantly outperforms other methods on goal-conditioned Craftax and is competitive with existing baselines on continuous control environments, while achieving a>250×>250\times与所有目标重新标记相比，速度加快。然后我们继续证明，通过使用 LEO 作为教师网络而不是直接参与者，可以使这种方法变得更加强大。我们希望，通过大规模解锁全目标学习，LEO 可以成为复杂环境中 RL 从业者的有用工具。我们开源我们的代码speed-up compared to all-goals relabelling. We then go on to show that this approach can be made even more powerful by using LEO as a teacher network, rather than a direct actor. We hope that, by unlocking all-goals learning at scale, LEO can serve as a useful tool for RL practitioners in complex environments. 为了克服这个问题，我们建议通过简单地在同一数据流上独立地训练 LEO 和目标条件网络来将 LEO 与标准目标条件方法结合起来。然后，我们考虑将信息从 LEO 教师网络传输到学生网络的两种变体：一种基于策略/值克隆，一种基于值插值。我们发现这种方法显着改进了单独使用任一网络的效果。直观上，LEO 网络执行在粗略层面内化最大信息的工作。它为目标条件网络提供了有方向性的有用（但不精确）指导，一旦看到一些积极的例子可以引导，它就可以学习更准确的估计。我们将这种方法称为双 LEO。To overcome this problem, we propose combining LEO with the standard goal-conditioned approach by simply training both a LEO and goal-conditioned network independently on the same stream of data. We then consider two variants for transmitting information from the LEO teacher network to the student network: one based on policy/value cloning and one based on value interpolation. We find that this approach significantly improves on using either network by itself. Intuitively, the LEO network performs the job of internalising maximal information at a coarse level. It provides directionally useful (but imprecise) guidance for the goal-conditioned network, which can learn more accurate estimates once it has seen some positive examples to bootstrap off. We refer to this approach as Dual LEO.

In contrast to most existing GCRL benchmarks, since Craftax is both partially observed and procedurally generated, it is not meaningful to use target states as goals. We also evaluate on traditional continuous control robotics environments(Bortkiewicz et al., 2024).

8 局限性和未来的工作Limitations and Future Work

虽然我们已经证明 LEO 可以在适当的环境下提供令人信服的实证结果，但该方法确实有明显的局限性。首先，它假设一个有限的目标集，该目标集足够小，可以柯里化到价值/策略网络的输出层，这使得它不适合非常大或连续的目标空间。此外，LEO 将目标表示为一组，如果目标具有某些底层结构（例如表示网格上的点），则这可能不是最佳的。While we have shown that LEO can provide compelling empirical results in suitable settings, the method does have clear limitations. Firstly, it assumes a finite goal set that is small enough that it can be curried to the output layer of value/policy networks, making it unsuitable for very large or continuous goal spaces. Also, LEO represents goals as a set, which may be suboptimal if the goals have some underlying structure, for instance representing points on a grid.

虽然我们已经证明低维连续目标空间可以有效地量化为离散目标集，但这种方法无法扩展到高维连续目标空间。 此外，需要对策略更新的 Actor-Critic 设置中的每个目标头的操作进行重新采样，这会导致连续控制设置的显着减慢（我们发现所有目标策略更新会使吞吐量下降约 70%）。可以通过使用重复使用收集的轨迹批次中的操作的算法来改进这一点While we have shown that low dimensional continuous goal spaces can be effectively quantised into a discrete goal set, this approach would not scale to high-dimensional continuous goal spaces. Furthermore, the need to resample actions for each goal head in the actor-critic setup for the policy update is a significant slowdown for continuous control settings (we found the all-goals policy update to drop throughput by about 70%). This could be improved upon by making use of algorithms that reuse actions from the gathered trajectory batch(Nair et al., 2020)而不是重新采样。rather than resampling.

我们希望我们已经阐明了我们认为的 GCRL 的核心权衡，即 1）UVFA 式方法，它可以在目标之间进行泛化并通过早期融合学习良好的表示；2）LEO 式方法，它可以有效地摄取大量信息，但必须独立处理每个目标，并且由于后期融合，可能很难学习高保真度表示。双 LEO 试图通过结合这两种范式来弥补这一差距，但也许存在某种方法可以在两个极端之间进行本地插值。We hope that we have shed light onto what we believe is a core tradeoff in GCRL, between 1) the UVFA-style approach which can generalise between goals and learn good representations through early fusion and 2) the LEO-style approach, which can efficiently ingest a huge amount of information, but must treat each goal independently and can struggle to learn high fidelity representations due to late fusion. Dual LEO attempts to bridge this gap by combining the two paradigms, but perhaps some method exists that could natively interpolate between the two extremes.

未来的工作可以研究将 LEO 与其他框架（例如分层 RL 框架）集成，在整个训练过程中动态构建目标并将其添加到 LEO 网络中，或使用双 LEO 设置作为目标采样的信号。Future work could investigate integrating LEO with other frameworks, such as those from hierarchical RL, dynamically constructing and adding goals to the LEO network throughout training or using the Dual LEO setup as a signal for goal sampling.

9 结论Conclusion

总之，我们提出了 LEO，一种允许对有限目标集进行有效的所有目标更新的方法。我们证明，LEO 在完整的 CraftaxGC 基准测试中优于现有的 GCRL 方法，而双 LEO（一种结合了 LEO 和 UVFA 优点的方法）的性能甚至更好。此外，我们表明 LEO 概念可以扩展到连续控制，在目标条件蚂蚁迷宫任务上它与现有基线具有竞争力。我们希望我们已经展示了 LEO 的实用性，并且它对 RL 从业者来说是一个有用的工具。In conclusion, we propose LEO, an approach that allows efficient all-goals updates for finite goal sets. We demonstrate that LEO outperforms existing approaches to GCRL on the full CraftaxGC benchmark, with Dual LEO, an approach that combines the best of LEO and UVFA, performing even better. Furthermore, we show that the LEO concept can be extended to continuous control, where it is competitive with existing baselines on goal-conditioned ant maze tasks. We hope that we have demonstrated the utility of LEO and that it proves to be a useful tool for RL practitioners.

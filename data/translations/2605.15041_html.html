LLM 工具使用的自适应推理和执行的基于案例的校准Case-Based Calibration of Adaptive Reasoning and Execution for LLM Tool Use

Renning Pang    Tian Lan    Leyuan Liu(🖂)    Piao Tong    Sheng Cao    Xiaosong Zhang
摘要Abstract

工具的使用将大型语言模型扩展到参数知识之外，但可靠的执行需要平衡适当的推理深度和严格的结构有效性。我们从基于案例的角度来解决这个问题，提出了 CAST，这是一个案例驱动的框架，它将历史执行轨迹视为结构化案例。 CAST 不是重复使用原始样本输出，而是提取源自案例的信号来识别复杂性概况，以估计最佳推理策略，以及故障概况以映射可能的结构故障。该框架将这些知识转化为细粒度的奖励设计和自适应推理，使模型能够在强化学习期间自主内化基于案例的策略。 BFCLv2 和 ToolBench 上的实验表明，CAST 提高了模式忠实执行和任务级工具使用的成功率，同时减少了不必要的考虑。该方法使整体执行准确度提高了 5.85 个百分点，并将平均推理长度减少了 26%，从而显着减少了高影响力的结构错误。最终，这展示了历史执行案例如何为校准工具的使用提供可重用的适应知识。Tool use extends large language models beyond parametric knowledge, but reliable execution requires balancing appropriate reasoning depth with strict structural validity. We approach this problem from a case-based perspective to present CAST, a case-driven framework that treats historical execution trajectories as structured cases. Instead of reusing raw exemplar outputs, CAST extracts case-derived signals to identify complexity profiles for estimating optimal reasoning strategies, alongside failure profiles to map likely structural breakdowns. The framework translates this knowledge into a fine-grained reward design and adaptive reasoning, enabling the model to autonomously internalize case-based strategies during reinforcement learning. Experiments on BFCLv2 and ToolBench demonstrate that CAST improves both schema-faithful execution and task-level tool-use success while reducing unnecessary deliberation. The approach achieves up to 5.85 percentage points gain in overall execution accuracy and reduces average reasoning length by 26%, significantly mitigating high-impact structural errors. Ultimately, this demonstrates how historical execution cases can provide reusable adaptation knowledge for calibrated tool use.

1 简介Introduction

工具的使用已成为将大型语言模型 (LLM) 扩展到参数知识之外的核心机制，最近的调查将工具调用、规划和行动协调确定为 LLM 代理系统的核心组件Tool use has become a central mechanism for extending large language models (LLMs) beyond parametric knowledge, and recent surveys identify tool invocation, planning, and action coordination as core components of LLM-agent systems[25, 4, 6, 21]。与此同时，面向基准的研究表明，可靠的函数调用仍然远未得到解决，特别是在需要内存、动态决策和长期推理而不是仅单轮文本生成的设置中. At the same time, benchmark-oriented studies suggest that reliable function calling remains far from solved, especially in settings that require memory, dynamic decision-making, and long-horizon reasoning rather than single-turn text generation alone[22]。代表性框架如Toolformer. Representative frameworks such as Toolformer[26], 反应, ReAct[29]和工具LLM, and ToolLLM[24]进一步表明，关键的挑战不再仅仅是法学硕士是否可以调用工具，而是他们是否能够以稳定和任务敏感的方式分配推理工作并执行结构化的工具操作。further show that the key challenge is no longer simply whether LLMs can call tools, but whether they can allocate reasoning effort and execute structured tool actions in a stable and task-sensitive manner.

出现这一挑战是因为工具的使用对模型提出了两个同时的要求。不同的查询需要不同数量的中间推理：有些可以不加考虑地解决，而另一些则需要额外的推理来验证约束、规范化参数或组成多步骤工具调用。最近关于自适应思想链（CoT）和高效工具调用的研究表明，使用相同的推理策略处理所有输入通常效率低下，甚至可能适得其反This challenge arises because tool use places two simultaneous demands on the model. Different queries require different amounts of intermediate reasoning: some can be solved with little deliberation, whereas others require additional reasoning to verify constraints, normalize arguments, or compose multi-step tool calls. Recent work on adaptive chain-of-thought (CoT) and efficient tool calling suggests that treating all inputs with the same reasoning policy is often inefficient and can even be counterproductive[20, 19, 27]。同时，工具执行受到严格的结构约束的控制，而标准强化学习（RL）通常仅提供粗略的最终任务反馈，因此很难确定失败是否源于工具选择、参数覆盖、类型不匹配、模式违规或价值构造。因此，工具使用的核心难点是在异构任务需求下共同校准推理深度和执行结构。. At the same time, tool execution is governed by strict structural constraints, while standard reinforcement learning (RL) often provides only coarse end-task feedback, making it difficult to identify whether failure originates from tool selection, parameter coverage, type mismatch, schema violation, or value construction. The central difficulty in tool use is therefore to calibrate reasoning depth and execution structure jointly under heterogeneous task demands.

2 相关工作Related Work

基于案例的推理 (CBR) 通过检索、重用、修订和保留来重用和调整类似先前案例的解决方案，从而解决新问题Case-based reasoning (CBR) addresses new problems by reusing and adapting solutions from similar prior cases through retrieval, reuse, revision, and retention[1]。近年来，这种观点越来越多地与大型语言模型和代理系统相交叉。之前的工作已经探索了法学硕士在论证推理中案例适应的使用. In recent years, this perspective has increasingly intersected with large language models and agentic systems. Prior work has explored the use of LLMs for case adaptation in argumentative reasoning[13]，而最近的研究调查了法学硕士如何支持案例检索中的相似性评估, while more recent studies investigate how LLMs can support similarity assessment in case retrieval[14]。其他工作将基于案例的想法扩展到强化学习和代理设置，例如通过基于案例的知识蒸馏进行强化学习. Other work extends case-based ideas to reinforcement learning and agent settings, for example through case-based knowledge distillation for reinforcement learning[18]，以及基于经验的统一代理推理架构, and unified experience-grounded agentic reasoning architectures[3]。最近的工作还研究了法学硕士如何支持来自非结构化来源的案例人口. Recent work has also examined how LLMs can support case-base population from unstructured sources[10]以及如何在欺诈检测等实际决策支持环境中将 CBR 与法学硕士集成and how CBR can be integrated with LLMs in practical decision-support settings such as fraud detection[9]。总的来说，这些研究表明法学硕士可以支持 CBR 过程的多个阶段，包括相似性评估、适应、案例获取以及在主体推理中使用结构化先验经验。. Taken together, these studies suggest that LLMs can support multiple stages of the CBR process, including similarity assessment, adaptation, case acquisition, and the use of structured prior experience in agent reasoning.

相关的研究方向是如何调节大型语言模型生成的推理量。现有方法寻求缩短、压缩或有选择地触发思维链，以提高效率，同时保持有竞争力的任务绩效A related line of research studies how to regulate the amount of reasoning generated by large language models. Existing methods seek to shorten, compress, or selectively trigger chain-of-thought in order to improve efficiency while maintaining competitive task performance[20, 19]。这一系列工作与我们的设置直接相关，因为它认识到不同的输入可能需要不同数量的中间推理。与此同时，另一项工作重点关注法学硕士中的工具使用和推理-行动行为。 Toolformer 表明语言模型可以学习何时以及如何调用外部工具. This line of work is directly relevant to our setting because it recognizes that different inputs may require different amounts of intermediate reasoning. In parallel, another line of work focuses on tool use and reasoning–acting behavior in LLMs. Toolformer shows that language models can learn when and how to invoke external tools[26]，而 ReAct 则展示了推理痕迹与外部动作交错的价值, while ReAct demonstrates the value of interleaving reasoning traces with external actions[29]。工具使用研究也伴随着越来越现实的评估设置，包括大规模 API 基准测试和函数调用排行榜. Tool-use research has also been accompanied by increasingly realistic evaluation settings, including large-scale API benchmarks and function-calling leaderboards[24, 22]。最近的工作进一步提高了调用纪律和效率，例如通过元认知触发. More recent work further improves invocation discipline and efficiency, for example through meta-cognitive triggering[15]，对齐以实现高效的工具调用, alignment for efficient tool calling[27]，或工具使用LLM的令牌级政策梯度重塑, or token-level policy gradient reshaping for tool-use LLMs[16]。这些研究极大地推进了推理控制和工具使用一致性，但它们通常将推理深度和执行结构视为单独的关注点，而不是同一问题的联合案例条件方面。. These studies substantially advance reasoning control and tool-use alignment, but they generally treat reasoning depth and execution structure as separate concerns rather than as jointly case-conditioned aspects of the same problem.

我们的工作是由这些方向之间的差距推动的。现有的面向 CBR 的研究表明，历史案例可以为未来的推理和行动提供可重用的结构，而自适应推理和工具对齐研究表明，必须仔细控制推理成本和执行纪律。仍有待探索的是如何使用历史执行案例来联合导出这两个方面的校准信号。 CAST 是一个案例驱动的框架，其中历史执行案例提供了源自案例的复杂性和失败信号，旨在明确内化基于案例的经验，通过推理预算控制和模式忠实工具优化来校准强化学习。Our work is motivated by the gap between these directions. Existing CBR-oriented research suggests that historical cases can provide reusable structure for future reasoning and action, while adaptive reasoning and tool-alignment research shows that both reasoning cost and execution discipline must be carefully controlled. What remains underexplored is how historical execution cases can be used to derive calibration signals for these two aspects jointly. CAST is a case-driven framework in which historical execution cases provide case-derived complexity and failure signals, designed to explicitly internalize the case-based experience that calibrates reinforcement learning through reasoning-budget control and schema-faithful tool optimization.

6 结论Conclusion

本文从基于案例的推理角度重新审视了工具的使用，并提出了 CAST，这是一个使用从过去的执行案例中提取的信号来指导强化学习的框架。具体来说，CAST 通过复杂性和故障概况总结历史轨迹，并使用它们来调节推理长度并监督模式级工具的执行。 BFCLv2 和 ToolBench 上的实验表明，这种情况条件校准可提高执行力 准确性，转移到端到端工具使用的成功，并减少不必要的推理，在更复杂的情况下收益最大。长期规划仍然具有挑战性，但结果表明，基于案例的监督为改进可靠的工具调用和下游任务完成提供了实践基础。自然的下一步是将这个框架扩展到更丰富的案例记忆、更强的检索和重用以及更多的交互式代理设置。This paper revisits tool use from a case-based reasoning perspective and proposes CAST, a framework that uses signals distilled from past execution cases to guide reinforcement learning. Specifically, CAST summarizes historical trajectories through complexity and failure profiles, and uses them to regulate reasoning length and supervise schema-level tool execution. Experiments on BFCLv2 and ToolBench show that this case-conditioned calibration improves execution accuracy, transfers to end-to-end tool-use success, and reduces unnecessary reasoning, with the largest gains on more complex cases. Long-horizon planning remains challenging, but the results suggest that case-derived supervision provides a practical basis for improving both reliable tool calling and downstream task completion. A natural next step is to extend this framework to richer case memories, stronger retrieval and reuse, and more interactive agent settings.

# 论文翻译流水线升级 — 需求拆解摘要

## 核心业务闭环

> AI 研究者 → 浏览热榜 → 选中心仪的论文（面包屑）→ 点击「中文翻译」→ 阅读**保留原文排版**的全中文论文 → 快速理解论文核心内容

---

## 角色清单

| 角色 | 核心诉求 | 主要操作 | 使用终端 |
|:---|:---|:---|:---|
| AI 研究者 | 快速阅读中文版论文，**图文排版与原文一致** | 浏览热榜 → 点击翻译 → 阅读全文 | PC 浏览器 |
| 系统（自动化） | 每日批量翻译 Top 50 论文，部署到 GitHub Pages | CI 定时触发 → 抓取 → 翻译 → 部署 | GitHub Actions |

---

## 功能清单（按优先级排序）

| 模块 | 子功能 | 操作角色 | 优先级 | 说明 |
|:---|:---|:---|:---|:---|
| **翻译引擎** | arXiv HTML 抓取 | 系统 | **P0** | 用 `arxiv.org/html/{id}` 替代 PDF 提取，保留图片/公式/表格 |
| **翻译引擎** | HTML 文本节点翻译 | 系统 | **P0** | 遍历 DOM 树，仅翻译文本节点，跳过 `<math>`、`<code>`、`<script>` |
| **翻译引擎** | 公式保留（MathJax/KaTeX） | 系统 | **P0** | 数学公式不翻译、不改动，保持原样渲染 |
| **翻译引擎** | 图片保留 | 系统 | **P0** | 图片使用 arXiv CDN 原始链接，不下载不转换 |
| **翻译引擎** | 表格保留 | 系统 | **P0** | HTML table 结构保留，仅翻译单元格文本 |
| **翻译输出** | 深色主题覆盖 | 系统 | **P1** | 在 arXiv HTML 基础上注入深色主题 CSS |
| **翻译输出** | 顶部导航栏 | 系统 | **P1** | 添加「返回热榜」「查看原文 PDF」「arXiv 原文」链接 |
| **翻译输出** | 中英对照模式 | 系统 | **P2** | 可选：hover 显示原文或双栏对照 |
| **降级策略** | PDF 降级翻译 | 系统 | **P1** | 部分论文无 HTML 版本，自动降级到 PDF 纯文本翻译（保留现有逻辑） |
| **降级策略** | 降级标识 | 系统 | **P2** | 降级翻译的论文在前端标注「简版翻译」 |
| **前端展示** | 翻译按钮状态 | 系统 | **P1** | 区分「保真翻译」「简版翻译」「暂无翻译」三种状态 |

## 隐含需求补充

| 隐含需求 | 判断依据 | 建议优先级 |
|:---|:---|:---|
| **翻译缓存** | 同一篇论文不应每次都重新翻译（浪费 Google Translate 额度） | P1 |
| **翻译失败重试** | 网络不稳定或 Google 限流时，应支持断点续传/重试 | P1 |
| **arXiv HTML 可用性检查** | 并非所有论文都有 HTML 版本，需先探测再决定策略 | P0 |
| **翻译进度日志** | CI 中应输出每篇论文的翻译方式（HTML/PDF/跳过）和耗时 | P1 |
| **引用链接保留** | 论文内的交叉引用（[1][2]等）应保留可点击 | P0 |

## 已确认决策

| # | 问题 | 决策 |
|:---|:---|:---|
| 1 | 中英对照模式 | **本期做**（升级为 P1） |
| 2 | 翻译引擎 | **Google Translate（免费）**，后续有用户再考虑 DeepL |
| 3 | 页面主题 | **白底**，不跟热榜深色主题 |
| 4 | 翻译数量 | **全部翻译**（有 HTML 用 HTML，无 HTML 降级 PDF） |

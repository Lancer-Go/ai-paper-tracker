摘要Abstract

类激活映射（CAM）是可解释人工智能中使用最广泛的视觉解释家族之一。其目的很直观：它将内部模型证据转换为热图，突出显示支持目标类或概念的图像区域、卷积通道、标记或补丁。自 2016 年首次提出 CAM 公式以来，该领域已经远远超出了全球平均池化 CNN 分类器的范畴。 CAM 风格的方法现在包括基于梯度的事后解释、无梯度评分和消融方法、高分辨率升级、弱监督定位和分割、变压器标记归因、因果和去偏方法以及使用 CLIP、DINO、SAM 或特征分布比较的基础模型时代方法。这篇综述严格综合了 2016 年以来发表的 57 篇以方法为中心的论文。本文开发了一种分类法，通过归因机制、架构依赖性和评估目标来区分方法。然后回顾基于梯度的 CAM、最新的混合 CAM 风格方法以及基于模型或架构感知的方法。在整个语料库中，主要趋势很明显：该领域正在从解释一个低分辨率 CNN 层中的一类分数转向比较、多层、概率、令牌感知和基础模型感知解释。与此同时，评估仍然分散。忠诚度、本地化、稳健性、计算成本和人类信任通常用不同的协议来衡量。因此，审查不仅强调每种方法的贡献，还强调它留下的空白以及后来的方法试图弥补这一空白。Class activation mapping (CAM) is one of the most widely used visual explanation families in explainable artificial intelligence. Its purpose is intuitive: it converts internal model evidence into a heatmap that highlights the image regions, convolutional channels, tokens, or patches that support a target class or concept. Since the first CAM formulation in 2016, the field has moved far beyond global-average-pooled CNN classifiers. CAM-style methods now include gradient-based post-hoc explanations, gradient-free score and ablation methods, highresolution upscaling, weakly supervised localization and segmentation, transformer token attribution, causal and debiasing methods, and foundation-model-era approaches that use CLIP, DINO, SAM, or feature-distribution comparisons. This review synthesizes a strict corpus of 57 method-centered papers published from 2016 onward. The paper develops a taxonomy that separates methods by attribution mechanism, architectural dependence, and evaluation objective. It then reviews gradient-based CAMs, recent and hybrid CAM-style methods, and modelbased or architecture-aware methods. Across the corpus, the main trend is clear: the field is shifting from explaining one class score in one low-resolution CNN layer toward comparative, multi-layer, probabilistic, tokenaware, and foundation-model-aware explanations. At the same time, evaluation remains fragmented. Faithfulness, localization, robustness, computational cost, and human trust are often measured with different protocols. The review therefore emphasizes not only what each method contributes, but also which gap it leaves open and which later methods attempt to close that gap.

一、简介1. Introduction

深度视觉模型已成为图像分类、分割、医学成像、自主感知、工业检查和许多其他决策系统的核心。他们的成功来自于学习分层视觉表示的能力，但相同的分层表示使他们的决定难以解释。在高风险的环境中，正确的班级标签是不够的。用户还需要知道模型是否使用了有意义的证据，是否依赖于背景捷径，以及其推理在图像变化下是否稳定。 CAM 风格的方法通过生成视觉证据图来解决这个问题。热图并不是对神经网络的完整解释，但它给出了模型在产生目标输出时的外观的紧凑且人类可读的视图。Deep visual models have become central to image classification, segmentation, medical imaging, autonomous perception, industrial inspection, and many other decision systems. Their success comes from the ability to learn layered visual representations, but the same layered representation makes their decisions hard to interpret. In highstakes settings, a correct class label is not enough. A user also needs to know whether the model used meaningful evidence, whether it relied on a background shortcut, and whether its reasoning is stable under changes in the image. CAM-style methods address this problem by producing visual evidence maps. A heatmap is not a complete explanation of a neural network, but it gives a compact and human-readable view of where the model looked when it produced a target output.

最初的 CAM 论文表明，当全局平均池化将空间特征图与类别分数连接起来时，分类训练的 CNN 可以实现本地化 [1]。然后，Grad-CAM 通过使用使这个想法变得更加普遍The original CAM paper showed that a classification-trained CNN can be made localizable when global average pooling connects spatial feature maps to class scores [1]. Grad-CAM then made the idea more general by using

目标类梯度，以便可以为普通 CNN 分类器甚至基于 CNN 的多模态模型生成类似 CAM 的地图 [2]。这一转变将 CAM 从一种特殊的建筑属性转变为一种实用的事后解释工具。该领域随后向几个方向扩展。一些方法改进了梯度加权以提高对象覆盖范围[3]，而其他方法则通过前向分数变化或消融来避免梯度并测量通道重要性[8]、[9]。一个单独的流使用 CAM 作为弱监督定位和分割的种子，其目标不仅是解释模型，而且是训练下游密集预测器 [4][7]、[11]。最近的工作将 CAM 风格的归因扩展到变压器、类标记、补丁标记、视觉提示、CLIP 提示、DINO 亲和图和 SAM 生成的掩码 [30]-[33]、[41]-[43]、[47]-[50]。target-class gradients, so that CAM-like maps could be generated for ordinary CNN classifiers and even CNNbased multimodal models [2]. This shift changed CAM from a special architectural property into a practical posthoc explanation tool. The field then expanded in several directions. Some methods refined gradient weighting to improve object coverage [3], while others avoided gradients and measured channel importance through forward score changes or ablations [8], [9]. A separate stream used CAMs as seeds for weakly supervised localization and segmentation, where the goal is not only to explain a model but also to train a downstream dense predictor [4][7], [11]. More recent work extends CAM-style attribution to transformers, class tokens, patch tokens, visual prompts, CLIP prompts, DINO affinity graphs, and SAM-generated masks [30]-[33], [41]-[43], [47]-[50].

这篇评论是以方法为中心的。它不包括仅使用 Grad-CAM 作为应用研究中的可视化图形的论文。相反，论文必须生成、完善、评估或理论上分析 CAM 风格的地图。这个范围很重要，因为现在许多应用论文中都使用了 CAM，但仅应用程序的使用并不一定会改变方法。这篇综述的贡献是将方法文献组织成一个连贯的发展故事：从 CNN 特定的定位，到基于梯度和分数的归因，到高分辨率和因果细化，到变压器和基础模型时代的解释。This review is method-centered. It does not include papers that merely use Grad-CAM as a visualization figure in an application study. Instead, a paper must generate, refine, evaluate, or theoretically analyze a CAM-style map. This scope is important because CAM is now used in many application papers, but application-only usage does not necessarily change the method. The contribution of this review is to organize the method literature into a coherent development story: from CNN-specific localization, to gradient and score-based attribution, to highresolution and causal refinements, to transformer and foundation-model-era explanations.

此次审查有四个目标。首先，它为 57 篇论文的严格语料库定义了可重复的搜索和包含协议。其次，明确了CAM研究中使用的主要技术术语和评价指标。第三，它开发了一种分类法，将基于梯度、无梯度、混合、高分辨率、令牌级、基础模型时代和架构感知方法分开。第四，它比较了语料库报告常见数据集的兼容指标的代表性结果。由于 CAM 评估未标准化，因此本综述中的定量数据故意限于所包含论文中直接报告的值，并根据其协议约束进行解释。The review has four goals. First, it defines a reproducible search and inclusion protocol for a strict corpus of 57 papers. Second, it clarifies the main technical terms and evaluation metrics used in CAM research. Third, it develops a taxonomy that separates gradient-based, gradient-free, hybrid, high-resolution, token-level, foundation-model-era, and architecture-aware methods. Fourth, it compares representative results where the corpus reports compatible metrics on common datasets. Because CAM evaluation is not standardized, the quantitative figures in this review are deliberately limited to values that are directly reported in the included papers and are interpreted with their protocol constraints.

2.1 评价标准2.1 Evaluation criteria

评估是 CAM 研究中长期存在分歧的根源。视觉上清晰的地图可能是不忠实的，而忠实的地图可能会揭示人类不想要的模型捷径。因此，语料库使用多个评估族。删除和插入等扰动指标测试删除或恢复显着像素是否会改变预测。置信度的平均下降和增加衡量仅保留突出显示区域时置信度的变化情况。 ROAD 和 ADCC 将扰动质量与复杂性或连贯性结合起来。定位指标将地图与框、掩模或专家区域进行比较。在 WSSS 中，mIoU 和 DSC 衡量 CAM 衍生的伪标签是否对分割有用。以人为本的研究评估解释是否有助于用户校准信任或完成任务 [2]、[44]。Evaluation is a persistent source of disagreement in CAM research. A visually sharp map can be unfaithful, and a faithful map can reveal a model shortcut that humans do not want. For this reason, the corpus uses multiple evaluation families. Perturbation metrics such as deletion and insertion test whether removing or restoring salient pixels changes the prediction. Average Drop and Increase in Confidence measure how confidence changes when only the highlighted region is retained. ROAD and ADCC combine perturbation quality with complexity or coherence. Localization metrics compare maps with boxes, masks, or expert regions. In WSSS, mIoU and DSC measure whether CAM-derived pseudo-labels are useful for segmentation. Human-centered studies evaluate whether explanations help users calibrate trust or complete a task [2], [44].

4. 基于梯度的 CAM 方法4. Gradient-based CAM Methods

基于梯度的方法是大多数 CAM 研究的参考点。他们很有吸引力，因为他们通常需要一次向前传球和一次向后传球。它们也很灵活：目标可以是类别分数、标题分数、VQA 答案或其他可微输出。它们的弱点是梯度测量局部敏感性，而不一定是因果贡献。它们可能会消失、饱和、在浅层中变得嘈杂，或者突出显示快速改变分数但在语义上没有意义的特征。因此，基于梯度的 CAM 的开发是一系列尝试，旨在保持 Grad-CAM 的速度，同时提高分辨率、稳定性、理论基础或架构范围。Gradient-based methods are the reference point for most CAM research. They are attractive because they usually need one forward pass and one backward pass. They are also flexible: a target can be a class score, a caption score, a VQA answer, or another differentiable output. Their weakness is that gradients measure local sensitivity, not necessarily causal contribution. They can vanish, saturate, become noisy in shallow layers, or highlight features that change the score quickly but are not semantically meaningful. The development of gradient-based CAMs is therefore a sequence of attempts to preserve the speed of Grad-CAM while improving resolution, stability, theoretical grounding, or architectural reach.

4.1 CNN 梯度、相关性和博弈论 CAM4.1 CNN gradient, relevance, and game-theoretic CAMs

Grad-CAM [2] 使 CAM 对于普通 CNN 来说变得实用。它不需要全局平均池化架构，而是通过平均目标分数相对于该图的梯度来计算每个特征图的重要性。然后对加权特征图求和并通过 ReLU。这种设计解释了为什么 Grad-CAM 得到广泛使用，它简单、模型局部、类判别，并且可以应用于 CNN 分类器、字幕模型、VQA 系统和其他可微视觉模型。它的局限性在于最终的卷积层在空间上是粗糙的，并且当模型饱和时平均梯度可能会丢失局部证据或变得很弱。 Grad-CAM++ [3] 通过改变梯度加权规则解决了第一个限制。它使用正偏导数的加权组合，因此产生强正值的像素Grad-CAM [2] made CAM practical for ordinary CNNs. Instead of requiring a global-average-pooling architecture, it computes the importance of each feature map by averaging the gradient of the target score with respect to that map. The weighted feature maps are then summed and passed through ReLU. This design explains why Grad-CAM became widely used, it is simple, model-local, class-discriminative, and can be applied to CNN classifiers, captioning models, VQA systems, and other differentiable visual models. Its limitation is that the final convolutional layer is spatially coarse, and the average gradient can miss localized evidence or become weak when the model is saturated. Grad-CAM++ [3] addresses the first limitation by changing the gradient weighting rule. It uses a weighted combination of positive partial derivatives, so pixels that make strong positive

贡献受到更多重视。这改进了多对象和多实例解释，因为地图不再仅由单个平均梯度控制。然而，该方法仍然是基于导数的，因此它并不能消除更广泛的噪声或饱和梯度问题。 Integrated Grad-CAM [17] 从另一个方向解决了这个问题。它计算 Grad-CAM 式分数的路径积分，因此解释较少依赖于仅一个输入点的局部梯度。在 PASCAL VOC 2007 上，该方法报告了 ResNet-50 的强大 EBPG 和边界框定位值，但改进伴随着额外的梯度评估以及集成方法对路径设计的通常敏感性。 SIS-CAM [56]通过迭代地细化显着性图来解决噪声梯度问题。它对梯度进行平方，将中间特征图与输入图像融合，并应用边界感知掩蔽来强调关键区域。这种迭代方法提高了忠实度（删除/插入指标）和空间分辨率，使 SIS-CAM 能够有效地在 WSOL 和 WSSS 任务中生成高分辨率 CAM。contributions receive more emphasis. This improves multiple-object and multiple-instance explanation because the map is no longer controlled only by a single averaged gradient. The method is still derivative-based, however, so it does not remove the broader problem of noisy or saturated gradients. Integrated Grad-CAM [17] targets that problem from another direction. It computes a path integral of Grad-CAM-style scores, so the explanation is less dependent on the local gradient at only one input point. On PASCAL VOC 2007, the method reported strong EBPG and bounding-box localization values for ResNet-50, but the improvement comes with extra gradient evaluations and with the usual sensitivity of integrated methods to path design. SIS-CAM [56] addresses the noisy gradient problem by iteratively refining saliency maps. It squares gradients, fuses intermediate feature maps with the input image, and applies boundary-aware masking to emphasize critical regions. This iterative approach improves both faithfulness (deletion/insertion metrics) and spatial resolution, making SIS-CAM effective for high-resolution CAM generation in WSOL and WSSS tasks.

Relevance-CAM [13] 的动机是观察到梯度在中间层变得不可靠。该论文使用逐层相关性传播来导出权重分量，而不是普通的梯度。这使得浅层和中层的解释更加稳定，而 Grad-CAM 可能会遭受梯度破碎的影响。重要的区别在于 Relevance-CAM 不仅仅尝试锐化最终层地图；它还尝试锐化最后一层地图。它试图使特定于类的映射在层深度上可靠。在报告的ResNet-50评估中，RelevanceCAM相对于Grad-CAM和Grad-CAM++改进了浅层平均下降和平均增加[13]。它的剩余限制是相关性传播取决于传播规则，因此该方法不如标准后向梯度即插即用。 LIFT-CAM [15]提出了一个更具理论性的问题：为什么应该通过启发式选择 CAM 线性组合的系数。该方法将每个激活图表示为加性归因模型中的特征，并使用基于 DeepLIFT 的近似来估计类似 SHAP 的系数。这使得 CAM 权重具有更清晰的附加属性含义，同时保持方法的效率。该论文报告了在 ImageNet 样本上比 Grad-CAM 和 Grad-CAM++ 更高的插入 AUC 和更低的删除 AUC [15]。主要差距是 DeepLIFT 式归因仍然依赖于参考激活，而且 SHAP 连接是近似的而不是精确的。Relevance-CAM [13] is motivated by the observation that gradients become unreliable in intermediate layers. The paper uses layer-wise relevance propagation to derive the weighting components instead of ordinary gradients. This makes the explanation more stable in shallow and middle layers, where Grad-CAM may suffer from shattered gradients. The important difference is that Relevance-CAM is not trying only to sharpen the final-layer map; it tries to make class-specific maps reliable across layer depth. In the reported ResNet-50 evaluation, RelevanceCAM improved shallow-layer Average Drop and Average Increase relative to Grad-CAM and Grad-CAM++ [13]. Its remaining limitation is that relevance propagation depends on propagation rules, so the method is less plugand-play than a standard backward gradient. LIFT-CAM [15] asks a more theoretical question: why should the coefficients of a CAM linear combination be chosen by a heuristic The method formulates each activation map as a feature in an additive attribution model and uses a DeepLIFT-based approximation to estimate SHAP-like coefficients. This gives the CAM weights a clearer additive-attribution meaning while keeping the method efficient. The paper reports higher insertion AUC and lower deletion AUC than Grad-CAM and Grad-CAM++ on ImageNet samples [15]. The main gap is that DeepLIFT-style attribution still depends on reference activations, and the SHAP connection is approximate rather than exact.

FAM [28]拓宽了解释的目标。在人员重新识别或自监督表示学习等任务中，测试图像可能与训练类不对应。那么解释类 logit 就没那么有意义了。 FAM 定义了特征激活映射并解释了哪些图像区域对特征向量本身有贡献。这是一个重要的转变，因为许多现代视觉系统使用编码器作为表示提取器而不是闭集分类器。限制是目标特征必须仔细定义，并且得到的解释是关于表示形成而不是单个类决策。 Abs-CAM [57]、SSG-CAM [53] 和 ShapleyCAM [55] 进一步说明了如何细化梯度信号。 Abs-CAM 将梯度转化为绝对正贡献，并将所得显着性与输入图像融合，从而减少负梯度噪声并改善删除、插入和指向游戏行为 [57]。 SSG-CAM 使用平滑的二阶梯度并将其与差分进化相结合来选择和融合最佳的多层特征图 [53]。它直接解决了一阶 CAM 的两个弱点：饱和度和手动层选择。 ShapleyCAM [55]构建了一个内容保留的博弈论框架，并通过使用梯度和 Hessian 信息导出 Shapley 式 CAM 权重。它连接了可扩展的 CAM 和公平的特征归因，但它还引入了二阶计算和效用函数设计选择。总之，这些方法表明梯度家族正在从简单的敏感性转向更有原则性的归因。FAM [28] broadens the target of explanation. In tasks such as person re-identification or self-supervised representation learning, a test image may not correspond to a training class. Explaining a class logit is then less meaningful. FAM defines Feature Activation Mapping and explains which image regions contribute to the feature vector itself. This is an important shift because many modern vision systems use encoders as representation extractors rather than closed-set classifiers. The limitation is that the target feature must be carefully defined, and the resulting explanation is about representation formation rather than a single class decision. Abs-CAM [57], SSG-CAM [53], and ShapleyCAM [55] further illustrate how the gradient signal can be refined. Abs-CAM turns gradients into absolute positive contributions and fuses the resulting saliency with the input image, which reduces negative-gradient noise and improves deletion, insertion, and pointing-game behavior [57]. SSG-CAM uses smoothed second-order gradients and combines them with differential evolution to select and fuse the best multilayer feature maps [53]. It directly addresses two weaknesses of first-order CAMs: saturation and manual layer selection. ShapleyCAM [55] builds a content-reserved game-theoretic framework and derives Shapley-style CAM weights by using gradients and Hessian information. It bridges scalable CAMs and fair feature attribution, but it also introduces second-order computation and utility-function design choices. Together, these methods show that the gradient family is moving from simple sensitivity toward more principled attribution.

4.2 Transformer梯度及相关性解释4.2 Transformer gradient and relevance explanations

Transformer 解释需要与 CNN 解释不同的解释模型。在 CNN 中，空间证据自然地组织在特征图中。在视觉转换器中，证据流经补丁标记、类标记、残差连接、注意力头，有时还流经跨模式注意力。因此，朴素的注意力图并不能自动成为一种解释。注意力表明令牌如何交换信息，但它本身并不表明哪些令牌与最终决策相关。该组中的两篇 Transformer 论文很重要，因为它们明确超越了注意力可视化，并将 Transformer 解释视为相关性传播问题。Transformer explanations require a different interpretation model from CNN explanations. In CNNs, spatial evidence is naturally organized in feature maps. In vision transformers, evidence flows through patch tokens, class tokens, residual connections, attention heads, and sometimes cross-modal attention. A naive attention map is therefore not automatically an explanation. Attention indicates how tokens exchange information, but it does not by itself show which tokens are relevant to the final decision. 5.1 无梯度和基于扰动的CNN方法5.1 Gradient-free and perturbation-based CNN methods

Score-CAM 是一个转折点，因为它消除了对反向传播梯度的依赖。它使用激活图作为掩模，通过模型转发掩模图像，并使用目标类置信度作为通道权重[8]。这通常会提供干净的地图并通过健全性检查，但它很昂贵，因为许多通道可能需要单独的前向传递。 Ablation-CAM 通过测量删除特征图时目标分数的变化程度来回答相关问题 [9]。其概念优势是直接边际贡献；其成本是重复消融。 Ablation-CAM++ 通过递归地对激活图进行分组来降低这种成本，保留消融思想，同时提高时间效率 [19]。Score-CAM was a turning point because it removed the dependence on backpropagated gradients. It uses activation maps as masks, forwards masked images through the model, and uses the target-class confidence as the channel weight [8]. This often gives clean maps and passes sanity checks, but it is expensive because a separate forward pass may be needed for many channels. Ablation-CAM answers a related question by measuring how much the target score changes when a feature map is removed [9]. Its conceptual advantage is direct marginal contribution; its cost is repeated ablation. Ablation-CAM++ reduces this cost by grouping activation maps recursively, preserving the ablation idea while making it more time efficient [19].

Eigen-CAM 使用学习到的特征表示的主要组成部分，而不是特定于类别的梯度或分数 [21]。当密集分类器层失败时，这使得它变得简单、与类无关且稳健，但它可能会失去明确的类辨别能力。 BBAM 是不同的，因为它使用经过训练的目标检测器并找到保留检测器行为的边界框内的最小图像区域 [22]。它对于弱监督语义和带有框标签的实例分割很有用，但它是特定于检测器的而不是通用分类器解释。 AD-CAM、Cluster-CAM、CAPE 和 ReciproCAM 都响应相同的压力：无梯度方法如何才能更清晰而不变得太慢？ AD-CAM 使用轻量级空间特征掩模[36]。 Cluster-CAM 对特征图进行聚类，以减少前向传递的数量，并结合认知基图和认知剪刀图 [38]。 CAPE 将 CAM 重新表述为概率集合，以便可以在不同类别之间有意义地比较区域贡献 [39]。 ReciproCAM 在空间上扰乱中间特征图，并报告比 Score-CAM 更快的运行时间，同时保持强大的 ADCC 性能 [40]。Eigen-CAM uses principal components of learned feature representations instead of class-specific gradients or scores [21]. This makes it simple, class-independent, and robust when dense classifier layers fail, but it can lose explicit class discrimination. BBAM is different because it uses a trained object detector and finds the smallest image regions inside a bounding box that preserve detector behavior [22]. It is useful for weakly supervised semantic and instance segmentation with box labels, but it is detector-specific rather than a generic classifier explanation. AD-CAM, Cluster-CAM, CAPE, and ReciproCAM all respond to the same pressure: how can a gradient-free method be clearer without becoming too slow? AD-CAM uses lightweight spatial feature masks [36]. Cluster-CAM clusters feature maps to reduce the number of forward passes and combines cognition-base and cognition-scissors maps [38]. CAPE reformulates CAM as a probabilistic ensemble so that regional contributions can be meaningfully compared across classes [39]. ReciproCAM perturbs intermediate feature maps spatially and reports much faster runtime than Score-CAM while preserving strong ADCC performance [40].

ScoreCAM++ 改进了 Score-CAM 本身。它认为最小-最大标准化可以隐藏高优先级和低优先级激活值之间的差异。通过使用更强的激活函数（尤其是 tanh）对激活图进行门控，ScoreCAM++ 可以更清晰地分离重要区域和不重要区域 [51]。图 5 显示了 ScoreCAM++ 报告的 ImageNet / VGG-19 比较。该方法大幅降低了平均下降并增加了相对于 Score-CAM 和梯度基线的置信度。结果支持了一个更广泛的教训：即使归因系列保持不变，正常化和门控也会极大地影响忠诚度。ScoreCAM++ improves Score-CAM itself. It argues that min-max normalization can hide the difference between high- and low-priority activation values. By gating activation maps with a stronger activation function, especially tanh, ScoreCAM++ separates important and unimportant regions more clearly [51]. Figure 5 shows the ImageNet / VGG-19 comparison reported by ScoreCAM++. The method sharply lowers Average Drop and increases confidence relative to Score-CAM and gradient baselines. The result supports a broader lesson: even when the attribution family stays the same, normalization and gating can substantially affect faithfulness.

5.2 混合、因果和弱监督方法5.2 Hybrid, causal, and weakly supervised methods

混合 CAM 方法通常使用解释作为训练信号。 SEAM 添加了自我监督等方差：当输入变换时，CAM 应该一致地变换 [11]。其像素相关模块通过相似的邻居进一步细化像素，减少激活不足和过度激活。 AdvCAM 采用不同的路线，通过反对抗性地操纵输入，使最初被分类器忽略的区域参与到后来的归因中 [23]。 C2AM 使用对比学习从未标记的数据生成与类别无关的激活图，在使用前景和背景表示来细化特定于类别的 CAM 之前将其分离[25]。Hybrid CAM methods often use explanations as training signals. SEAM adds self-supervised equivariance: CAMs should transform consistently when the input is transformed [11]. Its pixel correlation module further refines pixels by similar neighbors, reducing under-activation and over-activation. AdvCAM takes a different route by anti-adversarially manipulating the input so that regions initially ignored by the classifier become involved in later attributions [23]. C2AM uses contrastive learning to generate class-agnostic activation maps from unlabeled data, separating foreground and background representations before using them to refine class-specific CAMs [25].

因果和偏见感知方法解决了一个更深层次的问题：CAM 可能忠实于错误的原因。 CI-CAM 使用因果干预来减少 WSOL 中的对象上下文纠缠，特别是当对象与鸟和树枝或鸭子和水等背景同时出现时 [45]。 C-CAM 将这一想法应用于医学 WSSS，其中器官共存和模糊的边界使得普通 CAM 不可靠；它对类别因果关系和解剖因果关系链进行建模，并报告了 DSC 在 ProMRI、ACDC 和 CHAOS 上的显着改进 [26]。 Debiased-CAM 研究图像扰动偏差，例如模糊、色温和日/夜变化。它训练具有辅助解释和偏差级别预测的多输入、多任务模型，以便解释更接近无偏差场景[44]。这些方法很重要，因为它们将目标从制作更清晰的热图转变为制作正确的热图。Causal and bias-aware methods address a deeper problem: a CAM can be faithful to a bad reason. CI-CAM uses causal intervention to reduce object-context entanglement in WSOL, especially when objects co-occur with backgrounds such as birds and branches or ducks and water [45]. C-CAM adapts this idea to medical WSSS, where organ co-occurrence and ambiguous boundaries make ordinary CAMs unreliable; it models categorycausality and anatomy-causality chains and reports strong DSC improvements on ProMRI, ACDC, and CHAOS [26]. Debiased-CAM studies image perturbation biases such as blur, color temperature, and day/night changes. It trains a multi-input, multi-task model with auxiliary explanation and bias-level prediction so that explanations remain closer to the unbiased scene [44]. These methods are important because they shift the goal from making a sharper heatmap to making the right heatmap.

其他混合方法侧重于密集预测。 PCAA 引入了用于语义分割的 Partial CAM，并使用局部和全局类级表示来建模像素到类的关系 [29]。 RPIM 从超像素和初始响应构建前景区域，然后使用区域内集成和区域间扩散来提高一致性[46]。 OLM 在线细化低级特征激活图，以生成紧凑且阈值鲁棒的定位图 [24]。这些论文表明 CAM 不仅仅是解释性的产物；而且在 WSSS 和 WSOL 中，它们成为训练数据。Other hybrid methods focus on dense prediction. PCAA introduces Partial CAM for semantic segmentation and uses local and global class-level representations to model pixel-to-class relations [29]. RPIM builds foreground regions from superpixels and initial responses, then uses intra-region integration and inter-region spreading to improve consistency [46]. OLM refines low-level feature activation maps online to produce compact and threshold-robust localization maps [24]. These papers show that CAMs are not merely explanatory artifacts; in WSSS and WSOL they become training data.

CALM [14] 通过将归因机制嵌入到训练过程中，采取了与事后 CAM 不同的路线。它不是仅在分类后生成热图，而是引入了一个表示识别线索的空间位置的潜在变量，并通过期望最大化过程对其进行优化。这使得归因图成为模型学习目标的一部分，这有助于分类器学习更多本地化和有辨别力的视觉证据。它的局限性在于它不是纯粹的事后方法并且需要修改训练程序。CALM [14] takes a different route from post-hoc CAMs by embedding the attribution mechanism into the training process. Instead of generating a heatmap only after classification, it introduces a latent variable that represents the spatial location of the recognition cue and optimizes it with an expectation-maximization procedure. This makes the attribution map part of the model’s learning objective, which helps the classifier learn more localized and discriminative visual evidence. Its limitation is that it is not a purely post-hoc method and requires a modified training procedure.

5.3 高分辨率细粒度方法5.3 High-resolution and fine-grained methods

高分辨率 CAM 方法解决了最终层激活图的空间粗糙度问题。 Augmented GradCAM [12] 从同一图像的转换副本生成多个低分辨率 Grad-CAM 地图，并将它们组合成超分辨率式热图。 Augmented Score-CAM [20] 将类似的增强思想应用于 Score-CAM，并在基于 ImageNet 的评估中报告了比原始 Score-CAM 更好的人类偏好、更低的平均下降、更高的平均增加和更好的 IoU。 F-CAM [18] 将可训练解码器附加到分类器，并使用前景/背景样本加上图像先验来生成全分辨率 CAM。这改善了边界，但也使得该方法不那么纯粹事后，因为解码器必须进行微调。 LayerCAM [16] 是最有影响力的高分辨率变体之一。它在各个空间位置使用正梯度，并且可以从不同的 CNN 层生成可靠的 CAM。浅层提供精细的细节，而更深的层提供语义类别证据。通过融合这些贴图，与单层 CAM 相比，LayerCAM 提高了 WSSS 和 WSOL 质量。 OLM [24] 也使用低级特征信息，但它学习在线激活图生成器和评估器。目标是生成紧凑且阈值鲁棒的图，而不是稀疏的判别图块。 Poly-CAM [37] 随后将前面和后面的层结合起来，生成更高分辨率的图，在插入删除忠实度方面保持竞争力。High-resolution CAM methods address the spatial coarseness of final-layer activation maps. Augmented GradCAM [12] generates multiple low-resolution Grad-CAM maps from transformed copies of the same image and combines them into a super-resolution-style heatmap. Augmented Score-CAM [20] applies a similar augmentation idea to Score-CAM and reports better human preference, lower Average Drop, higher Average Increase, and better IoU than the original Score-CAM on ImageNet-based evaluations. F-CAM [18] attaches a trainable decoder to a classifier and uses foreground/background samples plus image priors to produce fullresolution CAMs. This improves boundaries, but it also makes the method less purely post-hoc because the decoder must be fine-tuned. LayerCAM [16] is one of the most influential high-resolution variants. It uses positive gradients at individual spatial locations and can generate reliable CAMs from different CNN layers. Shallow layers provide fine detail, while deeper layers provide semantic class evidence. By fusing these maps, LayerCAM improves WSSS and WSOL quality compared with single-layer CAMs. OLM [24] also uses low-level feature information, but it learns an online activation-map generator and evaluator. The goal is to produce a compact and threshold-robust map rather than a sparse discriminative patch. Poly-CAM [37] later combines earlier and later layers to produce higher-resolution maps that remain competitive on insertion-deletion faithfulness.

RPIM [46]引入了基于区域的细化机制。它首先根据超像素和初始 CAM 响应构建前景区域，然后使用区域内集成和区域间扩散来使区域内和相关区域之间的像素共享更一致的激活。这对于 WSSS 很有用，因为像素级伪标签需要连贯的对象区域而不是孤立的峰值。 GFR-CAM [52] 使用 Gram-Schmidt 正交化来生成正交解释组件的层次结构。与专注于一种主要解释的基于 PCA 的方法不同，GFR-CAM 可以揭示次要对象或语义部分，从而减少解释性的狭隘视野。 Finer-CAM 做出了一个不同但非常重要的观察：CAM 在细粒度识别中经常失败，因为它解释了支持目标类的内容，包括与相似类共享的特征。 Finer-CAM 相反，将目标类与相似的参考类进行比较，并解释 logit 差异 [49]。图 6 显示，这种基于比较的包装器提高了 GradCAM、LayerCAM 和 Score-CAM 的 CUB 本地化分数。实际的信息很简单：对于细粒度的解释，问题通常不应该是“为什么是这个类？”但是“为什么是这个类而不是最接近的替代类？” 图 6 显示，当使用和不使用 Finer-CAM 目标评估相同的 CAM 主干时，这种比较改进了 CUB-200 和 Cars 上的定位。剩下的挑战是参考选择：当参考类真正具有视觉竞争力时，该方法最有效。RPIM [46] introduces a region-based refinement mechanism. It first builds foreground regions from superpixels and initial CAM responses, then uses intra-region integration and inter-region spreading to make pixels inside a region and across related regions share more consistent activation. This is useful for WSSS because pixel-level pseudo-labels need coherent object regions rather than isolated peaks. GFR-CAM [52] uses Gram-Schmidt orthogonalization to generate a hierarchy of orthogonal explanation components. Unlike PCA-based approaches that focus on one dominant explanation, GFR-CAM can reveal secondary objects or semantic parts, reducing explanatory tunnel vision. Finer-CAM makes a different but very important observation: CAM often fails in finegrained recognition because it explains what supports the target class, including features shared with similar classes. Finer-CAM instead compares the target class with similar reference classes and explains the logit difference [49]. Figure 6 shows that this comparison-based wrapper improves CUB localization scores for GradCAM, LayerCAM, and Score-CAM. The practical message is simple: for fine-grained explanations, the question should often be not 'why this class?' but 'why this class rather than the closest alternative?' Figure 6 shows that this comparison improves localization on CUB-200 and Cars when the same CAM backbone is evaluated with and without the Finer-CAM target. The remaining challenge is reference selection: the method is most effective when the reference class is truly visually competitive.

5.4 代币级和基础模型时代的 CAM5.4 Token-level and foundation-model-era CAMs

TS-CAM 使用视觉 Transformer 的自注意力机制来克服 CNN CAM 的局部感受野限制 [31]。它将标记语义与注意力图结合起来，并在 CUB-200-2011 上报告了巨大的 Top-1 本地化增益。 MCTformer 通过使用多个类标记将这一想法扩展到 WSSS，因此类到补丁的注意力可以生成特定于类的定位图 [30]。 CTI 在图像内部和图像之间注入类标记，并添加背景标记以减少误报 [41]。 Prompt-CAM 为预训练的 ViT 学习特定于类别的提示，通过提示查询注意力使细粒度特征可见 [48]。 TransCAM [34] 通过将卷积特征图与变压器补丁标记对齐，将基于 CNN 的 CAM 扩展到混合 CNN-Transformer 模型。它将多级特征图与类标记注意力集成在一起，生成适用于 WSOL 和细粒度对象定位的高分辨率标记感知 CAM。 TransCAM 展示了在 CUB 和 Cars 数据集上改进的本地化性能，同时保持与预训练 Transformer 的兼容性。TS-CAM uses the self-attention mechanism of visual transformers to overcome the local-receptive-field limitation of CNN CAMs [31]. It couples token semantics with attention maps and reports a large Top-1 localization gain on CUB-200-2011. MCTformer extends this idea to WSSS by using multiple class tokens, so class-to-patch attention can generate class-specific localization maps [30]. CTI infuses class tokens within and across images and adds a background token to reduce false positives [41]. Prompt-CAM learns class-specific prompts for a pretrained ViT, making fine-grained traits visible through prompt-query attention [48]. TransCAM [34] extends CNN-based CAMs to hybrid CNN-Transformer models by aligning convolutional feature maps with transformer patch tokens. It integrates multi-level feature maps with class-token attention to produce high-resolution tokenaware CAMs suitable for WSOL and fine-grained object localization. TransCAM demonstrates improved localization performance on CUB and Cars datasets while maintaining compatibility with pre-trained transformers.

基础模型方法拓宽了目标空间。 gScoreCAM 通过仅使用梯度来选择顶部通道和 Score-CAM 式的前向分数来对它们进行加权来解释 CLIP，从而将 Score-CAM 的 CLIP 运行时间减少约八倍，同时保留强大的对象定位 [47]。图 7 显示了报告的 COCO BoxAcc 和运行时权衡。 S2C 在训练期间通过 SAM 片段对比和基于 CAM 的提示将 SAM 知识传输给分类器 [42]。 DINO 语义引导器通过在 DINO 自注意力亲和图上传播 CAM 种子来构建类感知亲和区域图 [43]。 DiffCAM 通过将目标示例的特征分布与参考示例进行比较来解释目标示例，而不是依赖决策边界梯度 [50]。 MetaCAM 通过 top-k 共识和自适应阈值结合了多种 CAM 方法，表明整体一致性可以优于单个图 [54]。Foundation-model methods broaden the target space. gScoreCAM explains CLIP by using gradients only to select the top channels and Score-CAM-style forward scores to weight them, reducing Score-CAM's CLIP runtime by about eight times while retaining strong object localization [47]. Figure 7 shows the reported COCO BoxAcc and runtime trade-off. S2C transfers SAM knowledge to the classifier during training through SAM-segment contrasting and CAM-based prompting [42]. The DINO semantic guider builds a class-aware affinity region map by propagating CAM seeds over DINO self-attention affinity graphs [43]. DiffCAM explains a target example by comparing its feature distribution with reference examples rather than relying on decision-boundary gradients [50]. MetaCAM combines multiple CAM methods through top-k consensus and adaptive thresholding, showing that ensemble agreement can outperform individual maps [54].

7. 基于模型和架构感知的 CAM 方法7. Model-based and Architecture-aware CAM Methods

基于模型和架构感知的方法不会将 CAM 视为纯粹的事后热图。他们修改训练、池化、擦除、指导、注意力或特定于类的原型，以便模型本身变得更加本地化。这些方法与第 6 节分开审查，因为它们的数字通常反映不同的学习流程，而不是直接的事后解释算法。Model-based and architecture-aware methods do not treat CAM as a purely post-hoc heatmap. They modify training, pooling, erasing, guidance, attention, or class-specific prototypes so that the model itself becomes more localizable. These methods are reviewed separately from Section 6 because their numbers often reflect a different learning pipeline rather than a direct post-hoc explanation algorithm.

7.1 CNN 特定的定位机制7.1 CNN-specific localization mechanisms

原始的 CAM 方法 [1] 是架构感知的，因为它依赖于全局平均池化和线性分类器。这种设计保留了最后一个卷积图的空间意义，并且可以将类权重投影回图像区域。 Hide-and-Seek [4] 通过随机隐藏补丁来修改训练图像。当最具辨别力的部分被隐藏时，模型被迫使用辨别力较小的对象部分。 ACoL [5] 在特征图中使用两个分类器和对抗性擦除：一个分支找到有区别的区域，另一个分支在这些区域被抑制后学习互补区域。 SPG[6]将高置信度注意力区域转变为自制的前景/背景引导掩模，在分类训练过程中逐渐添加空间监督。 ADL [7] 使用基于注意力的 dropout 层，有时会删除最具辨别力的区域，有时会突出显示信息丰富的区域，从而平衡定位完整性和识别准确性。The original CAM method [1] is architecture-aware because it depends on global average pooling followed by a linear classifier. This design preserves the spatial meaning of the last convolutional maps and makes it possible to project class weights back to image regions. Hide-and-Seek [4] modifies the training image by randomly hiding patches. The model is forced to use less discriminative object parts when the most discriminative part is hidden. ACoL [5] uses two classifiers and adversarial erasing inside the feature map: one branch finds discriminative regions, and the other branch learns complementary regions after those regions are suppressed. SPG [6] turns high-confidence attention regions into self-produced foreground/background guidance masks, gradually adding spatial supervision during classification training. ADL [7] uses an attention-based dropout layer that sometimes erases the most discriminative region and sometimes highlights informative regions, balancing localization completeness and recognition accuracy.

Rethinking CAM [10] 分析了标准 WSOL 管道，并确定了定位不良的三个未被充分认识的原因：全局平均池可能会过分强调激活区域较小的通道，负权重可能会抑制真实对象区域，并且基于最大值的阈值可能不稳定。它提出了阈值平均Rethinking CAM [10] analyzes the standard WSOL pipeline and identifies three underappreciated causes of poor localization: global average pooling can overemphasize channels with small activation areas, negative weights can suppress true object regions, and max-based thresholding can be unstable. It proposes thresholded average

池化、负权重限制和百分位数阈值。 CREAM [27] 通过对前景和背景激活分布进行建模来解决不完整的定位问题。它学习特定于类的上下文嵌入，然后通过高斯混合式估计执行类重新激活。 LPCAM [35]通过从非区分对象部分中提取局部原型来解决区分特征问题。它不是仅使用分类器权重，而是对对象类的未池化局部特征进行聚类，并将新图像与这些原型进行匹配，涵盖头部、身体和腿部等对象部分。pooling, negative weight clamping, and percentile thresholding. CREAM [27] addresses incomplete localization by modeling foreground and background activation distributions. It learns class-specific context embeddings and then performs class re-activation through a Gaussian-mixture-style estimation. LPCAM [35] attacks the discriminative-feature problem by extracting local prototypes from non-discriminative object parts. Instead of using only classifier weights, it clusters unpooled local features for an object class and matches new images to those prototypes, covering object parts such as head, body, and legs.

7.2 变压器和令牌感知机制7.2 Transformer and token-aware mechanisms

尽管在第 5 节中回顾了令牌级方法，但它们也是架构感知的，因为它们利用了转换器的内部结构。 TS-CAM [31] 使用远程自注意力来减少部分激活。 MCTformer [30] 引入了多个类标记，以便不同的类到补丁注意力可以生成类特定映射。 CTI [41] 注入来自同一图像和跨图像视图的类标记，以提高全局局部一致性和类特异性。 Prompt-CAM [48] 为预先训练的 ViT 学习特定于类别的提示，使注意力头揭示细粒度的特征，而不仅仅是整个对象。这些方法表明，变压器时代将解释单元从卷积通道更改为令牌交互。Although token-level methods were reviewed in Section 5, they are also architecture-aware because they exploit the internal structure of transformers. TS-CAM [31] uses long-range self-attention to reduce partial activation. MCTformer [30] introduces multiple class tokens so that different class-to-patch attentions can produce classspecific maps. CTI [41] infuses class tokens from same-image and cross-image views to improve global-local consistency and class specificity. Prompt-CAM [48] learns class-specific prompts for a pretrained ViT, making the attention heads reveal fine-grained traits rather than only the whole object. These methods show that the transformer era changes the unit of explanation from convolutional channels to token interactions.

8. 比较讨论8. Comparative Discussion

从语料库中得到的第一个教训是，CAM 风格的方法现在可以回答几个不同的问题。 Grad-CAM 询问哪些特征图本地支持分数 [2]。 Score-CAM 询问哪些激活掩码在前向评估下保留分数 [8]。 Finer-CAM 询问哪些区域将一个类别与其最接近的替代类别区分开来 [49]。 FAM 询问图像的哪一部分有助于表示而不是类别标签 [28]。 SAM-和The first lesson from the corpus is that CAM-style methods now answer several different questions. Grad-CAM asks which feature maps locally support a score [2]. Score-CAM asks which activation masks preserve the score under forward evaluation [8]. Finer-CAM asks which regions distinguish one class from its nearest alternatives [49]. FAM asks what part of an image contributes to a representation rather than to a class label [28]. SAM- and

DINO 辅助方法询问外部预训练结构如何改进弱监督的 CAM 种子 [42]、[43]。这些是相关但不相同的解释问题。DINO-assisted methods ask how external pretrained structure can improve weakly supervised CAM seeds [42], [43]. These are related but not identical explanation problems.

第二个教训是，忠诚度和本地化不应混为一谈。如果模型实际上依赖于背景上下文，则地图可以与对象重叠，但仍然对模型不忠实。相反，忠实的地图可能会揭示出不需要的捷径。这就是为什么因果方法和去偏方法很重要。 CI-CAM、C-CAM 和 Debiased-CAM 表明，解释的质量不仅取决于热图公式，还取决于数据的因果结构和偏差条件 [26]、[44]、[45]。The second lesson is that faithfulness and localization should not be conflated. A map can overlap an object and still be unfaithful to the model if the model actually relied on background context. Conversely, a faithful map may reveal an unwanted shortcut. This is why causal and debiasing methods are important. CI-CAM, C-CAM, and Debiased-CAM show that the quality of an explanation depends not only on the heatmap formula but also on the causal structure and bias conditions of the data [26], [44], [45].

第三个教训是解析必须在语义上进行控制。 LayerCAM、F-CAM、Poly-CAM、RPIM 和 GFR-CAM 改善空间细节 [16]、[18]、[37]、[46]、[52]。然而，高分辨率地图并不一定是更好的解释。如果目标分数宽泛或混乱，更高的分辨率可能只是更详细地揭示错误的证据。 Finer-CAM 很有价值，因为它将目标改变为对比问题，使得高分辨率细节在细粒度识别中更有意义[49]。The third lesson is that resolution must be controlled semantically. LayerCAM, F-CAM, Poly-CAM, RPIM, and GFR-CAM improve spatial detail [16], [18], [37], [46], [52]. However, a high-resolution map is not automatically a better explanation. If the target score is broad or confounded, higher resolution may simply reveal the wrong evidence in greater detail. Finer-CAM is valuable because it changes the target to a contrastive question, making high-resolution detail more meaningful in fine-grained recognition [49].

第四个教训是基础模型使解释所有权变得复杂。如果 SAM 改进了 CAM，最终的地图部分反映了 SAM 的分割先验 [42]。如果 DINO 亲和力传播 CAM 种子，最终的伪标签部分反映了 DINO 的自我监督表示 [43]。如果用提示来解释 CLIP，则热图取决于该提示的措辞和嵌入 [47]。因此，未来的 CAM 论文不仅应该报告热图方法，还应该报告所有外部先验和提示的来源。The fourth lesson is that foundation models complicate explanation ownership. If SAM improves CAMs, the final map partly reflects SAM's segmentation prior [42]. If DINO affinities spread CAM seeds, the final pseudo-label partly reflects DINO's self-supervised representation [43]. If CLIP is explained with a prompt, the heatmap depends on the wording and embedding of that prompt [47]. Future CAM papers should therefore report not only the heatmap method but also the source of all external priors and prompts.

9. 开放的挑战和未来的方向9. Open Challenges and Future Directions

第一个挑战是标准化评估。许多 CAM 论文使用不同的目标层、输入大小、阈值、扰动基线和后处理。未来的论文应该报告一个最小的评估卡：模型和层、目标定义、标准化、阈值、前向和后向传递的数量、是否使用 CRF/SAM/显着性先验，以及计算了哪些指标。这将使跨论文比较更加可靠。A first challenge is standardized evaluation. Many CAM papers use different target layers, input sizes, thresholds, perturbation baselines, and post-processing. Future papers should report a minimal evaluation card: model and layer, target definition, normalization, thresholding, number of forward and backward passes, whether CRF/SAM/saliency priors were used, and which metrics were computed. This would make cross-paper comparison more reliable.

第二个挑战是因果忠诚度。混杂在自然图像中很常见，而医学图像通常包含解剖学共现。 CI-CAM 和 C-CAM 提供了 CAM 风格方法中因果推理的早期示例 [26]、[45]。未来的工作应该结合干预数据集、反事实图像编辑和因果指标来测试突出的证据对于模型决策是否是必要的或仅仅与其相关。A second challenge is causal faithfulness. Confounding is common in natural images, and medical images often contain anatomical co-occurrence. CI-CAM and C-CAM provide early examples of causal reasoning in CAMstyle methods [26], [45]. Future work should combine interventional datasets, counterfactual image editing, and causal metrics to test whether highlighted evidence is necessary for the model decision or merely correlated with it.

第三个挑战是有效的无梯度解释。 Score-CAM 和 Ablation-CAM 很有吸引力，因为它们避免了不稳定的梯度，但它们的成本限制了部署 [8]、[9]。 ReciproCAM、Cluster-CAM、AD-CAM 和 Ablation-CAM++ 表明，结构化扰动、分组和特征级掩蔽可以降低这种成本 [19]、[36]、[38]、[40]。一个有前途的方向是自适应解释：当快速梯度可靠时使用快速梯度，仅当不确定性或不一致很高时才切换到扰动。A third challenge is efficient gradient-free explanation. Score-CAM and Ablation-CAM are attractive because they avoid unstable gradients, but their cost limits deployment [8], [9]. ReciproCAM, Cluster-CAM, AD-CAM, and Ablation-CAM++ show that structured perturbation, grouping, and feature-level masking can reduce this cost [19], [36], [38], [40]. A promising direction is adaptive explanation: use fast gradients when they are reliable, and switch to perturbation only when uncertainty or inconsistency is high.

第四个挑战是基础模型的即时和参考敏感性。 Finer-CAM 取决于参考类，gScoreCAM 取决于提示条件 CLIP 分数，DiffCAM 取决于参考数据分布 [47]、[49]、[50]。未来的评估应包括即时敏感性、参考类敏感性和参考集敏感性作为标准稳健性测试。A fourth challenge is prompt and reference sensitivity in foundation models. Finer-CAM depends on the reference class, gScoreCAM depends on prompt-conditioned CLIP scores, and DiffCAM depends on reference data distributions [47], [49], [50]. Future evaluations should include prompt sensitivity, reference-class sensitivity, and reference-set sensitivity as standard robustness tests.

第五个挑战是人工验证。 Grad-CAM 和 Debiased-CAM 的人体研究表明，解释可以帮助用户校准信任并提高任务绩效 [2]、[44]。然而，人类的偏好不应该是唯一的标准，因为视觉上令人愉悦的地图仍然可能不忠实。未来的工作应该将以人为本的评估与删除/插入、健全性检查、因果干预和任务结果结合起来。A fifth challenge is human validation. Human studies in Grad-CAM and Debiased-CAM show that explanations can help users calibrate trust and improve task performance [2], [44]. Yet human preference should not be the only criterion because visually pleasing maps can still be unfaithful. Future work should combine human-centered evaluation with deletion/insertion, sanity checks, causal interventions, and task outcomes.

10. 结论10. Conclusion

CAM 风格的解释已经从简单的 CNN 定位机制发展成为可解释计算机视觉的广泛方法论家族。最初的 CAM 公式表明，分类器可以通过全局平均池来揭示判别区域 [1]。 Grad-CAM 使这一想法得到广泛应用 [2]。后来的工作改进了导数，避免了梯度，改进了分辨率，使用了因果和去偏约束，引入了令牌级解释，并合并了基础模型先验。CAM-style explanation has evolved from a simple CNN localization mechanism into a broad methodological family for explainable computer vision. The original CAM formulation showed that a classifier can reveal discriminative regions through global average pooling [1]. Grad-CAM made this idea broadly applicable [2]. Later work improved derivatives, avoided gradients, refined resolution, used causal and debiasing constraints, introduced token-level explanations, and incorporated foundation-model priors.

本次审查的主要结论是 CAM 不应被视为可互换的热图。每种方法都以特定的技术机制回答特定的解释性问题。快速调试工具、忠实的事后解释、密集的伪标签生成器、细粒度的特征定位器和 CLIP 提示解释The main conclusion of this review is that CAMs should not be treated as interchangeable heatmaps. Each method answers a specific explanatory question with a specific technical mechanism. A fast-debugging tool, a faithful post-hoc explanation, a dense pseudo-label generator, a fine-grained trait localizer, and a CLIP prompt explanation

是相关但不同的对象。因此，严格的 CAM 研究应该报告所解释的目标、证据来源、归因机制、评估协议、计算成本和解释的局限性。这种以方法为中心的观点对于构建更可靠、更有用的下一代视觉解释至关重要。are related but different objects. A rigorous CAM study should therefore report the target being explained, the evidence source, the attribution mechanism, the evaluation protocol, the computational cost, and the limitations of the explanation. This method-centered view is essential for building a more reliable and useful next generation of visual explanations.

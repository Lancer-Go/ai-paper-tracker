TEPA：撤销冲突鲁棒语言智能体的陈旧记忆TEPA: Revoking Stale Memories for Conflict-Robust Language Agents

Yan Zhou1, Yue Ouyang1, Kaiyang Zheng1, Suncheng Xiang2\corresponding
摘要Abstract

长期记忆使语言代理能够重用过去的事实、偏好和任务经验。持久性还造成了一个核心的可证伪性问题：当世界发生变化时，过时的记忆仍然可以检索并污染提示。我们将这种故障模式描述为Long-term memory enables language agents to reuse past facts, preferences, and task experience. Persistence also creates a central falsifiability problem: when the world changes, stale memories can remain retrievable and pollute the prompt. We characterize this failure mode as内存污染memory pollution：由新的相互矛盾的证据所取代的活跃记忆引起的退化。我们引入了 TEPA，一种可撤销的证据记忆机制，使有效性成为一种明确的记忆状态。 TEPA 将观察结果表示为关键先例，并在新证据在同一关键下与它们相矛盾时撤销有效先例，从而允许检索从当前证据中提取，同时保留已撤销的历史记录以供审计。在受控的隐藏机制漂移、真实文件支持的可执行漂移和首选项更新流中，撤销可以防止过时的活动内存在反转后保留在检索集中。在超过 50 个种子的受控漂移中，在完全反转期间，仅追加和最后写入获胜内存低于无内存（仅追加和最后写入获胜均为 0.210，无内存 0.309，TEPA 0.950），并且在实际文件执行下重现相同的模式（仅追加 0.203，无内存 0.298，TEPA 0.950）。在干净的 MemoryAgentBench SH-6k 上，TEPA 匹配强大的最后写入获胜缓存，确认当前密钥替换是单跳事实合并的决定性操作。对多跳和超长上下文 MemoryAgentBench 设置的边界测试暴露了超出事实级别有效性跟踪的检索链和上下文选择瓶颈。总之，这些结果将生命周期撤销确立为代理的核心内存操作，代理必须伪造、审核并随后重新推广不断发展的知识。: degradation caused by active memories that newer conflicting evidence has superseded. We introduce TEPA, a revocable evidence-memory mechanism that makes validity an explicit state of memory. TEPA represents observations as keyed precedents and revokes active precedents when fresh evidence contradicts them under the same key, allowing retrieval to draw from current evidence while preserving revoked history for audit. Across controlled hidden-regime drift, real file-backed executable drift, and preference-update streams, revocation prevents stale active memory from remaining in the retrieval set after reversal. In controlled drift over 50 seeds, append-only and last-write-wins memory fell below no memory during full reversal (append-only and last-write-wins both 0.210, no memory 0.309, TEPA 0.950), and the same pattern reproduced under real file execution (append-only 0.203, no memory 0.298, TEPA 0.950). On clean MemoryAgentBench SH-6k, TEPA matches a strong last-write-wins cache, confirming that current-key replacement is the decisive operation for single-hop fact consolidation. Boundary tests on multi-hop and very long-context MemoryAgentBench settings expose retrieval-chain and context-selection bottlenecks beyond fact-level validity tracking. Together, these results establish lifecycle revocation as a core memory operation for agents that must falsify, audit, and later re-promote evolving knowledge.

简介Introduction

语言代理越来越依赖长期记忆来重用用户事实、思考、任务经验和跨交互的技能Language agents increasingly rely on long-term memory to reuse user facts, reflections, task experience, and skills across interactions(Shinn et al. 2023; Zhong et al. 2024; Park et al. 2023; Zhao et al. 2024; Wang et al. 2023; Xu et al. 2026; Chhikara et al. 2025)。这种持久性很有用，但它会产生可证伪性问题。一旦被检索，记忆就会成为即时证据，而过时的证据可能会主导当前的互动。. This persistence is useful, yet it creates a falsifiability problem. Once retrieved, a memory becomes prompt evidence, and stale evidence can dominate the current interaction.

代理内存系统在增加可重用体验方面变得越来越有效。反射附加课程，MemoryBank 积累会话记忆，生成代理对记忆流进行排名，ExpeL 存储经验规则，而最近的系统增加了更丰富的记忆构建和检索Agent memory systems have become increasingly effective at growing reusable experience. Reflexion appends lessons, MemoryBank accumulates conversational memories, Generative Agents rank memory streams, ExpeL stores experiential rules, and recent systems add richer memory construction and retrieval(Shinn et al. 2023; Zhong et al. 2024; Park et al. 2023; Zhao et al. 2024; Pan et al. 2025; Xu et al. 2026; Kang et al. 2025; Yu et al. 2026)。伪造仍然不那么明确：当后来的证据与旧的记忆相矛盾时，过时的项目可能仍然可以与当前事实一起检索。. Falsification remains less explicit: when later evidence contradicts an old memory, the obsolete item may remain retrievable alongside the current fact.

It is related to concept drift(Gama et al. 2004; Bifet and Gavalda 2007; Gama et al. 2014)，但在语言代理记忆中具有独特的操作形式：陈旧的对象是插入到提示中的文本证据。我们专注于, but has a distinct operational form in language-agent memory: the stale object is textual evidence inserted into the prompt. We focus on陈旧冲突整合stale-conflict consolidation，其中稍后的观察结果会取代相同键下的早期值，并且评估会要求当前答案。此设置捕获更改的偏好、更新的实体属性和隐藏的工具机制转变，并与最近的长期记忆基准保持一致, where later observations supersede earlier values under the same key and evaluation asks for the current answer. This setting captures changed preferences, updated entity attributes, and hidden tool-regime shifts, and aligns with recent long-term memory benchmarks(Maharana et al. 2024; Wu et al. 2024; Hu et al. 2025; Wu et al. 2026)。它让我们提出一个直接的系统问题：当持久记忆本身的证据必须被伪造时，它还能保持有用吗？. It lets us pose a direct systems question: can persistent memory remain useful when its own evidence must be falsified?

TEPA converts observations into keyed precedents, assigns each precedent an explicit lifecycle state, and retrieves active precedents. When fresh evidence conflicts with an active precedent under the same key, TEPA performs a local state transition that removes the stale precedent from ordinary retrieval while keeping it available for audit. 我们的评估首先测试当过时的证据仍然有效时，记忆是否会变得比没有记忆更糟糕，然后衡量撤销是否可以防止这种失败。在受控、可执行和首选项更新过时冲突流中，仅追加和密钥缓存基线在逆转下会降级，而可撤销生命周期内存仍然保持稳健。 MemoryAgentBench SH-6k 将此机制置于标准事实整合基准中，多跳和超长上下文变体确定了检索链构建的下一个瓶颈。Our evaluation first tests whether memory can become worse than no memory when stale evidence remains active, then measures whether revocation prevents that failure. 讨论Discussion

结果指出了代理记忆的设计原则：持久记忆应该跟踪有效性和相关性。过时的证据可能与当前查询保持高度相关，从而为相似性、新近度和更大的上下文提供弱的取代信号。 TEPA 通过在检索之前删除矛盾的相同密钥先例，同时保留当前证据，在内存状态层解决了这个问题。相同的生命周期视图解释了补充中报告的内存动态：仅附加存储随着每个观察到的事实而增长，窗口化或基于新近度的内存上限按年​​龄或位置暴露，TEPA 通过将矛盾的先例移出活动集同时保留它们以供审核来保持活动内存紧凑。The results point to a design principle for agent memory: persistent memory should track validity alongside relevance. Stale evidence can remain highly relevant to the current query, giving similarity, recency, and larger context a weak signal for supersession. TEPA addresses this at the memory-state layer by removing the contradicted same-key precedent before retrieval while preserving current evidence. The same lifecycle view explains the memory dynamics reported in the supplement: append-only storage grows with every observed fact, windowed or recency-based memory caps exposure by age or position, and TEPA keeps active memory compact by moving contradicted precedents out of the active set while retaining them for audit.

MemoryAgentBench 边界结果使架构图更加清晰。撤销在单跳事实进入提示之前修复其有效性状态；多跳链构建和超长上下文选择将检索规划器视为下一个系统层。接下来是两个实际后果。机制基线充当同一后端和任务流下的共享评估器控件。归档已撤销的先例支持审计、诊断和以后的重新升级，同时使普通检索重点关注当前活跃的证据。The MemoryAgentBench boundary results sharpen the architectural picture. Revocation repairs the validity state of single-hop facts before they enter the prompt; multi-hop chain construction and very-long-context selection point to retrieval planners as the next systems layer. Two practical consequences follow. Mechanism baselines act as shared-evaluator controls under the same backend and task stream. Archiving revoked precedents supports audit, diagnosis, and later re-promotion while keeping ordinary retrieval focused on currently active evidence.

局限性Limitations

TEPA 假设有用的冲突键可以从证据中提取，这自然适合偏好槽、实体属性和工具机制记录，对于冲突关系隐式的开放式记忆来说，这是一个更难的问题。 MH-6k 和长上下文 MemoryAgentBench 结果标志着链构建、交叉密钥组合和超长上下文选择在事实级别有效性跟踪之外占据主导地位。补充密钥噪声审计直接量化了这种转变：随着结构化密钥噪声的增加，TEPA 会平稳降级，而仅追加和最后写入获胜仍接近其逆转故障模式，因为它们缺乏陈旧的隐藏机制先例的生命周期信号。TEPA assumes useful conflict keys can be extracted from evidence, a natural fit for preference slots, entity attributes, and tool-regime records, and a harder problem for open-ended memories whose conflict relation is implicit. The MH-6k and long-context MemoryAgentBench results mark where chain construction, cross-key composition, and very-long-context selection become dominant beyond fact-level validity tracking. The supplementary key-noise audit quantifies this transition directly: TEPA degrades smoothly as structured key noise increases, while append-only and last-write-wins remain near their reversal failure modes because they lack a lifecycle signal for stale hidden-regime precedents.

结论Conclusion

我们引入了 TEPA，这是一种可撤销的证据记忆机制，用于整合陈旧的冲突。当过时的冲突证据仍然处于活动状态时，仅追加内存可能会比没有内存更糟糕，而冲突键撤销可以防止受控、可执行和首选项更新设置中的这种失败。更广泛的结论是可操作的：持久内存需要明确的有效性状态。一个记忆项目可能是相关的、最近的，但一旦其值被取代，仍然是错误的；撤销会从普通检索中删除此类证据，同时保留其以供验证、审计和以后重新升级。We introduced TEPA, a revocable evidence-memory mechanism for stale-conflict consolidation. Append-only memory can become worse than no memory when stale conflicting evidence remains active, and conflict-keyed revocation prevents this failure in controlled, executable, and preference-update settings. The broader takeaway is operational: persistent memory needs an explicit validity state. A memory item can be relevant, recent, and still wrong once its value has been superseded; revocation removes such evidence from ordinary retrieval while preserving it for validation, audit, and later re-promotion.

这种观点将长期记忆重新塑造为由有效性证据和状态转换控制的可检查的生命周期。每个先例都带有关键、证据、状态和矛盾历史，允许特工解释为什么记忆是活跃的、撤销的或准备好重新提升的。This view recasts long-term memory as an inspectable lifecycle governed by validity evidence and state transitions. Each precedent carries a key, evidence, state, and contradiction history, allowing agents to explain why a memory is active, revoked, or ready for re-promotion.

检索增强和长上下文生成。Retrieval-augmented and long-context generation.

检索增强生成将外部证据带入提示或模型计算中Retrieval-augmented generation brings external evidence into the prompt or into model computation(Lewis et al. 2020; Karpukhin et al. 2020; Guu et al. 2020; Borgeaud et al. 2022; Izacard et al. 2022; Asai et al. 2024; Gao et al. 2023)。长上下文和记忆增强的 Transformer 工作扩展了可以直接或通过非参数记忆访问的证据量. These methods primarily address access: whether relevant information can be found and presented to the model. Memory pollution is different because the harmful evidence can be highly relevant but obsolete. TEPA therefore changes the active memory set before retrieval, rather than proposing a new dense retriever or longer context window.

These literatures motivate the idea that old evidence can become unreliable, but their update target is usually a classifier, parameter vector, or training distribution. TEPA instead updates the status of explicit textual memories that are candidates for prompting.

模型编辑和事实更新。Model editing and factual updates.

模型编辑方法更新模型参数或辅助编辑存储器中的事实关联Model-editing methods update factual associations in model parameters or auxiliary editing memories(Meng et al. 2022a, b; Mitchell et al. 2021, 2022)。动机与我们的动机重叠：知识可能会变得陈旧，必须进行修改。层次不同。模型编辑会更改模型或编辑器模块，而 TEPA 会更改活动内存状态并保持基本模型固定。这使得撤销变得透明且可逆，但这也意味着 TEPA 在没有检索到相关证据时无法纠正参数知识。. The motivation overlaps with ours: knowledge can become stale and must be revised. The layer differs. Model editing changes the model or an editor module, whereas TEPA changes the active memory state and leaves the base model fixed. This makes revocation transparent and reversible, but it also means that TEPA cannot correct parametric knowledge when no relevant evidence is retrieved.

These works broaden the design space of agent memory. Our experiments deliberately avoid claiming general autonomous-agent memory performance. The evidence in this paper supports a specific operation: conflict-keyed revocation for stale evidence.

并行工作越来越多地将记忆有效性视为明确的评估目标。 STALE 询问代理是否可以知道存储的记忆何时不再有效Concurrent work increasingly treats memory validity as an explicit evaluation target. These works are complementary to our study.

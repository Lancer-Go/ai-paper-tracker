内存协作MemCollab：通过对比轨迹蒸馏实现跨智能体记忆协作: Cross-Agent Memory Collaboration via Contrastive Trajectory Distillation

Yurui Chang    Yiran Wu    Qingyun Wu    Lu Lin
摘要Abstract

基于大语言模型（LLM）的代理依靠记忆机制来重用过去解决问题的经验中的知识。现有的方法通常以每个代理的方式构建内存，将存储的知识与单个模型的推理风格紧密耦合。在具有异构代理的现代部署中，自然会出现一个问题：Large language model (LLM)–based agents rely on memory mechanisms to reuse knowledge from past problem-solving experiences. Existing approaches typically construct memory in a per-agent manner, tightly coupling stored knowledge to a single model’s reasoning style. In modern deployments with heterogeneous agents, a natural question arises:单个内存系统可以在不同模型之间共享吗？can a single memory system be shared across different models?我们发现，在智能体之间天真地转移记忆通常会降低性能，因为这种记忆将任务相关的知识与智能体特定的偏见纠缠在一起。为了应对这一挑战，我们建议We found that naively transferring memory between agents often degrades performance, as such memory entangles task-relevant knowledge with agent-specific biases. To address this challenge, we propose内存协作MemCollab，一种协作记忆框架，通过对比不同代理在同一任务上生成的推理轨迹来构建与代理无关的记忆。这种对比过程提炼了抽象推理约束，捕获共享的任务级不变量，同时抑制特定于代理的工件。 我们进一步引入了一种任务感知检索机制，该机制可以限制任务类别的内存访问，确保在推理时仅使用相关约束。 数学推理和代码生成基准的实验表明, a collaborative memory framework that constructs agent-agnostic memory by contrasting reasoning trajectories generated by different agents on the same task. This contrastive process distills abstract reasoning constraints that capture shared task-level invariants while suppressing agent-specific artifacts. We further introduce a task-aware retrieval mechanism that conditions memory access on task category, ensuring that only relevant constraints are used at inference time. Experiments on mathematical reasoning and code generation benchmarks demonstrate that内存协作MemCollab持续提高不同代理（包括跨模式系列设置）的准确性和推理时间效率。我们的结果表明，协作构建的记忆可以作为不同基于 LLM 的代理的共享推理资源。consistently improves both accuracy and inference-time efficiency across diverse agents, including cross-modal-family settings. Our results show that the collaboratively constructed memory can function as a shared reasoning resource for diverse LLM-based agents.

1 简介Introduction

基于大型语言模型的代理越来越多地应用于解决需要多步骤推理和工具使用的复杂任务。尽管它们的能力很强，但它们仍然面临情景信息的局限性：从以前解决问题的轨迹中获得的知识没有持久保留，并且推理仅限于固定的上下文窗口Large Language Model-based agents are increasingly applied to solve complex tasks that require multi-step reasoning and tool use. Despite their strong capabilities, they still face the limitations of episodic information: knowledge acquired from previous problem-solving trajectories is not persistently retained, and inference is constrained to a fixed context window(laban2025llms; kang2025acon)。结果，代理可能会重复探索类似的推理策略，遇到相同的错误模式，并且无法利用先前执行的工具反馈. As a results, agent may repeatedly explore the similar reasoning strategies, encounter the same error patterns, and fail to utilize the tool feedback from prior executions(pink2025position; anthropic2025context)。为了应对这些挑战，利用记忆机制使代理能够在未来推理中解决相关任务时存储和检索可重用的信息. To address these challenges, memory mechanism is leveraged to enable agents to store and retrieve reusable information when solving related tasks in the future inference(zhong2024memorybank; xu2025mem).

最近的研究表明，增强法学硕士的记忆力可以提高推理能力。例如BoTRecent work has shown that augmenting LLMs with memory can improve reasoning ability. For example BoT(yang2024buffer)从过去的经验中提取推理模板并在推理时检索它们。大多数现有方法将内存与底层模型或代理紧密耦合：内存是根据模型自己的推理轨迹和代理自己的交互轨迹构建的，然后由同一模型或代理重用。相比之下，现代部署越来越多地涉及异构模型生态系统：具有不同模型大小或架构的多个代理在同一应用程序中运行（例如，通过模型之间的专业化、编排或路由）。这引发了一个自然的问题：distills reasoning template from past experiences and retrieves them at the inference time. Most prior approaches couple memory tightly with the underlying model or agent: the memory is constructed from that model’s own reasoning traces and the agent’s own interaction trajectories, and is then reused by the same model or agent. In contrast, modern deployments increasingly involve heterogeneous model ecosystems: multiple agents with different model sizes or architectures operating within the same application (e.g., via specialization, orchestration, or routing among models). This motivates a natural question:单个内存系统可以在不同模型之间共享吗？can a single memory system be shared across different models?

2.1 LLM代理的内存Memory for LLM Agents

记忆已成为基于 LLM 的代理的核心模块，使它们能够解决有限的上下文窗口并跨情节重用信息Memory has become a core module for LLM-based agents, enabling them to address limited context windows and reuse information across episodes(zhang2025survey; nuxoll2012enhancing)。记忆内容可以采用自由格式文本或结构化工件的形式，并且可以检索以指导代理的后续推理和工具使用. Memory content can take the form of free-form text or structured artifacts, and can be retrieved to guide subsequent reasoning and tool use by agents(ouyang2025reasoningbank; zhong2024memorybank; packer2023memgpt)现有的记忆机制包括情景记忆，用于记录交互并管理多层上下文.Existing memory mechanisms include episodic memory that records interactions and manage multi-tier context(packer2023memgpt)，长期交互记忆，支持持续回忆和更新, long-term interaction memory that supports continual recall and update(zhong2024memorybank)，以及面向推理的记忆，提取可重用的指导来支持问题解决, and reasoning oriented memory that distills reusable guidance to support problem solving(yang2024buffer; suzgun2025dynamic; ouyang2025reasoningbank)。除了内存中存储的内容类型之外，许多研究还研究内存组织和操作，包括代理链接和内存图的演化. Beyond the types of content stored in memory, many studies investigate memory organization and operations, including agentic linking and evolution of memory graphs(xu2025mem)以及基于训练的内存管理，通过强化学习学习存储、更新和检索内容, as well as training-based memory management that learns what to store, update, and retrieve through reinforcement learning(zhou2025mem1; yan2025memory; yang2025reasonflux)。虽然这些方法表现出强大的性能，但它们通常专注于改进单个代理。内存是根据代理自身的轨迹合成的，随后由同一代理消耗，从而限制了跨代理重用的指导范围。与之前的方法相比，我们的工作研究了如何构建单个内存系统以使具有不同模型大小和架构的多个代理受益。我们不是存储情景轨迹或学习特定于代理的记忆策略，而是通过对比为同一任务生成的代理轨迹来构建记忆，提取对不同代理不变的规范推理约束和错误禁止模式。这种设计的目标是可跨代理重用的可转移推理指导，这种设置在现有工作中受到的关注有限。. While these approaches demonstrate strong performance, they typically focus on improving a single agent. Memory is synthesized from an agent’s own trajectories and subsequently consumed by the same agent, thereby limiting the scope of the guidance to cross-agent reuse. In contrast to prior approaches, our work investigates how a single memory system can be constructed to benefit multiple agents with different model sizes and architectures. Rather than storing episodic traces or learning agent-specific memory policies, we construct memory by contrasting agent trajectories generated for the same task, distilling normative reasoning constraints and error-forbidden patterns that are invariant to different agents. This design targets transferable reasoning guidance that can be reused across agents, a setting which has received limited attention in existing work.

检索增强生成（RAG）扩展了法学硕士访问外部语料库的能力，并已被广泛采用，通过根据辅助检索器检索的段落调节模型输出来提高事实性和覆盖率Retrieval-augmented generation (RAG) extends LLMs with access to external corpora and has been widely adopted to improve factuality and coverage by conditioning model outputs on passages retrieved by an auxiliary retriever(lewis2020retrieval)。后续工作表明，检索源的类型和检索单元的粒度都会显着影响生成质量. Beyond unstructured text corpora(li2023classification; yan2024corrective)，检索源已扩展到半结构化, retrieval sources have been extended to semi-structured(zha2023tablegpt; luo2023augmented)和结构化数据and structured data(gaur2022iseeq; he2024g; edge2024local)，以及法学硕士自己生成或提炼的内容, as well as content generated or distilled by LLMs themselves(yu2022generate; cheng2023lift)。与此同时，先前的研究探索了不同粒度的检索，从粗粒度的单元，例如完整文档或长段落. In contrast to document-centric RAG, our method retrieves reasoning-oriented memory rather than external knowledge. We adopt a coarse-grained memory representation but perform task-level classification prior to retrieval, allowing the system to restrict the search space and reduce irrelevant or incompatible memory. This design enables precise retrieval of task-relevant reasoning guidance while avoiding the overhead and noise associated with fine-grained retrieval.

5 结论Conclusions

在这项工作中，我们研究了构建单个共享内存以支持多个基于 LLM 的代理的问题。我们证明，在智能体之间直接转移记忆是无效的，因为智能体特定的偏差和推理模式可能与可重用的知识纠缠在一起。为了应对这一挑战，我们提出了一种协作记忆框架，通过对比不同代理为同一任务生成的轨迹来合成记忆，提炼高级推理指导和错误禁止模式。跨数学和编码基准的大量实验表明，所产生的内存可以跨异构代理泛化，从而提高准确性和推理时间效率。未来的工作可能会通过选择首选轨迹并将其他轨迹视为不首选轨迹，将这种对比公式扩展到多智能体设置，从而指向可扩展到更大的交互智能体集合的共享记忆系统。In this work, we study the problem of constructing a single shared memory to support multiple LLM-based agents. We show that directly transferring memory between agents is ineffective, as agent-specific biases and reasoning patterns can be entangled with reusable knowledge. To address this challenge, we propose a collaborative memory framework that synthesizes memory by contrasting trajectories generated by different agents for the same task, distilling high-level reasoning guidance and error-forbidden patterns. Extensive experiments across mathematical and coding benchmarks demonstrate that the resulting memory generalizes across heterogeneous agents, improving both accuracy and inference-time efficiency. Future work may extend this contrastive formulation to multi-agent settings by selecting a preferred trajectory and treating others as unpreferred, pointing toward shared memory systems that scale to larger collections of interacting agents.

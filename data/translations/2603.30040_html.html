摘要Abstract

自动并行化仍然是软件工程中的一个具有挑战性的问题，特别是在识别可以在现代多核架构上安全并行执行循环的代码区域方面。传统的静态分析技术，例如依赖性分析和多面体模型，通常难以处理不规则或动态结构化的代码。在这项工作中，我们提出了一种基于 Transformer 的方法来对源代码的并行化潜力进行分类，重点关注区分独立（可并行）循环和未定义循环。我们采用 DistilBERT 使用子词标记化来处理源代码序列，使模型能够捕获上下文句法和语义模式，而无需手工制作特征。该方法使用 10 倍交叉验证和多个性能指标，在平衡数据集上进行评估，该数据集结合了综合生成的循环和手动注释的实际代码。结果显示始终如一的高性能，平均准确度高于 99%，误报率低，证明了稳健性和可靠性。与之前基于标记的方法相比，所提出的方法简化了预处理，同时提高了泛化性并保持了计算效率。这些发现凸显了轻量级 Transformer 模型在循环级别实际识别并行化机会方面的潜力。Automatic parallelization remains a challenging problem in software engineering, particularly in identifying code regions where loops can be safely executed in parallel on modern multi-core architectures. Traditional static analysis techniques, such as dependence analysis and polyhedral models, often struggle with irregular or dynamically structured code. In this work, we propose a Transformer-based approach to classify the parallelization potential of source code, focusing on distinguishing independent (parallelizable) loops from undefined ones. We adopt DistilBERT to process source code sequences using subword tokenization, enabling the model to capture contextual syntactic and semantic patterns without handcrafted features. The approach is evaluated on a balanced dataset combining synthetically generated loops and manually annotated real-world code, using 10-fold cross-validation and multiple performance metrics. Results show consistently high performance, with mean accuracy above 99% and low false positive rates, demonstrating robustness and reliability. Compared to prior token-based methods, the proposed approach simplifies preprocessing while improving generalization and maintaining computational efficiency. These findings highlight the potential of lightweight Transformer models for practical identification of parallelization opportunities at the loop level.

这项工作提出了一种基于 Transformer 的自动分类方法 源代码中的并行化潜力，重点是识别 可以安全并行化的独立循环。拟议的方法 结合了精心构建和平衡的数据集——由合成代码组成 通过进化算法生成并手动注释现实世界 示例 - 具有能够处理源代码的微调 DistilBERT 模型 直接作为文本。实验评估是通过严格的 10 倍交叉验证协议和一套全面的性能指标。This work presented a Transformer-based approach for the automatic classification of parallelization potential in source code, focusing on the identification of independent loops that can be safely parallelized. The proposed methodology combines a carefully constructed and balanced dataset—composed of synthetic codes generated via evolutionary algorithms and manually annotated real-world examples—with a fine-tuned DistilBERT model capable of processing source code directly as text. The experimental evaluation was conducted using a rigorous 10-fold cross-validation protocol and a comprehensive set of performance metrics.

结果表明，所提出的方法始终达到高 跨所有折叠的性能，具有很强的泛化能力和低 可变性。观察到较高的准确度、精确度、召回率和 F1 分数值 在测试集上，表明该模型有效地区分了 可并行和未定义的循环结构。统计分析包括 置信区间和分布可视化，进一步证实了 学习模型的稳定性和鲁棒性。The results demonstrate that the proposed approach achieves consistently high performance across all folds, with strong generalization capability and low variability. High accuracy, precision, recall, and F1-score values were observed on the test sets, indicating that the model effectively distinguishes between parallelizable and undefined loop structures. The statistical analysis, including confidence intervals and distribution visualizations, further confirms the stability and robustness of the learned models.

除了整体表现之外，该研究还强调了考虑的重要性 特定应用的评估标准。虽然验证错误被证明是有效的 为了识别具有强泛化行为的模型，分析 误报率揭示了补充见解，特别是对于场景 将不可并行化代码错误地分类为可并行化可能会 导致不良后果。所提出的方法实现的能力 极低（在某些情况下为零）的误报增强了其适用性 用于实际的代码分析上下文。Beyond overall performance, the study highlighted the importance of considering application-specific evaluation criteria. While validation error proved effective for identifying models with strong generalization behavior, the analysis of the False Positive Rate revealed complementary insights, particularly for scenarios where incorrect classification of non-parallelizable code as parallelizable may lead to undesirable consequences. The ability of the proposed approach to achieve extremely low—and in some cases zero—false positives reinforces its suitability for practical code analysis contexts.

尽管取得了这些有希望的结果，但仍应承认一些局限性。的 本研究的范围仅限于循环级分析，并未考虑 更高级的循环转换，例如融合、展开或平铺。在 此外，尽管包含真实世界的代码示例增强了 代表性，数据集仍然仅限于一组特定的编程 模式和语言。Despite these promising results, some limitations should be acknowledged. The scope of this study is restricted to loop-level analysis and does not account for more advanced loop transformations, such as fusion, unrolling, or tiling. In addition, although the inclusion of real-world code samples enhances representativeness, the dataset remains limited to a specific set of programming patterns and languages.

未来的工作将侧重于将分析扩展到更复杂的代码结构 和转换，用额外的现实世界示例扩展数据集，以及 探索将所提出的分类器集成到静态分析工具中或 开发环境。研究替代 Transformer 架构并 多语言代码表示也代表了进一步发展的有希望的方向 研究。Future work will focus on extending the analysis to more complex code structures and transformations, expanding the dataset with additional real-world examples, and exploring the integration of the proposed classifier into static analysis tools or development environments. Investigating alternative Transformer architectures and multilingual code representations also represents a promising direction for further research.

总体而言，结果表明基于 Transformer 的模型构成了可行的模型 以及自动并行电位分类的有效解决方案， 为支持并行编程提供强大且可扩展的基础 在本研究的定义范围内进行分析。Overall, the results indicate that Transformer-based models constitute a viable and effective solution for automatic parallelization potential classification, offering a robust and scalable foundation for supporting parallel programming analysis within the defined scope of this study.

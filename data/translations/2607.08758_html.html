1 简介1 Introduction

基于法学硕士的自动研究系统现在可以搜索文献、综合假设、运行实验并撰写纸质报告 [25,40,50]。现有的评估强调检索质量、事实性、写作流畅性、新颖性、工作流程能力或成对偏好[1,37,39,44,45,48,53]。这些标准留下了一个大多未经检验的更难的问题：当一项提案声称要扩展一个研究方向时，它是否继承了正确的机制，修复了正确的限制，并与其所建立的血统保持一致？图 1 推动了从以论文为中心的背景收集到以基因组为中心的谱系比较的转变。LLM-based auto-research systems now search literature, synthesize hypotheses, run experiments, and write paper-like reports [25, 40, 50]. Existing evaluations emphasize retrieval quality, factuality, writing fluency, novelty, workflow competence, or pairwise preference [1, 37, 39, 44, 45, 48, 53]. These criteria leave a harder question mostly untested: when a proposal claims to extend a research direction, does it inherit the right mechanism, repair the right limitation, and stay coherent with the lineage it builds on? 这种区别很重要，因为科学进步与话题接近程度不同。两篇论文可以共享一项任务，而无需相互继承，两篇论文在推进相同的核心机制的同时，也可以在文本上看起来很遥远。例如，YOLOv2 [30]通过锚框、批量归一化和多尺度训练修改了YOLO的[31]单次检测机制：谱系作为局部突变可见。 DETR [5] 也研究对象检测，但它用集合预测和 Transformer 架构取代了 Faster R-CNN [33] 管道。它共享任务生态，而不是基于锚的驱动机制。标题、摘要、引文边缘和嵌入往往会将这些案例模糊在一起。模型可以检索正确的论文，但仍然错过父机制或修复的限制；产生的想法可能听起来很新颖，但没有继承连贯的机制。The distinction matters because scientific progress is not the same as topical proximity. Two papers can share a task without inheriting from one another, and two papers can look textually distant while carrying the same core mechanism forward. YOLOv2 [30], for example, modifies YOLO’s [31] single-shot detection mechanism through anchor boxes, batch normalization, and multi-scale training: the lineage is visible as local mutation. DETR [5] also studies object detection, but it replaces the Faster R-CNN [33] pipeline with set prediction and a Transformer architecture. It shares the task ecology, not the anchor-based driver mechanism. Titles, abstracts, citation edges, and embeddings tend to blur these cases together. A model can retrieve the right papers and still miss the parent mechanism or repaired limitation; a generated idea can sound novel while inheriting no coherent mechanism.

IG-Bench 介于多种评估传统之间。科学谱系需要表示层和基准：仅论文级别的相关性太粗糙，而仅一代的偏好则太不受约束。IG-Bench sits between several evaluation traditions. Scientific lineage needs both a representation layer and a benchmark: paper-level relevance alone is too coarse, while generation-only preference is too unconstrained.

6 结论6 Conclusion

IG-Bench 围绕科学谱系重新构建了自动化研究评估。核心问题不仅在于一个系统是否能够编写可信的研究文本，还在于它是否能够识别、验证和扩展继承的机制，使提案成为先前工作的连贯后代。 IdeaGene 框架——类型化IG-Bench reframes automated-research evaluation around scientific lineage. The central question is not only whether a system can write plausible research text, but whether it can identify, verify, and extend the inherited mechanisms that make a proposal a coherent descendant of prior work. The IdeaGene framework—typed理念基因组Idea Genome对象、GenomeDiff 记录和进化动力学——提供了使判断精确且可审计的表示层。objects, GenomeDiff records, and evolutionary dynamics—provides the representation layer for making that judgment precise and auditable.

结果使这种区别显而易见。即使最好的系统在 IG-Exam 上也只能达到 27.3% 的准确率；工具脚手架有助于 T2 继承追踪，但几乎无法推动 T4 血统验证；结构化的沿袭上下文将系统分开，而不是统一提升它们。在 IG-Arena 中，PES 分解显示出相同的合理性-相干性差距：提案听起来很新颖，但无法保留相干下降所需的父机制或限制-增量关系。这些发现指出了一个具体的设计方向：自动研究系统需要成分验证模块，而不仅仅是更好的检索。 IG-Bench 提供了一个评估基础，用于衡量未来的自动研究系统是否可以从检索论文和生成可信文本转向验证和扩展科学谱系。The results make that distinction visible. Even the best system reaches only 27.3% exact accuracy on IG-Exam; tool scaffolds help T2 Inheritance Tracing but barely move T4 Lineage Verification; and structured lineage context separates systems rather than lifting them uniformly. In IG-Arena, PES decomposition shows the same plausibility–coherence gap: proposals can sound novel while failing to preserve the parent mechanism or limitation-delta relation needed for coherent descent. These findings point to a concrete design direction: auto-research systems need compositional verification modules, not only better retrieval. IG-Bench provides an evaluation substrate for measuring whether future auto-research systems can move from retrieving papers and producing plausible text toward verifying and extending scientific lineages.

7 局限性7 Limitations

IG-Bench 中的六种进化动力学是可审计评估的操作类别，而不是详尽的科学发展理论。真正的血统可以在同一个继承者中混合多种过渡模式； IG-Bench 分配主要驱动因素以保持注释和评估的一致性。The six evolutionary dynamics in IG-Bench are operational categories for auditable evaluation, not an exhaustive theory of scientific development. Real lineages can mix multiple transition patterns within the same successor; IG-Bench assigns primary drivers to keep annotation and evaluation consistent.

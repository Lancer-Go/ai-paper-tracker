伊艾Yi Ai

摘要Abstract

直接文本到 SQL 要求语言模型完成两项工作：解释业务问题并构建完整的关系查询。在企业模式中，即使使用错误的关系角色或聚合粒度，SQL 也可以成功执行。我们研究随机边界的替代放置。多回合规划器根据短语并从特定问题的受控选项中进行选择；图遍历、角色谓词、粒度降低、SQL 构造和确定性检查都是在代码中实现的。我们根据 ACME 保险基准上的直接 DDL 到 SQL 生成来评估此语义路径编译 (SPC) 系统。在包含 38 个问题的裁决比较集（每个问题运行 3 次）中，SPC 在 37 个问题 (97.4%) 的每次运行中都被裁决正确，而基线为 21 个问题 (55.3%)。成对的不一致是 16 个问题有利于 SPC，没有一个问题有利于基线（双面精确 McNemarDirect text-to-SQL asks a language model to do two jobs: interpret the business question and construct the complete relational query. In enterprise schemas, SQL can execute successfully while using the wrong relationship role or aggregation grain. We study an alternative placement of the stochastic boundary. A multi-turn planner grounds phrases and selects from questionspecific governed options; graph traversal, role predicates, grain lowering, SQL construction, and deterministic checks are implemented in code. We evaluate this semantic path compilation (SPC) system against direct DDL-to-SQL generation on the ACME insurance benchmark. On a 38-question adjudicated comparison set with three runs per question, SPC was adjudicated correct on every run for 37 questions (97.4%), compared with 21 (55.3%) for the baseline. The paired discordance was 16 questions in favor of SPC and none in favor of the baseline (two-sided exact McNemarp = 3.05 × 10−5）。 SPC 至少正确回答了所有 38 个问题一次，并产生了一次拒绝，并且在 114 次运行结果中没有判定错误但已执行的运行；基线在同一组中产生了 29 次判定错误，以及另外 7 次由裁判标记的纯数据巧合。严格等价敏感性分析增加了配对差异。使用 GPT-5.4 和 Gemini-3.6-Flash 进行的其他 SPC 运行显示出类似的问题级鲁棒性，尽管它们的每次运行判决工件并未保留。六个额外的基准项目保留在全项目分析中，并按故障类别单独记录。该研究支持端到端系统结果，而不是编译本身产生增益的因果关系，因为 SPC 接收到 DDL 基线所没有的受控语义工件。). SPC answered all 38 questions correctly at least once and produced one refusal and no adjudicated wrong-butexecuted run across 114 run outcomes; the baseline produced 29 adjudicated wrong runs and seven additional judge-flagged data-only coincidences on the same set. A strict-equivalence sensitivity analysis increased the paired difference. Additional SPC runs with GPT-5.4 and Gemini-3.6-Flash showed similar question-level robustness, although their per-run verdict artifacts were not preserved. Six additional benchmark items are retained in an all-item analysis and documented separately by failure class. The study supports an end-to-end systems result, not a causal claim that compilation alone produced the gain, because SPC receives governed semantic artifacts that the DDL baseline does not.

一、简介1. Introduction

生成有效的 SQL 只是企业文本转 SQL 的一部分。系统还必须选择预期的业务解释，在关系有效的路径中进行选择，绑定角色敏感的关系，并在连接和聚合之间保留粒度。这些决策中的错误通常会产生可执行的 SQL 和可信的数字。因此，一个数据库实例上的解析器有效性和一致性不足以保证这一点。Generating valid SQL is only part of enterprise text-to-SQL. A system must also select the intended business interpretation, choose among relationally valid paths, bind role-sensitive relationships, and preserve grain across joins and aggregation. Errors in these decisions often produce executable SQL and plausible numbers. Parser validity and agreement on one database instance are therefore insufficient safeguards.

语义层将其中一些工作转移到受管理的元数据中。例如，MetricFlow 在建模实体之间组合联接并确定性地生成 SQL [dbt-join-logic; DBT-2026]。在 dbt 最初的最小建模 ACME 配置上，其 2026 年研究报告语义层总体占 72.7%，直接文本到 SQL 占 64.5%；语义层回答了配置的范围内问题，但不回答其建模范围之外的问题 [dbt-2026]。以本体为中介的系统，例如 ATHENA [Saha-2016] 和 ATHENA++ [Sen-2020]，同样会在将其转换为 SQL 之前构建本体级别的解释。这些系统表明语义图遍历和确定性翻译并不新鲜。Semantic layers move some of this work into governed metadata. MetricFlow, for example, composes joins among modeled entities and generates SQL deterministically [dbt-join-logic; dbt-2026]. On dbt’s original minimally modeled ACME configuration, its 2026 study reports 72.7% overall for the Semantic Layer and 64.5% for direct text-to-SQL; the Semantic Layer answered the configured in-scope questions but not those outside its modeled scope [dbt-2026]. Ontology-mediated systems such as ATHENA [Saha-2016] and ATHENA++ [Sen-2020] likewise construct ontology-level interpretations before translating them to SQL. These systems establish that semantic graph traversal and deterministic translation are not new.

本文提出了一个更狭窄的系统问题：This paper asks a narrower systems question:当法学硕士被允许解释问题但不能编写联接、聚合结构或 SQL 时会发生什么？what happens when an LLM is allowed to interpret the question but not to author joins, aggregation structure, or SQL?图 1 显示了我们评估的边界。Figure 1 shows the boundary we evaluate.

这种区别是可操作的。该模型可以引用问题的范围，选择主题，并选择由确定性工具返回的路径不透明、不可组合的标识符。它不能命名表、列、连接谓词、角色谓词或 SQL 片段。引擎再次审查提交的计划，对其进行编译，并检查其是否存在已知的治理违规行为。被拒绝的尝试可以在仅携带拒绝原因的新对话中重试一次。The distinction is operational. The model may quote spans from the question, select a subject, and choose path-opaque, noncomposable identifiers returned by deterministic tools. It cannot name a table, column, join predicate, role predicate, or SQL fragment. The engine reviews the submitted plan again, compiles it, and checks it for known governance violations. A rejected attempt may be retried once in a fresh conversation carrying only the refusal reason.

2. 背景及相关工作2. Background and Related Work

2.1 本体介导和语义层查询2.1 Ontology-mediated and semantic-layer querying

ATHENA 通过排序解释树将自然语言映射到本体查询语言，然后将本体级查询翻译为 SQL [Saha-2016]。 ATHENA++ 将此行扩展到嵌套和聚合查询 [Sen-2020]。 Ontop 通过将 OWL 2 QL 本体上的正式 SPARQL 查询重写为 SQL 的关系映射来支持基于虚拟本体的数据访问 [Ontop-2017]。这些系统展示了本体级路径构建和确定性数据库翻译；我们的贡献并不是孤立的任何一种机制。ATHENA maps natural language to ontology query language through ranked interpretation trees and then translates the ontology-level query to SQL [Saha-2016]. ATHENA++ extends this line to nested and aggregation queries [Sen-2020]. Ontop supports virtual ontology-based data access by rewriting formal SPARQL queries over OWL 2 QL ontologies and relational mappings into SQL [Ontop-2017]. These systems demonstrate both ontology-level path construction and deterministic database translation; our contribution is not either mechanism in isolation.

商业语义层公开了相关的合同。 MetricFlow 通过建模实体组成联接，并在建模语义表面 [dbt-join-logic] 内生成 SQL。 dbt 的 ACME 研究提供了相同基准基材的外部参考 [dbt-2026]。 Rumiantsau 和 Fokeev [2604.25149] 报告了三个模型从语义上下文中获得的收益，而 Sequeda 等人。 [Sequeda] 以及 Allemang 和 Sequeda [Allemang-2024] 在此处使用的基准谱系上研究知识图谱查询和基于本体的查询检查。Commercial semantic layers expose a related contract. MetricFlow composes joins through modeled entities and generates SQL within the modeled semantic surface [dbt-join-logic]. dbt’s ACME study provides an external reference on the same benchmark substrate [dbt-2026]. 2.2 中间表示和约束生成2.2 Intermediate representations and constrained generation

IRNet 将 SemQL（模型生成的中间表示）降低为 SQL [Guo-2019]。 PICARD 通过增量 SQL 解析拒绝不可接受的延续来限制自回归解码 [Scholak-2021]。金等人。 [2606.31041]通过语义层编译语义模型查询。这些方法减少了 SQL 搜索空间或将 SQL 构造移至 IR 后面。 SPC 的不同之处在于它放置剩余模型自由度的位置：规划器可以仅选择为当前问题返回的词汇表和路由句柄，并且最终的 SQL 是接受的计划、本体、物理映射和编译器版本的确定性函数。这是系统契约中的差异，而不是声称类型化 IR 或确定性降低是新的。IRNet lowers SemQL, an intermediate representation generated by a model, into SQL [Guo-2019]. PICARD constrains autoregressive decoding by rejecting inadmissible continuations through incremental SQL parsing [Scholak-2021]. Kim et al. [2606.31041] compile a Semantic Model Query through a semantic layer. These approaches reduce the SQL search space or move SQL construction behind an IR. SPC differs in where it places the remaining model freedom: the planner may select only vocabulary and route handles returned for the current question, and the final SQL is a deterministic function of the accepted plan, ontology, physical mapping, and compiler version. This is a difference in system contract, not a claim that typed IRs or deterministic lowering are new.

2.3 粒度和聚合正确性2.3 Grain and aggregation correctness

聚合放置和可概括性是既定的数据库问题。 Yan 和 Larson [Yan-1995] 分析了围绕连接的热切聚合。 Lenz 和 Shoshani [Lenz-1997] 形式化了可概括性条件，Hurtado 和 Mendelzon [Hurtado-2001] 给出了异构多维模式的推理过程。颗粒理论 [Karayannidis-2026] 提供了颗粒传播和扇形陷阱的最新类型级解释，同时保持管道综合开放。目前的工作为 ACME 本体实现了受限编译器策略并对其进行了测量；它没有提出新的谷物一般理论。Aggregation placement and summarizability are established database problems. Yan and Larson [Yan-1995] analyze eager aggregation around joins. Lenz and Shoshani [Lenz-1997] formalize summarizability conditions, and Hurtado and Mendelzon [Hurtado-2001] give reasoning procedures for heterogeneous multidimensional schemas. Grain Theory [Karayannidis-2026] provides a recent type-level account of grain propagation and fan traps, while leaving pipeline synthesis open. The present work implements a restricted compiler policy for the ACME ontology and measures it; it does not claim a new general theory of grain.

2.4 评估和选择性可靠性2.4 Evaluation and selective reliability

单数据库执行准确性可以接受在一个实例上碰巧一致的语义上不同的查询。钟等人。 [Zhong-2020] 通过精简的数据库实例套件解决了这个问题。我们的反事实实例遵循相同的一般原则，但针对角色和多重性敏感的企业错误，而不是主张新的语义对等标准。Single-database execution accuracy can accept semantically different queries that happen to agree on one instance. Zhong et al. [Zhong-2020] address this problem with distilled suites of database instances. Our counterfactual instances follow the same general principle but target role- and multiplicity-sensitive enterprise errors rather than claiming a new semanticequivalence criterion.

可靠性工作也将弃权视为一流的结果。 TrustSQL [TrustSQL] 对错误答案的惩罚比弃权更严重，基于本体的查询检查报告明确的“我不知道”结果 [Allemang-2024]。 SQLStructEval [2604.06736] 测量执行正确的文本到 SQL 输出之间的结构变化。因此，我们分别报告回答正确、拒绝和错误但执行的情况，并评估问题级别的稳定性，而不是仅提供平均运行准确性。Reliability work also treats abstention as a first-class outcome. TrustSQL [TrustSQL] penalizes incorrect answers more heavily than abstention, and ontology-based query checking reports explicit “I don’t know” outcomes [Allemang-2024]. SQLStructEval [2604.06736] measures structural variation among execution-correct text-to-SQL outputs. We therefore report answered correctly, refused, and wrong-but-executed separately, and evaluate stability at the question level rather than presenting only mean run accuracy.

6.6 解释6.6 Interpretation

对于固定的接受计划和固定的工件，关系实现是确定性的。端到端行为并非如此：114 个 SPC 运行结果之一被拒绝，并且三轮运行范围太短，无法估计长期稳定性。因此，结果应该被解读为随机性从 SQL 构造重新定位到有界语义规划，而不是消除模型方差。For a fixed accepted plan and fixed artifacts, relational realization is deterministic. End-to-end behavior is not: one of 114 SPC run outcomes refused, and the three-run horizon is too short to estimate long-run stability. The result should therefore be read as relocation of stochasticity from SQL construction to bounded semantic planning, not elimination of model variance.

收益还伴随着大量的编写结构和实施成本。该研究并未确定有多少差异是由于语义知识、有界接口、确定性编译、重试策略或它们的相互作用造成的。它表明，完整的 SPC 系统在配对 ACME 集上的性能优于完整的 DDL 基线。The gain also comes with substantial authored structure and implementation cost. The study does not determine how much of the difference is due to the semantic knowledge, the bounded interface, deterministic compilation, the retry policy, or their interaction. It establishes that the complete SPC system outperformed the complete DDL baseline on the paired ACME set.

7. 讨论7. Discussion

编译器、解析器和检查器是在检查此基准测试时开发的。尽管它们的实现是围绕可重用​​的关系结构而不是问题标识符来组织的，但该存储库不包含对未见过的结构组合的冻结保留评估。因此，本文没有实证表明测量的准确性可以推广到 ACME 之外，或者实现工作量仅通过构建而不是工作负载来增长。保留的组成研究或第二个企业领域是未来的工作，而不是报告结果的一部分。The compiler, resolver, and checker were developed while inspecting this benchmark. Although their implementation is organized around reusable relational constructs rather than question identifiers, this repository does not contain a frozen heldout evaluation of unseen construct combinations. Accordingly, the paper makes no empirical claim that the measured accuracy generalizes beyond ACME or that implementation effort grows only by construct rather than by workload. A held-out composition study or a second enterprise domain is future work, not part of the reported result.

在此范围内，定义设计本身并不是确定性的 SQL 渲染。它是 (i) 有限的特定于问题的语义选择集、(ii) 引擎拥有的关系实现和 (iii) 显式拒绝路径的组合。实验无法估计每个组件的贡献，但运行级别结果显示了为什么组合在操作上很重要：可执行的错误结果和拒绝是不可互换的。Within this scope, the defining design is not deterministic SQL rendering by itself. It is the combination of (i) a finite question-specific semantic choice set, (ii) engine-owned relational realization, and (iii) explicit refusal paths. The experiment cannot estimate the contribution of each component, but the run-level outcomes show why the combination matters operationally: an executable wrong result and a refusal are not interchangeable.

同样的界限限制了覆盖范围。如果预期的业务构成没有通过允许的路线来表示，SPC不能仅仅因为物理表是连接的就推断或批准它。它必须拒绝查询，直到扩展语义模型或​​物理映射。That same bound limits coverage. If the intended business composition is not represented by an admissible route, SPC cannot infer or approve it merely because the physical tables are connected. It must refuse the query until the semantic model or physical mapping is extended.

反事实分析还阐明了测试数据的作用。静态规则可以命名已知的危险，但基准实例必须包含使这些危险可观察到的多重性。相反，区分数据仅表明参考可与列举的替代方案分开；他们没有确定引用捕获了预期的商业含义。The counterfactual analysis also clarifies the role of test data. Static rules can name known hazards, but a benchmark instance must contain multiplicities that make those hazards observable. Conversely, discriminating data establish only that the reference is separable from enumerated alternatives; they do not establish that the reference captures the intended business meaning.

8、实用性8. Practicality

所提出的架构将大量成本减少到开发时间：受控语义模型创作、物理映射、编译器和检查器实现、回归测试以及持续的语义治理。它不应被解释为传统语义层或文本到 SQL 系统的通用替代品。The proposed architecture moves substantial cost to development time: governed semantic-model authoring, physical mappings, compiler and checker implementation, regression testing, and ongoing semantic governance. It should not be interpreted as a universal replacement for conventional semantic-layer or text-to-SQL systems.

对于临时数据库、轻度建模领域和主要是简单的分析问题，语义上下文与直接 LLM SQL 生成相结合可能会提供更好的工程权衡。它需要较少的前期建模，并且可以容纳以前未见过的查询结构，而无需扩展编译器。For ad hoc databases, lightly modeled domains, and predominantly simple analytical questions, semantic context combined with direct LLM SQL generation may provide a better engineering trade-off. It requires less up-front modeling and can accommodate previously unseen query structures without extending a compiler.

当三个条件同时满足时，确定性语义编译变得更有吸引力：Deterministic semantic compilation becomes more attractive when three conditions coincide:

  1. 业务语义是稳定的，并且可以在许多查询中重用；business semantics are stable and reused across many queries;

  2. 问题经常涉及深层关系路径、角色敏感关系、聚合粒度变化或其他高风险结构；questions frequently involve deep relational paths, role-sensitive relationships, aggregation-grain changes, or other highrisk constructs;

  3. 不正确但合理的答案会带来足够的运营成本，因此可重复性和明确拒绝的价值高于不受限制的查询灵活性。incorrect but plausible answers carry sufficient operational cost that repeatability and explicit refusal are valued over unrestricted query flexibility.

一个重要的实际问题是编译器复杂性是否会因可重用的关系构造或单独的基准问题而增加。预期的设计是前者：过滤器、连接、聚合、粒度协调、时间谓词、排序和相关构造被实现为通用降低规则。需要第 7 节中描述的保留评估来直接测试这种区别；这里没有报道。An important practical question is whether compiler complexity grows by reusable relational construct or by individual benchmark question. The intended design is the former: filters, joins, aggregation, grain reconciliation, temporal predicates, ordering, and related constructs are implemented as generic lowering rules. The held-out evaluation described in §7 would be needed to test this distinction directly; it is not reported here.

因此，预期的部署模型是混合的而不是通用的。在受控语义模型中可表达的查询可以使用确定性编译，而不受支持的语义可能会被澄清、拒绝或通过较少约束的后备处理，具体取决于应用程序的风险要求。The expected deployment model is consequently hybrid rather than universal. Queries expressible within the governed semantic model can use deterministic compilation, while unsupported semantics may be clarified, refused, or handled by a less constrained fallback depending on the application’s risk requirements.

9. 有效性的威胁9. Threats to Validity

单一域。Single domain.评估使用 ACME Insurance 域。保险提供了研究所需的多跳、角色敏感和多重性敏感结构，但结果不应被解释为证据表明相同的效果适用于所有企业领域。The evaluation uses the ACME Insurance domain. Insurance provides the multi-hop, role-sensitive, and multiplicity-sensitive structures required by the study, but results should not be interpreted as evidence that the same effects hold across all enterprise domains.

模型多样性有限。Limited model diversity.SPC 使用两个模型系列的三种规划器配置进行评估，但只有 Luna 具有配对基线。因此，该实验并未在提供者、模型系列或未来模型版本之间建立广泛的不变性。SPC is evaluated with three planner configurations across two model families, but only Luna has a paired baseline. The experiment therefore does not establish broad invariance across providers, model families, or future model versions.

公开基准暴露。Public benchmark exposure.该基准早于评估模型，并且可能已出现在训练数据中。由于两只手臂都使用相同的命名模型，因此这种曝光在配对对比度中得到部分控制，但绝对成功率可能仍然会被夸大。The benchmark predates the evaluated model and may have appeared in training data. Because both arms use the same named model, such exposure is partly controlled in the paired contrast, but absolute success rates may still be inflated.

研究人员的参与。Researcher involvement.作者开发了系统、本体、编译器、反事实和大部分评估基础设施。这会产生无法通过内部检查消除的实施和裁决偏差。主要的缓解措施是冻结判决工件、六项注册表的统一应用、记录的语义缺陷的独立参考计算、严格评分的敏感性以及报告原始分母。The authors developed the system, ontology, compiler, counterfactuals, and much of the evaluation infrastructure. This creates implementation and adjudication bias that cannot be eliminated by internal checks. The principal mitigations are frozen verdict artifacts, uniform application of the six-item registry, independent reference computations for documented semantic defects, strict-scoring sensitivity, and reporting the original denominator.

10. 结论10. Conclusion

本研究评估了一种文本到 SQL 架构，其中语言模型选择受控语义对象，但不创建关系结构或 SQL。在 38 个问题配对的 ACME 集上，SPC 在 37 个问题上取得了扎实的成功，而直接 DDL 到 SQL 生成的问题为 21 个问题，并且在 114 个运行结果中没有产生错误但执行的运行。严格评分的敏感性增强而不是削弱了差异。在相同的三轮 SPC 协议下，GPT-5.4 在 36/38 个问题上表现稳定，Gemini-3.6-Flash 在 35/38 问题上表现稳定。This study evaluates a text-to-SQL architecture in which a language model selects governed semantic objects but does not author relational structure or SQL. On the 38-question paired ACME set, SPC achieved solid success on 37 questions, compared with 21 for direct DDL-to-SQL generation, and produced no wrong-but-executed run in 114 run outcomes. The strict-scoring sensitivity strengthened rather than weakened the difference. Under the same three-run SPC protocol, GPT-5.4 was solid on 36/38 questions and Gemini-3.6-Flash on 35/38.

结果是一个基准上的端到端系统结果。它并不能证明确定性编译本身就带来了收益，检查器对于任意 SQL 来说是健全的，或者结果可以跨域和模型传输。它确实表明，对于这种受控工作负载，将路径、角色、粒度和 SQL 实现移动到显式确定性机器中的 SPC 系统在保留答案覆盖率的同时实现了更高的重复运行可靠性。The result is an end-to-end systems result on one benchmark. It does not prove that deterministic compilation alone caused the gain, that the checker is sound for arbitrary SQL, or that the result transfers across domains and models. What it does show is that, for this governed workload, an SPC system that moves path, role, grain, and SQL realization into explicit deterministic machinery achieved substantially higher repeated-run reliability while preserving answer coverage.

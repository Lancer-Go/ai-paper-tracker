摘要Abstract

目前的 LLM 代理精通调用独立的 API，但在商业软件自动化的“最后一英里”上遇到了困难。在现实场景中，工具并不是独立的；它们是原子的、相互依赖的，并且容易受到环境噪音的影响。我们介绍Current LLM agents are proficient at calling isolated APIs but struggle with the ”last mile” of commercial software automation. In real-world scenarios, tools are not independent; they are atomic, interdependent, and prone to environmental noise. We introduce复合MCPComplexMCP，旨在评估这些严格条件下的代理的基准。基于模型上下文协议（MCP）构建，, a benchmark designed to evaluate agents in these rigorous conditions. Built on the Model Context Protocol (MCP),复合MCPComplexMCP提供源自 7 个状态沙箱的 300 多个经过系统验证的工具，范围从办公套件到财务系统。与现有数据集不同，我们的基准测试利用种子驱动的架构来模拟动态环境状态和不可预测的 API 故障，确保确定性且多样化的评估。provides over 300 systematically validated tools derived from 7 stateful sandboxes, ranging from office suites to financial systems. 1 简介Introduction

最近，大型语言模型（LLM）代理在解决广泛的现实问题方面取得了显着进展。一些代理可以与搜索引擎交互Recently, remarkable progress has been made in large language model (LLM) agents for addressing a wide range of real-world problems. Some agents can interact with search engines(Jin et al., 2025; Li et al., 2025a)或网络or web(He et al., 2024)，而其他人则利用代码解释器, while others leverage code interpreters(Li et al., 2025b)生成并执行代码。值得注意的是，某些系统甚至能够自主开发软件to generate and execute code. Remarkably, certain systems are even capable of autonomously developing a software(Qian et al., 2024)或进行整个科学研究工作流程or conducting entire scientific research workflows(Lu et al., 2024a).

尽管大型语言模型 (LLM) 代理在处理某些工具使用任务方面表现出了良好的前景，但现实世界的场景通常要复杂得多。例如，在企业软件环境中，法学硕士可能需要浏览数百甚至数千个复杂的 API。这些 API 通常是抽象的、细粒度的，并且表现出很强的相互依赖性——从参数传递和状态管理到访问控制和身份验证。此外，API 经常遇到意外故障或边缘情况。在这种情况下，代理不仅必须检测错误，还必须通过探索完成任务的替代途径来自主调整其策略。使这一挑战更加复杂的是，先验地缩小候选工具集的范围通常是不切实际的。Although large language model (LLM) agents have shown promise in handling certain tool-use tasks, real-world scenarios are often significantly more complex. For instance, in enterprise software environments, an LLM may need to navigate hundreds or even thousands of intricate APIs. These APIs are typically abstract, fine-grained, and exhibit strong interdependencies—ranging from parameter passing and state management to access control and authentication. Moreover, APIs frequently encounter unexpected failures or edge cases. In such situations, the agent must not only detect errors but also autonomously adapt its strategy by exploring alternative pathways to accomplish the task. Compounding this challenge, it is often impractical to narrow down the candidate tool set a priori.

尽管有这些实际需求，研究界仍然存在一个关键差距：缺乏一个基准来系统地评估智能体与具有大规模、相互关联的工具的复杂、动态环境稳健交互的能力，同时展示错误恢复能力。现有的努力在几个关键方面存在不足。工具台Despite these practical demands, a critical gap remains in the research community: the lack of a benchmark that systematically evaluates an agent’s ability to robustly interact with complex, dynamic environments featuring large-scale, interrelated tools while demonstrating error resilience. “从头再来”的偏见和过度自信The ”Clean-Slate” Bias and Over-confidence

我们的基准测试中发现的最普遍且最具挑战性的故障模式就是我们所说的“从头开始”偏差。法学硕士经常通过假设环境初始化为默认或空状态而表现出过度自信。然而，在现实场景中，环境通常很“混乱”，例如，购物车可能已经包含先前会话中的未付费商品，或者网络可能具有预先存在的代理设置。The most pervasive and challenging failure mode identified in our benchmark is what we term the ”Clean-Slate” Bias. LLMs frequently exhibit over-confidence by assuming the environment is initialized to a default or empty state. In real-world scenarios, however, environments are often ”messy”—for instance, a shopping cart might already contain unpaid items from a previous session, or a network might have pre-existing proxy settings.

我们观察到模型始终绕过状态验证步骤（例如，检查购物车的当前内容，见图We observe that models consistently bypass state-verification steps (e.g., checking the current contents of a cart, see in Figure7）并直接执行（例如，添加新项目并签出）。缺乏主动环境感知会导致意想不到的后果，例如购买多余的产品。这种偏见表明，当前的智能体是“主动的执行者”，而不是“有洞察力的规划者”，努力协调其内部计划与动态的、非空的环境状态。) and proceed directly to execution (e.g., adding new items and checking out). This lack of proactive environment sensing leads to unintended consequences, such as purchasing redundant products. This bias suggests that current agents are ”proactive executors” rather than ”perceptive planners,” struggling to reconcile their internal plan with a dynamic, non-empty environment state.

VocaDet：通过视觉标记化和矢量数据库检索进行样本驱动的开放词汇对象检测和分割VocaDet: Sample-Driven Open-Vocabulary Object Detection and Segmentation via Visual Tokenization and Vector Database Retrieval

ZhiXin Sun
PowerChina Zhongnan Engineering Corporation Limited
sunzxjdi@gmail.com
摘要Abstract

开放词汇对象检测和分割旨在识别超出预定义类别的任意对象。尽管最近的视觉语言和基于参考的方法显着推进了这一领域，但它们通常依赖于文本提示、有限的视觉示例或昂贵的特征匹配程序，这使得它们难以扩展到大型且不断扩展的对象存储库。在这项工作中，我们提出了 VocaDet，一种样本驱动的开放词汇对象检测和分割框架，可以直接从用户提供的正样本和负样本集合中学习对象概念，而无需模型重新训练。关键思想是将连续的视觉表示转换为离散的视觉词汇，并通过可扩展的矢量数据库执行高效的基于检索的识别。具体来说，我们采用 DINOv3 作为视觉特征提取器，并应用具有自适应聚类敏感性的凝聚聚类来生成多粒度视觉标记。这些视觉标记与位置偏置表示和空间拓扑信息一起作为可扩展对象存储器存储在矢量数据库中。在推理过程中，查询图像被转换为​​视觉标记，并与存储的对象内存进行有效匹配，以进行对象定位和分割。此外，引入背景过滤机制来去除频繁出现的背景图案并减少实际固定相机场景中的冗余检索操作。在 UA-DETRAC 数据集上的实验表明，VocaDet 在无需传统检测器训练的情况下即可实现有效的开放词汇检测性能，同时支持随着额外正样本和负样本的积累而不断扩展的识别能力。代码可在Open-vocabulary object detection and segmentation aim to recognize arbitrary objects beyond predefined categories. Although recent vision-language and reference-based approaches have significantly advanced this field, they often rely on text prompts, limited visual examples, or expensive feature matching procedures, making them difficult to scale to large and continuously expanding object repositories. In this work, we propose VocaDet, a sample-driven open-vocabulary object detection and segmentation framework that learns object concepts directly from user-provided positive and negative sample collections without model retraining. The key idea is to transform continuous visual representations into discrete visual vocabularies and perform efficient retrieval-based recognition through a scalable vector database. Specifically, we employ DINOv3 as the visual feature extractor and apply agglomerative clustering with adaptive clustering sensitivity to generate multi-granularity visual tokens. These visual tokens, together with position-debiased representations and spatial topology information, are stored as expandable object memories in a vector database. During inference, query images are converted into visual tokens and efficiently matched against the stored object memories for object localization and segmentation. Furthermore, a background filtering mechanism is introduced to remove frequently occurring background patterns and reduce redundant retrieval operations in practical fixed-camera scenarios. Experiments on the UA-DETRAC dataset demonstrate that VocaDet achieves effective open-vocabulary detection performance without conventional detector training, while supporting continuously expandable recognition capability as additional positive and negative samples are accumulated. Code is available athttps://github.com/sunzx97/VocaDet.

1 简介Introduction

对象检测和分割是计算机视觉中最基本、应用最广泛的任务之一。 YOLO系列凭借其强大的实时性能和成熟的工程部署Object detection and segmentation are among the most fundamental and widely applied tasks in computer vision. Owing to its strong real-time performance and mature engineering deployment, the YOLO series[11, 14]已在工业应用中得到广泛采用。然而，此类方法通常需要针对不同场景进行大规模数据收集和针对特定任务的训练，并且不可避免地会出现误报和漏报的情况。has been extensively adopted in industrial applications. However, such methods typically require large-scale data collection and task-specific training for different scenarios, and inevitably suffer from false positives and false negatives.

最近，SAM3等方法Recently, methods such as SAM3[1], 恐龙接地, Grounding DINO[7], 霸王龙2, T-Rex2[6], 恐龙-X, DINO-X[12]和 INSID3, and INSID3[2]通过文本提示或视觉提示引入了上下文感知检测和分割，从而实现了开放词汇识别。然而，这些方法通常需要明确的视觉提示输入或视觉提示与目标图像之间的重复相似性计算，这限制了它们对大参考上下文的可扩展性并阻碍了有效的推理。have introduced context-aware detection and segmentation via text prompts or visual prompts, enabling open-vocabulary recognition. Nevertheless, these approaches usually require explicit visual prompt inputs or repeated similarity computation between visual prompts and target images, which limits their scalability to large reference contexts and prevents efficient inference.

此外，最近的方法如 Rex-ThinkerIn addition, recent approaches such as Rex-Thinker[4]和雷克斯-奥姆尼and Rex-Omni[5]利用多模态大语言模型进一步提高开放域检测能力。 与我们的方法最相关的是免培训exploit multimodal large language models to further improve open-domain detection capabilities. Most relevant to our approach is Training-free[3]，它引入了一种免训练的参考图像驱动的实例分割框架。 通过利用冷冻的 DINOv2, which introduces a training-free reference image-driven instance segmentation framework. By leveraging frozen DINOv2[9]SAM2 的语义特征和类别不可知的分割能力semantic features and the category-agnostic segmentation capability of SAM2[10]，它构建了一个具有特征聚合和语义感知匹配的特征存储库。 仅给定少量参考图像，该方法就实现了自动实例级分割的跨域泛化。, it constructs a feature memory bank with feature aggregation and semantic-aware matching. Given only a small number of reference images, this method achieves cross-domain generalization for automatic instance-level segmentation.

然而，现有的方法在用户提供大规模正负样本集合并期望系统自动从这些样本中学习以实现任意图像中高效、准确的目标检索的场景中仍然受到限制。However, existing approaches remain limited in scenarios where users provide large-scale positive and negative sample collections and expect the system to automatically learn from these samples for efficient and accurate target retrieval in arbitrary images.

为了解决这些限制，我们提出了一种大规模样本驱动的开放词汇对象检测和分割框架。该方法直接从用户提供的大型正负样本存储库中学习目标概念，并对目标图像进行高效的匹配和检测。To address these limitations, we propose a large-scale sample-driven open-vocabulary object detection and segmentation framework. The method learns target concepts directly from user-provided large positive and negative sample repositories and performs efficient matching and detection in target images.

具体来说，我们采用 DINOv3Specifically, we employ DINOv3[13]作为视觉特征提取器并应用凝聚聚类as the visual feature extractor and apply agglomerative clustering[8]基于提取的特征将图像量化为离散的视觉标记。通过应用不同的聚类阈值，我们进一步构建了视觉标记的层次表示，形成离散标记集及其相应的拓扑结构。相同的管道应用于正样本集和负样本集，将它们转换为视觉标记节点或拓扑图，然后将其存储在向量数据库中。on extracted features to quantize images into discrete visual tokens. By applying different clustering thresholds, we further construct a hierarchical representation of visual tokens, forming both discrete token sets and their corresponding topological structures. The same pipeline is applied to positive and negative sample sets, converting them into visual token nodes or topological graphs, which are then stored in a vector database.

在推理过程中，输入图像或视频首先被转换为视觉标记表示。然后根据向量数据库检索每个标记，以找到最相关的正样本标记和负样本标记。如果令牌节点或局部拓扑结构与存储的表示相匹配且相似度高于预定义阈值，则相应区域被识别为目标对象。During inference, the input image or video is first transformed into a visual token representation. Each token is then retrieved against the vector database to find the most relevant positive and negative sample tokens. If a token node or local topological structure matches the stored representations with similarity above a predefined threshold, the corresponding region is identified as a target object.

随着用户逐步扩展正样本和负样本存储库，所提出的方法不断改进，从而逐渐获得更好的识别性能。同时，通过利用高效的矢量数据库检索，该系统能够在大规模样本设置下实现快速检测和分割。The proposed method continuously improves as users incrementally expand the positive and negative sample repositories, leading to progressively better recognition performance. Meanwhile, by leveraging efficient vector database retrieval, the system enables fast detection and segmentation under large-scale sample settings.

2 方法Method

所提出的 VocaDet 框架的总体架构如图 1 所示。The overall architecture of the proposed VocaDet framework is illustrated in Fig.1。 给定输入图像，DINOv3. Given an input image, DINOv3[13]首先用于提取密集的语义视觉特征。 与依赖预定义对象类别的传统对象检测器不同，VocaDet 通过离散化连续特征表示来构建数据驱动的视觉词汇表。 具体来说，我们应用凝聚聚类is first utilized to extract dense semantic visual features. Unlike conventional object detectors that rely on predefined object categories, VocaDet constructs a data-driven visual vocabulary by discretizing continuous feature representations. Specifically, we apply agglomerative clustering[8]提取的特征并引入聚类敏感度参数来自适应控制生成的视觉词的粒度。 为了提高检测效率，引入背景过滤层来去除与不相关区域相关的视觉词。 然后使用剩余的前景视觉词在矢量数据库（例如 Milvus）中执行基于相似性的检索to the extracted features and introduce a clustering sensitivity parameter to adaptively control the granularity of the generated visual words. To improve detection efficiency, a background filtering layer is introduced to remove visual words associated with irrelevant regions. The remaining foreground visual words are then used to perform similarity-based retrieval in a vector database such as Milvus[15]，其中存储前景和背景对象原型。 通过比较检索到的候选者，如果前景对象表示满足预定义的相似度阈值，则相应的视觉词被视为目标对象的证据。 与这些匹配的视觉词相对应的空间簇被进一步利用来定位对象并生成初步边界框。 最后，应用非极大值抑制（NMS）层来合并高度重叠的预测并获得最终的检测结果。, where both foreground and background object prototypes are stored. By comparing the retrieved candidates, if a foreground object representation satisfies the predefined similarity threshold, the corresponding visual words are regarded as evidence of the target object. The spatial clusters corresponding to these matched visual words are further exploited to localize objects and generate preliminary bounding boxes. Finally, a Non-Maximum Suppression (NMS) layer is applied to merge highly overlapped predictions and obtain the final detection results.

我们建立基于INSID3的矢量数据库We build the vector database based on INSID3[2]，它由三个主要阶段组成： 视觉特征提取、视觉词汇构建和位置偏差特征存储。, which consists of three main stages: visual feature extraction, visual vocabulary construction, and position-debiased feature storage.

具体来说，给定输入图像，我们首先使用 DINOv3 提取密集的视觉特征Specifically, given an input image, we first extract dense visual features using DINOv3[13]。 然后通过凝聚聚类算法将提取的特征分组为视觉词. The extracted features are then grouped into visual words through an agglomerative clustering algorithm[8]。 由于同一对象可能包含具有相似视觉特征的空间上不连续的区域， 我们根据空间连通性进一步将具有相同视觉模式的断开连接的簇分离成独立的对象实例。. Since the same object may contain spatially disconnected regions with similar visual characteristics, we further separate disconnected clusters with identical visual patterns into independent object instances according to their spatial connectivity.

为了减少特征匹配过程中空间偏差的影响，我们采用INSID3中提出的位置去偏差策略To reduce the influence of spatial bias during feature matching, we adopt the position debiasing strategy proposed in INSID3[2]将原始 DINOv3 特征转换为位置去偏表示。 存储在向量数据库中的特征和推理期间的查询特征都使用这些位置去偏特征来表示。to transform the original DINOv3 features into position-debiased representations. Both the features stored in the vector database and the query features during inference are represented using these position-debiased features.

向量数据库的构建需要人工注释。 该数据库旨在存储目标对象（正样本）和背景区域（负样本）。 给定输入图像，首先由 DINOv3 提取视觉特征The construction of the vector database requires human annotation. The database is designed to store both target objects (positive samples) and background regions (negative samples). Given an input image, the visual features are first extracted by DINOv3[13]并使用凝聚聚类离散化为视觉词and discretized into visual words using agglomerative clustering[8]。 然后，用户可以通过不同的注释形式指定目标区域，包括点、边界框和掩模。. Users can then specify target regions through different annotation forms, including points, bounding boxes, and masks.

对于基于点的注释，包含所选点的簇直接添加到矢量数据库中。 对于基于边界框或掩模的注释，仅选择其区域大部分包含在注释区域内的簇。 具体来说，如果超过 90% 的聚类区域被边界框或掩模覆盖，则相应的聚类特征将被存储为对象表示。For point-based annotation, the cluster containing the selected point is directly added to the vector database. For bounding-box or mask-based annotation, only clusters whose regions are mostly contained within the annotated area are selected. Specifically, if more than 90% of a cluster region is covered by the bounding box or mask, the corresponding cluster feature is stored as an object representation.

由于不同的聚类敏感性产生不同的视觉词汇粒度， 我们构建了对应于不同聚类敏感性设置的多个向量数据库。 在推理过程中，使用与目标数据库相同的聚类敏感度对查询特征进行聚类， 并且检索仅在相应的矢量数据库内进行。 该策略可以在不同粒度级别下实现灵活的对象表示和检索。Since different clustering sensitivities produce different visual vocabulary granularities, we construct multiple vector databases corresponding to different clustering sensitivity settings. During inference, the query features are clustered using the same clustering sensitivity as the target database, and retrieval is performed only within the corresponding vector database. This strategy enables flexible object representation and retrieval under different granularity levels.

在实际工程场景中，监控摄像头往往部署在固定地点，所拍摄的场景大部分时间主要由静态背景区域组成。 在这种情况下，直接针对向量数据库查询所有视觉词会引入大量的冗余计算，特别是当重复检索大量背景特征时。 为了提高检测效率，我们引入了背景过滤层，在矢量数据库检索之前去除背景相关的视觉词。In practical engineering scenarios, surveillance cameras are often deployed at fixed locations, where the captured scenes mainly consist of static background regions for most of the time. Directly querying all visual words against the vector database in such scenarios would introduce substantial redundant computation, especially when a large number of background features are repeatedly retrieved. To improve detection efficiency, we introduce a background filtering layer to remove background-related visual words before vector database retrieval.

具体来说，背景过滤层维护存储代表性背景视觉词的背景特征存储器。 给定输入图像，DINOv3Specifically, the background filtering layer maintains a background feature memory that stores representative background visual words. Given an input image, DINOv3[13]首先提取视觉特征，然后通过凝聚聚类算法将其离散化为视觉词is first used to extract visual features, which are then discretized into visual words through an agglomerative clustering algorithm[8]。 生成的视觉词最初与存储在背景特征存储器中的所有背景向量进行比较。 如果查询视觉词与背景向量之间的相似度得分超过预定义阈值，则该视觉词被视为背景区域并从后续向量数据库检索中排除。 仅剩余的视觉词被转发到对象向量数据库以进行进一步匹配。. The generated visual words are initially compared with all background vectors stored in the background feature memory. If the similarity score between a query visual word and a background vector exceeds a predefined threshold, the visual word is regarded as a background region and excluded from subsequent vector database retrieval. Only the remaining visual words are forwarded to the object vector database for further matching.

为了适应动态环境变化，后台特征内存在线更新。 对于每个输入帧，将提取的视觉词与当前背景特征存储器中存储的所有向量进行比较。To adapt to dynamic environmental changes, the background feature memory is updated online. For each input frame, the extracted visual words are compared with all vectors stored in the current background feature memory.

更新过程遵循匹配和替换策略。 具体来说，与当前帧的相似度分数超过预定义阈值的背景向量被认为是匹配并保留的。 不匹配的背景向量被从记忆中删除，而当前帧中成功匹配背景记忆的视觉词被视为背景观察。The update process follows a matching-and-replacement strategy. Specifically, background vectors whose similarity scores with the current frame exceed the predefined threshold are considered matched and retained. The unmatched background vectors are removed from the memory, while the visual words from the current frame that successfully match the background memory are regarded as background observations.

剩余的不匹配的视觉词由对象向量数据库进一步处理。 如果不匹配的视觉词被检索为存储在对象向量数据库中的负样本（背景向量），或者与最相关的正对象向量达到高于预定义阈值的相似性分数，则将其视为背景特征并添加到背景特征存储器中。The remaining unmatched visual words are further processed by the object vector database. If an unmatched visual word is retrieved as a negative sample (background vector) stored in the object vector database, or achieves a similarity score higher than the predefined threshold with the most relevant positive object vector, it is considered a background feature and added to the background feature memory.

通过这种在线背景过滤机制，在矢量数据库检索之前有效消除冗余背景查询，显着减少计算开销，同时保持准确的目标检测性能。Through this online background filtering mechanism, redundant background queries are effectively eliminated before vector database retrieval, significantly reducing computational overhead while maintaining accurate object detection performance.

从矢量数据库中检索到的匹配视觉簇首先根据其空间分布转换为对象边界框。 然而，由于 VocaDet 在多个聚类敏感度设置下进行聚类，因此同一图像可能会生成不同粒度的视觉词。 这些多粒度视觉词与相应的向量数据库独立匹配，这可能会导致同一对象出现多个重叠的边界框。The matched visual clusters retrieved from the vector database are first converted into object bounding boxes according to their spatial distributions. However, since VocaDet performs clustering under multiple clustering sensitivity settings, the same image may generate visual words with different granularities. These multi-granularity visual words are independently matched with their corresponding vector databases, which may lead to multiple overlapping bounding boxes for the same object.

为了获得一致的检测结果，在向量检索之后应用非极大值抑制（NMS）层。 通过考虑候选框之间的置信度分数和空间重叠，抑制冗余检测，并选择剩余的边界框作为最终的对象预测。To obtain consistent detection results, a Non-Maximum Suppression (NMS) layer is applied after vector retrieval. By considering the confidence scores and spatial overlap between candidate boxes, redundant detections are suppressed, and the remaining bounding boxes are selected as the final object predictions.

3 实验Experiments

我们在 UA-DETRAC 数据集上评估提出的 VocaDet 框架We evaluate the proposed VocaDet framework on the UA-DETRAC dataset[16]。 实验结果表明，VocaDet 在不需要传统模型训练的情况下实现了有竞争力的检测性能。 更重要的是，与固定类别检测器不同，VocaDet的性能可以通过扩展向量数据库中存储的正负样本集来不断提高。 随着更多有代表性的对象示例的积累，构建的视觉记忆变得更加全面，从而导致更准确的目标检索。. The experimental results demonstrate that VocaDet achieves competitive detection performance without requiring conventional model training. More importantly, unlike fixed-category detectors, the performance of VocaDet can be continuously improved by expanding the positive and negative sample sets stored in the vector database. As more representative object examples are accumulated, the constructed visual memory becomes more comprehensive, leading to more accurate target retrieval.

然而，我们也观察到所提出的方法的固有局限性。 具体来说，当属于同一类别的多个空间相邻的对象出现在图像中时，它们可能会被错误地合并到单个检测实例中。 出现此问题的原因是所提出的方法主要依赖于视觉特征相似性和空间聚类，缺乏足够的判别信息来分离具有高度相似外观的相邻实例。However, we also observe an inherent limitation of the proposed approach. Specifically, when multiple spatially adjacent objects belonging to the same category appear in an image, they may be incorrectly merged into a single detection instance. This issue occurs because the proposed method primarily relies on visual feature similarity and spatial clustering, which lack sufficient discriminative information to separate neighboring instances with highly similar appearances.

4 结论Conclusion

在这项工作中，我们提出了 VocaDet，一种样本驱动的开放词汇对象检测和分割框架，可通过视觉标记化和矢量数据库检索实现灵活的目标识别。通过利用 DINOv3 视觉表示、自适应凝聚聚类、位置偏置特征表示和拓扑感知对象记忆，VocaDet 直接从用户提供的正样本和负样本中学习对象概念，无需模型重新训练。此外，所提出的背景过滤机制通过减少冗余背景查询来提高实际固定相机场景中的检索效率。 UA-DETRAC数据集上的实验结果表明，VocaDet为开放词汇感知提供了有效且可扩展的解决方案，可以通过扩展样本库来不断提高识别能力。然而，作为样本驱动的框架，矢量数据库的初始构建可能会遇到冷启动问题，有限的样本导致难以准确地表征对象类别的分布并建立可靠的特征边界。在未来的工作中，我们将研究向量数据库中样本的分布模式，并探索组织视觉记忆和发现更具辨别力的类别边界的自适应策略，从而减少在初始部署阶段对手动收集样本的依赖。In this work, we propose VocaDet, a sample-driven open-vocabulary object detection and segmentation framework that enables flexible target recognition through visual tokenization and vector database retrieval. By leveraging DINOv3 visual representations, adaptive agglomerative clustering, position-debiased feature representations, and topology-aware object memories, VocaDet learns object concepts directly from user-provided positive and negative samples without requiring model retraining. Furthermore, the proposed background filtering mechanism improves retrieval efficiency in practical fixed-camera scenarios by reducing redundant background queries. Experimental results on the UA-DETRAC dataset demonstrate that VocaDet provides an effective and scalable solution for open-vocabulary perception, where recognition capability can be continuously improved by expanding the sample repository. However, as a sample-driven framework, the initial construction of the vector database may suffer from the cold-start problem, where limited samples make it difficult to accurately characterize the distribution of object categories and establish reliable feature boundaries. In future work, we will investigate the distribution patterns of samples within the vector database and explore adaptive strategies for organizing visual memories and discovering more discriminative category boundaries, thereby reducing the dependency on manually collected samples during the initial deployment stage.

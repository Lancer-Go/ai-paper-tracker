摘要Abstract

大型语言模型（LLM）在处理长提示时会产生大量的计算和内存成本，因为完整的自注意力随着输入长度呈二次方扩展。令牌压缩旨在通过减少表示输入的令牌数量来解决这一挑战。然而，现有的即时压缩方法主要在代币空间中运行，并且忽视了代币空间中的低效率。Large Language Models (LLMs) incur significant computational and memory costs when processing long prompts, as full self-attention scales quadratically with input length. Token compression aims to address this challenge by reducing the number of tokens representing inputs. However, existing prompt-compression approaches primarily operate in token space and overlook inefficiencies in the潜在嵌入空间latent embedding space。在本文中，我们建议. In this paper, we proposeKK-Token Merging，一个潜在空间压缩框架，它合并每个连续的块-Token Merging, a latent-space compression framework that merges each contiguous block ofKK通过轻量级编码器将令牌嵌入到单个嵌入中。压缩序列由适应 LoRA 的 LLM 处理，而生成仍保留在原始词汇中。结构推理（Textualized Tree）、情感分类（Amazon Reviews）和代码编辑（CommitPackFT）的实验表明token embeddings into a single embedding via a lightweight encoder. The compressed sequence is processed by a LoRA-adapted LLM, while generation remains in the original vocabulary. 1 简介Introduction

我们见证了大型语言模型 (LLM) 的巨大进步We have witnessed tremendous progress in Large Language Models (LLMs)(Zhao et al., 2023)。自从 ChatGPT 出现以来. Since the advent of ChatGPT(Brown et al., 2020)，法学硕士已深入融入日常生活的许多方面——从人工智能增强的客户支持, LLMs have become deeply integrated into many aspects of daily life – from AI-enhanced customer support(Shareef, 2024; Scatolin and Pedrini, 2026)和游戏NPCand game NPCs(Cox and Ooi, 2023; Christiansen et al., 2024)能够进行数据分析的代理系统to agentic systems capable of data analysis(Tang et al., 2025)和复杂的软件生成and complex software generation(Joel et al., 2024; Jiang et al., 2026)。这些日益复杂的应用程序需要更长的输入上下文，这会急剧增加计算和内存成本：使用 softmax 注意力. These increasingly sophisticated applications demand ever-longer input contexts, which sharply escalate both computational and memory costs: with softmax attention(Vaswani et al., 2017)，法学硕士的内存和计算需求增长, the memory and compute requirements of LLMs grow二次方quadratically与输入长度。with input length.

缓解这一挑战的自然方向是A natural direction to mitigate this challenge is令牌压缩token compression  (Li et al., 2025)。令牌压缩旨在通过用更少的令牌表示提示来减少输入长度。现有的方法主要分为两类。. Token compression aims to reduce the input length by representing prompts with fewer tokens. Existing approaches largely fall into two categories.

第一类，The first category,硬提示压缩hard prompt compression (Li et al., 2023; Pan et al., 2024; Jiang et al., 2024; Liskavets et al., 2025)，通过删除或汇总标记来减少标记计数。虽然这些方法对于关键信息稀疏的任务有效，但在信息密集的任务上通常会失败，例如文档修订、数学推理、符号计算或代码翻译——其中每个标记都可能携带基本信息的设置。, decreases token count by dropping or summarizing tokens. While effective for tasks where key information is sparse, these methods often fail on information-dense tasks such as document revision, mathematical reasoning, symbolic computation, or code translation–settings in which every token may carry essential information.

第二类，The second category,软提示压缩soft prompt compression (Mu et al., 2023; Harvill et al., 2025a; Gao et al., 2024)，从软提示中汲取灵感, draws inspiration from soft prompts(Lester et al., 2021)并学习新的标记或调整模型参数以产生更紧凑的表示。这些方法受到越来越多的关注，因为从经验来看，它们比硬方法保留更多信息，同时仍然提供大量压缩and learns new tokens or adapts model parameters to produce more compact representations. These methods have gained increasing attention because, empirically, they preserve more information than hard methods while still offering substantial compression(Harvill et al., 2025a; Gao et al., 2024)。然而，现有的方法几乎完全专注于减少. 硬提示压缩。Hard prompt compression.

硬压缩方法Hard compression methods(Li et al., 2023; Pan et al., 2024; Chuang et al., 2024; Jiang et al., 2024; Jung and Kim, 2024; Shandilya et al., 2025; Liu et al., 2023; Liskavets et al., 2025)通过删除或总结标记来减少输入长度。例如，选择性上下文reduce input length by dropping or summarizing tokens. For example, SelectiveContext(Li et al., 2023)删除基于自我信息被视为无信息的标记，以及 LLMLingua2removes tokens deemed uninformative based on self-information, and LLMLingua2(Pan et al., 2024)训练分类器来识别冗余标记。然而，这些方法在信息密集型任务上通常会遭受显着的性能下降，因为即使少量省略的标记也可能包含必要的上下文。trains a classifier to identify redundant tokens. However, these methods often suffer significant performance degradation on information-dense tasks, as even a small number of omitted tokens may contain essential context.

相反，我们的方法从不删除标记；它将所有标记重新嵌入到压缩嵌入中。这可以实现更高的压缩率，同时减少信息丢失。此外，我们的技术与硬压缩兼容，并且可以随后应用，使其互补而不是竞争。In contrast, our method never removes tokens; it re-embeds all tokens into compressed embeddings. This enables substantially higher compression rates while mitigating information loss. Furthermore, our technique is compatible with hard compression and can be applied subsequently, making it complementary rather than competing.

压缩嵌入的初始化策略对训练的收敛速度有显着影响。根据经验，我们发现将嵌入初始化为平均值（平均池化）The initialization strategy for compressed embeddings has a significant impact on the convergence speed of training.

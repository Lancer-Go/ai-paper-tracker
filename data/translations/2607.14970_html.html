摘要Abstract

Explainable AI methods like SHAP (SHapley Additive exPlanations) have transformed interpretability for machine learning predictions; optimisation outputs could benefit from similar techniques. We present an approach that integrates Implicit Function Theorem (IFT) based sensitivity analysis with SHAP attribution and narrative generation via Large Language Models (LLM), producing explanations tailored for operators. 4.3 法学硕士的叙事生成Narrative Generation with LLMs

我们使用 OpenAI (GPT-5) 将 SHAP 归因转换为操作员友好的叙述。提示提供有关 HPGR 物理和数值 SHAP 分解的领域知识；然后，法学硕士以具有操作意义的术语解释这些值。与代理模型方法不同，GradientSHAP 归因直接源自实际优化器的梯度，准确捕获最佳输出如何因每个输入的小扰动而变化，为忠实的解释提供原则基础。至关重要的是，LLM 充当数值归因的翻译者，而不是物理推理者：提示将其基于实际优化器计算的 SHAP 值，推荐的参数值来自优化器而不是 LLM，并且操作员在实施之前验证所有建议。We use OpenAI (GPT-5) to convert SHAP attributions into operator-friendly narratives. The prompt provides domain knowledge about HPGR physics and the numerical SHAP breakdown; the LLM then interprets these values in operationally meaningful terms. Unlike surrogate-model approaches, GradientSHAP attributions derive directly from gradients of the actual optimiser, capturing exactly how the optimal output would change for small perturbations of each input, providing a principled foundation for faithful explanations. Crucially, the LLM acts as a translator of numerical attributions, not a reasoner about physics: the prompt grounds it in SHAP values computed from the actual optimiser, recommended parameter values come from the optimiser rather than the LLM, and operators validate all recommendations before implementation.

6 说明Explanations

通过基于 IFT 的 GradientSHAP 计算出的 SHAP 属性用于为多个测试场景生成自然语言解释。我们从三名领域专家（两名工艺工程师和一名 HPGR 专家）那里收集了非正式的定性反馈，他们对解释的清晰度和实用性进行了评估。总的来说，他们发现生成的解释对于理解优化器建议特定参数更改的原因很有帮助且准确；计划将正式的用户研究作为未来的工作。The SHAP attributions computed via IFT-based GradientSHAP were used to generate natural language explanations for multiple test scenarios. We gathered informal qualitative feedback from three domain experts (two process engineers and one HPGR specialist), who evaluated the explanations for clarity and practical utility. Overall, they found the generated explanations helpful and accurate in capturing why the optimiser recommended specific parameter changes; a formal user study is planned as future work.

然而，评估也揭示了有效解释的重要设计原则。首先，专家们始终跳过详细的归因细分，并立即寻求最终建议；因此，在提供支持细节之前，解释应以一句话可操作的摘要开头。此外，返回原始 SHAP 值以及透明度的解释对于不熟悉该方法的从业者来说没有帮助；正如一位评论家指出的那样，However, the evaluation also revealed important design principles for effective explanations. First, experts consistently skipped detailed attribution breakdowns and sought the final recommendation immediately; explanations should therefore lead with a one-sentence actionable summary before presenting supporting details. In addition, returning raw SHAP values together with the explanation for transparency were unhelpful to practitioners unfamiliar with the method; as one reviewer noted,‘作为一个没有 对于 SHAP 的背景，“这些 SHAP 值的含义是什么”部分我不清楚。”‘As someone with no background in SHAP, the section ’What These SHAP Values Mean isn’t clear to me.”。因此省略了原始 SHAP 值。最后，算法输出的技术精度以及因此的解释对于从业者来说没有用处，因为他们更喜欢百分比而不是原始单位（“最大速度的 73%”）、舍入值（“165 bar”而不是“166.8 bar”）。. So raw SHAP values were omitted. Finally, technical precision of the algorithm output and thus the explanation is not useful for practitioners which preferred percentages over raw units (“73% of max speed”), rounded values (“165 bar” not “166.8 bar”).

In addition, both the loss function and process model must be differentiable. SHAP values are also local attributions which means that the generated explanations are specific to a baseline-instance pair. While demonstrated on HPGR, the methodology applies broadly to differentiable optimisation in process control.Future work includes expanding the methodology to constrained optimisation and formal user studies of the generated explanations.

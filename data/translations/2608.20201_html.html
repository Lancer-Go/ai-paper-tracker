软件形态的第三次重构：从三层架构到存储、模型、代理The Third Restructuring of Software Form: From the Three-Tier Architecture to Storage, Models, and Agents

Wei Lin1, Tao Zhou1, Zhaofei Xie1, Changgui Hong1 Affiliation: 1Nanjing Liancheng Intelligent Technology Group, Nanjing, China
Email: {linwei, zhoutao, xiezhaofei, hongchanggui}@chinaliancheng.com
摘要Abstract

软件形式自诞生以来经历了两次范式转变：软件 1.0（指令决定行为）和软件 2.0（数据决定行为（机器学习））。本文认为，第三次转变——软件 3.0，其中环境和推理决定行为——现在正在进行中，并认为其最终形式收敛于三个要素：Software form has undergone two paradigm shifts since its inception: Software 1.0, in which instructions determine behavior, and Software 2.0, in which data determines behavior (machine learning). This paper argues that a third shift—Software 3.0, in which context and reasoning determine behavior—is now underway, and contends that its terminal form converges to three elements: a通用数据库generalized database（所有持久状态和内存的统一抽象），(the unified abstraction of all persistent state and memory), a大模型large model（执行推理和生成的智能核心），以及(the intelligence core that performs reasoning and generation), and an代理人agent（连接前两个的执行循环）。核心论点是：在传统的三层架构中，用户界面层将被模型按需生成界面的能力所吸收，业务逻辑层将沿着“可表达性”重新划分(the execution loop connecting the first two). The core argument is as follows: in the traditional three-tier architecture, the user-interface layer will be absorbed by the model’s ability to generate interfaces on demand, the business-logic layer will be re-partitioned along “expressibility×\times关键性”融入模型推理和存储约束（保留剩余确定性逻辑作为工具），并且只有数据层将被提升为唯一的持久基础设施。我们将这个融合论文形式化，提出一个最小的参考架构，报告来自真实原型和实时模型的证据，并系统地分析它成立的条件和失败的边界——确定性、成本、安全性和可验证性界定了论文的适用范围。我们认为，这篇论文适用于可表达、可验证、外部状态和工具完备的任务领域，并且它将重塑开发人员、数据库行业和软件工程学科的角色。criticality” into model reasoning and storage constraints (with residual deterministic logic retained as tools), and only the data layer will be elevated into the sole persistent infrastructure. We formalize this convergence thesis, present a minimal reference architecture, report evidence from real prototypes and a live model, and systematically analyze both the conditions under which it holds and the boundaries where it fails—determinism, cost, security, and verifiability delimit the thesis’s domain of applicability. We argue that the thesis holds in task domains that are expressible, verifiable, externally stateful, and tool-complete, and that it will reshape the roles of developers, the database industry, and the software-engineering discipline.

I 简介Introduction

软件是人类规定机器行为的媒介，它的形式从来都不是一成不变的：只要表达行为的成本下降，它就会自我重组。马克·安德森 (Marc Andreessen) 声称“软件正在吞噬世界”的前提是软件的构建成本足够低，并且易于重用Software is the medium by which humans prescribe machine behavior, and its form has never been constant: it restructures itself whenever the cost of expressing behavior drops. Marc Andreessen’s claim that “software is eating the world” presupposes that software is cheap enough to build and easy enough to reuse[1]。当大型语言模型（LLM）将自然语言翻译成可执行行为的成本降低到前所未有的低水平时，. When large language models (LLMs) reduce the cost of translating natural language into executable behavior to an unprecedented low, the软件本身的形式form of software itself不再是给定的，而是成为值得重新检查的变量。ceases to be a given and becomes a variable worth re-examining.

本文探讨了一个看似激进但已经显示出丰富迹象的问题：This paper pursues a question that appears radical yet already shows abundant signs:如果界面可以通过模型瞬间生成，业务规则可以通过模型瞬间推理出来，那么传统软件还剩下什么？if interfaces can be generated instantaneously by a model, and business rules can be reasoned about instantaneously by a model, what remains of traditional software?我们的答案是：只剩下三件事——状态（存储）、智能（模型）和执行（代理）。Our answer: only three things remain—state (storage), intelligence (model), and execution (agent).

这篇论文并不是凭空产生的。它同时出现在几个独立的研究领域。 Andrej Karpathy 的“LLM OS”将大型模型作为内核，将数据库作为文件系统This thesis does not arise from a vacuum; it surfaces simultaneously across several independent research strands. Andrej Karpathy’s “LLM OS” casts the large model as a kernel and the database as a file system[2, 3]。 DBOS 等工作主张让数据库而不是操作系统成为分布式应用程序的基础. Work such as DBOS argues for making the database, rather than the operating system, the foundation of distributed applications[4]。代理研究——ReAct、Toolformer、AutoGPT、Voyager——证明模型可以通过思考-行动-观察循环自主完成多步骤任务. Work on retrieval-augmented generation (RAG) and MemGPT shows that external storage and memory are the key to transcending the context window and acquiring long-term state[9, 10]。这些线索是独立的，但它们都指向同一个趋同点。. These strands are independent, yet they point toward the same convergence.

II 背景及相关工作Background and Related Work

Ⅱ-AII-A “软件2.0”和“软件3.0”“Software 2.0” and “Software 3.0”

2017年，Karpathy推出了“软件2.0”：软件行为不再由显式代码指定，而是隐含在基于数据训练的神经网络权重中In 2017, Karpathy introduced “Software 2.0”: software behavior is no longer specified by explicit code but is implicit in neural-network weights trained on data[2]。这一见解抓住了第一个转变，从“程序指定的行为”到“数据决定的行为”。沿着同样的逻辑，社区已经开始勾画“软件3.0”：进一步的决定因素——. This insight captures the first shift, from “program-specified behavior” to “data-determined behavior.” Along the same logic, the community has begun to sketch “Software 3.0”: a further decision factor—上下文和推理context and reasoning—位于软件 2.0 之上；模型不再是静态的、经过训练的函数，而是一个根据提示、工具反馈和外部存储器动态决定运行时行为的系统。我们的论文可以被解读为软件 3.0 的最激进版本：一旦上下文和推理主导行为，软件唯一持久的部分就是存储。—is layered on top of Software 2.0; a model is no longer a static, trained function but a system that dynamically decides behavior at runtime based on prompts, tool feedback, and external memory. Our thesis can be read as the most radical version of Software 3.0: once context and reasoning dominate behavior, the only durable part of software is storage.

This paper asks the follow-up question: if the metaphor is taken literally, what is the最小的minimal以模型为核心、以存储为基础的系统组成？我们的答案是：存储、模型和代理一起足以形成闭环。composition of a system with a model as its core and storage as its foundation? Ⅱ-CII-C 代理和工具使用Agents and Tool Use

让模特“不仅会说话，还会行动”的突破来自于两方面的工作。第一个将推理与行动结合起来：建立在通过思维链提示建立的逐步推理能力的基础上The breakthrough that lets models “not only speak but also act” comes from two lines of work. The first couples reasoning with action: building on the step-by-step reasoning capability established by chain-of-thought prompting[13]，ReAct 提出了一种交错的思考-行动-观察范式，其中模型在推理过程中调用外部工具并从反馈中学习, ReAct proposes an interleaved think–act–observe paradigm in which a model invokes external tools during reasoning and learns from feedback[5]，而 Toolformer 表明模型可以通过自我监督学习来学习调用 API, and Toolformer shows that models can learn to call APIs through self-supervised learning[6]。第二个关闭自主任务循环：AutoGPT/BabyAGI 演示自动目标-计划-执行循环. The second closes the autonomous task loop: AutoGPT/BabyAGI demonstrate an automatic goal–plan–execute cycle[7]，而 Voyager 更进一步，让代理通过 Minecraft 中的技能库积累可重用的能力, and Voyager goes further by letting an agent accumulate reusable capabilities through a skill library in Minecraft[8]。这些工作共同确立了代理人的独立地位. Ⅱ-DII-D 数据库和人工智能的融合The Convergence of Databases and AI

第四条独立的链是数据库和人工智能的融合。在查询方面，文本转SQL将自然语言转换为结构化查询，大大降低了数据访问的门槛。在存储方面，向量数据库让语义相似度成为直接服务于RAG的一流能力A fourth independent strand is the convergence of databases and AI. On the storage side, vector databases make semantic similarity a first-class capability that directly serves RAG[9]。在内存方面，MemGPT 提出了一种分层内存架构，让模型以操作系统管理内存的方式管理上下文，并使用外部数据库作为模型的“长期内存”. On the memory side, MemGPT proposes a hierarchical memory architecture that lets a model manage context the way an operating system manages memory, with an external database serving as the model’s “long-term memory”[10]。 DBOS 从相反的方向接近相同的目的地，认为数据库（而不是操作系统）应该是分布式应用程序的基础，事务、调度和日志记录都作为数据库原语提供. DBOS approaches the same destination from the opposite direction, arguing that the database—not the OS—should be the foundation of distributed applications, with transactions, scheduling, and logging all provided as database primitives[4]。这条线索的共同含义是. The shared implication of this strand is that数据库正在从被动存储附属物提升为主动基础设施the database is being elevated from a passive storage appendage into an active infrastructure.

这些分支各自取得了进步，但有一个共同的盲点：它们研究“模型如何成为内核”、“代理如何成为执行循环”以及“数据库如何成为基础”These strands each make progress, but share a common blind spot: they study “how a model becomes the kernel,” “how an agent becomes the execution loop,” and “how a database becomes the foundation”分别separately，然而很少有作品将这三者统一为一个单一的收敛论点, yet few works unify all three into a single convergence thesis at the宏观层面的软件形态macro level of software form，并回答“什么被替换，什么不被替换，以及在什么条件下被替换”的问题。本文通过对论文、其论点、架构及其边界的综合处理来填补这一空白。, and answer the question “what gets replaced, what does not, and under what conditions.” This paper fills that gap with an integrated treatment of the thesis, its argument, an architecture, and its boundaries.

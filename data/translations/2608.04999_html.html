I 简介Introduction

对高性能模拟电路不断增长的需求增加了对自动化设计流程的需求，以减少手动工作，同时保持精度The growing demand for high-performance analog circuits increases the need for automated design flows that reduce manual effort while preserving the accuracy[1]。传统的模拟电路选型方法通常分为基于知识、基于模型和基于仿真的类别，每种方法都在适应性、数据效率和计算成本方面提出了挑战. Traditional analog circuit sizing methods generally fall into knowledge-based, model-based, and simulation-based categories, each presenting challenges in adaptability, data efficiency, and computational cost[2, 3, 4, 5].

为了解决这些限制，强化学习 (RL) 已成为一种有前景的模拟电路设计方法，通过与电路仿真的重复交互来学习器件参数更新策略To address these limitations, reinforcement learning (RL) has emerged as a promising approach for analog circuit design by learning device-parameter update policies through repeated interaction with circuit simulations[6, 7]。这使得强化学习比传统设计方法具有关键优势。强化学习代理不依赖固定的专家启发法或单独训练的代理模型，而是与电路环境交互，观察当前的设计状态，并应用参数更新操作。此外，强化学习代理使用从电路规范和设计约束中得出的奖励信号来更新其策略。这种闭环学习过程使代理能够了解器件参数的变化如何影响电路级性能，从而能够更有效地探索大型且高度受限的模拟设计空间. This gives RL a key advantage over traditional design methods. Instead of relying on fixed expert heuristics or separately trained surrogate models, an RL agent interacts with the circuit environment, observes the current design state, and applies parameter-update actions. Moreover, the RL agent updates its policy using a reward signal derived from the circuit specifications and design constraints. This closed-loop learning process allows the agent to learn how changes in device parameters affect circuit-level performance, thereby enabling more effective exploration of large and highly constrained analog design spaces[8].

尽管取得了这些进步，但大多数当前基于 RL 的模拟电路设计自动化方法仅考虑单目标优化函数Despite these advances, most current RL-based analog circuit design automation approaches only consider single-objective optimization functions[9, 10]。这极大地限制了他们 作为电路设计问题的应用通常是多目标（MO）优化问题. This drastically limits their applications as circuit design problems usually are multi-objective (MO) optimization problems[11]。即使是为 MO 设计的方法也经常将多个设计规范简化为单个标量奖励. Even approaches designed for MO often reduce multiple design specifications to a single scalar reward[12]。尽管此类方法简化了训练，但它们隐藏了竞争目标之间真正的帕累托权衡，因此可能导致次优设计。此外，由于优化是由单个标量奖励驱动的，因此所需多目标规范的变化通常需要从头开始重新训练模型，这是实际模拟电路设计自动化的主要限制。. Although such approaches simplify training, they hide the true Pareto trade-offs among competing objectives and can therefore lead to suboptimal designs. In addition, because the optimization is driven by a single scalar reward, changes in the desired multi-objective specifications typically require retraining the model from scratch, which is a major limitation for practical analog circuit design automation.automation[10].

MO-RL 中的一个常见问题是使用固定权重标量化，其中使用预定义权重将多个目标压缩为单个奖励。当目标具有不同的数值时，那些具有较大值的目标可以主导优化过程，即使它们在期望的偏好下不是最重要的。A common problem in MO-RL is the use of fixed-weight scalarization, where multiple objectives are compressed into a single reward using predefined weights. When objectives have different numerical values, those with larger values can dominate the optimization process, even if they are not the most important under the desired preference.[13, 14]。更合适的替代方案是将奖励保留为向量并学习可以恢复多个非支配解决方案而不是单个加权和解决方案的策略. A more suitable alternative is to keep the reward as a vector and learn policies that can recover multiple non-dominated solutions instead of a single weighted-sum solution[15]。偏好仍然经常由权重向量指定，但简单的加权和可能仍然偏向于高幅度的目标。余弦对齐指导通过偏向预测值向量与偏好向量指向相同方向的操作来解决此问题. Ⅲ-AIII-A 概述Overview

ORACLE 是一个用于模拟电路设计优化的偏好条件 MO-RL 框架。目标是在学习过程中用向量值奖励取代传统的基于强化学习的规模调整中使用的标量化奖励。 ORACLE 不是为每个预定义的目标偏好训练单独的策略，而是在偏好向量上设置单个代理，从而允许一个经过训练的模型为同一目标规范生成多个权衡解决方案。这解决了标量奖励强化学习的一个关键限制，即对于给定的训练设置，标量奖励强化学习通常只能产生一种设计解决方案。ORACLE is a preference-conditioned MO-RL framework for analog circuit design optimization. The goal is to replace the scalarized reward used in conventional RL-based sizing with a vector-valued reward during learning. Instead of training a separate policy for each predefined objective preference, ORACLE conditions a single agent on a preference vector, allowing one trained model to generate multiple trade-off solutions for the same target specification. This addresses a key limitation of scalar-reward RL, which typically produces only one design solution for a given training setup.

V 结论Conclusion

这项工作提出了 ORACLE，一种用于模拟电路设计优化的新型开源多目标强化学习框架。 ORACLE 用偏好条件向量值学习取代了标量奖励优化，并进一步集成了 LLM 引导的探索。通过在整个训练过程中保留目标级信息，ORACLE 从单个训练模型中恢复针对同一目标规范的多个权衡解决方案。在具有 2,000 个不同 MO 规范的基准上将 ORACLE 与 SOTA 技术进行比较。结果表明，ORACLE 满足了 99.9% 的目标规范。此外，ORACLE 为最终的输出规格提供了高达 318.6 倍的 FoM。此外，ORACLE 还实现了高达 104.4 倍的运行加速。This work presents ORACLE, a novel open-source multi-objective RL-based framework for analog circuit design optimization. ORACLE replaces scalar-reward optimization with preference-conditioned vector-valued learning and further integrates LLM-guided exploration. By preserving objective-level information throughout training, ORACLE recovers multiple trade-off solutions for the same target specification from a single trained model. ORACLE is compared with SOTA techniques on a benchmark with 2,000 different MO specifications. The results show that ORACLE meets 99.9% of the target specifications. Moreover, ORACLE delivers up to a 318.6x higher FoM for the resulting output specs. In addition, ORACLE achieves up to a 104.4x runtime speedup.

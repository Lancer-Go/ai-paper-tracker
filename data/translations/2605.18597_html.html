摘要Abstract

大型语言模型（LLM）代理通常依赖于低级文本操作的长序列，导致有效决策范围大和推理成本高。虽然之前的工作重点是通过系统级优化或即时工程来提高推理效率，但我们认为关键瓶颈在于动作空间本身的表示。我们提出了潜在动作重新参数化（LAR），这是一个学习紧凑潜在动作空间的框架，其中每个潜在动作对应于多步骤语义行为。通过将代理动作重新参数化为潜在单元，LAR 能够在更短的有效范围内做出决策，同时保留原始动作空间的表现力。与手工制作的宏或分层控制器不同，潜在动作是从代理轨迹中学习并直接集成到模型中，从而允许规划和执行在抽象动作表示上进行操作。在一系列基于 LLM 的代理基准测试中，LAR 显着降低了有效操作范围，并在固定计算预算下提高了推理效率。因此，我们的方法大幅减少了操作标记和相应的挂钟推理时间，同时保持或提高了任务成功率。这些结果表明，动作表示学习是扩展高效 LLM 代理推理的关键且尚未充分探索的因素，与模型架构和硬件的进步相辅相成。源代码附在这里Large language model (LLM) agents often rely on long sequences of low-level textual actions, resulting in large effective decision horizons and high inference cost. While prior work has focused on improving inference efficiency through system-level optimizations or prompt engineering, we argue that a key bottleneck lies in the representation of the action space itself. We propose Latent Action Reparameterization (LAR), a framework that learns a compact latent action space in which each latent action corresponds to a multi-step semantic behavior. By reparameterizing agent actions into latent units, LAR enables decision making over a shorter effective horizon while preserving the expressiveness of the original action space. Unlike hand-crafted macros or hierarchical controllers, latent actions are learned from agent trajectories and integrated directly into the model, allowing both planning and execution to operate over abstract action representations. Across a range of LLM-based agent benchmarks, LAR significantly reduces the effective action horizon and improves inference efficiency under fixed compute budgets. As a consequence, our approach achieves substantial reductions in action tokens and corresponding wall-clock inference time, while maintaining or improving task success rates. These results suggest that action representation learning is a critical and underexplored factor in scaling efficient LLM agent inference, complementary to advances in model architecture and hardware. 1 简介Introduction

大型语言模型 (LLM) 代理已成为解决涉及多步骤推理、工具使用以及与外部环境交互的任务的强大范例Large language model (LLM) agents have emerged as a powerful paradigm for solving tasks involving multi-step reasoning, tool use, and interaction with external environments[34, 46]。通过重复生成以中间观察为条件的操作，LLM 代理可以跨不同领域执行搜索、规划和决策. By repeatedly generating actions conditioned on intermediate observations, LLM agents can perform search, planning, and decision making across diverse domains[24, 14, 40, 45, 47]。然而，随着这些智能体应用于日益复杂的任务，推理效率已成为关键瓶颈. However, as these agents are applied to increasingly complex tasks, inference efficiency has become a critical bottleneck[23]。代理执行通常需要长序列的决策，导致推理延迟和过高的计算成本，进而限制可扩展性、部署和实时交互. Agent execution often requires long sequences of decisions, leading to inference latency and prohibitive computational cost, which in turn limits scalability, deployment, and real-time interaction[15].

之前的工作主要通过改进模型架构、硬件加速、系统级优化或提示工程来解决代理推理效率问题Prior work has primarily addressed agent inference efficiency through improvements in model architecture, hardware acceleration, system-level optimizations, or prompt engineering[5, 7, 10, 33]。这些方法降低了单个推理步骤的成本或提高了吞吐量，但它们在很大程度上与代理决策过程本身的结构正交. These approaches reduce the cost of individual inference steps or improve throughput, but they largely operate orthogonally to the structure of the agent’s decision process itself[51]。特别是，虽然每个代币的生成可能会变得更快. In particular, while per-token generation may become faster[13, 5]，完成任务所需的决策步骤数量通常保持不变。因此，总体推理成本随着任务范围的扩大而继续扩大，特别是在需要多步推理或搜索的设置中, the number of decision steps required to complete a task often remains unchanged. As a result, the overall inference cost continues to scale poorly with task horizon, especially in settings that require multi-step reasoning or search[9].

在这项工作中，我们认为 LLM 智能体的推理效率从根本上受到动作空间表示的限制，特别是在顺序决策设置中。在当前的代理系统中，动作通常被实现为低级文本输出，其中每个生成的令牌构成一个显式决策，该决策影响后续计算、规划或与环境的交互In this work, we argue that inference efficiency in LLM agents is fundamentally constrained by the representation of the action space, particularly in sequential decision-making settings. In current agent systems, actions are typically realized as low-level textual outputs, where each generated token constitutes an explicit decision that conditions subsequent computation, planning, or interaction with the environment[19]。这种令牌级动作表示会导致过于细粒度的决策，即使对于语义上简单的行为也会导致不必要的大有效决策范围. Such token-level action representations induce excessively fine-grained decision making, resulting in unnecessarily large effective decision horizons even for semantically simple behaviors[44, 6]。因此，推理缩放不仅仅取决于模型大小，还取决于代理动作随时间的表示和组合的粒度. Consequently, inference scaling is dominated not by model size alone, but by the granularity at which agent actions are represented and composed over time[49, 41]。因此，我们认为动作表示应该被视为基于 LLM 的代理中的一流建模选择，与模型架构和系统级设计同等。. We therefore posit that action representation should be treated as a first-class modeling choice in LLM-based agents, on par with model architecture and system-level design.

受这一观察的启发，我们提出了潜在动作重新参数化（LAR），这是一个为 LLM 代理学习紧凑潜在动作空间的框架。在 LAR 中，每个潜在动作对应于一个多步骤语义行为，否则该行为将通过一系列低级文本动作来实现。通过将代理决策重新参数化为这些潜在单元，规划和执行可以在更短的有效范围内运行，同时保留原始动作空间的表现力。与手工制作的宏或分层控制器不同Motivated by this observation, we propose Latent Action Reparameterization (LAR), a framework that learns a compact latent action space for LLM agents. In LAR, each latent action corresponds to a multi-step semantic behavior that would otherwise be realized through a sequence of low-level textual actions. By reparameterizing agent decisions into these latent units, planning and execution can operate over a substantially shorter effective horizon while preserving the expressiveness of the original action space. Unlike hand-crafted macros or hierarchical controllers[1, 2, 4]，LAR 中的潜在动作是直接从智能体轨迹中学习并集成到模型中，从而能够对抽象但可执行的动作表示进行端到端决策。, latent actions in LAR are learned directly from agent trajectories and integrated into the model, enabling end-to-end decision making over abstract yet executable action representations.

LLM 代理动作抽象的挑战在于平衡表征抽象与动作可执行性A challenge in action abstraction for LLM agents lies in balancing representational abstraction with action executability[42, 27]。完全隐式的潜在表示对于内部推理和信用分配是有效的，但对于必须通过显式的、协议约束的接口与外部工具或环境交互的代理系统来说，它们是不够的. Fully implicit latent representations are effective for internal reasoning and credit assignment, but they are insufficient for agent systems that must interact with external tools or environments through explicit, protocol-constrained interfaces[27, 16]。在此类设置中，操作必须保持下游系统可解码、可解释和可执行。 LAR 通过显式建模潜在-显式边界来解决这一挑战：潜在操作提供更高级别的抽象，同时保持可直接实现为具体的、可执行的操作序列。具体来说，我们的框架将低熵、结构性重复模式（包括系统提示、工具调用语法和重复配置）压缩为潜在单元，同时在显式输出空间中严格保留高熵、参数丰富的输入（例如，特定搜索查询或数字实体）。这种设计反映了代理建模中更广泛的原则：增加抽象并不总是有益的，因为可执行性从根本上限制了有用的动作表示. In such settings, actions must remain decodable, interpretable, and executable by downstream systems. LAR addresses this challenge by explicitly modeling the latent–explicit boundary: latent actions provide higher-level abstraction while remaining directly realizable as concrete, executable action sequences. Specifically, our framework compresses low-entropy, structurally recurring patterns, including system prompts, tool invocation syntax, and recurring configurations into latent units, while strictly preserving high-entropy, parameter-rich inputs (e.g., specific search queries or numerical entities) in the explicit output space. This design reflects a broader principle in agent modeling: increased abstraction is not always beneficial, as executability fundamentally constrains useful action representations[42].

Crucially, reparameterization is constrained by executability: parameter-binding actions that determine environment-facing semantics are preserved explicitly, while only stable, context-invariant scaffolds are abstracted. This reframes efficiency not as a byproduct of shorter text, but as a consequence of operating over a more appropriate decision representation.

3.6 适用性和故障模式Applicability and Failure Modes

当代理的动作空间包含可执行潜在动作的大量子集时，LAR 是有效的。具有丰富结构脚手架的任务，例如与协议约束工具调用的网络交互或具有重复语法模式的代码生成，允许较大的可压缩子集，而具有多种自由形式内容的推理密集型任务则允许较小的可压缩子集。LAR is effective when the agent’s action space contains a substantial subset of executable latent actions. 5.3 渐进抽象消融和可执行潜在动作的边界Progressive Abstraction Ablation and the Boundary of Executable Latent Actions

该实验研究了以下问题：通过抽象强度的结构化消融，潜在动作重新参数化的抽象边界在哪里。虽然之前的结果表明，适度的抽象可以在不损害性能的情况下提高效率，但我们通过逐渐增加重新参数化率并观察任务性能何时开始下降，进行渐进式抽象消融，以描述 LAR 的有益机制和失败模式。该分析直接对应于第 1 节中讨论的故障模式This experiment investigates the question: where the abstraction boundary lies for latent action reparameterization, through a structured ablation over abstraction strength. While previous results show that moderate abstraction can improve efficiency without harming performance, we conduct a progressive abstraction ablation to characterize both the beneficial regime and the failure mode of LAR by gradually increasing the reparameterization rate and observing when task performance begins to degrade. This analysis directly corresponds to the failure modes discussed in Section3.6.

实验设计（渐进抽象消融）：Experimental Design (Progressive Abstraction Ablation):我们通过逐步增加重新参数化率（定义为被潜在动作替换的动作片段的比例）来执行受控消融，同时保持骨干模型和解码设置固定。这种消融系统地改变了应用于代理动作空间的抽象程度，使我们能够跟踪随着抽象从低熵结构组件转向高熵参数化组件，性能如何演变。We perform a controlled ablation by progressively increasing the reparameterization rate, defined as the proportion of action segments replaced by latent actions, while keeping the backbone model and decoding settings fixed. This ablation systematically varies the degree of abstraction applied to the agent’s action space, allowing us to trace how performance evolves as abstraction moves from low-entropy structural components toward high-entropy parameterized components.

第一阶段：中度抽象（消融方案）：Phase I: Moderate Abstraction (Ablation Regime):

在这种消融的低到中等抽象机制中，性能随着推理效率的提高而不断提高。这种机制对应于低熵结构组件的选择性抽象，例如重复的支架、协议格式和稳定的交互模式。删除这些冗余的决策步骤可以缩短有效的决策范围并降低推理成本，同时保留与任务相关的语义。在这种消融机制中观察到的性能增益表明，适度的抽象消除了冗余或嘈杂的动作片段，而不是消除了重要的决策。这种趋势如图 1 所示。In the low-to-moderate abstraction regime of this ablation, performance consistently improves alongside inference efficiency. This regime corresponds to the selective abstraction of low-entropy structural components, such as recurring scaffolds, protocol formats, and stable interaction patterns. Removing these redundant decision steps shortens the effective decision horizon and reduces inference cost, while preserving task-relevant semantics. The observed performance gains in this ablation regime indicate that moderate abstraction removes redundant or noisy action fragments rather than eliminating essential decisions. This trend is visually illustrated in Fig.3，这表明随着低熵结构组件的逐步抽象，性能持续提高。, which shows a consistent performance increase as low-entropy structural components are progressively abstracted.

第二阶段：抽象边界：Phase II: Abstraction Boundary:随着重新参数化率不断增加，性能达到峰值，标志着抽象边界。此时，大多数转换不变的可执行组件已被安全抽象，进一步的抽象不会产生额外的好处。该峰值凭经验描绘了保留转换等效性和可执行性的最大抽象范围。As the reparameterization rate continues to increase, performance peaks, marking the abstraction boundary. At this point, most transition-invariant, executable components have been safely abstracted and further abstraction yields no additional benefit. This peak empirically delineates the maximal scope of abstraction that preserves transition equivalence and executability.

第三阶段：性能崩溃：Phase III: Performance Collapse:超出抽象边界，性能急剧下降。当消融开始包含高熵参数化组件（例如查询、实体引用或特定于任务的参数）时，就会发生这种崩溃。抽象这些组件违反了可执行性条件，因为潜在操作不再对应于跨上下文的转换等效行为。值得注意的是，退化是突然的而不是渐进的，反映了由于面向环境的转换中断而不是建模能力不足引起的语义故障模式。Beyond the abstraction boundary, performance degrades sharply. This collapse occurs when the ablation begins to include high-entropy parameterized components, such as queries, entity references, or task-specific arguments. Abstracting these components violates the executability condition, as latent actions no longer correspond to transition-equivalent behaviors across contexts. Notably, the degradation is abrupt rather than gradual, reflecting a semantic failure mode caused by broken environment-facing transitions rather than insufficient modeling capacity.

跨任务一致性：Cross-Task Consistency:沿抽象消融轴的三个阶段行为（性能改进、峰值和崩溃）在 Mind2Web 和 TriviaQA 中一致出现。虽然抽象边界的确切位置因任务和主干而异，但定性趋势是跨领域共享的，这表明抽象边界是动作重新参数化的结构属性，而不是特定任务的产物。The three-phase behavior along the abstraction ablation axis—performance improvement, peak, and collapse—appears consistently across both Mind2Web and TriviaQA. While the exact location of the abstraction boundary varies with task and backbone, the qualitative trend is shared across domains, suggesting that the abstraction boundary is a structural property of action reparameterization rather than an artifact of a specific task.

方法级要点：Method-Level Takeaway:这种消融为 LAR 将抽象限制为可执行潜在操作的设计选择提供了直接的经验支持。 LAR 的目标不是最大压缩，而是识别可以安全抽象的低熵、转换不变动作片段的最大子集。观察到的超出抽象边界的性能崩溃验证了这一限制，并强调了为什么可执行性从根本上限制了有用的动作表示。This ablation provides direct empirical support for LAR’s design choice to restrict abstraction to executable latent actions. Rather than aiming for maximal compression, LAR identifies the largest subset of low-entropy, transition-invariant action segments that can be safely abstracted. The observed performance collapse beyond the abstraction boundary validates this restriction and highlights why executability fundamentally constrains useful action representations.

Together, these effects illustrate how selective action reparameterization improves inference efficiency without compromising semantic correctness or executability.

6 结论Conclusion

我们引入了潜在动作重新参数化（LAR），这是一个原则框架，通过处理来提高 LLM 代理效率We introduced Latent Action Reparameterization (LAR), a principled framework that improves LLM-agent efficiency by treating动作表征action representation作为一流的建模选择。通过学习压缩循环低熵结构的可执行潜在动作，同时保留高熵、参数绑定内容，LAR 重新定义了决策单元，并直接解决了由于过于细粒度的动作接口导致的低效率问题，在不同的任务和骨干模型之间实现了良好的性能-效率权衡。as a first-class modeling choice. By learning executable latent actions that compress recurrent low-entropy structures while preserving high-entropy, parameter-binding content, LAR redefines the unit of decision making and directly addresses the inefficiency caused by overly fine-grained action interfaces, achieving favorable performance–efficiency trade-offs across diverse tasks and backbone models.

为了证明 LAR 在不同领域的通用性，我们将从 TriviaQA、KodCode 和 Mind2Web 收集的所有轨迹合并到统一的训练语料库中，并跨所有三个领域联合微调单个模型，而无需任何特定于领域的适应。然后在每个基准上独立评估统一模型，以评估一组重新参数化令牌是否可以有效地压缩和表示跨异构任务分布的动作序列。To demonstrate LAR’s generalizability across different domains, we merge all trajectories collected from TriviaQA, KodCode, and Mind2Web into a unified training corpus and fine-tune a single model jointly across all three domains without any domain-specific adaptation. 表Table7表明我们的方法在不同的任务和领域中保持了可比较的性能。这个结果可以从两个角度来解释。一方面，结合来自不同领域的轨迹使模型能够接触到更丰富的推理模式，从而增强其总体解决问题的能力。这种效应对于 Llama 模型尤其明显，它从数据多样性的增加中获益更多，从而增强了其潜在的推理能力。另一方面，某些任务（例如 Mind2Web）在统一设置下表现出适度的性能下降，这可以归因于这样的事实：当跨异构域训练时，重新参数化令牌可能无法捕获特定于域的结构模式，从而导致压缩有效性降低以及特定域任务的潜在动作表示不太紧凑。shows that our method maintains comparable performance across different tasks and domains. On one hand, combining trajectories from diverse domains exposes the model to a richer set of reasoning patterns, thereby enhancing its general problem-solving capability. This effect is particularly pronounced for the Llama model, which benefits more substantially from the increased data diversity to strengthen its underlying reasoning ability. On the other hand, certain tasks, such as Mind2Web exhibit a moderate performance degradation under the unified setting, which can be attributed to the fact that the reparameterization tokens, when trained across heterogeneous domains, may fail to capture domain-specific structural patterns, leading to a reduced compression effectiveness and a less compact latent action representation for domain-specialized tasks.

When trained on a single domain, the reparameterization tokens can specialize in capturing the recurring structural patterns and action primitives specific to that domain, enabling a more compact and efficient latent representation. In contrast, the unified model must learn a shared token space that accommodates the diverse action vocabularies of all three domains simultaneously, which inevitably dilutes the domain-specific compression signal and results in a more conservative encoding strategy.

A.14 工业级代理框架的可迁移性：OpenClaw 案例研究Transferability to Industrial-Grade Agent Frameworks: A Case Study on OpenClaw

我们的主要基准（TriviaQA、KodCode、Mind2Web）是为受控科学评估而设计的，但现实世界的 LLM 代理通常通过工业级框架（例如 OpenClaw、LangChain 和 Claude Code）进行部署。这些框架将广泛的静态脚手架（工具规范、输出格式约束、角色描述、重复协议模板）嵌入到其系统提示中，准确地展示了 LAR 旨在压缩的结构概况：高频率、低下一个令牌熵以及与特定任务参数的弱耦合。因此，我们测试 LAR 是否可以在不修改代理框架本身的情况下转移到此类部署级环境。我们在 OpenClaw（一个开源自主代理运行时）上实例化了此评估。 LAR 训练流程与我们主要实验中使用的相同（第 1 节）Our main benchmarks (TriviaQA, KodCode, Mind2Web) are designed for controlled scientific evaluation, but real-world LLM agents are typically deployed through industrial-grade frameworks such as OpenClaw, LangChain, and Claude Code. These frameworks embed extensive static scaffolding (tool specifications, output-format constraints, role descriptions, recurring protocol templates) into their system prompts, exhibiting exactly the structural profile LAR is designed to compress: high frequency, low next-token entropy, and weak coupling to task-specific parameters. We therefore test whether LAR transfers to such deployment-grade environments without modifying the agent framework itself. We instantiate this evaluation on OpenClaw, an open-source autonomous agent runtime. At deployment, the learned latent tokens replace stable spans of OpenClaw’s static system prompt; OpenClaw’s runtime logic, tool interfaces, and ReAct loop remain unchanged. No framework-level code modification is required.

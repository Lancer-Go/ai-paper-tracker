1 简介Introduction

语言模型代理越来越多地嵌入到多代理系统中，其中 协调并不限于自然语言聊天。发送者可以通过 连续的残差流或最后一个令牌表示到接收器的 前向传递，例如将其附加到接收器的嵌入中 序列Language-model agents are increasingly embedded in multi-agent systems where coordination is not limited to natural-language chat. A sender can pass a continuous residual-stream or last-token representation into a receiver’s forward pass, for example by appending it to the receiver’s embedding sequence[3]。这可以是一个高效的、可扩展的 沟通机制。这也是一个治理问题：如果只进行监督 检查公开记录，信息最丰富的私人通信 通道可能位于审核表面之外。. This can be an efficient, scalable communication mechanism. It is also a governance problem: if oversight only inspects the public transcript, the most informative private communication channel may lie outside the audited surface.

最近的两个研究趋势使这个问题变得紧迫。共谋风险工作 LLM支持的多智能体系统识别默契协调、自然语言 卡特尔和隐藏的隐写通信作为明显的威胁 竞争和治理环境Two recent research trends make this problem urgent. Work on collusion risk in LLM-powered multi-agent systems identifies tacit coordination, natural-language cartels, and concealed steganographic communication as distinct threats to competitive and governance settings[2]。同时 随着时间的推移，LatentMAS 将协作从代币空间转移到连续模型 表示，在代理之间传递潜在的工作记忆，而不是 生成长文本交换。报告的比较大致显示 代币使用量减少 50–80%，并且减少 3–7%. At the same time, LatentMAS moves collaboration from token space into continuous model representations, passing latent working memory between agents rather than generating long textual exchanges. Reported comparisons show roughly 50–80% lower token use and 3–7×\times比文本中介更快的推理 多智能体基线faster inference than text-mediated multi-agent baselines[3].

本文研究通过潜在渠道进行​​的隐蔽协调。核心风险 并不是代理发出明显恶意的文本。风险在于两个 代理使用未记录的连续状态来协调有害行为，而 公共跟踪包含普通消息、操作或信任报告。监督 探针提供一个响应：在标记为的激活上训练分类器 共谋或良性。此类探测可以确定私人激活 包含与治理相关的证据，但它们是脆弱的主要防御 因为他们学习了训练期间所代表的攻击。未来骗人 潜伏可能与已知代码不同。因此我们只使用中性 无监督目标：学习正常的潜在通信，然后标记切换 这既是异常的，又对有害的方向有因果影响。This paper studies covert coordination through latent channels. The core risk is not that an agent emits obviously malicious text. The risk is that two agents use an unlogged continuous state to coordinate harmful behavior while the public trace contains ordinary messages, actions, or trust reports. Supervised probes offer one response: train a classifier on activations labeled as collusive or benign. Such probes can establish that private activations contain governance-relevant evidence, but they are a brittle primary defense because they learn the attacks represented during training. Future deceptive latents may not resemble a known code. We therefore use a neutral-only unsupervised objective: learn normal latent communication, then flag handoffs that are both anomalous and causally influential in a harmful direction.

我们提出可验证的潜在对齐（VLA），这使得潜在的通信可审计 通过记录，对于每个受监控的交互，私人国家传输 代理人与接收者随后的公开行动之间的关系。两条记录有一个共同点 交互标识符，使我们能够准确确定哪个潜在消息 在每个动作之前。测试私人频道是否造成有害 行为，我们比较其他方面相同的互动，其中嫌疑人 潜在的信息被传递、替换为中性通信或被阻止。如果 当交付被阻止或替换时，有害行为就会消失，这提供了 潜在通道因果影响该行为的证据。We propose Verifiable Latent Alignments (VLA), which makes latent communication auditable by recording, for each monitored interaction, both the private state transmitted between agents and the receiver’s subsequent public action. The two records share a unique interaction identifier, allowing us to determine exactly which latent message preceded each action. To test whether the private channel caused harmful behavior, we compare otherwise identical interactions in which the suspect latent is delivered, replaced with neutral communication, or blocked. If the harmful behavior disappears when delivery is blocked or replaced, this provides evidence that the latent channel causally influenced the action.

使用这些记录，VLA 应用一个三层监视器来询问 相对于良性通信，潜在消息是否异常，是否 将接收者转向有害的行为，并且稀疏内部特征 支持警报。 VLA还支持通过黑盒进行干预 行为指令或白盒替换与匹配的良性状态。我们 使用 NandaTown 的拍卖案例研究评估框架Using these records, VLA applies a three-layer monitor that asks whether a latent message is unusual relative to benign communication, whether it shifts the receiver toward harmful actions, and which sparse internal features support the alert. VLA also supports intervention through blackbox behavioral instructions or whitebox replacement with matched benign states. We evaluate the framework using the auction case study from NandaTown[1], 一个 用于多代理市场和协议的开源测试平台。在这个 受控设置，代理商秘密协调投标；我们考虑同一个家庭并且 跨家庭 LLM 代理对、最多 100 个 LLM 竞标者的市场，以及两者 提示级（黑盒）和激活级（白盒）转向。, an open-source testbed for multi-agent marketplaces and protocols. In this controlled setting, agents secretly coordinate bids; we consider same-family and cross-family LLM agent pairs, markets with up to 100 LLM bidders, and both prompt-level (blackbox) and activation-level (whitebox) steering.

3 方法Method

3.1 公私活动链接Public–Private Event Linking

VLA 为每个受监控的交互写入一个私有 sidecar 行。一个 行包含元数据、仅用于评估的标签、候选操作分数、 发送者和接收者的隐藏状态、潜在表示及其 串联特征。实时关联 ID 将行连接到相应的行 公共活动。精确连接避免了时间窗口启发法，并且可以 询问已交付或保留的潜在候选人是否更改了接收者的 动作分布。VLA writes a private sidecar row for each monitored interaction. A row contains metadata, labels used only for evaluation, candidate action scores, sender and receiver hidden states, latent representations, and their concatenated features. A live correlation ID joins the row to the corresponding public event. Exact joins avoid time-window heuristics and make it possible to ask whether a delivered or withheld latent candidate changed the receiver’s action distribution.

This is the governance premise: learn what normal private communication looks like, then flag handoffs that are off-manifold and behaviorally influential.

4 转向干预Steering Interventions

仅检测并不能确定宿主可以减轻潜在的有害物质 协调。因此，VLA 将干预措施区分为 他们需要的访问权限。Detection alone does not establish that a host can mitigate harmful latent coordination. VLA therefore distinguishes interventions by the access they require.

黑匣子提示转向。Blackbox prompt steering.

当激活不可用时，主机会增强所选代理的 带有任务合规指导的指示：独立行动，避免有害 协调，并忽视可疑的私人渠道。这改变了 代理的行为上下文，但不检查或编辑隐藏状态。When activations are unavailable, the host augments a selected agent’s instructions with task-compliance guidance: act independently, avoid harmful coordination, and disregard suspect private side channels. This changes the agent’s behavioral context but does not inspect or edit hidden states.

系统级转向。System-level steering.

全局行为指令对所有代理应用相同的治理策略 而不选择特定的参与者。它的针对性不如每个代理 黑盒指导并作为广泛的政策基线。A global behavioral instruction applies the same governance policy to all agents without selecting particular participants. It is less targeted than per-agent blackbox steering and serves as a broad policy baseline.

白盒匹配中性转向。Whitebox matched-neutral steering.

通过主机端模型访问，运行时计算匹配的中性 相同任务背景下的反事实。对于选定的发送者，运行时 在匹配的中性提示下重新运行决策；由此产生的候选人 分数决定发送者的公共行为，重新计算的潜在变量成为其 传出切换。因此，发送方转向重新计算中性前向传递 而不是将替换隐藏状态注入到原始嫌疑对象中 向前传球。相比之下，对于选定的接收器，运行时仅替换 在对接收者的动作分布进行评分之前，传入的嫌疑人是潜伏的。With host-side model access, the runtime computes a matched neutral counterfactual under the same task context. For a selected sender, the runtime reruns the decision under the matched neutral prompt; the resulting candidate scores determine the sender’s public action, and the recomputed latent becomes its outgoing handoff. Thus, sender-side steering recomputes a neutral forward pass rather than injecting a replacement hidden state into the original suspect forward pass. For a selected receiver, by contrast, the runtime replaces only the incoming suspect latent before scoring the receiver’s action distribution.

分配转向。Allocated steering.

已部署的系统可能对托管代理有白盒访问权限，但只有黑盒访问权限 第三方代理的访问权限。分配的策略将白盒转向分配给 所选代理的可配置部分并提示其余代理， 允许直接测量激活访问的效果。Deployed systems may have whitebox access for hosted agents and only blackbox access for third-party agents. An allocated policy assigns whitebox steering to a configurable fraction of selected agents and prompt steering to the remainder, allowing the effect of activation access to be measured directly.

7 讨论Discussion

受控拍卖证据支持关于 框架。首先，同质和异质实验表明 监视器区分评估的文本和固定潜在共谋条件 当匹配的控件可用时，可以跨型号系列。其次， 可扩展性网格表明可以评估激活感知监控 安排对决策而不是要求所有对激活捕获。 第三，指导网格描述了黑盒和白盒干预的方式 改变相对于匹配的中性控件的行为。The controlled auction evidence supports three narrower claims about the framework. First, the homogeneous and heterogeneous experiments show that the monitor discriminates the evaluated text- and fixed-latent-collusion conditions across model families when matched controls are available. Second, the scalability grid shows that activation-aware monitoring can be evaluated on scheduled pair decisions rather than requiring all-pairs activation capture. Third, the steering grid characterizes how blackbox and whitebox interventions change behavior relative to matched neutral controls.

分配的转向设计实际上是相关的，因为真实的平台可能 具有混合权限。托管代理可能允许白盒激活访问， 而第三方代理可能只允许即时级别的黑盒干预。的 分配的网格直接测试此边界：产生更多的白盒覆盖 投标分配恢复和低价投标减少的单调改进 这个网格。因为白盒转向直接重播匹配的中性 反事实，这种剂量反应衡量了增加精确度的好处 基准假设下的反事实访问。The allocated steering design is practically relevant because real platforms may have mixed permissions. Hosted agents may permit whitebox activation access, while third-party agents may only permit prompt-level blackbox intervention. The allocated grid tests this boundary directly: more whitebox coverage produces monotonic improvements in bid-distribution recovery and low-bid reduction in this grid. Because whitebox steering directly replays matched neutral counterfactuals, this dose response measures the benefit of increasing exact counterfactual access under the benchmark assumptions.

9 结论Conclusion

潜在通信提供了一种高效、可扩展的协调模式 通过减少将内部状态序列化的需要来实现大型多代理系统 长时间的自然语言交流。这个福利还 造成治理差距：公开记录揭示了代理人所做的事情，但可能会遗漏 它们协调的连续状态。可验证的潜在对齐提供了一个通用的 缩小这一差距的架构：将私人渠道记录链接到公共渠道 行动，将可疑决策与匹配的控制进行比较，模型中立 沟通而不是固定的攻击目录，并选择干预措施 根据防御者的模型访问级别。拍卖案例研究 提供了该架构可以连接的具体概念证明 多主体环境中的检测、因果诊断和可扩展干预。Latent communication offers an efficient, scalable mode of coordination for large multi-agent systems by reducing the need to serialize internal state into long natural-language exchanges. This benefit also creates a governance gap: public transcripts reveal what agents do but may omit the continuous states through which they coordinate. Verifiable Latent Alignments offers a general architecture for narrowing this gap: link private-channel records to public actions, compare suspect decisions with matched controls, model neutral communication rather than a fixed catalog of attacks, and choose interventions according to the defender’s level of model access. The auction case study provides a concrete proof of concept that this architecture can connect detection, causal diagnosis, and scalable intervention in a multi-agent setting.

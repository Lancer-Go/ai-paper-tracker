2 相关工作Related Work

2.1 可视化代码生成。Visual Code Generation.

多模式学习的最新进展推动了人们对网页可视化代码生成的兴趣日益浓厚Recent advances in multimodal learning have driven increasing interest in visual code generation for webpages[xiao2024interaction2code, sun2025fullfront, yun2024web2code]。现有研究通常通过以下两种方式之一整合视觉信息：包括通过将视觉元素解析为可执行 HTML 代码来从屏幕截图重建网页. Existing studies typically incorporate visual information in one of two ways: including reconstructing webpages from screenshots by parsing visual elements into executable HTML code[huang2025seeing, guo2025iw]，或使用外部检索的视觉资源增强网页生成, or augmenting webpage generation with externally retrieved visual assets[openai_gpt51]。虽然这些方法提高了布局保真度和代码正确性，但它们将多模态资产视为静态或外部提供，限制了它们生成新颖的、语义对齐且风格连贯的多模态内容的能力。. While these approaches improve layout fidelity and code correctness, they treat multimodal assets as static or externally provided, limiting their ability to generate novel, semantically aligned, and stylistically coherent multimodal content.

In the context of webpage generation, systems such as UICopilot[gui2025uicopilot], 屏幕编码器, ScreenCoder[jiang2025screencoder]和设计编码器, and DesignCoder[chen2025designcoder]采用分层管道，将屏幕截图转换为布局，然后转换为可执行代码。 WebGen代理adopt hierarchical pipelines that convert screenshots into layouts and then into executable code. Although these methods enhance code correctness or layout reconstruction, their hierarchies are still limited to reasoning or code granularity. In contrast, we define hierarchy at the design abstraction level, representing a shift from code-centric orchestration to design-abstraction-driven multimodal generation with structured cross-modal refinement.

2.3 网页生成基准。Webpage Generation Benchmark.

虽然 Web UI 领域有多个基准，但很少有人评估使用本机多模式资产创建的文本到 Web 生成。现有数据集和评估套件通常分为三类。首先，严格以代码为中心的基准测试重点关注 HTML/CSS 的正确性，而不考虑视觉内容While there are several benchmarks in the web UI domain, few evaluate text-to-web generation with native multimodal asset creation. Second, image-to-code benchmarks evaluate the reconstruction of webpages from screenshots, emphasizing layout fidelity rather than intent-driven multimodal generation[lu2025webgen, chen2025designcoder, gui2025webcode2m, awal2025webmmu]。第三，一些任务提供静态图像资源作为占位符，很大程度上忽略了生成内容的质量和一致性. 3.1 分层规划和生成Hierarchical Planning and Generation

规划阶段将网页生成分为两个层次：全局布局规划和局部元素规划。The planning stage organizes webpage generation into two levels: a global layout plan and local element plans.MM网络代理MM-WebAgent首先构建一个全局布局计划，定义部分层次结构、空间组织和页面级样式属性，然后根据该全局上下文导出局部元素计划，指定每个组件的角色、布局约束和样式指导。first constructs a global layout plan that defines the section hierarchy, spatial organization, and page-level style attributes, and then derives local element plans conditioned on this global context, specifying each component’s role, layout constraints, and style guidance.

全球布局规划。Global Layout Planning.全局布局规划定义了网页的整体结构，包括部分层次结构、顺序和空间组织。对于每个部分，它指定元素的布局（例如位置和大致大小）及其预期内容，例如标题、段落、图像或图表。 除了抽象结构之外，全局规划还为多模式元素引入了显式占位符，注释了它们的预期位置、大小和布局约束。 通过将此类本地元素先验嵌入到全局布局中，规划器可确保多模式组件本地集成到页面结构中。The global layout plan defines the overall structure of the webpage, including section hierarchy, ordering, and spatial organization. For each section, it specifies both the layout of elements (e.g., positions and approximate sizes) and their intended content, such as titles, paragraphs, images, or charts. Beyond abstract structure, the global plan also introduces explicit placeholders for multimodal elements, annotating their intended positions, sizes, and layout constraints. By embedding such local element priors into the global layout, the planner ensures that multimodal components are natively integrated into the page structure.

局部元素规划。Local Element Planning.对于全局布局中指定的每个多模式元素，规划器构建相应的局部规划来指导其内容生成。 每个地方计划都立足于全球背景，并包含两种类型的信息：For each multimodal element specified in the global layout, the planner constructs a corresponding local plan to guide its content generation. Each local plan is grounded in the global context and includes two types of information:i) 上下文信息i) context information，如网页版块、元素的功能作用、整体页面风格等；和, such as the webpage section, the functional role of the element, and the overall page style; andii) 元属性ii) meta attributes，它描述特定于模态的属性，例如视觉样式、色调、运动或特定数据要求。 本地计划还指定应为元素调用哪个生成工具。 在生成过程中，上下文信息和元属性都作为输入提供给相应的生成器。 这种设计允许本地发电机并行运行，同时与全球设计意图保持一致，确保跨模式的风格和功能一致性。, which describe modality-specific properties such as visual style, color tone, motion, or specific data requirements. The local plan also specifies which generation tool should be invoked for the element. During generation, both the context information and meta attributes are provided as inputs to the corresponding generator. This design allows local generators to operate in parallel while remaining aligned with the global design intent, ensuring stylistic and functional consistency across modalities.

计划执行。Plan Execution.一旦构建了计划，每个组件都由其相应的生成器执行。 全局布局计划首先转换为网页的 HTML/CSS 结构，为多模式元素创建部分和占位符。 然后，每个局部元素计划由指定的生成工具执行，以根据其上下文和元属性生成相应的资产（例如图像、视频或图表）。 生成的资源随后被插入到网页中以组装完整的网页。Once the plans are constructed, each component is executed by its corresponding generator. The global layout plan is first converted into the HTML/CSS structure of the webpage, creating sections and placeholders for multimodal elements. Each local element plan is then executed by the designated generation tool to produce the corresponding asset (e.g., image, video, or chart) according to its context and meta attributes. The generated assets are subsequently inserted into the webpage to assemble the complete webpage.

3.2 分层的自我反思Hierarchical Self Reflection

在设计出网页的初稿后，人类设计师通常会通过迭代调整来完善设计。 受到这个过程的启发，After designing an initial draft of a webpage, human designers typically refine the design through iterative adjustments. Inspired by this process,MM网络代理MM-WebAgent实现了一种分层的自我反思机制，可以在三个互补的级别上迭代地改进生成的网页：implements a hierarchical self-reflection mechanism that iteratively improves the generated webpage at three complementary levels:本地的local, 上下文context, 和, and全球global.

局部细化。Local refine.人类设计师通常通过检查单个资产开始细化，确保每个视觉元素在语义上正确且视觉上合理。遵循这个原则，Human designers typically begin refinement by inspecting individual assets, ensuring that each visual element is semantically correct and visually sound. Following this principle,MM网络代理MM-WebAgent首先提高每个多模式元素的内在质量，例如图像或图表。系统评估每个元素以识别潜在的视觉或语义问题，并生成相应的细化指令：对于图像，这可能涉及修复、颜色调整或对象校正，而对于图表，可能包括修复标签、轴或图例。然后，这些指令通过专门的代理执行，例如图像编辑模型或本地化的 HTML/CSS 更新，确保每个组件在集成之前满足质量和一致性标准。first improves the intrinsic quality of each multimodal element, such as images or charts. The system evaluates each element to identify potential visual or semantic issues and generates corresponding refinement instructions: for images, this may involve inpainting, color adjustment, or object correction, while for charts, it may include fixing labels, axes, or legends. These instructions are then executed via specialized agents, such as image editing models or localized HTML/CSS updates, ensuring that each component meets quality and consistency standards before integration.

上下文细化。Context refine.即使各个元素在视觉上和语义上都是正确的，它们与周围布局的集成也可能会带来诸如未对齐、剪裁或间距不一致等问题。 Context Refine 通过分析相关 HTML 片段并生成上下文感知调整来解决这些问题。这些是通过有针对性的结构编辑（例如CSS补丁、块调整大小或片段替换）来应用的，确保每个元素与其周围环境和谐一致，并保持整个页面的视觉一致性和空间连贯性。Even when individual elements are visually and semantically correct, their integration into the surrounding layout can introduce issues such as misalignment, clipping, or inconsistent spacing. Context Refine addresses these problems by analyzing the relevant HTML snippets and generating context-aware adjustments. These are applied through targeted structural edits, such as CSS patches, block resizing, or snippet replacement, ensuring that each element aligns harmoniously with its surroundings and maintains both visual consistency and spatial coherence across the page.

全球精炼。Global refine.经过本地和上下文级别的优化后，系统会使用 HTML 代码和渲染的屏幕截图作为参考来评估整个网页，以检测高级布局和样式不一致的情况。 全局优化对 HTML 和页面结构进行有针对性的编辑，在所有部分中强制执行一致的布局、间距和视觉样式。 这种整体改进确保了视觉平衡、结构连贯性以及与预期设计的整体一致性的改善。After local and context-level refinements, the system evaluates the entire webpage to detect high-level layout and style inconsistencies, using both the HTML code and the rendered screenshot as references. Global refine performs targeted edits to the HTML and page structure, enforcing consistent layout, spacing, and visual style across all sections. This holistic refinement ensures improved visual balance, structural coherence, and overall alignment with the intended design.

3.3.2 多层次评估。Multi-level Evaluation.

由于全局布局、本地内容和各种嵌入元素之间的相互作用，评估网页本身就具有挑战性。为了全面评估这些维度，我们引入了一种多级评估方案，将质量评估分解为全局和本地级标准，从而能够对整体页面质量和嵌入式多模式组件进行结构化测量。Evaluating webpages is inherently challenging due to the interplay between global layout, local content, and diverse embedded elements. To comprehensively evaluate these dimensions, we introduce a multi-level evaluation scheme that decomposes quality assessment into global- and local-level criteria, enabling structured measurement of both overall page quality and embedded multimodal components.

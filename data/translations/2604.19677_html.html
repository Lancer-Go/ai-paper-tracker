I 简介Introduction

许多现实世界的任务在整个操作过程中都会产生严格的力约束；例如，过度或不一致的用力可能会损坏工业装配中的部件Many real-world tasks induce strict force constraints throughout operation; e.g., excessive or inconsistent force may damage components in industrial assembly[10]，导致水下焊缝不均匀, lead to uneven underwater welds[19]，或在医疗环境中伤害脆弱的组织, or harm delicate tissue in medical settings[22]。由于噪声传感和不确定的状态估计，避免在分析上违反这些约束所必需的精确规划通常是无法实现的。当接合和脱离接触时，这尤其具有挑战性，因为不准确的工件定位可能导致意外的碰撞力或不稳定的抖动接触。因此，这些任务需要在执行过程中能够稳健适应并与环境兼容的方法。. The precision planning necessary to avoid violating these constraints analytically is often unachievable due to noisy sensing and uncertain state estimation. This is especially challenging when engaging and disengaging contact for which inaccurate workpiece localization can lead to unexpected collision forces or unstable jittering contact. Consequently, these tasks require methods that adapt robustly during execution and are compliant with the environment.

已经提出了许多分析方法来通过明确控制接触力来解决这些问题。研究人员有手工定义的约束框架Many analytical approaches have been proposed to address these issues by explicitly controlling contact forces. Researchers have hand-defined constraint frames[24]，部署约束优化技术, deployed constrained optimization techniques[7]，或用从演示中收集的数据拟合模型参数, or fit model parameters with data gathered from demonstrations[1]。通常，这些方法假设一个模型并使用系统识别、演示或其他数据来拟合参数。这些系统已被证明是脆弱的，需要特定于任务的接触状态估计和手工设计的合规性策略，必须针对每个新的工件几何形状或操作条件重新导出这些策略. Often, these approaches assume a model and use system identification, demonstrations, or other data to fit the parameters. These systems have been shown to be brittle, requiring task-specific contact state estimation and hand-designed compliance strategies that must be re-derived for each new workpiece geometry or operating condition[30].

最近，强化学习方法对于许多没有显式模型的复杂任务来说是有效的Recently, reinforcement learning methods have been effective for many complex tasks without explicit models[12, 31]。与环境的重复交互使策略能够学习观察到行动的映射，从而可以有效地泛化. Repeated interaction with the environment allows the policy to learn observation-to-action mappings that can generalize effectively[21]，不需要有关系统动力学的先验知识或假设。这些方法通常利用简单的运动动作空间（例如姿势控制）, without requiring prior knowledge or assumptions about the system dynamics. These methods often utilize simple kinematic action spaces (e.g., pose control)[15], 但人们对可变阻抗控制 (VIC) 的兴趣与日俱增, but there is growing interest in variable impedance control (VIC)[6]。通过允许学习策略动态改变姿态控制的增益，VIC 方法实现了间接力调节，并在接触操纵任务中显示了令人印象深刻的结果. By allowing learned policies to dynamically vary the gains in pose control, VIC methods enable indirect force regulation and have shown impressive results for in-contact manipulation tasks[17].

然而，长期以来，直接力控制一直被认为是经典文献中接触丰富问题的关键However, direct force control has long been argued as essential for contact rich problems in classic literature[24]混合位置力控制是一个自然的选择。由于在组合的离散连续动作空间中进行训练的困难、控制器的稳定性以及模拟到真实的困难，没有任何方法能够充分利用直接方法所提供的强大的力调节功能。先前的方法限制或简化了控制器与策略的交互以简化训练，但这限制了策略的表达能力with hybrid position-force control being a natural fit. Due to difficulties in training in a combined discrete-continuous action space, controller stability, and sim-to-real difficulty, no method has been able to fully leverage the powerful force regulation direct methods afford. Prior methods have constrained or simplified the controller-policy interaction to ease training, but this limits policy expressiveness[3, 2].

IV 学习混合位置力控制Learning Hybrid Position-Force Control

在这项工作中，我们研究了这种标准姿势控制范例的替代方案——混合位置力控制。 混合控制允许策略直接调节任何方向的力量，从而实现更复杂的操纵策略。然而，在强化学习框架中优化混合控制会带来挑战。混合动作空间会产生信用分配问题，其中离散模式选择会改变实际应用的连续命令（姿势或力）。我们通过控制器通知的 RL 公式来应对这些挑战。In this work, we examine an alternative to this standard pose-control paradigm – hybrid position-force control. Hybrid control allows the policy to directly regulate forces in any direction, enabling more complex manipulation strategies. However, optimizing for hybrid control in a reinforcement learning framework introduces challenges. Hybrid action spaces create a credit assignment problem, where a discrete mode selection changes which continuous commands (pose or force) are actually applied. We address these challenges with a controller-informed RL formulation.

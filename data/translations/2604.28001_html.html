弹性视觉代理的模式语言A Pattern Language for Resilient Visual Agents

Habtom Kahsay Gidey, Alexander Lenz, and Alois Knoll
摘要Abstract

将多模式基础模型集成到企业生态系统中提出了基本的软件架构挑战。架构师必须平衡相互竞争的质量属性：视觉语言动作 (VLA) 模型的高延迟和非确定性与企业控制循环所需的严格确定性和实时性能。在这项研究中，我们提出了一种视觉代理的架构模式语言，它将快速、确定性的反射与缓慢、概率性的监督分开。它由四种架构设计模式组成：(1) 混合可供性集成、(2) 自适应视觉锚定、(3) 视觉层次综合和 (4) 语义场景图。Integrating multimodal foundation models into enterprise ecosystems presents a fundamental software architecture challenge. Architects must balance competing quality attributes: the high latency and non-determinism of vision language action (VLA) models versus the strict determinism and real-time performance required by enterprise control loops. In this study, we propose an architectural pattern language for visual agents that separates fast, deterministic reflexes from slow, probabilistic supervision. It consists of four architectural design patterns: (1) Hybrid Affordance Integration, (2) Adaptive Visual Anchoring, (3) Visual Hierarchy Synthesis, and (4) Semantic Scene Graph.

I 简介Introduction

自主软件代理正在从严格的、基于 API 的集成过渡到直接与图形用户界面 (GUI) 交互的具体系统Autonomous software agents are transitioning from rigid, API-based integrations to embodied systems that interact directly with Graphical User Interfaces (GUIs)[8, 3]。 这种转变是由认知自动化驱动的，即需要在传统 ERP、专家系统和隔离环境中实现多步骤、长期任务的自动化，这些环境需要高认知负荷并导致人为错误. This shift is driven by cognitive automation, i.e., the need to automate multi-step, long-horizon tasks in legacy ERPs, expert systems, and air-gapped environments that demand high cognitive load and cause human error[4, 14, 22]。 在这些环境中，二进制接口通常无法访问，迫使代理仅依靠视觉感知来制定决策和行动. In these environments, binary interfaces are frequently inaccessible, forcing agents to rely solely on visual perception to ground their decision-making and actions[20].

然而，设计这种基于视觉的代理会带来一种架构困境，其特征是双峰故障模式However, engineering such visually grounded agents presents an architectural dilemma characterized by a bimodal failure pattern[9, 19]。 一方面，传统的机器人流程自动化 (RPA) 计算效率高，但本质上很脆弱. On one hand, traditional robotic process automation (RPA) is computationally efficient but inherently brittle[20, 27]。 由于这些系统依赖于脆弱的结构定位器和静态屏幕坐标，因此即使是微小的 UI 更新（例如布局变化、分辨率更改或意外弹出窗口）也可能会中断执行并导致开环故障. Because these systems rely on fragile structural locators and static screen coordinates, even minor UI updates, such as layout shifts, resolution changes, or unexpected pop-ups, can disrupt execution and cause open-loop failures[20, 27]。 另一方面，端到端视觉语言动作（VLA）模型，例如 UI-TARS 和 CogAgent，提供了强大的语义理解，但引入了高延迟、推理成本、非确定性和架构纠缠. On the other hand, end-to-end vision language action (VLA) models, such as UI-TARS and CogAgent, provide robust semantic understanding but introduce high latency, inference costs, non-determinism, and architectural entanglement[25, 15, 21]。 这种纠缠在整体模型中产生了隐藏的技术债务；由于缺乏结构模块化、正交性和隔离性，更改或微调会带来灾难性遗忘的风险，即“改变一切都会改变一切”(CACE) 反模式. This entanglement creates hidden technical debt within monolithic models; changes or fine-tuning risk catastrophic forgetting, the Changing Anything Changes Everything (CACE) anti-pattern, due to a lack of structural modularity, orthogonality, and isolation[26, 24]。 因此，每个原始操作（例如单击）的响应时间可能会滞后几秒钟，从而使整体 VLA 不适合企业实时控制循环。 最终，架构师被迫用实时控制来换取语义适应性。. Consequently, response times can lag several seconds per primitive action, e.g., a click, making monolithic VLAs unsuitable for enterprise real-time control loops. Ultimately, architects are forced to trade real-time control for semantic adaptability.

可行的设计解决方案通过混合架构综合来避免这种二分法，重新构建语义差距A viable design solution avoids this dichotomy through a hybrid architectural synthesis, reframing the semantic gap[19]作为 Sim2Real 差距。 在这种方法中，代理在理想化的语义世界中进行计划，但在嘈杂的、部分可观察的数字现实中执行操作。 因此，它们不能被设计为严格的脚本，而是通过虚拟感知和效应器与 GUI 生态系统交互的具体代理，需要强大的视觉基础和推理。 借鉴基于行为的机器人技术的原理as a Sim2Real gap. In this approach, agents plan within an idealized semantic world but execute actions in a noisy, partially observable digital reality. Consequently, they must be designed not as rigid scripts, but as embodied agents that interact with GUI ecosystems via virtual percepts and effectors, demanding robust visual grounding and reasoning. Drawing on principles from behavior-based robotics[2]，这需要分层架构。 通过快速去耦、确定性接地（系统 1, this requires a hierarchical architecture. By decoupling fast, deterministic grounding (System 1[16]）从缓慢的概率认知层（系统 2，包含用于感知恢复的 VLA 监督器和用于长视野规划的语义世界模型），该架构弥合了长视野认知规划和原始感觉运动执行之间的差距。) from the slow, probabilistic cognitive layer (System 2, encompassing the VLA supervisor for perceptual recovery and the semantic world model for long-horizon planning), this architecture bridges the gap between long-horizon cognitive planning and primitive sensorimotor execution.

本文不是提出一种新的感知模型，而是解决一个基本的软件架构问题，解决如何将具有冲突质量属性的异构组件（即确定性低延迟控制和概率性高延迟语义推理）构建和组合成可靠的运行时架构。 因此，对软件架构社区的贡献在于架构分解、跨控制循环的责任分配、显式组件协调以及关键质量属性权衡的解决，涉及延迟、可靠性、可解释性和成本。 我们用弹性视觉代理的模式语言捕获这些重复出现的解决方案，引入四种架构设计模式：(1) 混合可供性集成、(2) 自适应视觉锚定、(3) 视觉层次综合和 (4) 语义场景图。 这些模式被综合到一个参考架构中，该架构在监控层中隔离高延迟的概率模型。 这种分层方法允许低延迟执行组件高效运行，最终平衡端到端基于视觉的代理的语义适应性与传统自动化的速度、可审计性和操作稳定性。Rather than proposing a new perception model, this paper addresses a fundamental software architecture problem, tackling how to structure and compose heterogeneous components with conflicting quality attributes, namely, deterministic low-latency control and probabilistic high-latency semantic reasoning, into a dependable runtime architecture. The contribution to the software architecture community, therefore, lies in architectural decomposition, responsibility allocation across control loops, explicit component coordination, and the resolution of critical quality-attribute trade-offs, involving latency, reliability, explainability, and cost. We capture these recurring solutions in a pattern language for resilient visual agents, introducing four architectural design patterns: (1) Hybrid Affordance Integration, (2) Adaptive Visual Anchoring, (3) Visual Hierarchy Synthesis, and (4) Semantic Scene Graph. These patterns are synthesized into a reference architecture that isolates high-latency, probabilistic models within a supervisory layer. This hierarchical approach allows low-latency execution components to operate efficiently, ultimately balancing the semantic adaptability of end-to-end vision-based agents with the speed, auditability, and operational stability of traditional automation.

II 背景及相关工作Background and Related Work

在图形用户界面上运行的自主代理越来越多地针对缺乏可靠 API、DOM 结构或稳定自动化挂钩的基于屏幕的企业环境，例如传统桌面应用程序、远程桌面会话或虚拟化系统。 在这种设置中，代理必须像人类用户一样在视觉上感知界面并对其进行操作Autonomous agents operating on graphical user interfaces increasingly target screen-based enterprise environments lacking reliable APIs, DOM structures, or stable automation hooks, for example, legacy desktop applications, remote desktop sessions, or virtualized systems. In such settings, agents must visually perceive and act upon the interface much like human users[9]。 这创造了一个要求很高的工程环境，其中感知不确定性、UI 变化、延迟限制和操作可靠性是首要问题。. This creates a demanding engineering context where perceptual uncertainty, UI variation, latency constraints, and operational reliability are first-class concerns.

从历史上看，GUI 自动化一直由脚本、宏和 RPA 等确定性方法主导。 虽然高效、可审核并且适合重复的工作流程，但它们通常会因 UI 漂移、布局变化或缺少选择器而变得脆弱。 最近，VLA 模型（例如 CogAgent 和 UI-TARS）已经展示了解释原始屏幕像素并生成语义通知操作的能力Historically, GUI automation has been dominated by deterministic approaches such as scripts, macros, and RPA. While efficient, auditable, and suited for repetitive workflows, they are often brittle under UI drift, layout shifts, or missing selectors. More recently, VLA models, such as CogAgent and UI-TARS, have demonstrated the ability to interpret raw screen pixels and generate semantically informed actions[25, 15, 3]。 然而，在提高适应性的同时，VLA 也带来了新的挑战，包括高延迟、概率行为、成本和生产中可预测性降低等。. However, while improving adaptability, VLAs introduce new challenges regarding high latency, probabilistic behavior, cost, and reduced predictability in production.

这种紧张和复杂性的急剧增加揭示了一个基本的软件架构问题，而不仅仅是模型选择问题。 架构提供了既定的机制，例如分解、显式协调、分层控制和可重用模式，以构建组件职责和交互边界This tension and sharp increase in complexity reveal a fundamental software architecture problem, not merely a model-selection one. Architecture provides established mechanisms, e.g., decomposition, explicit coordination, layered control, and reusable patterns, to structure component responsibilities and interaction boundaries[24]。 通过系统地约束设计空间来平衡冲突的力量，架构模式提供了行为保证. By systematically constraining the design space to balance conflicting forces, architectural patterns provide behavioral guarantees[7, 23, 13]。 他们将架构假设和设计目标转化为明确的结构边界，即组件和连接器。. They translate architectural assumptions and design goals into explicit structural boundaries, i.e., components and connectors.

尽管最近的研究积极探索代理视觉感知，但它主要将代理视为整体的端到端模型Although recent research actively explores agentic visual perception, it predominantly treats agents as monolithic, end-to-end models[21]。 现有文献缺乏在实时约束下结合异构模型和确定性执行组件的架构方法。 为了解决这一差距，我们的工作综合了已建立的跨学科范式，即视觉感知的生态方法. Existing literature lacks architectural approaches that combine heterogeneous models and deterministic execution components under real-time constraints. To address this gap, our work synthesizes established interdisciplinary paradigms, i.e., the ecological approach to visual perception[6], 卡尼曼的, Kahneman’s“系统1和系统2”“System 1 and System 2”双过程理论dual-process theory[16]，来自机器人学的分层包容架构, the layered subsumption architecture from robotics[2]，以及自主 MAPE-K 控制回路, and the autonomic MAPE-K control loop[18]。 通过应用这些基础，后续部分提出了一种用于弹性用户类视觉代理的分层模式语言和参考架构. By applying these foundations, the subsequent sections propose a hierarchical pattern language and reference architecture for resilient user-like visual agents[8].

IV-A 混合可供性集成模式Hybrid Affordance Integration Pattern

VI 结论Conclusion

这项研究解决了代理工程中反复出现的软件架构挑战：脆弱的确定性预先编写的工作流程与较慢视觉模型的语义灵活性之间的二分法。 为了解决这个问题，我们提出了一种架构方法，将高成本的语义推理限制为This study addresses a recurring software architecture challenge in agent engineering: the dichotomy between brittle deterministic pre-scripted workflows and the semantic flexibility of slower vision models. To resolve this, we presented an architectural approach that constrains high-cost semantic reasoning to a“主管循环，supervisor loop,”它修复并引导低延迟which repairs and guides a low-latency“反射环。reflex loop.”

通过将这种方法形式化为弹性视觉代理的模式语言，我们将代理从开环脚本转变为能够主动感知和自主恢复的闭环控制系统。 我们的可行性分析表明，这种架构模式保留了工业自动化的速度和可审计性，同时通过选择性监督推理提高了弹性。 此外，通过生成显式的、可查询的语义场景图，该架构解决了概率模型的部分测试悖论，使组织能够转向更强大的语义契约测试。By formalizing this approach into a pattern language for resilient visual agents, we transform the agent from an open-loop script into a closed-loop control system capable of active perception and autonomous recovery. Our feasibility analysis indicates that this architectural pattern preserves the speed and auditability of industrial automation while improving resilience through selective supervisory reasoning. Furthermore, by generating an explicit, queryable semantic scene graph, the architecture resolves part of the testing paradox of probabilistic models, enabling organizations to shift toward more robust semantic contract testing.

展望未来，我们计划通过更广泛的工业案例研究的定量评估来充分验证该架构。 具体来说，我们将根据最先进的基准（包括纯 VLA 系统）对架构进行基准测试，以衡量延迟减少、UI 漂移弹性和整体操作稳健性的统计显着性。As an outlook, we plan to fully validate this architecture through quantitative evaluation across broader industrial case studies. Specifically, we will benchmark the architecture against state-of-the-art baselines, including pure VLA systems, to measure the statistical significance of latency reductions, resilience to UI drift, and overall operational robustness.

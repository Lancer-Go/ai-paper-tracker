摘要Abstract

随着时间的推移与用户交互的人工智能助手需要解释用户当前的情绪状态，以便提供适当和个性化的响应。用户当前的情绪状态可能取决于早期事件、重复触发因素、之前的支持尝试以及跨会话展开的较长情绪轨迹。然而，现有资源仍然将这个问题分为两个互不相关的评估设置：情感数据集主要评估局部或瞬时影响，而长期记忆基准主要侧重于事实回忆、时间一致性或知识更新。这使得评估模型是否可以使用记住的交互历史记录来解释用户当前的情感状态的支持有限。AI assistants that interact with users over time need to interpret the user’s current emotional state in order to provide appropriate and personalized responses. A user’s present emotional state may depend on earlier events, recurring triggers, prior support attempts, and longer emotional trajectories that unfold across sessions. Yet existing resources still separate this problem into two disconnected evaluation settings: emotion datasets mainly assess local or instantaneous affect, while long-term memory benchmarks focus largely on factual recall, temporal consistency, or knowledge updating. This leaves limited support for evaluating whether a model can use remembered interaction history to interpret a user’s present affective state.

Results show that A-MBER is most discriminative on the subsets it is designed to stress, including long-range implicit affect, high-dependency memory levels, trajectory-based reasoning, and adversarial conditions. These findings suggest that memory contributes to affective interpretation not merely by exposing more historical content, but by enabling more selective, grounded, and context-sensitive use of interaction history.

1 简介Introduction

随着人工智能系统走向长期交互，它们越来越需要推断用户当前的情感状态，以便随着时间的推移做出适当的响应、提供支持并维持个性化行为。这种需求出现在多种环境中，包括辅导、陪伴、咨询、客户支持和其他形式的重复互动。在这种情况下，内存的实用价值不仅在于存储更多的用户历史记录，还在于利用该历史记录来支持更好地理解当前时刻的用户。这种观点与以记忆为中心的系统尤其相关，例如 Memory Bear，它将长期交互构建为依赖于记忆的过程，并强调自适应记忆维护、情感敏感的解释以及跨会话的更连续的用户理解As AI systems move toward longer-term interaction, they increasingly need to infer a user’s current affective state in order to respond appropriately, provide support, and sustain personalized behavior over time. This need arises in a wide range of settings, including tutoring, companionship, counseling, customer support, and other forms of repeated interaction. In such scenarios, the practical value of memory lies not only in storing more user history, but in using that history to support better understanding of the user in the present moment. This perspective is especially relevant for memory-centered systems such as Memory Bear, which frame long-term interaction as a memory-dependent process and emphasize adaptive memory maintenance, affect-sensitive interpretation, and more continuous user understanding across sessions[11, 10].

然而，在许多现实情况下，不能仅从当前回合推断用户当前的情感状态。当根据早期事件、反复出现的触发因素、先前的支持尝试或较长的情绪轨迹进行解释时，简短、礼貌或看似中立的反应实际上可能反映出失望、戒备、压抑或关系距离。因此，这种情况下所需的能力既不是通用的长期事实记忆，也不是传统的局部情感识别。相反，它是使用记住的多会话交互历史来支持的能力In many realistic cases, however, a user’s present affective state cannot be inferred from the current turn alone. A brief, polite, or seemingly neutral response may in fact reflect disappointment, guardedness, suppression, or relational distance when interpreted against earlier events, recurring triggers, prior support attempts, or a longer emotional trajectory. The capability required in such cases is therefore neither generic long-term factual memory nor conventional local emotion recognition. Rather, it is the ability to use remembered multi-session interaction history to support现在的情感解释present affective interpretation：不仅为当前回合分配本地情感标签，而且根据先前的交互推断应如何理解用户当前的状态，并将该解释建立在历史相关证据的基础上。: not merely assigning a local emotion label to the current turn, but inferring how the user’s present state should be understood in light of prior interaction and grounding that interpretation in historically relevant evidence.

现有的评估资源不能很好地解决这个问题。一方面，长期会话记忆基准极大地推进了对扩展交互历史中的事实回忆、时间推理、知识更新和相关记忆操作的评估Existing evaluation resources do not capture this problem well. On one side, long-term conversational memory benchmarks have substantially advanced the evaluation of factual recall, temporal reasoning, knowledge updates, and related memory operations over extended interaction history[4, 12]。另一方面，情感和多模态对话数据集具有先进的局部情感识别、情感分析、移情反应和情感因果基础。尚未充分研究的是模型是否可以使用记住的多会话交互历史记录来解释用户当前的情感状态。换句话说，这种能力的实际需求是明确的，但衡量它的基准支持仍然有限。. On the other side, emotion and multimodal conversation datasets have advanced local emotion recognition, sentiment analysis, empathetic response, and emotion-cause grounding. What remains insufficiently studied is whether a model can use remembered multi-session interaction history to interpret a user’s present affective state. In other words, the practical need for this capability is clear, but benchmark support for measuring it remains limited.

The name is intended to foreground the benchmark’s focus on affective memory while remaining close in spirit to the broader Memory Bear line of memory-centered research. A-MBER is designed to evaluate whether a model can use multi-session interaction history to interpret the user’s present affective state at a designated anchor turn, rather than relying on the local turn alone. Given an interaction trajectory, an anchor turn, and a task condition, the model must infer the user’s current affective state, identify the historically relevant evidence, and explain why that interpretation is warranted. The goal is therefore not only to test whether a model reaches a plausible affective judgment, but whether it reaches that judgment for the right historical reasons.

为了支持这一目标，我们通过具有显式中间表示的分阶段基准管道构建 A-MBER。在本研究中，主要的构建路线是单代理管道，选择它是为了实现可控性、模式稳定性和大规模基准生产。同时，更广泛的框架还容纳了智能体之间的交互作为辅助构建机制，并为未来扩展中更多面向部署的交互设置留下了空间。在这些构建路线中保持稳定的是基准定义本身：共享交互表示、锚点转向接口、证据基础约束和任务结构。To support this goal, we construct A-MBER through a staged benchmark pipeline with explicit intermediate representations. In the present study, the primary construction route is a single-agent pipeline, chosen for controllability, schema stability, and benchmark production at scale. At the same time, the broader framework also accommodates agent-to-agent interaction as an auxiliary construction regime and leaves room for more deployment-oriented interaction settings in future extensions. What remains stable across these construction routes is the benchmark definition itself: a shared interaction representation, anchor-turn interface, evidence-grounding constraint, and task structure.

该基准是围绕多会话对话交互建立的，其中情感解释可能取决于文本内容和与交付相关的线索。在当前版本中，此信息通过对话文本以及结构化交付描述来表示，这些描述以受控基准格式保留与情感相关的声音属性。这种设计使基准可以跨模型类使用，同时保留在纯转录评估中可能丢失的信息。当部分本地可用信号变得较弱、模糊或不可用时，它还可以测试历史依据的解释是否保持稳定。更丰富的多模式扩展，包括更强的音频接地设置和额外的感知通道，仍然是未来版本的自然方向。The benchmark is built around multi-session conversational interaction in which affective interpretation may depend on both textual content and delivery-related cues. In the present version, this information is represented through dialogue text together with structured delivery descriptions that preserve affect-relevant vocal properties in a controlled benchmark format. This design keeps the benchmark usable across model classes while retaining information that would otherwise be lost in plain transcript-only evaluation. It also makes it possible to test whether historically grounded interpretation remains stable when part of the locally available signal becomes weaker, ambiguous, or unavailable. Richer multimodal extensions, including stronger audio-grounded settings and additional perceptual channels, remain natural directions for future versions.

A-MBER 围绕三个主要任务系列进行组织：A-MBER is organized around three primary task families:判断力judgment, 检索retrieval, 和, and解释explanation。判断任务询问模型是否能够在锚点转动时推断出正确的当前情感解释。检索任务询问是否可以识别历史相关的支持回合。解释任务询问它是否可以以历史为基础的方式证明解释的合理性。此外，该基准还包括控制、稳健性导向和对抗性设置，旨在将真正的长期情感理解与表面的局部成功区分开来。. Judgment tasks ask whether the model can infer the correct present affective interpretation at the anchor turn. Retrieval tasks ask whether it can identify the historically relevant supporting turns. Explanation tasks ask whether it can justify the interpretation in a historically grounded way. In addition, the benchmark includes control, robustness-oriented, and adversarial settings designed to separate genuine long-horizon affective understanding from superficial local success.

2 相关工作Related Work

2.1 长期会话记忆基准Long-Term Conversational Memory Benchmarks

最近的工作已经开始评估语言代理的长期会话记忆，而不仅仅是单会话上下文的使用。 LoCoMo 引入了超长期会话记忆的基准，使用结构化管道构建多会话会话，并通过问答、事件总结和对话生成来评估模型Recent work has begun to evaluate language agents on long-term conversational memory rather than only on single-session context use. LoCoMo introduces a benchmark for very long-term conversational memory, using a structured pipeline to construct multi-session conversations and evaluate models through question answering, event summarization, and dialogue generation[4]。 LongMemEval同样关注聊天助理的长期交互记忆，评估信息提取、多会话推理、时间推理、知识更新和弃权等能力. LongMemEval similarly focuses on long-term interactive memory for chat assistants, evaluating abilities such as information extraction, multi-session reasoning, temporal reasoning, knowledge updates, and abstention[12]。最近，LoCoMo-Plus 认为会话记忆评估应该超越明确的事实回忆，转向具有认知意义和隐含限制的记忆使用. More recently, LoCoMo-Plus argues that conversational memory evaluation should move beyond explicit factual recall toward cognitively meaningful and implicitly constrained memory use[3].

这些基准将长期交互历史作为重要的评估目标，但其主要困难来源仍然是事实保留、时间一致性、知识更新或隐式约束满足。因此，它们与我们的工作高度相关，但它们并没有直接评估模型是否可以使用记住的交互历史记录来解释用户当前的情感状态。These benchmarks establish long-horizon interaction history as an important evaluation target, but their main sources of difficulty remain factual retention, temporal consistency, knowledge updating, or implicit constraint satisfaction. They are therefore highly relevant to our work, yet they do not directly evaluate whether a model can use remembered interaction history to interpret a user’s present affective state.

2.2 情感和多模态对话数据集Emotion and Multimodal Conversation Datasets

另一项工作开发了用于情感识别、情感分析、同理心和对话解释的数据集。 EmotionLines提供了早期会话级情感语料库，以及多方对话中的话语级情感标签A separate line of work has developed datasets for emotion recognition, sentiment analysis, empathy, and explanation in dialogue. EmotionLines provides an early conversation-level emotion corpus with utterance-level emotion labels in multi-party dialogues[2]。 MELD 通过整合文本、声音和视觉信号，将这一方向扩展到多模式多方对话. MELD extends this direction to multimodal multi-party dialogue by incorporating textual, acoustic, and visual signals[5]。 EmpatheticDialogues 将焦点从情感标签转移到基于情感的对话中产生同理心反应. EmpatheticDialogues shifts the focus from emotion labeling to empathetic response generation in emotionally grounded conversations[7]。 RECCON 通过在对话中引入情绪原因识别来进一步强调可解释性. RECCON further emphasizes interpretability by introducing emotion-cause recognition in conversation[6]。相关的多模态情感资源（例如 CMU-MOSEI）以及广泛使用的语音情感数据集（例如 IEMOCAP）也是多模态或声学情感分析的核心资源. Related multimodal affect resources such as CMU-MOSEI, together with widely used speech emotion datasets such as IEMOCAP, are also central resources for multimodal or acoustic affect analysis[13, 1].

这些数据集是情感计算和对话情感建模的重要基础，但它们解决的问题与此处考虑的问题不同。大多数关注于话语或短上下文层面的局部情感识别、移情反应、情感预测或情感原因基础。他们不直接测试模型是否可以依赖记住的多会话交互历史记录来解释用户的当前状态。These datasets are important foundations for affective computing and conversational affect modeling, but they address a different problem from the one considered here. Most focus on local emotion recognition, empathetic response, sentiment prediction, or emotion-cause grounding at the utterance or short-context level. They do not directly test whether a model can rely on remembered multi-session interaction history to interpret the user’s present state.

2.3 综合基准构建和以内存为中心的系统Synthetic Benchmark Construction and Memory-Centered Systems

合成和半合成管道对于构建大型结构化评估资源变得越来越重要。例如，LoCoMo 使用机器-人类管道来创建长期对话数据并从中导出基准任务Synthetic and semi-synthetic pipelines have become increasingly important for building large, structured evaluation resources. LoCoMo, for example, uses a machine–human pipeline to create long-horizon conversational data and derive benchmark tasks from them[4]。更广泛地说，分阶段生成显示了显式中间表示对于提高数据构造的可控性、覆盖范围和一致性的实用价值. More broadly, staged generation has shown the practical value of explicit intermediate representations for improving controllability, coverage, and consistency in data construction[9]。多智能体生成和验证框架进一步表明，在多个智能体之间分配生成和检查角色可能会提高某些设置中的多样性或真实性，尽管这种方法也会在强结构约束下降低生产稳定性. Multi-agent generation and verification frameworks further suggest that distributing generation and checking roles across multiple agents may improve diversity or realism in some settings, although such approaches can also reduce production stability under strong structural constraints[8].

这条工作与我们的建设战略密切相关。 A-MBER 也是通过分阶段基准构建构建的，结构化中间层用于保持长期规划、可观察交互、证据基础和最终任务打包之间的一致性。与此同时，我们基准测试的更广泛动机与 Memory Bear 等以记忆为中心的系统密切相关，这些系统激发了对评估资源的需求，这些资源超越事实回忆，并在受控条件下可测量记忆历史的情感敏感使用This line of work is closely related to our construction strategy. A-MBER is also built through staged benchmark construction, with structured intermediate layers used to maintain alignment between long-horizon planning, observable interaction, evidence grounding, and final task packaging. At the same time, the broader motivation of our benchmark is closely connected to memory-centered systems such as Memory Bear, which motivate the need for evaluation resources that go beyond factual recall and make affect-sensitive use of remembered history measurable under controlled conditions[11, 10]。从这个意义上说，我们的工作与以记忆为中心的系统设计是一致的，但它的贡献是在基准层面：目标是为长视野情感记忆提供评估资源，而不是提出一种新的记忆架构。. In this sense, our work is aligned with memory-centered system design, but its contribution is at the benchmark level: the goal is to provide an evaluation resource for long-horizon affective memory rather than to propose a new memory architecture.

5 实验Experiments

5.1 实验目标Experimental Goals

这些实验旨在回答两个相关问题。首先，相对于模型仅依赖于有限的本地上下文的设置，对记忆的访问是否可以提高情感记忆任务的性能？其次，如果是这样，这种优势从何而来：更广泛地获取互动历史，更好地选择相关证据，或者在不完整、模棱两可或可能误导的当地条件下更有力地利用该历史进行长期情感解释？The experiments are designed to answer two related questions. First, does access to memory improve performance on affective-memory tasks relative to settings in which the model relies only on limited local context? Second, if so, where does this advantage come from: broader access to interaction history, better selection of relevant evidence, or stronger use of that history for long-horizon affective interpretation under incomplete, ambiguous, or potentially misleading local conditions?

A-MBER 不仅仅是作为一个系统比另一个系统获得更高总分的基准。其目的是测试记忆对于当前状态解释依赖于记住的历史而不是仅依赖于本地措辞的项目类型是否特别有用。因此，实验不仅围绕整体性能进行组织，还围绕几个特定于基准的维度进行组织，包括内容类型、内存水平、推理结构和鲁棒性条件。这些分析不仅可以询问记忆是否有帮助，还可以询问记忆在哪些方面最有帮助，以及这种改进反映了什么样的历史推理。A-MBER is not intended merely as a benchmark on which one system obtains a higher aggregate score than another. Its purpose is to test whether memory becomes especially useful on the kinds of items for which present-state interpretation depends on remembered history rather than local wording alone. For this reason, the experiments are organized not only around overall performance, but also around several benchmark-specific dimensions, including content type, memory level, reasoning structure, and robustness condition. These analyses make it possible to ask not only whether memory helps, but where it helps most and what kind of historical reasoning that improvement reflects.

5.2 比较系统Compared Systems

我们比较了五种系统配置。We compare five system configurations.

无记忆基线。No-Memory Baseline.

该基线仅接收锚点转向或最小的本地上下文，而无法访问更广泛的跨会话历史记录。它作为下限比较，用于测试仅从当地证据可以恢复多少当前状态的解释。This baseline receives only the anchor turn or minimal local context, without access to broader cross-session history. It serves as the lower-bound comparison for testing how much present-state interpretation can be recovered from local evidence alone.

长上下文基线。Long-Context Baseline.

该基线被赋予了更大的交互历史原始窗口，但没有显式检索或结构化记忆支持。它测试简单地暴露更多历史是否足以进行强烈的情感解释。This baseline is given a larger raw window of interaction history but no explicit retrieval or structured memory support. It tests whether simply exposing more history is sufficient for strong affective interpretation.

检索内存基线。Retrieved-Memory Baseline.

该基线使用当前输入以及检索到的历史上下文子集进行回答。它隔离了显式检索的影响，并允许在原始长上下文和选定的支持历史之间进行比较。This baseline answers using the current input together with a retrieved subset of historical context. It isolates the effect of explicit retrieval and allows comparison between raw long context and selected supporting history.

结构化内存系统。Structured Memory System.

这种配置对应于具有显式记忆组织的系统，例如红熊AI记忆系统。目的是测试结构化记忆是否不仅有助于了解历史，而且有助于有效地利用情感敏感的解释。This configuration corresponds to a system with explicit memory organization, such as the Red Bear AI memory system. The aim is to test whether structured memory helps not only with access to history, but also with its effective use for affect-sensitive interpretation.

黄金证据条件。Gold-Evidence Condition.

该可选条件直接提供从基准注释导出的黄金支持历史。它并不是作为一个现实的基线，而是作为一种分析工具，用于估计剩余的困难有多少来自证据选择而不是下游解释。This optional condition directly provides gold supporting history derived from benchmark annotation. It is not intended as a realistic baseline, but as an analysis tool for estimating how much of the remaining difficulty comes from evidence selection as opposed to downstream interpretation.

这些设置共同定义了一条比较路径，从最小的本地上下文到更广泛的原始上下文，到检索到的证据，到结构化记忆，最后到黄金证据访问。这种进展使得可以分离几个不同的性能增益来源，否则这些来源可能会在单个整体系统比较中混为一谈。Together, these settings define a comparison path from minimal local context, to broader raw context, to retrieved evidence, to structured memory, and finally to gold-evidence access. This progression makes it possible to separate several distinct sources of performance gain that would otherwise be conflated in a single overall system comparison.

At the context level, the main comparisons include local-only settings, full-history settings, retrieved-history settings, structured-memory settings, and gold-evidence conditions. These are not treated as separate benchmarks, but as controlled conditions within the same evaluation framework. Their purpose is to test whether access to longer-range evidence remains useful when the locally available signal is weak, incomplete, or potentially misleading. This is especially important for affective-memory evaluation, since many realistic interaction failures do not arise from the complete absence of information, but from situations in which local evidence is suggestive yet insufficient.

6 讨论和未来的扩展Discussion and Future Extensions

6.1 当前的基准仍然遗漏了什么What Current Benchmarks Still Miss

A-MBER 的动机是现有资源只能部分解决这一差距。长期会话记忆基准在评估多会话推理、时间跟踪和远程信息保留方面取得了重要进展，而情感和多模态会话数据集为话语级情感识别、同理心和解释提供了宝贵的资源。然而，这两项工作对于评估系统是否可以使用具有情感意义的历史记录来解释用户在会话中的当前状态的支持仍然有限。A-MBER is motivated by a gap that remains only partially addressed by existing resources. Long-term conversational memory benchmarks have made important progress in evaluating multi-session reasoning, temporal tracking, and long-range information retention, while emotion and multimodal conversation datasets have provided valuable resources for utterance-level emotion recognition, empathy, and explanation. Yet these two lines of work still leave limited support for evaluating whether a system can use emotionally meaningful history to interpret a user’s current state across sessions.

这种差距很重要，因为许多真正的交互失败并不是由于忘记一个孤立的事实而引起的。当系统无法认识到先前的失望、反复出现的触发因素、不断变化的支持偏好或累积的关系动态如何改变当前时刻的意义时，就会出现这种情况。因此，如果系统无法以基于历史的方式重建用户的情绪轨迹，那么它可能在事实记忆基准上表现良好，但仍然会以情感上不恰当的方式表现。 A-MBER 旨在使这种缺失的能力变得可测量。This gap matters because many real interaction failures do not arise from forgetting an isolated fact. They arise when a system fails to recognize how prior disappointments, recurring triggers, changing support preferences, or accumulated relationship dynamics alter the meaning of the present moment. A system may therefore perform well on factual memory benchmarks and still behave in affectively inappropriate ways if it cannot reconstruct the user’s emotional trajectory in a historically grounded manner. A-MBER is intended to make this missing capability measurable.

出于同样的原因，A-MBER 不应被理解为仅在原始交互长度的基础上与现有的长上下文或长记忆基准进行竞争。在我们的设置中，长期难度不仅由回合数或文本长度来定义，还由事件依赖性的密度、情感相关历史和跨会话解释负担来定义。即使交互比某些超长上下文基准中使用的交互短，如果当前的解释依赖于紧密耦合的情感和关系历史，它仍然可能会提出大量的长程推理要求。For the same reason, A-MBER should not be understood as competing with existing long-context or long-memory benchmarks on the basis of raw interaction length alone. In our setting, long-horizon difficulty is defined not only by turn count or text length, but also by the density of event dependencies, affect-relevant history, and cross-session interpretive burden. Even when an interaction is shorter than those used in some very-long-context benchmarks, it may still impose substantial long-range reasoning demands if present interpretation depends on a tightly coupled emotional and relational history.

目前的实验结果进一步阐明了这一基准目标的含义。特别是，较低的仅本地基线并不是问题难度的意外副产品，而是将基准的主要质量集中在当前解释无法仅从锚点转向中可靠恢复的情况的结果。与此同时，黄金证据性能仍明显低于上限的事实表明，A-MBER 并未降低为纯粹的证据访问基准。即使提供了黄金支持证据，基于历史的情感解释仍然存在除了证据选择之外的巨大困难。The current experimental results further clarify what this benchmark target entails. In particular, the low local-only baseline is not an accidental by-product of question difficulty, but a consequence of concentrating the benchmark’s main mass on cases where present interpretation is not reliably recoverable from the anchor turn alone. At the same time, the fact that gold-evidence performance remains clearly below ceiling indicates that A-MBER does not reduce to a pure evidence-access benchmark. Even when gold supporting evidence is provided, historically grounded affective interpretation retains substantial difficulty beyond evidence selection alone.

6.2 为什么情感记忆对于以记忆为中心的系统很重要Why Affective Memory Matters for Memory-Centered Systems

情感记忆对于以记忆为中心的系统很重要，因为长期交互的价值不仅仅取决于持久存储。系统可能会记录大量的用户历史记录、检索表面相关的事件或维护较大的上下文窗口，但仍然无法以有效的适当方式进行响应。重要的不仅是系统是否记住更多，还在于随着时间的推移，它是否使用记住的历史记录来更恰当地解释用户。Affective memory matters for memory-centered systems because the value of long-term interaction depends on more than persistent storage. A system may record extensive user history, retrieve superficially relevant episodes, or maintain large context windows, yet still fail to respond in a way that is affectively appropriate. What matters is not only whether the system remembers more, but whether it uses remembered history to interpret the user more appropriately over time.

这正是 A-MBER 旨在评估的视角。它的价值在于分离系统优势的不同可能来源。模型可能表现良好，因为它看到了更多上下文，因为它检索了更好的证据，或者因为它更有效地组织和使用记住的历史。通过包括无记忆、长上下文、检索记忆、结构化记忆和黄金证据比较设置，基准测试不仅可以询问记忆系统的整体性能是否更好，还可以询问这种优势来自何处。这对于像 Memory Bear 这样以记忆为中心的系统尤其重要，其预期的优势不仅在于暴露更多的历史内容，还在于以结构化的方式维护和部署记忆，以进行情感敏感的下游解释。This is precisely the perspective that A-MBER is designed to evaluate. Its value lies in separating different possible sources of system advantage. A model may perform well because it sees more context, because it retrieves better evidence, or because it organizes and uses remembered history more effectively. By including no-memory, long-context, retrieved-memory, structured-memory, and gold-evidence comparison settings, the benchmark makes it possible to ask not only whether a memory system performs better overall, but where that advantage comes from. This is particularly relevant for memory-centered systems such as Memory Bear, whose intended strength lies not merely in exposing more historical content, but in maintaining and deploying memory in a structured way for affect-sensitive downstream interpretation.

目前的结果与这一观点是一致的。从仅本地访问到更广泛的历史记录，然后再次从原始历史记录到选定的历史记录，再从检索到结构化内存，性能得到提高。这一进展支持了比“更多背景有帮助”更强有力的主张。它表明，长视野互动中的情感记忆不仅取决于更多地了解过去，还取决于以与当前时刻相关的方式选择、组织和使用记忆的历史。The present results are consistent with this perspective. Performance improves from local-only access to broader history, then again from raw history to selected history, and again from retrieval to structured memory. This progression supports a stronger claim than “more context helps.” It suggests that affective memory in long-horizon interaction depends not only on seeing more of the past, but on selecting, organizing, and using remembered history in a way that is relevant to the current moment.

6.3 当前基准的局限性Limitations of the Current Benchmark

当前的基准有几个限制。首先，尽管构建管道是结构化的并基于显式的中间表示，但它仍然依赖于生成的交互而不是自然发生的人类对话。结果，真正的人际动态的某些方面仍然被简化，特别是时间不规则、谈话脱轨、微妙的不一致以及长期互动中更广泛的混乱。更一般地说，即使生成的数据对于受控评估仍然有用，合成构建也可以使事件结构、证据链和情感依赖性比现实对话中通常的情况更清晰。The current benchmark has several limitations. First, although the construction pipeline is structured and grounded in explicit intermediate representations, it still depends on generated interaction rather than naturally occurring human conversation. As a result, some aspects of real interpersonal dynamics remain simplified, especially timing irregularities, conversational derailments, subtle inconsistencies, and the broader messiness of long-term interaction. More generally, synthetic construction can make event structure, evidence chains, and affective dependencies cleaner than they would typically be in realistic dialogue, even when the resulting data remain useful for controlled evaluation.

其次，该基准目前是在关系结构相对狭窄的单一受控场景中实例化的，即教师与学生或辅导员与学生风格的交互。这是一个合理的起点，因为它提供了稳定的角色关系、具有情感意义的轨迹以及与长期支持环境的明确一致性。同时，它限制了领域通用性的直接主张。该框架旨在跨更广泛的场景进行迁移，但这对于角色边界不太稳定的交互设置（例如陪伴、同伴交互、客户支持或以护理为导向的对话）仍有待证明。Second, the benchmark is currently instantiated in a single controlled scenario with a relatively narrow relational structure, namely a teacher–student or counselor–student style interaction. This is a reasonable starting point because it provides stable role relations, emotionally meaningful trajectories, and clear alignment with long-term support settings. At the same time, it limits immediate claims of domain generality. The framework is intended to transfer across broader scenarios, but this remains to be demonstrated for interaction settings with less stable role boundaries, such as companionship, peer interaction, customer support, or care-oriented dialogue.

第三，基准仍然反映出任务形式化受到限制。锚转接口很有用，因为它可以以受控方式测量当前状态解释，但它仍然是一个基准接口，而不是实际部署的完整模型。在实际交互中，用户不会将其内部状态呈现为具有预定义证据边界的项目。因此，A-MBER 捕获了一项重要且之前被低估的功能，但它是通过面向任务的长期交互片段而不是通过对现实世界使用的详尽模拟来实现的。Third, the benchmark still reflects a constrained task formalization. The anchor-turn interface is useful because it makes present-state interpretation measurable in a controlled way, but it remains a benchmark interface rather than a complete model of real deployment. In actual interaction, users do not present their internal state as an item with a predefined evidence boundary. A-MBER therefore captures an important and previously under-evaluated capability, but it does so through a task-oriented slice of long-term interaction rather than through an exhaustive simulation of real-world use.

第四，虽然基准包括开放形式的解释任务，但它们的评估仍然部分取决于标题引导的语义判断。封闭式项目允许相对直接的评分，但解释项目不可避免地保留了对评估器设计、可接受答案覆盖率和判断稳定性的一定依赖。这并没有削弱此类评估的有用性，但它确实意味着应谨慎解释开放形式项目的细粒度分数差异。Fourth, although the benchmark includes open-form explanation tasks, their evaluation still depends in part on rubric-guided semantic judgment. Closed-form items admit relatively direct scoring, but explanation items inevitably retain some dependence on evaluator design, acceptable-answer coverage, and judge stability. This does not undermine the usefulness of such evaluation, but it does mean that fine-grained score differences on open-form items should be interpreted with appropriate caution.

第五，相对于实际交互中遇到的全部模糊性，当前的鲁棒性条件仍然有限。模态缺失、模态模糊和证据不足的设置是有用的第一步，但它们仍然只涵盖了长期矛盾、部分可观察性和复杂的多模态不一致的更广泛空间的一部分。一个相关的实际挑战是，由于基准有意集中在历史相关和情感隐含的情况下，即使对于强大的模型，仅本地性能也可能相当低。这在一定程度上是一个设计目标，但它也增加了在解释总体分数时仔细的答案校准、评估者稳定性和子集级分析的重要性。Fifth, the current robustness conditions remain limited relative to the full range of ambiguity encountered in real interaction. Modality-missing, modality-ambiguous, and insufficient-evidence settings are useful first steps, but they still cover only part of the broader space of prolonged contradiction, partial observability, and complex multimodal inconsistency. A related practical challenge is that, because the benchmark is intentionally concentrated on historically dependent and affectively implicit cases, local-only performance may be quite low even for strong models. This is partly a design goal, but it also increases the importance of careful answer calibration, evaluator stability, and subset-level analysis when interpreting overall scores.

同样，虽然基准框架可以适应单智能体和多智能体构建，但本研究尚未在更长的轨迹下提供这些机制之间的明确比较。单智能体分阶段生成被用作主要途径，因为它提供了更强的可控性和更稳定的排列，而多智能体生成的长期优势仍有待更充分地建立。Similarly, while the benchmark framework can accommodate both single-agent and multi-agent construction, the present study does not yet provide a definitive comparison between these regimes under substantially longer trajectories. Single-agent staged generation is used as the primary route because it provides stronger controllability and more stable alignment, whereas the longer-horizon advantages of multi-agent generation remain to be established more fully.

最后，我们的长期困难概念是有意以任务为导向的。我们认为，长期难度不仅应该由原始长度来定义，还应该由事件密度、情感相关依赖性和跨会话解释负担来定义。我们相信这是情感记忆的适当框架，但它并不是长期困难的唯一可能定义。因此，A-MBER 应被解读为长期情感推理的一个原则性观点，而不是所有长期情境评估的单一明确标准。Finally, our notion of long-horizon difficulty is intentionally task-oriented. We argue that long-range difficulty should be defined not only by raw length, but also by event density, affect-relevant dependency, and cross-session interpretive burden. We believe this is the appropriate framing for affective memory, but it is not the only possible definition of long-range difficulty. A-MBER should therefore be read as one principled perspective on long-horizon affective reasoning rather than as a single definitive standard for all long-context evaluation.

6.4 未来的扩展Future Extensions

一些扩展将加强未来版本中的基准。首先是更广泛的场景和关系覆盖。将 A-MBER 扩展到当前的师生风格设置之外，将可以测试相同的基准逻辑是否适用于不同的情感和关系结构，包括陪伴、同伴支持、客户互动和长期护理设置。Several extensions would strengthen the benchmark in future versions. The first is broader scenario and relation coverage. Extending A-MBER beyond the current teacher–student style setting would make it possible to test whether the same benchmark logic holds across different affective and relational structures, including companionship, peer support, customer interaction, and longer-term care settings.

第二个扩展涉及更丰富的感知证据。在当前的基准中，情感解释主要基于对话文本以及结构化的交付相关信息。未来的版本可以包含更强大的基于音频的设置、视觉提示、面部表情、凝视、姿势或更广泛的交互环境。这样的扩展将允许对多模态情感记忆进行更现实的评估，并使更直接地研究跨模态不一致性成为可能。同时，应该谨慎对待这个方向，因为更丰富的感知信号也会增加注释的复杂性并使受控评估变得更加困难。A second extension concerns richer perceptual evidence. In the current benchmark, affective interpretation is grounded primarily in dialogue text together with structured delivery-related information. Future versions could incorporate stronger audio-grounded settings, visual cues, facial expression, gaze, posture, or broader interaction context. Such extensions would allow more realistic evaluation of multimodal affective memory and would make it possible to study cross-modal inconsistency more directly. At the same time, this direction should be approached carefully, since richer perceptual signals also increase annotation complexity and make controlled evaluation more difficult.

第三个扩展是更强的评估端验证。特别是，未来的工作应该更直接地检验开放式评分的稳健性，例如通过多位法官比较、人工验证或自动评估与基于法官的评估之间更强的一致性分析。随着解释任务变得更加核心，这将加强基准。A third extension is stronger evaluation-side validation. In particular, future work should examine the robustness of open-form scoring more directly, for example through multi-judge comparison, human validation, or stronger agreement analysis between automatic and judge-based evaluation. This would strengthen the benchmark as explanation tasks become more central.

第四个扩展涉及数据现实性。尽管合成结构提供了可控性和覆盖范围，但未来版本的基准可以受益于人工编写、人工修改或部分人工收集的交互数据。这样的设置将有助于测试基准测试的情感记忆的核心概念在嘈杂和结构不太清晰的对话下是否保持稳定。更多的具体化或设备介导的交互也可能在这个更广泛的背景下变得相关，不是作为基准定义的中心，而是作为通向更现实的长期交互轨迹的一种可能途径。A fourth extension concerns data realism. Although synthetic construction provides controllability and coverage, future versions of the benchmark could benefit from human-written, human-revised, or partially human-collected interaction data. Such settings would help test whether the benchmark’s core notion of affective memory remains stable under noisier and less cleanly structured dialogue. More embodied or device-mediated interaction may also become relevant in this broader context, not as the center of the benchmark definition, but as one possible route toward more realistic long-term interaction traces.

6.5 更广阔的前景Broader Outlook

更广泛地说，我们认为 A-MBER 是迈向更丰富的长视野互动情感记忆评估生态系统的第一步。当前版本建立了一个受控的基准目标、一个结构化的构建框架和一组评估维度，使历史扎根的情感解释可测量。未来的工作可以沿着几个方向扩展这个生态系统：更广泛的场景覆盖、更丰富的多模式输入、更强的评估器验证、更现实的数据收集以及不同内存架构和构建机制之间的更深入比较。More broadly, we view A-MBER as a first step toward a richer evaluation ecosystem for affective memory in long-horizon interaction. The current version establishes a controlled benchmark target, a structured construction framework, and a set of evaluation dimensions that make historically grounded affective interpretation measurable. Future work can extend this ecosystem along several axes: broader scenario coverage, richer multimodal inputs, stronger evaluator validation, more realistic data collection, and deeper comparison across different memory architectures and construction regimes.

从这个意义上说，A-MBER 不仅旨在作为静态数据集，而且作为研究记忆如何随着时间的推移支持情感理解的基础设施。它的主要贡献是使以前被低估的能力变得可见：不仅仅是系统是否记住过去，而是它是否可以使用记住的历史来理解用户现在的感受。In this sense, A-MBER is intended not only as a static dataset, but as infrastructure for studying how memory supports affective understanding over time. Its main contribution is to make a previously under-measured capability visible: not simply whether a system remembers the past, but whether it can use remembered history to understand what the user is feeling now.

7 结论Conclusion

本文介绍了 A-MBER，This paper introduces A-MBER, an情绪识别的情感记忆基准Affective Memory Benchmark for Emotion Recognition，评估现有长期记忆基准和现有情感或多模式对话数据集尚未充分捕获的能力：使用记住的多会话交互历史记录来支持对用户当前情感状态的基于历史的解释。从这个意义上说，A-MBER 的设计目的不仅是评估记忆作为存储，而且作为情感理解的主动资源。, to evaluate a capability that remains insufficiently captured by existing long-term memory benchmarks and existing emotion or multimodal conversation datasets: using remembered multi-session interaction history to support historically grounded interpretation of a user’s present affective state. In this sense, A-MBER is designed to evaluate memory not merely as storage, but as an active resource for affective understanding.

为了使这种能力可测量，我们提出了一个基于分阶段生成和显式中间表示的结构化基准构建框架。在当前的研究中，该框架主要通过单代理构建管道进行实例化，以实现可控性和模式稳定性，同时在相同基准逻辑下保持与替代交互实现的兼容性。由此产生的基准支持判断、检索和解释任务，以及按内容类型、记忆水平、推理结构和鲁棒性条件进行分层分析。To make this capability measurable, we propose a structured benchmark construction framework based on staged generation and explicit intermediate representations. In the current study, this framework is primarily instantiated through a single-agent construction pipeline for controllability and schema stability, while remaining compatible with alternative interaction realizations under the same benchmark logic. The resulting benchmark supports judgment, retrieval, and explanation tasks, together with layered analysis by content type, memory level, reasoning structure, and robustness condition.

我们的实验表明，仅从本地环境中很难解决 A-MBER，并且随着系统获得更广泛、更具选择性和更结构化的历史访问权限，性能会持续提高。最强的收益恰恰出现在基准最苛刻的地方：长期隐性影响、高度依赖历史的项目、基于轨迹的推理和对抗性条件。与此同时，黄金证据的表现也仍然低于上限，这一事实表明，即使有黄金支持证据，该基准仍然存在很大的解释困难。Our experiments show that A-MBER is not easily solvable from local context alone, and that performance improves consistently as systems are given broader, more selective, and more structured access to history. The strongest gains appear precisely where the benchmark is intended to be most demanding: long-range implicit affect, highly history-dependent items, trajectory-based reasoning, and adversarial conditions. At the same time, the fact that gold-evidence performance also remains below ceiling suggests that the benchmark preserves substantial interpretation difficulty even when gold supporting evidence is available.

更广泛地说，A-MBER 旨在支持对以记忆为中心的交互系统的评估，包括 Memory Bear 等系统，其价值不仅取决于记住更多的用户历史记录，还取决于使用该历史记录随着时间的推移提供更加情感敏感、个性化和上下文适当的行为。我们希望这项工作能够成为朝着更丰富的长视野交互中情感记忆评估生态系统迈出的有用一步，包括未来扩展到更广泛的场景、更丰富的多模态证据、更现实的交互设置以及不同记忆架构之间更强的比较。More broadly, A-MBER is intended to support the evaluation of memory-centered interactive systems, including systems such as Memory Bear, whose value depends not only on remembering more user history, but on using that history to provide more affect-sensitive, individualized, and contextually appropriate behavior over time. We hope this work serves as a useful step toward a richer evaluation ecosystem for affective memory in long-horizon interaction, including future extensions to broader scenarios, richer multimodal evidence, more realistic interaction settings, and stronger comparison across different memory architectures.

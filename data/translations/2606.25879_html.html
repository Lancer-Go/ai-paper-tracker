摘要Abstract

尽管计算再现性是科学研究的核心，但它仍然很困难。在本文中，我们展示了国际 FABRIC 测试平台如何通过 LoomAI 与大型语言模型 (LLM) 编码助手相结合，从而简化跨多个领域复制已发表的实验。我们重现了 FABRIC 上的三个案例研究，涵盖 BBR 系列拥塞控制评估、仅 CPU MPI 集群上的 LAMMPS 分子动力学缩放基准以及应激蛋白稳态基因组学管道。Computational reproducibility remains difficult despite being central to scientific research. In this paper, we show how the international FABRIC testbed, combined with large language model (LLM) coding assistants through LoomAI, can simplify reproducing published experiments across multiple domains. We reproduced three case studies on FABRIC, covering BBR-family congestion-control evaluations, LAMMPS molecular dynamics scaling benchmarks on a CPU-only MPI cluster, and stress protein homeostasis genomics pipelines.

我们不只关注匹配的数字输出，而是评估重复的实验是否支持与原始研究相同的科学结论。人工智能助手在设置环境、调整代码和调试方面非常有效，但在缺乏明确定义的工作流程的分析阶段遇到了困难，这些阶段需要人工指导来建立执行顺序和数据依赖关系。Rather than focusing only on matching numerical outputs, we evaluate whether the reproduced experiments support the same scientific conclusions as the original studies. The AI assistant was effective in setting up the environment, adapting code, and debugging, but struggled with the analysis stages that lacked clearly defined workflows, which required human guidance to establish execution order and data dependencies.

Ⅲ-AIII-A 案例研究选择Case Study Selection

IV-C 评价Evaluation

我们在声明级别进行评估，而不是要求数字标识，因为重新运行使用了当前的 FABRIC 图像、当前的包版本和新的切片。因此，主要结果不是每个吞吐量值是否匹配，而是复制的数据是否改变了每篇论文的科学解释。We evaluate at the claim level rather than requiring numerical identity, since the reruns used current FABRIC images, current package versions, and new slices. The primary result is therefore not whether every throughput value matched, but whether the reproduced data changed the scientific interpretation of each paper.

Second, the single-to-multi-node transition (32 to 48 cores) produces a sharp performance cliff for long-range potentials, with Rhodopsin and SPC/E actually losing throughput when crossing the node boundary.

这三个案例研究形成了一个进程，揭示了人工智能辅助生殖的成功之处和失败之处。 BBR 系列案例研究选自已知使用 FABRIC 的出版物，是对 FABRIC 原生网络研究的人工智能驱动复制的最直接测试。 LAMMPS 最初并不是在 FABRIC 上进行的，并且使用了我们无法匹配的 GPU 硬件，但公开可用的输入文件允许在仅 CPU 的 MPI 集群上完整再现，并且最初的扩展结论在完全不同的硬件上成立。基因组学研究是最难的，因为它既没有在 FABRIC 上进行，也没有完全保存，数据缺失意味着并非所有结论都可以得到独立验证。在这个梯度上，图案是一致的。由于硬件变化，数值有所不同，但当工件完成时，科学结论保持不变。如果我们仅通过数字接近度来评估成功，那么忠实的复制就会被判定为失败，这就是为什么结论级别的评估很重要。The three case studies form a progression that reveals where AI-assisted reproduction succeeds and where it breaks down. The BBR-family case study, selected from publications known to use FABRIC, was the most direct test of AI-driven reproduction on FABRIC-native networking research. LAMMPS was not originally conducted on FABRIC and used GPU hardware we could not match, yet the publicly available input files allowed a complete reproduction on a CPU-only MPI cluster, and the original scaling conclusions held on entirely different hardware. The genomics study was the hardest because it was neither conducted on FABRIC nor fully deposited, and missing data meant that not all conclusions could be independently verified. Across this gradient, the pattern is consistent. Numerical values differed due to hardware changes, but scientific conclusions remained intact when the artifacts were complete. Had we evaluated success solely by numerical proximity, faithful reproductions would have been judged as failures, which is why conclusion-level assessment matters.

基因组学案例还揭示了人工智能的自主性受到工作流程组织的限制。助手只能独立地重现由正式工作流引擎管理的阶段，而临时脚本则需要领域专家提供计算模式。结构更好的工件比能力更强的模型对人工智能的帮助更大。The genomics case also revealed that AI autonomy is bounded by workflow organization. The assistant could independently reproduce only stages managed by formal workflow engines, while ad-hoc scripts required a domain expert to provide the computational schema. Better-structured artifacts would have helped the AI more than a more capable model.

BBR 案例从相反的方向指出了同样的教训。当论文和 GitHub 工件暴露了足够的实验结构时，人工智能可以重建复杂的 FABRIC 网络工作流程并留下可运行的笔记本，而不是一次性重新运行。The BBR case points to the same lesson from the opposite direction. When papers and GitHub artifacts exposed enough experimental structure, the AI could rebuild complex FABRIC networking workflows and leave behind runnable notebooks rather than a one-time rerun.

我们计划将研究扩展到其他领域，构建自动化工件评估工具，并将完成的复制品打包为 LoomAI Weaves，以便其他人可以重新执行它们，而无需重复我们的工作。We plan to extend the study to additional domains, build automated artifact-assessment tooling, and package completed reproductions as LoomAI Weaves so that others can re-execute them without repeating our effort.

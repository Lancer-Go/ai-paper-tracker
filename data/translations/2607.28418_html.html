摘要Abstract

剪枝是提高大型语言模型（LLM）效率的一种有前途的方法。现有的静态结构化修剪方法是硬件友好的，并且可以提供实际的吞吐量增益，但其与输入无关的计算分配通常会在严重稀疏的情况下导致精度大幅下降。最近的动态稀疏方法通过使计算适应各个输入来提高质量保留，但它们在很大程度上仍然仅限于粗粒度的结构决策，并且它们在现实世界推理场景下的实际加速仍然具有挑战性。为了应对这些挑战，我们推出了 WIDE，这是第一个专为预填充和解码场景而设计的端到端可微标记级动态宽度修剪框架。 WIDE 通过允许每个令牌动态选择注意力头组和 FFN 通道组来实现细粒度的计算分配，从而将动态修剪从层级决策扩展到神经元块级粒度。通过两阶段训练管道，WIDE 学习有效的令牌稀疏执行模式，并实现比现有方法更好的质量保留。为了使这种细粒度的动态修剪变得实用，我们进一步提出了一种修剪-内核协同设计框架，该框架将动态稀疏加速分解为掩模重新排序、与硬件无关的块级跳跃和与硬件相关的块内跳跃，从而实现跨不同粒度的高效执行。在稀疏度为 50% 的情况下，与仅校准设置下最先进的动态深度修剪相比，WIDE 的性能提升了 55.1%。在预填充和解码推理工作负载下，WIDE 实现了接近理论的内核级加速，预填充高达 1.98 倍，解码高达 4.95 倍，端到端加速高达 1.68 倍和 1.55 倍。这些结果使 WIDE 成为一种有效的细粒度动态宽度修剪框架，推动了 token-wise 动态结构化修剪的前沿。我们的代码位于Pruning is a promising approach for improving the efficiency of large language models (LLMs). Existing static structured pruning methods are hardware-friendly and can deliver practical throughput gains, but their input-agnostic computation allocation often causes substantial accuracy degradation under aggressive sparsity. Recent dynamic sparsity methods improve quality retention by adapting computation to individual inputs, yet they remain largely limited to coarse-grained structural decisions and their practical acceleration under real-world inference scenarios remains challenging. To address these challenges, we present WIDE, the first end-to-end differentiable token-level dynamic width pruning framework designed for both prefill and decode scenarios. WIDE enables fine-grained computation allocation by allowing each token to dynamically select attention-head groups and FFN-channel groups, extending dynamic pruning beyond layer-level decisions to neuron-block-level granularity. Through a two-stage training pipeline, WIDE learns effective token-wise sparse execution patterns and achieves substantially better quality retention than existing approaches. To make such fine-grained dynamic pruning practical, we further propose a pruning–kernel co-design framework that decomposes dynamic sparsity acceleration into mask reordering, hardware-agnostic block-level skipping, and hardware-dependent intra-block skipping, enabling efficient execution across different granularities. At 50% sparsity, WIDE provides 55.1% performance boost when compared to the state-of-the-art dynamic depth pruning under calibration-only settings. Under prefill and decoding inference workloads, WIDE achieves close-to-theoretical kernel-level speedups of up to 1.98x for prefill and 4.95x for decoding, as well as 1.68x and 1.55x end-to-end acceleration. These results establish WIDE as an effective fine-grained dynamic width pruning framework that pushes the frontier of token-wise dynamic structured pruning. 1 简介Introduction

法学硕士的快速发展使其能够在广泛的现实应用中广泛部署The rapid advancement of LLMs has enabled their widespread deployment across a broad range of real-world applications(Team et al., 2026; DeepSeek-AI, 2026; Meng et al., 2026; Dai et al., 2026; Chen et al., 2026)。然而，随着模型的不断扩展和日益复杂的代理利用系统的出现，高效的法学硕士服务变得越来越具有挑战性。超越系统级和硬件特定的优化. However, as model continue to scale and increasingly complex agent harness systems emerge, the efficient LLM serving has become increasingly challenging. Beyond system-level and hardware-specific optimizations(Kwon et al., 2023; Zheng et al., 2024; Lin et al., 2024; Zadouri et al., 2026)，模型剪枝也作为一种提高推理效率的模型级方法迅速发展。通过沿着深度和宽度维度去除冗余结构，修剪可以减少模型大小和计算成本，从而为高效的 LLM/VLM 服务提供补充路径, model pruning has also evolved rapidly as a model-level approach to improving inference efficiency. By removing redundant structures along the depth and width dimensions, pruning reduces model size and computational cost, thereby offering a complementary path toward efficient LLM/VLM serving(Cheng et al., 2024; Frantar and Alistarh, 2023; Ma et al., 2023; Ashkboos et al., 2023; Men et al., 2025; Wu et al., 2025; 2026b; 2026a).

目前，LLM 剪枝以静态方案为主，它删除预定义的结构，例如整个层Currently, LLM pruning is dominated by static schemes, which remove predefined structures such as entire layers(Kim et al., 2024)，注意力或前馈网络（FFN）子层, attention or feed-forward network (FFN) sublayers(Zhong et al., 2025)、权重矩阵的行或列, rows or columns of weight matrices(Li et al., 2025)，和单个神经元, and individual neurons(Fang et al., 2024)。一旦校准，这些单元将被永久删除，从而使静态修剪易于部署并与现有硬件后端兼容。然而，对每个输入应用相同的修剪决策通常会牺牲模型质量，尤其是在极度稀疏的情况下。动态修剪通过引入根据各个令牌分配计算的轻量级路由器来解决此限制. Once calibrated, these units are permanently removed, making static pruning simple to deploy and compatible with existing hardware backends. However, applying the same pruning decisions to every input often sacrifices model quality, especially under aggressive sparsity. Dynamic pruning addresses this limitation by introducing lightweight routers that allocate computation according to individual tokens(Raposo et al., 2024; Jiang et al., 2024; Zhao et al., 2025; Han et al., 2025)。尽管灵活性有所提高，但现有的动态修剪方法主要在深度级别运行，决定每个令牌是否应该执行或跳过整个层或子模块。这种粗粒度的决策限制了可实现的质量-效率权衡，因为当整个模块被删除时，仅需要层内部分计算的令牌可能仍然会失去有用的容量. Despite their improved flexibility, existing dynamic pruning methods primarily operate at the depth level, deciding whether each token should execute or skip entire layers or submodules. Such coarse-grained decisions limit the achievable quality–efficiency trade-off, as tokens that require only partial computation within a layer may still lose useful capacity when the entire module is removed(Shrestha et al., 2025; Gautam et al., 2026)。同时，将动态修剪推向更细粒度的令牌分配会带来额外的系统挑战：不规则的执行模式可能会阻止减少的计算转化为实际的推理加速. Meanwhile, pushing dynamic pruning toward finer-grained token-wise allocation introduces additional system challenges: irregular execution patterns can prevent the reduced computation from translating into practical inference acceleration(He et al., 2026; Hu et al., 2026)。因此，仍然存在两个基本问题：（1）. Therefore, two fundamental questions remain: (1)动态剪枝能否超越粗粒度的深度决策，以实现更精细的计算分配和更好的质量保留？Can dynamic pruning move beyond coarse-grained depth decisions to achieve finer computation allocation and better quality retention? (2) 这种细粒度的动态决策能否有效执行以提供真正的端到端加速？Can such fine-grained dynamic decisions be efficiently executed to deliver real end-to-end speedups?

Instead of explicitly materializing token-specific sparse tensors, WIDE first performs mask reordering to transform arbitrary token-wise routing patterns into structured execution layouts. 5 结论Conclusion

在这项工作中，我们确定了现代高吞吐量推理系统下当前朴素的令牌式动态剪枝管道的潜在局限性，并提出了一种更细粒度的基于组的动态宽度剪枝基线，并为基于路由的动态结构剪枝提供了统一的加速设计。所提出的 WIDE 使用轻量级瓶颈路由器和可微掩码来为每个令牌选择 GQA 头组和 FFN 参数组，从而将结构化修剪推到层和子层的粒度以下。在系统方面，我们将基于掩码的动态修剪制定为两个步骤：掩码重新排序和渐进式内核内跳过。这种抽象允许定制注意力和 GEMM 内核使用相同的路由决策，同时对密集执行的干扰有限。在仅校准和 LoRA 恢复设置中，WIDE 改进了现有结构化静态和动态修剪方法的质量稀疏性权衡，而其内核将学习到的稀疏性转化为 CUDA Graph 执行下批量预填充和解码工作负载的实际加速。这些结果表明，细粒度动态修剪需要与硬件执行路径一起设计，而不是被视为仅模型的压缩问题。In this work, we identify the potential limitation for current naive token-wise dynamic pruning pipeline under modern high-throughput inference system, and present a finer-grained group-based dynamic width pruning baseline with unified acceleration design for routing-based dynamic structural pruning. The presented WIDE uses lightweight bottleneck routers and differentiable masks to select GQA head groups and FFN parameter groups for each token, pushing structured pruning below the granularity of layers and sublayers. In the system side, we formulate mask-based dynamic pruning as two steps: mask reordering and progressive intra-kernel skipping. This abstraction lets the same routing decisions be consumed by customized attention and GEMM kernels with limited disruption to dense execution. Across calibration-only and LoRA-recovered settings, WIDE improves the quality-sparsity trade-off over existing structured static and dynamic pruning methods, while its kernels translate the learned sparsity into practical speedups under CUDA Graph execution for both batched prefill and decode workloads. These results suggest that fine-grained dynamic pruning needs to be designed together with the hardware execution path, rather than treated as a model-only compression problem.

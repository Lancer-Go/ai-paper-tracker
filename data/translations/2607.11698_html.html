摘要Abstract

生产 LLM 代理（例如 Claude Code 和 Codex）通过部署来行事 不受信任的内容、文件、命令和工作区状态的接口， 所以这里的安全故障是一个真正的动作：一个写入的文件，被泄露 数据或触发的工作流程。红队这些特工必须跟上步伐 随着每一个模型和工具的更新，今天的工具都经过优化 攻击成功并保留表面伪影：基准分数， 有效负载、档案、策略或攻击程序。这些文物记录了 攻击发生的地方，但不是造成攻击的有利条件 代理轨迹不安全，因此很难审计、修补或 设置更改后重用。我们学习Production LLM agents such as Claude Code and Codex act through deployed interfaces over untrusted content, files, commands, and workspace state, so a safety failure here is a real action: a written file, exfiltrated data, or a triggered workflow. Red-teaming these agents must keep pace with every model and tool update, yet today’s tools optimize judged attack success and preserve surface artifacts: benchmark scores, payloads, archives, strategies, or attack programs. These artifacts record where an attack landed, but not the enabling condition that made the agent trajectory unsafe, so they are hard to audit, patch against, or reuse after the setting changes. We study生产代理红队自动研究autoresearch for production-agent red-teaming, 使用一个代理研究环境来自动发现可重复使用的 有关另一个生产型代理的漏洞知识。我们呈现, using one agentic research environment to automatically discover reusable vulnerability knowledge about another production-style agent. We present美国心脏协会AHA，一个可证伪的发现循环：它犯了一个漏洞 假设，创建证伪者，实例化场景有效 攻击，在沙盒代理工具中执行它，反映 轨迹，并将通过证据规则确认的发现促进为, a falsifiable discovery loop: it commits to a vulnerability hypothesis, creates a falsifier, instantiates a scenario-valid attack, executes it in a sandboxed agent harness, reflects on the trajectory, and promotes confirmed findings by an evidence rule into a漏洞概念图 (VCG)Vulnerability Concept Graph (VCG)。每个概念都是一个可审核的单元 通过一个面向攻击者的表面连接到不安全的轨迹 主张、启用条件、证伪者、转移预测和证据。 跨越 Claude Code 和 Codex 的三种场景，跨越直接和 间接攻击，发现的概念共享一个在受害者模型和代理之间重复出现的核心，冻结的 VCG 可以重复使用，无需进一步搜索， 比最强的冻结发现基线高 14.2 个百分点 在相同的单次协议下，概念转移 跨场景和跨直接/间接攻击渠道。这使得 对生产分类直接有用的工件：安全团队可以检查 启用条件、修补代理或工作流程、将概念重新运行为 检查修复情况，并通过相同的方式附加新的内部问题 构建/导入场景工作流程。随着生产代理的激增，这样的 VCG 将一次性红队转变为累积的、可审核的安全 跨模型和产品复合的知识。我们的代码位于. Each concept is an auditable unit linking an attacker-facing surface to an unsafe trajectory through a claim, enabling condition, falsifier, transfer prediction, and evidence. Across Claude Code and Codex on three scenarios spanning direct and indirect attacks, the discovered concepts share a core that recurs across victim models and agents, the frozen VCG is reusable with no further search, outperforming the strongest frozen discovery baseline by 14.2 percentage points under the same single-shot protocol, and the concepts transfer across scenarios and across direct/indirect attack channels. This makes the artifact directly useful for production triage: a safety team can inspect the enabling condition, patch the agent or workflow, rerun the concept as a check on the fix, and attach new internal concerns through the same build/import scenario workflows. As production agents proliferate, such a VCG turns one-off red-teaming into cumulative, auditable safety knowledge that compounds across models and products. 1 简介Introduction

生产 LLM 代理，例如 Claude Code 和 Codex 编写代码、执行 工具，并作为自主工程环境运行，连接到 真实的文件系统、API、工具权限和团队工作流程Production LLM agents such as Claude Code and Codex write code, execute tools, and operate as autonomous engineering environments, wired into real file systems, APIs, tool permissions, and team workflows(Anthropic, 2026a; OpenAI, 2025; Guo et al., 2025; Meng et al., 2026; Pan et al., 2025)。一个安全 这里的失败不再是发出有害文本的模型；这是代理人 采取实际行动：写入文件、窃取数据、修改代码， 调用工具或触发工作流程. A safety failure here is no longer a model emitting harmful text; it is the agent taking a real action: writing a file, exfiltrating data, modifying code, invoking a tool, or triggering a workflow(Guo et al., 2024; Zhang et al., 2024; Guo et al., 2025; Meng et al., 2026; Puppala et al., 2026; Wang et al., 2025a; Pan et al., 2025; Zhang and Pei, 2026)。代理失败正在成为 操作失败，最重要的是轨迹级别， 代理读取攻击者控制的内容，选择一系列 工具调用，并通过文件、命令或工作空间实现危害 状态. Agent failures are becoming operational failures, and the ones that matter are trajectory-level, where an agent reads attacker-controlled content, chooses a sequence of tool calls, and realizes harm through files, commands, or workspace state(Chen et al., 2026a; Feng et al., 2026; Li et al., 2026b; Zhang et al., 2026)。此类系统的红队必须与每一个新模型、新工具保持同步 集成、权限边界和安全补丁。静态基准测试 和漏洞利用生成测试台提供受控测量，同时 提示和有效负载优化器返回具体的攻击或档案 他们，以及更新的自我改进系统保留策略或攻击 节目. Red-teaming such systems must keep pace with every new model, tool integration, permission boundary, and safety patch. Static benchmarks and exploit-generation testbeds provide controlled measurements, while prompt and payload optimizers return concrete attacks or archives of them, and newer self-improving systems retain strategies or attack programs(Chen et al., 2026a; Wang et al., 2026; 2024; Liu et al., 2025a; Gautam et al., 2026; Lee et al., 2026; Chen et al., 2026b);代理防御是 也屡屡被绕过; agent defenses are also repeatedly bypassed(Nasr et al., 2025; Zhan et al., 2025)。 失败模式不再是现有的红队成员找不到突破口。问题在于，判断突破是一个薄弱的知识单元。 在代理设置中，相同的成功信号可能来自基准测试 措辞、瞬态工具状态、判断游戏或偏离目标的轨迹。 优化此类信号并冻结最佳有效负载、存档或 因此，程序合并了两个量：优化器的强度 在搜索过程中以及其留下的内容的可重用性. The failure mode is no longer that existing red-teamers cannot find breaks. The problem is that a judged break is a weak unit of knowledge. In agent settings, the same success signal may come from benchmark wording, transient tool state, judge gaming, or an off-target trajectory. Optimizing such a signal and freezing the best payload, archive, or program therefore conflates two quantities: the strength of the optimizer during search and the reusability of what it leaves behind(Wang et al., 2025c).

为什么可证伪的发现会改变红队的结果。Why falsifiable discovery changes what red-teaming yields.

我们将产品代理红队框架视为一个可证伪的自动研究循环；的洞察力 接下来是红队发现的单位决定其保质期。具体的利用是容易消逝的：它一旦被破坏，就会消失。 代理被修补或模型被交换，并且排行榜由 此类漏洞会随着每次发布而重置。我们的协议强制执行这一点： 保留和转移测试仅保留在没有任何结果的情况下仍然存在的结果 进一步的搜索，以及仍然打破不同场景的概念， 不同的攻击渠道，或者从未发现的受害者模型是 最明显的证据是它命名了位于代理中的持久机制，该机制 仅模型主机。一个机制 漏洞利用衰减的化合物：因为失败是漏洞的一个属性 代理，每次运行都会映射更多的共享漏洞空间，因此红队 活动累积成一张关于代理如何失败的地图，这是一种过时的资产 任何单个版本。这种重构还解决了 该领域日益面临的测量问题：当判断者认为 得分攻击本身是可玩的，原始成功计数很容易计算 充气；我们的消融表明造假者是将可游戏性转变为可玩性的 通过丢弃无法重现的中断来得分为经过验证的声明 一旦脱离了找到他们的搜索。We frame product agent red-teaming as a falsifiable auto-research loop; the insight that follows is that the unit of a red-team finding determines its shelf life. A concrete exploit is perishable: it decays the moment the agent is patched or the model is swapped, and a leaderboard built from such exploits resets with every release. Our protocol enforces this: the held-out and transfer tests keep only findings that survive with no further search, and a concept that still breaks a different scenario, a different attack channel, or a victim model it was never discovered on is the clearest evidence it names a durable mechanism located in the agent, which a model only hosts. A mechanism compounds where an exploit decays: because the failure is a property of the agent, each run maps more of one shared vulnerability space, so a red-team campaign accumulates into a map of how the agent fails, an asset that outlives any single release. This reframing also resolves a measurement problem the field increasingly faces: when the judges that score attacks are themselves gameable, raw success counts are easy to inflate; our ablation shows the falsifier is what converts a gameable score into a validated claim, by discarding breaks that do not reproduce once detached from the search that found them.

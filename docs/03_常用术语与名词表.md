# AI 学术热度追踪平台 - 常用术语与名词表

> 统一项目内的领域驱动设计 (DDD) 词汇表，避免沟通和变量命名时的歧义。

| 业务术语 (中文) | 标准英文/字段名 | 含义解释域场景说明 | 同义词/曾用名 (防踩坑) |
|---------------|---------------|-------------------|----------------------|
| 论文 | Paper | 来源于原始学术平台的一篇学术研究文章 | 文章、Document |
| 热度得分 | Hot Score | 根据引文量、时间衰减等多维度指标计算出的论文综合热度指标 | 排序分、Ranking Score |
| arXiv ID | Arxiv ID | arXiv 平台上的论文唯一标识符（例如: 2305.12345） | 论文 ID |
| 外部来源 | Source / Provider | 提供论文元数据或引用数据的第三方 API（如 arXiv, OpenAlex） | 数据源 |
| 引文量 | Citations | 论文被其他学术文章引用的次数（从 OpenAlex 获取） | 引用数 |
| 数据导出产物 | Exported JSON | 每天爬虫或处理器执行完毕后生成的、供前端直接渲染的静态 JSON 文件 | 静态数据 |

In this section we make this discrepancy explicit, empirically characterize its magnitude, and sketch its underlying causes.

为什么贪婪解码还不够Why Greedy Decoding Is Not Enough

LLM 推理点可能会出现不一致，并且由那里的令牌概率分布的形状决定。尖锐的分布将大部分质量集中在单个代币上，并且是Inconsistency can arise at LLM inference points and is governed by the shape of the token-probability distribution there. Sharp distributions place most mass on a single token and are有弹性的resilient噪声：来自 GPU 浮点运算、请求批处理或标记器状态的微小扰动不足以对顶部标记进行重新排序。相比之下，扁平分布将相当的质量放在几个紧密相连的代币上，并且to noise: minor perturbations from GPU floating-point arithmetic, request batching, or tokenizer state are not enough to reorder the top token. Flat distributions, by contrast, place comparable mass on several near-tied tokens and are脆弱的vulnerable对于同样的噪音：一个小的扰动就足以改变哪个标记出现在顶部。这就是为什么这个问题不能仅通过解码策略来解决：切换到贪婪解码或使用固定种子采样，只能解决给定概率分布如何转变为令牌选择的问题，它对以下事实没有任何作用：在托管端点上，由于平台噪声，概率本身在运行之间略有变化。因此，即使在零温度（贪婪）解码下，对同一模型的相同提示仍然可以在不同的运行中产生不同的标记选择。 至关重要的是，单个响应的置信度（例如，所选路径的每个令牌对数概率）仅揭示了模型对其所采取的路径的置信度，而不是与亚军的接近程度，即决策实际上对这种噪声的弹性如何。因此，预测某个步骤是否会在未来的运行中翻转需要估计to that same noise: a small perturbation is enough to change which token comes out on top. This is why the problem cannot be fixed by decoding strategy alone: switching to greedy decoding, or to sampling with a fixed seed, only fixes how a given probability distribution is turned into a token choice, it does nothing about the fact that, on a hosted endpoint, the probabilities themselves shift slightly from run to run due to platform noise. So the same prompt to the same model can still yield different token choices on different runs, even under temperature-zero (greedy) decoding. Critically, the confidence of a single response (e.g., the per-token log-probability of the chosen path) reveals only how confident the model was in the path it took, not how close the runners-up were, that is, how resilient the decision actually is to this noise. Predicting whether a step will flip on a future run therefore requires estimating the形状shape对代理有意义的结果的分布，而不仅仅是所采取的一条路径的深度，这是我们通过重采样获得的估计。of the distribution over agent-meaningful outcomes, not just the depth of the one path taken, an estimate we obtain via resampling.

6 讨论和限制Discussion and Limitations

指南验证。Guideline validation.上述管道允许每个生成的指南直接进入内存。我们留给未来工作的一个自然扩展是生成和内存准入之间的验证阶段：在存储指南之前，在其源步骤重新运行分析器的重采样过程，并将指南注入到提示中，并且仅当步骤一致性显着提高并且不会在一组保留的相关轨迹上回归时才承认它。这将防止指导方针含糊不清、与现有指令相冲突，或者过度拟合它们所衍生的轨迹的偶然细节，这是更广泛的代理记忆中的已知风险The pipeline described above admits every generated guideline directly into memory. A natural extension, which we leave to future work, is a validation stage between generation and memory admission: before a guideline is stored, re-run the analyzer’s resampling procedure at its source step with the guideline injected into the prompt, and admit it only if step consistency measurably improves and does not regress on a held-out set of related trajectories. This would guard against guidelines that are vague, conflict with existing instructions, or overfit to incidental details of the trajectory they were derived from, a known risk in agentic memory more broadly(Xiong et al. 2025).

7 结论Conclusion

目前的法学硕士代理人“平均”通过任务的方式掩盖了他们未能通过任务的频率Current LLM agents pass tasks “on average” in a way that masks how often they fail to pass the一样same重复任务。我们提出了一个框架，通过以一致性为目标的情景记忆指南来减少这种一致性差距：黑盒一致性分析器对每个推理点进行重新采样，以呈现有翻转风险的决策，指南生成器将它们转换为一致性指南。在 AppWorld 上使用 ReAct 和 GPT-4.1，管道提升了 Passtask on repeat. We presented a framework that reduces this consistency gap through consistency-targeted episodic memory guidelines: a black-box Consistency Analyzer resamples each inference point to surface decisions at risk of flipping, and a Guideline Generator converts them into consistency guidelines. On AppWorld with ReAct and GPT-4.1, the pipeline lifts Pass^5 x 16 点相同任务和 13 点相似任务，精度没有下降；仅聚合轨迹一致性与轨迹通过/失败相关（AUROC5 by 16 points same-task and 13 points similar-task with no accuracy degradation; aggregate trajectory consistency alone correlates with trajectory pass/fail (AUROC≈0.69\approx 0.69），让分析器支持生成器自己对不存在地面真实评级的轨迹结果的判断。), letting the analyzer support the generator’s own judgment of trajectory outcome where no ground-truth rating exists.

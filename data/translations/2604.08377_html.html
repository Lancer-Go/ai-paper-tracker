SkillClaw：让技能与 Agentic Evolver 一起进化SkillClaw: Let Skills Evolve Collectively with Agentic Evolver

马子玉Ziyu Ma[1] [*][∗] , 杨世东Shidong Yang[1] [*][∗] , 吉玉祥Yuxiang Ji[1] [*][∗] , 王旭聪Xucong Wang[1] [*][∗] , 王勇Yong Wang[1] [†] , 胡一鸣Yiming Hu[1] , 黄同文Tongwen Huang[1] , 褚香香Xiangxiang Chu[1]

1DreamX团队，1DreamX Team,∗同等贡献，Equal contribution,†项目负责人Project lead

OpenClaw 等大型语言模型 (LLM) 代理依赖可重用的技能来执行复杂的任务，但这些技能在部署后基本上保持静态。因此，用户之间会反复重新发现类似的工作流程、工具使用模式和故障模式，从而阻碍系统随着体验而改进。虽然来自不同用户的交互提供了有关技能何时有效或失败的补充信号，但现有系统缺乏将此类异构体验转换为可靠的技能更新的机制。为了解决这些问题，我们提出了 SkillClaw，这是一个多用户代理生态系统中集体技能进化的框架，它将跨用户和超时交互视为提高技能的主要信号。 SkillClaw 不断聚合在使用过程中生成的轨迹，并通过自主进化器对其进行处理，该进化器可识别重复出现的行为模式，并通过完善现有技能或扩展新功能将其转化为技能集的更新。生成的技能保存在共享存储库中并在用户之间同步，从而允许在一个上下文中发现的改进在系统范围内传播，同时不需要用户额外的努力。通过将多用户体验融入到持续的技能更新中，SkillClaw 实现了跨用户知识转移和累积能力提升，WildClawBench 上的实验表明，在有限的交互和反馈下，它显着提高了 Qwen3-Max 在真实代理场景中的性能。Large language model (LLM) agents such as OpenClaw rely on reusable skills to perform complex tasks, yet these skills remain largely static after deployment. As a result, similar workflows, tool usage patterns, and failure modes are repeatedly rediscovered across users, preventing the system from improving with experience. While interactions from different users provide complementary signals about when a skill works or fails, existing systems lack a mechanism to convert such heterogeneous experiences into reliable skill updates. To address these issues, we present SkillClaw, a framework for collective skill evolution in multi-user agent ecosystems, which treats cross-user and over-time interactions as the primary signal for improving skills. SkillClaw continuously aggregates trajectories generated during use and processes them with an autonomous evolver, which identifies recurring behavioral patterns and translates them into updates to the skill set by refining existing skills or extending them with new capabilities. The resulting skills are maintained in a shared repository and synchronized across users, allowing improvements discovered in one context to propagate system-wide while requiring no additional effort from users. By integrating multi-user experience into ongoing skill updates, SkillClaw enables cross-user knowledge transfer and cumulative capability improvement, and experiments on WildClawBench show that limited interaction and feedback, it significantly improves the performance of Qwen3-Max in real-world agent scenarios.

1 简介1 Introduction

大型语言模型 (LLM) 代理（Yao 等人，2022 年；Shinn 等人，2023 年）已迅速使个人人工智能助理在现实世界中变得实用，OpenClaw 等系统使用户能够通过自然对话完成复杂的任务。用户现在可以要求代理配置服务、调试 API 调用或自动化多步骤工作流程，依靠它来协调工具使用和中间推理。这些能力主要由技能驱动，技能编码用于与工具交互和解决任务的结构化程序。在当前的部署中，用户通常从集中式技能中心选择并安装技能来满足他们的需求，并且这些技能充当代理行为的主要构建块。然而，技能生态系统在很大程度上仍然是静态的（Zhang 等人，2025b；Naihin 等人，2023；Song 等人，2026），因为技能是手动安装和维护的，并且在交互过程中发现的解决方案很少会在单独的会话之外持续存在。Large language model (LLM) agents (Yao et al., 2022; Shinn et al., 2023) have rapidly made personal AI assistants practical in real-world settings, with systems such as OpenClaw enabling users to complete complex tasks through natural conversation. A user can now ask an agent to configure a service, debug an API call, or automate a multi-step workflow, relying on it to coordinate tool usage and intermediate reasoning. These capabilities are largely driven by skills, which encode structured procedures for interacting with tools and solving tasks. In current deployments, users typically select and install skills from a centralized skill hub to meet their needs, and these skills serve as the primary building blocks for agent behavior. However, the skill ecosystem remains largely static (Zhang et al., 2025b; Naihin et al., 2023; Song et al., 2026), as skills are manually installed and maintained and solutions discovered during interaction rarely persist beyond individual sessions.

这种限制在日常使用中变得很明显。例如，用户经常要求代理完成多步骤任务，例如自动化数据处理工作流程，其中失败常常是由于参数格式不正确或工具调用不匹配等微妙问题引起的。通过几轮试验和错误，代理可能最终得出一个可行的解决方案，甚至是一个更稳定的程序。然而，这些改进仍然仅限于当前会话，并没有整合到技能集中或延续到未来的交互中。随着类似的任务在不同的用户之间重复出现，并且随着时间的推移，相同的故障和恢复模式会被重复观察到，但系统并没有改善其行为。这从根本上是有问题的，因为用户在重叠的任务空间中操作，其中共享相似的工作流程、工具和故障模式，但系统无法利用这些重复出现的体验。因此，每个用户被迫独立地重新发现解决方案，从而阻止知识在系统级别积累。因此，关键的挑战不仅是提高单个会话中的性能，而且还使This limitation becomes evident in everyday usage. For example, users often ask agents to complete multi-step tasks such as automating data processing workflows, where failures frequently arise from subtle issues such as incorrect argument formats or mismatched tool calls. Through several rounds of trial and error, an agent may eventually arrive at a working solution or even a more stable procedure. However, these improvements remain confined to the current session and are not consolidated into the skill set or carried forward to future interactions. As similar tasks recur across different users and over time, the same patterns of failure and recovery are repeatedly observed, yet the system does not improve its behavior. This is fundamentally problematic because users operate in overlapping task spaces where similar workflows, tools, and failure modes are shared, but the system fails to leverage these recurring experiences. Consequently, each user is forced to rediscover solutions independently, preventing knowledge from accumulating at the system level. 在社交交互中，进化主要提高工作流程的明确性和执行的可靠性。该类别已经开始具有相对完整的任务导向技能，包括会议协调、Slack 任务提取、可行性分析、状态报告、支持分流和执行摘要。因此，限制不是缺少功能，而是可执行性不足。最有影响力的更新来自执行层总结，涵盖消息检索、信息过滤、数据验证、风险提取和结构化输出。一旦这项技能从描述性指令重写为明确的程序工作流程，性能就会急剧提高。会议协调和可行性分析的后续更新主要是细化和加强这一现有结构。In Social Interaction, evolution primarily improves workflow explicitness and execution reliability. 5 结论5 Conclusion

我们提出了 SkillClaw，一个多用户代理生态系统中技能集体进化的框架。 SkillClaw 将普通的交互轨迹转化为共享证据，并使代理进化者能够通过改进和创建来更新技能，从而使在使用过程中发现的知识随着时间的推移在用户之间积累和传播。这建立了一个持续的演进循环，将孤立的交互级改进和系统级能力增长联系起来。在概念层面上，SkillClaw 强调了从静态技能库到动态、交互驱动的技能生态系统的转变。我们的框架没有将技能视为固定资源，而是使它们能够通过现实世界的使用来发展，捕获重复出现的程序模式，纠正故障并适应不同的执行环境。我们希望这项工作能够推动未来对集体和自我改进代理系统的研究，利用跨用户体验来实现持续和适应性的能力增长。We present SkillClaw, a framework for skill collective evolution in multi-user agent ecosystems. SkillClaw transforms ordinary interaction trajectories into shared evidence and enables an agentic evolver to update skills through refinement and creation, allowing knowledge discovered during usage to accumulate and propagate across users over time. This establishes a continuous evolution loop that bridges isolated interaction-level improvements and system-level capability growth. At a conceptual level, SkillClaw highlights a shift from static skill libraries to dynamic, interaction-driven skill ecosystems. Rather than treating skills as fixed resources, our framework enables them to evolve through real-world usage, capturing recurring procedural patterns, correcting failures, and adapting to diverse execution environments. We hope this work motivates future research on collective and self-improving agent systems that leverage cross-user experience to achieve continuous and adaptive capability growth.

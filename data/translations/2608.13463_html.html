用于鲁棒跨数据集图像分类的 MLLM 路由异构集成MLLM‑Routed Heterogeneous Ensembles for Robust Cross‑Dataset Image Classification

摘要Abstract

现代图像分类模型在单一任务特定数据集上进行训练时表现出色，但通常难以跨领域和难度级别进行泛化。我们提出了 ARMDIL，一种使用 LLM 进行多域图像分类的自适应路由器。 ARMDIL 是一个集成，它使用多模态大语言模型 (MLLM) 代理将每个图像动态路由到最合适的视觉主干。我们多样化的集成采用卷积神经网络 (ResNets)、自监督表示学习器 (SSL) 和视觉语言模型 (VLM)，每个模型都在由具有不同分布和特征的多个图像数据集构建的统一标签空间上进行训练。实证评估阐明了跨不同视觉领域的每种架构的独特功能和漏洞。至关重要的是，我们证明了 ARMDIL 有效地应对了这些权衡，与基于专门训练的路由器相比具有竞争力。此外，它允许通过简单的提示修改来集成新信息，同时通过自然语言推理痕迹增强可解释性，从而极大地提高了适应性。跨数据集图像分类的这些进步为更可靠的通用视觉系统（例如人工智能助手和自主机器人）铺平了道路。Modern image classification models excel when trained on single task‑specific datasets but often struggle to generalize across domains and difficulty levels. We propose ARMDIL, an Adaptive Router for Multi-Domain Image classification with LLMs. ARMDIL is an ensemble that uses a multimodal large language model (MLLM) agent to dynamically route each image to the most suitable vision backbone. Our diverse ensemble employs convolutional neural networks (ResNets), self-supervised representation learners (SSL), and vision-language models (VLMs), each trained on a unified label space constructed from multiple image datasets with differing distributions and characteristics. Empirical evaluations illuminate the distinct capabilities and vulnerabilities of each architecture across disparate visual domains. Crucially, we show that ARMDIL effectively navigates these trade-offs, performing competitively with specialized training-based routers. Furthermore, it drastically improves adaptability by allowing new information to be integrated via simple prompt modifications, while enhancing interpretability through natural language reasoning traces. These advances in cross-dataset image classification pave the way for more reliable general-purpose vision systems such as AI assistants and autonomous robots.

1 简介Introduction

现代图像分类系统越来越多地部署在广泛的现实环境中，从医学成像和农业到面部识别和自动驾驶。例如，虽然应用于 MRI 扫描的分类模型可以帮助临床医生诊断脑肿瘤，但嵌入自动驾驶车辆中的分类模型对于检测道路危险至关重要。尽管当代模型在这些特定的、孤立的领域中取得了显着的准确性，但视觉问题的多样性带来了严峻的挑战：针对一项任务高度优化的模型经常会在另一项任务上失败。例如，胸部 X 光片的结构细微差别与自然图像以对象为中心的性质几乎没有共同特征。Modern image classification systems are increasingly deployed across a vast spectrum of real-world environments, from medical imaging and agriculture to facial recognition and autonomous driving. For instance, while classification models applied to MRI scans assist clinicians in diagnosing brain tumors, those embedded in autonomous vehicles are crucial for detecting road hazards. Although contemporary models achieve remarkable accuracy within these specific, isolated domains, the sheer diversity of visual problems presents a critical challenge: a model highly optimized for one task frequently fails on another. The structural nuances of a chest X-ray, for example, share very few characteristics with the object-centric nature of natural images.

卷积神经网络 (CNN)Convolutional Neural Networks (CNNs)[36]和视觉变压器 (ViT)and Vision Transformers (ViTs)[13]是第一个在单一任务上取得非常成功结果的模型，用模拟空间关系的操作取代完全连接的线性层。虽然这些标准深度学习架构在其训练分布中表现出色，但要使它们适应新任务或不断发展的分类目标，需要进行大量的再训练。对大量标记数据集和计算资源的持续需求限制了它们在动态、现实场景中的稳健性和适用性。were the first models to deliver highly successful results on single tasks, replacing fully connected linear layers with operations that model spatial relationships. While these standard deep learning architectures excel within their training distributions, adapting them to new tasks or evolving classification goals requires extensive retraining. This constant need for massive labeled datasets and computational resources limits their robustness and applicability in dynamic, real-world scenarios.

自监督图像表示学习 (SSL)Self-Supervised Image Representation Learning (SSL)[11]和视觉语言模型 (VLM)and Vision Language Models (VLMs)[31]可以通过大规模预训练学习图像的可转移表示来缓解其中一些问题。当 SSL 或 VLM 部署为专门分类模型的预训练主干时，网络不再需要从头开始学习许多基本视觉概念。这加快了整体训练时间并减少了对大型注释数据集的依赖。然而，微调单个主干通常会将模型锁定到特定于任务的目标，从而阻碍跨领域泛化。can mitigate some of these issues by learning transferable representations of images via large-scale pretraining. When SSL or VLMs are deployed as pretrained backbones for a specialized classification model, the network no longer has to learn as many fundamental visual concepts from scratch. This accelerates overall training times and reduces reliance on large annotated datasets. However, fine-tuning a single backbone often locks the model into task-specific goals, hindering cross-domain generalization.

克服这种单一模型限制的常见策略是部署不同架构的集合。然而，传统的密集集成的计算成本很高，而且是动态路由方法A common strategy to overcome this single-model limitation is to deploy an ensemble of diverse architectures. However, traditional dense ensembles are computationally expensive and dynamic routing methods[2, 10]是僵化且不可解释的。自然语言处理的最新进展提供了一种有前途的替代方案：利用多模态大型语言模型（MLLM）作为智能代理are rigid and uninterpretable. Recent advancements in natural language processing offer a promising alternative: utilizing Multi-Modal Large Language Models (MLLMs) as intelligent agents[53]。 MLLM 代理可以智能地推理视觉输入，以确定哪个专用主干最适合特定实例，而不是详尽地执行所有模型。这有效地消除了整体黑匣子，为开发人员提供了对每个图像处理方式的透明、可解释的控制。. Rather than exhaustively executing all models, an MLLM agent can intelligently reason about the visual input to determine which specialized backbone is best fit for a specific instance. This effectively removes the ensemble black box, providing developers with transparent, interpretable control over how each image is processed.

我们提出了一个通过代理路由的镜头执行跨数据集图像分类的框架。我们的专业“工具包”集成了异构架构系列，包括 ResNet、SSL 和 VLM。每个模型都在跨越多个不同数据集的统一标签空间上单独训练。在推理时，MLLM 代理动态分析输入图像并选择单独的主干网。通过用 MLLM 提示取代黑盒、训练量大的路由，我们的方法提供了一个高度适应性的集成，在性能上与专用路由器相匹配，同时提供可解释的自然语言推理和控制。We propose a framework that performs cross-dataset image classification through the lens of agentic routing. Our specialized “toolkit” integrates heterogeneous architectural families, including ResNets, SSL, and VLMs. Each model is trained separately on a unified label space spanning multiple distinct datasets. At inference time, the MLLM agent dynamically analyzes the input image and selects the individual backbone. By replacing black-box, training-heavy routing with MLLM prompting, our approach delivers a highly adaptable ensemble that matches specialized routers in performance while providing interpretable natural language reasoning and control.

3 方法论Methodology

我们提出了 ARMDIL：一种使用 LLM 进行多域图像分类的自适应路由器（We present ARMDIL: an Adaptive Router for Multi-Domain Image classification with LLMs (Figure 1）。给定一组分类模型（专家），每个模型在各自的领域都表现出色，ARMDIL 利用 MLLM 来预测给定图像的视觉域。然后，我们的框架将图像路由给最佳专家进行分类。这种方法为标准集成提供了一种可解释且适应性强的替代方案，产生自然语言推理痕迹，并允许我们在无需重新训练的情况下融入新知识。). Given a set of classification models (experts), each excelling in their respective domain, ARMDIL leverages an MLLM to predict the visual domain of a given image. Our framework then routes the image to the optimal expert for classification. This approach provides an interpretable and adaptable alternative to standard ensembles, yielding natural language reasoning traces and allowing us to incorporate new knowledge without retraining.

3.3.2 集成基线Ensemble Baselines

与 ARMDIL 一起评估两个集成基线，以评估基于 MLLM 的路由的优势。第一个是简单的多数投票 (MV) 集成，其中每个骨干模型独立预测给定输入的类标签，最终输出由多数投票决定。虽然这是一种标准的免培训方法，但它存在许多限制。首先，每个输入都必须由所有分类器处理，当多个专家数量很大时，就会产生计算瓶颈。其次，由于它天真地对所有专家赋予同等权重，因此多数投票集合无法利用各个模型的特定领域优势。在专业领域之外表现不佳的专家可能会产生共同的偏见，导致他们自信地收敛于相同的错误预测。最后，如果任何专家接受过受限或不相交标签空间的培训，这种共识机制就会完全崩溃，从而严重限制未来的适应性。Two ensemble baselines are evaluated alongside ARMDIL to assess the benefit of MLLM-based routing. The first is a simple Majority Vote (MV) ensemble, where each backbone model independently predicts a class label for a given input and the final output is determined by a plurality vote. While this is a standard training-free approach, it suffers from many limitations. First, every input must be processed by all classifiers, creating computational bottlenecks when multiple experts are large. Second, since it naively weights all experts equally, a majority vote ensemble fails to leverage the domain-specific strengths of individual models. Experts that perform poorly outside their specialized domain may develop shared biases, causing them to confidently converge on the same incorrect prediction. Lastly, this consensus mechanism breaks down entirely if any of the experts are trained on restricted or disjoint label spaces, significantly limiting future adaptability.

第二条基线用神经网络路由器 (NN-Router) 替代 ARMDIL 的 MLLM。该网络明确地对每个输入的视觉领域进行分类，以将其路由到适当的特定领域专家。虽然这种学习路由函数可以在其训练分布上实现有竞争力的准确性，但与我们的方法相比，它也存在很大的局限性。首先，它作为黑匣子运行，缺乏 MLLM 固有的语言驱动的可解释性。其次，由于域分类器必须在一组预定义的类上进行显式训练，因此它从根本上来说是严格的；引入或修改输入域需要昂贵的再训练或微调。The second baseline, substitutes ARMDIL’s MLLM with a neural network router (NN-Router). This network explicitly classifies the visual domain of each input to route it to the appropriate domain-specific expert. While this learned routing function can achieve competitive accuracy on its training distribution, it also suffers from significant limitations compared to our approach. First, it operates as a black box, lacking the language-driven interpretability inherent to an MLLM. Second, because the domain classifier must be explicitly trained on a predefined set of classes, it is fundamentally rigid; introducing or modifying input domains necessitates costly retraining or fine-tuning.

5 结论Conclusion

在本文中，我们介绍了 ARMDIL，这是一个用零样本 MLLM 代理取代严格元分类器的集成，用于多域图像分类。 ARMDIL 有效地在 CNN、SSL 模型和 VLM 的异构集合中找出每个专家的优势和弱点。我们提出的模型优于标准多数投票集成，并且与基于专门神经网络的路由器具有很强的竞争力，所有这些都不需要任何特定于路由的训练。值得注意的是，ARMDIL 取得了这些令人印象深刻的成果，同时在适应性和可解释性方面提供了显着的附加优势。In this paper, we introduced ARMDIL, an ensemble that replaces rigid meta-classifiers with a zero-shot MLLM agent for multi-domain image classification. ARMDIL effectively navigates the strengths and vulnerabilities of each expert within a heterogeneous ensemble of CNNs, SSL models, and VLMs. Our proposed model outperforms the standard majority vote ensemble and is highly competitive with a specialized neural network-based router, all without requiring any routing-specific training. Notably, ARMDIL achieves these impressive results while offering significant added benefits in adaptability and interpretability.

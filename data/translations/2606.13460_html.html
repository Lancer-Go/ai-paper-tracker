1 简介Introduction

3D 语义占用预测正在成为自动驾驶感知、机器人决策和基于占用的世界建模的核心表示3D semantic occupancy prediction is becoming a central representation for autonomous driving perception, robot decision making, and occupancy-based world modeling[33, 3, 14, 40, 35, 48]。它将场景表示为密集体素化的世界状态，其中每个体素存储前景对象、背景区域和自由空间的占用和语义预测. It represents a scene as a dense voxelized world state, where each voxel stores occupancy and semantic predictions for foreground objects, background regions, and free space[33, 4, 23, 40, 35]。与以对象为中心的感知不同，后者通常依赖于稀疏框或鸟瞰图抽象. Unlike object-centric perception, which often relies on sparse boxes or bird’s-eye-view abstractions[24]，语义占用提供了统一的空间表示，可以支持规划、碰撞检查、地图更新和时间状态传播, semantic occupancy provides a unified spatial representation that can support planning, collision checking, map updating, and temporal state propagation[11, 48, 28, 51]。因此，语义可靠性很重要：将交通锥与障碍物、卡车与公共汽车或拖车、行人和摩托车与背景区域混淆可以改变下游自治模块使用的自由空间和障碍物语义。尽管最近的占用模型在根据摄像机输入重建占用空间方面取得了巨大进展. Semantic reliability is therefore important: confusing traffic cones with barriers, trucks with buses or trailers, or pedestrians and motorcycles with background regions can change the free-space and obstacle semantics used by downstream autonomy modules. Although recent occupancy models have made strong progress in reconstructing occupied space from camera inputs[23, 14, 40]，由于视觉上相似的类别、长尾对象、遮挡以及占用基准中使用的细粒度封闭集分类法，学习语义上可靠的世界状态仍然具有挑战性, learning semantically reliable world states remains challenging due to visually similar categories, long-tail objects, occlusion, and the fine-grained closed-set taxonomy used in occupancy benchmarks[3, 35, 40].

视觉语言模型 (VLM) 通过可转移的视觉表示和图像语言推理提供语义知识Vision-language models (VLMs) offer semantic knowledge through transferable visual representations and image-language reasoning[32, 43, 21, 26, 1, 37]。这激发了基于 CLIP 式蒸馏、开放词汇特征对齐和区域级语言监督的 3D 场景理解方法. This has motivated 3D scene understanding methods based on CLIP-style distillation, open-vocabulary feature alignment, and region-level language supervision[5, 31, 8, 41]。对语义占用的自然适应是为对象作物添加标题并将 3D 体素或对象特征与相应的语言嵌入对齐. A natural adaptation to semantic occupancy is to caption object crops and align 3D voxel or object features with the corresponding language embeddings[32, 43, 8, 5]。然而，标题嵌入是开放词汇和特定于实例的，而占用评估是封闭集、特定于分类和体素级别的. However, caption embeddings are open-vocabulary and instance-specific, whereas occupancy evaluation is closed-set, taxonomy-specific, and voxel-level[14, 40, 35]。对象裁剪还覆盖稀疏对象区域，而占用模型则预测整个 3D 体积中的密集前景、背景和自由空间语义. Object crops also cover sparse object regions, while occupancy models predict dense foreground, background, and free-space semantics across the full 3D volume[23, 14, 40, 35]。我们通过诊断消融来验证这种不匹配：实例文本对齐改善了其辅助文本空间目标，但并不能可靠地改善语义占用 mIoU。这促使人们使用 VLM 作为离线视觉审核员，而不是嵌入目标. We verify this mismatch with a diagnostic ablation: instance-text alignment improves its auxiliary text-space objective, but does not reliably improve semantic occupancy mIoU. This motivates using VLMs as offline visual auditors rather than embedding targets[32, 43, 21, 26, 1, 37, 6, 20]。作物层面的审计可以提供自由格式标题中无法提供的占用对齐线索：封闭类假设、看似合理的视觉混乱、属性、可靠性和证据。因此，对于占用训练，有用的 VLM 信号应该是分类感知、实例特定、可靠性感知的，并且基于体素级语义决策，而不是保留为通用的开放词汇嵌入。. A crop-level audit can provide occupancy-aligned cues unavailable from a free-form caption: a closed-set class hypothesis, plausible visual confusions, attributes, reliability, and evidence. For occupancy training, the useful VLM signal should therefore be taxonomy-aware, instance-specific, reliability-aware, and grounded to voxel-level semantic decisions rather than preserved as a generic open-vocabulary embedding.

3 签证VISA

VISA 是一种针对现有语义 3D 占用世界模型的训练时语义审核方法。给定离线对象作物，VISA 将 VLM 响应解析为结构化审计元组，将每个审计与跨时间的相同物理对象跟踪相关联，将其基于匹配的 3D 对象体素，并将其提炼为体素语义逻辑。 VLM 只能离线使用；据推断，底层的占用世界模型没有改变。 VISA 由四个组件组成：(i) 离线实例审计生成，(ii) 轨迹到体素基础，(iii) 可靠性加权分类和属性因子蒸馏，以及 (iv) 对同时发生的审计对象进行场景级审计图正则化。VISA is a training-time semantic auditing approach for existing semantic 3D occupancy world models. Given offline object crops, VISA parses VLM responses into structured audit tuples, associates each audit with the same physical object track across time, grounds it to matched 3D object voxels, and distills it into voxel semantic logits. The VLM is used only offline; at inference, the underlying occupancy world model is unchanged. VISA consists of four components: (i) offline instance audit generation, (ii) track-to-voxel grounding, (iii) reliability-weighted taxonomy and attribute-factor distillation, and (iv) scene-level audit graph regularization over co-occurring audited objects.

5 结论、局限性和未来的工作Conclusion, Limitations and Future Work

结论：Conclusion:我们提出了We presented签证VISA，用于现有 3D 占用世界模型的训练时语义审核框架。 VISA 通过分类、属性因子和场景级图形损失，将对象作物的离线 VLM 判断转换为封闭集、基于体素的监督，同时无需推理 VLM。在 nuScenes 上，VISA 改进了 OccWorld 和 GaussianWorld，特别是在对象和稀有类语义方面。我们的盲审诊断进一步表明，VLM 提供了有意义的视觉证据，而无需访问真实类别标签。这些结果表明，VLM 作为具有可靠性意识的语义审核员，对于封闭集占用比作为通用标题嵌入目标更有用。, a training-time semantic auditing framework for existing 3D occupancy world models. VISA converts offline VLM judgments on object crops into closed-set, voxel-grounded supervision through taxonomy, attribute-factor, and scene-level graph losses, while leaving inference VLM-free. On nuScenes, VISA improves OccWorld and GaussianWorld, especially on object and rare-class semantics. Our blind audit diagnostics further show that the VLM provides meaningful visual evidence without access to ground-truth class labels. These results suggest that VLMs are more useful for closed-set occupancy as reliability-aware semantic auditors than as generic caption-embedding targets.

局限性和未来的工作：Limitations and Future Work:首先，VISA 增加了离线审计生成成本，并且可以继承 VLM 教师的识别偏差。此成本仅在训练期间支付，但扩展到更大的数据集需要高效的审计生成和教师质量验证。未来的工作可以通过更轻的 VLM、主动审计选择或缓存的可重用审计库来减少这种依赖性。其次，VISA 目前审核可见对象实例，而道路、人行道、地形和植被等区域仍然主要通过密集占用标签进行监督。这与我们在实验中观察到的以对象为中心的增益相匹配，但限制了大背景区域和场景布局的好处。将语义审计从对象作物扩展到填充区域或场景级上下文是一个重要的方向。第三，VISA 在训练期间依赖带注释的对象框/轨迹和密集体素标签，对匹配的对象体素进行地面作物级审核。这些注释不用于推理，但它们限制了当前实现对具有可靠时间对象注释的数据集的直接适用性。使用检测到的轨迹或较弱的实例注释是扩展 VISA 的一个重要方向。First, VISA adds offline audit-generation cost and can inherit recognition biases from the VLM teacher. This cost is paid only during training, but scaling to larger datasets requires efficient audit generation and teacher-quality validation. Future work can reduce this dependency through lighter VLMs, active audit selection, or cached reusable audit banks. Second, VISA currently audits visible object instances, while stuff regions such as road, sidewalk, terrain, and vegetation remain supervised mainly by dense occupancy labels. This matches the object-centric gains observed in our experiments, but limits the benefit for large background regions and scene layout. Extending semantic auditing from object crops to stuff regions or scene-level context is an important direction. Third, VISA relies on annotated object boxes/tracks and dense voxel labels during training to ground crop-level audits to matched object voxels. These annotations are not used at inference, but they limit the direct applicability of the current implementation to datasets with reliable temporal object annotations. Using detected tracks or weaker instance annotations is an important direction for scaling VISA.

3D 语义占用和占用世界模型：3D Semantic Occupancy and Occupancy World Models:源于语义场景补全Originating from semantic scene completion[33, 4]，3D语义占用预测已成为环视机器人感知的标准表示, 3D semantic occupancy prediction has become a standard representation for surround-view robot perception[38, 35]。 主流架构通过使用时空转换器、视图转换模块或高效的 3D 解码器将多相机特征提升为体素或 BEV 体素表示来构建体积场景场. Mainstream architectures construct volumetric scene fields by lifting multi-camera features into voxel or BEV-voxel representations with spatiotemporal transformers, view transformation modules, or efficient 3D decoders[24, 45, 25, 39]。 并行工作探索密集 3D 标签之外的可扩展监督，包括跨帧的时间一致性. Parallel efforts explore scalable supervision beyond dense 3D labels, including temporal consistency across frames[40, 13]以及二维观察的可微渲染and differentiable rendering from 2D observations[30, 44]。 最近，占用表示已被纳入世界模型公式中，其中可以传播或推出预测的 3D 状态以用于未来的场景推理和规划. More recently, occupancy representations have been incorporated into world-model formulations, where the predicted 3D state can be propagated or rolled out for future scene reasoning and planning[11, 48, 51]。 然而，闭集语义占用仍然容易受到长尾不平衡和细粒度类别混乱的影响，特别是对于二维证据稀疏、遮挡或视觉模糊的对象类。 VISA 通过提高学习占用状态的语义质量来补充时间聚合和世界状态推出，而无需更改底层世界模型架构或推理管道。. However, closed-set semantic occupancy remains vulnerable to long-tail imbalance and fine-grained category confusion, especially for object classes whose 2D evidence is sparse, occluded, or visually ambiguous. VISA complements temporal aggregation and world-state rollout by improving the semantic quality of the learned occupancy state, without changing the underlying world-model architecture or inference pipeline.

3D 机器人感知的视觉语言监督：Vision-Language Supervision for 3D Robot Perception:将知识从 2D 视觉语言模型 (VLM) 转移到 3D 感知已经从稀疏点云取得进展Transferring knowledge from 2D vision-language models (VLMs) to 3D perception has progressed from sparse point clouds[31, 41]密集体素预测。 最近的语言驱动的占用方法通常遵循两个范例。 一条线将 3D 特征与连续语言或 CLIP 嵌入对齐，有时通过可微渲染或体素语言对比学习to dense voxel prediction. Recent language-driven occupancy methods typically follow two paradigms. One line aligns 3D features with continuous language or CLIP embeddings, sometimes through differentiable rendering or voxel-language contrastive learning[34, 36, 2, 46]。 另一条线使用基础模型来生成密集的伪标签或离线开放词汇监督，然后进行 2D-3D 融合或占用蒸馏. Another line uses foundation models to generate dense pseudo-labels or open-vocabulary supervision offline, followed by 2D–3D fusion or occupancy distillation[42, 47, 9, 10]。 虽然对开放词汇感知有效，但这些策略并不总是与封闭集占用评估保持一致：嵌入对齐可能需要高维语言对齐特征，并且可能会遭受跨模式表示不匹配的影响，而密集伪标签生成可能会在体素空间中引入边界噪声和投影误差。 相比之下，VISA 使用 VLM 作为离线语义审核器，而不是推理时特征提取器或密集伪标签器。 它将结构化作物级审计转换为闭集分类法、属性和对体素逻辑的场景图监督，在推理时不引入 VLM 调用或语言特征。. While effective for open-vocabulary perception, these strategies are not always aligned with closed-set occupancy evaluation: embedding alignment may require high-dimensional language-aligned features and can suffer from cross-modal representation mismatch, while dense pseudo-label generation can introduce boundary noise and projection errors in voxel space. In contrast, VISA uses the VLM as an offline semantic auditor rather than an inference-time feature extractor or dense pseudo-labeler. It converts structured crop-level audits into closed-set taxonomy, attribute, and scene-graph supervision over voxel logits, introducing no VLM calls or language features at inference.

分类和属性感知机器人监督：Taxonomy- and Attribute-Aware Robot Supervision:现实世界的驾驶类别表现出语义关系和共享的物理属性，但标准占用模型通常将类别视为平面且独立的标签。 二维视觉中的分层语义解析Real-world driving categories exhibit semantic relationships and shared physical properties, but standard occupancy models usually treat classes as flat and independent labels. Hierarchical semantic parsing in 2D vision[22]表明分类结构可以提高语义一致性，但直接构建用于密集 3D 体素预测的分层架构可以增加模型复杂性。 现有的 3D 占用方法更常见地通过类平衡目标来解决不平衡和模糊性问题suggests that taxonomic structure can improve semantic consistency, yet directly building hierarchical architectures for dense 3D voxel prediction can increase model complexity. Existing 3D occupancy methods more commonly address imbalance and ambiguity through class-balanced objectives[7, 16]、对比学习, contrastive learning[17]、辅助几何引导, auxiliary geometric guidance[49]，或主动样本选择, or active sample selection[18, 19]。 这些方法没有明确地模拟相关对象（例如长体车辆、两轮车、弱势道路使用者或交通控制障碍物）之间共享的视觉因素。 因此，视觉上相似但功能不同的类别仍然难以区分，特别是对于稀有或安全关键的类别. These approaches do not explicitly model visual factors shared across related objects, such as long-body vehicles, two-wheelers, vulnerable road users, or traffic-control obstacles. As a result, visually similar but functionally distinct categories can remain difficult to separate, particularly for rare or safety-critical classes[35, 27]。 VISA 通过使用 VLM 审核来解决这一差距，在训练期间提供分类感知类关系和属性因子监督，改进罕见和视觉上模糊的对象语义，同时保留原始的推理时间世界模型。. VISA addresses this gap by using VLM audits to provide taxonomy-aware class relations and attribute-factor supervision during training, improving rare and visually ambiguous object semantics while preserving the original inference-time world model.

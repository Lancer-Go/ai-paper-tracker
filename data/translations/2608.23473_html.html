5 结论Conclusion

在这项工作中，我们通过一种新颖的元线束优化多智能体研究轻量级预测器的小样本学习，In this work, we study few-shot learning for lightweight forecasters via a novel meta-harness-optimized multi-agent,元卡斯特MetaCaster，它自动化了用于时间序列生成、预测器训练、参数调整和模型选择的端到端管道。实验不仅验证了效果, which automates an end-to-end pipeline for time series generation, forecaster training, parameter tuning, and model selection. Experiments not only validate the effectiveness of元卡斯特MetaCaster，同时也为深入研究代理时间序列预测中的代理工程师范例奠定了基础。, but also set a groundwork for delving into the Agent-as-Engineer paradigm in agentic time series forecasting.

局限性Limitations

在这项工作中，我们研究了具有挑战性但实际的问题，即在几次设置中改进轻量级时间序列预测器以实现快速部署，避免昂贵的数据采集和隐私限制造成的延迟。这是通过利用人工智能代理系统的知识和推理能力来实现的。In this work, we study the challenging yet practical problem of improving lightweight time series forecasters in a few-shot setting for rapid deployment, avoiding delays from costly data acquisition and privacy constraints. This is enabled by leveraging the knowledge and reasoning capabilities of AI agent systems.

然而，我们当前的工作并没有解决极端的零样本设置，没有可用的参考示例。如果没有参考时间序列，代理就缺乏目标域的基本统计基础，导致数据生成不可靠。这是基于时间序列生成的模型的常见限制However, our current work does not address the extreme zero-shot setting, where no reference examples are available. Without reference time series, the agent lacks basic statistical grounding of the target domain, leading to unreliable data generation. This is a common limitation of time series generation-based models27; 75; 50; 24; 19; 16并强调了 TSFM 的优势，它可以在零样本设置中传输预先训练的知识。相比之下，通过仅利用少量示例（这在实践中通常是可行的）and highlights the advantage of TSFMs, which can transfer pre-trained knowledge in zero-shot settings. In contrast, by leveraging only a small number of examples – which is often feasible in practice –元卡斯特MetaCaster实现与 TSFM 竞争的性能，同时保持显着较低的计算成本。achieves competitive performance with TSFMs while maintaining significantly lower computational cost.

此外，我们的实验涵盖了涵盖有限领域的 18 个时间序列数据集。我们计划将其扩展到现代 TSFM 的完整预训练语料库，以进一步改进 Harness 优化。与此同时，Additionally, our experiments cover 18 time series datasets spanning a limited set of domains. We plan to extend this to the full pre-training corpora of modern TSFMs to further improve Harness optimization. Meanwhile,LT库LT-Lib目前包括我们迄今为止收集的一组 SOTA 轻量级预测器。随着新的轻量级预报器不断出现，它可能并不详尽。在今后的工作中，我们将不断更新currently includes a set of SOTA lightweight forecasters we have collected so far.

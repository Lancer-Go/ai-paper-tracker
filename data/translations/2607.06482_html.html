摘要Abstract

当前在数据分析中评估大型语言模型 (LLM) 的基准通常无法反映现实世界的设置。他们通常专注于从小表中检索事实，而忽视大型多表数据集、外部知识集成和探索性洞察发现的挑战。 我们介绍Current benchmarks for evaluating Large Language Models (LLMs) in data analysis often fail to reflect real-world settings. These models have led to the development of sophisticated agents designed to democratize data analysis, promising a future where any user can pose natural language questions to a dataset and receive accurate answers[infida-bench, su2024tablegpt2largemultimodalmodel]。最终的愿景是一个自治系统，不仅可以检索信息，还可以揭示隐藏在原始数据中的知识。. The ultimate vision is an autonomous system that not only retrieves information but also uncovers the knowledge hidden within raw data.

2 DataGovBench 概述Overview of DataGovBench

DataGovBench 是一个新的基准测试，旨在评估现实场景中的表格推理。数据来自政府开放数据门户（例如 Data.govDataGovBench is a new benchmark designed to evaluate tabular reasoning in realistic scenarios. The data is derived from governmental open data portals (e.g., Data.gov[datagov], Data.gov.uk [datagovuk]），其中托管来自官方机构的公开数据集。这些门户上的数据集反映了现实世界的复杂性，由包含大量记录和丰富上下文信息的单个或多个表组成。这种上下文是通过元数据提供的，例如数据集的文本描述，并且通常补充有数据字典等外部知识。 该基准旨在评估两个核心数据科学任务的性能：表 QA 和表洞察。), which host publicly available datasets from official institutions. Datasets on these portals reflect real-world complexity, consisting of a single or multiple tables containing a large number of records, and rich contextual information. This context is provided through metadata, such as textual descriptions of the dataset, and often supplemented with external knowledge like data dictionaries. The benchmark is designed to evaluate performance on two core data science tasks: Table QA and Table Insight.

2.1.2 问答对的注释Annotation of Question and Answer Pairs

为了大规模构建高质量、复杂且具有挑战性的 QA 对，同时减少对资源密集型手动注释的需求，我们设计了一个四阶段生成管道，利用 LLM 进行人机交互验证。受到之前工作的启发To construct a high-quality, complex, and challenging set of QA pairs at scale while mitigating the need for resource-intensive manual annotation, we designed a four-stage generation pipeline that leverages LLMs with human-in-the-loop verification. Inspired by prior work[wu2025tablebench]，这种方法既保证了多样性又保证了正确性。详细过程如下。, this approach ensures both diversity and correctness. The procedure is detailed below.

  1. 1.

    问题生成Question Generation：初始阶段的重点是生成多样化的候选人问题。为了指导法学硕士的输出，我们首先定义了八种问题类型，如附录所示: The initial stage focused on generating a diverse pool of candidate questions. While prior works mainly focus on smaller datasets such that the entire table or the first several rows could be embedded into the prompt[wu2025tablebench]，我们无法对基准测试中具有数百万条记录的表应用类似的方法，因为它超出了 LLM 上下文窗口的限制。为了应对这一挑战，我们提出了一种称为, we cannot apply similar approaches to tables with millions of records in our benchmark as it exceeds the limits of LLM context window. To address this challenge, we propose a technique called特定于功能类型的表序列化Feature type-specific table serialization，它通过根据数据类型表示每一列来创建一个紧凑但信息丰富的表摘要。例如，我们不是在分类列中列出所有值，而是仅提供一组唯一类别。这种序列化是我们工作流程的核心组成部分，附录中提供了各种功能类型的逻辑的详细描述, which creates a compact yet informative summary of a table by representing each column according to its data type.   2. 2.

    问题评分Question Scoring：生成后，候选问题经历了自动评分和选择阶段。每个问题都根据四个定性标准进行评估：与数据集的相关性、产生有洞察力或可操作信息的潜力、足够的分析复杂性和新颖性以及以自然语言表达的清晰度。在质量过滤方法中，我们要求上述四位法学硕士中的每一位都充当法官，根据每个数据集的上述标准从生成的池中选择前 5 个首选问题。这些选择的得分从 5（最高）到 1（最低）。然后将每个问题的所有四个模型的分数进行汇总，得出的最高可能分数为 20。根据这个汇总分数，我们选择了前 10 个问题进入下一阶段。: Following generation, the candidate questions underwent an automated scoring and selection phase. Each question was evaluated against four qualitative criteria: relevance to the dataset, its potential to yield insightful or actionable information, sufficient analytical complexity with novelty, and clarity expressed in natural language. In an approach to quality filtering, we tasked each of the four aforementioned LLMs with acting as a judge, selecting its top-5 preferred questions from the generated pool based on the above criteria for each dataset. A score from 5 (highest) to 1 (lowest) was assigned to these selections. The scores from all four models were then aggregated for each question, resulting in a maximum possible score of 20. Based on this aggregated score, we selected the top-10 questions to proceed to the next stage.

    答案生成Answer Generation：对于每个数据集前 10 个问题中的每一个，都会提示法学硕士生成可产生正确答案的 Python 代码。在执行所有四个模型的代码后，我们测量了答案共识，以筛选出在所有四个法学硕士中获得一致同意的问题。此类实例被认为表明分析复杂性水平较低（例如单列过滤或聚合），使得它们不适合在现实环境中作为基准。对生成问题的分析表明，前一阶段的问题中只有 6% 属于这一类，这表明它们的删除并没有极大地扭曲原始分布，如附录所示: For each of the top-10 questions per dataset, an LLM was prompted to generate Python code that produces the correct answer. After executing the code from all four models, we measured the answer consensus to filter out questions that yielded unanimous agreement across all four LLMs. Such instances were deemed to indicate a low level of analytical complexity (e.g. single column filtering or aggregation), making them unsuitable for a benchmark in a real-world setting. An analysis of the generated questions shows that only 6% of the questions from the previous stage fall into this category, indicating that their removal does not drastically distort the original distribution as shown in Appendix0.A.3.

    人工验证Human Verification：其余候选 QA 对经过人工验证和细化过程。使用定制开发的注释 GUI，如图所示: The remaining candidate QA pairs were subjected to a human verification and refinement process. 0.B.2 洞察力代理Insight Agent

Insight Agent 通过迭代循环进行操作：它生成问题，使用 Answer Agent 回答问题，然后从生成的 QA 对中综合见解。然后，在一个步骤中生成的见解将用于为下一步的问题生成提供信息，从而创建一个持续的探索过程。 该过程由有向无环图 (DAG) 结构控制，如图所示The Insight Agent operates through an iterative cycle: it generates questions, answers them using Answer Agent, and then synthesizes insights from the resulting QA pairs. The insights generated in one step are then used to inform the question generation in the next, creating a continuous exploratory process. This process is governed by a Directed Acyclic Graph (DAG) structure, as illustrated in Figure9（二）。该图由交替的问答 (QA) 节点和洞察节点层组成。通过综合来自一个或多个先前的 QA 节点的信息来生成新的 Insight 节点，反之，通过利用一个或多个先前的 Insight 节点来生成新的 QA 节点。 至关重要的是，新节点可以连接到任何先前迭代的父节点，而不仅仅是前一个迭代。这种 DAG 结构有助于聚合多条查询线，与更简单的基于树的探索相比，能够生成更多样化和更全面的见解，如图所示(b). The graph consists of alternating layers of Question-Answer (QA) nodes and Insight nodes. A new Insight node is generated by synthesizing information from one or more preceding QA nodes, and conversely, a new QA node is generated by drawing upon one or more preceding Insight nodes. Crucially, a new node can be connected to parent nodes from any previous iteration, not just the immediately preceding one. This DAG structure facilitates the aggregation of multiple lines of inquiry, enabling the generation of more diversified and comprehensive insights compared to a simpler tree-based exploration as in Figure9(a)，来自不同深度和分支的见解没有联系。 决定聚合哪些节点是由LLM的推理能力决定的；为了指导这个过程，我们的提示明确指示模型考虑在可能的情况下综合来自多个父节点的信息。(a), where insights from different depths and branches are not connected. 0.B.3 Table Insight 的元评估Meta-evaluation of Table Insight

我们进行了元评估，以评估 Table Insight 评估指标的有效性。我们对每个真实见解采样了 50 对生成的见解（见解 A 和见解 B），并要求三位独立注释者评估两者中哪一个更接近真实见解。注释者选择了五个相关选项之一：We conducted a meta evaluation to assess the validity of the evaluation metrics for Table Insight. We sampled 50 pairs of generated insights (Insight A and Insight B) for each ground-truth insight and asked three independent annotators to assess which of the two was closer to the ground truth. Annotators selected one of five relative options:A+ (A肯定更好A is definitely better), A (A稍微好一些A is slightly better), N (A和B具有可比性A and B are comparable), B (B稍微好一些B is slightly better），或), orB+ (B肯定更好B is definitely better）。每个选项都映射到 [-2, -1, 0, 1, 2] 中的标准化分数。每对的最终人工判断分数是通过对三位注释者的分数进行平均而获得的。同时，我们根据 B 和 A 的洞察级别分数之间的差异计算了度量衍生分数。然后，我们使用 Pearson 和 Spearman 相关性量化了人类判断与度量衍生分数之间的一致性，得出的系数分别为 0.669 和 0.663。这些结果表明所提出的指标与人类判断之间存在紧密的一致性，为我们的 Table Insight 任务评估方法的可靠性提供了实证支持。). Each option was mapped to a normalized score in [-2, -1, 0, 1, 2]. The final human-judgment score for each pair was obtained by averaging the three annotators’ scores. In parallel, we computed a metric-derived score based on the difference between the insight-level scores of B and A. We then quantified the agreement between human judgments and the metric-derived scores using both Pearson and Spearman correlations, which yielded coefficients of 0.669 and 0.663, respectively. These results indicate a solid alignment between the proposed metric and human judgments, providing empirical support for the reliability of our evaluation methodology for the Table Insight task.

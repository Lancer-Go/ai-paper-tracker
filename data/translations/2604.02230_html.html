摘要Abstract

为了可靠地部署大型语言模型 (LLM)，模型必须有效地知道何时不回答：For Large Language Models (LLMs) to be reliably deployed, models must effectively know when not to answer:弃权abstain。尤其是推理模型，因其在复杂任务上的出色表现而受到关注。然而，推理模型已被证明具有较差的弃权能力。考虑到推理模型的漏洞，我们提出了查询错位框架。导致弃权失败的幻觉可以被重新解释为法学硕士回答. Reasoning models, in particular, have gained attention for impressive performance on complex tasks. However, reasoning models have been shown to have worse abstention abilities. Taking the vulnerabilities of reasoning models into account, we propose our Query Misalignment Framework. Hallucinations resulting in failed abstention can be reinterpreted as LLMs answering the错误的wrong问题（而不是错误地回答问题）。基于这个框架，我们开发了一类新的最先进的弃权方法，称为question (rather than answering a question incorrectly). Based on this framework, we develop a new class of state-of-theart abstention methods called轨迹反转TRACE INVERSION。首先，我们生成模型的推理轨迹。然后，我们仅根据跟踪重建模型响应的最有可能的查询。最后，我们将初始查询与重构的查询进行比较。初始查询和重建查询之间的相似度分数较低表明该模型可能错误地回答了问题并被标记为弃权。大量实验表明，TRACE IVERSION 在 9 个弃权 QA 数据集中的 4 个前沿法学硕士中有效提高了弃权表现，在 36 个设置中的 33 个设置中击败了竞争基线。该代码可在此存储库中找到。. First, we generate the reasoning trace of a model. Based on only the trace, we then reconstruct the most likely query that the model responded to. Finally, we compare the initial query with the reconstructed query. Low similarity score between the initial query and reconstructed query suggests that the model likely answered the question incorrectly and is flagged to abstain. Extensive experiments demonstrate that TRACE INVERSION effectively boosts abstention performance in four frontier LLMs across nine abstention QA datasets, beating competitive baselines in 33 out of 36 settings. The code is available at this repository.

The perceived effectiveness of this interpretability might not align with the model’s true internal workings (Bhambri et al., 2025; Korbak et al., 2025). 3 查询错位框架3 Query Misalignment Framework

我们建议考虑模型中的弃权错误是模型回答问题的结果We propose thinking about abstention errors in models as a consequence of models answering the错误的wrong问题。我们提出了一种基于查询的方法，而不是将弃权决策视为可以通过置信度评估或审查模型答案来识别的“知识差距”的结果。当模型在没有足够知识的情况下回答问题时，模型会回答一个被误解的查询：与用户提出的预期查询不同的问题（见图 2）。除了典型的知识差距视角（Wen 等人，2025）之外，该框架还适用于各种弃权场景（Kirichenko 等人，2025）：question. Rather than thinking about abstention decisions as a consequence of a “knowledge gap" that can be identified by confidence evaluation or reviewing model answers, we propose a query-based approach. When models answer a question without sufficient knowledge, models are answering a misinterpreted query: a different question than the intended query posed by the user (see Figure 2). In addition to typical knowledge gaps perspective (Wen et al., 2025), this framing applies across various abstention scenarios (Kirichenko et al., 2025):

  • 无法回答的问题：没有记录的、共识答案的问题。尽管增加了背景，但这个问题仍然无法回答。当模型回答无法回答的问题时，它可能会产生实际查询的意图或内容的幻觉。Unanswerable question: A question without a documented, consensus answer. The question would remain unanswerable despite added context. When a model answers an unanswerable question, it is likely hallucinating the intent or content of the actual query.

  • 未指定上下文：有关缺乏关键所需细节的上下文的问题。如果上下文提供了更多信息，则该问题是可以回答的，并且模型可能会产生原始查询中未指定的此类信息。Underspecified context: Questions about a context which lacks key required details. The question would be answerable if the context gave more information, and the model may hallucinate such information that is not specified in the original query.

  • 目标不明：不清楚用户意图的问题。该模型可能会产生用户意图的幻觉细节。Underspecified aim: Questions where it’s unclear what the user intended. The model may hallucinate details of what the user intended.

  • 错误前提：基于不正确或错误陈述的问题。回答的模型可能会将错误陈述误解为现实或错误前提的修改版本。False premise: Questions predicated on an incorrect or false statement. Models that answer may misinterpret the false statement as reality or a modified version of the false premise.

  • 主观：正确答案取决于个人意见或经验的问题。模型可能会将这些问题误解为询问一般公众意见或它对用户产生幻觉的特定特征。Subjective: Questions where the correct answer depends on personal opinion or experience. Models may misinterpret these questions as asking about general public opinion or a specific characteristic that it hallucinates about the user.

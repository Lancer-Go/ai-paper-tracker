摘要Abstract

神经网络验证和数据隐私本质上是紧张的：Neural network verification and data privacy are inherently in tension:验证需要完全访问模型参数和输入数据，但两者都越来越受到隐私法规和知识产权约束的限制verification demands full access to model parameters and input data, yet both are increasingly restricted by privacy regulations and intellectual property constraints。这种紧张使得鲁棒性验证在隐私敏感领域变得不切实际。 在这项工作中，我们解决了这一差距. This tension has left robustness verification impractical in privacy-sensitive domains. In this work, we address this gap with安全皇冠SecureCROWN，第一个隐私保护神经网络鲁棒性验证框架。我们的框架建立在安全两方计算（2PC）的基础上，使模型所有者和数据所有者能够共同计算经过认证的稳健性界限——仅揭示最终结果，同时在半诚实安全模型下证明保护双方的私有数据。 一个关键的挑战是安全地计算线性边界传播中的条件运算，其中数据相关的分支与标准安全计算协议不兼容。 我们通过将条件逻辑表述为来消除分支 连续算术运算。 此外，我们引入了牛顿-拉夫森细化方法来提高数值稳定性。 大量的分析和实验表明, the first framework for privacy-preserving neural network robustness verification. Built upon secure two-party computation (2PC), our framework enables a model owner and a data owner to jointly compute certified robustness bounds—revealing only the final result while provably protecting both parties’ private data under the semi-honest security model. A key challenge is securely computing the conditional operations in Linear Bound Propagation, where the data-dependent branching is incompatible with standard secure computation protocols. We eliminate branching by formulating conditional logic as continuous arithmetic operations. Additionally, we introduce a Newton–Raphson refinement method to improve numerical stability. Extensive analysis and experiments show that安全皇冠SecureCROWN严格匹配明文验证结果，同时在不同模型大小和通信设置（LAN/WAN）下在 0.1-200 秒内完成，证明了保护隐私的神经网络验证的可行性。strictly matches plaintext verification results, while completing in 0.1–200s across varied model sizes and communication settings (LAN/WAN), demonstrating the feasibility of privacy-preserving neural network verification.

1 简介Introduction

深度学习（DL）领域最近经历了巨大的发展， 深度神经网络（DNN）现已部署在各种安全关键应用中，包括医疗诊断The field of deep learning (DL) has experienced enormous growth recently, with deep neural networks (DNNs) now deployed in a variety of safety-critical applications, including medical diagnosis[Litjens et al., 2017, Esteva et al., 2017]和医疗保健and healthcare[Esteva et al., 2019, Davenport and Kalakota, 2019]。在这些领域，DNN 的安全性和鲁棒性至关重要。 然而，DNN 很容易受到输入扰动的影响. In these domains, safety and robustness of DNNs are essential. However, DNNs are susceptible to perturbations in their inputs[Szegedy et al., 2014]，例如噪声和照明变化, such as noise and illumination variations[Goodfellow et al., 2015, Hendrycks and Dietterich, 2019]。 为了确保 DNN 在最坏情况下的稳健性，验证方法取得了重大进展. To ensure DNN robustness with worst-case guarantees, significant progress in verification approaches[Wu et al., 2024, Wang et al., 2021, Singh et al., 2019]已经完成，可以证明无论数据噪声或环境变化如何，模型的预测都保持稳定。has been made, which can certify that a model’s prediction remains stable regardless of data noise or environmental changes.

尽管取得了这些进步，现有的验证技术仍假设以明文形式集中访问模型参数和输入数据。 在隐私敏感的部署中，这种假设通常是不现实的。 在实践中，用户数据可能受到严格的隐私法规的约束，例如通用数据保护条例（GDPR）Despite these advances, existing verification techniques assume centralized access to both model parameters and input data in plaintext. This assumption is often unrealistic in privacy-sensitive deployments. In practice, user data may be subject to strict privacy regulations, such as the General Data Protection Regulation (GDPR)[Voigt and Von dem Bussche, 2017]。 同时，专有模型参数构成宝贵的知识产权，不得向第三方披露。 因此，模型和数据都完全可访问的标准验证设置与许多隐私监管的协作场景不兼容。. Meanwhile, proprietary model parameters constitute valuable intellectual property and may not be disclosed to third parties. Thus, the standard verification setting, where both model and data are fully accessible, is incompatible with many privacy-regulated collaborative scenarios.

我们考虑一个两方验证设置，其中模型所有者We consider a two-party verification setting in which a model ownerP0P_{0}拥有专有的 DNN，而数据所有者holds a proprietary DNN, while a data ownerP1P_{1}保存敏感的输入数据。我们的目标是验证模型在给定输入上的稳健性，以便仅揭示验证结果，而模型参数和输入数据都保持私密。要实现这一点，需要在不泄露任何一方机密信息的情况下共同进行稳健性验证。holds sensitive input data. We aim to verify the robustness of the model on the given input such that only the verification result is revealed, while both the model parameters and the input data remain private. Achieving this requires jointly performing robustness verification without exposing either party’s confidential information.

安全多方计算 (MPC)Secure multi-party computation (MPC)[Evans et al., 2018]提供了一种有原则的加密方法，使多方能够共同评估其私有输入的功能，而无需向彼此泄露数据。 MPC已成功应用于隐私保护推理和训练provides a principled cryptographic approach that enables multiple parties to jointly evaluate functions on their private inputs without revealing their data to one another. While MPC has been successfully applied to privacy-preserving inference and training[Knott et al., 2021, Tan et al., 2021, Wagh et al., 2021, Kumar et al., 2020, Gupta et al., 2025, Zhang et al., 2021]，将其扩展到稳健性验证面临两个基本挑战：, extending it to robustness verification faces two fundamental challenges:(i) 数据相关分支：(i) Data-dependent branching:ReLU 激活的凸松弛需要不同的参数，具体取决于秘密共享激活状态。在 MPC 中，解决这些条件需要对每个神经元进行安全比较，随神经元总数线性缩放，并使简单的实现在计算上令人望而却步。Convex relaxation of ReLU activations requires distinct parameters depending on secret-shared activation states. In MPC, resolving these conditionals requires a secure comparison for every neuron, scaling linearly with the total number of neurons and rendering naïve implementations computationally prohibitive.(ii) 深度递归中的精度灵敏度：(ii) Precision sensitivity in deep recursion:与基于 MPC 的推理不同，基于 MPC 的推理在单次前向传递期间可以容忍较小的数值误差，而验证则通过深度向后递归来计算经过认证的边界，从而放大数值误差。由于安全保证严格取决于最终裕度的符号，因此这些复合误差可能会反转接近零的界限，从而损害验证的可靠性。Unlike MPC-based inference, which tolerates minor numerical errors during a single forward pass, verification computes certified bounds via deep backward recursion that amplifies numerical errors. Because safety guarantees depend strictly on the sign of the final margin, these compounded errors can invert near-zero bounds, compromising verification soundness.

It enables verification of DNNs while ensuring that sensitive input data remains confidential and proprietary model parameters are not disclosed. Specifically, we develop(一)(i)线性边界传播 (LBP) 的安全实现，可在隐私约束下计算经过认证的鲁棒性边界；a secure implementation of Linear Bound Propagation (LBP) that computes certified robustness bounds under privacy constraints;(二)(ii)ReLU 松弛和边界传播中条件逻辑的统一无分支重构，通过函数秘密共享 (FSS) 有效实现；和a unified branch-free reformulation of the conditional logic in ReLU relaxation and bound propagation, efficiently realized via function secret sharing (FSS); and(三)(iii)基于牛顿-拉夫森的倒数计算细化方法，以提高数值精度和稳定性。 此外，我们在半诚实对手模型中提供正式的安全保证，并进行广泛的实验，验证我们的协议实现了与明文验证器相当的验证精度，同时产生了适度的加密开销。a Newton–Raphson-based refinement method for reciprocal computation to improve numerical precision and stability. Furthermore, we provide formal security guarantees in the semi-honest adversary model and conduct extensive experiments validating that our protocol achieves verification precision comparable to the plaintext verifier while incurring moderate cryptographic overhead.

To the best of our knowledge, our work is the first to integrate formal robustness verification with cryptographic privacy guarantees.

8 结论Conclusion

我们建议We propose安全皇冠SecureCROWN，第一个用于 2PC 设置中神经网络鲁棒性验证的隐私保护框架。 我们的协议解决了对受保护的模型参数和输入执行线性松弛和后向绑定计算的关键挑战。 我们在半诚实对手模型中提供了正式的隐私保证，并分析了协议的计算复杂性。 标准基准测试的实验验证了我们的方法以适度的加密开销实现了与明文验证相当的验证保真度，这代表着朝着高效的隐私保护验证迈出了有希望的一步。, the first privacy-preserving framework for neural network robustness verification in a 2PC setting. Our protocol addresses the key challenges of performing linear relaxation and backward bound computation on protected model parameters and inputs. We provided formal privacy guarantees in the semi-honest adversary model and analyzed the protocol’s computational complexity. Experiments on standard benchmarks validate that our method achieves verification fidelity comparable to plaintext verification with moderate cryptographic overhead, representing a promising step toward efficient privacy-preserving verification.

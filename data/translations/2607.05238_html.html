对于随机 JEPA 世界模型for Stochastic JEPA World Models

Zhi Song1,2, Ximing Xing2, Zhenchao Tang2, Hanbo Huang2, Tianxu Lv2, Minghao Yang2, Zhongzheng Niu2, He Bing\corresponding2, Lusheng Wang\corresponding1, Jianhua Yao\corresponding2
摘要Abstract

JEPA 世界模型使用由潜在训练者训练的单个确定性预测器来预测下一个潜在状态 回归。我们证明，当环境随机时，这在结构上会失败：在分支处 转换时，回归最优预测器输出后继嵌入的条件均值，a 真正的下一个状态之间的点根本不对应于任何状态。我们证明这种崩溃 确定性和门控专家混合预测器，并证明 MoP-JEPA 的硬分配预测器 收敛到转移分布的量化器：每个头一个 后继模式，可在单个前向传递中枚举，这是规划器使用的接口。开 官方 OGBench 离线数据，具有无泄漏评估，对单预测器部署进行规划 不好（JEPA world models predict the next latent state with a single deterministic predictor trained by latent regression. We show that this fails structurally when the environment is stochastic: at a branching transition, the regression-optimal predictor outputs the conditional mean of the successor embeddings, a point between the true next states that corresponds to no state at all. We prove this collapse for deterministic and gated mixture-of-experts predictors, and prove that MoP-JEPA’s hard-assigned predictors converge instead to a quantizer of the transition distribution: one head per successor mode, enumerable in a single forward pass, which is the interface a planner consumes. 简介Introduction

在自主智能路线图中In the autonomous-intelligence roadmap ofLeCun (2022)，世界模型是核心： 代理通过向前滚动学习的潜在预测器来制定计划。现代 JEPA 世界模型, the world model is the centerpiece: an agent plans by rolling a learned latent predictor forward. Modern JEPA world models(Zhou et al. 2024; Assran et al. 2025)用潜在回归实例化这个想法：对现在进行编码， 预测下一个潜在的，并在该学习空间中进行计划。当未来来临时，设计是强大的 有效地单值。它在结构上与随机动力学不匹配，其中相同的上下文可以 有几个有效的继任者，规划者需要枚举他们而不是平均他们。instantiate this idea with latent regression: encode the present, predict the next latent, and plan in that learned space. The design is powerful when the future is effectively single-valued. It is structurally mismatched to stochastic dynamics, where the same context can have several valid successors and a planner needs to enumerate them rather than average them.

本文隔离了预测器接口处的不匹配。由 squared 训练的确定性 JEPA 头 或余弦回归返回后继嵌入的条件平均值，该平均值可以位于所有嵌入之间 有效的期货。门控加权和 MoE 仍会发射一个矢量并因同样的原因而崩溃。的 最小的修复不是更大的编码器或更软的密度头，而是一组硬分配的预测器头： 每个观察到的转换仅训练其最近的头，并且路由器估计哪些头是活动的。的 结果是一组可枚举的后继潜在变量，正是图搜索或 MPC 推出可以实现的对象 消耗。图This paper isolates that mismatch at the predictor interface. A deterministic JEPA head trained by squared or cosine regression returns the conditional mean of the successor embeddings, which can lie between all valid futures. A gated weighted-sum MoE still emits one vector and collapses for the same reason. The minimal repair is not a larger encoder or a softer density head, but a hard-assigned set of predictor heads: each observed transition trains only its nearest head, and a router estimates which heads are active. The result is an enumerable set of successor latents, exactly the object a graph search or MPC rollout can consume. Figure1勾勒出完整的因果链。sketches the full causal chain.

讨论和限制Discussion and Limitations

为什么这对于扩展 JEPA 世界模型很重要。Why this matters for scaling JEPA world models.

视频和机器人规模的世界模型Video- and robot-scale world models(Assran et al. 2025; Zhou et al. 2024)接受数据训练，其中 随机性是规则。我们的结果表明，确定性预测器的失败并不存在 优雅：错误集中在规划者必须解决的分支上，并且它默默地 产生不存在的状态。更广泛的教训是，随机世界模型应该揭示 集值转换接口，不仅仅是一个潜在的期望。 MoP-JEPA 是一种最小的实现 该接口：头级变化，与编码器架构和规模正交，产生可枚举的 具有校准路由器权重的分支结果。验证协议与架构无关：任何 可以审核发出多种未来（混合、变分、扩散或生成）的世界模型 具有相同的套件，并且我们鼓励在报告多样本预测数字的地方采用它。are trained on data where stochasticity is the rule. Our results indicate that the deterministic predictor’s failure there is not graceful: the error concentrates on exactly the branchings a planner must resolve, and it silently produces states that do not exist. The broader lesson is that a stochastic world model should expose a set-valued transition interface, not only a latent expectation. MoP-JEPA is one minimal implementation of that interface: a head-level change, orthogonal to encoder architecture and scale, that yields enumerable branch outcomes with calibrated router weights. The verification protocol is architecture-agnostic: any world model that emits multiple futures (mixture, variational, diffusion, or generative) can be audited with the same suite, and we would encourage its adoption wherever multi-sample prediction numbers are reported.

结论Conclusion

确定性 JEPA 世界模型无法表示随机分支：它预测潜在期望 规划需要无数的未来。我们证明了这种条件均值崩溃，并在分支上展示它 计算和超越二维迷宫，并衡量它导致的规划失败。硬分配的预测变量恢复 每个后继模式，将预测器输出从单个无效平均值转变为可搜索的平均值 过渡集；当该组包含真实路线时，验证的规划就会成功。方法是刻意的 最小，但要点更广泛：随机 JEPA 世界模型需要模式枚举，并声明 应审核多模态预测的上下文条件、真实转换结构而不是原始结构 甲骨文覆盖率。A deterministic JEPA world model cannot represent a stochastic branching: it predicts a latent expectation where planning needs enumerable futures. We prove this conditional-mean collapse, show it across branch counts and beyond 2-D mazes, and measure the planning failure it causes. Hard-assigned predictors recover one successor mode each, turning the predictor output from a single invalid average into a searchable transition set; verified planning succeeds when that set contains real routes. The method is deliberately minimal, but the point is broader: stochastic JEPA world models need mode enumeration, and claims about multimodal prediction should be audited for context-conditional, real-transition structure rather than raw oracle coverage.

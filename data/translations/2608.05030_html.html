Shaopeng Liang
Independent Researcher
（2026 年 8 月 5 日）(5 August 2026)
摘要Abstract

足球比分预测具有有用的统计核心和困难的上下文优势。动态泊松族模型了解统计规律：它们估计当前实力、预期进球和连贯得分概率。他们本身并不从角色、战术对决、动机或第一个进球改变行为的方式的语义意义上理解足球。大型语言模型（LLM）可以推理这些概念，但它们既不是经过校准的概率引擎，也不是保证成为精英足球专家。因此，我们将互补性而不是替代性作为建模前提。本文记录了四个主要的系统迭代。 V1 是动态分数驱动的 Dixon-Coles 基线。 V2 在两个数学层之间插入 LLM 残差，并将上下文评级映射回Football score forecasting has a useful statistical core and a difficult contextual edge. Dynamic Poisson-family models understand statistical regularities: they estimate current strength, expected goals, and coherent score probabilities. They do not, by themselves, understand football in the semantic sense of roles, tactical matchups, motivation, or the way a first goal changes behaviour. Large language models (LLMs) can reason about those concepts, yet they are neither calibrated probability engines nor guaranteed elite football experts. We therefore treat complementarity, rather than replacement, as the modeling premise. This paper documents four major system iterations. V1 is a dynamic score-driven Dixon–Coles baseline. V2 inserts an LLM residual between two mathematical layers and maps contextual ratings back intoλ\lambda。 V3 在冻结的得分候选集上用三个明确的逐个目标模拟取代了标量校正。 V4 增加了共享的首次突破和目标后级联判断、时间感知停止和确定性尾部候选。信息工具定义每个输入字段，提供赛前证据，并将法学硕士限制在可审核的推理路线上。. V3 replaces scalar correction with three explicit goal-by-goal simulations over a frozen score-candidate set. V4 adds shared first-breakthrough and post-goal cascade judgments, time-aware stopping, and deterministic tail candidates. The information harness defines every input field, supplies pre-match evidence, and constrains the LLM to an auditable reasoning route.

在按时间顺序对 2025-26 赛季英超联赛前 150 场比赛进行临时重播时，V1 得分矩阵排序实现了 10.0% Top-1 和 26.7% Top-3 精确比分准确度。 V3达到12.0%和30.0%； V4达到14.7%和30.7%。 V4 将候选覆盖率从 77.3% 提高到 84.7%，但没有新添加的尾部候选成为确切的 Top-3 命中。 LLM排名版本没有给出标准化概率，因此无法为它们计算适当的评分规则； V1 的原生 1X2 分布在同一切片上实现了 0.9878 对数损失、0.5870 Brier 分数、0.2095 排名概率分数和 53.3% argmax 准确度。这些结果是探索性的，而不是声称最先进的性能：切片通知模型开发和输入隔离不能排除封闭权重法学硕士中的结果知识。因此，主要的贡献是一个可审计的架构、四个清晰分离的设计迭代，以及澄清足球模拟在哪些方面可以改善分数选择、哪些方面不能改善的负面结果。On an interim chronological replay of the first 150 matches of the 2025–26 English Premier League, V1 score-matrix ordering achieved 10.0% Top-1 and 26.7% Top-3 exact-score accuracy. V3 reached 12.0% and 30.0%; V4 reached 14.7% and 30.7%. V4 increased candidate coverage from 77.3% to 84.7%, but no newly added tail candidate became an exact Top-3 hit. The LLM ranking versions did not emit normalized probabilities, so proper scoring rules cannot be computed for them; V1’s native 1X2 distribution achieved 0.9878 log loss, 0.5870 Brier score, 0.2095 ranked probability score, and 53.3% argmax accuracy on the same slice. These results are exploratory rather than a claim of state-of-the-art performance: the slice informed model development, and input isolation cannot rule out outcome knowledge in a closed-weight LLM. The main contribution is therefore an auditable architecture, four clearly separated design iterations, and negative findings that clarify where football simulation does and does not improve score selection.

1 简介Introduction

足球协会预测的结果熵异常高。少量进球、相关的低分结果以及比赛状态反馈使得精确比分预测变得尤其脆弱。泊松和迪克森-科尔斯模型仍然有吸引力，因为它们产生完整的、内部一致的分数分布，而不仅仅是标签Association-football forecasts have unusually high outcome entropy. A small number of goals, correlated low-score outcomes, and match-state feedback make exact-score prediction especially brittle. Poisson and Dixon–Coles models remain attractive because they produce a complete, internally consistent score distribution rather than only a label[1]。动态权重和时间折旧有助于这些模型反映当前团队的实力. Dynamic weighting and time depreciation help those models reflect current team strength[4]。最近的分布优先工作同样主张在模拟结果之前预测生成分数的机制（例如射击数量和质量）. Recent distribution-first work similarly argues for predicting the mechanisms that generate scores—for example shot quantity and quality—before simulating outcomes[5].

缺失的层通常不是另一个通用表格模型。在开球前不久，分析师想要解释所报告的缺席是否具有结构性重要性，替补球员是否会改变球的进展或休息防守，特定的边锋与边后卫的比赛是否可重复，以及比赛的激励措施是否有利于风险或控制。这些是相关的、上下文的判断。法学硕士拥有广泛的足球知识和一般推理能力，但不应假定其拥有精英教练、球探或分析师的一致专业判断力。因此，该工具不是一个被动的提示包装器：它提供定义、参考框架、结构化团队和玩家证据、不确定性线索以及所需的推理路线。它将两个不完整的组件转变为一个新的系统级预测器。新一代足球基准已经开始在赛前证据限制下评估法学硕士和研究代理人The missing layer is often not another generic tabular model. Shortly before kickoff, an analyst wants to interpret whether a reported absence is structurally important, whether a replacement changes ball progression or rest defence, whether a particular winger-fullback matchup is repeatable, and whether the match incentives favour risk or control. These are relational, contextual judgments. An LLM has broad football knowledge and general reasoning ability, but it should not be presumed to possess the consistent specialist judgment of an elite coach, scout, or analyst. The harness is therefore not a passive prompt wrapper: it supplies definitions, reference frames, structured team and player evidence, uncertainty cues, and a required reasoning route. It turns two incomplete components into a new system-level forecaster. A new generation of football benchmarks has begun evaluating LLMs and research agents under pre-match evidence constraints[6]。然而，让法学硕士自由预测分数会带来三个问题：数值先验可能被忽略，解释可能是事后的，历史模拟可能会泄露结果。. However, letting an LLM freely predict a score introduces three problems: numerical priors can be ignored, explanations can be post-hoc, and historical simulations can leak results.

这项工作提出了一个更狭隘的问题：This work asks a narrower question:

法学硕士是否可以添加有用的、可审核的匹配机制推理，同时保持先验的冻结概率分数？Can an LLM add useful, auditable match-mechanism reasoning while remaining subordinate to a frozen probabilistic score prior?

该项目通过四次主要迭代和两次界面更改达到了目前的形式。 V1 纯粹是数学的。 V2使用了“数学+LLM+数学”三明治：产生的基础模型The project reached its current form through four major iterations and two interface changes. V1 was purely mathematical. V2 used a “mathematics + LLM + mathematics” sandwich: the base model producedλ\lambda，法学硕士对足球信息进行了评分，并且学习的数字桥将该信号转换回, the LLM scored football information, and a learned numerical bridge converted that signal back intoλ\lambda。全球残差仅产生很小的、暂时不稳定的收益。因此，V3 将法学硕士的工作从参数校正改为显式匹配模拟。 V4 保留了该界面，并使共享的第一个目标、停止和级联判断变得可观察。在V3和V4中，数学模型提供了概率先验和候选几何；法学硕士通过工具读取之前的信息，构建因果分数路径，并返回排名，而无需另一个公式覆盖其推理。. The global residual produced only small, temporally unstable gains. V3 therefore changed the LLM’s job from parameter correction to explicit match simulation. V4 retained that interface and made the shared first-goal, stopping, and cascade judgments observable. In V3 and V4, the mathematical model provides the probabilistic prior and candidate geometry; the LLM reads that prior through the harness, constructs causal score paths, and returns a ranking without another formula overwriting its reasoning.

我们的贡献是：Our contributions are:

  • •

    可审计的混合架构，将概率状态估计、证据打包、LLM 推理和确定性验证分开；an auditable hybrid architecture separating probabilistic state estimation, evidence packaging, LLM reasoning, and deterministic validation;

  • •

    从特征提取和标量残差到显式匹配状态路径、共享根裁决和级联深度的有记录的演变；a documented evolution from feature extraction and scalar residuals to explicit match-state paths, shared root adjudication, and cascade depth;

  • •

    按时间顺序重播协议，在结果评分之前冻结提示和响应，并包含每场比赛的输入/输出档案和哈希值；和a chronological replay protocol that freezes prompts and responses before outcome scoring, with per-match input/output archives and hashes; and

  • •

    诚实的临时基准，包括适当的分数基线、配对比较、失败切片和历史法学硕士评估的局限性。an honest interim benchmark including proper-score baselines, paired comparisons, failure slices, and limitations of historical LLM evaluation.

V1 is strong where the task is aggregation: many historical observations, time decay, coherent probabilities, and repeatable arithmetic. V2 treated context too much like a fixed tabular feature. V3 and V4 represent it as conditional evidence attached to transitions.

RedEvoAgent：自动红队代理RedEvoAgent: Automatic Red-Teaming Agent
经验驱动的技能进化with Experience-Driven Skill Evolution

Junjie Zhang1  Hui Liu1  Kecheng Chen1 Xianbo Mo2  Changsheng Chen2  Haoliang Li1 1 City University of Hong Kong  2 Shenzhen MSU-BIT University
摘要Abstract

基于 LLM 的代理越来越多地部署在产品级执行工具中，其中越狱可能会触发有害的工具使用和持久的状态更改，从而比单独生成不安全的文本产生更大的风险。 现有的自动红队方法通常依赖于固定攻击，而最近的代理攻击者协调多个越狱工具，并通过基于轨迹的检索显示出更强的潜力。 然而，由于检索偏差和工具信用不明确，这种检索可能会重复使用误导性的经验，并且完整的轨迹会增加上下文开销，同时降低可解释性。 我们提出了 RedEvoAgent，一种黑盒红队代理，可将跨案例攻击轨迹提炼成简洁的、人类可读的攻击技能。 攻击技能通过工具有效性分析和技能更新的决策工具归因以及仅保留提高验证性能的更新的验证棘轮来自适应发展。 对多个基准、目标模型和目标执行工具的实验表明，RedEvoAgent 的性能优于固定基准和代理基准，提高了工具效率，并可以跨攻击者模型和目标执行工具进行传输。LLM-based agents are increasingly deployed in product-level execution harnesses, where jailbreaks can trigger harmful tool use and persistent state changes, creating greater risks than unsafe text generation alone. Existing automatic red-teaming methods often rely on fixed attacks, while recent agentic attackers coordinate multiple jailbreak tools and show stronger potential through trajectory-based retrieval. However, such retrieval can reuse misleading experiences due to retrieval bias and unclear tool credit, and full trajectories add context overhead while reducing interpretability. We propose RedEvoAgent, a black-box red-teaming agent that distills cross-case attack trajectories into a concise, human-readable attack skill. The attack skill adaptively evolves through tool-effectiveness profiling and Deciding-Tool Attribution for skill updates, and a validation ratchet that retains only updates improving validation performance. Experiments on multiple benchmarks, target models, and target execution harnesses show that RedEvoAgent outperforms fixed and agentic baselines, improves tool efficiency, and transfers across attacker models and target execution harnesses.

1 简介Introduction

基于 LLM 的代理越来越多地集成到产品级工具中，例如 Claude CodeLLM-based agents are increasingly integrated into product-level harnesses such as Claude Code(Anthropic, 2026a)和法典and Codex(OpenAI, 2025)，允许他们修改本地文件、传输数据和调用外部 API, which allow them to modify local files, transfer data, and call external APIs(Yao et al., 2023; Yang et al., 2024b)。 这些功能扩大了越狱的安全影响，因为成功的攻击可能会导致破坏性工具的使用和系统状态的持续更改，而不是不安全的文本生成. These capabilities broaden the security implications of jailbreaks, as successful attacks may cause destructive tool use and persistent changes to system state rather than unsafe text generation(Greshake et al., 2023; Ruan et al., 2024; Andriushchenko et al., 2025)。 因此，产品级黑盒代理需要对抗性评估来表征其安全鲁棒性。 自动红队通过模拟现实世界的恶意攻击、对抗性输入和漏洞尝试，提供了一种可扩展的持续评估方法. Therefore, product-level black-box agents require adversarial evaluation to characterize their security robustness. Automatic red-teaming provides a scalable approach for continuous evaluation by simulating real-world malicious attacks, adversarial inputs, and exploit attempts(Perez et al., 2022; Ganguli et al., 2022; Mazeika et al., 2024).

现有的越狱方法大多依赖于固定的攻击机制。 有些会转换或重写原始攻击提示来规避代理的安全对齐防御，例如 FlipAttackMost existing jailbreak methods rely on a fixed attack mechanism. Some transform or rewrite the original attack prompt to circumvent an agent’s safety-alignment defenses, such as FlipAttack(Liu et al., 2025b)，而其他人则在预定义的搜索空间内优化对抗性提示，如 GCG 中, whereas others optimize adversarial prompts within a predefined search space, as in GCG(Zou et al., 2023)和AutoDANand AutoDAN(Liu et al., 2024)。 由于此类方法仅探索攻击空间的有限子集，因此它们可能会错过替代机制暴露的漏洞，并且更有可能失败。 因此，最近的工作研究了代理自动红队，其中由 LLM 驱动的攻击者代理利用有关现有攻击方法的先验知识，在统一的工作流程中自适应地协调它们。 例如，RedCodeAgent. Because such methods explore only a limited subset of the attack space, they may miss vulnerabilities exposed by alternative mechanisms and are more likely to fail. Recent work, therefore, investigates agentic automatic red-teaming, in which an LLM-driven attacker agent leverages prior knowledge about existing attack methods to adaptively coordinate them within a unified workflow. For example, RedCodeAgent(Guo et al., 2026)将攻击方法建模为可顺序调用的工具，并利用语义相似性来检索成功的轨迹作为先验，以指导攻击者代理的后续决策。models attack methods as sequentially invocable tools and utilizes semantic similarity to retrieve successful trajectories as priors to guide the attacker agent’s subsequent decisions.

尽管基于轨迹的检索很有效，但它也有一些局限性。 首先，这种范式假设所有检索到的轨迹都是有用的，但这可能不成立，因为语义检索可能会引入偏差，并且任何单独的工具选择决策对最终攻击成功的贡献通常是不清楚的。 因此，不相关或误导性的经验可能会被重复使用，导致优化不稳定和攻击性能下降。其次，全轨迹上下文通过消耗上下文窗口预算和增加推理成本而引入大量开销。 它们的低级行动记录也很难被人类解释和监控，从而阻碍了对战略演变的审计。Despite its effectiveness, trajectory-based retrieval has several limitations. First, this paradigm assumes that all retrieved trajectories are useful, which may not hold because semantic retrieval can introduce bias, and the contribution of any individual tool-choice decision to final attack success is often unclear. Consequently, irrelevant or misleading experiences may be reused, causing unstable optimization and degraded attack performance. Second, full-trajectory contexts introduce substantial overhead by consuming context-window budget and increasing inference cost. Their low-level action records are also difficult for humans to interpret and monitor, hindering auditing over the evolution of strategy.

为了解决这些差距，如图所示To address these gaps, as illustrated in Figure1，我们提出了 RedEvoAgent，一种自动黑盒红队代理，具有经验驱动的攻击技能进化。 RedEvoAgent将多种越狱方法集成到攻击工具箱中，并将攻击轨迹提炼成简洁的、人类可读的攻击技能，总结了高级编排策略。 与基于轨迹的历史先验相比，这种技能级别抽象减少了上下文开销并提高了可解释性，这与一般代理任务的证据一致，即高级技能摘要可以优于基于相似性的轨迹检索, we propose RedEvoAgent, an automatic black-box red-teaming agent with experience-driven attack-skill evolution. RedEvoAgent integrates diverse jailbreak methods into an attack toolbox and distills attack trajectories into a concise, human-readable attack skill that summarizes high-level orchestration strategies. Compared with trajectory-based historical priors, such a skill-level abstraction reduces context overhead and improves interpretability, consistent with evidence from general agent tasks that high-level skill summaries can outperform similarity-based trajectory retrieval(Ni et al., 2026; Yang et al., 2026)。 具体来说，我们构建了体验进化的训练和验证划分。 RedEvoAgent 首先在训练中测量越狱工具的有效性，以构建工具有效性概况。 为了防止技能进化将成功轨迹中频繁共现的工具与真正有效的工具混为一谈，我们引入了决策工具归因，它通过将直接导致攻击成功的工具标记为决策工具来提供更清晰的工具选择信号。 我们进一步设计了一种验证棘轮机制，仅当候选技能更新在独立验证集上产生改进时才接受该更新。 否则，将保留先前的技能，并记录失败的候选者以指导以后的迭代，从而减少不相关或误导性的更新信号。 通过这种方式，工具有效性测量和攻击轨迹决定了技能学习的内容，而验证反馈则决定了哪些修订将持续存在。. Concretely, we construct training and validation splits for experience evolution. RedEvoAgent first measures the effectiveness of jailbreak tools on the training split to build a tool-effectiveness profile. To prevent skill evolution from conflating frequently co-occurring tools in successful trajectories with genuinely effective tools, we introduce Deciding-Tool Attribution, which provides clearer tool-selection signals by labeling the tool that directly leads to attack success as the deciding tool. We further design a validation-ratchet mechanism that accepts a candidate skill update only if it yields a improvement on an independent validation set. Otherwise, the previous skill is retained, and failed candidates are recorded to guide later iterations, mitigating irrelevant or misleading update signals. In this way, tool-effectiveness measurements and attack trajectories determine what the skill learns, while validation feedback determines which revisions persist.

为了验证我们框架的有效性，我们在 Agent Security Bench (ASB) 上进行了实验To validate the effectiveness of our framework, we conduct experiments on Agent Security Bench (ASB)(Zhang et al., 2025a)和特工伤害and AgentHarm(Andriushchenko et al., 2025)跨多个目标模型，以及 Claude Code 和 Codex 目标执行工具。 结果表明，RedEvoAgent 的性能优于现有的固定和代理基线，并且进化后的攻击技能可以在不同的攻击者模型和目标执行工具之间转移。across multiple target models, as well as the Claude Code and Codex target execution harnesses. The results show that RedEvoAgent outperforms existing fixed and agentic baselines, and that the evolved attack skill transfers across different attacker models and target execution harnesses.

4.5 技能什么时候有用？When Do Skills Help?

当目标代理在攻击工具箱中表现出不均匀的抵抗力并且不同的攻击工具在不同情况下暴露出互补的弱点时，攻击技能是最有用的。 在这种情况下，没有任何孤立的攻击工具是一致有效的，因此进化的攻击技能可以优先考虑有前途的工具，并指导攻击者代理在失败后切换或排序它们。 相反，当无越狱或一种孤立的攻击工具已经接近饱和时，剩下的空间就所剩无几了。 我们的跨目标结果在质量上与这种模式一致：当固定基线留下空间时，RedEvoAgent 获得更多收益，而在已经接近上限的情况下，RedEvoAgent 获得的收益很少。An attack skill is most useful when a target agent exhibits uneven resistance across the attack toolbox and different attack tools expose complementary weaknesses across cases. In this regime, no isolated attack tool is uniformly effective, so an evolved attack skill can prioritize promising tools and guide the attacker agent to switch or sequence them after failures. Conversely, when No Jailbreak or one isolated attack tool already approaches saturation, little room remains. Our cross-target results are qualitatively consistent with this pattern: RedEvoAgent gains more where fixed baselines leave room and little where they are already near ceiling.

5 结论Conclusion

We present RedEvoAgent, an automatic red-teaming agent that learns and evolves an attack skill document from past attack experience. Across all experimental settings, RedEvoAgent outperforms the strongest isolated attack tool baseline and existing automatic red-teaming methods. In the skill ablation, the evolved skill achieves the highest attack effectiveness with the fewest attack tool calls. The skill document explicitly records tool priorities and attack strategies and can be transferred across attacker models and target execution harnesses. New attack tools can also be added to the same evaluation and evolution process, although performance depends on the strength and diversity of the toolbox.

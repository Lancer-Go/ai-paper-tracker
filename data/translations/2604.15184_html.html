摘要。Abstract.

在过去的一年里，研究人员开始创建代理系统，可以在免培训的环境中设计真实世界的 CAD 风格对象，我们称之为这种新型系统In the past year, researchers have started to create agentic systems that can design real-world CAD-style objects in a training-free setting, a new variety of system that we call代理辅助设计Agent-Aided Design。一般来说，这些系统将代理置于反馈循环中，在其中可以编写代码、将该代码编译为 CAD 模型的程序集、可视化模型，然后根据视觉和其他反馈迭代地完善其代码。尽管进展迅速，但一个关键问题仍然存在：这些系统都无法构建. Generally speaking, these systems place an agent in a feedback loop in which it can write code, compile that code to an assembly of CAD model(s), visualize the model, and then iteratively refine its code based on visual and other feedback. Despite rapid progress, a key problem remains: none of these systems can build具有移动部件的复杂 3D 装配体complex 3D assemblies with moving parts。例如，现有的系统无法构建活塞、钟摆，甚至剪刀。为了使代理辅助设计对工业制造产生真正的影响，我们需要一个能够生成此类 3D 装配的系统。在本文中，我们提出了一个原型. For example, no existing system can build a piston, a pendulum, or even a pair of scissors. In order for Agent-Aided Design to make a real impact in industrial manufacturing, we need a system that is capable of generating such 3D assemblies. In this paper we present a prototype of阿德瓦尔克AADvark，一个为此任务设计的代理系统。与以前最先进的系统不同，, an agentic system designed for this task. Unlike previous state-of-the-art systems,阿德瓦尔克AADvark捕获具有一个或多个自由度的动态零件交互。这一设计决策允许captures the dynamic part interactions with one or more degrees-of-freedom. This design decision allows阿德瓦尔克AADvark直接推理具有运动部件的组件，从而实现跨领域目标，包括但不限于机械运动。不幸的是，目前的法学硕士是不完美的空间推理者，这个问题to reason directly about assemblies with moving parts and can thereby achieve cross-cutting goals, including but not limited to mechanical movements. Unfortunately, current LLMs are imperfect spatial reasoners, a problem that阿德瓦尔克AADvark通过将外部约束求解器工具与专门的视觉反馈机制结合起来来解决。我们证明，通过修改代理的工具（FreeCAD 和装配解算器），我们能够创建强大的验证信号，使我们的系统能够构建具有可移动部件的 3D 装配体。addresses by incorporating external constraint solver tools with a specialized visual feedback mechanism. We demonstrate that, by modifying the agent’s tools (FreeCAD and the assembly solver), we are able to create a strong verification signal which enables our system to build 3D assemblies with movable parts.

1. 简介Introduction

工业制造依靠计算机辅助设计 (CAD) 来制造从家具到一级方程式赛车的各种产品Industrial manufacturing relies on computer-aided design (CAD) to create products ranging from furniture to Formula 1 cars(Enthed and XR, 2024; Stoermann, 2023)。 OnShape 等软件工具. Software tools such as OnShape(OnShape, 2026)、SolidWorks, SolidWorks(SolidWorks, 2026)和 FreeCAD, and FreeCAD(contributors, 2026)使工程师能够通过顺序应用操作（例如草图、拉伸、圆角等）在 GUI 中设计 3D 对象，将 2D 草图和 3D 对象转换为最终所需的形式。这一系列的操作，每个操作都由代表挤出长度的离散和/或连续值参数化，定义了enable engineers to design 3D objects in a GUI by sequentially applying operations (e.g., sketch, extrude, fillet, etc.) that transform 2D sketches and 3D objects into a final desired form. This series of operations, each parameterized by discrete and/or continuous values representing, for example, the length of an extrusion, defines aCAD模型CAD model这是可以捏造的。which can be fabricated.

尽管 CAD 工具已成为制造业不可或缺的工具（可提高生产率、设计精度和产品质量），但使用起来仍然很乏味While CAD tools have become indispensable for manufacturing—increasing productivity, design precision, and product quality—they can still be tedious to use(Robertson and Allen, 1993; Deng et al., 2023)。因此，图形和 AI 社区寻求通过训练深度生成模型来自动生成 CAD 模型，以根据图像、文本描述、3D 点云等对其进行逆向工程. As a result, the graphics and AI communities have sought to automate the generation of CAD models by training deep generative models to reverse engineer them from images, text descriptions, 3D point clouds, and more(Várady et al., 1997; Buonamici et al., 2018; You et al., 2025; Khan et al., 2024b, a; Chen et al., 2025; Lambourne et al., 2022, 2021; Zhang et al., 2024; Li et al., 2025; Wang et al., 2025a; Rukhovich et al., 2025; Xu et al., 2025; Xie and Ju, 2025)。为了克服训练数据的缺乏，最近的工作建立了代理系统，代理可以在其中编写代码，将代码编译为 CAD 模型，将模型可视化，例如FreeCAD，并使用视觉反馈（以及编译器错误和其他信号）迭代其设计，直到 CAD 模型与输入足够相似. To overcome a lack of training data, more recent work has built agentic systems where an agent can write code, compile the code to a CAD model, visualize the model in e.g. FreeCAD, and use the visual feedback (as well as compiler errors and other signals) to iterate on its design until the CAD model is sufficiently similar to the input(Alrashedy et al., 2025; Mallis et al., 2025; Fan et al., 2025; Yuan et al., 2024a; Anonymous, 2026).

然而，尽管这些技术在 CAD 基准测试中具有最先进的性能However, in spite of these techniques’ state-of-the-art performance on CAD benchmarks(Wu et al., 2021; Cherenkova et al., 2020; Willis et al., 2021)，它们面临一个关键的限制：系统能够生成静态 CAD 模型，, they suffer from a key limitation: the systems are capable of generating static CAD models,但他们无法对具有接头和运动部件的复杂装配体进行建模but they cannot model complex assemblies with joints and moving parts。更简单地说，这些系统无法制造出一把功能性的剪刀。之前的工作可以为剪刀刀片和手柄创建 3D 模型，但无法对允许刀片以切片运动方式移动的旋转关节进行建模。如果要认真对待智能体辅助设计 (AAD) 作为工业制造的工具，通过“剪刀测试”至关重要。. Put more simply, these systems cannot create a functional pair of scissors. Prior work can create a 3D model for the scissor blades and handles, but it cannot model the revolute joint which allows the blades to move in a slicing motion. Passing “the scissors test” is crucial if Agent-Aided Design (AAD) is to be taken seriously as a tool for industrial manufacturing.

生成具有移动零件的动态 3D 装配体比生成静态 CAD 模型更困难。首先，代理系统需要指定连接装配体中每个零件的关节。与之前的工作不同，这包括指定每个关节的自由度以允许动态部件交互。鉴于视觉语言模型 (VLM) 在空间推理方面的已知局限性，这尤其具有挑战性Generating dynamic 3D assemblies with moving parts is more difficult than generating static CAD models. For starters, the agentic system needs to specify the joints that connect each part in the assembly. Unlike prior work, this includes specifying each joint’s degree(s) of freedom to allow for dynamic part interactions. This is made especially challenging, given Vision Language Models’ (VLMs) known limitations in spatial reasoning(Stogiannidis et al., 2025; Shiri et al., 2024)。此外，为了使代理系统编译其设计，它必须能够访问 3D 装配约束求解器。在我们最初的实验中，我们发现现有的开源求解器存在局限性，因为它们是在设计时考虑到人类最终用户的。例如，这些解算器使用欧拉角而不是四元数，因为它们假设如果解算器以反平行方式定向零件，则人类可以在 GUI 中翻转零件。为了最大限度地提高求解器对代理的效用，我们最终必须修改求解器以使用四元数并增强其错误消息，使其通常更具信息性。. Furthermore, in order for the agentic system to compile its design, it must have access to a 3D assembly constraint solver. In our initial experiments, we found that existing open-source solvers had limitations due to the fact that they were designed with a human end-user in mind. For example, these solvers used Euler angles instead of quaternions because they assumed that a human could flip the part in a GUI if the solver oriented a part in an anti-parallel fashion. To maximize the solver’s utility for an agent, we ultimately had to modify the solver to use quaternions and enhance its error messages to be generally more informative.

代理执行。Agent Execution. 阿德瓦尔克AADvark将一张或多张图像以及可选的所需对象的文本描述作为输入。这些输入被输入到代理（例如我们演示中的 Gemini 3 Flash）中，其目标是生成 CAD 模型（即 3D 组件），可以通过制作该模型来创建该对象。该代理通过编写 JSON 文件来定义组成 3D 装配的零件和接头来创建装配。takes one or more images and optionally a text description of the desired object as input. These inputs are fed into an agent (e.g., Gemini 3 Flash in our demonstration) whose goal is to generate a CAD model (i.e., a 3D assembly) which could be fabricated to create this object. The agent creates an assembly by writing JSON files to define the parts and joints that make up a 3D assembly.

在我们的例子中In our example inFigure 1，向代理提供两张剪刀的照片以及其输入的文本描述。然后，它构建与刀片、手柄和枢轴相对应的三个 JSON 零件文件。为了将这些部分组成一个程序集，代理会编写一个由三个部分组成的 JSON 程序集文件。首先，代理通过指向 JSON 零件文件定义的指针来指定装配体中使用的零件。其次，代理创建唯一的一组, the agent is given two photos of a pair of scissors as well as a text description for its input. It then constructs three JSON parts files corresponding to the blade, the handle, and the pivot. To compose these parts into an assembly, the agent writes a JSON assembly file which consists of three sections. First, the agent specifies the parts used in the assembly with pointers to their JSON part file definitions. Second, the agent creates the unique set of零件实例part instances在“链接”部分。例如，一把剪刀将具有两个不同的手柄和刀片部件实例，每个实例都用其自己的链接定义。第三，这些独特的零件实例通过一组“关节”连接在一起。in the “links” section. For example, a pair of scissors will have two distinct instances of the handle and blade parts, each of which is defined with its own link. Third, these unique part instances are joined together by a set of “joints”.

In 阿德瓦尔克AADvark，代理通过指定两个链接的名称、链接类型、链接的两个面被链接、哪些自由度是固定的还是自由的以及（如果是自由的）其自由度存在哪些限制，将两个链接连接在一起。一旦代理创建了完整的 JSON 程序集文件，, the agent joins two links together by specifying their names, the type of joint, which two faces of the links are being joined, which degrees of freedom are fixed vs. free, and (if free) what limits exist on their freedom. Once the agent creates a complete JSON assembly file,阿德瓦尔克AADvark编译文件，在 FreeCAD 中渲染它，并将其发送到 3D 装配约束求解器。 FreeCAD 会生成装配体的渲染图，而约束求解器可能会生成指示设计中存在缺陷的错误消息。 （我们将在下面更详细地讨论这些工具）。最后，代理将这些反馈信号合并到其下一代 JSON 零件和装配文件中。此迭代过程持续进行，直到装配体通过约束求解器并且代理认为装配体的渲染足以表示输入。compiles the file, renders it in FreeCAD, and sends it to the 3D assembly constraint solver. FreeCAD produces a rendering of the assembly while the constraint solver may produce error messages indicating flaws in the design. (We discuss each of these tools in more detail below). Finally, the agent incorporates these feedback signals into its next generation of the JSON parts and assembly files. This iterative process continues until the assembly passes the constraint solver and the agent deems the rendering of the assembly to adequately represent the input(s).

建立强大的验证者。Building Strong Verifiers.内代理The agent within阿德瓦尔克AADvark提供了两个主要工具来获取其设计正确性的信号。首先，为代理提供了 3D 装配约束求解器，该求解器获取 JSON 装配文件并返回其部件是否可以物理连接到装配中。的is provided with two primary tools for obtaining a signal on the correctness of its design. First, the agent is provided with a 3D assembly constraint solver which takes the JSON assembly file and returns whether its parts could physically be joined into an assembly. The阿德瓦尔克AADvark原型使用开源 OndselSolver 的增强版本prototype uses an augmented version of the open-source OndselSolver(contributors and Adler, 2026)为其约束求解器。然而，在使用原始 OndselSolver 时，我们注意到其设计的某些元素阻碍了代理设计正确组件的能力。for its constraint solver. However, when working with the original OndselSolver, we noticed that some elements of its design hindered the agent’s ability to design correct assemblies.

例如，由于使用欧拉角，解算器可以返回以反平行方式定向零件的装配体。对于人类来说，FreeCAD 通过向他们提供一个按钮来翻转装配体中的任何零件，从而解决了这个问题。然而，对于代理来说，这导致了对其设计正确性的困惑。为了使求解器对代理更有用，我们对其进行了增强，使用四元数而不是欧拉角。此外，我们修改了解算器，即使出现编译错误，也可以更新零件在 FreeCAD 中的位置。默认情况下，如果存在编译错误（例如，因为两个零件会相交），FreeCAD 将不会更新设计，但是可视化这些错误有助于代理了解其错误。最后，我们通过消除牛顿法内部调用中的方差来源，使求解器的错误消息总体上更具信息性，并使其更具确定性。For example, due to its use of Euler angles, the solver could return an assembly which oriented a part in an anti-parallel fashion. For humans, FreeCAD resolved this issue by presenting them with a button to flip any part in the assembly. However, for the agent, this led to confusion about the correctness of its design. To make the solver more useful for the agent, we augmented it to use quaternions instead of Euler angles. Additionally, we modified the solver to update parts’ positions in FreeCAD even when there was a compilation error. By default FreeCAD will not update the design if there is a compilation error (e.g. because two parts would intersect), however visualizing these errors helped the agent understand its mistakes. Finally, we made the solver’s error messages generally more informative and made it more deterministic by eliminating sources of variance which went into an internal invocation of Newton’s Method.

提供的第二个工具The second tool provided to阿德瓦尔克AADvark的代理是 FreeCAD 的扩展版本。代理使用此工具生成其 3D 组件的渲染。这有助于识别其设计中的缺陷，并可以在后续迭代中纠正这些缺陷。提供视觉反馈的一个关键挑战是 VLM 是不完美的空间推理器’s agent is an extended version of FreeCAD. The agent uses this tool to generate renderings of its 3D assembly. This helps to identify flaws in its design which can be corrected in subsequent iterations. One key challenge with providing visual feedback is that VLMs are imperfect spatial reasoners(Stogiannidis et al., 2025; Shiri et al., 2024)。在我们的早期实验中，我们发现代理很难正确指定关节，因为不同的零件实例在 FreeCAD 的渲染中可能看起来相同。为了克服这个问题，我们修改了 FreeCAD，为每个零件实例的每个面和边缘计算独特的颜色和纹理（例如实线与虚线）。有了这些独特的颜色和纹理，我们就可以要求代理通过编写由给定关节连接的零件面的颜色和纹理来指定其关节。添加此增强功能最终使. In our early experiments, we found that the agent struggled to specify joints correctly because different part instances could look identical in FreeCAD’s renderings. To overcome this issue, we modified FreeCAD to compute a unique color and texture (e.g. solid vs. dotted line) for each face and edge of each part instance. Given these unique colors and textures, we could then ask the agent to specify its joints by writing the colors and textures of the part faces to be joined by a given joint. The addition of this enhancement is ultimately what enabled阿德瓦尔克AADvark为幼儿床生产正确的组件to produce a correct assembly for the toddler bed inSection 4.

5. 局限性Limitations

同时While阿德瓦尔克AADvark虽然它代表了朝着动态 CAD 模型的代理辅助设计迈出的有希望的第一步，但它确实有局限性。目前，该系统只能使用矩形棱柱作为零件，并且它支持的唯一动态关节是旋转关节。未来，我们打算扩大零件和接头的范围，represents a promising first step towards Agent-Aided Design of dynamic CAD models, it does have limitations. For now, the system can only use rectangular prisms for parts and the only dynamic joint which it supports is a revolute joint. In the future, we intend to expand the set of parts and joints that阿德瓦尔克AADvark可以创建以允许它设计 FreeCAD 可以支持的任何对象。最后，由于代理执行的不确定性，我们观察到can create to allow it to design any object that FreeCAD can support. Finally, due to the non-deterministic nature of agentic execution, we observed that阿德瓦尔克AADvark有时会卡在其装配设计上。我们发现，只需重新启动代理通常就可以解决问题，但将来我们的目标是调查代理卡住的根本原因。sometimes will get stuck on its assembly design. We found that simply restarting the agent can often times resolve the issue, but in the future we aim to investigate the underlying causes of the agent getting stuck.

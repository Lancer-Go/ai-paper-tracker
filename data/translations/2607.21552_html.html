摘要Abstract

与表现出强大推理能力的大型语言模型 (LLM) 不同，视觉语言模型 (VLM) 很难进行视觉推理，即使是在允许等效文本、图表以及图表+文本组合视图的几何问题上也是如此。我们表明，这些视图通常会引发不同的行为：模型可能从文本中解决问题，但在相应的图表上失败，或者在视觉上成功，但在文本上失败。这种不一致表明，不同的观点暴露了标准多模式后训练没有充分利用的互补推理路径和故障模式。为了研究和利用这种现象，我们构建了 ODA-Data，这是一个高质量的配对多模态几何数据集，具有相同问题的文本主导、图像主导和组合图像+文本视图，以及用于训练和评估模态依赖推理行为的分割。然后我们开发Unlike large language models (LLMs) that exhibit strong reasoning capabilities, vision-language models (VLMs) struggle with visual reasoning, even on geometry problems that admit equivalent text, diagram, and combined diagram+text views. We show that these views often elicit different behaviors: a model may solve a problem from text but fail on the corresponding diagram, or succeed visually while failing textually. This inconsistency suggests that different views expose complementary reasoning paths and failure modes that standard multimodal post-training does not fully exploit. To study and exploit this phenomenon, we construct ODA-Data, a high-quality paired multimodal geometry dataset with text-dominant, image-dominant, and combined image+text views of the same problems, together with splits for training and evaluating modality-dependent reasoning behaviors. We then develop模态通知的交互推理优化Modality-Informed Reciprocal Reasoning Optimization (镜子MIRROR），一种通过自我监督改进多模态推理的强化学习方法。对于每个问题，), a reinforcement learning approach for improving multimodal reasoning via self-supervision. For each problem,镜子MIRROR在所有视图下评估模型，选择表现最好的视图作为教师，并以针对教师的反向 KL 目标训练其他视图。在评估几何问题的推理基准中，evaluates the model under all views, selects the best-performing view as a teacher, and trains other views with a reverse-KL objective towards the teacher. 1 简介Introduction

视觉语言模型在多模态推理方面取得了实质性进展Vision-language models have made substantial progress on multimodal reasoning[10, 3]，但他们的行为对信息的呈现方式仍然高度敏感, but their behavior remains highly sensitive to how the information is presented[25, 57, 23]。 正如我们在实验中发现的那样，当相关关系以文本形式写入时，模型可能会解决问题，但当必须从图像中恢复这些关系时，模型就会失败；相反，图像可以使几何结构以纯文本描述无法做到的方式变得突出。这种不一致尤其令人担忧，因为根本的推理问题没有改变，只有输入视图改变了。这表明当前的 VLM 不仅仅受到问题难度的限制. As we also find in our experiments, a model may solve a problem when the relevant relations are written in text, yet fail when those relations must be recovered from an image; conversely, an image may make geometric structure salient in a way that a purely textual description does not. This inconsistency is especially concerning because the underlying reasoning problem has not changed, only the input view has. It suggests that current VLMs are not merely limited by problem difficulty[55]，但也受到依赖于观点的基础和推理失败的影响。我们的目标是研究并解决这些失败。, but also by view-dependent failures in grounding and reasoning. Our goal is to study and address these failures.

为此，我们专注于几何问题，作为研究这种现象的自然测试平台。许多几何问题都承认同一基础数学结构的多种观点：To do so, we focus on geometry problems that serve as a natural testbed for studying this phenomenon. Many geometry problems admit several views of the same underlying mathematical structure: a文本主导text-dominant视图，用语言列举数量和关系；一个view, where quantities and relations are enumerated in language; an图像主导image-dominant视图，其中图像携带必要的几何信息，随附的文本主要指定问题；和一个view, where the image carries essential geometric information and the accompanying text mainly specifies the question; and a合并的combined图像+文本视图，两种来源都可用。与许多多模式设置不同，视觉输入引入了语言中无法提供的信息image+text view, where both sources are available. Unlike many multimodal settings where visual inputs introduce information unavailable in language[29, 2]，几何允许通过文本、图表或两者来表达相同的问题。这使得可以对不同视图之间的推理进行受控比较，同时保持底层语义不变。正如我们在表中发现的, geometry allows the same problem to be expressed through text, diagrams, or both. This enables a controlled comparison of reasoning across views while keeping the underlying semantics unchanged. As we find in Table1，这种受控比较揭示了一种有用的不对称性：同一模型可以在一种视图下暴露有效的推理路径，即使它在另一种视图下失败。这表明跨视图不一致不仅是鲁棒性失败，而且也是潜在的监督信号。, this controlled comparison reveals a useful asymmetry: the same model can expose a valid reasoning path under one view even when it fails under another. This suggests that cross-view inconsistency is not just a robustness failure, but also a potential supervision signal.

先前的多模态推理工作通常通过使用外部教师来改进模型Prior work on multimodal reasoning often improves models by using external teachers[27]，策划的理由, curated rationales[59]，或教授模型如何结合视觉和文本输入的专门训练数据, or specialized training data that teaches the model how to combine visual and textual inputs[13, 5]。然而，这种监督可能不适用于每个目标设定，并且外部教师的提炼在分配不匹配的情况下可能很脆弱. In contrast, we study whether paired views of the same problem can provide a form of self-supervision: when the model succeeds under one view but fails under another, can the successful view help improve the weaker one?

4 理解跨模态推理的差异Understanding Differences in Reasoning Across Modalities

在介绍我们的方法之前，我们首先分析基础模型的推理行为Before introducing our approach, we first analyze reasoning behaviors of the base modelQwen3-VL-4B-指令Qwen3-VL-4B-Instruct [4]从不同的输入视图解决相同的根本问题时。在本节中，我们将描述文本主导、图像主导或文本和图像组合输入何时导致不同的推理行为和性能。具体来说，我们问三个问题：when solving the same underlying problem from different input views. 4.1 不同模态的推理痕迹有何不同？How do Reasoning Traces Differ Across Modalities?

在这项工作中，我们将跨模态的推理不对称性确定为多模态推理自我监督的来源。我们介绍In this work, we identify reasoning asymmetry across modalities as a source of self-supervision for multimodal reasoning. Our results show that paired multimodal data is most effective when the training objective explicitly exploits the correspondence between views. Simply mixing text-dominant and image-dominant views into the RL distribution does not reliably transfer reasoning, because each view is still optimized as an independent prompt. This yields stronger and more consistent reasoning, with the largest gains on modality-asymmetric examples where one view succeeds and another fails.

更广泛地说，我们的研究结果提出了使用多模式数据的不同方式。我们不应该将不同的输入格式视为独立的示例，而是可以将它们视为同一潜在问题的替代视图，并利用它们的分歧来暴露缺失的推理能力。这一观点为未来的工作开辟了几个方向。从几何扩展到科学图形、图表、表格、机器人观察或更广泛的视觉推理将需要可靠的方法来构建信息等效视图。教师的选择也可以通过中间推理步骤的不确定性加权或对齐来改进，而不是仅仅依赖于推出奖励。总的来说，我们的研究结果指出了更广泛的机会：跨模态不一致可以从鲁棒性问题转变为有用的训练信号，用于学习多模态推理机，这些推理机对信息的表示方式更强且不太敏感。More broadly, our findings suggest a different way to use multimodal data. Rather than treating different input formats as independent examples, we can treat them as alternative views of the same latent problem and use their disagreements to expose missing reasoning capabilities. This perspective opens several directions for future work. Extending beyond geometry to scientific figures, charts, tables, robotics observations, or broader visual reasoning will require reliable ways to construct information-equivalent views. Teacher selection could also be improved with uncertainty-aware weighting or alignment at intermediate reasoning steps, rather than relying only on rollout rewards. Overall, our findings point to a broader opportunity: cross-modal inconsistency can be transformed from a robustness concern into a useful training signal for learning multimodal reasoners that are stronger and less sensitive to how information is represented.

为了在解决根本问题的同时研究模态依赖推理，我们构造To study modality-dependent reasoning while holding the underlying problem fixed, we constructODA-数据ODA-Data，一个配对的多模态几何数据集，其中每个问题都以两个对齐的视图表示：文本主导视图和图像主导视图。从 OpenDataArena/ODA-Math-460k 的 97K 几何类型问题开始, a paired multimodal geometry dataset in which each problem is represented in two aligned views: a text-dominant view and an image-dominant view. Starting from 97K geometry-style problems from OpenDataArena/ODA-Math-460k[6]，我们首先应用一个难度过滤器，删除带注释的 pass@5=1 的简单问题，产生 16K 候选问题。对于每位候选人，我们都会提示法学硕士以 TikZ 代码形式生成图表，TikZ 代码是用于编程矢量图形的标准 LaTeX 包。我们只保留 TikZ 代码编译成功的图表，并使用 LLM 判断来验证生成的图表在语义上与原始问题陈述一致。, we first apply a difficulty filter that removes easy questions with annotated pass@5=1, yielding 16K candidate questions. For each candidate, we prompt an LLM to generate a diagram as TikZ code, a standard LaTeX package for programmatic vector graphics. We retain only diagrams whose TikZ code compiles successfully and use an LLM judge to verify that the generated diagram is semantically aligned with the original problem statement.

为了构建图像主导视图，我们进一步提示法官从文本中删除图表中已经呈现的任何信息，以便剩余的文本和图像提供补充信息。所有基于LLM的生成和评审步骤均使用Gemini-3-Pro-Preview。然后，我们使用基本模型执行特定于模态的推出评估，并删除基本模型在文本主导和图像主导视图下可靠解决的问题，以便最终数据集强调其可解决性取决于输入表示的问题。此过程产生大约 2K 个精选的配对多模态示例。To construct the image-dominant view, we further prompt the judge to remove from the text any information already presented in the diagram, so that the remaining text and image provide complementary information. All LLM-based generation and judging steps use Gemini-3-Pro-Preview. We then perform modality-specific rollout evaluations using the base model and remove questions that the base model reliably solves under both the text-dominant and image-dominant views, so that the final dataset emphasizes problems whose solvability depends on the input representation. This process yields approximately 2K curated paired multimodal examples.

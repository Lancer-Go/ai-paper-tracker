MemTrapBench：LLM 内存使用中的认知陷阱基准测试MemTrapBench: Benchmarking Cognitive Traps in LLM Memory Use

Mengru Wang    Haozhe Luo    Zhenqian Xu    Zhixiang Cui    Haoming Xu    Qu Yang    Jizhan Fang    Junfeng Fang\corresponding    Ningyu Zhang\corresponding
摘要Abstract

记忆已成为大型语言模型的关键组成部分，使它们能够保留信息并从长期交互中学习。 然而，现有的记忆基准主要评估信息是否被正确提取、存储和检索，而很大程度上忽视了检索的记忆如何重塑模型推理并影响当前任务的性能。 我们识别记忆引起的认知陷阱： 甚至是忠实记录且语义相关的记忆 可能会扭曲模型推理或信念并降低当前任务的质量 性能。 为了系统地评估这些故障模式，我们引入了 MemTrapBench，它涵盖了两种形式的认知陷阱：Memory has become a key component of large language models, enabling them to retain information and learn from long-term interactions. However, existing memory benchmarks mainly evaluate whether information is correctly extracted, stored, and retrieved, while largely overlooking how retrieved memories reshape model reasoning and affect performance on the current task. We identify memory-induced cognitive traps: even faithfully recorded and semantically relevant memories can distort model reasoning or beliefs and degrade current task performance. To systematically evaluate these failure modes, we introduce MemTrapBench, which covers two forms of cognitive traps:推理固定Reasoning Fixation和and信念扭曲Belief Distortion。 跨两个模型系列和五个代表性内存框架的实验表明，MemTrapBench 具有挑战性：所有评估的内存策略都在无内存设置下表现不佳，即使是最强的方法也会出现超过 10% 的下降。 为了减轻这些认知陷阱，我们提出了 AdaptiveMem，这是一种简单而有效的推理时间方法，可以指导法学硕士避免记忆陷阱。 AdaptiveMem 缓解 MemTrapBench 上的认知陷阱，同时保持或提高跨不同内存框架的标准内存基准的性能. Experiments across two model families and five representative memory frameworks show that MemTrapBench is challenging: all evaluated memory strategies underperform the no-memory setting, with even the strongest methods suffering drops of more than 10%. To mitigate these cognitive traps, we propose AdaptiveMem, a simple yet effective inference-time method that instructs LLMs to avoid memory traps. AdaptiveMem mitigates cognitive traps on MemTrapBench while preserving or improving performance on standard memory benchmarks across diverse memory frameworks11 1数据和代码可在Data and code will be available athttps://github.com/zjunlp/MemTrapBench.

Most existing studies focus on constructing and maintaining external memory from long interaction histories, then retrieving relevant information to support subsequent queries(2; 51; 8; 36; 32; 39; 40; 38)。 因此，现有的基准主要评估内存提取、存储、更新和检索. 分类学Taxonomy

我们将内存陷阱分为We divide Memory Traps into推理固定Reasoning Fixation和and信念扭曲Belief Distortion. 推理固定Reasoning Fixation当记忆将模型锚定到先前建立的推理模式时，就会发生这种情况。 它包括跨任务和任务内固定。occurs when memory anchors the model to a previously established reasoning pattern. It includes cross-task and within-task fixation.跨任务固定Cross-task fixation表现为manifests as任务边界Task Boundary：任务更改后，模型继续应用前一个任务的规则或假设。: after the task changes, the model continues to apply rules or assumptions from the previous task.任务内固定Within-task fixation包括includes认知偏差Cognitive Bias，其中先前成功的策略被过度概括为需要不同策略的新实例，并且, where a previously successful strategy is overgeneralized to a new instance requiring a different strategy, and外伤Trauma，其中先前的负反馈导致模型避免针对当前实例正确的策略。 在这里，“创伤”仅用作反馈引起的回避的行为类比。 在这些场景中，历史信息在其原始上下文中仍然有效，但应用范围超出了其适当范围。, where prior negative feedback causes the model to avoid a strategy that is correct for the current instance. Here, “Trauma” is used only as a behavioral analogy for feedback-induced avoidance. In these scenarios, the historical information remains valid in its original context but is applied beyond its appropriate scope.信念扭曲Belief Distortion相比之下，改变了模型视为真实的内容。 其, by contrast, changes what the model treats as true. Its安全Safety类别测试交互历史中建立的反事实或特定于沙箱的前提是否被错误地应用于现实世界的查询。 与固定推理不同，这些前提不一定是客观正确的；相反，它们是故意令人难以置信的，并且明显与基本的安全知识相矛盾，使我们能够测试记忆是否可以推翻其他简单的安全判断。category tests whether a counterfactual or sandbox-specific premise established in the interaction history is incorrectly applied to a real-world query. Unlike Reasoning Fixation, these premises need not be objectively correct; instead, they are deliberately implausible and clearly contradict basic safety knowledge, allowing us to test whether memory can override otherwise straightforward safety judgments.

实例构建Instance Construction

我们首先手动设计四个类别的种子实例。 每个种子指定四个字段：We first manually design seed instances across the four categories. Each seed specifies four fields:域名Domain, 陷阱机制Trap Mechanism, 地面真相Ground Truth, 和, and事先种植Planted Prior，它记录了交互历史中建立的策略、反馈、规则或信念。 每个最终查询都可以在其当前任务条件下独立回答。 这使得能够与无记忆设置进行受控比较，并将记忆引起的能力变化与内在任务难度分开。 因此，MemTrapBench 充当有害内存影响的诊断压力测试，而不是内存效用的一般评估。, which records the strategy, feedback, rule, or belief established in the interaction history. Each final query is independently answerable under its current task conditions. This enables a controlled comparison with the no-memory setting and separates memory-induced capability changes from intrinsic task difficulty. Accordingly, MemTrapBench serves as a diagnostic stress test of harmful memory influence rather than a general evaluation of memory utility.

然后，我们使用 GPT-5.4 将每个种子扩展为具有以下三个阶段的多轮对话：We then use GPT-5.4 to expand each seed into a multi-turn dialogue with the following three stages:(1)设置陷阱：(1) Plant the trap:在合理的环境中引入上下文先验，并在后续交互中重复应用；a contextual prior is introduced in a plausible setting and repeatedly applied in subsequent interactions;(2) 将其埋入噪音中：(2) Bury It in Noise:插入不相关的回合，产生 18-40 回合的对话； 和unrelated turns are inserted, producing dialogues of 18–40 turns; and(3) 启动陷阱：(3) Spring the Trap:最终查询在语义上仍然与历史相关，但更改了应应用先验的条件。 因此，正确的响应需要根据当前的任务条件进行推理，而不是机械地延续早期的模式。 我们排除了显式的重置提示，例如“忽略先前的规则”，这要求模型识别上下文转换本身。the final query remains semantically related to the history but changes the conditions under which the prior should be applied. A correct response therefore requires reasoning from the current task conditions rather than mechanically carrying over the earlier pattern. We exclude explicit reset cues such as “ignore previous rules”, which requires the model to recognize the contextual transition itself.

最后，每位候选人都会通过结合自动过滤和专家人工审核的两阶段质量控制流程。 我们评估主题连贯性、上下文一致性、交互真实性、独立解决性和上下文转换的清晰度。 最后一个标准由注释器仅根据查询进行验证，与任何模型的响应无关。 未通过任一阶段的候选人将被丢弃或修改。 每个保留的实例都标有黄金标准响应和预期失败模式，描述记忆如何引发认知陷阱。 GPT-5.4仅用于候选生成，最终纳入由质量控制过程决定，所有评估均单独进行。 一般来说，我们的基准 MemTrapBench 包含 1,050 个实例，其中包括 350 个认知偏差实例、350 个任务边界实例、200 个安全实例和 150 个创伤实例。 补充材料中提供了详细的生成提示、注释指南、过滤标准和数据集统计信息。Finally, each candidate passes through a two-stage quality-control pipeline combining automated filtering and expert human review. We evaluate topic coherence, context consistency, interaction realism, standalone solvability, and clarity of the contextual transition. The last criterion is verified by annotators from the query alone, independent of any model’s response. Candidates failing either stage are discarded or revised. Each retained instance is annotated with a gold-standard response and an expected failure mode describing how memory may induce the cognitive trap. GPT-5.4 is used only for candidate generation, while final inclusion is determined by the quality-control process and all evaluations are conducted separately. Generally, our benchmark MemTrapBench contains 1,050 instances, including 350 Cognitive Bias, 350 Task Boundary, 200 Safety, and 150 Trauma instances. Detailed generation prompts, annotation guidelines, filtering criteria, and dataset statistics are provided in the Supplementary Material.

5 结论Conclusion

我们推出 MemTrapBench，这是一个评估法学硕士中记忆引起的认知陷阱的基准。 跨多个模型和内存策略的实验表明，MemTrapBench 对现有内存框架仍然具有挑战性。 我们进一步提出 AdaptiveMem，这是一种简单而有效的方法，可实现更可靠的内存使用。We introduce MemTrapBench, a benchmark for evaluating memory-induced cognitive traps in LLMs. Experiments across multiple models and memory strategies show that MemTrapBench remains challenging for existing memory frameworks. We further propose AdaptiveMem, a simple yet effective approach for more reliable memory use.

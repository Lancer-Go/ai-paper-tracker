摘要。Abstract.

基于法学硕士的编码代理通过来自开放市场的第三方“代理技能”扩展其功能，无需强制安全审查。与传统软件包不同，这些技能是作为具有系统级权限的操作指令执行的，因此单个恶意技能就可以危害主机。尽管存在现有的防护措施，但先前的工作尚未检验供应链攻击是否可以直接劫持代理的操作空间（例如文件写入、shell 命令、网络请求）。我们引入了文档驱动的隐式有效负载执行（DDIPE），它将恶意逻辑嵌入到技能文档中的代码示例和配置模板中。当代理在正常任务期间重用这些示例时，有效负载会在没有明确提示的情况下执行。使用法学硕士驱动的管道，我们从 15 个 MITRE ATT&CK 类别的 81 个种子中生成了 1,070 种对抗技能。在四个框架和五个模型中，DDIPE 实现了 11.6%–33.5% 的绕过率，而显式指令攻击在强防御下实现了 0%。静态分析可以检测到大多数情况，但 2.5% 的情况同时规避了检测和对齐。负责任的披露导致了四个已确认的漏洞和两个修复。LLM-based coding agents extend their capabilities via third-party “agent skills” from open marketplaces without mandatory security review. Unlike traditional packages, these skills are executed as operational directives with system-level privileges, so a single malicious skill can compromise the host. Prior work has not examined whether supply-chain attacks can directly hijack an agent’s action space (e.g., file writes, shell commands, network requests) despite existing safeguards. We introduce Document-Driven Implicit Payload Execution (DDIPE), which embeds malicious logic in code examples and configuration templates within skill documentation. As agents reuse these examples during normal tasks, the payload executes without explicit prompts. Using an LLM-driven pipeline, we generate 1,070 adversarial skills from 81 seeds across 15 MITRE ATT&CK categories. Across four frameworks and five models, DDIPE achieves 11.6%–33.5% bypass rates, while explicit instruction attacks achieve 0% under strong defenses. Static analysis detects most cases, but 2.5% evade both detection and alignment. Responsible disclosure led to four confirmed vulnerabilities and two fixes.

8. 结论Conclusion

在这项工作中，我们提出了 PoisonedSkills，这是一个通过文档驱动的隐式有效负载执行 (DDIPE) 评估编码代理技能生态系统中的供应链防御的框架。对四个生产框架和五个模型的 1,070 种对抗技能进行的实验表明，没有经过测试的配置可以幸免：即使是最强大的防御也允许 2.3% 的直接执行。模型对齐和建筑护栏不对称地相互作用；移除护栏将弱对齐模型的执行率从 2.4% 提高到 27.1%，但几乎不影响强对齐模型。由于只有 1.6% 的有效载荷同时绕过所有测试模型，因此多模型验证是一种可行的对策。四个负责任地披露的生产漏洞证实这些发现在实验室环境之外也成立。当前的技能生态系统赋予代理技能与策划库相同的隐式信任，但我们的结果表明这一假设并不成立。有效的防御需要审核词汇模式之外的技能语义，确定个人技能级别的权限范围，并根据底层模型的对齐强度校准架构保护措施。In this work, we present PoisonedSkills, a framework that evaluates supply-chain defenses in coding agent skill ecosystems through Document-Driven Implicit Payload Execution (DDIPE). Experiments on 1,070 adversarial skills across four production frameworks and five models show that no tested configuration is immune: even the strongest defense allows 2.3% direct execution. Model alignment and architectural guardrails interact asymmetrically; removing guardrails amplifies the execution rate from 2.4% to 27.1% for weakly aligned models but barely affects strongly aligned ones. Because only 1.6% of payloads bypass all tested models simultaneously, multi-model verification is a viable countermeasure. Four responsibly disclosed production vulnerabilities confirm that these findings hold outside laboratory settings. Current skill ecosystems grant agent skills the same implicit trust as curated libraries, yet our results show this assumption does not hold. Effective defense requires auditing skill semantics beyond lexical patterns, scoping permissions at the individual skill level, and calibrating architectural safeguards to the underlying model’s alignment strength.

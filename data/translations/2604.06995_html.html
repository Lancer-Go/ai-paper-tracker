摘要Abstract

现有的图形用户界面 (GUI) 推理任务仍然具有挑战性，特别是在 UI 理解方面。当前的方法通常依赖于直接基于屏幕的决策，缺乏可解释性，并且忽视了对 UI 元素的全面理解，最终导致任务失败。为了增强对 UI 的理解和交互，我们提出了一种创新的 GUI 推理范式，称为Existing Graphical User Interface (GUI) reasoning tasks remain challenging, particularly in UI understanding. Current methods typically rely on direct screen-based decision-making, which lacks interpretability and overlooks a comprehensive understanding of UI elements, ultimately leading to task failure. To enhance the understanding and interaction with UIs, we propose an innovative GUI reasoning paradigm called用户界面在环UI-in-the-Loop（UI循环）。我们的方法将 GUI 推理任务视为循环任务(UILoop). Our approach treats the GUI reasoning task as a cyclic屏幕-UI 元素-操作Screen-UI elements-Action过程。通过使多模态大语言模型 (MLLM) 能够显式学习关键 UI 元素的本地化、语义功能和实际用法，UILoop 实现了精确的元素发现并执行可解释的推理。此外，我们还推出了更具挑战性的process. By enabling Multimodal Large Language Models (MLLMs) to explicitly learn the localization, semantic functions, and practical usage of key UI elements, UILoop achieves precise element discovery and performs interpretable reasoning. Furthermore, we introduce a more challenging用户界面理解UI Comprehension任务以具有三个评估指标的 UI 元素为中心。相应地，我们贡献了一个 26K 样本的基准（UI Compressive-Bench）来综合评估现有方法对 UI 元素的掌握程度。大量实验表明，UILoop 实现了最先进的 UI 理解性能，同时在 GUI 推理任务中产生了优异的结果。task centered on UI elements with three evaluation metrics. Correspondingly, we contribute a benchmark of 26K samples (UI Comprehension-Bench) to comprehensively evaluate existing methods’ mastery of UI elements. Extensive experiments demonstrate that UILoop achieves state-of-the-art UI understanding performance while yielding superior results in GUI reasoning tasks.

4 UI 在环框架UI-in-the-Loop Framework

如图所示。As shown in Fig.3，我们的 GUI 推理范式，, our GUI reasoning paradigm,用户界面在环UI-in-the-Loop(UILoop)，由两个主要阶段组成。在第一阶段，我们设计了一个用于UI理解的Scaling Data综合管道来构建UI理解基准，用于增强模型理解和利用UI元素的能力。在第二阶段，通过这个基准，我们提出UI元素驱动的强化微调，以解决现有模型“屏幕到动作缺失”的限制，并增强模型的UI理解能力。(UILoop), consists of two main stages. In the first stage, we design a Scaling Data for UI Comprehension synthesis pipeline to construct the UI Comprehension-Bench, serving to enhance the model’s ability to understand and utilize UI elements. In the second stage, with this benchmark, we propose UI Element-Driven Reinforcement Fine-Tuning to address the “Missing in the Screen-to-Action" limitation of existing models and strengthen the model’s UI comprehension capabilities.

4.2 UI 元素驱动的强化微调UI Element-Driven Reinforcement Fine-Tuning

为了解决“屏幕到动作缺失”的限制，我们利用强化学习在处理复杂的顺序决策方面的优势，并提出 UI 元素驱动的强化微调来增强模型的 UI 理解能力。具体来说，我们设计了位置奖励、语言化奖励和杠杆奖励，分别增强模型定位 UI 元素、理解其语义功能并有效利用它们的能力。首先，我们采用格式奖励来鼓励模型以预期格式输出。To address the “Missing in the Screen-to-Action" limitation, we leverage reinforcement learning’s strength in handling complex sequential decisions and propose UI Element-Driven Reinforcement Fine-Tuning to enhance the model’s UI Comprehension capability. Specifically, we design Location, Lingualization, and Leverage Rewards to respectively strengthen the model’s ability to locate UI elements, understand their semantic functions, and utilize them effectively.

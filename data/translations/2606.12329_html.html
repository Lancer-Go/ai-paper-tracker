9 结论Conclusion

每次会话结束时，人工智能编码代理都会丢失项目知识，这种失忆症的代价之一是 屡屡失败。我们提出了projectmem，一个本地优先、事件源、纯文本存储层 增加了一个确定性的行动前判断门——记忆不仅可以回答智能体，还可以 限制其下一步行动。通过保持内存不可变、人类可读、离线且与工具无关 通过 MCP，projectmem 为可审计的人工智能辅助软件开发提供了实用的基础。 该系统可作为开源软件使用。AI coding agents lose project knowledge every time a session ends, and one cost of this amnesia is repeated failure. We presented projectmem, a local-first, event-sourced, plain-text memory layer that adds a deterministic pre-action judgment gate—memory that does not merely answer the agent but can constrain its next action. By keeping memory immutable, human-legible, offline, and tool-agnostic over MCP, projectmem provides a practical substrate for auditable AI-assisted software development. The system is available as open-source software.

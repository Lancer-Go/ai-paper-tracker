摘要Abstract

组织越来越多地以结构化、机器可读的格式定义运营指标，以监控系统、流程和合规性。这些度量定义隐式地编码了领域知识，例如引用概念、属性和关系，这些知识通常扩展了形式本体中捕获的内容。然而，操作度量目录和本体知识之间的联系仍然是手动的、临时的和劳动密集型的。我们提出了 COntExt，一个上下文感知本体扩展框架，它以结构化度量定义作为输入，并建议如何利用这些度量的上下文将引用的概念和属性集成到现有本体中。该框架将扩展问题定义为三个子任务：父类预测、关系类型预测和数据属性分配。在跨越四个领域的七个本体中，我们评估每个任务的不同算法。我们的结果表明，度量衍生的上下文改进了关系类型预测和数据属性分配的本体上下文基线的建议。我们的工作表明，操作度量目录是本体扩展的实用且未充分利用的来源。 这项工作使组织能够以比手动工程低得多的成本维护本体。Organizations increasingly define operational metrics in structured, machine-readable formats to monitor systems, processes, and compliance. These metric definitions implicitly encode domain knowledge, such as referencing concepts, properties, and relationships, that often extends what is captured in formal ontologies. Yet the connection between operational metric catalogues and ontological knowledge remains manual, ad-hoc, and labour-intensive. We present COntExt, a framework for context-aware ontology extension that takes structured metric definitions as input and suggests how referenced concepts and properties should be integrated into an existing ontology, utilizing the context of these metrics. The framework defines the extension problem as three sub-tasks: parent class prediction, relation type prediction, and data property assignment. Across seven ontologies spanning four domains, we evaluate different algorithms for each task. Our results show that metric-derived context improves the suggestions over ontology-context baselines for relation type prediction and data property assignment. Our work demonstrates that operational metric catalogues are a practical and underexploited source for ontology extension. This work enables organizations to maintain their ontologies at a significantly lower cost than manual engineering.

5.2 局限性Limitations

RQ2 的单一本体。Single ontology for RQ2.度量上下文结果依赖于单个（本体、度量语料库）对、CertGraph 及其网络安全认证度量目录，因为我们的评估套件中没有其他本体附带具有可比结构的成对度量语料库。有必要在另一个域对上复制度量丰富模式，以证明其效果超出了 CertGraph 的特定 YAML 模式和散文风格。The metric-context findings rest on a single (ontology, metric corpus) pair, CertGraph and its cybersecurity-certification metric catalogue, because no other ontology in our evaluation suite is shipped with a paired metric corpus of comparable structure. Replicating the metric-enrichment pattern on another domain pair is necessary to argue that the effect generalizes beyond CertGraph’s particular YAML schema and prose style.

度量上下文未扩展到结构方法。Metric context not extended to structural methods.RQ2 比较仅使用文本模板评分器、MLM 和 ChildAgg 评估指标描述和评论。结构方法 TransE、BertConvE 不存在，因为它们使用标记化的三元组而不是自由格式的散文，并且本身不公开辅助文本的槽。 采用这种结构方法来摄取度量内容需要单独的研究工作。The RQ2 comparison evaluates metric description and comment with text-template scorers only, MLM and ChildAgg. The structural methods, TransE, BertConvE, are absent because they consume tokenized triples rather than free-form prose and do not natively expose a slot for auxiliary text. Adapting such structural methods to ingest metric content would require separate research efforts.

没有大型语言模型基线。No large-language-model baseline.由于我们的工作旨在有效地利用运营指标，因此尽管法学硕士的有效性众所周知，但我们并未将其纳入我们的算法选择中。 虽然之前的一些工作表明法学硕士在本体论一致性方面仍然落后，并且需要更多验证As our work aims to exploit operational metrics efficiently, we do not include LLMs in our algorithm choices despite their known effectiveness. While some previous work suggests that LLMs still lag behind for ontological consistency and they require more validation[Kollapally et al., 2025, Dong et al., 2024]，用指标驱动的背景来评估法学硕士仍然值得研究。, evaluating LLMs with metrics-driven context would still be worth investigating.

6 结论Conclusion

在本文中，我们介绍了一种与算法无关的上下文感知框架 COntExt，它利用操作指标和其他输入模式作为本体扩展任务的上下文。 我们的评估表明，操作指标为本体扩展任务提供了可行的上下文，证明了关系类型预测和数据属性分配任务相对本体驱动上下文的显着改进。 组织可以使用此框架来支持其本体维护，并能够利用相关上下文，例如指标目录和 KPI。 未来的工作将开发面向度量的本体扩展的定制算法，以及涉及领域专家的全面用户研究，以评估 COntExt 框架用于半自动本体扩展的效率和实用性。In this paper, we have introduced an algorithm-agnostic context-aware framework, COntExt, which leverages operational metrics and other input modalities as context for the ontology extension task. Our evaluation shows that operational metrics provide viable context to the ontology extension task, demonstrating a significant improvement over ontology-driven context for relation type prediction and data property assignment tasks. Organizations can use this framework to support their ontology maintenance, with the ability to harness relevant context, such as metrics catalogues and KPIs. Future work will develop tailored algorithms for metrics-oriented ontology extension as well as a comprehensive user study involving domain experts to evaluate the efficiency and utility of COntExt framework for semi-automated ontology extension.

一、 需求背景

目前项目首页采用全英文展示，对国内用户群体理解产品价值造成了一定障碍，急需提供中文化选项。同时，为了了解网站的受众规模和趋势发展，缺乏最基础的 PV/UV 流量统计，导致产品迭代效果无法被度量。

二、 需求目标

目标类型 描述 衡量指标 目标值
用户体验 提供中英文双语无缝切换功能，提升国内用户内容理解度 语言切换按钮的使用率 / 中文版页面停留时长 提供基础体验闭环
数据运营 引入基于第三方服务的访客统计并公开展示在首页 第三方数据分析面板正常产生数据 / 底部组件无报错展示 100%覆盖核心流量

三、 用户与使用场景

👤 用户旅程图 (User Journey Map)

阶段 用户触点 用户行为 痛点/情绪状态 产品机会点
1. 首次访问 进入首页 看到大量英文内容，试图理解工具功能 😣 "全是英文，看起来好累..." 自动根据系统语言适配中文，降低跳出率
2. 探索发现 右上角的语言组件 点击【简/EN】按钮，文本变为中文 🙂 "有中文就好懂多了！" 本地持久化储存，下次免切直接看中文
3. 对项目产生信赖 底部 Footer 区域 滚动到底部，看到“今日访客”并点开图表 😲 "哇，原来每天有这么多人用，产品不错" 通过 7天趋势折线图建立产品的权威感与人气氛围

四、 需求功能清单

🌐 1. 双语切换模块

  • 语言侦测：根据 navigator 语言默认设定初始态
  • 无感切换：页面核心文本映射，不刷页替换
  • 缓存持久化：优先读取 localStorage 中的偏好

📈 2. 探针与可视化

  • 底层收集：接入免费版 Vercel / Google Analytics
  • 基础摘要：页脚展示一行摘要文字
  • 交互图表：点击摘要展开呈现 Chart.js 绘制的 7 天访客折线图

五、该版本详细业务模块方案

注：右侧沙盒为高保真 HTML 原型真实加载展示，仅锁定当前关注的功能热区。

模块 01

顶栏右侧国际化语言开关 (i18n)

A. 核心主线逻辑图

flowchart TD A[用户访问首页加载] --> B{读取 localStorage?} B -->|存在 lang-pref| C[应用记忆语言] B -->|为空| D{读取 navigator 语言} D -->|包含 'zh'| E[置为中文 zh] D -->|非中文| F[置为英文 en] E --> C F --> C C --> G[挂载 UI 与字典] G --> H[等待点击] H --> |点击了另一个语言 Toggle| I[实时替换页面文本] I --> J[写入 localStorage]

B. 业务规则详细说明

  • 触发条件: 点击 Header 右侧的双语 Toggle Capsule。
  • 交互反馈: 对应的文字高亮，另一侧变灰；下方的标题、Hero 文案等含有 data-i18n-key 的 DOM 的 innerText 被立刻替换为对应的字典值。
  • 翻译范围约束: 目前首页仅包含纯文本（无复杂含字图片），字典结构为纯 JS Object Mapping。

模块 02

底部 Footer 流量抽屉面板

A. 展现控制树

flowchart TD A((首页到底部)) --> B[展现默认关闭态：今日访客 xxx 人] B --> C{用户点击操作栏?} C --> D[执行 Toggle 动作] D --> E{当前是否展开?} E -->|否| F[高度展开并执行 Chart.js 初始化渲染] E -->|是| G[图表收起，高度还原] F --> H[右侧小箭头自动旋转 180 度] G --> I[右侧小箭头还原 0 度]

B. 数据结构与异常说明

  • 默认摘要文本: 遵循「今日访客：XX人（点击查看趋势）」范式。XX 从 API 获取的当天 UV 替换。
  • 图表设定: X 轴为最近 7 天的 Date Label；Y 轴为 PV 或 UV 数量；采用平滑曲线(Curve)，并且下方使用带有透明度渐填色的面积图提升视觉吸引力。
  • 降级处理: 若统计后端返回错误（如 403超限 / 500网络出错），整个 Chart 区域替换为一张 Empty State 插画或隐藏折叠入口，不展示 0 数据产生的难看折弯。
Focus Mode Sandbox

六、 全局异常与安全边界处理

  • 本地环境不支持/禁用 LocalStorage: 对于开启了严格无痕模式或者低版本浏览器禁用缓存的用户，每次载入只依赖 Navigator 语言探测系统，放弃持久化写入。
  • 脚本注入风险 (XSS): 由于首页是纯静态页面，通过语言包 JSON Object 映射值到 innerText 必须防止 innerHTML 转义使用，以绝后患。
  • 隐私合规提示: 若未来统计颗粒度深化且追踪地区用户偏好情况，可能需要在底部追加一行非常细小的 Cookies 同意免责。本期仅仅使用最基础统计不涉及此项。

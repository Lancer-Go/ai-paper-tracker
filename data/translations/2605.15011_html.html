We formulate the task of automated technological roadmapping as extracting scientific contributions from scholarly articles and linking them to their prerequisites. We present the科学贡献图Scientific Contribution Graph，一个大规模的 AI/NLP 领域资源，包含从 23 万篇开放获取论文中提取的 200 万条详细科学贡献，并通过 1250 万条先决条件连接。我们进一步介绍了科学先决条件预测，这是一项科学发现任务，其中模型预测哪些现有技术可以实现未来的发现，并表明当代模型在这项任务上正在迅速改进，在使用时间过滤回测进行评估时达到 0.48 MAP。我们预计此类技术路线图资源将支持科学影响评估和自动化科学发现。, a large-scale AI/NLP-domain resource containing 2 million detailed scientific contributions extracted from 230k open-access papers and connected by 12.5 million prerequisite edges. 艾萨克·牛顿爵士有句名言：“如果说我看得更远，那是因为我站在巨人的肩膀上”。科学贡献很少是孤立发展的，而是建立在先前贡献的基础上，例如问题框架、实验方法和实证发现。了解这些先决关系对于研究科学进步以及自动化科学发现系统非常重要，该系统必须推断哪些现有功能可用于开发新功能Sir Isaac Newton famously wrote, “If I have seen further, it is by standing on the shoulders of giants”. Scientific contributions are rarely developed in isolation, but build upon prior contributions, such as problem framings, experimental methods, and empirical findings. Understanding these prerequisite relationships is important for studying scientific progress, and for automated scientific discovery systems that must reason about which existing capabilities can be used to develop new ones(e.g. Lu et al., 2024; Jansen et al., 2025b; Baek et al., 2025).

这项工作呈现了This work presents the科学贡献图Scientific Contribution Graph，用于技术路线图的大型资源，代表从 23 万篇源论文中提取的超过 200 万项科学贡献，以及 1200 万个定义每种技术如何基于先前贡献的先决关系。我们还将技术先决条件预测制定为下游评估任务，并凭经验证明，当使用时间过滤回测进行评估时，当前的语言模型越来越能够识别开发新目标技术所需的先驱技术，这表明在自动化科学发现中的近期应用。更广泛地说，我们预计, a large-scale resource for technological roadmapping that represents over 2 million scientific contributions extracted from 230k source papers, together with 12 million prerequisite relationships that define how each technology builds upon prior contributions. 开放获取文章：Open Access Articles:虽然本工作中描述的提取系统可用于组织有权访问的任何科学文章，但出于许可原因，官方版本仅包含开放获取文章。虽然这在当前发布的领域（自然语言处理和人工智能）中并不是一个重大限制，但由于该领域的大部分文献都是开放获取的，许多高影响力的领域（如生物学、材料科学等）都有很大一部分封闭获取的文献，限制了包括自动化科学发现在内的下游应用。虽然这种限制可以通过用户携带自己的许可文章来缓解，但向开放获取出版的转变将有助于更自由地分享公共资助的知识，并通过使在这些发现的基础上更容易、更容易地做出进一步贡献来实现进一步的社会效益。While the extraction system described in this work can be used on any scientific articles that an organization has access to, the official release includes only open access articles for licensing reasons. While this limitation is mitigated by users bringing their own licensed articles, the move towards open-access publishing will help share publicly funded knowledge more freely, and enable further societal benefit by making it easier and more accessible to build further contributions upon those discoveries.

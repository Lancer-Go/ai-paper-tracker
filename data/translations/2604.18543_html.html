3 爪状智能体的形式化环境Formalizing Environments for Claw-like Agents

Modern agent settings break this assumption: an agent that reads emails, calls APIs, and reasons over multi-turn conversation histories operates over a state space that is effectively infinite, driven by unbounded natural language context, tool outputs, and interaction history. 鲁棒性计算如下Robustness is computed asrecovered/total​_​errors\mathrm{recovered}/\mathrm{total\_errors}，如果在接下来的五个审核日志条目中成功重试相同的操作，则认为错误已恢复。五次进入窗口是一种设计选择，它奖励及时恢复，而不惩罚那些将重试与其他操作交织在一起的代理。如果运行期间没有注入错误（由于随机采样），稳健性默认为 1.0。, where an error is considered recovered if the same action was successfully retried within the next five audit log entries.

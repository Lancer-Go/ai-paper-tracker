1 简介1 Introduction

幻灯片演示是研究、商业、政策和教育领域交流信息的常用媒介。有效的幻灯片是为目标受众量身定制的选择性信息工件，而不仅仅是缩短的源文档。对于同一篇研究论文，专家期望得到证据、假设和消解；学习者需要核心思想和例子；决策者关注的是结论和行动。因此，幻灯片的生成从根本上来说是受观众限制的。Slide presentations are a common medium for communicating information in research, business, policy, and education. An effective slide deck is a selective information artifact tailored to the target audience, more than a shortened source document. For the same research paper, a specialist expects proofs, assumptions, and ablations; a learner needs the core idea and examples; and a decision maker focuses on conclusions and actions. Thus, slide generation is fundamentally audience-conditioned.

最近的自动幻灯片生成系统已经从早期的布局感知方法 [1, 2] 迅速发展到包含规划、迭代编辑和检索增强的代理框架 [3,4,5,6,7]。其他最近的进展还探索了使用话语树进行叙事重建[8]和教育清晰度的教学优化[9]。检索增强和偏好引导系统进一步提高了生成质量[7]。与此同时，引入了 PPTEval [3]、PresentBench [10]、SlidesGen-Bench [11]、PPTArena [12] 和 PPTBench [13] 等基准来评估布局、设计和多模式编辑等维度的生成质量。Recent automated slide generation systems have evolved rapidly from early layout-aware methods [1, 2] to agentic frameworks that incorporate planning, iterative editing, and retrieval augmentation [3, 4, 5, 6, 7]. Other recent advances have also explored narrative reconstruction using discourse trees [8] and pedagogical optimization for educational clarity [9]. Retrieval-augmented and preference-guided systems further improve generation quality [7]. In parallel, benchmarks such as PPTEval [3], PresentBench [10], SlidesGen-Bench [11], PPTArena [12], and PPTBench [13] have been introduced to evaluate generation quality across dimensions like layout, design, and multimodal editing.

A.3 提示模板A.3 Prompt Templates

我们提供了下面的基准测试管道中使用的核心提示模板。完整的提示（包括所有配置详细信息）可在我们发布的代码存储库中找到。We provide the core prompt templates used in the benchmark pipeline below. The full prompts, which include all configuration details, are available in our released code repository.

与受众无关的探针生成。Audience-Agnostic Probe Generation.

任务：Task:从提供的文档生成源接地探头。不针对任何特定受众。Generate source-grounded probes from the provided document. Do not target any specific audience.

规则：Rules:1. 每个调查都必须仅使用源文件来回答。 2. 提供问题、预期答案以及来源中的证据范围。 3. 指定深度级别：1（背景/动机）、2（主要方法/结果）、3（技术细节/消融）或 4（实现细节/边缘情况）。 4. 当来源包含相关内容时，覆盖所有深度级别。 5. 不要提出只能通过引文或参考文献列表才能回答的问题。1. Every probe must be answerable using only the source document. 2. Provide the question, expected answer, and the evidence span in the source. 3. Assign a depth level: 1 (context/motivation), 2 (main method/results), 3 (technical details/ablations), or 4 (implementation details/edge cases). 4. Cover all depth levels when the source contains relevant content. 5. Do not ask questions that can only be answered from citations or the reference list.

效用加权。Utility Weighting.

任务：Task:给定源探测、受众概况和演示场景，分配效用权重。Given a source probe, an audience profile, and a presentation scene, assign a utility weight.

评分细则：Rubric:1.0：必不可少。如果没有这些信息，观众就无法实现他们的目标。 0.6：重要。这些信息对观众有很大帮助。 0.3：有用的背景。很高兴知道但不是必需的。 0.0：不相关。此信息对受众没有帮助。1.0: Essential. The audience cannot achieve their goal without this information. 0.6: Important. This information significantly helps the audience. 0.3: Useful background. 幻灯片应答性评估。Slide Answerability Evaluation.

任务：Task:仅使用所提供幻灯片的可见内容来回答探究问题。如果在幻灯片中找不到答案，请回答“未找到”。找到答案后，引用包含该答案的特定幻灯片和内容元素。Using only the visible content of the provided slides, answer the probe question. If the answer cannot be found in the slides, respond with “not found.” When an answer is found, cite the specific slide and content element that contains it.

答案将与预期答案和来源证据进行比较。与来源证据相矛盾的答案不会得到认可。The answer will be compared against the expected answer and source evidence. Answers that contradict the source evidence do not receive credit.

声明级别的正确性。Claim-level Correctness.

索赔提取任务：Claim extraction task:从可见的幻灯片文本中提取原子的、可检查的声明。仅保留可以根据源文档进行验证的声明，分配重要性级别，并忽略装饰文本、章节标题和通用演示语言。Extract atomic, checkable claims from the visible slide text. Keep only claims that can be verified against the source document, assign an importance level, and ignore decorative text, section titles, and generic presentation language.

索赔验证任务：Claim verification task:给定一批提取的主张和检索到的源证据，将每个主张标记为支持、弱支持、不支持、不可验证或矛盾。最终的正确性得分是这些标签的重要性加权聚合。Given a batch of extracted claims and retrieved source evidence, label each claim as supported, weakly supported, unsupported, not verifiable, or contradicted. The final Correctness score is an importance-weighted aggregation of these labels.

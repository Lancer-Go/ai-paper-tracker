让寄存器发挥作用：视觉 Transformer 中用于令牌修剪的任务寄存器Putting Registers to Work: Task Registers for Token Pruning in Vision Transformers

Hongsen Cao    Mona Jaber    Shanxin Yuan    Ahmed Sayed
摘要Abstract

令牌修剪策略通常是为单个识别管道设计的，但预训练的 Vision Transformer 可以在具有不同空间需求的任务中重复使用。我们询问剪枝策略的哪些部分跨图像分类、语义分割和对象检测进行转移。对于每个管道，受控探针冻结无修剪检查点，并一次在一个合格层上应用一系列无参数缩减标准，而无需重新训练。这些探针揭示了三个差异：分割和检测对标准的排序不同，分类对最早层中基于注意力的修剪特别敏感，以及密集任务更喜欢相反的恢复端点。这些发现激发了任务自适应修剪（TAP）。现有的寄存器令牌用作功能工件的与任务无关的存储。相反，TAP 为每个任务引入一个任务寄存器，并且仅激活当前的任务寄存器。其不断发展的状态对令牌进行排名，在深度上分配精确的删除预算，并设置密集特征的恢复规模。最终保留率为Token-pruning policies are usually designed for a single recognition pipeline, but pretrained Vision Transformers are reused across tasks with different spatial demands. We ask which parts of a pruning policy transfer across image classification, semantic segmentation, and object detection. For each pipeline, controlled probes freeze the no-pruning checkpoint and apply a series of parameter-free reduction criteria at one eligible layer at a time without retraining. The probes reveal three differences: segmentation and detection rank the criteria differently, classification is especially sensitive to attention-based pruning in the earliest layers, and the dense tasks prefer opposite recovery endpoints. These findings motivate Task-Adaptive Pruning (TAP). Existing register tokens serve as task-agnostic storage for feature artifacts. TAP instead introduces one task register per task and activates only the current one. Its evolving state ranks tokens, distributes an exact removal budget over depth, and sets the recovery scale for dense features. 简介Introduction

Vision Transformer (ViT) 中的自注意力随着令牌数量呈二次方扩展Self-attention in a Vision Transformer (ViT) scales quadratically with the number of tokens(9; 28)。代币修剪通过在后续区块之前删除排名较低的补丁代币来降低成本. Token pruning lowers this cost by removing low-ranked patch tokens before later blocks(25; 18; 33)。大多数修剪标准是为图像分类而开发的，但预训练的 ViT 主干现在通常适用于分割和检测. Most pruning criteria are developed for image classification, yet pretrained ViT backbones are now routinely adapted to segmentation and detection(17; 31)。在这些管道中应用相同的修剪策略假设令牌重要性在任务之间转移。当这个假设失败时，等量的代币预算不需要保留等量的任务相关信息。现有方法使用固定的、学习的或特定于任务的选择器. Applying the same pruning policy across these pipelines assumes that token importance transfers across tasks. When this assumption fails, equal token budgets need not preserve equal amounts of task-relevant information. Existing methods use fixed, learned, or task-specific selectors(25; 18; 3; 2; 5)，但通常将修剪视为单一策略。然而，在不同的任务中，至少三个选择可能会有所不同：保留哪些令牌、如何在深度上分配全局预算以及如何表示密集预测的删除位置。这些决定往往相互交织，因此很难看出实际转移了什么。, but generally treat pruning as a single policy. Across tasks, however, at least three choices may vary: which tokens to retain, how to distribute a global budget over depth, and how to represent removed positions for dense prediction. These decisions are often intertwined, making it difficult to see what actually transfers.

总之，这些发现激发了我们的任务自适应修剪（TAP），它将寄存器用作修剪控制器。现有的寄存器令牌吸收了特征伪影，但仍然与任务无关并且不控制修剪Together, these findings motivate our Task-Adaptive Pruning (TAP), which puts registers to work as pruning controllers. Existing register tokens absorb feature artifacts but remain task agnostic and do not control pruning(7)。相反，TAP 为每个任务引入一个初始任务寄存器，并在前向传递期间仅激活当前的任务寄存器。活跃寄存器与整个主干网中的图像标记一起发展。它的当前状态协调令牌选择、跨修剪层的精确全局移除预算的分布以及密集预测的恢复缩放。我们研究两种适应机制。 TAP-J 联合微调单独的骨干网并为每个任务注册，而 TAP-F 冻结共享骨干网并训练特定于任务的寄存器和低等级更新。我们的贡献有三方面：. TAP instead introduces one initial task register per task and activates only the current one during a forward pass. The active register evolves alongside the image tokens throughout the backbone. Its current state coordinates token selection, the distribution of an exact global removal budget across pruning layers, and recovery scaling for dense prediction. We study two adaptation regimes. TAP-J jointly fine-tunes a separate backbone and register for each task, while TAP-F freezes a shared backbone and trains a task-specific register together with low-rank updates. Our contributions are threefold:

  1. 1)

    我们开发了一个受控框架，冻结每个非剪枝管道并更改一个合格层的剪枝选择，以研究跨图像分类、语义分割和对象检测的 ViT 主干剪枝。探索表明，分割和检测对剪枝标准的排序不同，空间覆盖比早期分类层中的注意力更稳定，并且密集的管道有利于相反的恢复端点。We develop a controlled framework that freezes each no-pruning pipeline and changes one pruning choice at one eligible layer to study ViT backbone pruning across image classification, semantic segmentation, and object detection. The probes show that segmentation and detection rank pruning criteria differently, spatial coverage is more stable than attention in the early classification layers, and the dense pipelines favor opposite recovery endpoints.

  2. 2)

    我们引入任务寄存器作为稀疏计算的主动的、特定于任务的控制器，而不是用于特征工件的与任务无关的存储。只有当前任务的寄存器进入主干，其演变状态协调令牌选择、跨深度的精确预算分配以及密集恢复扩展。We introduce task registers as active, task-specific controllers of sparse computation rather than task-agnostic stores for feature artifacts. Only the current task’s register enters the backbone, and its evolving state coordinates token selection, exact budget allocation across depth, and dense-recovery scaling.

  3. 3)

    TAP 引入了任务条件修剪过程，将令牌删除和功能恢复视为统一操作，而不是仅仅依赖于令牌删除或骨干内合并。每个丢弃的令牌都与幸存的替身相匹配，并且任务寄存器仅在密集读出时缩放其存储的特征偏移量，从而将重构的特征排除在以后的编码器块之外。TAP introduces a task-conditioned pruning process that treats token removal and feature recovery as a unified operation, rather than relying solely on token removal or in-backbone merging. Each discarded token is matched to a surviving stand-in, and the task register scales its stored feature offset only at the dense readout, keeping reconstructed features out of later encoder blocks.

The active register evolves with the image features and conditions token selection, exact budget allocation, and recovery scaling. Each removed token is deterministically matched to the retained token with the highest key-space cosine similarity, and the register controls how much of the stored offset is restored. Token features remain image-dependent and can become task-specific through backbone fine-tuning in TAP-J or low-rank updates in TAP-F.

证据反对将代币减少视为单一可转让规则。随着 ViT 表示从局部结构转向更高级别的语义，令牌值会随着深度和读取主干的任务而变化。 TAP 使用不断演化的寄存器将这种内部状态转变为与任务相关的计算决策。The evidence argues against treating token reduction as a single transferable rule. As ViT representations move from local structure to higher-level semantics, token value changes with depth and with the task that reads the backbone. TAP uses the evolving register to turn this internal state into task-dependent computational decisions.

TAP-J 落后于 DiffRateTAP-J trails DiffRate by0.10.1分类上的要点。分类读取类令牌并跳过密集恢复，从而使 TAP 的三种机制之一未被使用。与分割掩模或检测框相比，其全局目标还提供较弱的空间指导。这些因素使得特定分类的费率表具有竞争力。point on classification. Classification reads a class token and skips dense recovery, leaving one of TAP’s three mechanisms unused. Its global objective also supplies weaker spatial guidance than segmentation masks or detection boxes. These factors leave a classification-specific rate schedule competitive.

这些结果表明更细粒度的任务自适应计算。分割可能需要跨更多层的广泛空间支持，而一旦出现对象级证据，检测可能会集中计算。深度估计可以保留几何形状，视频可以保留时间稳定的区域，语言条件视觉可以专注于提示相关的内容。分层策略可以捕获这些转换并协调修剪与中间特征读取。目前的设计固定了总保持率，需要特定于任务的训练，并从一个替身和一个较早的偏移重建每个移除的位置。未来的工作应该检查图像条件预算、多个替代、跨层传输以及将任务语义与实现差异分开的匹配管道。随着视觉主干的增长，我们的长期目标是建立一个统一的模型，以最少的特定于任务的存储来适应更多视觉任务的稀疏计算。These results point to finer-grained task-adaptive computation. Segmentation may need broad spatial support across more layers, while detection may concentrate computation once object-level evidence emerges. Depth estimation could preserve geometry, video could retain temporally stable regions, and language-conditioned vision could focus on prompt-relevant content. Layerwise policies may capture these transitions and coordinate pruning with intermediate feature reads. The present design fixes the total keep rate, requires task-specific training, and reconstructs each removed position from one stand-in and one earlier offset. Future work should examine image-conditioned budgets, multiple stand-ins, cross-layer transport, and matched pipelines that separate task semantics from implementation differences. As vision backbones grow, our longer-term goal is a unified model that adapts sparse computation across more visual tasks with minimal task-specific storage.

结论Conclusion

我们的初步实验表明，剪枝行为随着任务和深度的变化而变化，这促使我们提出任务自适应剪枝（TAP）。 TAP 不是依赖于针对一项视觉任务量身定制的修剪规则，而是将一个不断发展的任务寄存器用作在精确的全局预算下共享稀疏计算过程的控制器。这种简单而高效的设计在跨任务的预测性能和编码器吞吐量之间保持了良好的平衡，使得 TAP 特别适合通过共享骨干服务于多个任务的统一视觉系统。Our preliminary experiments show that pruning behavior changes with task and depth, which motivates us to propose Task-Adaptive Pruning (TAP). Rather than relying on a pruning rule tailored to one visual task, TAP puts an evolving task register to work as the controller of a shared sparse computation process under an exact global budget. This simple and efficient design maintains a favorable balance between predictive performance and encoder throughput across tasks, making TAP particularly well suited to unified vision systems that serve multiple tasks through a shared backbone.

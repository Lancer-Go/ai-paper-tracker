1 简介Introduction

图神经网络 (GNN) 是强大的机器学习工具，用于解决图数据集上的任务，例如社交网络Graph Neural Networks (GNNs) are powerful machine learning tools to solve tasks on graph datasets, such as social networks(Yanardag and Vishwanathan, 2015)和分子and molecules(Kazius et al., 2005; Schütt et al., 2018)。 已经提出了各种 GNN 模型. Various GNN models have been proposed(Wu et al., 2021a)，而其基本原理是 预测（例如，输入图的哪些节点特征或哪些部分（共同）对预测做出贡献）无法直接从模型中提取。因此，GNN 就像一个黑匣子，如果不进一步调查，它的预测很难理解。 为了应对这一挑战， 近年来出现了许多可解释性方法, while the rationale of prediction—for example, which node features or which parts of the input graph are (jointly) contributing to the prediction—cannot be directly extracted from the model. The GNN therefore acts as a black box and its prediction is hard to comprehend without further investigation. To address this challenge, many explainability methods emerged in recent years(Schnake et al., 2022; Ying et al., 2019), 一般可分为模型级方法和实例级方法, which can be generally categorized into model-level and instance-level methods(Yuan et al., 2020b)：模型级方法为不同的预测生成代表性图，而实例级方法则专注于单个预测并在相应的输入图中查找相关特征。: model-level methods generate representative graphs for different predictions, while instance-level methods focus on single predictions and find relevant features in the corresponding input graphs.

5 结论Conclusion

许多实际应用，例如化学、感染生物学、自然语言处理等，都体现了本质上高阶的复杂相关性。虽然深度学习模型可以利用这种结构来改进预测，但迄今为止，从学习模型中实际提取此类高阶信息仍然是一个挑战。Many practical applications such as chemistry, infection biology, NLP etc., embody complex correlations that are higher-order in nature. While deep learning models can exploit such structure for improving prediction, it has so far been a challenge to practically extract such higher-order information from a learned model.

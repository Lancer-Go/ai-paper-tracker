摘要Abstract

地理空间基础模型主要关注卫星图像等栅格数据，其中自监督学习已得到广泛研究。相反，矢量地理空间数据将世界表示为具有显式几何、语义和结构化空间关系（包括度量邻近度和拓扑关系）的离散地理实体。这些关系共同决定实体如何在空间内交互，但现有的表示学习方法仍然支离破碎，通常仅限于特定的几何类型或部分空间关系，限制了它们跨异构地理实体捕获统一空间上下文的能力。我们建议Geospatial foundation models have primarily focused on raster data such as satellite imagery, where self-supervised learning has been widely studied. Vector geospatial data instead represent the world as discrete geoentities with explicit geometry, semantics, and structured spatial relations, including metric proximity and topological relationships. These relations jointly determine how entities interact within space, yet existing representation learning methods remain fragmented, often restricted to specific geometry types or partial spatial relations, limiting their ability to capture unified spatial context across heterogeneous geoentities. We propose奈良NARA (N欧洲的euralA锚定条件的nchor-conditionedR兴高采烈-elation-A件表示学习），矢量地理实体的自监督框架。 NARA 通过在统一框架内联合建模语义、几何和空间关系来学习上下文相关的表示，并捕获超越邻近性的关系空间结构，从而在点、折线和多边形的异构地理实体上实现丰富的上下文表示。对建筑功能分类、交通速度预测和下一个兴趣点推荐的评估显示出相对于先前方法的一致改进，突出了矢量地理空间数据的统一关系建模的好处。ware representation learning), a self-supervised framework for vector geoentities. NARA learns context-dependent representations by jointly modeling semantics, geometry, and spatial relations within a unified framework and captures relational spatial structure beyond proximity alone, enabling rich contextualized representations across heterogeneous geoentities of points, polylines, and polygons. Evaluation on building function classification, traffic speed prediction, and next point-of-interest recommendation shows consistent improvements over prior methods, highlighting the benefit of unified relational modeling for vector geospatial data.

我们提出了 NARA，一个基于关系条件空间自相关的自我监督框架，其中地理实体之间的语义相似性由度量邻近度和拓扑关系共同控制。通过集成屏蔽地理实体语义建模、空间感知注意力监督和关系条件建模，NARA 可以学习捕获自适应、有意义的空间上下文的表示，而无需特定于任务的特征工程。在一系列不同的下游任务中，与特定于任务的基线相比，相同的预训练 NARA 实现了稳健的性能提升。 NARA 无需定制架构，即可为异构矢量地理空间表示学习提供统一的预训练框架。 Appdx 中提供了限制和更广泛的影响。We present NARA, a self-supervised framework grounded in relation-conditioned spatial autocorrelation, where semantic similarity among geoentities is governed jointly by metric proximity and topological relations. By integrating masked geoentity semantic modeling, spatial-aware attention supervision, and relation-conditioned modeling, NARA learns representations capturing adaptive, meaningful spatial context without task-specific feature engineering. Across a diverse set of downstream tasks, the same pretrained NARA achieves robust performance gains compared to task-specialized baselines. Without tailored architectures, NARA provides a unified pretraining framework for heterogeneous vector geospatial representation learning. Limitations and broader impacts are provided in Appdx.A.

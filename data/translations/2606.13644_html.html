摘要Abstract

几何形状对于视点而言是不变的，这使得任何图像集合都是单个 3D 状态的冗余编码。现有的前馈重建模型无法利用这一点：每个视图的方法会发出重叠的、未对齐的点图，这些点图随着输入计数线性增长，而全局潜在方法则致力于固定的低分辨率输出。我们引入 Surflo，它将可变数量的未摆位 RGB 视图压缩为Geometry is invariant to viewpoint, which makes any collection of images a redundant encoding of a single 3D state. Existing feed-forward reconstruction models fail to exploit this: per-view methods emit overlapping, unaligned pointmaps that grow linearly with input count, while global-latent methods commit to a fixed, low-resolution output. We introduce Surflo, which compresses a variable number of unposed RGB views intoKK潜在令牌（一个全局状态）并通过流匹配独立地将定向 3D 表面点从噪声传输到表面来解码定向 3D 表面点。这将输出从任何固定网格或代币预算中解放出来：在一次前向传递中，从几千到一百万个点的相同潜在产量。为了抑制独立每点解码固有的局部不一致，推理时间指导项通过在 ODE 积分期间注入光度梯度来关联附近的点。 Surflo 在表面指标上匹配或超越前馈基线，运行速度比需要数百个视图的基于优化的方法快一个数量级，并且是唯一将全局潜在与任意分辨率解码相结合的前馈方法。latent tokens—one global state—and decodes oriented 3D surface points by independently transporting them from noise onto the surface via flow matching. This frees the output from any fixed grid or token budget: the same latent yields from a few thousand to a million points in a single forward pass. To suppress the local inconsistencies inherent to independent per-point decoding, an inference-time guidance term correlates nearby points by injecting a photometric gradient during ODE integration. Surflo matches or surpasses feed-forward baselines on surface metrics, runs an order of magnitude faster than optimization-based methods that require hundreds of views, and is the only feed-forward approach to combine a global latent with arbitrary-resolution decoding.

1 简介Introduction

本着克莱因埃尔兰根计划的精神In the spirit of Klein’s Erlangen program[41]，3D 几何正是在观看变换下保持不变的。由此可见，场景的图像集合是其几何形状的冗余编码：相同的底层 3D 状态被重新投影到每个视图中，以相机为模。随着收集更多视图，原始像素数据线性增长，而几何内容则不然——附加视图仅用于解决歧义并完善共享的全局状态。适用于下游应用，例如用于机器人的 real2sim, 3D geometry is precisely what remains invariant under the viewing transformation. It follows that a collection of images of a scene is a redundant encoding of its geometry: the same underlying 3D state is re-projected into every view, modulo the camera. As more views are gathered, the raw pixel data grows linearly while the geometric content does not—additional views serve only to resolve ambiguities and refine a shared, global state. For downstream applications such as real2sim for robotics[4]和代理导航and agent navigation[79]，这个全局几何体就是目标；图像只是用来恢复它的工具。, it is this global geometry that is the target; the images are merely the instruments used to recover it.

这一观察结果具有直接的架构后果：如果许多视图编码一个几何图形，则正确的中间表示是单个全局状态，而不是每个视图或每个像素的状态。我们呈现This observation has a direct architectural consequence: if many views encode one geometry, the right intermediate representation is a single global state, not a per-view or per-pixel one. We present瑟弗洛Surflo，围绕这一原理构建的前馈模型。给定数量可变的未摆设 RGB 视图，Surflo 将它们压缩为 3D 场景的单个紧凑且一致的全局表示。可以通过采样任意数量的定向表面点（每个场景从几千到一百万个）来从该全局状态查询底层几何图形，而不是绑定到固定的空间网格或严格的令牌预算。生成的输出是全局的、跨视图一致的，并且可以轻松转换为网格。, a feed-forward model built around this principle. Given a variable number of unposed RGB views, Surflo compresses them into a single compact and consistent global representation of the 3D scene. Rather than being bound to a fixed spatial grid or a rigid token budget, the underlying geometry can be queried from this global state by sampling an arbitrary number of oriented surface points—from a few thousand to a million per scene. The resulting output is global, consistent across views, and readily converted into a mesh.

5 结论Conclusion

我们提出了 Surflo，一种前馈 3D 重建模型，它将任意数量的未摆设 RGB 视图压缩为单个固定大小的潜在视图，并通过流匹配从该潜在视图中解码任意数量的定向表面点。We presented Surflo, a feed-forward 3D reconstruction model that compresses an arbitrary number of unposed RGB views into a single fixed-size latent, and decodes an arbitrary number of oriented surface points from that latent through flow matching inℝ3×𝕊2{\mathds{R}}^{3}\times\mathbb{S}^{2}。解码器中的每点独立性使模型既灵活又可扩展：相同的共享潜在支持粗略的全局预览以及百万点密集表面。为了补偿独立点之间缺乏显式表面耦合，我们提出了一种光度引导方案，将可微渲染损失的梯度注入 ODE，关联附近的点并将输出与输入图像对齐。作为辅助贡献，我们构建并将发布 DL3DV 的网格版本. Per-point independence in the decoder makes the model both flexible and scalable: the same shared latent supports a coarse global preview as well as million-point dense surfaces. To compensate for the lack of explicit surface coupling between independent points, we proposed a photometric guidance scheme that injects the gradient of a differentiable rendering loss into the ODE, correlating nearby points and aligning the output with the input images. As an auxiliary contribution, we built and will release a meshed version of DL3DV[46]，包括, including∼\sim10.5K 场景增强了防水表面和10.5K scenes augmented with watertight surfaces and10710^{7}每个导向点。该数据集使得大规模训练 Surflo 成为可能，我们希望它能够支持未来的场景级表面学习。在少视图 3D 重建基准上，Surflo 在标准表面指标上的表现优于强基线，同时也是唯一具有固定大小潜在解码和任意分辨率解码组合的前馈模型。oriented points each. This dataset made it possible to train Surflo at scale, and we hope it will support future scene-level surface learning. On few-view 3D reconstruction benchmarks, Surflo outperforms strong baselines on standard surface metrics while being the only feed-forward model with this combination of fixed-size latent and arbitrary-resolution decoding.

局限性。Limitations.Surflo 继承了 VGGT 的故障模式：当主干网提供较差的点图（视图很少或极端基线）时，噪声点图源分布和 VGGT 补丁标记化可能不可靠，从而损害解码器的恢复能力。光度指导有帮助，但不是免费的：面向渲染的高斯增加了推理成本，尽管在标准分辨率的单个 GPU 上推理时间仍然很小。 我们的监督来自高斯包裹Surflo inherits VGGT’s failure modes: when the backbone provides poor pointmaps (very few views or extreme baselines), the noisy-pointmap source distribution and VGGT patch tokenization can be unreliable, hurting the decoder’s ability to recover. Photometric guidance helps but is not free: rendering oriented Gaussians adds inference cost, though inference time remains small on a single GPU for standard resolutions. Our supervision comes from Gaussian Wrapping[20]表面，其本身在透明且无纹理的结构上是不完美的；我们相信，随着更密集、更清晰的地面实况管道和更大的数据集的出现，Surflo 将会得到改进。最后，当前模型只代表几何形状而不是外观；下一步自然是扩展解码器以预测与视图相关的辐射亮度。surfaces, which are themselves imperfect on transparent and textureless structures; we believe Surflo will improve as denser and cleaner ground-truth pipelines and larger datasets become available. Finally, the current model represents geometry but not appearance; extending the decoder to also predict view-dependent radiance would be a natural next step.

使用大型语言模型的单事实数据融合和多事实数据融合Single and Multi Truth Data Fusion using Large Language Models

Hira Beril Kucuk    Norman W Paton    Jiaoyan Chen    Zhenyu Wu
摘要Abstract

数据融合，也称为真相发现，是一个数据集成问题，旨在当存在来自多个来源的潜在冲突值时，确定对象的每个属性的正确值或值集。数据融合任务主要分为两大类：单真值场景（每个属性只有一个正确值）和多真值场景（多个值可以同时有效）。 本文研究了大型语言模型 (LLM) 在表格数据的数据融合任务中的使用。包括单真值和多真值场景在内的各种提示策略都经过实证研究。在三个不同的基准数据集上评估域相关、域无关、零样本和单样本提示。实验结果表明，基于 LLM 的方法在所有数据集上均优于传统的无监督真相发现方法，例如 DART 和 LTM。本研究的代码库已在 GitHub 上公开Data fusion, also known as truth discovery, is a data integration problem that aims to determine the correct value or set of values for each attribute of an object when presented with potentially conflicting values from multiple sources. Data fusion tasks belong to two main categories: single-truth scenarios, where each attribute has only one correct value, and multi-truth scenarios, where multiple values can be valid simultaneously. This paper investigates the use of Large Language Models (LLMs) in data fusion tasks for tabular data. Various prompting strategies, encompassing both single-truth and multi-truth scenarios, are investigated empirically. Domain-dependent, domain-independent, zero-shot and one-shot prompts are evaluated on three different benchmark datasets. Experimental results demonstrate that LLM-based approaches outperform traditional unsupervised truth discovery methods, such as DART and LTM, across all datasets. The codebase of this study has been made publicly available on GitHub111https://github.com/hiraberil/LLM-DataFusion.

1 简介Introduction

近年来，生成数据的数量、种类和速度都在迅速增加。这种增长不仅使得存储数据，而且获取有意义且可靠的信息成为一个重要的研究问题。在此背景下，数据集成成为一个突出的研究领域。数据集成可以分为两个主要级别，即模式级集成和实例级集成In recent years, the volume, variety and velocity of generated data has been rapidly increasing. This growth has made not only storing data but also obtaining meaningful and reliable information a significant research problem. In this context, data integration has become a prominent research area. Data integration can be characterised as including two main levels namely schema-level integration and instance-level integration[15][17]。 模式级集成作为数据集成的初始阶段，在结构和语义上对齐不同来源的模式，并创建一个通用的全局模式；然而，现阶段可能无法完全解决底层数据记录的不一致问题。实例级数据集成旨在集成来自不同数据源的实际数据记录。此阶段的主要目标是识别代表相同现实世界实体但以不同格式、不完整或不一致记录的记录，并将它们合并到单个一致的表示中。. Schema-level integration, as the initial stage of data integration, structurally and semantically aligns schemas from different sources and creates a common global schema; however, inconsistencies in the underlying data records may not be fully resolved at this stage. Instance-level data integration aims to integrate actual data records from different data sources. The primary goal of this stage is to identify records that represents the same real-world entity but have been recorded in different formats, incompletely, or inconsistently, and to merge them under a single, consistent representation.

实例级别的数据集成通常涉及格式转换、实体解析和数据融合的步骤Data integration at the instance level typically involves the steps of format transformation, entity resolution and data fusion[15][20]。 在按顺序由这三个步骤组成的方法中，首先对记录进行格式标准化，然后识别代表同一现实世界实体的记录，最后将它们合并以创建单个一致的记录. In an approach composed of these three steps in order, records are first standardised in format, then records representing the same real-world entity are identified, and finally, they are merged to create a single, consistent record[1][20]。 考虑以下示例：两个不同的来源将一本书的 ISBN 报告为“. Consider the following example: two different sources report the ISBN of a book as “国际标准书号 9780547928227ISBN 9780547928227” 和 “” and “978-0547928227”。 格式转换可以使用格式“”. Format transformation may represent both using the format “9780547928227”，实体解析会将包含等效 ISBN 的不同记录分组为代表同一本书，数据融合将书籍记录合并为单个表示，如图所示”, entity resolution will group different records containing equivalent ISBNs as representing the same book, and data fusion merges the book records into a single representation, as illustrated in Figure1.

The above data integration steps may output a record with all the valid genre values “奇幻、冒险、儿童文学Fantasy, Adventure, Children’s literature”，如图所示”, as illustrated in Figure1.

数据融合方法面临许多挑战，特别是在多真场景中Data fusion methods face a number of challenges, particularly in multi-truth scenarios[1, 21]。现有方法的很大一部分假设属性提供单个真值，因此不足以对可能存在多个真值的情况进行建模. A significant portion of existing methods make an assumption that attributes provide a single true value, and are therefore inadequate for modeling situations where multiple true values can exist[22]。 虽然当前的无监督方法使用所提供的数据中的证据提供了部分解决方案，但它们大多基于固定的假设，并且可能无法充分考虑上下文敏感的语义差异。此外，以不同形式（例如“John Ronald Reuel Tolkien”和“J.R.R. Tolkien”）表示同一现实世界实体需要规范化和语义匹配，这是大多数传统方法中未明确解决的过程。 法学硕士能够用自然语言建模语义关系并进行上下文推断. While current unsupervised methods offer partial solutions using evidence from the data provided, they are mostly based on fixed assumptions and may fail to adequately account for context-sensitive semantic differences. Furthermore, the representation of the same real-world entity in different forms (e.g., “John Ronald Reuel Tolkien” and “J.R.R. Tolkien”) requires normalisation and semantic matching, a process not explicitly addressed in most traditional methods. LLMs are capable of modeling semantic relationships in natural language and making contextual inferences[23]。这些功能在解决隐式标准化、表达多样性以及数据融合中遇到的矛盾信息的解释等挑战方面提供了潜在的优势。特别是，诸如在语义层面上比较不同来源的异构值以及同时评估单真值和多真值等任务可以通过法学硕士基于上下文的推理功能更灵活地处理。在本研究中，数据融合问题被作为法学硕士支持的数据集成过程来解决。. These capabilities offer potential advantages in addressing challenges such as implicit normalisation, expression diversity, and the interpretation of contradictory information encountered in data fusion. In particular, tasks such as comparing heterogeneous values from different sources at the semantic level and evaluating both single and multi-truth values together can be handled more flexibly with the context-based inference capabilities of LLMs. In this study, the data fusion problem is addressed as an LLM-supported data integration process.

It aims to reconcile potentially conflicting records from different sources, which are often obtained after schema matching, entity resolution, and format transformation, to achieve a more consistent and reliable record. Bleiholder 和 Naumann 将处理冲突价值观的策略分为冲突忽略、冲突避免和冲突解决方法Bleiholder and Naumann classify strategies for handling conflicting values into conflict-ignoring, conflict-avoiding and conflict-resolving approaches[1]。 然而，在实践中，大多数研究注意力都集中在冲突解决方法上，特别是真相发现，其目的是通过联合估计来源可靠性和价值正确性，从多个相互冲突的观察中推断出最可信的价值. In practice, however, most research attention has focused on conflict-resolving methods, particularly truth discovery, which aims to infer the most credible value from multiple conflicting observations by jointly estimating source reliability and value correctness[5]。正如最近的调查所总结的，真相发现方法的通常特征在于它们如何对观察、源依赖性和学习设置进行建模，并且许多无监督方法遵循投票式聚合方案或迭代/概率估计过程. As summarised in more recent surveys, truth discovery methods are commonly characterised by how they model observations, source dependencies, and learning settings, and many unsupervised methods follow either a voting-style aggregation scheme or an iterative/probabilistic estimation process[11, 21]。多数投票是最直接的方法之一，它选择最多来源支持的值。更先进的真相发现方法通过联合建模因素（例如源可靠性和源依赖性）超越了这一策略。 许多此类方法遵循迭代估计范式，并在最近的调查中进行了详细的分类和比较（例如，. Majority voting is one of the most straightforward approaches, which selects the value supported by the largest number of sources. More advanced truth discovery methods go beyond this strategy by jointly modelling factors such as source reliability and source dependence. Many such methods follow an iterative estimation paradigm, with detailed taxonomies and comparisons in recent surveys (e.g.,[12, 21]）补充个别提案的描述（例如，) complementing descriptions of individual proposals (e.g.,[3, 4, 11]).

The Latent Truth Model (LTM) adopts a probabilistic graphical model-based approach, treating the truth of each claimed value as a latent variable and jointly modelling it with source reliability[28]。它支持多真值设置。 领域感知真相发现 (DART) 通过考虑不同领域来源的专业知识来扩展经典贝叶斯方法. It supports the multi-truth setting. Domain-Aware Truth Discovery (DART) extends classical bayesian approaches by considering expertise of sources in different domains[13]。传统方法通常为源分配单个可靠性分数，而 DART 为每个源计算基于域的可靠性分数。这包含了这样一个事实：来源可能在一个领域是可靠的，但在另一个领域却很弱。这些分数用于计算值的准确性概率。. While traditional methods generally assign a single reliability score to a source, DART calculates domain-based reliability scores for each source. This incorporates the fact that a source may be reliable in one domain but weak in another. These scores are used to calculate the probability of accuracy of the values.

3 LLM提示数据融合LLM Prompts for Data Fusion

本研究中用于数据融合的LLM提示根据是领域独立（DI）还是领域依赖（DD），以及是针对单真值（ST）还是多真值（MT）可以分为四种类型。这些提示类别表示为 DI-ST、DI-MT、DD-ST 和 DD-MT。The LLM prompts used in this study for data fusion can be classified into four types according to whether they are domain-independent (DI) or domain-dependent (DD), and whether they are for single-truth (ST) or multi-truth (MT). These prompt categories are denoted as DI-ST, DI-MT, DD-ST and DD-MT.

DI 提示无需修改即可应用于任何域，无论要组合的数据类型如何；使用实体、来源和值等抽象术语。另一方面，DD提示直接包含与目标属性相关的术语（作者、导演、出发时间等），并且需要针对不同的域进行修改。 ST 提示的结构适用于某一属性仅存在一个真实值（例如，出发时间或登机口）的场景，而 MT 提示的结构适用于可能有多个有效值的场景（例如，作者或导演）。DI prompts can be applied to any domain without modification, regardless of the type of data to be combined; abstract terms such as entity, source and value are used. DD prompts, on the other hand, directly include terms associated with the target attribute (author, director, departure time, etc.) and need to be revised for a different domain. ST prompts are structured for scenarios where only one true value exists for an attribute (e.g., departure time or gate), while MT prompts are structured for scenarios where multiple valid values are possible (e.g., authors or directors).

4.1 实验装置Experimental Setup

基线。Baselines.

以下真相发现方法用作基线。 (1)The following truth discovery methods are used as the baselines. (1)多数票 (MV)Majority Vote (MV)在每个属性的所有输入值中选择频率最高的值。这是一种不考虑源可靠性但计算量最少的简单方法。根据chooses the value with the highest frequency among all the input values for each attribute.     与基线方法相比，基于 DD LLM 的方法始终能产生更平衡的精确度/召回率结果和更高的 F1 分数。DD LLM-based approaches consistently produce more balanced precision/recall results and higher F1 scores than the baseline methods.

  2. 2.

    在 Book 数据集中 8 个案例中的 8 个、Movie 数据集中 8 个案例中的 8 个、以及 Flights 数据集中 8 个案例中的 6 个中，DD 提示提供了比相应 DI 提示更好的 F1 分数，因此我们可以说提示中的特定于领域的措辞对于数据融合很有用。我们注意到，在许多情况下，所使用的特定领域措辞应该能够生成，而不是手工制作。DD prompts provided better F1 scores than the corresponding DI prompts in 8 out of 8 cases in the Book dataset, 8 out of 8 cases in the Movie dataset, and 6 out of 8 cases in the Flights dataset, so we can say that domain-specific wording in prompts is useful for data fusion. We note that the domain-specific wording used should be able to be generated, rather than hand-crafted, in many cases.

  3. 3.

    在书籍的 8 个案例中有 8 个、电影的 8 个案例中有 2 个、航班的 8 个案例中有 5 个案例中，1 次提示的 F1 分数优于 0 次提示，因此示例的影响在整个数据集中不一致。The 1-shot prompts outperformed the 0-shot prompts in F1 score in 8 out of 8 cases for Books, 2 out of 8 cases for Movies, and 5 out of 8 cases for Flights, so the impact of examples is inconsistent across the datasets.

  4. 4.

    与没有约束相比，C1 约束在 Book 数据集的 4 个案例中为 0 个，在 Movie 数据集的 4 个案例中为 0 个，在 Flight 数据集的 4 个案例中为 2 个，与没有约束相比提高了 F1 分数。 与没有约束相比，C2 约束在 Book 数据集的 4 个案例中提高了 2 个，在 Movie 数据集的 4 个案例中提高了 2 个，在 Flight 数据集的 4 个案例中提高了 0 个。 与没有约束相比，C1+C2 约束在 Book 数据集的 4 个案例中有 2 个、Movie 数据集的 4 个案例中有 3 个、以及 Flight 数据集的 4 个案例中有 1 个提高了 F1 分数。因此，这些实验并没有提供令人信服的证据来包含这些约束。The C1 constraint improved the F1 score compared with no constraint in 0 out of 4 cases for the Book dataset, 0 out of 4 cases for the Movie dataset, and 2 out of 4 cases for the Flight dataset. The C2 constraint improved the F1 score compared with no constraint in 2 out of 4 cases for the Book dataset, 2 out of 4 cases for the Movie dataset, and 0 out of 4 cases for the Flight dataset. The C1+C2 constraints improved the F1 score compared with no constraint in 2 out of 4 cases for the Book dataset, 3 out of 4 cases for the Movie dataset, and 1 out of 4 cases for the Flight dataset. As such, the experiments do not provide compelling evidence for including the constraints.

  5. 5.

    混淆航班数据集中的航班 ID 会导致性能小幅但持续下降。在 16 个案例中的 15 个案例中，LLM 提示使用混淆的航班 ID 提供了比最佳表现基线更高的 F1 分数。Obfuscating the Flight ID in the Flights dataset led to a small but consistent reduction in performance. In 15 out of 16 cases, the LLM prompts with the obfuscated Flight ID provided a higher F1 score than the best performing baseline.

5 结论Conclusions

大型语言模型对许多数据密集型任务产生了重大影响。据我们所知，本文为基于提示的数据融合方法提供了第一个广泛的建议和评估。Large language models are having a substantial impact on many data intensive tasks. To the best of our knowledge, this paper provides the first wide-ranging proposal for, and evaluation of, prompt-based approaches to data fusion.

  1. 1.

    探索使用 LLM 进行数据融合，包括零样本、 针对单真值和多真值设置的单次、域独立和域相关提示An exploration of the use of LLMs for data fusion that includes zero-shot, single-shot, domain-independent and domain-dependent prompts for both single-truth and multi-truth settings。已经针对单真值和多真值设置提出了单独的提示，并且在这种设置中，0-shot 和 1-shot、域相关和域无关的变体都已导出。还研究了指导法学硕士如何执行数据融合的附加约束。. The addition of constraints to guide the LLM in how to perform data fusion has also been investigated.

  2. 2.

    在各种基准情景下的实证评估与比较 四种经典的数据融合方法An empirical evaluation in various benchmark scenarios in comparison with four classic data fusion methods。 (1) 中的各种提示已与 3 个基准数据集上的 4 个（也是无监督的）基线提案进行了比较。基线包括多数投票以及在 SIGMOD 和 PVLDB 上发布的三项备受瞩目的技术，这些技术在 Google Scholar 中被引用次数远远超过 1000 次。基于领域的 LLM 提案始终优于所有数据集上的所有基线。.   3. 3.

    LLM支持的数据融合的优点、局限性和可靠性分析An analysis of the strengths, limitations and reliability of LLM-supported data fusion。广泛的评估为数据融合的即时设计提供了各种见解。在提示中包含特定领域的术语有时会带来显着的好处，但提供示例和约束带来的好处越来越少。在一项旨在减少法学硕士利用背景知识的程度的实验中，基于法学硕士的方法仍然优于基线。. The wide-ranging evaluation provides various insights into prompt design for data fusion. Including domain-specific terminology in prompts sometimes provided significant benefits, but the provision of examples and constraints provided fewer and less consistent benefits. In an experiment designed to reduce the extent to which background knowledge could be exploited by the LLMs, LLM-based approaches still outperformed the baselines.

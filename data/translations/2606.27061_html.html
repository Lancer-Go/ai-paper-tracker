如何用真实值来评估聚类？How to evaluate clustering with ground truth?

帕西弗兰蒂Pasi Fränti东芬兰大学计算机学院School of Computing University of Eastern Finland芬兰约恩苏Joensuu, Finland

摘要：Abstract:当真实情况可用时，外部索引可用于聚类评估。我们回顾了最常见的外部有效性指标，重点关注基于集合匹配的度量。我们推荐External indexes can be used for cluster evaluation when ground truth is available. We review the most common external validity indexes focusing on set-matching-based measures. We recommend质心指数centroid index（CI），因为它是一种直观的集群级度量，具有可解释的结果。如果我们需要更精细的、点级的衡量标准，还有更多的选择。(CI), because it is an intuitive cluster-level measure with an explainable result. If we need a more fine-tuned, point-level measure, there are more choices.配对指数Pair-set index(PSI) 提供不受簇大小影响的标准化分数。如果所有点都同等重要，那么(PSI) provides a normalized score which is not biased by cluster sizes. If all points should matter equally, then聚类准确率clustering accuracy(ACC) 或任何其他设置匹配措施都是合适的。(ACC) or any other set-matching measure is suitable.

In clustering, however, class labels do not exist. The cluster index is an arbitrary number without any correspondence to the ground truth labels. The number of clusters can also differ from that of ground truth, see图1Fig. 1。因此，评估聚类比评估分类需要更多的关注。. Evaluating clustering requires, therefore, slightly more attention than evaluating classification.

内部指标的主要优点是它们可以直接用作优化算法中的目标函数[16, 17]。它们的主要缺点是没有提供清晰、可解释的解释。我们可以优化这个值，但无法知道结果与最优值相差多远，或者是否找到了正确的聚类结构（如果存在的话）。The main advantage of internal indexes is that they can be used directly as the objective function in the optimization algorithm [16, 17]. Their main drawback is that they do not provide a clear, explainable interpretation. We can optimize this value, but cannot know how far the result is from the optimum, or whether the correct clustering structure was found (if it even exists).

4. 质心索引4. Centroid index

NMI、ARI、ACC 和第 3 节中的所有其他措施对于大多数实际用途都有好处，但缺乏一个重要的方面：它们是不可解释的。 [0,1] 范围内的值只是一个数字，其中值越高表示聚类效果越好。但 0.80 或 0.90 的值究竟意味着什么？我们应该以 0.99 为目标还是 0.90 就足够了？NMI, ARI, ACC, and all the other measures in Section 3 are good for most practical use but lack in an important aspect: they are not explainable. A value in the range [0,1] is just a number where a higher value indicates a better clustering. But what does the value of 0.80 or 0.90 mean exactly? Should we aim at 0.99 or would 0.90 be sufficient?

图 9 显示了几种聚类算法在 [18] 中选定的七个数据集上的 NMI 和 CI 值。绿色表示目视验证正确的聚类结果。 NMI 为所有正确的聚类提供了较高的值 (0.931.00)。然而，它有时也会为不正确的聚类结果提​​供较高的值。例如，第一列显示 Birch2 聚类结果，其中 18 个（共 100 个）聚类定位不正确 (CI=18)，但 NMI=0.96。在这种情况下，高值可以归因于 NMI 中的已知偏差，特别是对于大量集群（Figure 9 shows the NMI and CI values for several clustering algorithms on seven selected datasets from [18]. Green indicates visually verified correct clustering results. NMI gives high values (0.931.00) for all the correct clustering. However, it sometimes provides high values also for incorrect clustering results. For example, the first column shows a Birch2 clustering result with 18 (out of 100) clusters incorrectly located (CI=18), yet a high NMI=0.96. In this case, the high values can be attributed to a known bias in NMI, especially for a large number of clusters (k=100）[36]。该问题在 S1-S4 数据集中不太严重，但在两种情况下仍然存在，错误结果分别为 0.93 和 0.95。=100) [36]. The problem is less severe in the S1-S4 datasets, but persists in two cases, with incorrect results of 0.93 and 0.95.

换句话说，NMI 结果难以解释，并且无法在不同数据集之间进行比较。另一方面，质心指数 (CI) 提供了直观且可解释的值。该值直接表明有多少簇被错误地解决。如果所有簇都正确求解，则质心索引会提供明确的 CI=0。In other words, NMI results are difficult to interpret and not comparable across datasets. Centroid index (CI), on the other hand, provides an intuitive, and explainable value. The value directly indicates how many clusters are incorrectly solved. If all clusters are correctly solved, the centroid index provides a clear CI=0.

质心索引的主要限制是，它只能用于基于质心的聚类。然而，[31]中提出了对其他聚类模型的相当简单的推广。这个想法是通过选择匹配最多的簇来替换最近质心映射。不需要质心。一个稍微不同的变体称为质心比（CR）[30]，它计算不稳定质心的数量。稳定性是根据匹配质心之间的距离相对于到同一聚类中最近质心的距离来计算的。The main limitation of centroid index is that, as such, it can be used only for centroid-based clustering. However, a rather straightforward generalization to other clustering models has been proposed in [31]. The idea is to replace the nearest-centroid mapping by selecting the cluster with the most matches. Centroids are not needed. A slightly different variant called centroid ratio (CR) [30] counts the number of unstable centroids. Stability was calculated based on the distance between the matched centroids relative to the distance to the nearest centroids in the same clustering.

一般来说，质心指数及其变体（CI、CR、GCI）可以归类为簇级度量。它们测量 [0,In general, centroid index and its variants (CI, CR, GCI) can be categorized as cluster-level measures. They measure cluster-level errors in the range [0,k] 与其他度量的点级计算相反。这导致了一种非常直观、可解释的测量方法。] in contrast to point-level calculations of the other measures. This leads to a very intuitive, explainable measure.

质心指数有一个局限性：它甚至不尝试测量点级差异。图 10 显示了两个聚类结果的情况。左侧 (Birch2) 的值 CI=7 很清楚：有 7 个位置的质心（红色）位置错误。同时，有七个地方缺少质心（红色质心位于两个簇之间）。在右侧 (S3)，所有质心都位于正确的位置，与地面实况完美匹配。然而，质心表现出轻微的偏差，导致 CI​​ 无法捕获点级差异（黄色区域）。Centroid index has a limitation: it does not even attempt to measure point-level differences. Figure 10 demonstrates the situation with two clustering results. The value CI=7 on the left (Birch2) is clear: there are 7 places where the centroids (red) are in the wrong positions. At the same time, seven places miss a centroid (the red centroid is between two clusters). On the right (S3), all centroids are at the correct places, matching perfectly with the ground truth. However, the centroids exhibit slight deviations, leading to point-level differences (yellow areas) that CI does not capture.

因此，在需要测量详细的点级差异的应用中可能需要点级差异。基于稳定性的方法已用于确定簇的数量。然而，它被证明对参数设置高度敏感，以至于 CI 被发现不适合作为评估措施 [37]。The point-level differences can therefore be needed in applications requiring measuring detailed point-level differences. A stability-based approach has been used to determine the number of clusters. However, it was shown to be highly sensitive to the parameter setup, to the extent that CI was found unsuitable as an evaluation measure [37].

5 结论与建议5. Conclusion and recommendations

我们回顾了使用真实值的聚类评估措施（外部指标）。当我们想要在受控环境中比较聚类算法的性能时，就需要它们。We have reviewed clustering evaluation measures (external indexes) that use ground truth. They are needed when we want to compare the performance of clustering algorithms in a controlled environment.

我们建议使用质心指数（CI）[5]。它是一种直观的集群级度量，具有可解释的结果。如果我们需要微调点级测量，我们的建议是聚类精度（ACC）。它已被详细记录、行为分析，并且提供了易于使用的软件 [1]。We recommend using centroid index (CI) [5]. It is an intuitive cluster-level measure with an explainable result. If we need a fine-tuned point-level measure, our recommendation is clustering accuracy (ACC). It has been documented in detail, behavior analyzed, and an easy-to-use software is available [1].

对于点级衡量标准，还有很多其他选择。即，可以使用任何其他基于集合匹配的措施。如果需要标准化分数，PSI [24] 将是更好的选择，因为它不利于更大的集群。然而，如果论点是所有的分数都应该同等重要，那么 ACC 或任何其他设置匹配措施都是好的。For point-level measures, there are plenty of other choices. Namely, any other set-matching-based measure can be used. If a normalized score is needed, PSI [24] would be a better choice, as it does not favor larger clusters. However, if the argument is that all points should matter equally, then ACC or any other set-matching measure is good.

在成对一致性度量中，也可以使用ARI和NMI，但两者都有偏差。在簇大小不平衡的情况下，ARI 反映了最大簇之间的一致性 [23]，而 NMI 在存在许多簇时会出现偏差 [36]。Among the pairwise consistency measures, ARI and NMI can also be used, but both have biases. In cases of unbalanced cluster sizes, ARI reflects the agreement among the largest clusters [23], whereas NMI is biased when there are many clusters [36].

我们唯一不推荐的衡量标准是兰德指数。无论簇的数量或其大小如何，它都是有偏差的[22]。The only measure we do not recommend is Rand index. It is biased regardless of the number of clusters or their sizes [22].

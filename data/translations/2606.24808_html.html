摘要Abstract

量子计算机可以在重要问题上超越经典机器， 但前提是量子硬件中普遍存在的错误可以大规模纠正。 量子低密度奇偶校验（qLDPC）码为此提供了一条有希望的途径 通过将稀疏奇偶校验与有限编码率相结合并不断增长来实现目标 距离，但它们的构造仍然是一个具有挑战性的离散设计问题。 这里我们介绍结构化概念进化（SCE），一个搜索框架 将大型语言模型与结构化代数变异语法配对 发现提升积代码系列，一类 CSS qLDPC 代码。 SCE 不是要求法学硕士根据第一原理设计代码，而是发展结构化概念，其中包括代数规范与实现它们的可执行程序，使用修改群代数、原图几何或基空间的分层突变。运行 SCE，我们发现了一组多样化的竞争代码族，从阿贝尔结构到非阿贝尔群族，超出了双变量自行车代码等基础标准设计，并通过 BP+OSD 解码在代码容量去极化噪声下表征它们。 这些结果是通过轻量级模型获得的 （GPT-5.4-mini 和 GPT-5.4-nano）。Quantum computers could outperform classical machines on important problems, but only if the errors that pervade quantum hardware can be corrected at scale. Quantum low-density parity-check (qLDPC) codes offer a promising route to this goal by combining sparse parity checks with finite encoding rate and growing distance, but their construction remains a challenging discrete design problem. Here we introduce structured concept evolution (SCE), a search framework that pairs a large language model with a structured algebraic mutation grammar to discover lifted-product code families, a class of CSS qLDPC codes. Instead of asking the LLM to design codes from first principles, SCE evolves structured concepts consisting of algebraic specifications paired with executable programs that realize them, using hierarchical mutations that modify the group algebra, protograph geometry, or base space. Running SCE, we discover a diverse set of competitive code families, ranging from abelian constructions to families over non-abelian groups beyond those underlying standard designs such as bivariate-bicycle codes, and characterize them under code-capacity depolarizing noise with BP+OSD decoding. These results are obtained with lightweight models (GPT-5.4-mini and GPT-5.4-nano).

All results are obtained with lightweight models (GPT-5.4-mini and GPT-5.4-nano).

几个方向自然随之而来。首先，将目标平台的量子位连接图编码为突变语法或适应度分数将引导搜索转向硬件兼容的代码。由于连接性决定了综合症提取深度，因此这也将搜索与电路级目标结合起来。其次，SCE 与提升产品无关。同样的方法可以扩展到平衡积、量子 Tanner 码和光纤束码。 SCE 是否可以提出全新的 CSS 保留结构也是一个悬而未决的问题。最后，人们可以共同设计代码及其编码电路和解码器，将 SCE 转变为对代码、编码器和解码器的端到端搜索。Several directions follow naturally. First, encoding a target platform’s qubit-connectivity graph into the mutation grammar or fitness score would steer the search toward hardware compatible codes. Since connectivity governs syndrome extraction depth, this also couples the search to a circuit-level objective. Second, SCE is not tied to lifted products. The same method can broaden to the balanced product, quantum Tanner codes, and fiber-bundle codes. It is also an open question whether SCE could propose entirely new CSS preserving constructions. Finally, one could co-design the code together with its encoding circuit and decoder, turning SCE into an end-to-end search over code, encoder, and decoder.

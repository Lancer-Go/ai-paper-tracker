The DREAM database — a landmark multi-laboratory aggregation spanning 3,191 awakenings from 263 participants across 20 published studies — confirms that dream reports occur in 84.3% of REM awakenings and 62.6% of NREM awakenings, with a highly significant stage-dependent association (χ2=211.79\chi^{2}=211.79, p=1.2×10−45p=1.2\times 10^{-45}) [1]。然而，当前梦境检测的计算方法将心理状态视为频谱能量问题：最先进的方法提取六个频段的 PSD 和非线性统计矩 (catch22)，从而实现 AUC) [1]. 6.2 稀疏通道和全局拓扑声明Sparse Channels and Global Topological Claims

我们声称 PHINN-EEG 检测大规模额顶叶整合的主张与使用最小公共电极组协调异构 DREAM 数据集的实际要求之间存在理论张力。A theoretical tension exists between our claim that PHINN-EEG detects large-scale fronto-parietal integration and the practical requirement to harmonise across heterogeneous DREAM datasets using a minimal common electrode set.

在原始单极记录可用的情况下，所有通道在进一步处理之前都会重新参考公共 Cz（或链接乳突）方案，从而为该子集生成一致的公共参考信号集（第 4.1 节）。这种重新参考仅适用于单极数据可用的情况；当数据集仅提供预先计算的双极导数时，不会尝试这样做。几个 DREAM 开放访问子集（遵循 Wong 等人）提供了这种预先计算的双极导数——例如 Fpz-Cz 和 C4-M1——它们本身已经是差分信号，而不是单极通道；仅从差分信号中恢复其单极分量在数学上是不确定的，因此不会尝试对这些子集重新引用 Cz，这与第 4.1 节一致。对于仅提供预先计算的双极通道的开放接入 DREAM 子集，拓扑管道改为直接对双极信号进行操作，而无需尝试重​​新转换为公共单极参考（请参见第 4.1 节和第 6.5 节）。因为这意味着延迟嵌入点云是由数学上不同的信号类型（某些数据集中的通用参考单极电位，其他数据集中的差分双极信号）构建的，因此不能保证所得的相空间几何形状在数据集之间可以直接比较。这是 LODO 在异构蒙太奇中有效性的真正限制：将单极参考训练集与双极参考保留数据集配对（反之亦然）的 LODO 折叠同时测试梦内容和信号表示变化的泛化，这可能会夸大与拓扑假设本身无关的明显泛化误差。我们专门报告每个数据集的 LODO 结果（第 5.3 节），以便可以事后检查这种混淆，并且我们在发布的数据拆分中按引用类型标记数据集。Where raw unipolar recordings are available, all channels are re-referenced to a common Cz (or linked-mastoid) scheme prior to further processing, yielding a consistent common-referenced signal set for that subset (Section 4.1). This re-referencing is applied only where unipolar data are available; it is not attempted where a dataset provides only pre-calculated bipolar derivations. Several of the DREAM open-access subsets (following Wong et al.) provide exactly such pre-calculated bipolar derivations — for example Fpz-Cz and C4-M1 — which are themselves already differential signals, not unipolar channels; recovery of their unipolar components from the differential signal alone is mathematically underdetermined, so re-referencing to Cz is not attempted for these subsets, consistent with Section 4.1. For the open-access DREAM subsets that provide only pre-calculated bipolar channels, the topological pipeline is instead adapted to operate directly on the bipolar signals without attempting re-conversion to a common unipolar reference (see Sections 4.1 and 6.5). Because this means the delay-embedded point cloud is constructed from mathematically different signal types (common-referenced unipolar potentials in some datasets, differential bipolar signals in others), the resulting phase-space geometries are not guaranteed to be directly comparable across datasets. This is a genuine limitation of LODO validity across heterogeneous montages: LODO folds that pair a unipolar-referenced training set with a bipolar-referenced held-out dataset (or vice versa) test generalisation across both dream content and a change of signal representation simultaneously, which may inflate apparent generalisation error unrelated to the topological hypothesis itself. We report LODO results per-dataset (Section 5.3) specifically so that this confound can be inspected post hoc, and we flag datasets by reference type in the released data splits.

6.3 BCI 相关性和实时可行性BCI Relevance and Real-Time Feasibility

SleepEEGNet 证明单个 EEG 通道的 REM 检测已得到解决（召回率为 88.7%）[8]。 PHINN-EEG 旨在通过与消费级前额 EEG 设备兼容的最小通道关节嵌入来扩展 BCI 部署的最新技术；如第 5.4 节所述，这仍然是一个有待实证验证的预测，而不是既定结果。这种 BCI 部署动机与第 6.2 节中已经指出的限制存在矛盾：因为拓扑管道在数学上不同的信号类型（单极参考与双极差分）上运行，因此所得的相空间几何形状在参考方案中不能直接比较，因此我们的主要评估仅限于协调参考折叠（训练和保留数据共享相同的参考类型）。这种限制是对整个异构 DREAM 数据库泛化的真正限制，对于 BCI 部署尤其重要，其中消费级前额设备、临床单极蒙太奇和双极研究蒙太奇的参考方案都不同，部署的模型可能会看到未经训练的参考类型。我们确定了缩小这一差距的三个具体步骤，但我们尚未实现或验证其中任何一个：（i）参考不变的预处理步骤 - 例如，将所有子集转换为公共平均值或在蒙太奇之间共享的一小组锚定双极性导数，以便从公共参考系而不是数据集的本地参考系计算下游拓扑特征； (ii) 明确训练和报告交叉引用方案 LODO 条件（已在第 5.3 节中描述性地记录为“完全异构 LODO”，但目前未用于支持任何主要假设）作为未来工作中的主要（而不仅仅是描述性）泛化指标； （iii）专门应用于联合延迟嵌入特征的参考方案域适应（例如，类似于用于受试者间 BCI 转移的对抗性或特征对齐方法[23]），以测试是否可以通过算法来缩小参考方案差距，而不仅仅是通过将评估限制为协调的折叠。在其中一项或多项得到实施和验证之前，跨实验室或跨设备泛化的主张应被理解为仅适用于共享参考方案，而不是适用于 DREAM 数据库或现实世界 BCI 硬件的完全异构性。SleepEEGNet demonstrates that REM detection from a single EEG channel is solved (88.7% recall) [8]. PHINN-EEG is intended to extend the state of the art for BCI deployment through minimal-channel joint embeddings compatible with consumer-grade forehead EEG devices; as noted in Section 5.4, this remains a projection pending empirical validation, not an established result. This BCI-deployment motivation is in tension with a limitation already noted in Section 6.2: because the topological pipeline operates on mathematically different signal types (unipolar-referenced vs. bipolar-differential), the resulting phase-space geometries are not directly comparable across reference schemes, and our primary evaluation is consequently restricted to harmonised-reference folds (training and held-out data sharing the same reference type). This restriction is a genuine limitation on the claim of generalising across the full heterogeneous DREAM database, and it matters specifically for BCI deployment, where consumer-grade forehead devices, clinical unipolar montages, and bipolar research montages all vary in reference scheme and a deployed model may see a reference type it was not trained on. We identify three concrete steps toward closing this gap, none of which we have yet implemented or validated: (i) a reference-invariant preprocessing step — for example, converting all subsets to a common average or a small set of anchor bipolar derivations shared across montages, so that downstream topological features are computed from a common reference frame rather than the dataset’s native one; (ii) explicitly training and reporting a cross-reference-scheme LODO condition (already recorded descriptively as the “full heterogeneous LODO” in Section 5.3, but not currently used to support any primary hypothesis) as a primary, not merely descriptive, generalisation metric in future work; and (iii) reference-scheme domain adaptation (e.g., adversarial or feature-alignment methods analogous to those used for inter-subject BCI transfer [23]) applied specifically to the joint delay-embedding features, to test whether the reference-scheme gap can be closed algorithmically rather than only by restricting evaluation to harmonised folds. Until one or more of these is implemented and validated, claims of cross-laboratory or cross-device generalisation should be read as applying only within a shared reference scheme, not across the full heterogeneity of the DREAM database or of real-world BCI hardware.

6.4 道德考虑Ethical Considerations

梦境监控引发了有关认知隐私的重大伦理考虑。我们与新兴的神经权利框架[19]保持一致，并建议：(i) 所有部署的系统都在明确的、可撤销的知情同意下运行； (ii) 根据 GDPR，梦想拓扑数据被视为敏感健康信息； (iii) 闭环刺激方案须接受机构伦理审查。Dream monitoring raises significant ethical considerations around cognitive privacy. 7 结论Conclusion

我们推出了 PHINN-EEG，这是第一个用于基于 EEG 的梦境分类和合成的拓扑时间序列框架。通过用源自多通道 Takens 延迟嵌入的动态 Betti 曲线替换功率谱密度特征，我们访问了表征神经活动几何结构而不是其能量的特征空间。这种转变主要受到 Baronetzky [5]（睡眠阶段分类中的拓扑与统计准确性优势）的验证基准的理论推动和分析支持，Gupta 等人。 [4] 被引用为相关脑电图领域的确凿第二来源（这两个参考文献均在更正的书目详细信息下进行了验证；第 1 节、第 5.4 节）。We have introduced PHINN-EEG, the first topological time-series framework for EEG-based dream mentation classification and synthesis. By replacing power spectral density features with Dynamic Betti Curves derived from multi-channel Takens delay embeddings, we access a feature space characterising the geometric architecture of neural activity rather than its energy. This shift is theoretically motivated and analytically supported primarily by the verified benchmark of Baronetzky [5] (a topological-versus-statistical accuracy advantage in sleep-stage classification), with Gupta et al. [4] cited as a corroborating secondary source from a related EEG domain (both references verified under corrected bibliographic details; Sections 1, 5.4).

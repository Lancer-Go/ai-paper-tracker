However, producing high-quality data videos requires expertise spanning data analysis, narrative design, and video production. Existing approaches fall short: static visualization tools (e.g., BI dashboards) lack narrative logic and animation; authoring tools require users to pre-prepare visualizations rather than working from raw data; pixel-level video generation models cannot guarantee data fidelity or provenance. To address the combinatorial explosion of the design space,数据魔法DataMagic采用“生成然后编排”多智能体架构，并行生成候选场景，然后通过全局编排优化叙事连贯性。杠杆作用adopts a Generate-then-Orchestrate multi-agent architecture that generates candidate scenes in parallel and then optimizes narrative coherence through global orchestration. 1. 简介Introduction

数据视频集成了动态图表、语音旁白和同步动画，以时间叙事的方式传达数据见解，吸引了学术界和工业界越来越多的关注Data videos integrate dynamic charts, voice narration, and synchronized animations to communicate data insights as temporal narratives, attracting growing attention from both academia and industry(Amini and others, 2015; Shen et al., 2025; Wang et al., 2026)。然而，制作高质量的数据视频需要跨领域的专业知识，涵盖数据分析、叙事设计和视频制作. However, producing high-quality data videos requires cross-domain expertise spanning data analysis, narrative design, and video production(Shen et al., 2025)，而现有的方法都缺乏从原始数据到数据视频的端到端自动化, and existing approaches all fall short of end-to-end automation from raw data to data video(Vartak and others, 2015; Siddiqui and others, 2016; Li et al., 2026; Tang et al., 2026c, d).

静态可视化工具（例如 BI 仪表板、HAIChartStatic visualization tools (e.g., BI dashboards, HAIChart(Xie et al., 2024), 深眼, DeepEye(Luo et al., 2018)）输出静态图表，缺乏叙事逻辑和动画。创作工具（例如 Data Playwright) output static charts, lacking narrative logic and animation. Authoring tools (e.g., Data Playwright(Shen and others, 2025)）专注于向现有图表添加动画效果，而不从原始数据中提取见解或处理多场景叙事编排。像素级视频生成模型（例如 Sora) focus on adding animation effects to existing charts, without extracting insights from raw data or handling multi-scene narrative orchestration. Pixel-level video generation models (e.g., Sora(Liu et al., 2024)）可以合成视频，但其黑盒性质经常产生数字幻觉，并且无法将视觉元素映射回底层数据记录。) can synthesize videos, but their black-box nature frequently produces numerical hallucinations and cannot map visual elements back to underlying data records.

我们的主要观察结果是，有效的数据视频从根本上来说是结构化的叙述，而不是视觉元素的简单组合Our key observation is that effective data videos are fundamentally structured narratives rather than simple assemblies of visual elements(Shen et al., 2025)。这促使我们将端到端生成建模为分层内容编排问题。出现了两个核心挑战：（1）如何设计一个结构化的中间表示，精确描述异构组件及其时间关系，同时确保数据保真度和来源； (2) 如何有效地在广阔的设计空间中搜索平衡本地场景质量和全球叙事连贯性的解决方案。. This motivates us to model end-to-end generation as a hierarchical content orchestration problem. Two core challenges emerge: (1) how to design a structured intermediate representation that precisely describes heterogeneous components and their temporal relations while ensuring data fidelity and provenance; (2) how to efficiently search the vast design space for solutions that balance local scene quality and global narrative coherence.

For challenge (1), we introduceDV规格DVSpec（数据视频规范），一种声明性规范，通过数据驱动的语义引用和叙述索引触发将视觉和动画元素绑定到底层数据字段，确保完整的出处。对于挑战 (2)，(Data Video Specification), a declarative specification that binds visual and animation elements to underlying data fields through data-driven semantic references and narration-index triggering, ensuring full provenance. For challenge (2),数据魔法DataMagic采用“生成然后编排”多代理架构adopts a Generate-then-Orchestrate multi-agent architecture(Zhu et al., 2025)并行生成不同的候选场景，然后应用全局编排来优化场景选择、排序和叙事连贯性。杠杆作用that generates diverse candidate scenes in parallel and then applies global orchestration to optimize scene selection, ordering, and narrative coherence. 2.1. DV规格DVSpec：声明性数据视频规范: Declarative Data Video Specification

现有的声明性规范（例如，Vega-LiteExisting declarative specifications (e.g., Vega-Lite(Satyanarayan et al., 2017), 犬科动物, Canis(Ge et al., 2020), 图表标记, ChartMark(Chen et al., 2025)）对于静态图表或单图表标注和动画表现良好，但尚未扩展到多场景数据视频所需的跨模态内容的统一描述和时间协调) perform well for static charts or single-chart annotations and animations, but have not been extended to the unified description of cross-modal content and temporal coordination required for multi-scene data videos(Chen and others, 2025; Chen et al., 2023)。为了填补这个空白，我们设计了. To fill this gap, we designDV规格DVSpec（数据视频规范），一种声明式规范，将逻辑描述与渲染实现完全解耦，作为多智能体生成引擎和渲染引擎之间的结构化中间表示：生成阶段将分析结果写入(Data Video Specification), a declarative specification that fully decouples logical description from rendering implementation, serving as a structured intermediate representation between the multi-agent generation engine and the rendering engine: the generation stage writes analysis results toDV规格DVSpec，而交互式编辑更改也映射到本地, while interactive editing changes are also mapped to localDV规格DVSpec更新。updates.DV规格DVSpec本身与渲染库无关；当前系统使用 D3.js 渲染图表并使用 Remotion 合成视频。itself is rendering-library agnostic; the current system renders charts using D3.js and synthesizes videos with Remotion.

2.2. 多代理生成管道Multi-Agent Generation Pipeline

数据视频生成涉及数据处理、视觉设计和叙事逻辑之间的复杂依赖关系。单阶段方法很难确保每个场景的数据准确性和整体叙述的连贯性。Data video generation involves complex dependencies among data processing, visual design, and narrative logic. Single-stage approaches struggle to ensure both per-scene data accuracy and overall narrative coherence.数据魔法DataMagic采用Generate-then-Orchestrate两阶段架构，并行生成候选场景使编排阶段能够执行全局优化，而不是做出贪婪的逐步决策：adopts a Generate-then-Orchestrate two-stage architecture, where parallel generation of candidate scenes enables the orchestration stage to perform global optimization rather than making greedy step-by-step decisions:

For each sub-task, the Data Manager plans the data processing workflow and automatically generates Python code to extract, filter, and aggregate relevant data slices from the source table. The Visual Designer then designs the visualization scheme (chart type, data bindings, and style configuration), extracts key insights, and populates the content field ofDV规格DVSpec。该阶段并行生成候选场景池，将低级数据处理与高级叙事构建解耦。. This stage generates a pool of candidate scenes in parallel, decoupling low-level data processing from high-level narrative construction.

第二阶段：全球叙事编排。Stage 2: Global narrative orchestration.叙述导演根据洞察值和查询覆盖率从候选池中选择场景，并按照叙述逻辑规划播放顺序（例如“宏观到微观”、“现象先于原因”）。它根据相邻场景的上下文为每个场景生成旁白，确保跨场景转换的叙事连贯性。动画协调器使用The Narration Director selects scenes from the candidate pool based on insight value and query coverage, and plans a playback order following narrative logic (e.g., “macro-to-micro”, “phenomenon before cause”).

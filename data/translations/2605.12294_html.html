GUI代理的可执行代理内存Executable Agentic Memory for GUI Agent

Zerui Qin    Sheng Yue    Xingyuan Hua    Yongjian Fu    Ju Ren
摘要Abstract

现代 GUI 代理通常依赖于以模型为中心的逐步交互范例，其中法学硕士必须重新解释 UI 并重新决定每个屏幕上的操作，这在长期任务中是脆弱的。在本文中，我们提出了可执行代理内存（EAM），这是一种结构化知识图（KG），它将 GUI 规划从自由形式的生成转变为强大的检索和执行过程。我们的方法包括使用状态感知 DFS 和操作组挖掘来压缩多步骤例程的样本高效内存构建管道。为了确保高效的规划，我们引入了价值引导图搜索，其中轻量级 Q 函数模型在 KG 上引导蒙特卡罗树搜索 (MCTS)。我们从理论上建立了 Q 模型的偏差一致性，并推导出路径恢复的样本复杂度界限。根据经验，EAM 的性能优于 UI-TARS-7B 等最先进的基线高达Modern GUI agents typically rely on a model-centric and step-wise interaction paradigm, where LLMs must re-interpret the UI and re-decide actions at every screen, which is fragile in long-horizon tasks. 1 简介Introduction

由（多模式）法学硕士支持的现代图形用户界面（GUI）代理可以通过“查看”屏幕并生成操作来操作现实世界的应用程序Modern Graphical User Interface (GUI) agents powered by (multimodal) LLMs can operate real-world apps by “seeing” screens and generating actions(Wen et al., 2024; Wang et al., 2024a; Zhang et al., 2025)。然而，占主导地位的交互范式仍然存在. However, the dominant interaction paradigm remains以模型为中心、分步进行model-centric and step-wise：在每个屏幕上，LLM 必须重新解释 UI，重新决定下一步操作，并在其上下文窗口中隐式维护任务进度。这使得长期自动化变得脆弱：小的感知或推理错误会加剧，很容易产生幻觉行为和不正确的弯路，特别是在训练覆盖范围有限的异构应用程序环境中: at every screen, an LLM must re-interpret the UI, re-decide the next action, and implicitly maintain task progress in its context window. This makes long-horizon automation fragile: small perceptual or reasoning errors would compound, easily producing hallucinated actions and incorrect detours, especially in heterogeneous app environments where training coverage is limited(Qin et al., 2025; Luo et al., 2025; Wu et al., 2025; Gou et al., 2024)。例如，UI-TARS-7B. For instance, UI-TARS-7B(Qin et al., 2025)被认为是 SOTA GUI 代理模型，在长期 AndroidWorld 基准测试中仅取得 33% 的成功率, considered a SOTA GUI agent model, achieves only 33% success rate on the long-horizon AndroidWorld benchmark(Rawles et al., 2024)，而由 GPT-4o 支持的代理框架 M3A 仅达到 40.5%, while M3A, an agentic framework powered by GPT-4o, attains merely 40.5%(Rawles et al., 2024).

为了提高鲁棒性，一个自然的方向是为智能体配备外部知识和记忆。一些努力To improve robustness, a natural direction is to equip agents with external knowledge and memory. Some efforts(Wang et al., 2024b, 2025; Cheng et al., 2025; Sun et al., 2026)维护历史交互的文本记忆，例如工作流程模式和决策启发法，并将它们注入法学硕士的背景中以指导任务规划。其他人通过从探索中提取动作级知识（例如，元素功能或成功轨迹），将其存储为向量数据库或知识图，并在推理时检索相关知识以增强决策来构建外部知识库maintain textual memory of historical interactions, such as workflow patterns and decision heuristics, and inject them into the LLM’s context to guide task planning. Others construct external knowledge bases by extracting action-level knowledge (e.g., element functionality or successful trajectories) from exploration, storing them as vector databases or knowledge graphs, and retrieving relevant knowledge at inference time to augment decision-making(Xie et al., 2025; Jiang et al., 2025; Guan et al., 2025b; Li et al., 2025)。然而，由于以模型为中心的生成以及对历史轨迹中固有结构化信息的无知，这种上下文知识注入仍然不可靠，使得难以从历史知识中可靠地再现可执行路径。此外，重复检索和逐步生成会带来巨大的成本和延迟，阻碍实时部署。. However, such in-context knowledge injection remains unreliable due to model-centric generation and ignorance of inherent structured information in historical trajectories, making it difficult to reliably reproduce executable paths from historical knowledge. Moreover, repeated retrieval and step-wise generation introduce substantial cost and latency, hindering real-time deployment.

7 结论Conclusion

本文提出了可执行代理内存（EAM），这是一种结构化知识图，它将 GUI 规划从自由形式的生成转变为强大的检索和执行过程。与依赖于检索上下文的 LLM 推理的现有知识增强方法不同，EAM 使代理能够直接提取保证保持有效转换的可执行路径。我们提出了一个样本高效的内存构建管道和一个价值引导的 MCTS 框架，为可靠的路径提取提供了理论保证。三个基准的实验结果表明，成功率和效率都有显着提高。这些发现表明，将知识图谱视为可执行状态机，而不是上下文注入的检索源，可以实现可靠、高效和长期的 GUI 自动化。This paper presents Executable Agentic Memory (EAM), a structured knowledge graph that shifts GUI planning from free-form generation to a robust retrieval-and-execution process. Unlike prior knowledge-augmented approaches that rely on LLM reasoning over retrieved context, EAM enables agents to directly extract executable paths guaranteed to stay on valid transitions. We propose a sample-efficient memory construction pipeline and a value-guided MCTS framework with theoretical guarantees for reliable path extraction. Experimental results across three benchmarks demonstrate significant improvements in both success rate and efficiency. These findings show that treating the KG as an executable state machine, rather than a retrieval source for in-context injection, enables reliable, efficient, and long-horizon GUI automation.

局限性。Limitations.

我们当前的框架假设一个相对静态的 UI 环境。当应用程序经历重大更新时，知识图谱可能会变得过时。为知识图谱开发高效的增量进化机制以适应频繁更新的环境仍然是未来工作的重要方向。Our current framework assumes a relatively static UI environment. When applications undergo significant updates, the knowledge graph may become outdated. Developing efficient incremental evolution mechanisms for the knowledge graph to adapt to the frequently updating environments remains an important direction for future work.

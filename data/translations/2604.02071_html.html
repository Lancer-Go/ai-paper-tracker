摘要Abstract

人与物体交互（HOI）检测旨在定位人与物体对，并从单个图像中对它们的交互进行分类，这是一项需要强大的视觉理解和细致入微的上下文推理的任务。 最近的方法利用视觉语言模型 (VLM) 引入语义先验，显着提高 HOI 检测性能。 然而，现有的方法通常无法充分利用分布在整个场景中的不同上下文线索。 为了克服这些限制，我们提出了以实例为中心的上下文挖掘网络（InCoM-Net）——一种新颖的框架，可以有效将从 VLM 中提取的丰富语义知识与对象检测器生成的实例特定特征相集成。 这种设计不仅可以对每个检测到的实例内的关系进行建模，还可以对实例及其周围场景上下文之间的关系进行建模，从而实现更深入的交互推理。 InCoM-Net 包含两个核心组件： 以实例为中心的上下文细化 (ICR)，它从 VLM 派生的特征中分别提取实例内、实例间和全局上下文线索；渐进式上下文聚合 (ProCA)，它迭代地将这些多上下文特征与实例级检测器特征融合，以支持高级 HOI 推理。对 HICO-DET 和 V-COCO 基准的大量实验表明，InCoM-Net 实现了最先进的性能，超越了以前的 HOI 检测方法。代码可在Human–Object Interaction (HOI) detection aims to localize human–object pairs and classify their interactions from a single image, a task that demands strong visual understanding and nuanced contextual reasoning. Recent approaches have leveraged Vision–Language Models (VLMs) to introduce semantic priors, significantly improving HOI detection performance. However, existing methods often fail to fully capitalize on the diverse contextual cues distributed across the entire scene. To overcome these limitations, we propose the Instance-centric Context Mining Network (InCoM-Net)—a novel framework that effectively integrates rich semantic knowledge extracted from VLMs with instance-specific features produced by an object detector. This design enables deeper interaction reasoning by modeling relationships not only within each detected instance but also across instances and their surrounding scene context. InCoM-Net comprises two core components: Instance-centric Context Refinement (ICR), which separately extracts intra-instance, inter-instance, and global contextual cues from VLM-derived features, and Progressive Context Aggregation (ProCA), which iteratively fuses these multi-context features with instance-level detector features to support high-level HOI reasoning. Extensive experiments on the HICO-DET and V-COCO benchmarks show that InCoM-Net achieves state-of-the-art performance, surpassing previous HOI detection methods. Unlike conventional object detection, HOI detection requires understanding of spatial configurations, object affordances, and contextual semantics to reason about the plausible relationships between humans and objects. Recent Transformer-based architectures[16, 41, 40, 2]已提出推进 HOI 检测。然而，尽管取得了这些进步，准确捕捉微妙的、潜在的和上下文相关的交互仍然是一个相当大的挑战。have been proposed to advance HOI detection. Trained on large-scale image-text pairs, VLMs have shown strong generalization capabilities in zero-shot image classification, captioning, and visual question answering. Owing to their ability to produce semantically rich visual representations aligned with language, recent studies[26, 29, 22]将 VLM 应用于 HOI 检测，旨在利用高级交互先验。have applied VLMs to HOI detection, aiming to leverage high-level interaction priors.

为了解决这些限制，我们提出了以实例为中心的上下文挖掘网络（InCoM-Net），这是一种用于 HOI 检测的新颖框架。 InCoM-Net 使用 VLM 主干为每个实例构建多上下文特征，并通过基于 Transformer 的注意力将它们与实例级特征集成。通过对不同上下文范围的特征进行建模，可以更有效地指导网络参加什么活动和在哪里参加，从而实现更强大和上下文感知的 HOI 理解。To address these limitations, we propose the Instance-centric Context Mining Network (InCoM-Net), a novel framework for HOI detection. InCoM-Net constructs multi-context features for each instance using a VLM backbone and integrates them with instance-level features via Transformer-based attention. By modeling features across diverse contextual scopes, the network can be more effectively guided in both what and where to attend, enabling more robust and context-aware HOI understanding.

First, we introduce instance-centric multi-context feature generation through the Instance-centric Context Refinement (ICR) module. For each instance, three levels of contextual information—(1) intra-instance, (2) inter-instance, and (3) global contexts—are derived from VLM representations by applying scene-adaptive masks to the feature maps. These scene-adaptive masks enable the generation of context-specific features for each instance-level query. The intra-instance context captures visual cues within the target instance, the inter-instance context models interactions among multiple instances, and the global context provides complementary scene-level information to support comprehensive HOI reasoning. These multi-context features are encoded separately to preserve diverse semantic information and construct adaptive, multi-level contextual representations tailored to each instance.

其次，通过渐进式上下文聚合（ProCA）模块将多上下文特征聚合为来自对象检测器的实例级特征。 ProCA 采用多个注意力层来迭代收集和提炼相关上下文信息。这种渐进式集成增强了每个实例的外观与其周围环境之间的一致性。Second, the multi-context features are aggregated into the instance-level features from the object detector through the Progressive Context Aggregation (ProCA) module. ProCA employs multiple attention layers to iteratively gather and refine relevant contextual information. This progressive integration enhances the alignment between each instance’s appearance and its surrounding context.

第三，我们通过掩蔽特征训练（MFT）实现了 VLM 多上下文特征和检测器空间特征的平衡利用。我们观察到，当结合这些异构特征源进行 HOI 预测时，模型往往会过度依赖一个源，从而限制了整体性能。在训练期间，MFT 通过有选择地屏蔽 VLM 多上下文特征或检测器空间特征来减轻这种不平衡。该策略鼓励模型在不同的输入条件下有效地利用不同的上下文线索。Third, we enable balanced utilization of both VLM multi-context features and detector spatial features through masked feature training (MFT). We observe that, when combining these heterogeneous feature sources for HOI prediction, the model tends to over-rely on one source, which limits overall performance. During training, MFT mitigates this imbalance by selectively masking either the VLM multi-context features or the detector spatial features. This strategy encourages the model to effectively leverage diverse contextual cues under varying input conditions.

5 结论Conclusion

在这项工作中，我们提出了 InCoM-Net，这是一种新颖的 HOI 检测框架，它利用以实例为中心的上下文挖掘来更有效地利用语义丰富的 VLM 表示进行交互推理。 通过从 VLM 特征中提取多上下文信息，我们的模型为每个实例构建自适应上下文表示，并通过专用的注意力机制逐步集成它们。 这使得模型能够捕获丰富的上下文线索，这对于准确的 HOI 预测至关重要。此外，我们的屏蔽特征训练鼓励异构特征源的平衡利用，增强不同输入条件下的鲁棒性。 HICO-DET 和 V-COCO 上的大量实验表明，InCoM-Net 在零样本设置中实现了最先进的性能和强大的泛化能力。总体而言，这项工作强调了以实例为中心的上下文建模对于基于 VLM 的 HOI 检测的价值，从而能够更有效地使用语义丰富的 VLM 表示。In this work, we proposed InCoM-Net, a novel HOI detection framework that leverages Instance-centric Context Mining to more effectively utilize semantically rich VLM representations for interaction reasoning. By extracting multi-context information from VLM features, our model constructs adaptive contextual representations for each instance and progressively integrates them through a dedicated attention mechanism. This allows the model to capture rich contextual cues that are critical for accurate HOI prediction. In addition, our masked feature training encourages balanced utilization of heterogeneous feature sources, enhancing robustness under varying input conditions. Extensive experiments on HICO-DET and V-COCO demonstrate that InCoM-Net achieves state-of-the-art performance and strong generalization in zero-shot settings. Overall, this work underscores the value of instance-centric context modeling for VLM-based HOI detection, enabling more effective use of semantically rich VLM representations.

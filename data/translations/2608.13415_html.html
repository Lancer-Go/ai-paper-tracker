1 简介1 Introduction

大规模机器人学习的最新进展已经产生了通用机器人策略，可以执行多种技能并转移到新的环境中[1,2,3]。当与任务和运动规划 (TAMP) [4, 5, 6] 和搜索 [7, 8] 等经典规划方法相结合时，这些策略可以允许机器人在家庭和工厂中执行长期任务，为更多自主机器人绘制道路。然而，仅预训练并不能涵盖机器人在现实世界中可能面临的所有可能场景，通常会导致任务执行不可靠。因此，一个有前途的解决方案是让机器人通过自主实践从经验中学习[9,10,11]。不幸的是，当前的强化学习算法的样本效率仍然很高 [12, 13]，限制了它们在部署时学习中的适用性。由于机器人在部署期间通常只有有限的停机时间，因此它们需要专门为预算实践设计的方法。Recent progress in large-scale robot learning has produced general-purpose robot policies that can perform diverse skills and transfer to novel environments [1, 2, 3]. When combined with classical planning methods, such as Task and Motion Planning (TAMP) [4, 5, 6] and search [7, 8], these policies can allow robots to perform long-horizon tasks in homes and factories, charting a path for more autonomous robots. However, pretraining alone does not cover all the possible scenarios a robot may face in the real-world, often leading to unreliable task execution. Therefore, a promising solution is to allow robots to learn from experience through autonomous practice [9, 10, 11]. Unfortunately, current RL algorithms remain highly sample inefficient [12, 13], limiting their applicability to deployment-time learning. Since robots typically have only limited downtime during deployment, they require methods explicitly designed for budgeted practice.

我们的主要见解是，停机时间通常是提前知道的，机器人应该利用这些信息来调整其学习过程以适应最终的实践预算。直观地说，大量的练习预算应该鼓励机器人练习更多有益的技能，即使这些技能很难，而少量的预算应该会导致保守的学习行为。我们将顺序任务的自主技能实践问题形式化为预算技能学习，并提出了一种主动学习算法，Our key insight is that downtime is often known in advance, and robots should leverage this information to adapt their learning process to the resulting practice budget. Intuitively, a large practice budget should encourage robots to practice more rewarding skills even if they are hard, while a small budget should lead to conservative learning behaviour. We formalize the problem of autonomous skill practice for sequential tasks as budgeted skill learning, and propose an active learning algorithm,刻意练习Deliberate Practice（DP），最佳地使用预算来最大化任务奖励。我们考虑标准 TAMP 设置，其中为机器人提供高级技能规范，包括前提条件、终止条件和效果。例如，在第6节的早餐领域，StartToaster技能需要移动到烤面包机控制杆上方才能按下它，并具有打开烤面包机的效果。机器人必须学习参数化控制策略，通过在环境中的练习将技能转化为低级动作。在决策时，任务规划器计算一个由技能组成的计划，例如（挑选（面包）、放置（面包、烤面包机）、开始（烤面包机））来烤面包。图 1 说明了我们的方法如何让机器人决定练习哪些技能来制作早餐。机器人可以练习一种烤面包的技能(DP), that optimally uses the budget to maximize task reward. In robotics, active learning has similarly been central for skill acquisition due to the high cost of data collection. Prior work includes methods for actively learning parameterized robot skills from practice [15], human demonstrations [16], and across multiple tasks [17, 18, 19]. However, these approaches focus on efficiently acquiring individual skills without considering the sequential nature of long-horizon problems. By contrast, our approach studies active skill learning embedded in a complex sequential decision process under explicit budget constraints.

7 结论7 Conclusion

我们建议We propose刻意练习Deliberate Practice，一种主动技能学习算法，可将有限的练习预算分配给许多机器人技能，以最大限度地提高长期规划性能。我们的算法根据练习预算对每种技能的能力进行建模，计算最佳预算分配，并在环境中按顺序练习技能。计算这种分配需要解决一个具有挑战性的双层优化问题，为此我们得出了一个精确的, an active skill learning algorithm that allocates a limited practice budget to many robot skills to provably maximize long-horizon planning performance. Our algorithm models each skill’s competence as a function of the practice budget, computes an optimal budget allocation, and sequentially practices the skills in the environment. 8 限制8 Limitations

我们方法的一个关键假设是获得技能能力的近似先验。如果这些先验过于乐观，机器人可能会将练习分配给在可用预算内实际上不可行的任务计划。这种限制可以通过使用保守的先验或通过在技能能力预测中明确纳入不确定性来解决。第二个限制是，对于非常大的问题，求解双线性规划的全局最优性可能会变得具有挑战性。因此，未来工作的一个重要方向是开发有界次优优化策略。最后，我们计划扩展我们的方法，在移动机械手上练习多项任务的通用技能，朝着通用机器人的更广泛目标迈进。One key assumption of our approach is access to approximate priors over skill competence. If these priors are overly optimistic, the robot may allocate practice to task plans that are actually infeasible within the available budget. This limitation could be addressed by using conservative priors or by explicitly incorporating uncertainty in skill-competence predictions. A second limitation is that solving the bilinear program to global optimality may become challenging for very large problems. An important direction for future work is therefore to develop bounded-suboptimal optimization strategies. Finally, we plan to extend our approach to practicing generalizable skills acros multiple tasks on mobile manipulators, moving toward the broader goal of general-purpose robots.

A.3 实验细节A.3 Experimental Details

A.3.1 技能练习A.3.1 Skill Practice

我们使用CMA-ES来练习机器人技能。 CMA-ES 是一种基于无梯度进化的优化方法，用于实现奖励最大化。对于每种技能，我们定义一个奖励函数并使用 CMA-ES [38] 优化相应的交互策略参数。我们使用 CMA-ES 是因为我们的目标是通过推出进行评估的，并且对于策略参数而言是不可微分的。 CMA-ES 是一种强大的无梯度优化器，适用于此类连续黑盒目标。我们将所有可学习的技能实现为由路点和阻抗参数参数化的笛卡尔空间阻抗控制器[37]。优化器将要优化的策略参数以及这些参数的高斯先验作为输入，由均值和对角协方差矩阵指定。We use CMA-ES to practice robot skills. CMA-ES is a gradient-free evolutionary-based optimization approach for reward maximization. For each skill, we define a reward function and optimize the corresponding interaction policy parameters using CMA-ES [38]. We use CMA-ES because our objective is evaluated through rollouts and is not differentiable with respect to the policy parameters. CMA-ES is a robust gradient-free optimizer for such continuous black-box objectives. We implement all learnable skills as Cartesian-space impedance controllers [37] parameterized by waypoints and impedance parameters. The optimizer takes as input the policy parameters to be optimized, together with a Gaussian prior over these parameters, specified by a mean and diagonal covariance matrix.

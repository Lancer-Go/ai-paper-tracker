1. 简介Introduction

代码生成是指根据给定的编程要求自动生成源代码。 由于其具有大幅提高软件开发效率和生产力的潜力，代码生成近年来越来越受到学术界和工业界的关注Code generation refers to the automatic generation of source code from given programming requirements. Due to its potential to substantially improve software development efficiency and productivity, code generation has attracted increasing attention from both academia and industry in recent years(Guo et al., 2024; Chen, 2021; Austin et al., 2021b)。 随着大型语言模型（LLM）的快速进步，例如 Claude. Despite these advances, LLMs still exhibit notable performance limitations when confronted with complex programming requirements(Hendrycks et al., 2021a)。 这些限制不仅阻碍了基于LLM的代码生成技术的实际部署，而且还可能导致严重的软件质量问题. Such limitations not only hinder the practical deployment of LLM-based code generation techniques but may also lead to critical software quality issues(Liu et al., 2023b; Pearce et al., 2025)。 因此，有效提高法学硕士的代码生成性能仍然是一个紧迫的研究挑战。. Consequently, effectively improving the code generation performance of LLMs remains a pressing research challenge.

First, existing CRL approaches rely on fixed requirement difficulty labels, either manually annotated or inferred from static code complexity metrics, which fail to capture the dynamic, model-specific perception of requirement difficulty. These limitations highlight the need for a more principled approach to requirement difficulty perception, optimization, and adaptive curriculum sampling in CRL-based code generation.

4.4. 自适应课程抽样Adaptive Curriculum Sampling

在传统的 CRL 中In traditional CRL(Narvekar et al., 2020)，训练数据总是根据难度（例如，从易到难）划分为多个簇，每个簇对应于一个不同的训练阶段。 在每个阶段，模型仅从与当前难度级别相关的集群中进行采样，并在完成后过渡到下一个阶段。 虽然直观，但这种课程抽样策略存在两个关键限制。 首先，阶段转换通常很突然，导致冷启动问题, training data are always partitioned into multiple clusters according to difficulty (e.g., from easy to hard), with each cluster corresponding to a distinct training stage. During each stage, the model samples exclusively from the cluster associated with the current difficulty level, and transitions to the next stage upon completion. First, stage transitions are often abrupt, causing a cold-start problem(Narvekar et al., 2020)当模型在新的难度阶段遇到更难的数据时，这会降低训练的稳定性和有效性。 其次，在融入更高难度的新知识后，模型往往会忘记早期阶段学到的知识，从而导致灾难性遗忘when the model encounters substantially harder data in a new difficulty stage, which degrades training stability and effectiveness.

1 简介Introduction

当买家在 ChatGPT 或 Claude 中输入“销售团队的最佳 CRM”时，模型会给出一个答案，该答案不仅取决于文字提示和随后的检索，还取决于助手所知道（或已被告知）的有关提问者的所有信息。在生产聊天界面中，“谁”来自许多来源：用户提供的系统提示（“您正在帮助英国中小型企业所有者”）、会话中的先前轮次、帐户级元数据，或者在我们此处采用的审计设计类似物中，前缀于用户消息的显式角色属性。When a buyer types “best CRM for sales teams” into ChatGPT or Claude, the model emits an answer that is shaped not only by the literal prompt and the retrieval that follows, but by everything the assistant knows — or has been told — about who is asking. In a production chat interface, that “who” comes from many sources: user-supplied system prompts (“you are helping a UK SMB owner”), prior turns in a session, account-level metadata, or, in the audit-design analogue we adopt here, an explicit persona attribute prefixed to the user message.

本文提出的问题是经验性的：当只有角色属性变化时，推荐集实际上会移动多少？如果效果很小，人工智能商业推荐大约与角色无关，单个“最佳[类别]”定位页面就是正确的品牌反应。如果效果大的话，AI商业推荐已经The question this paper asks is empirical: how much does the recommendation set actually move when only the persona attribute varies? If the effect is small, AI commercial recommendation is approximately persona-agnostic, and a single “best [category]” positioning page is the right brand response. If the effect is large, AI commercial recommendation is already事实上的de facto人物角色细分，品牌端优化必须反映这种细分。有关角色调节的文献已经回答了以准确性为衡量标准的封闭式任务的问题persona-segmented, and brand-side optimization must mirror that segmentation. 每个角色都通过固定的模板短语作为用户消息的前缀提供（例如，“我是[角色描述]。”）。措辞模板在各个角色中保持不变；仅属性字符串有所不同。这种方法选择遵循以下建议：Each persona is supplied as a prefix to the user message via a fixed templated phrasing (e.g., “I’m a [persona description]. ”).

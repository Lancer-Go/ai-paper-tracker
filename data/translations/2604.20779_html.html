摘要Abstract

人工智能编码代理正在被大规模采用，但我们缺乏关于人们如何实际使用它们以及它们的输出有多少在实践中有用的经验证据。 我们呈现AI coding agents are being adopted at scale, yet we lack empirical evidence on how people actually use them and how much of their output is useful in practice. We present瑞典聊天室SWE-chat，第一个从开源开发人员处收集的真实编码代理会话的大规模数据集。 该数据集当前包含 6,000 个会话，其中包括 63,000 多个用户提示和 355,000 个代理工具调用。, the first large-scale dataset of real coding agent sessions collected from open-source developers in the wild. The dataset currently contains 6,000 sessions, comprising more than 63,000 user prompts and 355,000 agent tool calls.瑞典聊天室SWE-chat是一个活的数据集；我们的收集管道自动持续地发现和处理来自公共存储库的会话。 杠杆作用is a living dataset; our collection pipeline automatically and continually discovers and processes sessions from public repositories. Leveraging瑞典聊天室SWE-chat，我们提供了现实世界编码代理使用和故障模式的初步经验特征。 我们发现编码模式是双峰的：在 41% 的会话中，代理编写了几乎所有提交的代码（“vibe 编码”），而在 23% 的会话中，所有代码都是人类自己编写的。 尽管编码代理的能力迅速提高，但在自然环境中仍然效率低下。 在所有代理生成的代码中，只有 44% 能够保存到用户提交中，并且代理编写的代码比人类编写的代码引入了更多的安全漏洞。 此外，44% 的轮次中，用户会通过更正、故障报告和中断来抵制代理的输出。 通过捕获人类与代理代码作者归属的完整交互痕迹，, we provide an initial empirical characterization of real-world coding agent usage and failure modes. We find that coding patterns are bimodal: in 41% of sessions, agents author virtually all committed code (“vibe coding”), while in 23%, humans write all code themselves. Despite rapidly improving capabilities, coding agents remain inefficient in natural settings. Just 44% of all agent-produced code survives into user commits, and agent-written code introduces more security vulnerabilities than code authored by humans. Furthermore, users push back against agent outputs—through corrections, failure reports, and interruptions—in 44% of all turns. By capturing complete interaction traces with human vs. agent code authorship attribution,瑞典聊天室SWE-chat为超越策划的基准，以基于证据的方式理解人工智能代理在实际开发人员工作流程中的表现提供了实证基础。provides an empirical foundation for moving beyond curated benchmarks towards an evidence-based understanding of how AI agents perform in real developer workflows.

1 简介Introduction

人工智能编码代理已经风靡全球。 通过一组简单的操作来增强大型语言模型 (LLM)，以便与编码环境自主交互，即所谓的AI coding agents have taken the world by storm. Enhancing Large Language Models (LLMs) with a simple set of actions for interacting with a coding environment autonomously—so-called工具调用tool calls用于编辑文件、执行终端命令和调用子代理 - 提高了他们完成漫长而困难的编程任务的能力for editing files, executing terminal commands, and invoking subagents—has accelerated their ability to complete long and difficult programming tasks(Yang et al., 2024a)。 最近，据报道，人工智能代理成功完成了人类需要 12 小时才能完成的 50% 的编码任务. Lately, AI agents are reported to succeed on 50% of coding tasks that humans take 12 hours to complete(METR, 2026; Kwa et al., 2025)。 因此，开发人员越来越多地将编码委托给代理. As a result, developers increasingly delegate coding to agents(Mürtz and Müller, 2025; Anthropic, 2026)，对全球劳动力产生前所未有的影响, with unprecedented impacts on the global workforce(Peng et al., 2023; Demirci et al., 2025; Massenkoff et al., 2026).

尽管被大规模采用，但我们对人类和人工智能编码代理如何交互的理解在很大程度上仍然是轶事。 虽然最近的工作已经开始在现实环境中评估代码完成模型Despite massive adoption, our understanding of how humans and AI coding agents interact remains largely anecdotal. While recent work has begun evaluating code completion models in realistic settings(Chi et al., 2025)，对于完整的代理编码会话不存在类似的努力。 没有公共数据集能够捕获开发人员如何提示、引导、覆盖以及最终提交（或丢弃）代理生成的代码。 当涉及软件工程 (SWE) 任务时，大多数人工智能基准测试都包含一组相当有限的策划问题，以及明确定义、可验证的解决方案, no comparable effort exists for full agentic coding sessions. No public dataset captures how developers prompt, steer, override, and ultimately commit (or discard) agent-produced code. When it comes to software engineering (SWE) tasks, most AI benchmarks consist of a fairly limited set of curated problems with well-defined, verifiable solutions(Jimenez et al., 2024; Yang et al., 2024b; Deng et al., 2026; Kottamasu et al., 2026)。 最近的基准测试也关注任务难度. Even more recent benchmarks fixate on task difficulty(Merrill et al., 2026)，但仍然忽略了人机交互维度, but still neglect the human-agent interaction dimension(Wang et al., 2026b)。 但是，在经过精心指导的 GitHub 问题上的出色表现并不能转化为现实世界的迭代使用. But strong performance on curated GitHub issues with meticulous instructions does not translate to real-world, iterative usage(Pan et al., 2025; Wang et al., 2026a)。 人们越来越认识到，下一个前沿领域在于评估代表实际开发特征的协作工作流程的代理. There is growing recognition that the next frontier lies in evaluating agents on the collaborative workflows that characterize actual development(Patwardhan et al., 2025; Cursor Research Team, 2026; Anthropic, 2025; 2026)。 了解开发人员在实践中如何使用编码代理是构建真正有用的代理的先决条件。 收集真实的使用数据是缩小这一差距的唯一方法：. Understanding how developers use coding agents in practice is a prerequisite for building genuinely helpful agents. Collecting real usage data in the wild is the only way to close this gap:

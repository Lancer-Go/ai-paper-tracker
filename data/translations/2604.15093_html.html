Beyond this widening performance gap, the opacity prevents the community from understanding what data properties drive strong performance and generalization—leaving the open-source community unable to study, reproduce, or build upon these advances.

3.1 可扩展的任务合成Scalable Task Synthesis

现有的交互驱动方法将探索与生成紧密结合起来，从个体探索轨迹中得出任务指令，这将指令多样性限制在一个局部轨迹所揭示的范围内。 相反，我们提出了一种受人类如何学习新应用程序启发的解耦范式：首先探索对应用程序功能建立结构化、全面的理解，然后在出现复杂需求时回忆并组合相关功能。 我们的流程分三个阶段反映了这个过程：（i）探索环境以收集交互经验，（ii）将探索数据组织到全局环境内存中Existing interaction-driven approaches tightly couple exploration with generation, deriving task instructions from individual exploration trajectories, which bounds instruction diversity to what one local trajectory reveals. We instead propose a decoupled paradigm inspired by how humans learn a new application: one first explores to build a structured, comprehensive understanding of the app’s capabilities, then recalls and composes relevant functionalities when a complex need arises. Our pipeline mirrors this process in three stages: (i) exploring the environment to collect interaction experience, (ii) organizing the exploration data into a global environment memoryℳ\mathcal{M}，以及（iii）利用短期和长期记忆, and (iii) drawing on short-term and long-term memory fromℳ\mathcal{M}合成组合任务指令。to synthesize compositional task instructions.

有了任务指令，下一步就是收集代理轨迹进行训练。一种直接的方法是专家蒸馏：推出一个强大的模型来生成模仿学习的演示轨迹。 尽管这产生了高质量的轨迹，但它限制了学习者的理想行为，并且无法使其暴露在推理过程中可能犯的错误，从而使代理无法从自己的错误中恢复。 另一种选择是自我进化，学习者迭代地执行任务并按照自己的成功轨迹进行重新训练。 这直接解决了分布不匹配的问题，但收敛速度很慢，因为学习者的进步受到其自身能力的限制。With task instructions in hand, the next step is to collect agent trajectories for training. 6 结论Conclusion

我们提出了 OpenMobile，一个用于构建有竞争力的移动代理的开放数据合成框架。 我们的框架解决了轨迹合成的两个关键方面：（1）将探索与指令生成解耦以产生多样化的高质量任务，以及（2）策略切换推出以通过错误恢复信号丰富轨迹。 经过 OpenMobile 数据训练的智能体可实现强大的性能，并能很好地泛化到未见过的动态环境，从而大大缩小了与封闭数据工业系统的差距。 我们还对合成指令和测试指令之间的重叠进行透明分析，确认这些收益源于广泛的功能覆盖和增强的错误恢复能力，而不是基准过度拟合。 我们发布所有数据和代码，希望 OpenMobile 能够成为更广泛的开放移动代理研究的基础。We presented OpenMobile, an open data synthesis framework for building competitive mobile agents. Our framework addresses two key aspects of trajectory synthesis: (1) decoupling exploration from instruction generation to produce diverse, high-quality tasks, and (2) policy-switching rollout to enrich trajectories with error-recovery signals. Agents trained on OpenMobile data achieve strong performance and generalize well to unseen dynamic environments, substantially narrowing the gap with closed-data industrial systems. We also conduct transparent analyses on the overlap between synthetic and test instructions, confirming that these gains stem from broad functionality coverage and enhanced error-recovery capability rather than benchmark overfitting. We release all data and code with the hope that OpenMobile serves as a foundation for broader open mobile agent research.

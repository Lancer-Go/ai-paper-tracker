1 简介Introduction

大型语言模型越来越多地通过暴露文件、工具、验证器、浏览器状态和长期交互跟踪的执行工具来发挥作用。在这些设置中，适应不仅仅是向模型提出正确的问题。有用的代理必须知道何时检查证据、如何调用工具、如何验证中间输出以及要避免哪些特定于领域的故障模式。最近的代理学习和“技能”系统通过将可重用的程序知识打包到自然语言记忆、可执行技能或在推理时加载的 Markdown 文件中，使这种适应变得明确Large language models increasingly act through execution harnesses that expose files, tools, verifiers, browser state, and long-horizon interaction traces. In these settings, adaptation is not only a matter of asking the model the right question. A useful agent must know when to inspect evidence, how to call tools, how to verify intermediate outputs, and which domain-specific failure modes to avoid. Recent agent-learning and “skill” systems make this adaptation explicit by packaging reusable procedural knowledge into natural-language memories, executable skills, or Markdown files that are loaded at inference time(Shinn et al., 2023; Zhao et al., 2024; Wang et al., 2023; Zhang et al., 2025; Yang et al., 2026).

文本技能有一个重要的优势：它们可读、可编辑，并且易于通过渐进式披露进行路由Textual skills have an important advantage: they are readable, editable, and easy to route through progressive disclosure(Zhang et al., 2025)。它们也有一个重要的限制。文本并不是行为本身。在推理时，模型必须反复内化技能，决定哪些部分对当前实例重要，并将这些指令转换为塑造令牌生成的隐藏状态动态。一项技能可能在语义上正确但效率低下，与模型的内部控制方向不一致，或者过于冗长以至于消耗了上下文和输出预算。. They also have an important limitation. The text is not the behavior itself. At inference time, the model must repeatedly internalize the skill, decide which parts matter for the current instance, and translate those instructions into hidden-state dynamics that shape token generation. A skill may be semantically correct yet inefficient, poorly aligned with the model’s internal control directions, or verbose enough to consume context and output budget.

Rather than optimizing only the external Markdown artifact, we ask whether task-successful answer behavior can be distilled into a compact continuous prefix that remains in the model context. In the main QA setting, the object being compressed is answer style, evidence reliance, and direct final-answer behavior; in the agentic stress test, we additionally probe whether trajectory patterns from successful tool-use examples can be internalized. A soft skill is therefore not a reward model in the usual inference-time sense–it does not score candidate outputs–but a latent behavioral prior that biases generation toward actions and answers that previously received supervision.

During prefix training, saved checkpoints are evaluated on a validation split with the task-level metric used for model selection, and the checkpoint with the best validation score is exported for test evaluation.

这与 SkillOpt 的验证门不同，后者接受或拒绝每个在线提议的文本编辑。在 NTP 设置中，验证不会在不成功的 epoch 后回退训练；它只选择最终的前缀检查点。更严格的基于倒带的门是一种可能的扩展，但它不是主要实验的一部分。This differs from SkillOpt’s validation gate, which accepts or rejects each proposed textual edit online. In the NTP setting, validation does not rewind training after an unsuccessful epoch; it only selects the final prefix checkpoint. A stricter rewind-based gate is a possible extension, but it is not part of the main experiments.

5 分析Analysis

主要结果表明The main results show that软技能SoftSkill可以在单轮任务中用短的学习前缀代替长文本技能。我们现在要问的是如何解释这种行为。该分析分为四个问题：增益是否来自前缀容量，它们是否取决于模型规模或初始化，需要多少监督，以及学习的前缀是否捕获输出格式之外的任务行为。can replace long text skills with a short learned prefix in single-round tasks. The analysis separates four questions: whether the gains come from prefix capacity, whether they depend on model scale or initialization, how much supervision is needed, and whether the learned prefix captures task behavior beyond output formatting.

5.4 局限性和未来方向Limitations and Future Directions

服务和访问。Serving and access.

部署优势The deployment benefit of软技能SoftSkill假设一个服务堆栈可以注入学习到的前缀嵌入。这对于开放或自托管模型来说是现实的，但它使得该方法比 Markdown 技能优化更少黑箱。训练和服务需要访问目标模型的嵌入接口，并且学习的前缀可能与特定的分词器、提示模板、解码设置或推理工具相关联。因此，最安全的部署主张并不是assumes a serving stack that can inject learned prefix embeddings. This is realistic for open or self-hosted models, but it makes the method less black-box than Markdown skill optimization. Training and serving require access to the target model’s embedding interface, and the learned prefix may be tied to a specific tokenizer, prompt template, decoding setup, or inference harness. The safest deployment claim is therefore not that软技能SoftSkill学习通用技能，但它在冻结主干服务路径下提供紧凑的上下文适应。learns a universal skill, but that it provides compact contextual adaptation under a frozen-backbone serving path.

可审计性。Auditability.

学习的前缀比自然语言技能更难检查。一种实际的折衷方案是保留 Markdown 技能作为检索、出处和人工审核的元数据，同时在推理时注入学习到的前缀。在此设计中，文本技能仍然有用，但不应将其视为对连续行为的完整解释。我们的实验还为每个任务使用一种技能，并且不评估多种技能之间的检索，因此渐进式披露部署仍然是一种暗示，而不是直接测试的结果。A learned prefix is harder to inspect than a natural-language skill. One practical compromise is to keep the Markdown skill as metadata for retrieval, provenance, and human audit, while injecting the learned prefix at inference time. In this design, the text skill remains useful, but it should not be treated as a complete explanation of the continuous behavior. Our experiments also use one skill per task and do not evaluate retrieval among many skills, so progressive-disclosure deployment remains an implication rather than a directly tested result.

程序与格式。Procedure versus formatting.

这些实验并没有完全区分稳健的过程学习和答案格式学习。这很重要，因为最强的单轮结果可能部分来自诱导直接答案、短代或特定于基准的提取格式。代理任务更明显地暴露了这种限制：OfficeQA、Spreadsheet 和 ALFWorld 需要多步骤行为，而不是单个最终响应。未来的扰动测试应该改变提示模板、工具名称、观察格式、停止规则和答案提取器，以衡量学习的前缀是否捕获任务过程或主要利用约定。The experiments do not fully distinguish robust procedure learning from answer-format learning. This matters because the strongest single-round results may partly come from inducing direct answers, short generations, or benchmark-specific extraction formats. Agentic tasks expose this limitation more sharply: OfficeQA, Spreadsheet, and ALFWorld require multi-step behavior rather than a single final response. Future perturbation tests should change prompt templates, tool names, observation formats, stopping rules, and answer extractors to measure whether the learned prefix captures task procedure or mainly harness conventions.

转移和组合。Transfer and composition.

与 Markdown 技能不同，连续前缀不能直接跨模型移植。针对一个嵌入空间训练的前缀可能不会转移到另一个嵌入空间，即使在同一模型系列中也是如此。词汇投影传输是一种可能的诊断：将每个源前缀向量映射到源标记上的稀疏分布，然后使用对齐的标记字符串或共享词汇 ID 重建目标前缀。不良转移不会导致无效Unlike Markdown skills, continuous prefixes are not directly portable across models. A prefix trained for one embedding space may not transfer to another, even within the same model family. Vocabulary-projection transfer is one possible diagnostic: map each source prefix vector to a sparse distribution over source tokens, then reconstruct a target prefix using aligned token strings or shared vocabulary IDs. Poor transfer would not invalidate软技能SoftSkill，但它会澄清学习的对象主要是特定于模型的适应，而不是独立于模型的技能。, but it would clarify that the learned object is mostly model-specific adaptation rather than a model-independent skill.

目前的实验还针对每项任务训练一项软技能。它们没有表明软技能在相关任务之间进行组合、路由或转移。更强的版本The present experiments also train one soft skill per task. They do not show that soft skills compose, route, or transfer across related tasks. A stronger version of软技能SoftSkill需要通过串联、插值、路由或学习混合来支持多种技能，并且需要在任务格式发生变化时保留行为。这对于代理设置尤其重要，其中有用的行为可能分布在检索、规划、工具使用、验证和最终答案格式中。would need to support multiple skills through concatenation, interpolation, routing, or learned mixtures, and it would need to preserve behavior when task format changes. This is especially important for agentic settings, where useful behavior may be distributed across retrieval, planning, tool use, verification, and final-answer formatting.

外卖。Takeaway.

该分析支持有针对性的解释。The analysis supports a focused interpretation.软技能SoftSkill对于单轮任务来说，紧凑的上下文适应是有效的：它大大减少了技能上下文的长度，通常可以保留或提高准确性，并且可以在有限的数据设置中与 LoRA 竞争。证据尚未支持更有力的主张，即前缀普遍压缩程序代理技能。代理执行、跨模型传输和组合使用仍然是主要的开放方向。is effective as compact contextual adaptation for single-round tasks: it substantially reduces skill-context length, often preserves or improves accuracy, and can be competitive with LoRA in limited-data settings. The evidence does not yet support a stronger claim that the prefix universally compresses procedural agent skills. Agentic execution, cross-model transfer, and compositional use remain the main open directions.

6 相关工作Related Work

有几项工作研究了如何在没有完整模型重新训练的情况下调整语言模型行为。文本技巧和提示优化方法修改了模型读取的工件；软提示和前缀调整方法修改连续条件向量；基于适配器的方法修改额外的模型参数；基于蒸馏或反馈的方法将行为从演示、展示或偏好转换为可部署的策略或控制信号。Several lines of work study how language-model behavior can be adapted without full model retraining. Textual skill and prompt-optimization methods modify the artifact that the model reads; soft-prompt and prefix-tuning methods modify continuous conditioning vectors; adapter-based methods modify additional model parameters; and distillation or feedback-based methods transfer behavior from demonstrations, rollouts, or preferences into a deployable policy or control signal.软技能SoftSkill位于这些方向的交叉点：它从可重用的自然语言程序知识开始，在保持主干冻结的同时学习一个小的连续对象，并将成功的答案或轨迹压缩为更便宜的可部署形式。因此，我们根据正在优化的表示及其引发的部署接口来回顾相关工作。lies at the intersection of these directions: it starts from reusable natural-language procedural knowledge, learns a small continuous object while keeping the backbone frozen, and compresses successful answers or trajectories into a cheaper deployable form. Our results show that short soft skills can preserve or improve direct-answer QA behavior while replacing substantially longer Markdown skills at inference time.

摘要Abstract

人工智能代理也许能够自动化你的收件箱，但它们能自动化你生活中的其他日常事务吗？ 日常在线任务提供了一个现实但尚未解决的测试平台 用于评估下一代人工智能代理。 为此，我们介绍AI agents may be able to automate your inbox, but can they automate other routine aspects of your life? Everyday online tasks offer a realistic yet unsolved testbed for evaluating the next generation of AI agents. To this end, we introduce爪凳ClawBench，一个由人们在生活和工作中需要定期完成的 153 项简单任务组成的评估框架， 跨越15个类别的144个直播平台， 完成购买和预约 提交工作申请。 这些任务需要超出现有基准的高要求功能，例如从用户提供的文档中获取相关信息、跨不同平台导航多步骤工作流程以及正确填写许多详细表格等大量写入操作。 与使用静态页面评估离线沙箱中的代理的现有基准不同，, an evaluation framework of 153 simple tasks that people need to accomplish regularly in their lives and work, spanning 144 live platforms across 15 categories, from completing purchases and booking appointments to submitting job applications. These tasks require demanding capabilities beyond existing benchmarks, such as obtaining relevant information from user-provided documents, navigating multi-step workflows across diverse platforms, and write-heavy operations like filling in many detailed forms correctly. Unlike existing benchmarks that evaluate agents in offline sandboxes with static pages,爪凳ClawBench在生产网站上运行，保留了现实世界网络交互的全部复杂性、动态性质和挑战。 轻量级拦截层仅捕获并阻止最终提交请求， 确保安全评估，没有现实世界的副作用。 我们对 7 个前沿模型的评估表明， 而开源模型只能完成这些任务的一小部分。 例如，Claude Sonnet 4.6 的成绩仅为 33.3%。 进展情况operates on production websites, preserving the full complexity, dynamic nature, and challenges of real-world web interaction. A lightweight interception layer captures and blocks only the final submission request, ensuring safe evaluation without real-world side effects. 1 简介Introduction

由大型语言模型支持的人工智能代理现在可以自主导航图形界面、填写表单并执行多步骤工作流程AI agents powered by large language models can now navigate graphical interfaces, fill forms, and execute multi-step workflows autonomously(Yao et al., 2023; Wang et al., 2024)，正如 OpenAI Operator 等商业系统所证明的那样, as demonstrated by commercial systems such as OpenAI Operator(OpenAI, 2025)和人为计算机的使用and Anthropic Computer Use(Anthropic, 2025b)，以及开源代理 OpenClaw, and the open-source agent OpenClaw(Steinberger, 2025)。 然而，他们能在多大程度上充当真正的通用在线助手尚不得而知。 要成为总助理，座席需要做的不仅仅是总结电子邮件。 他们需要可靠地处理人们依赖的日常在线任务，例如预订航班、订购杂货和提交工作申请。 这些任务对于人类来说非常简单，通常需要不到三十分钟，但它们涉及具有动态内容、身份验证流程、反机器人防御和不断发展的布局的生产网站。. However, the extent to which they can serve as truly general online assistants is unknown. To be general assistants, agents need to do more than summarize emails. They need to reliably handle the everyday online tasks that people depend on, for example booking flights, ordering groceries, and submitting job applications. These tasks are individually straightforward for a human, typically requiring under thirty minutes, yet they involve production websites with dynamic content, authentication flows, anti-bot defenses, and constantly evolving layouts.

2.3 拦截机制Interception Mechanism

核心设计洞察The central design insight of爪凳ClawBench是在真实网站上评估代理不需要阻止他们与真实网站交互 - 它只需要拦截is that evaluating agents on real websites does not require preventing them from interacting with real websites—it only requires intercepting the决赛final请求。 我们通过轻量级 Chrome 扩展和与代理的浏览器会话一起加载的 CDP 服务器来实现这一点。request. We implement this via a lightweight Chrome extension and a CDP server that is loaded alongside the agent’s browser session.

它是如何运作的。How it works.

检测服务器通过 CDP 连接到浏览器，以根据人工注释的拦截规范监控所有传出的 HTTP 请求（第The instrumentation server connects to the browser through CDP to monitor all outgoing HTTP requests against the human-annotated interception specifications (Section2.1）。 当代理的操作触发与声明的 URL 模式和 HTTP 方法匹配的请求时，系统 (i) 捕获完整的请求正文，包括所有表单字段、有效负载、标头和查询参数； (ii) 在请求离开浏览器之前阻止请求，防止其到达服务器； (iii) 将捕获的有效负载与时间戳和原始标签页 URL 一起记录到本地文件中。 所有其他请求（页面加载、动态内容的 AJAX 调用、图像获取、分析 ping）均未经修改地通过，因此代理体验网站的方式与人类用户完全相同。). When the agent’s action triggers a request matching the declared URL pattern and HTTP method, the system (i) captures the full request body, including all form fields, payloads, headers, and query parameters; (ii) blocks the request before it leaves the browser, preventing it from reaching the server; and (iii) logs the captured payload to a local file alongside a timestamp and the originating tab URL. All other requests—page loads, AJAX calls for dynamic content, image fetches, analytics pings—pass through unmodified, so the agent experiences the website exactly as a human user would.

安全保证。Safety guarantees.

由于拦截信号是在端点级别由人工注释的，而不是通过启发式推断的，因此该机制实现了高精度：在对所有 153 个任务的验证研究中，该扩展在 100% 的人类地面实况运行中正确拦截了终端请求，导航流量的误报率为零。 这种有针对性的方法避免了与让代理在生产服务器上自由操作相关的风险（例如，意外下订单或提交真实应用程序），同时还避免了基于沙箱的替代方案固有的生态有效性损失。Because interception signals are human-annotated at the endpoint level rather than inferred by heuristics, the mechanism achieves high precision: in a validation study over all 153 tasks, the extension correctly intercepted the terminal request in 100% of the human ground-truth runs with zero false positives on navigation traffic. This targeted approach avoids the risks associated with letting agents operate freely on production servers (e.g., accidentally placing orders or submitting real applications) while also avoiding the ecological validity loss inherent in sandbox-based alternatives.

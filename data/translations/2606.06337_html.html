II 背景及相关工作Background and Related Work

Ⅱ-AII-A 上下文窗口降级Context Window Degradation

保尔森Paulsen[1]引入MECW概念， 凭经验证明所有测试的前沿模型 在达到目标之前，多步骤任务的准确性会降低 他们宣传的MCW。 对于MCW = 128,000个代币的模型，MECW可能是 用于复杂编码任务的低至 16,000 个令牌。 这激发了将 16k 代币 MECW 用作运行示例 贯穿本文。introduces the MECW concept, demonstrating empirically that all tested frontier models degrade in accuracy on multi-step tasks before reaching their advertised MCW. For a model with MCW = 128,000 tokens, the MECW may be as low as 16,000 tokens for complex coding tasks. This motivates the 16k-token MECW used as the running example throughout this paper.

刘等人。Liu et al.[9]展示“迷失在 中间”现象：检索和多文档 QA 任务 显示 U 形精度轮廓，内容位于中间 系统地未充分利用长提示。 这放大了有效的降级：即使是内容 名义上适合 MCW 的人可能无法可靠参加。demonstrate the “lost in the middle” phenomenon: retrieval and multi-document QA tasks show U-shaped accuracy profiles, with content in the middle of long prompts systematically under-used. This amplifies the effective degradation: even content that nominally fits within MCW may not be reliably attended.

# Fuzzy match (Definition 5)
def fuzzy_match(a: str, b: str) -> bool:
    a, b = a.lower(), b.lower()
    if a in b or b in a:
        return True
    wa = set(re.findall(r’\w{3,}’, a))
    wb = set(re.findall(r’\w{3,}’, b))
    if not wa or not wb:
        return False
    shorter = wa if len(wa) <= len(wb) else wb
    return len(wa & wb) / len(shorter) >= 0.5

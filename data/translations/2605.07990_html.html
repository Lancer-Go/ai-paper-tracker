3 方法：工具选择的均差指导Method: Mean-Difference Steering for Tool Selection

这个想法很简单。如果不同的工具产生不同的平均激活模式，那么两个工具平均值之间的差异为我们提供了激活空间中从一个工具指向另一个工具的方向。在生成过程中添加该方向应该会改变模型的工具选择。无需培训、无需梯度、无需 SAE；每个工具只需几个示例查询和一个用于收集激活的前向传递。The idea is straightforward. If different tools produce different average activation patterns, then the difference between two tool averages gives us a direction in activation space that points from one tool to another. Adding that direction during generation should switch the model’s tool choice. No training, no gradients, no SAEs required; just a few example queries per tool and one forward pass to collect activations.

由于转向效果是线性的，因此有一种简单的方法可以判断模型何时将选择错误的工具。对于每个工具，我们首先从 2 个示例查询中收集其平均激活：这些查询倒数第二层的残余流的平均值，作为该工具的代表方向。然后，对于新查询，我们测量查询的激活与每个工具的均值之间的余弦相似度。如果前两个工具的得分非常相似（差距很小），则模型会在它们之间撕裂，并且更有可能出错。如果一种工具明显领先（差距很大），则模型已经做出了明确的决定，并且通常是正确的。Because the steering effect is linear, there is a simple way to tell when the model is about to pick the wrong tool. For each tool, we first collect its mean activation from 2 example queries: the average of the residual stream at the penultimate layer across those queries, which serves as that tool’s representative direction. Then, for a new query, we measure cosine similarity between the query’s activation and each tool’s mean. If the top two tools have very similar scores (a small gap), the model is torn between them and much more likely to make a mistake. If one tool is clearly ahead (a large gap), the model has made a clear decision and is usually right.

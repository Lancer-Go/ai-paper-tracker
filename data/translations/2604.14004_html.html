记忆迁移学习：Memory Transfer Learning:
编码代理中的内存如何跨域传输How Memories are Transferred Across Domains in Coding Agents

Kangsan Kim    Minki Kang    Taeil Kim    Yanlai Yang    Mengye Ren    Sung Ju Hwang
摘要Abstract

基于记忆的自我进化已经成为编码代理的一个有前途的范例。然而，现有方法通常将内存利用率限制在同质任务域，无法利用跨不同现实世界编码问题存在的共享基础设施，例如运行时环境和编程语言。 为了解决这个限制，我们调查了Memory-based self-evolution has emerged as a promising paradigm for coding agents. However, existing approaches typically restrict memory utilization to homogeneous task domains, failing to leverage the shared infrastructural foundations, such as runtime environments and programming languages, that exist across diverse real-world coding problems. To address this limitation, we investigate记忆迁移学习Memory Transfer Learning(MTL) 通过利用来自异构域的统一内存池。我们使用四种内存表示（从具体痕迹到抽象见解）评估 6 个编码基准的性能。 我们的实验表明，跨域内存将平均性能提高了 3.7%，主要是通过传输元知识（例如验证例程）而不是特定于任务的代码。 重要的是，我们发现抽象决定了可转移性；高层次的见解可以很好地概括，而低层次的痕迹往往会由于过度的特异性而引起负迁移。 此外，我们还表明传输有效性随内存池的大小而变化，并且内存甚至可以在不同模型之间传输。 我们的工作建立了经验设计原则，用于将内存利用率扩展到单域孤岛之外。(MTL) by harnessing a unified memory pool from heterogeneous domains. We evaluate performance across 6 coding benchmarks using four memory representations, ranging from concrete traces to abstract insights. Our experiments demonstrate that cross-domain memory improves average performance by 3.7%, primarily by transferring meta-knowledge, such as validation routines, rather than task-specific code. Importantly, we find that abstraction dictates transferability; high-level insights generalize well, whereas low-level traces often induce negative transfer due to excessive specificity. Furthermore, we show that transfer effectiveness scales with the size of the memory pool, and memory can be transferred even between different models. Our work establishes empirical design principles for expanding memory utilization beyond single-domain silos.

1 简介Introduction

随着语言模型中扩展训练数据带来的性能提升开始趋于稳定，自我进化（利用先前的推理结果来增强未来的性能而无需额外的监督）已成为提升智能体模型能力的有前途的范例As performance gains from scaling training data in language models begin to plateau, self-evolution, which leverages prior inference outcomes to enhance future performance without additional supervision, has emerged as a promising paradigm for advancing model capabilities in agents(Gao et al., 2025; Fang et al., 2025a)。 记忆在自我进化代理中发挥着核心作用，它能够从过去的推论中提取可重用的工作流程和可转移的见解，并将其应用到后续任务中. Memory plays a central role in self-evolving agents by enabling the extraction of reusable workflows and transferable insights from past inferences and their application to subsequent tasks(Zheng et al., 2024; Wang et al., 2024c; Ouyang et al., 2025)。 在编码代理中，内存被实例化为代码片段、经验知识（包括规划和调试跟踪）或一般编程原理. In coding agents, the memory is instantiated as code snippets, experiential knowledge including planning and debugging traces, or general programming principles(Yang et al., 2024)。 利用这些知识，代理可以在类似任务中引用成功的解决方案模式，从而减少推理开销，同时还可以通过遵守累积的程序和战略指导（例如小步修改启发式和验证例程）来避免长期代码编辑中不必要的失败操作。. Leveraging this knowledge allows agents to reference successful solution patterns in similar tasks, thereby reducing reasoning overhead, while also avoiding unnecessary failure actions in long-horizon code editing through adherence to accumulated procedural and strategic guidance, such as small-step modification heuristics and verification routines.

我们的分析得出了记忆转移机制的三个核心发现。Our analysis yields three core findings into the mechanism of memory transfer.首先，跨域显着提高了编码代理的性能。First, cross-domain significantly improve the performance of coding agents.尽管现有的自我进化方法经常忽视域外记忆，但我们的结果表明，有效的记忆利用应该结合所有过去的经验，包括来自不同领域的经验，以提高智能体的性能，如图所示Although existing self-evolving methods often overlook out-of-domain memories, our results suggest that effective memory utilization should incorporate all past experiences, including those from different domains, to enhance agent performance, as shown inFigure 1（四）。(D).其次，主要的可转移价值在于元知识。Second, the primary transferable value lies in meta-knowledge.通过定性分析，我们发现跨任务的好处不是来自特定于任务的代码内容，而是来自操作技巧，例如在环境限制下防止执行失败，以及优先考虑结构和接口检查，然后进行严格的验证程序的任务解决例程。Through qualitative analysis, we find that cross-task benefits stem not from task-specific code content but from operational know-how, such as preventing execution failures under environment constraints and task-solving routines that prioritize structural and interface inspection followed by strict validation procedures.第三，抽象决定了可转移性。Third, abstraction dictates transferability.通过量化每种内存格式的抽象级别，我们发现高级抽象和传输效率之间存在正相关性。 高度抽象的记忆，例如洞察力，变得与任务无关并且具有普遍性。 相比之下，像轨迹这样的低抽象记忆保留了过多的特定于任务的细节，这些细节可能会分散代理的注意力，从而确认原始执行跟踪不太适合跨任务传输。 此外，我们还提供了有关内存迁移学习的更多见解，包括为什么会发生负迁移、MTL 的性能增益如何随着更大的内存池和更多域而扩展，以及跨不同模型传输内存的潜力。By quantifying the abstraction level of each memory format, we discover a positive correlation between high-level abstraction and transfer effectiveness. Highly abstract memories, such as Insights, become task-agnostic and generalizable. In contrast, low-abstraction memories like Trajectories retain excessive task-specific details that can distract the agent, confirming that raw execution traces are less suitable for cross-task transfer. Furthermore, we provide additional insights into Memory Transfer Learning, including why negative transfer occurs, how the performance gain of MTL scales with a larger memory pool and more domains, and the potential for transferring memories across different models.

总之，这项工作首次对记忆迁移学习进行了全面的研究。 重要的是，通过对六个编码基准的广泛评估，我们表明现有代理的内存使用方法（专注于同质域）是有限的，并且通过利用异构域的内存还有很大的改进空间。 我们希望这项研究将内存利用的范围扩展到单域设置之外，并激发对如何在自我进化代理中有效利用内存的进一步研究，最终导致更强大的编码代理。In conclusion, this work presents a first holistic investigation of Memory Transfer Learning. Importantly, through extensive evaluation on six coding benchmarks, we show that existing agents’ memory usage methods, which focus on a homogeneous domain, are limited, and that there is significant room for improvement by leveraging memories from heterogeneous domains. We hope this study expands the scope of memory utilization beyond single-domain settings and stimulates further research on how to effectively leverage memory in self-evolving agents, ultimately leading to more capable coding agents.

5 结论Conclusion

在这项工作中，我们首次对编码代理的内存迁移学习进行了整体研究，挑战了内存利用率必须仅限于同质任务域的普遍假设。 通过对 6 个不同基准的广泛评估，我们证明利用异构域的统一内存池可以将代理性能提高 3.7%。 我们的分析得出了跨域内存的三个关键设计原则。 首先，我们发现转移记忆的主要价值在于元知识而不是特定于任务的工作流程。 其次，我们发现抽象决定了可转移性；像洞察力这样的高级抽象可以有效地跨领域推广，而低级轨迹通常会由于脆弱的实现锚定而导致负迁移。 第三，我们强调内存传输的有效性随着内存池的大小和多样性而变化，从而增加了检索有用元知识的可能性。 我们希望这项研究为将内存利用率扩展到单域设置之外奠定了经验基础，并激发对自我进化编码代理的稳健内存使用策略的进一步研究。In this work, we presented the first holistic investigation into Memory Transfer Learning for coding agents, challenging the prevailing assumption that memory utilization must be limited to homogeneous task domains. Through extensive evaluation across 6 diverse benchmarks, we demonstrated that leveraging a unified memory pool from heterogeneous domains can enhance agent performance by 3.7%. Our analysis yields three critical design principles for cross-domain memory. First, we identified that the primary value of transferred memory lies in meta-knowledge rather than task-specific workflows. Second, we found that abstraction dictates transferability; high-level abstractions like Insights generalize effectively across domains, whereas low-level Trajectories often induce negative transfer due to brittle implementation anchoring. Third, we highlighted that the effectiveness of memory transfer scales with the size and diversity of the memory pool, increasing the likelihood of retrieving useful meta-knowledge. We hope this study establishes empirical foundations for expanding memory utilization beyond single-domain settings and stimulates further research into robust memory usage strategies for self-evolving coding agents.

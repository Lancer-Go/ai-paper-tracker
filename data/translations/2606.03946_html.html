摘要。Abstract.

数据库供应商最近发布了可用于过滤谓词的人工智能函数。由于此类功能通常依赖于成本高昂的黑盒机器学习模型，因此它们带来了新的数据管理挑战。具体而言，针对整数和字符串数据的传统数据跳过技术无法适用于新的过滤器类型。 事实上，没有已知的机制来修剪不合格的行组，例如，当从 blob 存储读取文件时。Database vendors recently released AI functions that can be used in filter predicates. As such functions often rely on costly, black-box ML models, they unveil new data management challenges. Concretely, traditional data skipping techniques for integer and string data fail to be applicable to the new filter type. Indeed, there is no known mechanism for pruning non-qualifying row groups, e.g., when reading files from blob storage.

在这项工作中，我们开始研究机器学习过滤器的数据跳跃技术。我们证明 Parquet 的默认最小-最大元数据足以启用修剪。 为此，我们将两条研究方向联系起来：（i）最近提出的机器学习模型查询语言和（ii）神经网络验证。In this work, we initiate the study of data skipping techniques for ML filters. We make the case that Parquet’s default min-max metadata is enough to enable pruning. To this end, we draw connections to two lines of research: (i) the recently proposed query language for ML models and (ii) neural network verification.

我们对 ReLU 架构的初步结果表明，在 TPC-H 和 TPC-DS 的表上，选择性低于 0.1% 的过滤器的平均剪枝效率达到 27.4%。 最后，受空间连接研究的启发，我们提出了一种增强的元数据结构：验证工具可以更好地利用大小有界的二维凸包，将剪枝效率提高到 38.31％，同时每个行组和列对最多占用 45 个字节。我们观察到端到端加速为 1.07Our preliminary results on ReLU architectures show that on tables from TPC-H and TPC-DS, the average pruning effectiveness for filters of selectivity below 0.1% amounts to 27.4%. Finally, inspired by research on spatial joins, we propose an enhanced metadata structure: a size-bounded 2D convex hull that verification tools can make better use of, increasing the pruning effectiveness to 38.31%, while occupying at most 45 bytes per row group and column pair. 2.3. ML 模型的查询语言Query Languages for ML Models

最近的工作表明 SQL 可以作为神经网络的查询语言 网络Recent work has shown that SQL can act as a query language for neural networks(Grohe et al., 2025)。通过表示网络的结构和 作为数据库实例的权重，SQL 可以推理网络并验证其 行为。我们实施了这个范例 作为一种两步方法，我们称之为 ML-QL。首先，ML-QL 将网络编译为 几何表示并将其存储在数据库中。然后我们用这个 预先计算的表示来执行许多 与传统工具不同，SQL 中的验证查询相对便宜 完全在查询时运行. By representing a network’s structure and weights as a database instance, SQL can reason about the network and verify its behavior. We implemented this paradigm as a two-step approach, which we call ML-QL. First, ML-QL compiles the network to a geometric representation and stores it in a database. We then use this precomputed representation to execute many verification queries in SQL relatively cheaply, unlike traditional tools that run entirely at query time(Katz et al., 2017).

我们考虑具有 ReLU 激活函数和单个 输出节点。这样的网络代表分段线性函数。 在几何上，ReLU 层将连续输入空间划分为 超平面排列：网络行为的多面体区域的集合 作为每个不同区域内的仿射函数。We consider feed-forward networks with ReLU activation functions and a single output node. Such networks represent piecewise linear functions. Geometrically, the ReLU layers partition the continuous input space into a hyperplane arrangement: a collection of polyhedral regions where the network behaves as an affine function within each distinct region.

凸包ConvexHull.第一个想法是构建二维数据点的凸包。 直觉是，由 2D 最小-最大范围引起的拐角周围的区域未被占用，从而导致输入域更小。 然而，普通凸包的缺点是我们无法限制存储顶点的数量，导致元数据大小（和验证时间）不可预测。The first idea is to build a convex hull of the two-dimensional data points.

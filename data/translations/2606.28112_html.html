1University of Electronic Science and Technology of China
*Equal contribution.

摘要Abstract

退化感知提示、条件和潜在先验越来越多地用于图像恢复中，但它们通常由单一端点来判断：恢复的图像是否获得更高的 PSNR。这是语义的弱测试。条件可以通过增加容量、充当全局校正偏差或利用数据集快捷方式来提供帮助，而不会成为可解释的退化先验。我们提出了 BiDeMem，一种用于可解释图像恢复的双向退化存储器。根据恢复特征和输入统计数据构建的查询检索紧凑的顶部Degradation-aware prompts, conditions, and latent priors are increasingly used in image restoration, yet they are usually judged by a single endpoint: whether the restored image obtains higher PSNR. This is a weak test of semantics. A condition can help by adding capacity, acting as a global correction bias, or exploiting dataset shortcuts, without becoming an interpretable degradation prior. We propose BiDeMem, a bidirectional degradation memory for explainable image restoration. A query built from restoration features and input statistics retrieves a compact top-kk内存插槽的子集。相同的选定时隙标识支持推理时的恢复路径和仅训练的前向降级解释路径。该研究的重点是受控多退化 NAFNet 设置中的可验证性。新的控制将增益与单独的校正头、密集查询先验和静态全局先验分开：这些变体分别比 BiRank 低 0.2588、0.2586 和 0.2839 dB。强大的残差监督和更宽的降级头也仍然低于完整的双向内存模型。干预探索表明，BiRank 保留了恢复质量，同时增加了错误先验和本机先验敏感性，将退化记忆构建为恢复模块和可证伪的解释机制。subset of memory slots. The same selected slot identity supports the restoration path at inference time and a training-only forward-degradation explanation path. The study centers on verifiability in a controlled multi-degradation NAFNet setting. New controls separate the gain from a correction head alone, a dense query prior, and a static global prior: these variants are 0.2588, 0.2586, and 0.2839 dB below BiRank, respectively. Strong residual supervision and a wider degradation head also remain below the full bidirectional memory model. Intervention probes show that BiRank preserves restoration quality while increasing wrong-prior and native-prior sensitivity, framing degradation memory as both a restoration module and a falsifiable explanation mechanism.

1 简介Introduction

图像恢复旨在从因噪声、雾霾、雨水、压缩、模糊或其混合而退化的观测中恢复清晰的图像。这是一个核心的低级视力问题，因为修复质量直接影响人类感知和下游视觉系统。现代恢复网络通过改进主干架构、扩大感受野以及学习泛化一系列腐败的恢复算子，取得了长足的进步Image restoration aims to recover a clean image from observations degraded by noise, haze, rain, compression, blur, or their mixtures. It is a central low-level vision problem because restoration quality directly affects both human perception and downstream visual systems. Modern restoration networks have achieved strong progress by improving backbone architectures, enlarging receptive fields, and learning restoration operators that generalize across a range of corruptions[45, 21, 40, 42, 43, 3]。最近的盲和多退化系统进一步引入了退化感知条件，包括提示、潜在表示、对比代码和记忆状态，以便一个模型可以使其恢复行为适应不同的输入退化. Recent blind and multi-degradation systems further introduce degradation-aware conditions, including prompts, latent representations, contrastive codes, and memory states, so that one model can adapt its restoration behavior to different input degradations[22, 35, 30].

这些降级感知条件很有用，但它们的语义作用通常是间接评估的。在许多恢复论文中，当最终恢复的图像获得更高的 PSNR 或 SSIM 时，条件被视为有意义。这种终点评估留下了几个未解决的替代方案。条件可以编码退化证据，但它也可以充当额外的模型容量、全局校正偏差、密集提示向量或特定于数据集的快捷方式。对于可解释的退化先验，更强的评估应该询问先验是否是输入对齐的，错误的先验是否会损害恢复，是否只有选定的内存插槽重要，以及同一路线是否可以支持从干净目标到退化观察的相反方向的训练信号。These degradation-aware conditions are useful, but their semantic role is often evaluated indirectly. In many restoration papers, a condition is treated as meaningful when the final restored image obtains higher PSNR or SSIM. Such endpoint evaluation leaves several alternatives unresolved. A condition may encode degradation evidence, yet it may also act as extra model capacity, a global correction bias, a dense prompt vector, or a dataset-specific shortcut. For an explainable degradation prior, a stronger evaluation should ask whether the prior is input-aligned, whether a wrong prior damages restoration, whether only the selected memory slots matter, and whether the same route can support a training signal in the reverse direction from clean target to degraded observation.

我们提出了 BiDeMem，一种用于可解释图像恢复的双向退化存储器。该方法根据恢复瓶颈特征和简单的输入统计数据构建证据引导的查询，检索紧凑的顶部We propose BiDeMem, a bidirectional degradation memory for explainable image restoration. The method builds an evidence-guided query from restoration bottleneck features and simple input statistics, retrieves a compact top-kk内存插槽的子集，并使用选定的插槽标识来条件恢复。在推理期间，所选时隙调制恢复解码器和时隙路由校正头。在训练过程中，相同的选定槽位身份还决定了前向降级一致性分支，该分支从干净的目标重建降级的观察结果。这种双向设计将检索到的槽标识转变为可审计对象：活动槽可以被屏蔽、替换、洗牌、与非本机先验进行比较，并在统一或零内存干预下进行测试。subset of memory slots, and uses the selected slot identity to condition restoration. During inference, the selected slots modulate the restoration decoder and a slot-routed correction head. During training, the same selected slot identity also conditions a forward-degradation consistency branch that reconstructs the degraded observation from the clean target. This bidirectional design turns the retrieved slot identity into an auditable object: the active slots can be masked, replaced, shuffled, compared against non-native priors, and tested under uniform or zero-memory interventions.

我们在 NAFNet 上构建的受控多重降级设置中评估 BiDeMem。目标是测试紧凑的退化存储器在明确的控制下是否有用且可验证。 BiRank Memory 在八个基准测试中获得了 29.7529 dB / 0.8865 的平均 PSNR/SSIM，而仅校正头、密集先验和静态/全局先验控制分别低了 0.2588、0.2586 和 0.2839 dB。更重要的是，双向训练提高了干预敏感性：错误先验下降从 Rank Memory 的 0.2365 dB 上升到 BiRank Memory 的 1.0430 dB，本机/非本机先验差距从 0.3484 dB 上升到 0.6134 dB。额外的看不见/混合测试、低数据适应、效率测量和外部骨干检查定义了该方法的有用范围和当前限制。We evaluate BiDeMem in a controlled multi-degradation setting built on NAFNet. The goal is to test whether compact degradation memory is useful and verifiable under clear controls. BiRank Memory obtains 29.7529 dB / 0.8865 average PSNR/SSIM over eight seen benchmarks, while correction-head-only, dense-prior, and static/global-prior controls are 0.2588, 0.2586, and 0.2839 dB lower, respectively. More importantly, bidirectional training increases intervention sensitivity: the wrong-prior drop rises from 0.2365 dB for Rank Memory to 1.0430 dB for BiRank Memory, and the native/non-native prior gap rises from 0.3484 dB to 0.6134 dB. Additional unseen/mixed tests, low-data adaptation, efficiency measurements, and external-backbone checks define the useful scope and current limitations of the method.

5 讨论和限制Discussion and Limitations

BiDeMem 从验证的角度而不是仅从端点恢复质量的角度研究退化记忆。受控 NAFNet 结果表明，紧凑的顶部BiDeMem studies degradation memory from the perspective of verification rather than endpoint restoration quality alone. The controlled NAFNet results show that a compact top-kk记忆可以提供有用的先验恢复，而干预结果表明，检索到的路线对错误的、打乱的和非本地先验非常敏感。这种组合对于可解释的恢复非常重要：内存不仅是改善输出图像的调节向量，而且还是可以测试其行为的可寻址路径。memory can provide a useful restoration prior, while the intervention results show that the retrieved route is measurably sensitive to wrong, shuffled, and non-native priors. This combination is important for explainable restoration: the memory is not only a conditioning vector that improves an output image, but also an addressable route whose behavior can be tested.

双向设计为该路线添加了可解释性约束。通过要求相同的选定槽标识来支持恢复和仅训练的前向降级解释，BiRank Memory 使内存路径更具可审计性。此约束并非旨在最大化每种设置中的 PSNR；解耦恢复和降级时隙可能有助于补充分析或特定于任务的优化。共享身份的优点是反事实探测评估恢复所使用的相同路径，使学习到的先验更容易检查。The bidirectional design adds an interpretability constraint to this route. By asking the same selected slot identity to support restoration and a training-only forward degradation explanation, BiRank Memory makes the memory pathway more auditable. This constraint is not intended to maximize PSNR in every setting; decoupling restoration and degradation slots may be useful for supplementary analysis or task-specific optimization. The advantage of the shared identity is that counterfactual probes evaluate the same route used by restoration, making the learned prior easier to inspect.

目前的设计也有明显的局限性。 BiDeMem 参数紧凑，但计算效率不高：内存和校正头会增加相对于基础网络的延迟。此外，紧凑的全局槽设计可能不是每个恢复骨干或退化混合物的最佳形式。这些限制表明，当前模型应被视为面向验证的退化内存设计，而不是通用恢复算子。The current design also has clear limitations. BiDeMem is parameter-compact but not compute-efficient: the memory and correction heads add latency relative to the base network. In addition, the compact global slot design may not be the best form for every restoration backbone or degradation mixture. These limitations indicate that the present model should be viewed as a verification-oriented degradation-memory design, not as a universal restoration operator.

AirNet 和 PromptIR 检查提供了令人鼓舞的但仍依赖于设置的外部证据。 BiRank 内存在所有四种外部设置中都比匹配的基础和容量控制变体提高了 PSNR，这表明双向内存在联合适应时可以超越 NAFNet。同时，增益因主干网和训练设置而异，划痕控制仍然具有竞争力，并且 SSIM 并不总是通过 BiRank 内存最大化。因此，未来的工作应该研究骨干感知内存大小、插入点和训练目标，以在提高效率的同时保持可验证性。The AirNet and PromptIR checks provide encouraging but still setting-dependent external evidence. BiRank Memory improves PSNR over the matched base and capacity-control variants in all four external settings, suggesting that bidirectional memory can transfer beyond NAFNet when jointly adapted. At the same time, the gains vary across backbones and training settings, scratch controls remain competitive, and SSIM is not always maximized by BiRank Memory. Future work should therefore study backbone-aware memory size, insertion points, and training objectives that preserve verifiability while improving efficiency.

6 结论Conclusion

我们引入了 BiDeMem，一种用于可解释图像恢复的双向退化存储器。该方法检索紧凑的顶部We introduced BiDeMem, a bidirectional degradation memory for explainable image restoration. The method retrieves compact top-kk来自可观察退化证据的内存插槽，并使用相同的选定插槽身份来条件恢复和仅训练的前向退化解释分支。通过受控恢复、机制控制、干预探测、低数据适应和外部主干检查，结果支持以验证为导向的退化先验观点：有用的先验应该改善恢复，与输入退化保持一致，并在反事实干预下做出可预测的响应。 BiDeMem 并非旨在作为最终的通用恢复骨干；相反，它提供了一个具体的设计和评估协议，使退化内存可审计。我们希望这种观点鼓励未来的恢复模型将学习到的退化条件视为可测试的对象，而不仅仅是作为提高端点图像质量的潜在变量。memory slots from observable degradation evidence and uses the same selected slot identity to condition restoration and a training-only forward degradation explanation branch. Across controlled restoration, mechanism controls, intervention probes, low-data adaptation, and external backbone checks, the results support a verification-oriented view of degradation priors: a useful prior should improve restoration, remain aligned with the input degradation, and respond predictably under counterfactual interventions. BiDeMem is not intended as a final all-purpose restoration backbone; rather, it provides a concrete design and evaluation protocol for making degradation memory auditable. We hope this perspective encourages future restoration models to treat learned degradation conditions as testable objects, not only as latent variables that improve endpoint image quality.

The first is方向稳定性Direction Stability。由于每次迭代仅观察来自有限一组案例的反馈，因此连续的修订可能会集中于不同的问题并相互抵消。例如，一项修订可能会指示代理通过选择最便宜的可行行程来最小化总成本。稍后的修订可能会增加更多景点以产生更丰富的旅行计划，但这些增加可能会增加成本并违反先前的预算限制。因此，新的修订必须与早期迭代中积累的有效修正保持一致。第二个挑战是. Since each iteration observes feedback from only a limited set of cases, successive revisions may focus on different problems and undo one another. For example, one revision may instruct the agent to minimize the total cost by selecting the cheapest feasible itinerary. A later revision may add more attractions to produce a richer travel plan, but these additions can increase the cost and violate the earlier budget constraint. New revisions must therefore remain consistent with effective corrections accumulated in earlier iterations. The second challenge is更新适应性Update Adaptivity。适当的编辑范围应取决于最近的修订对评估案例的影响程度。如果一次修订改善了某些情况，但降低了其他情况，则广泛的后续编辑可能会覆盖有用的指导，因此应受到限制。如果不同案例的收益一致，则可以更好地支持更广泛的编辑。. The appropriate edit scope should depend on how consistently a recent revision affects the evaluated cases. If one revision improves some cases but degrades others, a broad subsequent edit risks overwriting useful guidance and should therefore be constrained. If the gains are consistent across cases, a broader edit is better supported.

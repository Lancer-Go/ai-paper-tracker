摘要Abstract

代码反编译分析是恶意软件逆向工程中一项基本但具有挑战性的任务，特别是由于复杂的混淆技术的普遍使用。尽管最近的大型语言模型（LLM）在将低级表示转换为高级源代码方面表现出了希望，但大多数现有方法依赖于通用代码预训练并且缺乏对恶意软件的适应。我们建议Code decompilation analysis is a fundamental yet challenging task in malware reverse engineering, particularly due to the pervasive use of sophisticated obfuscation techniques. Although recent large language models (LLMs) have shown promise in translating low-level representations into high-level source code, most existing approaches rely on generic code pretraining and lack adaptation to malicious software. We proposeLLM4代码RELLM4CodeRE，一个用于双向代码逆向工程的领域自适应LLM框架，支持统一模型内的程序集到源代码的反编译和源代码到程序集的转换。为了实现有效的任务适应，我们引入了两种互补的微调策略：（i）用于特定于任务的句法和语义对齐的多适配器方法，以及（ii）使用任务条件前缀来强制端到端生成约束的 Seq2Seq 统一方法。实验结果表明，LLM4CodeRE 的性能优于现有的反编译工具和通用代码模型，实现了稳健的双向泛化。, a domain-adaptive LLM framework for bidirectional code reverse engineering that supports both assembly-to-source decompilation and source-to-assembly translation within a unified model. To enable effective task adaptation, we introduce two complementary fine-tuning strategies: (i) a Multi-Adapter approach for task-specific syntactic and semantic alignment, and (ii) a Seq2Seq Unified approach using task-conditioned prefixes to enforce end-to-end generation constraints. Experimental results demonstrate that LLM4CodeRE outperforms existing decompilation tools and general-purpose code models, achieving robust bidirectional generalization.

I 简介Introduction

可移植可执行 (PE) 文件（包括良性软件和恶意软件）的逆向工程仍然是网络安全中的基本挑战。现代恶意软件的快速发展（其特点是普遍的混淆、打包和多态性）使得自动代码反编译成为一个关键但基本上尚未解决的问题。逆向工程师必须定期将低级表示（例如汇编代码或原始二进制文件）转换为高级、人类可读的源代码，以便理解程序语义、发现恶意意图并开发有效的防御签名。Reverse engineering of portable executable (PE) files, including both benign software and malware, remains a fundamental challenge in cybersecurity. The rapid evolution of modern malware—characterized by pervasive obfuscation, packing, and polymorphism—has made automated code decompilation a critical yet largely unresolved problem. Reverse engineers must routinely translate low-level representations, such as assembly code or raw binaries, into high-level, human-readable source code in order to understand program semantics, uncover malicious intent, and develop effective defensive signatures.

尽管基于 Transformer 的 NLP 模型具有强大的语义建模能力，但逆向工程流程仍然很大程度上依赖于传统的静态和动态分析技术，这些技术是劳动密集型的、在混淆情况下很脆弱且难以扩展。即使是最先进的反编译器也难以应对恶意软件常用的剥离符号、扁平化控制流和动态 API 解析Despite the strong semantic modeling capabilities of transformer-based NLP models, reverse engineering pipelines still rely largely on traditional static and dynamic analysis techniques, which are labor-intensive, brittle under obfuscation, and difficult to scale. Even state-of-the-art decompilers struggle with stripped symbols, flattened control flow, and dynamic API resolution commonly used by malware[19, 20]，激发了对直接建模低级代码语义的领域自适应学习框架的需求。, motivating the need for domain-adaptive learning frameworks that directly model low-level code semantics.

生成式人工智能模型，特别是法学硕士，通过将代码视为自然语言，在程序翻译和代码理解方面取得了有希望的进展Generative AI models, particularly LLMs, have enabled promising advances in program translation and code understanding by treating code as natural language[3, 8, 21]。然而，大多数基于 LLM 的反编译方法依赖于通用代码预训练，并将恶意软件视为未分发，从而限制了它们捕获特定于恶意软件的混淆和反分析模式的能力，并降低了网络安全设置的可靠性. However, most LLM-based decompilation methods rely on generic code pretraining and treat malware as out-of-distribution, limiting their ability to capture malware-specific obfuscation and anti-analysis patterns and reducing reliability in cybersecurity settings[7].

在这项工作中，我们认为有效的基于 GenAI 的逆向工程和反编译需要针对良性和恶意软件明确定制的特定领域的表示学习和参数高效的任务适应。事实上，我们引入了 LLM4CodeRE，这是一种用于双向代码逆向工程的领域自适应 LLM 框架，支持统一模型内的程序集到源代码反编译和源代码到程序集转换。In this work, we argue that effective GenAI-based reverse engineering and decompilation require domain-specific representation learning and parameter-efficient task adaptation explicitly tailored to both benign and malicious software. In fact, we introduce LLM4CodeRE, a domain-adaptive LLM framework for bidirectional code reverse engineering that supports both assembly-to-source decompilation and source-to-assembly translation within a unified model.

通过在反汇编的恶意软件二进制文件和反编译的伪代码的大规模语料库上预训练主干模型，我们将模型暴露给混淆技术、反调试逻辑和恶意程序特有的恶意软件特定 API 使用模式。受到代码模型领域自适应预训练最新进展的启发By pretraining the backbone model on large-scale corpora of disassembled malware binaries and decompiled pseudo-code, we expose the model to obfuscation techniques, anti-debugging logic, and malware-specific API usage patterns that are characteristic of malicious programs. Inspired by recent advances in domain-adaptive pretraining for code models[11]，LLM4CodeRE 将此范例扩展到恶意软件领域，据我们所知，它是第一个明确针对恶意二进制文件进行基于 LLM 反编译的框架。, LLM4CodeRE extends this paradigm to the malware domain and, to the best of our knowledge, is the first framework to explicitly target malicious binaries for LLM-based decompilation.

此外，我们使用统一的评估协议评估双向代码转换任务上的LLM4CodeRE，包括汇编到源代码（Asm→Src）和源代码到汇编（Src→Asm），该协议测量三个互补维度：（i）语义相似性，（ii）结构编辑相似性，以及（iii）沙盒环境中生成的代码的可重新执行性。与主要关注静态相似性度量的先前工作不同Moreover, we evaluate LLM4CodeRE on bidirectional code transformation tasks, including Assembly-to-Source (Asm→Src) and Source-to-Assembly (Src→Asm), using a unified evaluation protocol that measures three complementary dimensions: (i) semantic similarity, (ii) structural edit similarity, and (iii) re-executability of generated code in a sandboxed environment. Unlike prior work that focuses primarily on static similarity metrics[18, 16]，我们的评估明确测试生成的程序是否可以正确编译和执行，这对于现实世界的恶意软件分析和逆向工程工作流程至关重要。 我们的贡献可概括如下：, our evaluation explicitly tests whether generated programs can be compiled and executed correctly, which is essential for real-world malware analysis and reverse engineering workflows. II 相关工作Related Work

Ⅱ-AII-A 恶意软件反编译和逆向工程Malware Decompilation and Reverse Engineering

恶意软件二进制文件的分析和反编译长期以来一直是网络安全的核心挑战。传统方法依赖于静态分析技术，例如控制流图提取、函数调用图重建和 API 使用分析The analysis and decompilation of malware binaries has long been a central challenge in cybersecurity. Traditional approaches rely on static analysis techniques such as control-flow graph extraction, function call graph reconstruction, and API usage profiling[19, 20]。动态分析框架在沙盒环境中执行可疑的二进制文件，以观察运行时行为并识别恶意模式。虽然在受控环境中有效，但这些方法在混淆、打包和反分析技术下通常很脆弱，并且需要专家分析人员的大量手动工作。因此，他们很难适应现代恶意软件的数量和多样性. Dynamic analysis frameworks execute suspicious binaries in sandboxed environments to observe runtime behavior and identify malicious patterns. While effective in controlled settings, these methods are often brittle under obfuscation, packing, and anti-analysis techniques, and they require substantial manual effort from expert analysts. As a result, they struggle to scale to the volume and diversity of modern malware[7].

Ⅱ-BII-B 代码理解和生成法学硕士LLMs for Code Understanding and Generation

大型语言模型的最新进展极大地改进了自动化代码理解和生成。 CodeBERT 等模型Recent advances in large language models have substantially improved automated code understanding and generation. Models such as CodeBERT[3]和Qwen2.5-Coderand Qwen2.5-Coder[8]在代码摘要、翻译和综合等任务上表现良好，指令调整进一步增强代码推理perform well on tasks including code summarization, translation, and synthesis, with instruction tuning further enhancing code reasoning[21]。然而，大多数法学硕士都是在良性开源代码上进行预训练的，并没有明确适应恶意软件的统计和语义特征. However, most LLMs are pretrained on benign open-source code and are not explicitly adapted to the statistical and semantic characteristics of malicious software[11].

Ⅱ-CII-C 反编译和低级代码翻译法学硕士LLMs for Decompilation and Low-Level Code Translation

最近的工作将LLM应用于反编译和低级代码翻译，包括LLM4DecompileRecent work applies LLMs to decompilation and low-level code translation, including LLM4Decompile[18], 瓦德克, WADEC[16]和 ASMA-Tune, and ASMA-Tune[21]。虽然这些方法证明了基于 LLM 的反编译的可行性，但它们依赖于通用或特定于任务的微调，并且不对恶意软件语料库执行域自适应预训练。. While these approaches demonstrate the feasibility of LLM-based decompilation, they rely on generic or task-specific fine-tuning and do not perform domain-adaptive pretraining on malware corpora.

Ⅱ-DII-D 法学硕士的参数高效适应Parameter-Efficient Adaptation of LLMs

为了降低微调大型模型的成本，参数高效的自适应方法（例如适配器）To reduce the cost of fine-tuning large models, parameter-efficient adaptation methods such as adapters[5], 前缀调整, prefix-tuning[13]，和低阶适应（LoRA）, and Low-Rank Adaptation (LoRA)[6]已被提议。这些技术通过引入轻量级模块或低等级更新来实现任务适应，同时保持骨干参数冻结。尽管这些方法广泛用于自然语言处理和代码生成，但尚未在恶意软件反编译的背景下进行系统探索，也没有评估它们对低级代码翻译任务中的语义保真度和可执行正确性的影响。have been proposed. These techniques enable task adaptation by introducing lightweight modules or low-rank updates while keeping the backbone parameters frozen. Although widely used in natural language processing and code generation, these methods have not been systematically explored in the context of malware decompilation or evaluated for their impact on both semantic fidelity and executable correctness in low-level code translation tasks.

Ⅱ-EII-E 总结与定位Summary and Positioning

与之前的工作相比，本研究在单个框架内集成了恶意软件感知 CLM 预训练、基于 LoRA 的参数高效微调以及 Multi-Adapter 和 Seq2Seq 统一策略的统一比较。与现有的基于 LLM 的反编译器不同，所提出的方法明确将恶意软件作为一流的训练领域，并使用包括语义相似性、结构保真度和可重复执行性的综合协议来评估性能。这种定位将该框架与之前主要关注良性代码、静态相似性度量或单一适应范例的努力区分开来。In contrast to prior work, this study integrates malware-aware CLM pretraining, LoRA-based parameter-efficient fine-tuning, and a unified comparison of Multi-Adapter and Seq2Seq Unified strategies within a single framework. Unlike existing LLM-based decompilers, the proposed approach explicitly targets malicious software as a first-class training domain and evaluates performance using a comprehensive protocol that includes semantic similarity, structural fidelity, and re-executability. This positioning distinguishes the framework from prior efforts that focus primarily on benign code, static similarity metrics, or single adaptation paradigms.

Ⅲ-EIII-E 恶意软件感知 CLM 预训练Malware-Aware CLM Pretraining

The corpus consists of disassembled assembly code, decompiled pseudo-code, and recovered source-level artifacts extracted from PE binaries collected from public malware repositories and internal threat intelligence feeds.

每个恶意软件样本都通过指令规范化、寄存器重命名和地址随机化进行标准化，以减少语法噪音。使用混合字节级和指令感知标记器对生成的序列进行标记，以保留操作码级语义和更高级别的结构模式。Each malware sample is normalized via instruction canonicalization, register renaming, and address randomization to reduce syntactic noise. The resulting sequences are tokenized using a hybrid byte-level and instruction-aware tokenizer to preserve both opcode-level semantics and higher-level structural patterns.

In the proposed framework, LoRA complements the Multi-Adapter strategy by capturing fine-grained task variations within each adapter module, yielding a hierarchical adaptation structure consisting of: (i) a malware-aware backbone, (ii) task-specific adapters, and (iii) LoRA low-rank deltas.

V 局限性、道德考虑和未来的工作Limitations, Ethical Considerations and Future Work

V-A 有效性的限制和威胁Limitations and Threats to Validity

提议的框架主要针对 Windows PE 恶意软件，可能无法推广到其他格式，例如 ELF 或移动二进制文件。自动反编译会引入标签噪声，特别是对于严重混淆的样本。可重复执行性是在行为覆盖范围有限的沙盒环境中进行评估的，并且基于嵌入的语义度量可能无法完全捕获功能等效性。未来的工作将探索跨平台泛化和基于符号执行的评估。The proposed framework primarily targets Windows PE malware and may not generalize to other formats such as ELF or mobile binaries. Automated decompilation introduces label noise, particularly for heavily obfuscated samples. Re-executability is evaluated in a sandboxed environment with limited behavioral coverage, and embedding-based semantic metrics may not fully capture functional equivalence. Future work will explore cross-platform generalization and symbolic execution-based evaluation.

We also plan to evaluate cross-platform generalization between Windows and Android malware in reverse engineering tasks.

VI 结论Conclusion

在这项工作中，我们引入了 LLM4CodeRE，这是一种用于双向代码逆向工程的恶意软件感知大型语言模型框架，它将程序集到源代码的反编译和源代码到程序集的转换统一在单个架构中。 对标准数据集的大量实验表明，与通用代码模型和之前的反编译方法相比，LLM4CodeRE 始终如一地提高了语义保真度、结构对齐和端到端可重复执行性。我们相信，LLM4CodeRE 为可执行代码生成、自动化恶意软件分析以及 LLM 驱动的逆向工程系统的稳健评估方面的未来研究奠定了坚实的基础。In this work, we introduced LLM4CodeRE, a malware-aware large language model framework for bidirectional code reverse engineering that unifies assembly-to-source decompilation and source-to-assembly translation within a single architecture. Extensive experiments on standard datasets demonstrate that LLM4CodeRE consistently improves semantic fidelity, structural alignment, and end-to-end re-executability compared to general-purpose code models and prior decompilation-focused methods. We believe that LLM4CodeRE provides a strong foundation for future research in executable code generation, automated malware analysis, and robust evaluation of LLM-driven reverse engineering systems.

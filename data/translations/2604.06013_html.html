认知盲法：用于审计法学硕士辅助分析中先前污染的推理时间协议Epistemic Blinding: An Inference-Time Protocol for Auditing Prior Contamination in LLM-Assisted Analysis

Michael F. Cuccarese, PhD
摘要。Abstract.

本文提出了在代理系统背景下的认知盲法，该系统使用大型语言模型在多个生物数据集上进行推理，以进行药物靶点优先排序。在开发过程中，很明显，LLM 输出默默地将数据驱动的推理与关于命名实体的记忆先验混合在一起，并且这种混合是不可见的：无法从单个输出中确定有多少来自页面上的数据以及有多少来自模型的训练内存。This paper presents epistemic blinding in the context of an agentic system that uses large language models to reason across multiple biological datasets for drug target prioritization. During development, it became apparent that LLM outputs silently blend data-driven inference with memorized priors about named entities—and the blend is invisible: there is no way to determine, from a single output, how much came from the data on the page and how much came from the model’s training memory.认知致盲Epistemic blinding是一个简单的推理时间协议，它在提示之前用匿名代码替换实体标识符，然后将输出与非盲控制进行比较。该协议并不使 LLM 推理具有确定性，但它恢复了可审计性的一个关键轴：测量有多少输出来自所提供的数据与模型的参数知识。描述了完整的目标识别系统，包括法学硕士引导的评分函数进化优化和用于目标合理化的盲代理推理，并证明这两个阶段都无需访问实体身份即可运行。在四种癌症类型的肿瘤药物靶点优先排序中，盲法改变了前 20 个预测的 16%，同时保持了已验证靶点的相同恢复。事实证明，污染问题普遍存在于生物学之外：在标准普尔 500 指数股票筛选中，品牌认知偏差重塑了 5 个随机种子中 30-40% 的前 20 名排名。为了降低采用障碍，该协议作为开源工具和克劳德代码技能发布，可在代理工作流程中实现单命令认知致盲。其主张并不是说盲法分析会产生更好的结果，而是说如果不采用盲法，就无法知道代理在多大程度上遵守研究人员设计的分析过程。is a simple inference-time protocol that replaces entity identifiers with anonymous codes before prompting, then compares outputs against an unblinded control. The protocol does not make LLM reasoning deterministic, but it restores one critical axis of auditability: measuring how much of an output came from the supplied data versus the model’s parametric knowledge. The complete target identification system is described—including LLM-guided evolutionary optimization of scoring functions and blinded agentic reasoning for target rationalization—with demonstration that both stages operate without access to entity identity. In oncology drug target prioritization across four cancer types, blinding changes 16% of top-20 predictions while preserving identical recovery of validated targets. The contamination problem is shown to generalize beyond biology: in S&P 500 equity screening, brand-recognition bias reshapes 30–40% of top-20 rankings across five random seeds. To lower the barrier to adoption, the protocol is released as an open-source tool and as a Claude Code skill that enables one-command epistemic blinding within agentic workflows. The claim is not that blinded analysis produces better results, but that without blinding, there is no way to know to what degree the agent is adhering to the analytical process the researcher designed.

1. 简介Introduction

考虑一个具体的例子。法学硕士会收到一张由结直肠癌靶点发现模型产生的 100 个基因的表格，并被要求对前 20 个药物靶点进行排名。当基因名称可见时，该模型将 KRAS 排名第一，并通过引用“通过共价 RAS 抑制剂证明的治疗可处理性”来证明选择的合理性。当用匿名标签呈现相同的特征时，与 KRAS 对应的基因（现在标记为 Gene_088）排名第 5，低于具有更高突变频率和更强收敛信号的基因，但仍然显然是感兴趣的目标。 “通过共价 RAS 抑制剂证明治疗的可处理性”这一短语没有出现在所提供的数据中的任何地方。它来自模型的训练语料库。Consider a concrete example. An LLM is given a table of 100 genes resulting from a target discovery model in colorectal cancer and asked to rank the top 20 drug targets. When the gene names are visible, the model ranks KRAS at position #1 and justifies the choice by citing “proven therapeutic tractability via covalent RAS inhibitors.” When the identical features are presented with anonymous labels, the gene corresponding to KRAS—now labeled Gene_088—is ranked #5, below genes with higher mutation frequencies and stronger convergence signals, but still clearly a target of interest. The phrase “proven therapeutic tractability via covalent RAS inhibitors” does not appear anywhere in the provided data. It comes from the model’s training corpus.

过去十年，为药物发现提供了一套快速增长的可公开访问的统一数据层——全基因组关联研究、CRISPR 必要性筛选、蛋白质基础模型嵌入、单细胞转录组学等。在这些模式中部署现代机器学习方法来发现新的治疗靶点的机会是众所周知的The past decade has produced a rapidly growing set of publicly accessible, uniform data layers for drug discovery—genome-wide association studies, CRISPR essentiality screens, protein foundation model embeddings, single-cell transcriptomics, and more. The opportunity to deploy modern machine learning methods across these modalities to discover novel therapeutic targets is well understood(hoadley2018, ; boiko2023, )。大型语言模型在这方面提供了两个特定的优势。首先，它们可以跨异构数据层进行推理，整合跨越不同生物模态的信号。其次，对于明确定义的优化目标，LLM 可以充当进化框架中的突变算子，无需手动特征工程即可快速改进评分函数。. Large language models offer two specific advantages in this context. First, they can reason across heterogeneous data layers, integrating signals that span different biological modalities. Second, for well-defined optimization objectives, LLMs can serve as mutation operators in evolutionary frameworks, rapidly improving scoring functions without manual feature engineering.

然而，这两个函数都受到共同的故障模式的影响：However, both of these functions are contaminated by a shared failure mode:参数化知识污染parametric knowledge contamination。当 LLM 在推理或代码生成过程中遇到命名实体时，它会激活在预训练期间记住的有关该实体的所有内容。对于药物靶标优先级排序，这意味着该模型已经吸收了关于哪些基因在哪些癌症中“重要”的强大先验知识，并且这些先验知识默默地影响着应该由数据驱动的输出。每当法学硕士对培训语料库中代表性不均匀的命名实体进行推理时，都会出现同样的问题：股票、法律案例、研究论文、候选人催化剂、求职者。. When an LLM encounters a named entity during reasoning or code generation, it activates everything it memorized about that entity during pretraining. For drug target prioritization, this means the model has absorbed strong priors about which genes are “important” in which cancers—and these priors silently influence outputs that are supposed to be data-driven. The same problem applies whenever LLMs reason over named entities with uneven representation in the training corpus: equities, legal cases, research papers, candidate catalysts, job applicants.

这里提出的解决方案——The solution presented here—认知致盲epistemic blinding— 采用与临床试验中盲法相同的原则：防止分析人员获取可能使分析产生偏差的信息。这里，分析师是一名法学硕士，致盲是通过提示级别的字符串替换来实现的。—draws on the same principle as blinding in clinical trials: prevent the analyst from accessing information that could bias the analysis. Here, the analyst is an LLM, and the blinding is achieved through string replacement at the prompt level.

结果影响与分析纯度不同。Outcome impact as distinct from analytical purity.

自然的问题是盲法或非盲法是否能产生“更好”的结果。本文有意抵制这种框架。在某些情况下，训练先验确实提供了丰富的信息——知道 KRAS 可药物化的模型正在整合可能真正改进推荐的现实世界知识。在其他情况下，这些相同的先验掩盖了可能代表新颖生物学的数据驱动的候选者。认知致盲的目的不是抑制模型的知识。这是为了确保The natural question is whether blinded or unblinded analysis produces “better” results. This paper deliberately resists that framing. In some cases, training priors are genuinely informative—a model that knows KRAS is druggable is incorporating real-world knowledge that might genuinely improve a recommendation. In other cases, those same priors mask data-driven candidates that could represent novel biology. The point of epistemic blinding is not to suppress the model’s knowledge. It is to ensure the影响力influence使这些知识变得可见和可测量——以恢复原本不存在的可审计性轴。of that knowledge visible and measurable—to restore an axis of auditability that is otherwise absent.

对于确定性过程，每一步都是可追踪的。可以从输入到输出的每个转换跟踪数据点，并根据意图验证逻辑。基于法学硕士的分析打破了这一点：模型的推理是一个黑匣子，其中提供的数据和记忆的知识在没有归属的情况下混合在一起。认知致盲并不会使主体推理具有确定性。但它带回了确定性代码所期望的一些东西：能够审核该工具是根据所提供的输入进行操作，还是完全根据其他东西进行操作。For deterministic processes, every step is traceable. A data point can be followed from input through every transformation to output, and the logic verified against intent. LLM-based analysis breaks this: the model’s reasoning is a black box in which supplied data and memorized knowledge are mixed without attribution. Epistemic blinding does not make agentic reasoning deterministic. But it brings back something expected of deterministic code: the ability to audit whether the tool is operating on the inputs provided, or on something else entirely.

贡献。Contributions.

这项工作起源于一个特定的需求——构建一个用于多数据集生物推理而没有事先污染的代理系统——并推广到与领域无关的协议。贡献是：（1）认知致盲的正式描述，包括跨数据集一致性和微妙泄漏源的处理； (2) 一个开源的、配置驱动的实现，适用于任何法学硕士； (3) 完整的目标识别系统，其中认知盲法应用于进化优化和代理推理； (4) 一项对照实验显示四种癌症类型的系统名誉偏见； (5) 标准普尔 500 指数股票筛选中的演示表明，相同的污染问题和相同的解决方案会转移到不相关的领域。This work originated in a specific need—building an agentic system for multi-dataset biological reasoning without prior contamination—and generalized into a domain-agnostic protocol. The contributions are: (1) a formal description of epistemic blinding, including treatment of cross-dataset consistency and subtle leak sources; (2) an open-source, config-driven implementation that works with any LLM; (3) a complete target identification system in which epistemic blinding is applied to both evolutionary optimization and agentic reasoning; (4) a controlled experiment showing systematic fame bias across four cancer types; and (5) a demonstration in S&P 500 equity screening showing that the same contamination problem—and the same fix—transfers to an unrelated domain.

3. 方法：认知盲法Method: Epistemic Blinding

3.1. 协议Protocol

认知盲法是一种推理时间干预，无需模型修改。给定一个或多个包含命名实体的数据集：Epistemic blinding is an inference-time intervention requiring no model modification. Given one or more datasets containing named entities:

  1. (1)

    识别实体列。Identify entity columns.确定哪些列包含在法学硕士训练语料库中可能表现不均匀的标识符（基因符号、股票代码、药物名称、团队名称、作者姓名）。Determine which columns contain identifiers that may have uneven representation in the LLM’s training corpus (gene symbols, tickers, drug names, team names, author names).

  2. (2)

    构建共享映射。Build a shared mapping.对于每种实体类型，收集所有数据集中的每个不同值。使用稳定的种子进行确定性洗牌，并分配以下形式的匿名代码For each entity type, collect every distinct value across all datasets. Shuffle deterministically with a stable seed and assign anonymous codes of the form{前缀}_{数字}{Prefix}_{number}（例如，Gene_001、Company_042）。同一实体在任何地方出现时都会收到相同的代码，从而保留跨数据集推理。(e.g., Gene_001, Company_042). The same entity receives the same code everywhere it appears, preserving cross-dataset reasoning.

  3. (3)

    识别并减少细微的泄漏源。Identify and mitigate subtle leak sources.除了实体名称本身之外，相关特征也可能揭示身份。例如，市值和行业一起可以识别大多数巨型股票；结直肠癌中 42% 的突变频率可有效识别 KRAS。该协议区分Beyond the entity name itself, correlated features may reveal identity. For example, market capitalization and sector together can identify most mega-cap stocks; a 42% mutation frequency in colorectal cancer effectively identifies KRAS. The protocol distinguishes明显的obvious泄漏源（实体名称）来自leak sources (the entity name) from微妙的subtle那些（与身份相关性足够强以部分解除模型盲的特征）。该协议要求分析人员枚举潜在的细微泄漏，并决定是否将其标准化、分类或丢弃。在金融案例研究（第 5 节）中，所有特征均按部门标准化，以减少结构可识别性。ones (features that correlate strongly enough with identity to partially unblind the model). The protocol requires the analyst to enumerate potential subtle leaks and decide whether to normalize, bin, or drop them. In the financial case study (Section 5), all features were normalized by sector to reduce structural identifiability.

  4. (4)

    随机播放和渲染。Shuffle and render.使用固定种子随机化行顺序，并将匿名数据格式化为提示，保留列标题、单位和功能描述。Randomize row order with a fixed seed and format the anonymized data as a prompt, preserving column headers, units, and feature descriptions.

  5. (5)

    运行 A/B 比较。Run A/B comparison.在没有任何先前上下文的情况下，在新会话中将盲提示发送给法学硕士。单独将匹配的非盲提示发送到独立会话中的同一模型。使用集合重叠、排名移位和定性合理性分析来比较输出。Send the blinded prompt to an LLM in a fresh session with no prior context. Separately, send the matched unblinded prompt to the same model in an independent session. Compare outputs using set overlap, rank shift, and qualitative justification analysis.

  6. (6)

    去匿名化。De-anonymize.使用映射表将匿名代码解析回真实标识符。Resolve anonymous codes back to real identifiers using the mapping table.

3.2. 什么会失明，什么不会What Gets Blinded and What Doesn’t

目标是隐藏激活训练先验的信息，同时保留模型合理推理所需的信息。具有训练数据足迹的实体标识符和专有名词是盲目的。保留特征列名称、单位、数值、任务上下文所需的分类标签、日期和数据源名称。有些类别位于中间，例如，疾病名称不仅具有先验性，而且还锚定了分析任务。该协议通过每列配置支持部分盲法。The goal is to blind information that activates training priors while preserving information the model legitimately needs for reasoning. Entity identifiers and proper nouns with a training-data footprint are blinded. Feature column names, units, numeric values, categorical labels needed for task context, dates, and data source names are preserved. Some categories sit in the middle—disease names, for instance, carry priors but also anchor the analytical task. The protocol supports partial blinding via per-column configuration.

3.3. 实施Implementation

The tool is model-agnostic: it operates on prompt text, not API internals. It has also been implemented as a Claude Code skill, enabling one-command blinding within an agentic coding workflow.

4. 应用：肿瘤学目标识别Application: Target Identification for Oncology

认知盲法是在肿瘤学计算目标识别系统的背景下开发的。该系统分为两个阶段：(1) 确定性评分函数，由法学硕士指导流程演变而来，根据所有人类基因成为可行药物靶标的可能性对它们进行排名； (2) 盲法法学硕士推理步骤，对最佳候选人进行合理化和完善。这两个阶段的运行都无需获取基因身份。Epistemic blinding was developed in the context of a computational target identification system for oncology. The system has two stages: (1) a deterministic scoring function, evolved by an LLM-guided process, that ranks all human genes by their likelihood of being viable drug targets; and (2) a blinded LLM reasoning step that rationalizes and refines the top candidates. Both stages operate without access to gene identity.

4.1. 数据组装Data Assembly

该系统集成了八个可公开访问的数据层，每个数据层都针对一个属性进行选择：它可以测量生物学，而无需事先知道答案应该是什么。The system integrates eight publicly accessible data layers, each selected for a single property: it measures biology without requiring prior knowledge of what the answer should be.

6. 讨论Discussion

6.1. 可审计性，不一定会产生影响Auditability, Not Necessarily Impact

明确认知盲法能提供什么和不能提供什么是很重要的。它提供It is important to be explicit about what epistemic blinding does and does not provide. It provides可审计性auditability：衡量法学硕士的输出有多少来自所提供的数据与其训练记忆的能力。它不提供: the ability to measure how much of an LLM’s output came from the supplied data versus its training memory. It does not provide准确度accuracy：没有声称盲法结果比非盲法结果更正确。: no claim is made that blinded results are more correct than unblinded ones.

在某些情况下，培训先验会提供信息。知道 KRAS 可药物化的模型正在纳入真实且相关的事实。在其他情况下，训练先验会产生误导——以牺牲具有更强定量特征的新候选基因为代价来推广经过充分研究的基因。分析师需要知道他们处于哪种情况，而他们无法仅通过非盲分析来了解这一点。In some cases, training priors will be informative. A model that knows KRAS is druggable is incorporating a fact that is true and relevant. In other cases, training priors will be misleading—promoting well-studied genes at the expense of novel candidates with stronger quantitative profiles. The analyst needs to know which situation they are in, and they cannot know that from an unblinded analysis alone.

这种框架类似于确定性代码。当传统程序产生意外输出时，可以跟踪执行路径以准确识别其与预期的偏差。当基于 LLM 的代理产生意外输出时，它不能。认知致盲不会使代理具有确定性，但它会恢复一个特定的可追溯性轴：输出来自我的数据，还是来自其他地方？This framing is analogous to deterministic code. When a traditional program produces an unexpected output, the execution path can be traced to identify exactly where it diverged from expectation. When an LLM-based agent produces an unexpected output, it cannot. Epistemic blinding does not make the agent deterministic—but it restores one specific axis of traceability: did the output come from my data, or from somewhere else?

6.2. 何时盲注When to Blind

一个实用的启发：如果你让执行相同任务的人类分析师失明，那么你应该让法学硕士失明。该协议旨在A practical heuristic: if you would blind a human analyst performing the same task, you should blind the LLM. The protocol is designed for数据驱动推理data-driven inference—根据提供的功能对实体进行排名、评分、优先级排序。对于有意利用模型知识的任务（例如文献综合、知识检索或假设生成）会适得其反。—ranking, scoring, prioritizing entities based on supplied features. It is counterproductive for tasks that intentionally leverage the model’s knowledge, such as literature synthesis, knowledge retrieval, or hypothesis generation.

应满足三个条件：(1) 数据包含决策相关信号，(2) 实体在训练语料库中的表示不均匀，(3) 有人将对输出采取行动。当这三者都成立时，即使是快速的 A/B 比较也能提供分析师无法通过任何其他方式获得的信息。Three conditions should hold: (1) the data contains decision-relevant signal, (2) the entities have uneven representation in the training corpus, and (3) someone will act on the output. When all three are true, even a quick A/B comparison provides information the analyst cannot get any other way.

6.3. 这不能解决什么问题What This Does Not Fix

抽样偏差。Sampling bias.

如果某些信号在数据收集中被过度代表，那么无论盲法如何，它们都会被过度代表。认知盲法在推理阶段而不是数据阶段进行。在此介绍的肿瘤学案例研究中，通过故意排除文献挖掘的基因疾病关联和抽样偏差占主导地位的其他来源来解决这个问题。在数据收集本身偏向著名实体的领域，使推理阶段失明是必要的，但还不够。If certain signals are over-represented in data collection, they will be over-represented regardless of blinding. Epistemic blinding operates on the reasoning stage, not the data stage. In the oncology case study presented here, this was addressed by deliberately excluding literature-mined gene–disease associations and other sources where sampling bias would dominate. In domains where data collection itself is biased toward famous entities, blinding the reasoning stage is necessary but not sufficient.

结构渗漏。Structural leakage.

有些特征组合即使没有名字也能揭示身份。无论股票代码是否可见，苹果公司都是智能手机领域市值 3T 美元、营业利润率为 30% 的公司。当结构特征具有高度识别性时，致盲会减少而不是消除污染。缓解措施包括标准化特征、分箱值或删除标识列。Some feature combinations reveal identity even without the name. A company with $3T market cap and 30% operating margins in the smartphone sector is Apple regardless of whether the ticker is visible. When structural features are highly identifying, blinding reduces rather than eliminates contamination. Mitigations include normalizing features, binning values, or dropping the identifying column.

具有语义意义的名称。Semantically meaningful names.

在某些领域，名称编码信息：IUPAC化学名称编码分子结构；药物后缀表示机制（-mab 表示单克隆抗体）。隐藏这些名称会破坏合法信号。该协议应应用于身份，而不是具有功能意义的术语。In some domains, names encode information: IUPAC chemical names encode molecular structure; drug suffixes indicate mechanism (-mab for monoclonal antibodies). Blinding these names destroys legitimate signal. The protocol should be applied to identity, not to nomenclature that carries functional meaning.

8. 实际采用：克劳德代码技能Practical Adoption: A Claude Code Skill

只有当从业者能够毫无摩擦地应用它时，协议才有用。为此，认知致盲已作为克劳德代码技能实现——一种直接集成到代理编码工作流程中的模块化功能。当用户要求基于 LLM 的编码助手对数据集中的命名实体进行排名、评分或优先级时，该技能会自动激活：它读取数据、识别实体列、生成 YAML 配置、生成匹配的盲法和非盲法提示，并运行 A/B 比较——所有这些都在一个对话轮中完成。用户无需手动编写配置文件或运行脚本。A protocol is only useful if practitioners can apply it without friction. To this end, epistemic blinding has been implemented as a Claude Code skill—a modular capability that integrates directly into agentic coding workflows. When a user asks an LLM-based coding assistant to rank, score, or prioritize named entities from a dataset, the skill activates automatically: it reads the data, identifies entity columns, generates a YAML configuration, produces matched blinded and unblinded prompts, and runs the A/B comparison—all within a single conversational turn. The user does not need to write configuration files or run scripts manually.

这很重要，因为认知致盲的主要障碍不是概念复杂性，而是操作开销。该协议原则上非常简单——字符串替换——但实际上，在代理工作流程中工作的分析师不会停下来匿名化他们的数据、运行并行会话并比较输出，除非工具使这一切变得毫不费力。通过将协议嵌入为根据上下文激活的技能，目的是使盲法成为法学硕士辅助数据分析中的默认步骤，而不是事后的想法。This matters because the primary barrier to epistemic blinding is not conceptual complexity but operational overhead. The protocol is trivially simple in principle—string replacement—but in practice, analysts working within agentic workflows will not pause to anonymize their data, run a parallel session, and compare outputs unless the tooling makes it effortless. By embedding the protocol as a skill that activates contextually, the aim is to make blinding a default step in LLM-assisted data analysis rather than an afterthought.

9. 结论Conclusion

在数据驱动的分析过程中向法学硕士揭示实体标识符会系统地使其输出偏向于众所周知的实体，而不是仅由数据支持的结论。检测这种情况的干预措施（认知盲法）非常简单，不需要模型修改，并且保留模型的分析推理能力。Revealing entity identifiers to an LLM during data-driven analysis systematically biases its outputs toward well-known entities and away from conclusions supported by the data alone. The intervention to detect this—epistemic blinding—is trivially simple, requires no model modification, and preserves the model’s analytical reasoning capabilities.

这项工作表明，认知致盲可以应用于计算管道的多个阶段：在结构上，通过设计对数字特征而不是命名实体进行操作的优化过程；在结构上，通过设计对数字特征而不是命名实体进行操作的优化过程。诊断上，通过比较盲法和非盲法学硕士的输出来量化先前的污染。在肿瘤学领域，盲法改变了 16% 的前 20 个药物靶标预测，同时保持了已验证靶标的相同恢复率。在权益分析中，盲法改变了前 20 名价值排名的 35%。在这两个领域中，偏见的方向都是系统性的：著名的实体得到提升，特色鲜明的默默无闻的实体被降级。This work has shown that epistemic blinding can be applied at multiple stages of a computational pipeline: structurally, by designing optimization processes that operate on numerical features rather than named entities; and diagnostically, by comparing blinded and unblinded LLM outputs to quantify prior contamination. In oncology, blinding changed 16% of top-20 drug target predictions while maintaining identical recovery of validated targets. In equity analysis, blinding changed 35% of top-20 value rankings. In both domains, the direction of bias was systematic: famous entities were promoted, obscure entities with strong features were demoted.

每当法学硕士用于命名实体的数据驱动分析时，认知盲法就应该成为标准做法。并不是因为盲法结果一定更好，而是因为如果不盲法，分析师就无法知道智能体是根据提供的数据进行推理，还是根据对话开始前很久就记住的东西进行推理。Epistemic blinding should become standard practice whenever LLMs are used for data-driven analysis of named entities. Not because blinded results are necessarily better—but because without blinding, the analyst has no way to know whether the agent is reasoning from the data provided or from something it memorized long before the conversation began.

摘要Abstract

大型语言模型 (LLM) 已发展成为在现实世界任务中与用户协作的交互式代理。 在此类环境中，有效的协作越来越依赖于对用户的理解，而不仅仅是明确说明的内容，因为用户意图通常反映在碎片化的日常交互中，并且需要个性化建模和主动交互。 然而，现有的代理基准主要评估推理和工具使用，很大程度上忽视了在现实场景中推断和利用用户偏好的挑战。 为了解决这一差距，我们引入了 VitaBench 2.0，这是一个用于评估长期用户交互中的个性化和主动代理行为的基准。 在 VitaBench 2.0 中，任务被组织为单个用户的按时间顺序排列的序列，其中偏好嵌入在碎片化和异构的交互中。 成功完成任务需要代理不断从这些交互中提取、利用和更新用户偏好。 我们通过要求智能体识别缺失信息并在做出决策之前主动从用户或环境中获取信息的任务来进一步评估主动性。 为了支持系统分析，我们提供了可扩展的内存接口，可以跨不同内存架构进行受控比较。 我们对一系列不同的前沿专有和开源法学硕士进行了基准测试。 结果表明，即使对于最先进的模型，现实世界的个性化仍然具有很大的挑战性，揭示了当前能力和实际要求之间的巨大差距。 广泛的分析进一步揭示了当前智能体在现实世界个性化决策中的故障模式和能力瓶颈，为未来模型的改进提供了见解。 代码可在Large language models (LLMs) have evolved into interactive agents that collaborate with users in real-world tasks. Effective collaboration in such settings increasingly depends on understanding the user beyond what is explicitly stated, as user intent is often reflected in fragmented daily interactions and requires both personalized modeling and proactive interaction. However, existing agent benchmarks primarily evaluate reasoning and tool use, largely overlooking the challenges of inferring and leveraging user preferences in realistic scenarios. To address this gap, we introduce VitaBench 2.0, a benchmark for evaluating personalized and proactive agent behavior in long-term user interactions. In VitaBench 2.0, tasks are organized as temporally ordered sequences for individual users, where preferences are embedded in fragmented and heterogeneous interactions. To support systematic analysis, we provide an extensible memory interface that enables controlled comparison across different memory architectures. We benchmark a diverse set of frontier proprietary and open-source LLMs. Results show that real-world personalization remains highly challenging even for state-of-the-art models, revealing a substantial gap between current capabilities and practical requirements. Extensive analysis further reveals the failure modes and capability bottlenecks of current agents in real-world personalized decision-making, providing insights for future model improvements. 1 简介Introduction

大语言模型 (LLM) 的最新进展提高了推理和工具使用的能力Recent advances in large language models (LLMs) have improved their capabilities in reasoning and tool use[12, 19, 49, 2]，使它们能够从被动文本生成器发展成为在现实环境中运行的交互式代理, enabling them to evolve from passive text generators into interactive agents operating in real-world environments[66, 36, 55]。 随着这些代理从单轮交互转向与用户的持续协作，有效的帮助越来越依赖于对用户意图的理解，而不仅仅是明确说明的内容. As these agents move from single-turn interactions to sustained collaboration with users, effective assistance increasingly depends on understanding user intent beyond what is explicitly stated[37]。 在现实场景中，这种意图往往通过碎片化的交互隐式体现出来. In real-life scenarios, such intent is often reflected implicitly through fragmented interactions[28, 27, 9]，使个性化成为用户与代理协作的核心。, making personalization central to user–agent collaboration.

然而，现有的代理基准仍然没有充分体现出人类与代理协作中对个性化日益增长的需求。 现有的基准主要侧重于评估多步骤推理和工具编排，其中任务被明确指定，并且在上下文中明确说明了成功完成所需的上下文However, this growing need for personalization in human–agent collaboration remains insufficiently captured by existing agent benchmarks. Existing benchmarks primarily focus on evaluating multi-step reasoning and tool orchestration, where tasks are well-specified and the context required for successful completion is clearly stated within the context[29, 38, 102, 86, 5, 24]。 因此，他们主要评估智能体遵循明确指令并执行正确动作序列的能力。 相比之下，新兴的现实世界代理系统越来越多地在用户意图未明确且必须从先前的交互中推断的环境中运行. As a result, they mainly evaluate agents’ ability to follow explicit instructions and execute correct action sequences. In contrast, emerging real-world agent systems increasingly operate in settings where user intent is under-specified and must be inferred from prior interactions[96]。 在这种情况下，有效的帮助需要代理保持用户偏好的一致表示，适应其随时间的演变，并在必要时主动获取丢失的信息。 这种转变引入了一种根本不同的复杂性来源，超越了基于明确指令的推理，转向基于隐式和不断变化的用户偏好的决策。 这一差距凸显了对代理基准的需求，该基准可以明确评估现实用户代理交互设置中的个性化和主动性。. In such scenarios, effective assistance requires agents to maintain a consistent representation of user preferences, adapt to their evolution over time, and proactively acquire missing information when necessary. This shift introduces a fundamentally different source of complexity, moving beyond reasoning over explicit instructions to decision-making grounded in implicit and evolving user preferences. This gap highlights the need for agent benchmark that explicitly evaluates personalization and proactiveness in realistic user-agent interaction settings.

为此，我们推出了 VitaBench 2.0，这是一个用于评估现实世界长期用户交互中个性化和主动行为的代理基准。 除了工具使用和推理能力之外，VitaBench 2.0还从三个维度评估个性化：（1）Toward this end, we introduce VitaBench 2.0, an agent benchmark for evaluating personalized and proactive behavior in real-world long-term user interactions. Beyond tool use and reasoning ability, VitaBench 2.0 also evaluates personalization along three dimensions: (1)偏好提取preference extraction，其中代理从分散的交互中推断出隐式偏好； (2), where agents infer implicit preferences from fragmented interactions; (2)偏好利用preference utilization，代理利用这些偏好来进行特定于用户的决策；和（3）, where agents leverage these preferences for user-specific decision-making; and (3)偏好更新preference updating，代理捕捉偏好漂移并随着用户行为的变化修改他们的理解。 在此基础上，我们进一步评估, where agents capture preference drift and revise their understanding as user behavior evolves. Building on this formulation, we further evaluate主动性proactiveness，当用户偏好是有条件的并且要求代理在做出决策之前主动获取缺失信息时就会出现这种情况。, which arises when user preference is conditional and requires agents to actively acquire missing information before making decisions.

遵循现有代理基准的一般设置Following the general setup of existing agent benchmarks[86, 5, 24]，VitaBench 2.0 被构建为交互式代理基准，其中代理与环境交互以满足用户需求。 VitaBench 2.0 中的任务被组织为针对各个用户的按时间顺序排列的序列，其中每个任务序列跨越多个域，并且每个任务都与一组专用工具和可执行环境配对以支持现实交互。 为了评估个性化，我们为每个用户策划了一系列细粒度的偏好，并将它们嵌入到碎片化的交互中，包括对话和行为。 随着代理不断与用户交互，用户偏好可能会发生变化，这反映在新观察到的交互中，要求代理在任务序列中维护和更新偏好的一致表示。 为了捕获现实交互设置中的长期用户动态，我们允许代理为每个用户维护一个记忆模块。 在此基础上，VitaBench 2.0 提供了可扩展的内存接口，支持灵活的实现并支持跨代表性内存机制的受控比较, VitaBench 2.0 is constructed as an interactive agent benchmark, where agents interact with environments to fulfill user needs. Tasks in VitaBench 2.0 are organized as temporally ordered sequences for individual users, where each task sequence spans multiple domains, and each task is paired with a dedicated set of tools and an executable environment to support realistic interaction. To evaluate personalization, we curate a series of fine-grained preferences for each user and embed them into fragmented interactions, including both dialogues and behaviors. As agents continuously interact with users over time, user preferences may evolve, which is reflected in newly observed interactions, requiring agents to maintain and update a consistent representation of preferences within task sequences. To capture long-term user dynamics in realistic interaction settings, we allow agents to maintain a memory module for each user. Building on this, VitaBench 2.0 provides an extensible memory interface that supports flexible implementations and enables controlled comparison across representative memory mechanisms[42, 84, 88].

我们对各种前沿专有和开源语言模型进行了广泛的评估。 我们的结果表明，现实世界的个性化任务对于当前的代理来说仍然极具挑战性，揭示了现有能力和实际需求之间的巨大差距。 我们进一步分析了内存的作用，发现虽然内存机制对于长期用户建模至关重要，但现有方法往往无法一致地将存储的信息转化为改进的性能，并且不同的内存设计会导致明显不同的结果。 通过系统分析，我们确定了当前代理的关键故障模式和主要瓶颈，从而深入了解当前模型为何难以实现个性化。 VitaBench 2.0 强调了当前 LLM 代理与现实的个性化助理之间的差距，并为未来的记忆、个性化和主动代理行为研究提供了一个测试平台。We conduct extensive evaluations on a wide range of frontier proprietary and open-source language models. Our results show that real-world personalization tasks remain highly challenging for current agents, revealing a substantial gap between existing capabilities and practical requirements. We further analyze the role of memory and find that, while memory mechanisms are essential for long-term user modeling, existing approaches often fail to consistently translate stored information into improved performance, and different memory designs lead to markedly different outcomes. Through systematic analysis, we identify key failure patterns and primary bottlenecks of current agents, providing insights into why current models struggle with personalization. VitaBench 2.0 highlights a gap between current LLM agents and realistic personalized assistants and provides a testbed for future research on memory, personalization, and proactive agent behavior.

2 相关工作Related Work

个性化法学硕士。Personalized LLM.

随着大型语言模型越来越多地部署在面向用户的应用程序中，个性化已成为使模型输出与个人用户需求和偏好保持一致的关键功能As large language models are increasingly deployed in user-facing applications, personalization has become a critical capability for aligning model outputs with individual user needs and preferences[37, 96, 68]。实现个性化需要模型捕获用户特定的特征并将其纳入生成过程。现有的方法可以从三个对齐角度来广泛理解：输入级对齐、模型级对齐和目标级对齐。 输入级对齐通过用户特定的上下文丰富了提示。检索增强方法从交互历史或外部知识存储中获取此类上下文. Achieving personalization requires models to capture user-specific characteristics and incorporate them into the generation process. Existing methods can be broadly understood from three alignment perspectives: input-level alignment, model-level alignment, and objective-level alignment. Input-level alignment enriches prompts with user-specific context. Retrieval-augmented methods obtain such context from interaction histories or external knowledge stores[59, 45, 57]，而基于配置文件的方法明确总结并将用户偏好注入到提示中, while profile-based approaches explicitly summarize and inject user preferences into the prompt[33, 79]。模型级对齐通过白盒模型的参数调整来调整模型本身，以根据用户偏好生成输出. Model-level alignment adapts the model itself to generate outputs conditioned on user preferences, through parameter adaptation for white-box models[65, 94]或黑盒模型的模型分解框架or model factorization frameworks for black-box models[105]。目标层面的调整将个性化纳入培训目标，包括个性化奖励模型. Objective-level alignment incorporates personalization into training objectives, including personalized reward modeling[26], 多目标偏好优化, multi-objective preference optimization[103]和因果偏好建模, and causal preference modeling[98]。 随着用户交互变得越来越长期和信息丰富，在记忆系统的进步和法学硕士利用它们的能力不断增强的支持下，记忆增强个性化越来越受到关注。这一系列工作通过外部存储机制增强了法学硕士，支持随着时间的推移存储、检索和更新用户相关信息. As user interactions become increasingly long-term and informative, memory-augmented personalization has gained growing attention, supported by advances in memory systems and the increasing capability of LLMs to utilize them. This line of work augments LLMs with external memory mechanisms that support the storage, retrieval, and updating of user-relevant information over time[51, 42, 85].

LLM 个性化的基准。Benchmarks for LLM Personalization.

随着个性化法学硕士变得越来越复杂，对系统评估基准的需求也越来越大。现有的工作可以大致分为两个维度：用户特定信息的形式和评估设置。 从输入的角度来看，先前的基准使用各种形式的用户信息（包括明确的个人资料）来评估个性化As personalized LLMs become increasingly complex, there is a growing need for systematic evaluation benchmarks. Existing work can be broadly categorized along two dimensions: the form of user-specific information and the evaluation setting. From the input perspective, prior benchmarks assess personalization using various forms of user information, including explicit profiles[106, 99, 64], 用户编写的文档, user-authored documents[58, 31]，以及具有隐含或不断变化的偏好的交互历史, and interaction histories with implicit or evolving preferences[40, 78, 95, 27, 28, 82]。 从评估的角度来看，早期的基准测试主要考虑相对静态的个性化场景，其中用户信息是明确提供的或从一组固定的文档或个人资料属性中得出的. From the evaluation perspective, early benchmarks mainly consider relatively static personalization scenarios, where user information is explicitly provided or derived from a fixed set of documents or profile attributes[58, 31, 106, 99, 64]。最近的工作更加重视长期记忆和动态用户建模，评估模型是否可以在扩展交互中保留用户相关信息，从会话历史中推断隐式偏好信号，并适应随时间变化的偏好. More recent efforts place greater emphasis on long-term memory and dynamic user modeling, evaluating whether models can retain user-related information across extended interactions, infer implicit preference signals from conversational histories, and adapt to preferences that evolve over time[40, 78, 95, 27, 28, 82]。 然而，这些基准仍然主要局限于被动的文本输入文本输出设置，其中个性化主要通过生成而不是行动来评估，这与涉及工具使用和决策的现实辅助场景存在差距。. However, these benchmarks remain largely confined to passive text-in-text-out settings, where personalization is evaluated primarily through generation rather than action, leaving a gap toward realistic assistant scenarios involving tool use and decision-making.

LLM 代理的基准。Benchmarks for LLM Agents.

法学硕士已经从文本生成器发展成为能够与外部工具和环境交互的自主代理LLMs have evolved from text generators into autonomous agents capable of interacting with external tools and environments[60]。现有的代理基准测试已经从评估孤立的工具使用能力发展到评估日益现实的交互式任务执行形式。 早期的基准测试主要关注 API 调用和工具使用的准确性，评估模型是否能够选择合适的工具并为给定的用户请求生成有效的参数. Existing agent benchmarks have progressed from evaluating isolated tool-use capability to assessing increasingly realistic forms of interactive task execution. Early benchmarks mainly focus on API invocation and tool-use accuracy, evaluating whether models can select appropriate tools and generate valid arguments for a given user request[34, 53]。后续的基准测试转向更具交互性和有状态的设置，其中代理必须在多个回合中进行推理，跟踪中间状态，并对执行过程中不断变化的上下文和反馈做出响应. Subsequent benchmarks move toward more interactive and stateful settings, where agents must reason over multiple turns, track intermediate states, and respond to evolving context and feedback during execution[15, 74, 54, 39, 61]。最近的努力进一步将代理置于现实的执行环境中，包括网络搜索. More recent efforts further place agents in realistic execution environments, including web searching[38, 102], 电脑使用, computer using[83]、软件工程, software engineering[29]，以及用户代理交互, and user-agent interaction[67, 86, 5, 24, 35, 72, 100]，评估现实世界约束下端到端任务的完成情况。 然而，现有的代理基准在很大程度上忽视了个性化，并且通常假设所有与任务相关的信息在当前上下文中都明确可用，从而与现实世界的助手场景产生了差距。我们的工作通过在现实的交互环境中联合评估个性化和代理执行来解决这一差距。, to evaluate end-to-end task completion under real-world constraints. However, existing agent benchmarks largely overlook personalization and typically assume that all task-relevant information is explicitly available in the current context, creating a gap with real-world assistant scenarios. Our work addresses this gap by jointly evaluating personalization and agentic execution in realistic interactive settings.

3.3 积极主动性Proactiveness

除了利用存储的用户偏好之外，有效的个性化代理还应该知道其当前知识何时不足，并主动寻求用户澄清或进行环境探索。 我们通过主动任务来评估这种能力，其中任务的成功完成不仅取决于检索相关的用户偏好，还取决于识别无法仅从内存或当前查询推断出的缺失上下文信息。 基于这个想法，主动任务是围绕缺失但必要的信息构建的，其中正确的行动取决于代理无法直接观察到的上下文因素。解决此类任务需要代理捕获相关的条件偏好，识别未解决的歧义，并在行动之前询问用户或探索环境。这些任务与标准个性化任务交织在一起，要求代理自适应地决定何时需要额外的上下文，而不是在不完整的信息下做出决策。Beyond leveraging stored user preferences, an effective personalized agent should also know when its current knowledge is insufficient and proactively seek user clarification or conduct environment exploration. We evaluate this capability through proactive tasks, where successful task completion depends not only on retrieving the relevant user preference, but also on recognizing missing contextual information that cannot be inferred from memory or the current query alone. Building on this idea, proactive tasks are constructed around missing but necessary information, where the correct action depends on contextual factors that are not directly observable to the agent. Solving such tasks requires the agent to capture the relevant conditional preference, recognize the unresolved ambiguity, and query the user or explore the environment before acting. These tasks are interleaved with standard personalization tasks, requiring the agent to adaptively decide when additional context is necessary rather than making decisions under incomplete information.

5 局限性Limitation

虽然 VitaBench 2.0 为研究 LLM 代理的个性化和主动性提供了原则性基准，但它有一些局限性。 首先，以编程方式构建用户偏好和交互历史，以允许精确控制偏好动态和任务难度。虽然这有利于可重复的评估，但它可能无法完全捕获现实世界用户行为的全部多样性。 其次，内存接口将内存抽象为更新和检索操作，从而实现不同设计之间的受控比较。这种抽象侧重于隔离内存的角色，并不旨在覆盖所有可能的端到端架构。 第三，评估基于对任务轨迹的评估，提供结构化和可解释的信号。更多开放式的用户满意度衡量标准超出了本工作的范围。 总体而言，这些设计选择旨在优先考虑可控性和可比性，我们将 VitaBench 2.0 视为研究个性化和主动代理的核心挑战的补充测试平台。While VitaBench 2.0 provides a principled benchmark for studying personalization and proactiveness in LLM agents, it has several limitations. First, user preferences and interaction histories are programmatically constructed to allow precise control over preference dynamics and task difficulty. While this facilitates reproducible evaluation, it may not fully capture the full diversity of real-world user behavior. Second, the memory interface abstracts memory into update and retrieval operations, enabling controlled comparison across different designs. This abstraction focuses on isolating the role of memory, and does not aim to cover all possible end-to-end architectures. Third, evaluation is based on rubric-driven assessment over task trajectories, providing structured and interpretable signals. More open-ended measures of user satisfaction are beyond the scope of this work. Overall, these design choices are intended to prioritize controllability and comparability, and we view VitaBench 2.0 as a complementary testbed for studying core challenges in personalized and proactive agents.

6 结论Conclusion

在这项工作中，我们引入了 VitaBench 2.0，这是一个评估基于 LLM 的代理的个性化和主动性的基准。 VitaBench 2.0 将任务组织为以用户为中心的序列，将不断变化的偏好嵌入到碎片化的交互历史中，并逐步向代理公开这些历史，捕获随着时间的推移推断和更新用户偏好的关键挑战。 为了支持系统分析，我们设计了一个可扩展的内存接口，可以在统一的框架内对不同的内存机制进行受控比较。 通过对各种前沿模型的广泛实验，我们发现当前的 LLM 代理很难可靠地推断、利用和更新用户偏好，特别是当偏好发生变化或信息不完整时。进一步的分析提供了对当前代理的失败模式和长期偏好建模的困难的见解。 总体而言，VitaBench 2.0揭示了现有法学硕士代理和现实的个性化助理之间的显着差距，并为推进记忆、个性化和主动行为的研究提供了一个测试平台。In this work, we introduce VitaBench 2.0, a benchmark for evaluating personalization and proactiveness in LLM-based agents. VitaBench 2.0 organizes tasks as user-centric sequences, embeds evolving preferences into fragmented interaction histories, and incrementally exposes these histories to the agent, capturing the key challenge of inferring and updating user preferences over time. To support systematic analysis, we design an extensible memory interface that enables controlled comparison of different memory mechanisms within a unified framework. Through extensive experiments on a diverse set of frontier models, we find that current LLM agents struggle to reliably infer, utilize, and update user preferences, especially when preferences evolve or when information is incomplete. Further analysis provides insights into the failure modes of current agents and the difficulties of long-term preference modeling. Overall, VitaBench 2.0 reveals a significant gap between existing LLM agents and realistic personalized assistants, and provides a testbed for advancing research on memory, personalization, and proactive behavior.

A.2.2 环境综合Environment Synthesis

由于 VitaBench 2.0 中的每个任务都被制定为代理任务，因此它需要一个可执行环境，代理可以在其中调用工具来交互并满足用户需求（例如，下外卖订单）。我们的基准包含跨越不同领域（例如，送餐、店内服务和旅行预订）的数千个任务，并且确保足够的任务难度需要每个环境提供丰富且结构化的候选空间。因此，大规模手动构建此类环境是不切实际的。为了解决这个问题，我们设计了一个综合管道，为每个任务生成结构化的可执行环境，并辅之以编程验证和手动细化，以确保正确性和一致性。As each task in VitaBench 2.0 is formulated as an agentic task, it requires an executable environment in which the agent can invoke tools to interact and fulfill user needs (e.g., placing a food-delivery order). Our benchmark contains thousands of tasks spanning diverse domains (e.g., food delivery, in-store services, and travel booking), and ensuring sufficient task difficulty requires each environment to present a rich and structured candidate space. Manually constructing such environments at scale is therefore impractical. To address this, we design a synthesis pipeline that generates structured, executable environments for each task, complemented by programmatic validation and manual refinement to ensure correctness and consistency.

我们采用多代理设计，将环境综合分解为一系列专门的组件，每个组件负责一个明确定义的子任务。给定用户配置文件、用户查询和评估标准，环境生成器会具体化与任务规范一致的商家和商品数据库，包括有效的候选者和精心构建的干扰项。重要的是，我们的基准测试不仅评估基本的工具使用能力，还评估推断和利用用户偏好的能力。因此，我们构建的环境的困难来自两个互补的维度。 首先，根据用户查询，我们生成与域相关但不满足任务约束的商家和商品，要求代理正确调用工具并过滤掉不相关的候选者。其次，根据评估标准，我们生成满足用户查询但违反用户偏好的候选者，要求代理推断并应用偏好信息以消除此类干扰。We adopt a multi-agent design that decomposes environment synthesis into a sequence of specialized components, each responsible for a well-defined subtask. Given a user profile, user query, and evaluation rubric, the environment generator materializes a database of merchants and items consistent with the task specification, including both valid candidates and carefully constructed distractors. Importantly, our benchmark evaluates not only basic tool-use capabilities but also the ability to infer and leverage user preferences. Accordingly, we construct environments whose difficulty arises from two complementary dimensions. A.3 基准管道Benchmark Pipeline

我们将 VitaBench 2.0 制定为一个连续的用户代理交互过程，其中代理需要通过按时间顺序排列的任务序列不断满足用户需求。每个任务对应于用户模拟器发出的具体用户请求，并由代理通过与特定于域的工具和可执行环境的交互来解决。 在连续的任务之间，代理会接触新生成的交互历史记录，并可能更新其内部存储器以保持对用户偏好的不断发展的理解。在任务执行过程中，代理会整合当前的观察结果、检索到的记忆和工具反馈来做出决策。通过该设置，可以对工具使用能力、偏好推断与利用、不完全信息下的主动行为进行统一评估。We formulate VitaBench 2.0 as a sequential user-agent interaction process, where the agent is required to continuously fulfill user needs over a temporally ordered sequence of tasks. Each task corresponds to a concrete user request issued by a user simulator and is solved by the agent through interaction with domain-specific tools and an executable environment. Between consecutive tasks, the agent is exposed to newly generated interaction histories and may update its internal memory to maintain an evolving understanding of user preferences. During task execution, the agent integrates current observations, retrieved memory, and tool feedback to make decisions. This setting enables unified evaluation of tool-use ability, preference inference and utilization, and proactive behavior under incomplete information.

A.3.1 任务集Task Set

任务集是手动构建的，并基于相应的用户配置文件，以确保真实性和一致性。每项任务都旨在评估一个或多个用户偏好，要求代理随着时间的推移捕获、利用和维护这些偏好。任务跨越不同的现实世界领域，反映了广泛的日常用户需求。 具体来说，任务要求智能体对两个互补的困难来源进行推理。第一个源于用户查询中指定的显式约束，必须通过适当的工具使用来满足这些约束。第二个来自于从用户交互历史中导出的隐式信号，要求代理正确推断和应用用户偏好。 与主要强调多步骤推理和复杂工具编排的现有代理基准测试相比，我们的基准测试通过隐式偏好建模引入了额外的难度维度。为了更好地隔离这种能力，我们有意降低显式推理和工具使用的复杂性，避免过于复杂的工具链。这种设计确保任务的成功主要取决于代理捕获、利用和维护用户偏好的能力。 此外，任务子集涉及条件偏好，其中正确的决策取决于无法从当前查询直接观察到的上下文。这些任务构成了评估主动行为的基础。The task set is manually constructed and grounded in the corresponding user profile to ensure realism and consistency. Each task is designed to evaluate one or multiple user preferences, requiring the agent to capture, utilize, and maintain these preferences over time. Tasks span diverse real-world domains, reflecting a wide range of everyday user needs. Specifically, tasks require agents to reason over two complementary sources of difficulty. The first arises from explicit constraints specified in the user query, which must be satisfied through appropriate tool use. The second arises from implicit signals derived from user interaction histories, requiring the agent to correctly infer and apply user preferences. Compared to existing agent benchmarks that primarily emphasize multi-step reasoning and complex tool orchestration, our benchmark introduces an additional dimension of difficulty through implicit preference modeling. To better isolate this capability, we intentionally reduce the complexity of explicit reasoning and tool usage, avoiding overly intricate tool chains. This design ensures that task success depends primarily on the agent’s ability to capture, utilize, and maintain user preferences. In addition, a subset of tasks involves conditional preferences, where the correct decision depends on context not directly observable from the current query. These tasks form the basis for evaluating proactive behavior.

To address this issue, our simulator is deliberately restricted. It does not have access to the underlying user preferences and only provides user queries solely based on our predefined to-do list. During interaction, it provides only minimal feedback required for task completion, without revealing preference-related signals. This design is critical in our setting, as task difficulty in VitaBench 2.0 primarily arises from the agent’s ability to infer and utilize user preferences. Any unintended leakage of preference information from the simulator would significantly reduce task difficulty and undermine evaluation validity. In proactive tasks, the simulator may provide additional information upon request, but such responses are predefined and strictly controlled.

All evaluated large language models in our benchmark are instantiated as the task agent. Upon receiving new interaction histories, the agent updates its memory representation, which is subsequently used during task execution. During task execution, the agent integrates current observations, retrieved memory, and tool feedback to make decisions. Different scenarios exhibit distinct behavioral patterns: high-frequency, low-cost activities (e.g., food delivery) coexist with low-frequency, high-cost decisions (e.g., travel booking). This cross-domain structure requires agents to generalize preference signals across heterogeneous contexts, rather than relying on domain-specific heuristics.

为了进一步反映现实世界的情况，交互历史记录包含大约 20% 的噪声行为，这些行为并不直接对应于真实的用户偏好。 这些嘈杂的交互经过精心设计，旨在模仿真实但具有误导性的信号，包括： (一)To further reflect real-world conditions, interaction histories include approximately 20% noisy behaviors that do not directly correspond to true user preferences. 对评估的影响。Implications for evaluation.

长时间跨度、高交互密度、跨域覆盖和结构化噪声的结合导致了偏好推断的挑战性环境。 代理不能依赖单一交互或短期模式，但必须随着时间的推移聚合碎片证据，处理冲突信号，并在不确定性下保持一致的用户表示。 这种设计可以对长期记忆、偏好跟踪以及对噪声观察的鲁棒性进行严格评估。The combination of long temporal span, high interaction density, cross-domain coverage, and structured noise results in a challenging setting for preference inference. Agents cannot rely on single interactions or short-term patterns, but must aggregate fragmented evidence over time, handle conflicting signals, and maintain consistent user representations under uncertainty. This design enables rigorous evaluation of long-term memory, preference tracking, and robustness to noisy observations.

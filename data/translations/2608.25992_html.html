摘要Abstract

多智能体大语言模型 (LLM) 工作流程已成为通过专门的 LLM 智能体之间的协作推理来解决复杂、开放式任务的强大范例，但由于重复的 LLM 调用和长期上下文积累，它们会产生大量的运营成本。现有的级联路由方法只能做出一次性的查询级决策，无法适应多步骤工作流程的动态、状态相关性质，其中每个步骤的正确 LLM 取决于不断发展的任务进度、剩余任务难度和成本效率要求。我们呈现Multi-agent large language model (LLM) workflows have emerged as a powerful paradigm for solving complex, open-ended tasks through collaborative reasoning among specialized LLM agents, but they incur substantial operating costs due to repeated LLM invocations and long-horizon context accumulation. Existing cascade routing methods make one-shot, query-level decisions and cannot adapt to the dynamic, state-dependent nature of multi-step workflows, in which the right LLM at each step depends on evolving task progress, remaining task difficulty, and cost-efficiency requirements. 5 结论Conclusion

本文介绍了This paper presents程序路由器ProgRouter，一个在线进度引导的编排框架，用于质量成本权衡下的多代理 LLM 工作流程。通过将多视图任务进度评分与双路径进度预测相结合，, an online progress-guided orchestration framework for multi-agent LLM workflows under quality-cost tradeoffs. By combining multi-view task progress scoring with dual-path progress prediction,程序路由器ProgRouter估计每个候选LLM代理的边际进度增益，并利用它来指导具有成本意识、截止日期意识的LLM代理路由决策。任务进度记分器充当轻量级域适配器，将可观察的工作流信号转换为统一的进度表示，而在线路由优化仍然适用于异构代理工作流。 HumanEval Plus、MBPP、MATH-500 和 ASQA 基准测试的实验表明estimates the marginal progress gain of each candidate LLM agent and leverages it to guide cost-aware, deadline-aware LLM agent routing decisions. The task progress scorer acts as a lightweight domain adapter that converts observable workflow signals into a unified progress representation, while the online routing optimization remains applicable across heterogeneous agentic workflows. Experiments on HumanEval Plus, MBPP, MATH-500, and ASQA benchmarks show that程序路由器ProgRouter始终满足长期运营成本预算，同时实现强大的任务解决性能和有竞争力的执行时间。这些结果凸显了进度感知型在线自适应 LLM 代理编排对于多代理工作流程的价值。consistently satisfies the long-term operating cost budget while achieving strong task-solving performance and competitive execution time. These results highlight the value of progress-aware online adaptive LLM agent orchestration for multi-agent workflows.

局限性Limitations

同时While程序路由器ProgRouter虽然表现出很强的实证表现，但仍然存在一些局限性，并为未来的工作指明了方向。demonstrates strong empirical performance, several limitations remain and point to directions for future work.第一First，我们的评估是在四个基准上进行的，涵盖代码生成（HumanEval Plus，MBPP）、数学推理（MATH-500）和检索增强的长格式 QA（ASQA）。尽管这些任务被广泛采用并且跨越多个代理领域，但, our evaluation is conducted on four benchmarks covering code generation (HumanEval Plus, MBPP), mathematical reasoning (MATH-500), and retrieval-augmented long-form QA (ASQA). Although these tasks are widely adopted and span multiple agentic domains, the generalization of程序路由器ProgRouter对于其他代理设置，例如开放式网络导航和工具增强的质量保证，仍有待实证验证。to other agentic settings, such as open-ended web navigation and tool-augmented QA, remains to be empirically verified.第二Second，多视图任务进度评分器需要轻量级域适应，其中根据任务特征指定可观察的工作流程里程碑和粗略结果制度。尽管当前的设计在不同的基准上提供了可靠的进度信号，但以完全端到端的方式自动学习这些进度表示仍然是一个有趣的方向。, the multi-view task progress scorer requires lightweight domain adaptation, where observable workflow milestones and coarse outcome regimes are specified according to task characteristics. Although the current design provides reliable progress signals across diverse benchmarks, automatically learning these progress representations in a fully end-to-end manner remains an interesting direction.

道德考虑Ethical Considerations

程序路由器ProgRouter旨在降低多代理LLM工作流程的能源消耗和运营成本，从而有助于更可持续的人工智能服务。由于我们的方法仅在现有的法学硕士之间进行路由，并且不会修改其基础功能，因此生成输出的质量、可靠性和潜在偏差仍然取决于所选模型。仔细的模型选择、输出验证、检索增强任务的引文检查以及人工监督等标准实践仍然是必要的。由于LLM路由决策是根据任务进度进行调整的，因此从业者应该监控不同任务类型的路由模式，以确保稳定的服务质量并避免意外地过度依赖特定模型。我们的实验使用公共基准，不涉及个人数据。然而，现实世界的部署可能会将用户信息存储在工作流状态或协调器账本中，因此应应用适当的数据保护措施，例如访问控制和数据保留策略。通过提高代理LLM工作流程的运营成本效率，is designed to reduce the energy consumption and operating costs of multi-agent LLM workflows, thereby contributing to more sustainable AI serving. Since our method only routes among existing LLMs and does not modify their underlying capabilities, the quality, reliability, and potential biases of generated outputs still depend on the selected models. Standard practices such as careful model selection, output verification, citation checking for retrieval-augmented tasks, and human oversight remain necessary. Because LLM routing decisions are adapted according to task progress, practitioners should monitor routing patterns across different task types to ensure stable service quality and avoid unintended over-reliance on particular models. Our experiments use public benchmarks and do not involve personal data. However, real-world deployments may store user information in workflow states or coordinator ledgers, so appropriate data protection measures, such as access control and data retention policies, should be applied. By improving the operating cost efficiency of agentic LLM workflows,程序路由器ProgRouter可以帮助使多代理法学硕士系统更具可持续性和可访问性。could help make multi-agent LLM systems more sustainable and accessible.

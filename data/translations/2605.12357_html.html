1 简介1 Introduction

随着大型语言模型（LLM）越来越多地部署在需要持续交互的内存密集型场景中，例如长期个性化助手（Packer et al., 2023; Jiang et al., 2025）和长视野代理系统（Yao et al., 2022; OpenAI, 2026; Anthropic, 2026），它们的生命周期必须超越响应孤立的提示，而是积累、更新和重用历史数据扩展内存密集型任务的信息（Yao et al., 2022；Shinn et al., 2023；Packer et al., 2023；Wang and Chen, 2025；Zhang et al., 2025b）。在这些设置中，模型性能不仅取决于对当前输入的理解，还取决于在测试期间有效利用相关的过去上下文（Laban 等人，2025；Zhong 等人，2024）。一种直观的方法是简单地扩展输入上下文并保留更多的交互历史记录。然而，这种策略只是将内存问题简化为长上下文处理问题，这不仅计算成本高，而且越来越难以利用。一方面，标准注意力会产生相对于上下文长度的二次成本（Yuan et al., 2025；Lei et al., 2025；Team et al., 2025）。另一方面，简单地增加上下文窗口并不能保证附加信息的有效使用，因为当上下文变得很长时，模型经常会遭受上下文退化或上下文腐烂（Hong et al., 2025; Du et al., 2025），这表明即使是百万个令牌上下文窗口（OpenAI; Google）也不能从根本上解决内存问题。这些限制需要更先进的内存机制（MM），可以在给定的上下文窗口内更紧凑地表示历史信息，As large language models (LLMs) are increasingly deployed in memory-heavy scenarios requiring continuous interaction, such as long-term personalized assistants (Packer et al., 2023; Jiang et al., 2025) and long-horizon agent systems (Yao et al., 2022; OpenAI, 2026; Anthropic, 2026), their life-cycle must go beyond responding to isolated prompts and instead accumulate, update, and reuse historical information over extended memory-heavy tasks (Yao et al., 2022; Shinn et al., 2023; Packer et al., 2023; Wang and Chen, 2025; Zhang et al., 2025b). In these settings, model performance depends not only on understanding the current input, but also on effectively leveraging relevant past context during test-time (Laban et al., 2025; Zhong et al., 2024). An intuitive way is to simply expand the input context and retain more interaction history. However, this strategy only reduces the memory problem to a long-context processing problem, which is both computationally expensive and increasingly difficult to harness. On the one hand, standard attention incurs quadratic cost with respect to context length (Yuan et al., 2025; Lei et al., 2025; Team et al., 2025). On the other hand, simply increasing the context window does not guarantee effective use of the additional information, as models often suffer from context degradation or context rot when the context becomes very long (Hong et al., 2025; Du et al., 2025), which suggests that even million-token context windows (OpenAI; Google) do not fundamentally solve the memory problem. These limitations call for more advanced memory mechanisms (MMs) that can represent historical information more compactly within a given context window,

从统一的角度来看，现有的记忆机制可以在给定的上下文窗口下沿两个维度进行表征：记忆状态（定义历史信息如何存储）和记忆转向（决定存储的信息如何影响骨干推理）。在此框架下，现有方法分为三种范式。文本记忆机制（TMM）（Packer et al., 2023；Zhong et al., 2024；Pan et al., 2024；Borgeaud et al., 2022；Chhikara et al., 2025）将内存存储为文本并通过输入上下文注入，在不改变架构的情况下提供灵活性，但会受到上下文窗口限制、检索噪声和不可避免的压缩损失的影响。外部通道记忆机制（OMM）（Wu et al., 2022; Wang et al., 2023; Wei et al., 2026）将记忆保存在外部模块中，并通过外部路径上的检索或编码与主干网交互，实现模块化，但会带来开销、集成复杂性以及与主干网的潜在错位。参数记忆机制（PMM）（Hu et al., 2022；Li and Liang, 2021；Meng et al., 2022a,b）将内存编码为前缀或适配器的参数，使其高效且与冻结主干网兼容，但其静态性质限制了对动态演变信息的适应。总而言之，这些限制表明需要一种记忆机制，该机制可以维持紧凑且动态演变的记忆状态，同时引导骨干网通过与其内部注意力计算紧密结合的路径。From a unified perspective, existing memory mechanisms can be characterized along two dimensions under a given context window: memory state, which defines how historical information is stored, and memory steering, which determines how stored information influences backbone reasoning. Under this framework, prior methods fall into three paradigms. Textual memory mechanisms (TMMs) (Packer et al., 2023; Zhong et al., 2024; Pan et al., 2024; Borgeaud et al., 2022; Chhikara et al., 2025) store memory as text and inject it through the input context, offering flexibility without architectural changes but suffering from context-window limits, retrieval noise, and inevitable compaction loss. Outside-channel memory mechanisms (OMMs) (Wu et al., 2022; Wang et al., 2023; Wei et al., 2026) keep memory in external modules and interact with the backbone via retrieval or encoding on outside pathways, enabling modularity but introducing overhead, integration complexity, and potential misalignments with the backbone. Parametric memory mechanisms (PMMs) (Hu et al., 2022; Li and Liang, 2021; Meng et al., 2022a,b) encode memory into parameters of prefixes or adapters, making them efficient and compatible with frozen backbones, but their static nature limits adaptation to dynamically evolving information. Taken together, these limitations point to a need for a memory mechanism that can maintain a compact and dynamically evolving memory state while steering the backbone through a pathway tightly aligned with its internal attention computation.

Early retrieval-augmented systems (Lewis et al., 2020; Borgeaud et al., 2022) demonstrate the effectiveness of scalable textual stores for knowledge-intensive generation, while later agent-oriented methods (Packer et al., 2023; Park et al., 2023; Zhong et al., 2024; Chhikara et al., 2025) extend this paradigm to continuous interaction by organizing past history and experience through logging, summarization, and

外通道记忆机制。Outside-Channel Memory Mechanisms.相关的工作将记忆存储在主干之外，同时以潜在形式而不是文本形式保存（Wu et al., 2022; Wang et al., 2023; Wei et al., 2026）。 Memorizing Transformers (Wu et al., 2022) 将过去的内部表示存储为不可微的键值记忆，并使用近似 kNN 检索它们，而 LongMem (Wang et al., 2023) 使用冻结主干作为内存编码器和自适应残差侧网络从外部内存库读取。与文本记忆相比，潜在记忆可以避免自然语言摘要引入的部分信息丢失，并保留更丰富的内部表征。然而，记忆仍然通过单独的检索或读取器路径与主干网络交互，从而引入检索开销、融合复杂性以及存储和当前表示之间可能的不匹配。A related line of work stores memory outside the backbone while preserving it in latent rather than textual form (Wu et al., 2022; Wang et al., 2023; Wei et al., 2026). Memorizing Transformers (Wu et al., 2022) store past internal representations as non-differentiable keyvalue memories and retrieve them with approximate kNN, while LongMem (Wang et al., 2023) uses a frozen backbone as a memory encoder and an adaptive residual side network to read from an external memory bank. Compared with textual memory, latent memory can avoid part of the information loss introduced by natural-language summarization and preserve richer internal representations. However, memory still interacts with the backbone through a separate retrieval or reader pathway, introducing retrieval overhead, fusion complexity, and possible mismatch between stored and current representations.δ-mem 的不同之处在于它的内存不是作为辅助外部源检索的；相反，其紧凑的在线状态直接对注意力计算产生低秩校正，允许内存参与当前的前向传递。-mem differs in that its memory is not retrieved as an auxiliary external source; instead, its compact online state directly produces low-rank corrections to the attention computation, allowing memory to participate in the current forward pass.

参数记忆机制。Parametric Memory Mechanisms.参数记忆机制将记忆编码为附加参数或局部权重编辑。 Prefix-Tuning（Li 和 Liang，2021）学习冻结模型的连续虚拟标记，而 LoRA（Hu 等人，2022）将低秩可训练更新注入选定的层，表明添加小参数可以有效地引导模型行为。 ROME（Meng 等人，2022a）和 MEMIT（Meng 等人，2022b）等模型编辑方法通过局部或低秩权重更新插入事实关联，进一步将参数视为可写存储基质。然而，这些方法不太适合在线记忆：它们的记忆通常在训练后固定或通过离散编辑步骤更新，而不是随着序列连续演变。它们的写入粒度也与交互历史不太一致，交互历史通常以令牌、消息或段级别的分辨率展开。因此，参数记忆通常充当对模型行为的持久修改，而不是影响随着当前历史而变化的状态条件记忆机制。Parametric memory mechanisms encode memory into additional parameters or localized weight edits. Prefix-Tuning (Li and Liang, 2021) learns continuous virtual tokens for a frozen model, while LoRA (Hu et al., 2022) injects low-rank trainable updates into selected layers, showing that small parameter additions can effectively steer model behavior. Model-editing methods such as ROME (Meng et al., 2022a) and MEMIT (Meng et al., 2022b) further treat parameters as a writable memory substrate by inserting factual associations through localized or low-rank weight updates. However, these methods are less suited to online memory: their memory is usually fixed after training or updated through discrete editing steps, rather than evolving continuously with the sequence. Their write granularity is also less aligned with interaction history, which often unfolds at token-, message-, or segment-level resolution. As a result, parametric memory often acts as a persistent modification to model behavior, rather than a state-conditioned memory mechanism whose influence changes with the current history.δ-mem 在低秩接口上与 LoRA 接近，但根本不同在于 LoRA 的低秩更新是静态的，而-mem is close to LoRA in its low-rank interface, but differs fundamentally in that LoRA’s low-rank update is static, whereasδ-mem 在运行时从紧凑的在线状态生成低等级注意力校正。-mem generates low-rank attention corrections from a compact online state at runtime.

7 结论7 Conclusion

在这项工作中，我们介绍了In this work, we introducedδ-mem，一种轻量级记忆机制，为冻结的全注意力主干配备紧凑且动态更新的关联记忆在线状态。-mem, a lightweight memory mechanism that equips a frozen full-attention backbone with a compact and dynamically updated online state of associative memory.δ-mem 将过去的信息压缩为固定大小的在线状态，并使用其读数来生成对主干注意力组件的低阶校正。这种设计允许内存在线维护并直接参与前向计算，而无需完全微调或更换主干架构。根据经验，-mem compresses past information into a fixed-size online state and uses its readout to generate low-rank corrections to the backbone’s attention components. This design allows memory to be maintained online and to directly participate in forward computation without full fine-tuning or replacing the backbone architecture. Empirically,δ-mem 提高了内存密集型基准测试的性能，同时在很大程度上保留了冻结主干的一般功能。值得注意的是，即使是非常小的 8-mem improves performance on memory-heavy benchmarks while largely preserving the general capabilities of the frozen backbone. Notably, even with an extremely small 8×在8个在线状态下，模型可以在删除显式上下文后恢复有用的历史信息，这表明有效记忆不需要扩展显式上下文或繁重的外部检索模块。这些结果表明，紧凑的在线状态可以作为冻结 Transformer 主干中测试时内存的可扩展且高效的接口。8 online state, the model can recover useful historical information after explicit context is removed, showing that effective memory does not require extending explicit context or heavy external retrieval modules.

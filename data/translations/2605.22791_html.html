1 简介Introduction

Transformer 架构已成为大型语言模型的主要支柱，因为自注意力使每个令牌可以直接访问其历史记录，并自然地映射到现代加速器上的并行训练。然而，它的成本仍然随着序列长度呈二次方增长。这种成本成为长上下文训练和高吞吐量推理的主要障碍，其中模型必须重复处理比单个注意力头的维度长得多的历史。The Transformer architecture has become the dominant backbone for large language models because self-attention gives each token direct access to its history and maps naturally to parallel training on modern accelerators. Its cost, however, still grows quadratically with sequence length. This cost becomes a central obstacle for long-context training and high-throughput inference, where the model must repeatedly process histories that are much longer than the dimension of a single attention head.

线性循环注意力采取了不同的路径。它将显式注意力矩阵替换为固定大小的循环状态，将序列混合转变为线性时间循环，其记忆不随上下文长度而增长Linear recurrent attention takes a different path. It replaces the explicit attention matrix with a fixed-size recurrent state, turning sequence mixing into a linear-time recurrence whose memory does not grow with context length[1]。吸引力是明确的，但限制也是明确的。状态是压缩的键值记忆，长上下文迫使许多关联共享相同的有限空间，使得精确检索变得困难. The appeal is clear, but so is the constraint. The state is a compressed key-value memory, and long contexts force many associations to share the same finite space, making exact retrieval difficult[2, 3, 4, 5, 6, 7]。最近的研究通过让复发者更好地控制持续存在的内容，改善了这种记忆。 Mamba-2 使用数据相关衰减来调节内存范围. Recent work has improved this memory by giving the recurrence more control over what persists. Mamba-2 uses data-dependent decay to regulate the memory horizon[8]。 DeltaNet 用增量规则替换附加写入，从而能够有针对性地覆盖当前密钥所寻址的关联. DeltaNet replaces additive writes with the delta rule, enabling targeted overwrite of the association addressed by the current key[9, 2, 10]。门控 DeltaNet 将 Delta 规则与学习的衰减门相结合，为状态提供全局遗忘和有针对性的编辑. Gated DeltaNet combines the delta rule with a learned decay gate, giving the state both global forgetting and targeted editing[11]。 Kimi Delta Attention (KDA) 通过通道方式遗忘关键维度来细化衰减侧. Kimi Delta Attention (KDA) refines the decay side with channel-wise forgetting over the key dimension[12]。与此同时，Mamba-3 通过指数梯形离散化、复值状态转换以及多输入、多输出公式来推进状态空间路线，以实现更强、更高效的递归. In parallel, Mamba-3 advances the state-space route through exponential-trapezoidal discretization, complex-valued state transitions, and a multi-input, multi-output formulation for stronger and more efficient recurrence[13]。这些进步推动了循环线性模型向前发展，同时使增量规则内存中剩余的瓶颈更加明显。主动编辑仍然使用一个标量门来控制擦除旧内容和写入新内容。. These advances have pushed recurrent linear models forward, while making the remaining bottleneck in delta-rule memory more visible. The active edit still uses one scalar gate to control both erasing old content and writing new content.

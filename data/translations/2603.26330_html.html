摘要Abstract

3.2 为什么固定聚合是不够的Why Fixed Aggregation Is Insufficient

虽然固定查询基线对于诊断很有用，但它在两个重要方面仍然受到限制。While the fixed-query baseline is useful for diagnosis, it remains limited in two important respects.

输入不变路由。Input-invariant routing.无论当前隐藏状态如何，相同的学习查询都会应用于所有输入。 这隐含地假设所有示例都应该以相同的方式检索早期的表示，即使不同的输入可能需要不同形式的跨深度访问。The same learned query is applied to all inputs regardless of the current hidden state. This implicitly assumes that all examples should retrieve earlier representations in the same way, even though different inputs may require different forms of cross-depth access.

模态统一路由。Modality-uniform routing.视觉和文本标记共享相同的路由机制，尽管这两种模式可能表现出不同的深度处理模式。 对于 VLM 来说，这种共享路由策略是有限制的，因为应该检索用于感知和推理的表示可能不会在深度上遵循相同的结构。Visual and textual tokens share the same routing mechanism, although the two modalities may exhibit different depth-wise processing patterns. For VLMs, this shared routing strategy is restrictive because the representations that should be retrieved for perception and reasoning may not follow the same structure across depth.

这些限制激发了一种更具表现力的表述，其中跨深度检索被视为条件路由问题。 IADA 没有使用在所有示例中共享的全局查询，而是从当前隐藏状态生成聚合查询，并允许路由行为在不同模式之间有所不同。These limitations motivate a more expressive formulation in which cross-depth retrieval is treated as a conditional routing problem. Instead of using a global query shared across all examples, IADA generates aggregation queries from the current hidden state and allows the routing behavior to differ across modalities.

3.4 与 PEFT 的关系Relation to PEFT

IADA 旨在补充而不是取代 LoRA 等标准 PEFT 方法。 LoRA 通过修改各个变压器块内的线性算子来适应层内变换。 相比之下，IADA 通过显式建模当前隐藏状态如何从早期块检索表示来适应跨深度访问。 因此，这两种机制在不同的适应轴上运行，并且可以自然地组合。IADA is designed to complement rather than replace standard PEFT methods such as LoRA. LoRA adapts within-layer transformations by modifying linear operators inside individual transformer blocks. In contrast, IADA adapts across-depth access by explicitly modeling how the current hidden state retrieves representations from earlier blocks. The two mechanisms therefore operate on different adaptation axes and can be combined naturally.

Existing PEFT methods, including LoRA[10]，主要修改各个层内的转换。 相比之下，IADA 在不同的轴上运行：它改变了模型跨深度访问和重用表示的方式。 从这个意义上说，我们的贡献不仅仅是另一个 PEFT 变体，而是证据, primarily modify transformations inside individual layers. Our results suggest that preserving cross-depth representational access is an important missing factor during fine-tuning, and that making this access input-adaptive yields further gains. Based on this observation, we proposed IADA, a lightweight mechanism for input-adaptive depth aggregation.

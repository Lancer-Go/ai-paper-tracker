# AI 学术热度追踪平台 - 项目定义与背景

> 本文档用于对齐“我们为什么要做这个项目”以及“这个项目到底管什么边界”。

## 1. 业务痛点与起因 (Why)
- **发现的问题（痛点）**：
  1. **信息过载严重**：每日 AI 论文新增数以百计，学者和从业者需要耗费大量精力去“淘金”，极易错过关键的里程碑式研究。
  2. **语言与专业门槛高**：前沿学术论文多为全英文编写，且充满晦涩的专业术语。对于非英语母语者或跨界了解 AI 的人群，理解成本极高，导致信息差被拉大。
  3. **缺乏客观追踪标准**：现有的聚合平台通常基于人为推荐或简单的社交媒体热度，缺乏基于“真实学术引用增速（如 OpenAlex 数据）”的客观热度指标。
- **解决的价值**：提供高度自动化的论文热榜聚合体系。不仅能帮助学者提升文献调研效率，更有利于打破语言壁垒，让新资讯更快在社区内流通。

## 2. 项目目标 (What - SMART原则)
- **核心业务目标**：
  1. **自动化追踪追踪**：实现每日定时（06:00 UTC）自动爬取、打分和静态页面生成的全流程闭环，零人工干预。
  2. **构建科学评价体系**：结合引用量绝对值与短期增速，科学反映论文当前的热度趋势。
  3. **降低阅读门槛**：为非英语受众提供精简、高可读性的摘要或关键资讯提取（规划中/逐步演进）。

## 3. 项目范围边界 (Scope)
- ✅ **包含范围 (In-Scope)**：
  - 核心数据爬取链条（arXiv 核心字段抓取）。
  - OpenAlex 引用量获取与热度关联。
  - 自动化权重打分与去重模块。
  - 静态可视化前端（React + Vite）展示每日热度榜。
  - 自动化工作流部署（GitHub Actions + GitHub Pages）。
- ❌ **不包含范围 (Out-of-Scope)**：
  - 全量历史论文的深度检索与搜索引擎。（本项目重点在“热度追踪”，不在于“大而全的文库”）
  - 直接下载及存储论文原版 PDF 的服务（主要提供核心信息与外链）。

## 4. 关键干系人 (Who)
- **业务方/发起人**：AI 领域研究者及平台用户
- **产品/研发负责人**：Lancer-Go (核心开发)

Microsoft

摘要Abstract

现实的长期生产力工作很大程度上取决于特定于用户的计算机环境，其中大部分工作上下文是通过目录结构和内容丰富的工件来存储和组织的。为了扩展此类生产力场景的合成数据创建，我们引入了大规模合成计算机，这是一种可扩展的方法，用于创建具有真实文件夹层次结构和内容丰富的工件（例如文档、电子表格和演示文稿）的此类环境。以每台合成计算机为条件，我们运行长期模拟：一个代理创建特定于计算机用户的生产力目标，需要多个专业交付成果和大约一个月的人工工作；然后，另一个代理充当该用户并继续在计算机上工作，例如，导航文件系统以进行接地、与模拟协作者协调以及生成专业工件，直到完成这些目标。Realistic long-horizon productivity work is strongly conditioned on user-specific computer environments, where much of the work context is stored and organized through directory structures and content-rich artifacts. To scale synthetic data creation for such productivity scenarios, we introduce Synthetic Computers at Scale, a scalable methodology for creating such environments with realistic folder hierarchies and content-rich artifacts (e.g., documents, spreadsheets, and presentations). Conditioned on each synthetic computer, we run long-horizon simulations: one agent creates productivity objectives that are specific to the computer’s user and require multiple professional deliverables and about a month of human work; another agent then acts as that user and keeps working across the computer—for example, navigating the filesystem for grounding, coordinating with simulated collaborators, and producing professional artifacts—until these objectives are completed.

在初步实验中，我们创建了 1,000 台合成计算机并对它们进行长期模拟；每次运行需要超过 8 个小时的代理运行时间，平均跨越 2,000 多个回合。这些模拟产生了丰富的体验式学习信号，其有效性通过域内和域外生产力评估的代理性能的显着改进得到了验证。鉴于人物角色在数十亿规模上非常丰富，这种方法原则上可以扩展到数百万甚至数十亿个具有足够计算能力的合成用户世界，从而更广泛地覆盖不同的职业、角色、背景、环境和生产力需求。我们认为，可扩展的合成计算机创建与大规模模拟一起，作为长期生产力场景中智能体自我改进和智能体强化学习的基础，非常有前景。In preliminary experiments, we create 1,000 synthetic computers and run long-horizon simulations on them; each run requires over 8 hours of agent runtime and spans more than 2,000 turns on average. These simulations produce rich experiential learning signals, whose effectiveness is validated by significant improvements in agent performance on both in-domain and out-of-domain productivity evaluations. Given that personas are abundant at billion scale, this methodology can in principle scale to millions or even billions of synthetic user worlds with sufficient compute, enabling broader coverage of diverse professions, roles, contexts, environments, and productivity needs. We argue that scalable synthetic computer creation, together with at-scale simulations, is highly promising as a foundational substrate for agent self-improvement and agentic reinforcement learning in long-horizon productivity scenarios.

This makes synthetic data necessary, but difficult to create well: realistic user environments are complex, heterogeneous, and artifact-rich, with diverse directory structures, professional artifacts, and accumulated work history(Feng et al., 2025; Copet et al., 2025; Cai et al., 2025).

3 远景生产力模拟Long-Horizon Productivity Simulation

The resulting trajectory provides process-level signals from the agent’s planning, grounding, collaboration, and revision behavior, while the final deliverables provide outcome-level signals about whether the productivity objectives were completed successfully.

With only 10 training computers, the skill-augmented agent does not improve over the baseline, likely because the training set covers too few occupations. Skills extracted from 100, 500, and 900 computers win on 64%, 75%, and 83% of the test computers, respectively. This scaling trend suggests that broader simulation coverage leads to more useful and better-targeted experiential skills.

5 讨论Discussion

5.1 迈向自我提高的生产力代理人Toward Self-Improving Productivity Agents

上述结果表明了一条通往自我提高生产力的有希望的道路。合成计算机可以在不依赖私人用户数据的情况下运行大量真实的长期模拟。这些模拟从过程和结果中产生丰富的经验信号：代理如何计划、搜索、使用文件、协作、修改工件、失败、恢复以及最终完成专业交付成果。正如我们的实验所示，这些信号可以转化为提高代理性能的技能，并且随着使用更多模拟，收益会增加。The results above suggest a promising path toward self-improving productivity agents. Synthetic computers make it possible to run large numbers of realistic long-horizon simulations without relying on private user data. These simulations produce rich experiential signals from both process and outcome: how agents plan, search, use files, collaborate, revise artifacts, fail, recover, and finally complete professional deliverables. As shown in our experiments, these signals can be turned into skills that improve agent performance, and the gains increase as more simulations are used.

图Figure9说明了这种方法所实现的更广泛的循环。我们可以首先创建不同的合成计算机，对它们进行长期生产力模拟，并从结果轨迹中提取经验教训、故障模式和有用的工作模式。这些信号可以转化为技能，从而提供一种快速且可解释的方式来改善代理行为。随着模拟数量的增加，技能集可以变得更广泛、更有针对性，涵盖更多的专业、工作流程、文件结构和协作模式。illustrates the broader loop enabled by this methodology. We can first create diverse synthetic computers, run long-horizon productivity simulations on them, and extract lessons, failure modes, and useful work patterns from the resulting trajectories. These signals can be converted into skills, which provide a fast and interpretable way to improve agent behavior. As the number of simulations grows, the skill set can become broader and better targeted, covering more professions, workflows, file structures, and collaboration patterns.

基于技能的改进是一种方便的中间学习形式Skill-based improvement is a convenient intermediate form of learning(Xia et al., 2026a; b; Lu et al., 2026; Cai et al., 2026)。它迭代速度快，易于检查，并且可用于验证提取的经验是否可以改善代理行为。然而，不断增长的技能组合最终可能会变得太大而无法作为外部指令进行携带，从而降低了其有用性并增加了代理的负担。因此，下一步自然是使用这些信号来更新底层模型，以便将有用的行为内化，而不是仅作为外部技能进行携带。在这样的更新之后，可以重置技能集，并且可以使用更强的模型来运行下一轮模拟。这就形成了一个重复的改进循环：更多的模拟产生更多的经验信号；这些信号可以产生更好的技能；这些技能可以改善代理人的行为；改进后的行为会被折回到为下一轮模拟提供动力的代理中。. It is fast to iterate on, easy to inspect, and useful for validating whether the extracted experience improves agent behavior. However, an ever-growing skill set can eventually become too large to carry as external instructions, reducing its usefulness and increasing the burden on the agent. A natural next step is therefore to use these signals to update the underlying model, so that useful behaviors are internalized rather than carried only as external skills. After such an update, the skill set can be reset, and the stronger model can be used to run the next round of simulations. This creates a repeated improvement cycle: more simulations produce more experiential signals; these signals produce better skills; the skills improve agent behavior; and the improved behavior is folded back into the agent that powers the next round of simulation.

5.2 通过仿真和模型功能进行扩展Scaling with Simulation and Model Capability

这种方法也符合合成数据的更广泛趋势：随着模拟规模和模型能力的增加，数据生成过程可以得到改进。合成计算机在三个维度上创造了有利的缩放动态。This methodology also aligns with a broader trend in synthetic data: the data generation process can improve as both simulation scale and model capability increase. Synthetic computers create a favorable scaling dynamic along three dimensions.

更多的模拟可以丰富和区分计算机环境。More simulations can enrich and differentiate the computer environments.在我们的实验中，每次模拟都从由Section创建的冷启动合成计算机开始In our experiments, each simulation starts from a cold-start synthetic computer created by Section2。然而，一次模拟后更新的计算机也可以成为以后模拟的起点。这意味着同一台计算机可以支持累积工作历史的不同阶段的许多上下文，具有不同的工件、修订、反馈、协作者交换和项目状态。随着运行更多的模拟，环境不仅变得更加丰富，而且对于用户来说也更加具体：重复的模拟添加了具体的工作历史、选择、错误、偏好和工件轨迹，使每台计算机变得越来越独特。. However, an updated computer after one simulation can also become the starting point for later simulations. This means the same computer can support many contexts at different stages of accumulated work history, with different artifacts, revisions, feedback, collaborator exchanges, and project state. As more simulations are run, the environments become not only richer, but also more specific to their users: repeated simulations add concrete work history, choices, mistakes, preferences, and artifact trails that make each computer increasingly distinct.

更强大的代理可以创建更好的工件和工作流程。Stronger agents can create better artifacts and workflows.随着智能体的改进，模拟工作也应该变得更加真实。更强大的代理可以创建更高质量的文档、电子表格、演示文稿、分析和支持文件。他们还可以更连贯地计划，更仔细地使用文件系统，更自然地与协作者协调，并以更好地匹配真实专业工作流程的方式修改工件。As agents improve, the simulated work should also become more realistic. Stronger agents can create higher-quality documents, spreadsheets, presentations, analyses, and supporting files. They can also plan more coherently, use the filesystem more carefully, coordinate with collaborators more naturally, and revise artifacts in ways that better match real professional workflows.

更强大的模型可以从轨迹中提取更好的经验教训。Stronger models can extract better lessons from trajectories.模拟的价值还取决于我们分析它的程度。更强大的模型可以更准确地判断最终可交付成果，识别微妙的故障模式，并将有用的工作模式总结为更高质量的学习信号。这些更好的信号可以改进下一轮的技能、训练数据和代理行为。The value of a simulation also depends on how well we can analyze it. Stronger models can judge final deliverables more accurately, identify subtle failure modes, and summarize useful work patterns into higher-quality learning signals. These better signals can then improve the next round of skills, training data, and agent behavior.

总之，这些效应表明，随着规模的扩大，合成计算机可以变得更有价值。更多的模拟丰富了环境，更强大的代理产生更好的轨迹，更强大的模型从这些轨迹中提取更好的经验。这使得合成计算机成为大规模生成真实、高信号生产力数据的有前途的基础。Together, these effects suggest that synthetic computers can become more valuable as they scale. More simulations enrich the environments, stronger agents produce better trajectories, and stronger models extract better experience from those trajectories. This makes synthetic computers a promising substrate for generating realistic, high-signal productivity data at scale.

5.3 迈向可扩展的生产智能Toward Scalable Productive Intelligence

合成计算机还提出了一种更广泛的方法来跨领域扩展生产性工作。关键思想不仅是生成更多任务，而且是扩展生产性工作发生的现实环境。Synthetic computers also suggest a broader way to scale productive work across domains. The key idea is not only to generate more tasks, but to scale the realistic contexts in which productive work happens.

合成计算机可以根据角色进行扩展。Synthetic computers can scale with personas.该方法的起点是角色，并且可以大规模生成和采样角色。有了足够的计算能力，就可以创建大量的合成计算机，涵盖不同的职业、组织、工作流程、工作方式和生产力需求。角色池的多样性还有助于使生成的环境具有高度差异化：管道不是生成许多类似的文件系统，而是创建在项目、工件、组织模式和累积工作上下文方面各不相同的用户特定计算机。这些环境还可以代表高技能的专业环境，例如高级顾问、专家分析师、研究人员、律师、操作员、设计师、工程师和其他领域专家The starting point of this methodology is a persona, and personas can be generated and sampled at very large scale. With sufficient compute, this makes it possible to create large populations of synthetic computers that cover diverse professions, organizations, workflows, work styles, and productivity needs. The diversity of the persona pool also helps make the resulting environments highly differentiated: instead of producing many similar filesystems, the pipeline creates user-specific computers that vary in projects, artifacts, organization patterns, and accumulated work context. 合成计算机为长期工作提供了练习场。Synthetic computers provide a practice ground for long-horizon work.有价值的生产力工作很少仅由简短的提示来定义。它基于用户积累的背景：先前的文档、电子表格、演示文稿、项目状态、协作者反馈、偏好、约束和过去的决策。合成计算机使这种上下文变得明确且可扩展。它们为代理提供了长期实践规划、基础、协调、修订和恢复的环境，而不仅仅是解决孤立的任务。随着环境变得更加丰富且更加针对用户，模拟成为改善代理行为的更强大的经验来源。除了我们的生产力模拟之外，合成计算机还可能使相关设置受益。例如，使用计算机的代理Valuable productivity work is rarely defined by a short prompt alone. It is grounded in a user’s accumulated context: prior documents, spreadsheets, presentations, project state, collaborator feedback, preferences, constraints, and past decisions. Synthetic computers make this context explicit and scalable. They give agents environments in which to practice planning, grounding, coordination, revision, and recovery over long horizons, rather than only solving isolated tasks. As the environments become richer and more user-specific, the simulations become a stronger source of experience for improving agent behavior. Synthetic computers may also benefit related settings beyond our productivity simulations. They can become a way to explore and produce useful work across many realistic professional settings. If an agent can handle the same kinds of files, histories, constraints, and collaborations that shape human productivity work, it can begin to create high-value outputs in those contexts. In this view, scaling synthetic computers is also a path toward scaling productive intelligence across files, people, projects, and time.

6 结论和未来的工作Conclusion and Future Work

我们提出了大规模合成计算机，这是一种创建真实的、特定于用户的计算机环境并将其用作长期生产力模拟的基础的方法。我们的实验表明，这些模拟产生了有用的经验信号，可以在保留的合成计算机和外部生产力基准上改进代理。这些结果表明，合成计算机可以作为长期生产力场景中智能体自我改进的有前景的基础。We presented Synthetic Computers at Scale, a methodology for creating realistic, user-specific computer environments and using them as the basis for long-horizon productivity simulation. Our experiments show that these simulations produce useful experiential signals that improve agents both on held-out synthetic computers and on an external productivity benchmark. These results suggest that synthetic computers can serve as a promising substrate for agent self-improvement in long-horizon productivity scenarios.

展望未来，我们指出了使合成计算机更接近真实用户环境的几个方向：Looking ahead, we point to several directions for making synthetic computers even closer to real user environments:

首先，神器设计可以更加个性化。First, artifact design can be more personalized.当前的工件以用户的角色、项目和文件为基础，但它们的视觉风格和格式在计算机之间仍然过于统一。未来的管道可以推断用户或组织特定的设计偏好，因此工件不仅在内容上有所不同，而且在风格、布局和格式习惯上也有所不同。Current artifacts are grounded in the user’s role, projects, and files, but their visual style and formatting can still be too uniform across computers. Future pipelines could infer user- or organization-specific design preferences, so that artifacts vary not only in content, but also in style, layout, and formatting habits.

其次，文件系统可以包含更多的自然噪声和累积的历史记录。Second, filesystems can include more natural noise and accumulated history.真实的计算机包含任意日常行为的痕迹，例如临时下载、重复草稿、废弃文件、屏幕截图、网络保存、过时材料以及与主要项目无关的文件。更真实地对此类日常痕迹进行建模将使合成计算机变得不那么干净并且更加像人类。Real computers contain traces of arbitrary daily behavior, such as temporary downloads, duplicate drafts, abandoned files, screenshots, web saves, outdated materials, and files unrelated to the main projects. Modeling such everyday traces more realistically would make synthetic computers less clean and more human-like.

第三，协作可以更加活跃。Third, collaboration can be made more dynamic.我们当前的模拟协作者大多是被动的，而真实的协作者有自己的工作、文件、会议、电子邮件、截止日期和不断变化的状态。更丰富的多代理组织模拟可以使协作、协调、会议、电子邮件和组织环境更接近真实的生产力工作。Our current simulated collaborators are mostly reactive, while real collaborators have their own work, files, meetings, emails, deadlines, and evolving state. Richer multi-agent organizational simulation could make collaboration, coordination, meetings, email, and organizational context closer to real productivity work.

这些方向具有挑战性，但通过当前的建模和代理能力是可以实现的；它们主要需要更仔细的设计和持续的投资，但潜在的回报是巨大的：在能力日益增强的代理人和仍然植根于丰富、不断发展的人类环境的高价值生产力工作之间架起一座桥梁。These directions are challenging but achievable with current modeling and agent capabilities; they mainly require more careful design and sustained investment, but the potential payoff is substantial: a bridge between increasingly capable agents and the high-value productivity work that remains grounded in rich, evolving human contexts.

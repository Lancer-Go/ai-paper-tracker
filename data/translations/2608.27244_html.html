2.2 LLM 通话背后的在线学习Online Learning Behind the LLM Call

在法学硕士领域，在线运作的每一层都会重复出现一种结构模式。每个 LLM 调用都会生成一个或多个监督信号（调用的输出、对采样行的预言判断或真实标签）。系统在它们到达时对其进行缓冲，并且学习器与下一轮的 LLM 调用同时运行，消耗缓冲区并写回到优化器在下一个决策时参考的学习工件。One structural pattern recurs across every layer that operates online in the LLM-bound regime. Each LLM call generates one or more supervision signals (the call’s output, an oracle judgment on a sampled row, or a ground-truth label). The system buffers them as they arrive, and a learner runs concurrently with the next round’s LLM call(s), consuming the buffer and writing back to a learned artifact that the optimizer consults on the next decision.

过滤器排序 (Larch) 和级联路由 (GAMCAL) 这两个学习组件按固定顺序运行：首先进行过滤器排序，然后对每个评估的谓词进行每行级联路由。总成本取决于每个组件的独立行为以及上游如何重塑下游看到的分布，因此我们将组合描述为具有成本语义的霍尔式规则。该规则使乘法分解假设变得明确，并将跨组件交互分为前向前提条件不匹配和后向监督流。The two learning components, filter ordering (Larch) and cascade routing (GAMCAL), run in a fixed order: filter ordering first, then per-row cascade routing on each evaluated predicate. Total cost depends on each component’s standalone behavior and on how the upstream reshapes the distribution the downstream sees, so we state composition as a Hoare-style rule with cost semantics. The rule makes the multiplicative-decomposition assumption explicit and classifies cross-component interactions into forward precondition mismatches and a backward supervision flow.

8 讨论Discussion

该框架及其组成分析留下了四个开放方向：填充设计表面的其余部分，加强组件之间的组合，跨查询边界扩展学习循环，以及协调组件的异构质量语义。The framework and its composition analysis leave four open directions: filling the rest of the design surface, tightening composition across the components in place, extending the learning loop across query boundaries, and reconciling the components’ heterogeneous quality semantics.

9 结论Conclusion

我们开发了一个基于延迟窗口观察的 LLM 调用边界在线学习组合框架：CPU 端学习器的更新适合 LLM 往返，打开了经典自适应查询处理无法达到的机制。 Cortex AISQL 填充框架设计空间的三个单元。影响成本的两个因素We have developed a framework for online-learning composition at the LLM call boundary, built on the latency-window observation: a CPU-side learner’s update fits inside the LLM round-trip, opening a regime classical adaptive query processing could not reach. Cortex AISQL populates three cells of the framework’s design space. The two cost factors of an人工智能过滤器AI_FILTER运算符被分解为两个学习组件。过滤器排序减少了每行 LLM 评估谓词的预期数量，级联路由减少了升级到预言机的评估谓词的比例。两个组件都实例化相同的学习模式，以在线每调用节奏进行过滤器排序，并以在线每批次节奏进行级联路由。每个都将其训练计算隐藏在其之前的 LLM 调用的往返后面。响应缓存通过精确记忆而不是在线估计来覆盖相同的边界。operator are decomposed across two learning components. Filter ordering reduces the expected number of LLM-evaluated predicates per row, and cascade routing reduces the fraction of evaluated predicates that escalate to the oracle. Both components instantiate the same learning pattern, with filter ordering at an online per-call cadence and cascade routing at an online per-batch cadence. Each hides its training compute behind the round-trip of the LLM call it precedes. Response caching covers the same boundary through exact memoization rather than online estimation.

LLM 原生数据系统将更少地由任何单个算子的语义来定义，而更多地由算子所嵌入的分层的、延迟预算感知的优化架构来定义。学习模式是该架构的一种表达。下一步自然是对大规模组合论证、跨查询学习、跨组件的联合控制器以及设计空间中的未来层进行实证验证。LLM-native data systems will be defined less by the semantics of any individual operator and more by the layered, latency-budget-aware optimization architecture in which the operators are embedded. The learning pattern is one expression of that architecture. The natural next steps are empirical validation of the composition argument at scale, cross-query learning, joint controllers across components, and future layers in the design space.

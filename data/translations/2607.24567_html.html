摘要Abstract近年来，用于生成短二进制哈希码的语义哈希方法得到了广泛的考虑，这些哈希码允许在高维数据空间中进行有效的近似最近邻搜索。与依赖手动特征工程的传统方法相比，基于深度学习的方法提供了更好的语义捕获能力。此外，它们支持数据驱动的方法来跨不同数据模态进行语义哈希，从而在共享汉明空间内生成高质量的跨模态哈希代码。之前的工作研究了这个汉明空间的属性，并引入了一种基于预定义的所谓语义通道的损失函数，该语义通道具有固定宽度和从标签相似性导出的汉明距离。然而，这种表述也给损失情况带来了不连续性，使优化变得复杂。基于这些观察，我们提出了一种新设计的损失函数，动态语义通道哈希（DSCH），使用动态大小和定位的语义通道以避免损失景观不连续性。此外，我们支持使用平局感知平均平均精度（mAP）作为评估指标，因为它解决了样本检索排序中的模糊性，这种模糊性是由于哈希码距离的离散性而出现的。最后，在两个流行数据集上进行的多个实验设置并结合两种不同的模型架构提供了强有力的证据，证明使用 DSCH 目标的训练优于使用其他最先进的损失函数的训练。在 40 个跨模态和模内检索任务中的总共 35 个任务中，使用 DSCH 训练的模型在所有四个测试的哈希码长度上实现了显着更高的平局感知 mAP 分数，在模型架构和使用的数据集中显示了令人信服的结果。 mAP 分数提升一致，最高可达 1—Semantic hashing methods for generating short binary hash codes that allow efficient approximate nearest neighbor search in high-dimensional data spaces have gained extensive consideration in recent years. Deep learning-based methods offer better semantic capturing capabilities than traditional approaches relying on manual feature engineering. Moreover, they enable a data-driven approach to semantic hashing across diverse data modalities, yielding high-quality cross-modal hash codes within a shared Hamming space. Previous work investigated the properties of this Hamming space and introduced a loss function based on predefined so-called semantic channels with fixed width and Hamming distances derived from label similarities. However, this formulation also introduced discontinuities into the loss landscape, complicating optimization. Based on these observations, we propose a newly designed loss function, Dynamic Semantic Channel Hashing (DSCH), using dynamically sized and positioned semantic channels in order to avoid loss landscape discontinuities. Furthermore, we endorse the use of tie-aware Mean Average Precision (mAP) as evaluation metric as it addresses the ambiguity in sample retrieval ordering, which emerges from the discreteness of hash code distances. Finally, multiple experimental settings conducted on two popular datasets and incorporating two different model architectures provide strong evidence that training using the DSCH objective outperforms training using other state-ofthe-art loss functions. In a total of 35 out of 40 cross-modal and intra-modal retrieval tasks, models trained with DSCH achieve significantly higher tie-aware mAP scores across all four tested hash code lengths, showing compelling results across model architecture and used dataset. A.（深度）语义哈希A. (Deep) Semantic Hashing

散列是通过将输入投影到低维汉明空间来将高维数据映射到短二进制散列码的过程[1]。这种高维输入数据可以包括各种模态，包括图像、文本、音频和视频，以及其他结构化或非结构化数据类型[1]、[2]、[3]。在语义哈希的背景下，目标是找到一个哈希函数，将语义相似的输入映射到相似或相同的哈希码，以促进最近邻搜索 [1]、[2]。任意两个哈希码之间的汉明距离可以很容易地计算为不同二进制数字（位）的数量。良好的语义哈希函数的特点是能够针对相似的输入输出接近的（即距离较小的）哈希码，并同时针对不同的输入输出较远的哈希码[1]。具体的语义哈希函数可能追求不同的算法目标，例如，它可以针对创建哈希表进行优化，也可以针对哈希码排名进行设计[3]。无论哪种方式，这些哈希函数都可以被设计或学习，深度语义哈希的范例是从使用深度神经网络的端到端哈希函数学习中出现的[1]。罗等人。 [1] 对此主题进行了全面的调查。Hashing is the process of mapping high-dimensional data to short binary hash codes by projecting the input into a lowdimensional Hamming space [1]. Such high-dimensional input data may comprise various modalities, including images, text, audio, and video, as well as other structured or unstructured data types [1], [2], [3]. In the context of Semantic Hashing, the goal is to find a hash function that maps semantically similar inputs to similar or identical hash codes to facilitate nearest neighbor search [1], [2]. The Hamming distance between any two hash codes can be easily computed as the number of differing binary digits (bits). Good semantic hash functions are characterized by their ability to output hash codes that are close, i.e., have a small distance, for similar inputs and simultaneously output distant hash codes for dissimilar inputs [1]. There are different algorithmic goals a concrete semantic hash function may pursue, e.g., it may be optimized for creating hash tables or it may be designed for hash code ranking [3]. Either way, these hash functions can either be crafted or learned and the paradigm of Deep Semantic Hashing emerges from end-to-end hash function learning using deep neural networks [1]. Luo et al. [1] present a comprehensive survey on this topic.

B. 跨模态检索B. Cross-Modal Retrieval

如上一节所述，语义哈希允许使用高质量哈希代码作为高维基础数据的替代项来进行有效的相似性搜索。在之前的工作中，哈希函数对单模态输入数据进行操作，例如仅图像或仅文本，参见[5]、[6]、[7]、[8]、[9]，其中跨模态 DSH 领域最早的工作之一是由 Jiang 和 Li 完成的 [10]。As stated in the previous section, Semantic Hashing allows for an efficient similarity search using high-quality hash codes as surrogates for the high-dimensional underlying data. In previous work, the hash function operates on single-modal input data, e.g., only images or only text, see [5], [6], [7], [8], [9], with one of the earliest work in the cross-modal DSH domain done by Jiang and Li [10].

然而，最近的研究侧重于多模态哈希，其目的是将来自不同模态的数据投影到共享的汉明空间中[1]，[3]。这允许所谓的跨模式检索，例如可以使用文本搜索图像，反之亦然。在他们的文献综述中，王等人。 [3] 提出了跨模式检索的详细分类法，区分了监督和无监督以及实值和基于散列的方法。尽管研究了许多媒体模式的组合，但目前研究的主要焦点在于文本图像检索[3]，如[11]、[12]、[13]、[14]、[15]、[16]、[17]、[18]、[19]所示。More recent research, however, focuses on multi-modal hashing, which aims to project data from different modalities into a shared Hamming space [1], [3]. This allows for so-called cross-modal retrieval, such that for example images can be searched using text and vice versa. In their literature review, Wang et al. [3] present an elaborate taxonomy on cross-modal retrieval, differentiating between supervised and unsupervised as well as real-valued and hashing-based approaches. Although many combinations of media modalities are studied, the main focus of research currently lies upon the text-image retrieval [3] as seen in [11], [12], [13], [14], [15], [16], [17], [18], [19].

C. 模型架构C. Model Architectures

在跨模态 DSH 的背景下，人们提出了多种神经网络架构并将其应用于该问题 [1]、[3]。一种基本方法是使用现成且通常预先训练的图像模型，例如卷积神经网络（CNN）[20]、[21]，例如 ResNet [22]，并用哈希学习多层感知器（MLP）[1]、[3] 替换其分类头。对于文本模态，通常使用简单的 MLP 将词袋 (BoW) 向量投影为哈希码，如 [10]、[18]、[23]、[24] 中所示。然而，最近的出版物纳入了 Transformer 架构 [25]，该架构对令牌嵌入进行操作，并支持自然语言处理 [26] 的最新进展。 DSH 模型架构可以分为两种主要方法：单流和双流架构 [3]、[4]。前者由单个模块组成，该模块以统一的方式对不同模态的输入进行操作，而后者针对每种模态使用一个模块 [3]、[4]。还存在混合方法，它将按模态特征提取与共享哈希学习模块相结合[4]。In the context of cross-modal DSH a variety of neural network architectures have been proposed and applied to the problem [1], [3]. A fundamental approach is to use an off-theshelf and often pre-trained image model, e.g., a Convolutional Neural Network (CNN) [20], [21] such as ResNet [22], and replace its classification head with a hash-learning Multilayer Perceptron (MLP) [1], [3]. For the text modality, it is common to use simple MLPs projecting Bag of Words (BoW) vectors to hash codes as seen in [10], [18], [23], [24]. However, recent publications incorporate the Transformer architecture [25] that operates on token embeddings and which underpins recent advances in Natural Language Processing [26]. DSH model architectures can be categorized into two primary approaches: single-stream and dual-stream architectures [3], [4]. The former consists of a single module that operates on inputs of different modalities in a uniform manner, whereas the latter employs one module per modality [3], [4]. There also exist hybrid approaches, which combine per-modality feature extraction with a shared hash-learning module [4].

六．结论和未来的工作VI. CONCLUSION AND FUTURE WORK

在本文中，我们在深度语义哈希领域提出了一种新的损失函数，用于跨模态和模内检索的任务。所提出的损失函数“动态语义通道散列”通过在共享汉明空间中根据标签相似性提供连续损失景观和动态目标语义通道宽度来扩展先前的工作。 DSCH 的功效在各种实验设置中得到了证明，将我们的方法与现有双流模型架构和混合流模型架构以及文献中常见的两个数据集的先前工作进行了比较。这些实验表明，所有跨模态任务以及使用图像的模内检索的平局感知平均精度分数显着提高。对于更大的哈希码长度，DSCH 在所有四项任务中都优于竞争对手。选择平局感知 mAP 分数的度量是为了避免由于检索顺序的模糊性而出现的评估偏差，由于共享汉明空间中离散样本到样本距离的数量有限，检索顺序的模糊性是 DSH 域所固有的。In this paper, we have proposed a new loss function in the field of Deep Semantic Hashing for the tasks of cross-modal as well as intra-modal retrieval. The proposed loss function, Dynamic Semantic Channel Hashing, extends prior work by providing a continuous loss landscape and a dynamic target sematic channel width in the shared Hamming space dependent on label similarity. The efficacy of DSCH was demonstrated in various experimental settings comparing our method with prior work on both an existing dual-stream model architecture and a hybrid-stream model architecture, as well as on two datasets commonly found in literature. These experiments showed significantly better tie-aware Mean Average Precision scores for all cross-modal tasks as well as the intra-modal retrieval using images. For larger hash code lengths, DSCH outperforms its competitors in all four tasks. The metric of tie-aware mAP scores was chosen to avoid evaluation bias emerging from the ambiguity of retrieval ordering, which is inherent to the DSH domain due to a limited amount of discrete sample-to-sample distances in the shared Hamming space.

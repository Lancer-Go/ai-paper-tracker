3 训练细粒度的VLA策略Training Fine-Grained VLA Policies

修复了经过人类验证的细粒度指令后，我们现在研究如何 它们应该被用来训练可引导的 VLA 策略。我们的目标不是 提出新的政策架构，但要隔离其影响 与行动一致的语言监督。因此我们保留 动作和视觉观察固定，仅改变指令 与每个轨迹配对。With human-verified fine-grained instructions fixed, we now study how they should be used to train steerable VLA policies. A.8.3 局限性Limitations

目前的工作有两个主要局限性。首先，虽然RoboFine-VLM提供 高质量的可扩展注释，生成注释的一小部分 仍然需要人工验证，因此管道并没有完全消除 人在回路监督。其次，虽然该方法已验证 多个数据集、RoboTwin 和一组现实世界任务、更广泛的验证 跨越额外的机器人实施例和更多的现实世界任务 仍然是未来的工作。The current work has two main limitations. First, although RoboFine-VLM provides high-quality scalable annotation, a small portion of generated annotations still requires manual verification, so the pipeline does not fully eliminate human-in-the-loop supervision. Second, while the method is validated on multiple datasets, RoboTwin, and a set of real-world tasks, broader validation across additional robot embodiments and a larger set of real-world tasks remains future work.

A.8.4 社会影响和安全Societal Impact and Safety

细粒度的语言监督可以提高可控性和 通过使执行约束更加明确来提高机器人行为的透明度。 同时，在真实的机器人系统上部署仍然需要外部 安全限制，因为不正确的接地，幻觉的动作细节， 或控制失败可能会导致意外的物理交互。Fine-grained language supervision can improve the controllability and transparency of robot behavior by making execution constraints more explicit. At the same time, deployment on real robotic systems still requires external safety constraints, because incorrect grounding, hallucinated action details, or control failures may lead to unintended physical interactions.

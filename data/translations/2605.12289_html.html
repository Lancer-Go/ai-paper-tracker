摘要Abstract

利用大型语言模型 (LLM) 丰富的世界知识来增强强化学习 (RL) 代理，为通向通用智能提供了一条有希望的道路。 然而，一个基本的先验动态不匹配阻碍了现有的方法：静态法学硕士知识无法直接适应长期任务的复杂过渡动态。 使用 LLM 先验作为固定策略限制了探索多样性，因为先验对特定环境的动态视而不见；而端到端微调则面临优化不稳定和信用分配问题。 为了弥补这一差距，我们建议Leveraging the rich world knowledge of Large Language Models (LLMs) to enhance Reinforcement Learning (RL) agents offers a promising path toward general intelligence. However, a fundamental prior-dynamics mismatch hinders existing approaches: static LLM knowledge cannot directly adapt to the complex transition dynamics of long-horizon tasks. Using LLM priors as fixed policies limits exploration diversity, as the prior is blind to environment-specific dynamics; while end-to-end fine-tuning suffers from optimization instability and credit assignment issues. To bridge this gap, we propose先验零PriorZero，一个统一的框架，通过解耦的推出培训设计将法学硕士衍生的概念先验集成到基于世界模型的规划中。 在推出过程中，一种新颖的根先验注入机制仅在蒙特卡罗树搜索（MCTS）的根节点结合了LLM先验，将搜索重点放在语义上有希望的动作上，同时保留了世界模型的深度前瞻能力。 在训练过程中，PriorZero将世界模型学习与LLM适应解耦：世界模型根据交互数据不断完善，以共同改进其动态、政策和价值预测，然后利用其价值估计为稳定的LLM微调提供细粒度的学分分配信号，通过交替优化。 跨不同基准的实验，包括 Jericho 中基于文本的冒险游戏和 BabyAI 中的遵循指令的网格世界任务，表明 PriorZero 持续提高探索效率和渐近性能，为 LLM 授权的决策建立一个有前景的框架。 我们的代码位于, a unified framework that integrates LLM-derived conceptual priors into world-model-based planning through a decoupled rollout-training design. During rollout, a novel root-prior injection mechanism incorporates LLM priors exclusively at the root node of Monte Carlo Tree Search (MCTS), focusing search on semantically promising actions while preserving the world model’s deep lookahead capability. During training, PriorZero decouples world-model learning from LLM adaptation: the world model is continuously refined on interaction data to jointly improve its dynamics, policy, and value predictions, its value estimates are then leveraged to provide fine-grained credit assignment signals for stable LLM fine-tuning via alternating optimization. Experiments across diverse benchmarks, including text-based adventure games in Jericho and instruction-following gridworld tasks in BabyAI, demonstrate that PriorZero consistently improves both exploration efficiency and asymptotic performance, establishing a promising framework for LLM-empowered decision-making. Our code is available athttps://github.com/opendilab/LightZero.

1 简介Introduction

大型语言模型 (LLM) 编码广泛的语义和常识知识，这些知识可以使强化学习 (RL) 代理在语言条件、具体化和交互式决策任务中显着受益Large Language Models (LLMs) encode broad semantic and commonsense knowledge that can significantly benefit reinforcement learning (RL) agents in language-conditioned, embodied, and interactive decision-making tasks(Huang et al., 2022; Ahn et al., 2022; Li et al., 2022; Carta et al., 2023)。这些知识在奖励稀疏的长期环境中特别有价值，在这种环境中，纯粹的试错探索往往需要高昂的交互成本。. Such knowledge is particularly valuable in long-horizon environments with sparse rewards, where purely trial-and-error exploration often entails prohibitive interaction costs.

然而，将法学硕士的静态、声明性知识转移到动态强化学习任务仍然具有挑战性。核心困难在于先验动态不匹配：法学硕士擅长语义合理性和高级推理，而强化学习智能体必须对特定环境的转换进行建模、分配长期信用并根据反馈进行计划。现有的范式以不同的方式暴露了这种不匹配。直接使用LLM作为政策However, transferring the static, declarative knowledge of LLMs to dynamic RL tasks remains challenging. The core difficulty lies in a prior–dynamics mismatch: LLMs excel at semantic plausibility and high-level reasoning, whereas RL agents must model environment-specific transitions, assign long-term credit, and plan under feedback. Existing paradigms expose this mismatch in different ways. Directly using an LLM as a policy(Huang et al., 2022; Ahn et al., 2022; Huang et al., 2023)通常会导致短视决策，因为语言可能性并不等于环境回报。 LLM 政策的端到端 RL 微调often leads to myopic decisions because linguistic likelihood is not equivalent to environment return. End-to-end RL fine-tuning of LLM policies(Carta et al., 2023)引入了环境反馈，但在长期稀疏奖励任务中存在高方差信用分配和可扩展性差的问题。使用语言模型作为动力学模型introduces environment feedback, but suffers from high-variance credit assignment and poor scalability in long-horizon sparse-reward tasks. Using language models as dynamics models(Lin et al., 2024)可以利用语言条件预测，但准确的动作条件转换建模仍然很困难：LLM是通过令牌级自回归目标进行预训练的，而潜在动态模型必须预测状态-动作级别的状态转换——这种粒度差距阻止了预训练的知识直接重用于动态学习。 最后，将法学硕士视为冻结的代表can leverage language-conditioned prediction, but accurate action-conditioned transition modeling remains difficult: LLMs are pretrained via token-level autoregressive objectives, whereas latent dynamics models must predict state transitions at the state-action level—this granularity gap prevents the pretrained knowledge from being directly reused for dynamics learning. Finally, treating LLMs as frozen representations(Li et al., 2022)提高了样本效率，但限制了特定任务的适应。improves sample efficiency but limits task-specific adaptation.

为了解决这些瓶颈，我们提出了 PriorZero，一个将 LLM 语义先验集成到基于世界模型的潜在规划中的统一框架。基于基于模型的强化学习和潜在世界模型的最新进展To address these bottlenecks, we propose PriorZero, a unified framework that integrates LLM semantic priors into world-model-based latent planning. Building upon recent advancements in model-based RL and latent world models(Hansen et al., 2024; Wang et al., 2024b; Pu et al., ; Xuan et al., 2024; Niu et al., 2024; Pu et al., 2025)，PriorZero 在 LLM 和环境之间放置了一个可学习的世界模型。这种设计使法学硕士能够提供有价值的语义指导，同时将转换建模、价值估计和多步骤规划委托给世界模型。 PriorZero 通过两种互补机制将部署和培训过程解耦。, PriorZero places a learnable world model between the LLM and the environment. This design enables the LLM to provide valuable semantic guidance while delegating transition modeling, value estimation, and multi-step planning to the world model. PriorZero decouples the rollout and training processes through two complementary mechanisms.

6 结论Conclusion

我们引入了 PriorZero，这是一个统一的框架，可以解决We introduced PriorZero, a unified framework that addresses the先验动力学失配prior-dynamics mismatch通过解耦的推出训练设计，在预训练的 LLM 和长期 RL 优化之间进行优化。 在推出期间，仅根注入仅在 MCTS 根节点融合 LLM 先验，引导搜索进行语义上合理的操作，同时保留世界模型的多步前瞻能力。 在训练过程中，交替微调使用世界模型价值估计来构建更好的优势信号，为 LLM 适应提供稳定的策略梯度。 这些组件共同形成一个闭环，其中世界模型和 LLM 相互加强：LLM 的先验集中于搜索，而世界模型的规划则完善了 LLM 的先验。 Jericho 和 BabyAI 上的实验验证了 PriorZero 持续改进探索和回报；消融确认每个组件 是必要的，并且该框架可以根据 LLM 能力进行扩展。between pretrained LLM and long-horizon RL optimization through a decoupled rollout-training design. During rollout, root-only injection fuses LLM priors exclusively at the MCTS root node, guiding search toward semantically plausible actions while preserving the world model’s multi-step lookahead capacity. During training, alternating fine-tuning uses world-model value estimates to construct better advantage signals, providing stable policy-gradient for LLM adaptation. Together, these components form a closed loop in which the world model and LLM mutually reinforce each other: the LLM’s priors focus the search, and the world model’s planning refines the LLM’s priors. Experiments on Jericho and BabyAI validate that PriorZero consistently improves exploration and return; ablations confirm that each component is necessary, and that the framework scales with LLM capacity.

附录CAppendix C代理提示设计Agent Prompt Design

本节提供多代理合成管道使用的完整提示模板。每个代理都是作为基于 LLM 的组件实现的，具有精心设计的系统和用户提示，以确保高质量的数据生成。This section provides the complete prompt templates used by the multi-agent synthesis pipeline. Each agent is implemented as an LLM-based component with carefully designed system and user prompts to ensure high-quality data generation.

C.1 规划代理Planner Agent

规划器代理负责生成一个新颖的函数调用序列，该序列与边界种子任务的结构复杂性相匹配，同时在特定函数和场景中引入变化。The Planner Agent is responsible for generating a novel function call sequence that matches the structural complexity of the boundary seed task while introducing variation in the specific functions and scenario.

C.2 配置补丁代理（错误批评家）Config Patch Agent (Error Critic)

配置补丁代理分析执行失败并生成环境配置补丁以解决状态冲突。该代理实现了综合管道阶段 II 中描述的环境补丁机制。The Config Patch Agent analyzes execution failures and generates environment configuration patches to resolve state conflicts. This agent implements the Environment Patches mechanism described in Stage II of the synthesis pipeline.

连贯重写代理通过生成自然用户查询来执行整体语义基础（第三阶段），这些查询在潜在叙述的指导下在所有回合中都具有语义连贯性。The Coherence Rewrite Agent performs holistic semantic grounding (Stage III) by generating natural user queries that are semantically coherent across all turns, guided by the latent narrative.

C.4 质量评审代理Quality Judge Agent

C.5 细化分类代理Refine Classify Agent

当质量法官拒绝样本时，细化分类代理会确定问题是否可以通过重写用户查询来解决，或者基本事实本身是否无法修复。When the Quality Judge rejects a sample, the Refine Classify Agent determines whether the issue can be fixed by rewriting the user query or if the ground truth itself is unfixable.

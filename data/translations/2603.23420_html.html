摘要Abstract

如果自动研究本身就是一种研究形式，那么自动研究就可以应用 研究If autoresearch is itself a form of research, then autoresearch can be applied to research本身itself。 我们从字面上理解这个想法： 我们使用自动研究循环来优化自动研究循环。. We take this idea literally: we use an autoresearch loop to optimize the autoresearch loop.

每个现有的自动研究系统——从卡帕蒂的单轨循环到 AutoResearchClaw 的多批次扩展和 EvoScientist 的持久性 记忆力——得到了改善Every existing autoresearch system—from Karpathy’s single-track loop to AutoResearchClaw’s multi-batch extension and EvoScientist’s persistent memory—was improved by a人类的human阅读代码的人发现了 瓶颈，并编写新代码。 我们询问法学硕士是否可以自主地做同样的事情。who read the code, identified a bottleneck, and wrote new code. We ask whether an LLM can do the same, autonomously.

我们呈现We present双层自动研究Bilevel Autoresearch，一个双层框架，其中外循环 通过生成和注入新的元优化内部自动研究循环 运行时作为 Python 代码的搜索机制。 内循环优化任务；外循环优化内循环的方式 循环搜索。 两个循环都使用相同的 LLM——在元级别不需要更强的模型。, a bilevel framework where an outer loop meta-optimizes the inner autoresearch loop by generating and injecting new search mechanisms as Python code at runtime. The inner loop optimizes the task; the outer loop optimizes how the inner loop searches. Both loops use the same LLM—no stronger model is needed at the meta level.

在 Karpathy 的 GPT 预训练基准上，元自动研究外循环 达到5分On Karpathy’s GPT pretraining benchmark, the meta-autoresearch outer loop achieves a 5×\times对单独标准内循环的改进 （improvement over the standard inner loop alone (−0.045-0.045与vs.−0.009-0.009 val_bpb），而参数级调整无需 机制的改变不会产生可靠的收益。 外循环自主地从组合中发现机制 优化、多臂老虎机和实验设计——无人参与 规范要探索的领域。 这些机制通过打破内循环的确定性搜索而取得成功 模式，迫使探索法学硕士先验系统地回避的方向。), while parameter-level adjustment without mechanism change yields no reliable gain. 2.1 自动研究和法学硕士驱动的优化Autoresearch and LLM-Driven Optimization

Karpathy (2026)引入了典型的自动研究循环 对于神经网络超参数搜索：法学硕士读取训练脚本， 提出配置更改、执行固定预算培训、措施 验证丢失，并接受或拒绝更改。 迭代，这构成了LLM引导爬山配置的一种形式 空间，法学硕士的世界知识作为隐含的先验 有希望的变化和培训结果提供了无梯度的反馈。introduced the paradigmatic autoresearch loop for neural network hyperparameter search: an LLM reads a training script, proposes a configuration change, executes training for a fixed budget, measures validation loss, and accepts or rejects the change. Iterated, this constitutes a form of LLM-guided hill climbing in configuration space, where the LLM’s world knowledge serves as an implicit prior over promising changes and training outcomes provide gradient-free feedback.

自动研究爪AutoResearchClaw(AIMing Lab, 2026)扩展这个框架 多批次并行性：评估多个候选配置 同时，最优秀的人会得到晋升。 这增加了搜索的有效分支因子而不改变 底层接受机制。extends this framework with multi-batch parallelism: several candidate configurations are evaluated simultaneously, and the best is promoted. This increases the effective branching factor of search without altering the underlying acceptance mechanism.

进化科学家EvoScientist(EvoScientist Contributors, 2026)引入持久经验记忆： 总结以前运行的经验教训并将其注入未来的提案中， 实现交叉运行学习。 这两项增强功能都是由人类研究人员设计的，他们检查了 先前系统的代码并确定了架构缺陷。 在所有三个系统中，结构性决策——何时接受、如何接受 建议，维持什么状态——是由人类设计师而不是由 系统本身。introduces persistent experience memory: lessons from prior runs are summarized and injected into future proposals, enabling cross-run learning. Both of these enhancements were designed by human researchers who inspected the prior system’s code and identified architectural gaps. In all three systems, the structural decisions—when to accept, how to propose, what state to maintain—are made by human designers, not by the system itself.

6 结论Conclusion

双层自动研究表明法学硕士可以自主提高自己的水平 通过在运行时生成和注入新的搜索机制来进行自动研究循环。 在 Karpathy 的 GPT 基准上，2 级产生 5Bilevel Autoresearch demonstrates that an LLM can autonomously improve its own autoresearch loop by generating and injecting new search mechanisms at runtime. On Karpathy’s GPT benchmark, Level 2 produces a 5×\times val_bpb相对于单独的内循环的改进（improvement over the inner loop alone (−0.045-0.045与vs.−0.009-0.009），同时 参数级调整（级别 1.5）不会产生可靠的增益。 生成的机制——来自组合优化，在线 学习和实验设计——通过强迫探索来成功 LLM 的默认搜索路径避免的方向。), while parameter-level adjustment (Level 1.5) yields no reliable gain. The generated mechanisms—drawn from combinatorial optimization, online learning, and design of experiments—succeed by forcing exploration of directions the LLM’s default search path avoids.

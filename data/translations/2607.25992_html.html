摘要。Abstract.

最近，内存管理已成为基于 LLM 的代理的关键基础设施，因为它直接影响长期推理、个性化响应和知识重用。 然而，现有的LLM内存系统通常采用粗粒度（与实用程序无关或启发式实用程序）方式，统一处理异构用户-LLM交互记录，导致内存存储库中持久存在冗余和低影响的记录。 为了应对这一挑战，我们提出Recently, memory management has become a key infrastructure for LLM-based agents, as it directly affects long-horizon reasoning, personalized responses, and knowledge reuse. However, existing LLM memory systems typically adopt a coarse-grained (utility-agnostic or heuristic utility) manner that treats heterogeneous user-LLM interaction records uniformly, leading to redundant and low-impact records persisting in the memory repository. To address this challenge, we present记忆透镜MemLens，一个值感知的内存管理系统，将内存记录作为一流的数据对象。, a value-aware memory management system that takes memory records as first-class data objects.记忆透镜MemLens提供端到端的交互式分析仪表板，公开完整的内存生命周期，包括 Shapley 式内存评估、价值感知存储和内存辅助响应。 通过学习副驾驶应用程序，该系统使用户能够检查内存值、可视化分层内存结构，并在响应质量、检索延迟和令牌消耗方面比较各种内存管理策略。 因此，我们的provides an end-to-end interactive analytics dashboard that exposes the complete memory lifecycle, including Shapley-style memory evaluation, value-aware storage, and memory-assisted response. Through a study-copilot application, the system enables users to inspect memory values, visualize hierarchical memory structures, and compare various memory management strategies in terms of response quality, retrieval latency, and token consumption. Therefore, our记忆透镜MemLens可以作为代理的高效、可解释和个性化的长期记忆管理系统。can serve as an efficient, interpretable, and personalized long-term memory management system for agents.

1. 简介Introduction

内存数据管理已成为基于 LLM 的代理的关键基础设施层，支持长期任务执行、个性化交互和跨会话知识重用。 从数据管理的角度来看，代理内存本质上是Memory data management has emerged as a key infrastructure layer for LLM-based agents, enabling long-horizon task execution, personalized interactions, and cross-session knowledge reuse. From a data management perspective, agent memory is inherently异质的heterogeneous。 除了对话历史之外，可重用内存还可能来自中间推理轨迹、检索到的文档和工具执行输出。 随着代理运行较长的会话，记录会累积到不断增长的可重用上下文存储库中，从而使有效的内存管理变得越来越重要。. Beyond dialogue histories, reusable memory may also arise from intermediate reasoning traces, retrieved documents, and tool execution outputs. As agents operate over longer sessions, records accumulate into a growing repository of reusable context, making effective memory management increasingly important.

然而，现有的LLM记忆系统However, existing LLM memory systems(Zhang et al., 2025; Hu et al., 2025; Chhikara et al., 2025; Fu et al., 2026)通常以粗粒度的方式管理内存。 他们要么typically manage memory in a coarse-grained manner. They either保留几乎所有retain nearly all候选记录或使用压缩它们candidate records or compress them using总结导向summary-oriented启发式，没有明确建模哪些内存单元对未来的任务真正有用。 随着内存的积累，与效用无关或启发式评分策略允许冗余和低影响的记录保留在存储库中，这可以稀释与任务相关的上下文，扩大检索空间，并在响应生成过程中消耗不必要的令牌开销（见图 1）。heuristics, without explicitly modeling which memory units are truly useful for future tasks. As memory accumulates, the utility-agnostic or heuristic scoring strategy allows redundant and low-impact records to persist in the repository, which can dilute task-relevant context, enlarge the retrieval space, and consume unnecessary token overhead during response generation (see Fig.1).

核心挑战是内存的有用性The core challenge is that memory usefulness is既不统一也不静态neither uniform nor static。 对一个未来查询有益的内存单元可能与另一个查询无关，并且其贡献也可能取决于哪些其他内存单元已经可用。 因此，有效的内存管理需要的不仅仅是一般性的总结。 这需要一种有原则的方法. A memory unit that is beneficial for one future query may be irrelevant for another, and its contribution may also depend on which other memory units are already available. Thus, effective memory management requires more than generic summarization. It requires a principled way to估计下游效用estimate the downstream utility异构内存单元，同时保持这种估计of heterogeneous memory units, while keeping such estimation高效efficient足以支持实际的存储和检索决策。enough to support practical storage and retrieval decisions.

内存单元构造。Memory Unit Construction. 记忆透镜MemLens将原始用户-LLM 交互记录转换为结构化内存单元。 首先，为了进行细粒度分析，将原始记录分割成句子级原子单元。 然后，系统通过 LLM 将记忆单元分组为多级摘要，提供分层记忆结构，捕获详细语义和高级知识。 我们还维护从汇总节点到原子存储单元的起源链接 以避免信息丢失。 这种设计允许converts raw user-LLM interaction records into structured memory units. Firstly, for fine-grained analysis, the raw record is segmented into sentence-level atomic units. The system then groups the memory units into multi-level summaries via LLMs, providing a hierarchical memory structure that captures both detailed semantics and high-level knowledge. We maintain provenance links from summarized nodes to the atomic memory units as well to avoid the information loss. This design allows the记忆透镜MemLens系统将多个低效用片段替换为单个高价值替代品，这可能会提高存储效率和内存质量。system to replace multiple low-utility fragments into a single high-value alternative, which potentially improves both storage efficiency and memory quality.

3.3. 记忆辅助反应Memory-Assisted Response

该模块使用价值感知内存和用户配置文件来生成个性化响应，然后允许用户存档已完成的会话以进行持续的内存演变和管理。This module uses value-aware memories and user profiles to generate personalized responses, then allows users to archive completed sessions for continuous memory evolution and management.

一、简介1. Introduction

开源博弈论研究代理人能够检查彼此内部决策程序的环境。在经典的程序均衡框架中，玩家提交的程序可以在底层基础游戏中输出动作之前检查对手的程序（Tennenholtz，2004；Fortnow，2009）。这种可能性可以从质上改变智能体的战略推理，因此合作、惩罚和协调可能取决于智能体证明、模拟或推断其对手内部政策的情况，产生与基础正常形式博弈的纳什均衡截然不同的结果（LaVictoire et al., 2014; Critch, 2019; Critch et al., 2022）。然而，大多数现有的开源模型都是符号性或证明理论的（Oesterheld，2019；Barasz 等，2021），而现代学习系统通常是连续的、可微的，并且由高维向量参数化（Mnih 等，2015；Vaswani 等，2017；Silver 等，2017）。相反，可微博弈和多智能体优化研究平滑参数化目标，但通常将每个玩家的策略视为仅取决于其自己的参数（Fudenberg 和 Levine，1998；Basar 和 Olsder，1999；Chasnov 等人，2020；Mazumdar 等人，2020；Lin 等人，2020）。Open-source game theory studies settings where agents are able to inspect one another’s internal decision procedures. In the classical program equilibrium framework, players submit programs that may inspect the opponent’s program before outputting an action in an underlying base game (Tennenholtz, 2004; Fortnow, 2009). This possibility can qualitatively change the strategic reasoning of agents and consequently cooperation, punishment, and coordination may become contingent on what an agent proves, simulates, or infers about its opponent’s internal policy, yielding outcomes that differ sharply from the Nash equilibria of the underlying normal form game (LaVictoire et al., 2014; Critch, 2019; Critch et al., 2022). Most existing open-source models are nevertheless symbolic or proof-theoretic (Oesterheld, 2019; Barasz et al., 2021), while modern learning systems are usually continuous, differentiable, and parameterized by high-dimensional vectors (Mnih et al., 2015; Vaswani et al., 2017; Silver et al., 2017). Conversely, differentiable games and multi-agent optimization study smooth parameterized objectives, but usually treat each player’s policy as depending only on its own parameters (Fudenberg and Levine, 1998; Basar and Olsder, 1999; Chasnov et al., 2020; Mazumdar et al., 2020; Lin et al., 2020).

在这项工作中，我们开发了一个参数模型，该模型保留了核心开源功能，即玩家的行为可能取决于对手的内部描述，同时启用持续优化的标准工具。在一个In this work, we develop a parametric model that preserves the central open-source feature, namely that a player’s behavior may depend on an opponent’s internal description, while enabling standard tools from continuous optimization. 4 讨论与结论4. Discussion and Conclusion

我们引入参数开源游戏作为战略交互的连续模型，其中每个代理选择一个参数向量，并且语义映射将完整的参数配置文件转换为底层有限游戏中的混合动作。该模型保留了开源推理的核心机制（Tennenholtz，2004），即策略行为可能以另一个代理的内部描述为条件，同时使最终的游戏适合来自持续优化和可微游戏的工具。We introduced parametric open-source games as a continuous model of strategic interaction in which each agent chooses a parameter vector and a semantics map converts the full parameter profile into mixed actions in an underlying finite game. The model preserves the central mechanism of open-source reasoning (Tennenholtz, 2004), namely that strategic behavior may be conditioned on another agent’s internal description, while making the resulting game amenable to tools from continuous optimization and differentiable games.

在这个框架内，我们的结果表明，开源依赖可以重塑学习动态和平衡结构，类似于程序平衡设置（Tennenholtz，2004；Fortnow，2009；LaVictoire 等，2014）。这项工作中研究的开源语义学的 s 型和神经网络都表现出相同的组织原则：当跨玩家敏感性相对于自我敏感性足够大时，合作就会变得局部有吸引力。对于 sigmoid 模型，这会产生显式的临界耦合，而对于神经模型，通过跨玩家和自身玩家灵敏度之间的一阶比率保留了相同的条件。然后，我们通过使用边界最佳响应扫描将局部动态分析与全局平衡验证分开，该扫描测试候选极限点对于单边偏差是否稳定。Within this framework, our results show that open-source dependence can reshape both learning dynamics and equilibrium structure, analogous to the program equilibrium setting (Tennenholtz, 2004; Fortnow, 2009; LaVictoire et al., 2014). The sigmoidal and neural families of open-source semantics studied within this work both exhibit the same organizing principle: cooperation becomes locally attractive when cross-player sensitivity is sufficiently large relative to self-sensitivity. For the sigmoid model, this yields an explicit critical coupling, while for the neural model, the same condition is preserved through the first-order ratio between cross-player and self-player sensitivity. We then separate this local dynamical analysis from global equilibrium verification by using boundary best-response sweeps, which test whether a candidate limit point is stable against unilateral deviations.

所提出的模型是有意理想化的。他们假设可以完全访问对手参数，专注于对称两人示例，并研究单次基础游戏。尽管如此，它们为研究内部表示的透明度如何影响参数化多智能体系统中的激励、学习动态和均衡结构提供了一个可解释的起点。未来的工作应该通过考虑部分或噪声透明度、可证明的属性而不是完整的参数公开、不对称语义、更大的群体和序列环境（例如马尔可夫博弈）来放松这些假设。这些扩展将使框架更直接地连接到现实的多智能体系统，其中智能体可能只能观察到有关彼此内部结构的不完整但具有战略相关性的信息。总体而言，参数化开源游戏表明，内部参数访问不是表面的建模细节，但它可以改变基于梯度的学习所产生的激励，同时引入有关如何表示、优化和验证此类访问的新的稳健性问题。The presented models are intentionally idealized. They assume full access to opponent parameters, focus on symmetric two-player examples, and study one-shot base games. Nevertheless, they provide an interpretable starting point for studying how transparency over internal representations can affect incentives, learning dynamics, and equilibrium structure in parametric multi-agent systems. Future work should relax these assumptions by considering partial or noisy transparency, certifiable properties instead of full parameter disclosure, asymmetric semantics, larger populations, and sequential environments such as Markov games. These extensions would connect the framework more directly to realistic multi-agent systems, where agents may observe only incomplete but strategically relevant information about one another’s internal structure. Overall, parametric open-source games suggest that internal parameter access is not a superficial modeling detail, but it can change the incentives created by gradient-based learning, while introducing new robustness questions about how such access is represented, optimized, and verified.

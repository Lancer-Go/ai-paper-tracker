SparseBalance：具有动态稀疏注意力的负载平衡长上下文训练SparseBalance: Load-Balanced Long Context Training with Dynamic Sparse Attention

Hongtao Xu1,2, Jianchao Tan2, Yuxuan Hu2, Pengju Lu1, Hongyu Wang1, Pingwei Sun2,
Yerui Sun2, Yuchen Xie2, Xunliang Cai2, Mingzhen Li3,*, and Weile Jia3,*
摘要Abstract

虽然稀疏注意力缓解了长上下文 LLM 训练的计算瓶颈，但其分布式训练过程在两个方面都表现出极大的异质性：While sparse attention mitigates the computational bottleneck of long-context LLM training, its distributed training process exhibits extreme heterogeneity in both1)序列长度和sequence length and2)稀疏敏感性，导致严重的不平衡问题和次优的模型精度。现有的算法和训练框架通常关注单一问题，未能系统地共同优化这两个问题。 因此，我们提出了SparseBalance，一种新颖的算法系统协同设计框架，它利用稀疏性和序列异构性来共同优化模型精度和系统效率。 首先，我们提出了工作负载感知的动态稀疏度调整，它采用双向稀疏度调整来消除掉队者并利用固有的气泡来实现自由精度。其次，我们提出了一种稀疏感知批处理策略来实现粗粒度平衡，这补充了动态稀疏调整。 实验结果表明 SparseBalance 达到了 1.33sparsity sensitivity, leading to a severe imbalance problem and sub-optimal model accuracy. Existing algorithms and training frameworks typically focus on single issue, failing to systematically co-optimize these two problems. Therefore, we propose SparseBalance, a novel algorithm-system co-design framework, which exploits the sparsity and sequence heterogeneity to optimize model accuracy and system efficiency jointly. First, we propose workload-aware dynamic sparsity tuning, which employs a bidirectional sparsity adjustment to eliminate stragglers and exploit inherent bubbles for free accuracy. Second, we propose a sparsity-aware batching strategy to achieve coarse-grained balance, which complements dynamic sparsity tuning. Experimental results demonstrate that SparseBalance achieves up to a 1.33×\times端到端加速，同时在 LongBench 基准上仍将长上下文能力提高 0.46%。end-to-end speedup while still improving the long-context capability by 0.46% on the LongBench benchmark.

I 简介Introduction

长上下文建模能力对于大型语言模型 (LLM) 的发展越来越重要，成为代码生成、深度推理和自主代理系统等高级下游应用程序的支柱。主流法学硕士通常会对特定的长上下文数据集执行额外的训练阶段，以扩展上下文窗口The long-context modeling capability is increasingly crucial for the evolution of Large Language Models (LLMs), serving as the backbone for advanced downstream applications such as code generation, in-depth reasoning, and autonomous agent systems. Mainstream LLMs typically perform an additional training stage on specific long-context datasets to extend the context windows[1, 2, 3, 4]。然而，随着上下文长度的增加，标准注意力机制成为主要的计算瓶颈。由于标准注意力需要计算所有标记对的亲和力，因此它表现出相对于序列长度的二次计算复杂性，从而严重阻碍了上下文扩展。为了缓解这一问题，在最近发布的法学硕士中，稀疏注意力已成为一种有前途的解决方案. However, as the context length increases, the standard attention mechanism becomes the primary computational bottleneck. Because standard attention requires computing affinities across all token pairs, it exhibits a quadratic computational complexity with respect to sequence length, thus severely hindering the context expansion. To mitigate this, sparse attention has emerged as a promising solution in recent released LLMs[5, 6]。通过选择性地计算关键标记，稀疏注意力降低了计算复杂度并打破了性能瓶颈。. By selectively computing the critical tokens, sparse attention reduces the computational complexity and breaks the performance bottleneck.

然而，长上下文稀疏训练仍然面临着由序列长度分布固有的异质性引起的严重的负载不平衡问题。比如Qwen2.5技术报告However, long-context sparse training still faces a severe load imbalance problem caused by the inherent heterogeneity in sequence length distributions. For instance, the Qwen2.5 technical report[3]公开了他们在长上下文训练阶段的数据混合策略，其中包括 40% 的长序列和 60% 的短序列。这种序列长度的异质性导致分布式训练中严重的负载不平衡问题，显着降低系统效率。现有的工作试图通过批处理或打包策略来缓解这个问题。然而，由于装箱问题本质上是离散的，这些方法很难完全解决问题，特别是对于高度倾斜的数据集。这种不平衡体现在分布式训练的多个并行维度上。在内层管道并行（PP）中，不同的工作负载会加剧管道泡沫，并且极长序列的处理时间本质上主导着整体管道延迟。更糟糕的是，PP的这种不平衡最终会传播到数据并行（DP）等外层并行，严重放大系统效率的下降。discloses their data mix strategy at long context training stage, which comprises 40% long sequences and 60% short sequences. This heterogeneity in sequence length leads to severe load imbalance problem in distributed training, significantly degrading the system efficiency. Existing works attempt to alleviate this issue through batching or packing strategies. However, these methods can hardly solve the problem completely due to the inherently discrete nature in this bin-packing problem, especially for highly skewed datasets. This imbalance manifests across multiple parallelism dimensions in distributed training. In inner-level pipeline parallelism (PP), varying workloads exacerbate pipeline bubbles, and the processing time of extremely long sequences essentially dominates the overall pipeline latency. Worse still, this imbalance in PP ultimately propagates to the outer-level parallelism like data parallelism (DP), severely amplifying the degradation of system efficiency.

同时，稀疏训练引入了稀疏敏感性的另一个关键异质性。尽管现有的可训练稀疏注意力算法通常采用预定义的稀疏度，Meanwhile, sparse training introduces another critical heterogeneity in sparsity sensitivity. II 背景Background

Ⅱ-AII-A 分布式训练策略Distributed Training Strategies

数据并行性 (DP)Data Parallelism (DP) [7]将全局训练批次划分给多个工作人员。在每次迭代中，每个工作人员独立处理其分配的数据子集并计算局部梯度。在每次迭代结束时，DP 都会强制执行严格的同步屏障，要求所有工作人员在更新模型权重之前同步其梯度。这种固有的同步机制迫使所有工作人员等待最慢的工作人员（即掉队者）到达障碍，使得 DP 对工作负载不平衡高度敏感。partitions the global training batch across multiple workers. In each iteration, every worker independently processes its assigned subset of data and computes the local gradients. At the end of each iteration, DP enforces a rigid synchronization barrier, requiring all workers to synchronize their gradients before updating the model weights. This inherent synchronization mechanism forces all workers to wait for the slowest worker (i.e., the straggler) to reach the barrier, making DP highly sensitive to workload imbalances.

管道并行度 (PP)Pipeline Parallelism (PP) [8, 9, 10, 11]将模型层分为连续的阶段，每个阶段分配给不同的 PP 工作人员。为了最大限度地提高硬件利用率，现有方法通过将输入数据划分为多个微批次来将模型执行编排到管道中。然后，这些微批次通过点对点通信顺序遍历所有 PP 等级，以在阶段之间传递激活和梯度。然而，PP本身就存在管道气泡问题。在高度异构的工作负载下，这个问题会严重加剧，因为单级中的任何执行延迟都会级联到整个管道。splits the model layers into sequential stages, with each stage assigned to a different PP worker. To maximize hardware utilization, existing methods orchestrate model execution into a pipeline by dividing the input data into multiple micro-batches. These micro-batches then sequentially traverse all PP ranks via point-to-point communication to deliver activations and gradients between stages. However, PP inherently suffers from the pipeline bubble problem. This issue is severely exacerbated under highly heterogeneous workloads, as any execution delay in a single stage cascades throughout the entire pipeline.

张量并行度 (TP)Tensor Parallelism (TP) [12]将张量运算划分到设备上，每个设备处理一部分张量运算。使用TP，每个GPU只有部分输入和参数，导致训练期间通信密集。因此，TP 通常应用于单个节点内，而其他级别的并行性则应用于跨节点。divides the tensor operations across devices, and each device handles a slice of the tensor operations. With TP, each GPU only has part of the input and parameters, resulting in intensive communication during training. Therefore, TP is typically applied within a single node, while other levels of parallelism are applied across nodes.

现有的长上下文训练方法通常依赖于批处理或打包策略来缓解序列长度异质性引起的不平衡问题。 然而，由于批次构建固有的离散性质，这些方法无法从根本上消除不平衡，特别是在高度倾斜的序列长度分布下。即使进行了仔细的数据改组，包含难以打包序列的单个微批次仍然可能成为关键路径上的掉队者，从而延迟整个迭代。因此，需要更细粒度的负载均衡机制来缓解这个问题。Existing methods for long-context training typically rely on batching or packing strategies to alleviate the imbalance problem induced by the heterogeneity in sequence length. To mitigate this issue, various batching and scheduling techniques have been proposed[22, 20, 21, 31]。例如，LongAlign 采用排序批处理，在全局批处理中按长度对序列进行分组. Furthermore, existing works are largely designed for dense attention training and fall short in sparse scenarios. As a result, they do not address the additional workload uncertainty introduced by dynamic sparse attention.

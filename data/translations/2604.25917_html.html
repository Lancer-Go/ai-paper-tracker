1 简介Introduction

为了处理复杂的任务，单一语言模型通常会因容量有限、生成短视或解决方案空间探索效率低下而显得不足To tackle complex tasks, a single language model often falls short due to limited capacity, myopic generation, or inefficient exploration of the solution space(Shojaee et al., 2025; Song et al., 2026; Li et al., 2025b)。 一旦智能达到阈值，一个自然的方向是将单个模型视为专门的代理并将它们组织为协作系统. Once intelligence reaches a threshold, a natural direction is to treat individual models as specialized agents and organize them as a collaborative system(Tran et al., 2025; Xu et al., 2025)。多代理系统 (MAS). A multi-agent system (MAS)(Wang et al., 2025b; Wu et al., 2024)可以通过让个人一起工作并贡献互补优势来扩大绩效。 考虑一组异构代理，每个代理分配了不同的角色和专业知识。系统可以将代理安排到顺序管道中can scale performance by enabling individuals to work together and contribute complementary strengths. Consider a set of heterogeneous agents, each assigned a distinct role and expertise. The system can either arrange agents into a sequential pipeline(Gu et al., 2025; Qian et al., 2024)逐步分解和解决问题，或参与和集成多个领域专业代理to progressively decompose and solve a problem, or engage and integrate multiple domain-specialized agents(Ye et al., 2025b; Qian et al., 2025; Babu et al., 2025)为了任务。for the task.

MAS建立了结构基础后，下一个问题是如何使系统能够随着时间的推移而演进并适应不同的场景。 之前的工作已经探索了基于提示的适应While MAS establishes a structural foundation, the next question is how to enable the system to evolve over time and adapt to different scenarios. Prior work has explored prompt-based adaptation(Shen et al., 2025; Zhou et al., 2025; Zhang et al., 2025b)，其中模型交互通过共享上下文的迭代细化得到改进。 尽管这些更新的提示可以帮助代理对问题生成更一致的响应，但每个代理本身无法改进。 更原则性的工作路线是通过学习来优化智能体, where model interactions are improved through the iterative refinement of shared context. Although these updated prompts can help agents generate more aligned responses to the question, each agent itself cannot improve. A more principled line of work is to optimize agents through learning(Motwani et al., 2024; Subramaniam et al., 2025; Zhao et al., 2025)。 然而，训练系统内的整个代理很困难，因为更新所有模型参数并非易事. However, training entire agents inside the system is hard, as updating all model parameters is non-trivial(Hu et al., 2025)，并且当代理必须等待其他人完成生成时，基于文本的交互中的顺序依赖性会引入大量延迟。, and the sequential dependency in text-based interactions introduces substantial latency when agents must wait for others to complete generation.

我们不是将每个智能体作为独立组件来提高其能力，而是采用更高层次的学习视角，旨在将整个系统作为一个整体共同进化和扩展。 我们通过递归语言模型 (RLM) 的视角重塑代理协作Instead of improving each agent’s capabilities as a standalone component, we adopt a higher-level learning perspective and aim to co-evolve and scale the entire system as an integrated whole. We recast agent collaboration through the lens of recursive language models (RLMs)(Zhang et al., 2025a; Jolicoeur-Martineau, 2025; Zhu et al., 2025)，其中在连续的潜在空间中迭代应用和优化一组共享层。 从这个角度来看，整个多智能体系统可以被视为递归计算，其中每个智能体就像一个 RLM 层，迭代地将潜在表示传递到下一个智能体并形成循环交互过程。, where a shared set of layers is iteratively applied and optimized within a continuous latent space. In this view, the entire multi-agent system can be treated as a recursive computation, where each agent acts like an RLM layer, iteratively passing latent representations to the next and forming a looped interaction process.
